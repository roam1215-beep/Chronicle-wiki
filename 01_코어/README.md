# 🎯 코어

게임의 정체성. 모든 설계의 상위 기준.

| 문서 | 상태 | 설명 |
|------|------|------|
| 게임 컨셉 | ❌ 미정 | 장르, 플랫폼, 한 문장 정의, 차별점 |
| [핵심 경험 목표](./핵심경험목표.md) | 🔄 설계중 | 플레이어가 느껴야 할 경험 정의 |
| 설계 원칙 | ❌ 미정 | 모든 설계 판단의 상위 원칙 3~5개 |
| 세계관 | ❌ 미정 | 테오도라, 서자부대, 정규군, 전장 배경 |
| 진행 구조 | ❌ 미정 | 런 흐름, 스테이지 연결, 운명 달성 결산, 비용-보상 순환 |
| 레퍼런스 분석 | ❌ 미정 | 참고 게임 비교 분석, 차용/배제 근거 |

### 각 문서의 현황

**핵심 경험 목표** — 코어 판타지 정의 완료. 세 박자는 진행 구조로 이관 예정.

**게임 컨셉** — 핵심 경험 목표와 진행 구조가 잡힌 후 작성 가능.

**설계 원칙** — 대화에서 반복 합의된 원칙들이 문서화 안 됨. 추출 필요:
- "서자니까" — 보급 부족, 정보 부족, 인정받기 위한 무리
- 불완전한 정보 — 정답이 보이지 않는 상태에서 판단
- 되돌릴 수 없는 선택 — 커밋 후 결과를 받아들임
- (추가 정리 필요)

**세계관** — 테오도라, 서자부대 설정이 메커니즘 근거. 위업, 분기 효과, 명령 체계가 전부 세계관에서 파생됨. 문서화 안 되면 매 세션마다 구두 설명 반복.

**진행 구조** — 스테이지 세 박자(읽기→적응→선택)가 여기로 이동 예정. 런 전체 흐름, 운명 달성 결산, 스테이지 간 연결은 미정.

**레퍼런스 분석** — 2026-02-25 세션에서 BB/XCOM/FTL/다던/배너사가/BoR/아르멜로/BG3 분석 완료. 정리 필요.
