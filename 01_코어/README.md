# 🎯 코어

게임의 정체성. 모든 설계의 상위 기준.

| 문서 | 상태 | 설명 |
|------|------|------|
| 게임 개요 | ❌ 미정 | 한 문장 정의, 핵심 경험, 핵심 긴장, 레퍼런스 |
| 코어 루프 | ❌ 미정 | 런 구조, 전투 밖 전략층, 비용-보상 순환 |

### 왜 미정인가

전투 엔진은 시뮬 검증까지 완료됐으나, 상위 구조(코어 루프)가 없어서 하위 시스템 간 정합성 검증이 불가. 스테이지 설계, 메타 시스템, 성장 시스템 모두 코어 루프 확정을 블로커로 갖고 있음.

### 결정에 필요한 것

1. 게임이 플레이어에게 주고 싶은 **핵심 경험** 정의
2. 한 런(스테이지 연속)의 **흐름 구조** 확정
3. 전투 밖 **전략적 판단**이 무엇인지 명시
4. 기존 전투 시스템이 코어 경험에 부합하는지 검증
