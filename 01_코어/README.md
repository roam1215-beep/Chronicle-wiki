### 코어 루프가 미정인 이유

코어 판타지와 스테이지 세 박자가 정의됨. 그러나 다음 항목이 미확정:
1. "큰 선택"의 구체 메커니즘 (명령 변경 방향 유력, 지배 전략 문제 미해결)
2. 야영/성장 시스템 (META-*)
3. 런 전체 흐름 (스테이지 간 연결 구조)
