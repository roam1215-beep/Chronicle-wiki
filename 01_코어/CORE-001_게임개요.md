# CORE-001: 게임 개요 (Game Overview)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** CORE-001 · **수정일:** 2026-02-25

---

## ① 한 줄 요약

수치도 미니맵도 없이, 죽창부대를 이끌고 전쟁의 구멍을 때우는 턴제 전술 로그라이크. 정보 없고, 자원 없고, 장비 없다. 판단만으로 구멍을 막는다.

---

## ② 핵심 경험

| 항목 | 내용 |
|------|------|
| **핵심 긴장** | 부족한 정보로 돌이킬 수 없는 판단을 내리는 것 |
| **플레이어 역할** | 서자 기사 테오도라. 정규군이 아닌 예비 전력. 전쟁의 구멍을 때우는 자 |
| **핵심 루프** | 브리핑(정보 수집) → 스테이지(행군+전투) → 야영(자원 관리) |
| **감정 곡선** | 불안(정보 부족) → 긴장(판단 순간) → 안도 또는 후회(결과 확인) → 적응(다음 판단) |
| **승리 조건** | 스테이지 목표 달성 (세부는 스테이지별 상이) |
| **패배 조건** | 테오도라 사망 = 게임 오버 |

## ③ "서자니까" 원칙

> 모든 메카닉의 존재 이유. "왜 이렇게 만들었는가?"에 대한 답이 항상 여기로 돌아온다.

| 서자니까 | 메카닉 | 결과 |
|----------|--------|------|
| 정보를 안 줌 | 안개, 시야 제한, 밤 전투 | 플레이어는 불완전한 정보로 판단 |
| 장비가 없음 | 수치 비공개, T1 기본 유닛 | 적보다 항상 약함. 질로 이기는 게 아니라 판단으로 이김 |
| 보급이 안 됨 | 퍼마데스, 유닛 수=주사위 수 | 잃으면 영구 손실. 매 전투가 무겁다 |
| 기록이 안 남음 | 서사 — 기록의 폭력 | 역사는 테오도라를 기록하지 않는다. 플레이어만 안다 |

### 설계 검증 체크리스트

새 메카닉을 추가할 때 아래 질문에 답할 수 있어야 한다:

```
□ 이 메카닉은 "서자니까"에서 파생되는가?
□ 파생되지 않는다면, 왜 존재하는가?
□ 이 메카닉이 플레이어에게 과도한 정보/자원/장비를 주지 않는가?
□ 이 메카닉이 퍼마데스의 무게를 희석하지 않는가?
```

## ⑤ 서사 원칙

| 항목 | 내용 |
|------|------|
| **테마** | 기록의 폭력 — 역사가 지운 사람들의 이야기 |
| **주인공** | 테오도라: 순응하는 삶을 살아간 기사. 의문을 품지 않는다 |
| **부관** | 앰버: 사냥꾼 출신. 테오도라가 보지 못하는 것을 본다 |
| **서사 방식** | 가르치지 않는다. 보여줄 뿐. 플레이어가 판단한다 |
| **기록 vs 기억** | 기록(역사) 한 줄 vs 기억(게임) 한 권. 악의가 아니라 관성 |

> 서사 상세는 별도 문서(미정). 이 문서에서는 원칙만 명시.

## ⑥ 레퍼런스

### 핵심 레퍼런스 (메카닉 검증 완료)

| 게임 | 참고 포인트 | 적용 |
|------|-----------|------|
| **Slice & Dice** | 적 의도 선공개 = 낮 전투. 면 커스터마이징 | ✅ 설계됨 / 📋 04_메타 |
| **Tharsis** | 위험 다이스(✕=부상). 자원=위험 방지 | ✅ 설계됨 / 📋 지형 |
| **Dice Legacy** | 계급 승급→면 변화. 다이스 내구도 | ✅ T1→T2 |
| **Dice Gambit** | 이동을 전투 밖에 둔 것. 클래스 조합 | ✅ 맵/전투 분리 |
| **Citizen Sleeper** | 컨디션→다이스 수 (death spiral) | ✅ 유닛 수=주사위 수 |

### 서사 레퍼런스

| 작품 | 참고 포인트 |
|------|-----------|
| **Banner Saga** | 행군 중 분기 선택. 자원 관리와 서사의 결합 |
| **Darkest Dungeon** | 스트레스/부상의 영속적 결과. 퍼마데스의 무게 |

### 차별화 — "이 게임은 왜 다른가"

> "Warpips는 전쟁을 하는 게임이고, Holy Orders는 전쟁 안에 놓인 게임이다."

| 유사 게임 | 차이점 |
|-----------|--------|
| Slice & Dice | 완전 정보 + 최적해 추구. HO는 불완전 정보 + 판단 |
| Into the Breach | 퍼즐 (완전 정보). HO는 안개 (불완전 정보) |
| Banner Saga | 서사 중심, 전투 보조. HO는 전투와 서사가 동급 |
