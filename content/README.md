# content/ — 게임 데이터

> 클로드 코드 + claude.ai 공용. 실제 카드·인물·스테이지 데이터.

## 원칙

```yaml
- 데이터 결로 박힘 (YAML 또는 데이터 결 명시)
- 결의 의도·서사 결 = design/ 이동
- specs/ 스키마 따름
- 작가 결 우선 (콘텐츠 임의 생성 X)
```

## 구조

```yaml
orders/
  01_theodora/           # 미궁의 테오도라 (Order 1)
    README.md            # Order 메타 + 인격별 챕터·스테이지 명명
    characters.md        # 인물 카드 풀 (붕어빵 풀)
    courage/             # 용맹한 테오도라 (90장)
      cards.md           # 스토리 카드 풀
    wisdom/              # 지혜로운 테오도라 (펜딩)
    justice/             # 정의로운 테오도라 (펜딩)
```
