# 위키 정합성 체크

> 커밋 전 또는 새 세션 시작 시 사용. PAT + 레포 정보와 함께 이 내용을 전달.

---

```
CLAUDE.md 부팅 프로토콜을 수행한 뒤, DOCS/ARCHIVE, DOCS/DESIGN/LOG, DOCS/ART/LOG, DOCS/PROMPTS 제외 전체 .md를 읽어라.

08_스키마/태그규칙.md를 정본으로 삼아, 모든 활성 문서가 정본과 일치하는지 교차 대조해라.

찾아야 하는 것:
1. 같은 규칙이 문서마다 다르게 기술된 곳
2. 확정된 사항이 다른 문서에 반영되지 않은 곳
3. 폐기된 시스템/용어가 활성 문서에 남아있는 곳 (폐기 목록은 NEXT_SESSION.md와 세션 로그에서 수집)
4. 문서 간 참조 링크가 깨진 곳
5. 미확정으로 남아있지만 다른 문서에서 이미 확정된 항목

출력:
❌ 모순 — 규칙 충돌. 반드시 수정
⚠️ 잔존 — 구버전 미반영. 수정 권장
📋 미결 통합 — 전체 미확정 사항 목록

수정은 하지 마. 보고만 해. 커밋은 철이 지시할 때만.
```
