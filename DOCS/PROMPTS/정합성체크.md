# 위키 정합성 체크

> 커밋 전 또는 새 세션 시작 시 사용. PAT + 레포 정보와 함께 이 내용을 전달.

---

```
CLAUDE.md 부팅 프로토콜을 수행한 뒤, DOCS/ARCHIVE, DOCS/DESIGN/LOG, DOCS/ART/LOG, DOCS/PROMPTS를 제외한 전체 .md를 읽어라. DOCS/DESIGN/NEXT_SESSION.md는 포함.
git log -1과 git diff HEAD~1로 최신 변경 내용을 파악해라.

변경된 내용을 기준으로 전체 위키를 교차 대조해라. 대상은 메카닉, 구조, 용어, 서사, 참조 등 모든 것이다.

결과를 두 묶음으로 나눠서 보고해라:

🔧 자동 수정 — 용어 통일, 구버전 잔존 제거, 참조 링크 수정, 버전 번호 동기화 등 판단이 필요 없는 것. 수정 내용을 설명하고 커밋 준비해라.

❓ 판단 요청 — 규칙 충돌, 구조 모순, 설계 방향이 갈리는 지점 등 철의 결정이 필요한 것. 선택지와 각각의 영향을 제시해라.

자동 수정은 준비만 하고, 판단 요청에 대한 철의 답변이 끝난 뒤 전부 합쳐서 커밋해라. 푸시는 철이 지시한다.
```
