# 정합성 체크 프롬프트

> 새 세션에서 이 프롬프트를 그대로 붙여넣으면 깃 레포 전체 정합성 체크를 수행한다.

---

## 프롬프트

```
깃 레포를 클론한 뒤, 아래 순서로 전체 정합성 체크를 수행해.

## 1단계: 전체 읽기
- CLAUDE.md → README.md → DOCS/DESIGN/NEXT_SESSION.md 순서로 읽어
- 이후 모든 .md 파일을 전부 읽어 (DOCS/ARCHIVE 제외)

## 2단계: 용어 정합성
- 라벨-태그 체계: "태그"가 라벨 의미로 사용된 곳 찾기
- 폐기된 용어 잔존: [결전][수습][치료][재편][불운][표류][사기진작] 등 폐기 라벨이 활성 문서에 남아있는지
- 구 용어 잔존: "분기 효과", "전황 태그", "전술 태그" 등 구 체계 표현이 남아있는지
- 카드 명칭: "사건 카드"가 구 의미(전체 이벤트)로 쓰인 곳 vs 신 의미(비전투 카드)
- "지휘" vs "리롤": 플레이어 대면 명칭 통일

## 3단계: 규칙 충돌
- 라벨 효과가 7스텝과 충돌하는 곳
- 같은 규칙이 문서마다 다르게 기술된 곳
- 부상 관련: "전투 종료 즉시 자동 회복"과 모순되는 기술
- 카드락 관련: "아군 첫 굴림 시 적용"과 모순되는 기술
- Nameless 부상 관련: "Nameless 피격 = 즉사"와 모순되는 기술
- 패시브 관련: "민병 제외 기본 보유"와 모순되는 기술

## 4단계: 구조 정합성
- 이야기 카드 4종(전투/사건/우연/운명) 분류가 모든 문서에서 일관적인지
- 라벨 6분류(전략/전술/결과/비전투/우연/운명) 수와 내용이 태그규칙.md와 일치하는지
- 주사위 태그 4종(연마/열화/단조/보강) 정의가 참조하는 모든 문서에서 동일한지
- 배경 시스템(장소/계절/상황)이 다른 문서와 충돌하지 않는지
- 추종자 시스템이 동료 시스템과 역할이 겹치거나 모순되지 않는지
- 업적 A풀/B풀 정의가 영웅.md와 태그규칙.md에서 일관적인지

## 5단계: 버전/참조 정합성
- 각 문서의 버전 번호가 변경 이력과 일치하는지
- README 대시보드의 문서 목록이 실제 파일과 일치하는지
- 문서 간 참조 링크가 유효한지 (존재하지 않는 문서 참조)
- ARCHIVE로 이동된 문서가 활성 문서에서 참조되고 있는지

## 6단계: 미확정 사항 정리
- 각 문서의 "미확정 사항" 섹션을 모아서 전체 미결 목록 생성
- 이미 확정된 건데 미확정으로 남아있는 항목 찾기
- 미확정인데 다른 문서에서 확정된 것처럼 기술된 항목 찾기

## 출력 형식

### ❌ 모순/충돌 (반드시 수정)
| # | 파일 | 내용 | 수정 방향 |

### ⚠️ 불일치 (수정 권장)
| # | 파일 | 내용 | 수정 방향 |

### ✅ 정합 확인 완료
- 확인된 항목 나열

### 📋 미확정 사항 통합 목록
| # | 항목 | 출처 문서 | 결정에 필요한 것 |

수정은 하지 마. 보고만 해. 커밋은 철이 지시할 때만.
```
