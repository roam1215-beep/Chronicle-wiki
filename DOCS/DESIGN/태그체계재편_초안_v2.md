## 1. 구조 개요

## 2. 배틀 태그 (8종)

### 전략 레이어 (4종) — 카드 레벨 (분기 공통)

| 태그 | 효과 | 성격 |
|------|------|------|
| [기습] | R1 아군만 공격 | 긍정 |
| [역습] | R1 적만 공격 | 부정 |
| [우세] | 아군 유닛 추가 (전투 한정, 전투 후 사라짐) | 긍정 |
| [열세] | 적 유닛 추가 (전투 한정, 전투 후 사라짐) | 부정 |

### 전술 레이어 (4종) — 분기 레벨 (분기별 다름)

| 태그 | 효과 | 성격 |
|------|------|------|
| [봉쇄] | 전 라운드 아군만 선제 | 긍정 |
| [함정] | 전 라운드 적만 선제 | 부정 |
| [결투] | Named 1:1 판정 후 7스텝 | 양면 |
| [난전] | 선제 제외 패시브 무력화 | 양면 |

### 규칙

- 전투 카드: 배틀 태그 최소 1개. 전략 0~1 + 분기별 전술 1(필수)
- 운명 카드: 전략 1(필수) + 전술 1(필수)
- [기습]+[역습] 금지. [우세]+[열세] 금지

## 3. 이벤트 태그 (10종)

### 주사위 면 변환 (6종)

| 태그 | 대상 | 효과 | 성격 |
|------|------|------|------|
| [연마] | Named | ✕ → ★10/⚔30/🛡30/✕30 | 긍정 |
| [사기 진작] | Nameless | ✕ → ★10/⚔30/🛡30/✕30 | 긍정 |
| [열화] | Named | ⚔/🛡 → ⚔33/🛡33/✕33 (★ 제외) | 부정 |
| [사기 저하] | Nameless | ⚔/🛡 → ⚔33/🛡33/✕33 (★ 제외) | 부정 |
| [단조] | Named | 열화→연마 순차 | 양면 |
| [단련] | Nameless | 사기 저하→사기 진작 순차 | 양면 |

### 주사위 획득/제거 (4종)

| 태그 | 효과 | 성격 |
|------|------|------|
| [징집] | 민병 2기 획득 | 긍정 |
| [모병] | 보/창/궁 중 선택 1기 | 긍정 |
| [모집] | 민/보/창/궁 중 랜덤 1기 | 양면 |
| [이탈] | Nameless 랜덤 1기 제거 | 부정 |

### 규칙

- 전투 카드: 분기별 전투 후 리절트 이벤트 태그 1개 필수
- 사건 카드: 분기별 이벤트 태그 1~2개. 배틀 태그 불가
- 동일 태그 중복 허용
- 순수 긍정/순수 부정 분기 허용
- 양 분기는 전술도 리절트도 달라야 함
- 엣지 케이스: 대상 0이면 해당 태그 불발, 나머지 정상

## 4. 포츈-배틀 (5종, 택 1)

우연-전투 카드 전용. 강제 전투 내포. 5종 중 1개만.

| 레이어 | 태그 | 효과 | 성격 |
|--------|------|------|------|
| 중립 | [돌발상황] | 강제 전투 | 중립 |
| 행운 | [기습] | 강제 전투 + R1 아군만 공격 | 긍정 |
| 행운 | [회유] | 강제 전투 + 적 랜덤 NL → 아군. 디폴트 면. 영구 | 긍정 |
| 불운 | [역습] | 강제 전투 + R1 적만 공격 | 부정 |
| 불운 | [배신] | 강제 전투 + 아군 랜덤 NL → 적. 면 그대로 | 부정 |

> 포츈-배틀 [기습]/[역습]은 배틀 태그 [기습]/[역습] 참조 (동일 효과).

### 규칙

- 택 1. 추가 배틀 태그 없음
- 전술 슬롯 없음 (갑자기 닥친 전투)
- 전투 후 이벤트 태그 1개 (성격 제약 없음)
- 엣지 케이스: NL 0이면 전투 발생, 전환 효과만 불발

## 7. 카드별 태그 슬롯 요약

```
전투 카드:
 전략 0~1 (카드 레벨)
 분기별: 전술 1(필수) + 전투 후 리절트 이벤트 1(필수)
 양 분기 전술+리절트 달라야 함

사건 카드:
 분기별: 이벤트 태그 1~2개. 배틀 태그 불가.

우연-전투:
 포츈-배틀 택 1 + 전투 후 이벤트 1. 전술 없음.

우연-이벤트:
 포츈-이벤트 1~2개. 즉시 발동.

운명:
 전략 1 + 전술 1 + 승리 보상 [이끌림] 확정. 패배 = 게임 오버.
```

## 9. 설계 원칙

| 원칙 | 내용 |
|------|------|
| 태그 유저 미노출 | 서술로만 유추 |
| Named 태그로 획득/제거 불가 | 전투 사망과 동료 시스템만 |
| 기병 편성/모병 불가 | [회유]만 (극히 희귀) |
| 전투 카드에 이벤트 단독 불가 | 배틀 필수 |
| 사건 카드에 배틀 불가 | 이벤트만 |
| 우연-전투에 전술 없음 | 갑자기 닥친 전투 |
| 순수 긍정/부정 허용 | 풀 비율로 관리 |
| 정보 태그 의도적 배제 | 추종자에서 극히 희귀하게만 |
| 포츈 = 기존 태그 진폭 확대 | 새 메카닉 아님 |
| 운명 패배 = 게임 오버 | 이원화 폐기 |
| 면 교체 2개 ≈ 주사위 1개 | 밸런스 기준선 |
