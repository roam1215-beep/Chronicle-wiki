## 1. 용어 체계

### 유저 대면

| 계층 | 형식 | 예시 |
|------|------|------|
| 인물 | 이름 | 테오도라 |
| 권 (= Order) | N권 [제목] | 1권 [다리 위의 서자들] |
| 장 (= Chapter) | N장 [제목] | 1장 [도하 저지] ← 운명 카드가 제목을 줌 |
| 막 (= Stage) | N장 N막 | 1장 1막, 1장 2막 |

- 시리즈 개념 폐기. 유저에게 비노출. 전체 몇 편이 있는지 모르게 한다.
- 팩 개념 폐기. 권 = 풀. 카드는 개별적으로 풀에 존재.

### 시스템 내부

| 계층 | ID 형식 | 예시 |
|------|---------|------|
| 인물 | `{인물}` | `THEODORA` |
| 권 | `{인물}-V{N}` | `THEODORA-V1` |
| 일러스트 | `{권}-IL{NNN}` | `THEODORA-V1-IL001` |
| 전투 카드 | `{권}-IL{NNN}-C` | `THEODORA-V1-IL001-C` |
| 사건 카드 | `{권}-IL{NNN}-E` | `THEODORA-V1-IL001-E` |
| 우연 카드 | `{권}-IL{NNN}-CH` | `THEODORA-V1-IL001-CH` |
| 운명 카드 | `{권}-F{NN}-{1/2/3}` | `THEODORA-V1-F01-1` ~ `F01-3` |

## 2. 핵심 구조: 권 = 풀

```
테오도라 1권 [다리 위의 서자들]
 ├─ 기본 일러스트 60장 × 3종 (전투/사건/우연) = 180장
 ├─ 운명 일러스트 20장 × 3종 = 60장
 ├─ 배경 풀 (장소 / 상황 / 계절)
 ├─ 적 테이블 (권-장위치-막위치 레벨 공용 6세트)
 ├─ 추종자 풀 (일반 + 특별)
 └─ 권 규칙 (페이즈 수, 뽑기 수, 셔플 제약)

1권 총합: 240장
```

### 일러스트 = 카드 세트

일러스트 1개에서 카드 3장이 나옴. 같은 그림, 다른 카드.

```
일러스트 [마을] (IL001)
 ├─ IL001-C  전투 "마을 입구에서 적과 마주쳤다"
 ├─ IL001-E  사건 "마을 사람들이 도움을 청한다"
 └─ IL001-CH 우연 "마을에서 연기가 피어오른다"
```

운명 일러스트도 동일. 1개에서 3장.

```
운명 일러스트 [다리 위의 사투] (F01)
 ├─ F01-1  전략 [기습] + 전술 [봉쇄] + 적 테이블 A
 ├─ F01-2  전략 [역습] + 전술 [결투] + 적 테이블 B
 └─ F01-3  전략 [우세] + 전술 [난전] + 적 테이블 C
```

### 3층 독립 구조

| 층 | 역할 | 변경 시 다른 층 영향 |
|----|------|-------------------|
| 풀 층 | 카드 공급. 스토아 팩토리가 투입 | 없음 |
| 규칙 층 | 뽑기, 페이즈, 셔플, 적 테이블 | 없음 |
| 전투 층 | 7스텝 엔진 | 없음 |

## 3. 런 동선

```
1. 런 시작
2. 테오도라 초기화:
   - 병종: 기사 (고정). 면: ⚔2🛡3★2✕3 (고정)
   - 패시브: 방진/반격/쇄도 중 랜덤 1
   - 특성: B풀에서 랜덤 (겁이 많은, 선제 관련 제외)

3. 슬롯머신 연출 — 동시 결정:
   a. 운명 풀에서 6장 비중복 뽑기 (막당 1장) → 운명 카드가 장 제목
   b. 각 장에 배경 배정: [장소] / [상황] / [계절] 독립 롤
   c. 상황이 우연 주입 수 결정
   d. 화면에 인물 / 운명 / 배경 제시

4. 장 진행:
   1장 = 2페이즈 (도입)
   2장 = 3페이즈 (전개)
   3장 = 3페이즈 (절정)

5. 각 막 시작 시:
   a. 전투 풀에서 3장 뽑기 (런 내 비중복)
   b. 사건 풀에서 3장 뽑기 (런 내 비중복)
   c. 우연 풀에서 N장 뽑기 (상황 결정. 런 내 비중복)
   d. 전투+사건+우연 셔플
   e. 운명 카드 1장 (런 시작 시 배정됨)

6. 페이즈:
   a. 셔플 카드에서 뒷면 3장 제시
   b. 유저 홀드 탭 → 일러스트 일렁임 (희미하게 유추)
   c. 추종자 조언 (보유 시)
   d. 블라인드 2장 선택
   e. 안 뽑힌 1장 → 전해지지 않은 이야기 (뒷면 채 퇴장)
   f. 선택한 2장 뒤집기 → 순서 결정 → 순차 플레이

7. 모든 페이즈 종료 → 운명 카드 → 운명 전투

8. 운명 전투 승리 → 추종자 2명 제시, 1명 선택
   운명 전투 패배 → 게임 오버

9. 전투 종료 시: Named 부상 전원 회복 (구성면으로 복원)
```

## 4. 페이즈 구조

### 블라인드 선택

| 항목 | 내용 |
|------|------|
| 카드 제시 | 뒷면 3장. 전투/사건/우연 구분 불가 (뒷면 동일) |
| 홀드 탭 | 일러스트가 일렁임. 희미하게 그림 유추 가능. 확신 불가 |
| 기만 | 같은 일러스트가 전투/사건/우연 3종에 쓰임. 일러스트로 유형 확정 불가 |
| 추종자 조언 | Nameless = 현상 서술만, Named = 현상+해석+의견 (편향 있음, 틀릴 수 있음) |
| 선택 | 유저가 2장 블라인드 선택 |
| 버림 | 1장 = "전해지지 않은 이야기". 뒷면 채 퇴장. 내용 미공개 |
| 순서 | 2장 뒤집은 후 플레이 순서 유저 결정 |

### 셔플 제약

| 규칙 | 내용 |
|------|------|
| 같은 유형 3장 불가 | 한 페이즈에 전투-전투-전투, 사건-사건-사건 불가 |
| 우연 페이즈당 최대 1장 | 한 페이즈에 우연 2장 이상 불가 |

### 페이즈 수 (권 규칙)

| 장 위치 | 페이즈 수 | 성격 |
|---------|----------|------|
| 1장 | 2페이즈 | 도입 |
| 2장 | 3페이즈 | 전개 |
| 3장 | 3페이즈 | 절정 |

## 5. 홀드 탭 + 일러스트 기만

### 정보 신뢰도 스펙트럼

| 신뢰도 | 상태 | 예시 |
|--------|------|------|
| 확실 | 운명 카드 뒷면 (금색 테두리) | "이건 운명이다" |
| 높음 | 일러스트가 명확한 카드 | 칼 든 병사 → 전투 가능성 높음 |
| 중간 | 일러스트가 모호한 카드 | 길 위의 사람들 → 전투? 사건? 우연? |
| 낮음 | 일러스트가 기만하는 카드 | 평화로운 마을 → 실은 우연 [배신] |

### 기만 구조

- 같은 일러스트 = 반드시 전투/사건/우연 3종 존재
- 이전 런에서 사건이었던 그림이 이번에는 전투
- 리플레이할수록 "이 그림이면 3분의 1" 학습. 확신은 안 됨
- 일부 카드는 의도적으로 다른 유형처럼 보이는 일러스트 사용

## 9. 성장 시스템: 주사위 + 추종자

### 이원 구조

| 축 | 역할 | 대응 |
|----|------|------|
| 주사위 | 전투 도구. 면 변환/획득/제거로 변화 | 슬더스의 카드 덱 |
| 추종자 | 패시브 수정자 + 조언. 누적 | 슬더스의 유물 |

### 런 내 성장

| 경로 | 수단 | 빈도 |
|------|------|------|
| 주사위 면 변환 | 이벤트 태그 (연마/열화/사기 진작 등) | 매 전투 후 + 사건 분기 |
| 주사위 획득/제거 | 이벤트 태그 (징집/모병/모집/이탈) | 매 전투 후 + 사건 분기 |
| 추종자 획득 | 운명 승리 → 2명 제시 1명 선택 | 막당 1회 (런당 6회) |

### 런 간 메타 성장

| 경로 | 수단 |
|------|------|
| 추종자 풀 해금 | 런에서 조건 달성 → 다음 런부터 새 추종자 등장 |
| 스토리 카드 도감 | 겪은 카드 수집. 일러스트 단위 열람 |

### Named 특성 (기존 B풀)

적/아군 Named가 보유. Named의 고유 성격. 이름이 있으면 성격이 있다.

| 특성 | 효과 |
|------|------|
| 잔혹한 | 격돌 ⚔+1 확정 |
| 고집센 | 격돌 🛡+1 확정 |
| 겁이 많은 | 선제 🛡+1 (피격 흡수 시 소멸) |
| 교활한 | 선제 ⚔+1 (궁병 Named만) |
| 집요한 | 부상 1회 무효 |
| 위선적인 | 매 라운드 해당 진영 ✕ 1개 → ⚔/🛡 랜덤 |

### 테오도라 런 시작

| 항목 | 내용 |
|------|------|
| 병종 | 기사 (고정) |
| 면 | ⚔2🛡3★2✕3 (고정) |
| 패시브 | 방진(보병)/반격(창병)/쇄도(기병) 중 랜덤 1 |
| 특성 | B풀에서 랜덤. 겁이 많은, 교활한 제외 |

### 폐기

| 항목 | 사유 |
|------|------|
| 업적 A풀 (미덕 5종) | 추종자 패시브로 흡수 |
| 업적 B풀 → Named 특성으로 재정의 | 업적이 아닌 Named 고유 성격 |
| 위업 시스템 | 불필요. 추종자로 통합 |
| [명예] | 삭제. 불운 전투 승리 보상 = 살아남은 것 자체 |

## 10. 추종자 시스템

### 기본 구조

| 항목 | 내용 |
|------|------|
| 정의 | 비전투 Named. 패시브 + 조언을 가진 인물 |
| 상한 | 10명 |
| 획득 | 운명 승리 시 2명 제시, 1명 선택 (일반 풀) |
| 특별 획득 | 우연-이벤트 [운명적 이끌림] (전용 풀. 극히 드묾) |
| 상실 | 우연-이벤트 [결별] (유일한 경로) |
| 지속 | 런 전체 |

### Named/Nameless 추종자 차이

| | Nameless 추종자 | Named 추종자 |
|--|----------------|-------------|
| 이름 | 없음 (역할명) | 고유명 |
| 조언 형태 | 현상 서술만 | 현상 + 해석 + 의견 |
| 편향 | 없음 | 성격 기반 (신중/호전/비관/낙관 등) |
| 호칭 | 없음 | "테오도라님" 등 |
| 패시브 | 있음 | 있음 |
| [결별] 시 | 눈 하나를 잃음 | 관점 하나를 잃음 |

### 조언 예시

```
[같은 카드를 홀드 탭했을 때]

Nameless (예언가):
 "마을에서 불길이 치솟고 있습니다"

Named (책사 '마르쿠스'):
 "마을이 너무 조용합니다. 매복이 있을 수도 있습니다.
  조심하세요, 테오도라님."
```

> 추종자 조언은 틀릴 수 있음. 유저는 추종자의 편향을 학습해서 보정해야 함.

### 런 간 메타

추종자 풀 해금. 런에서 조건 달성 시 다음 런부터 새 추종자 등장.

## 12. 1권 물량

| 구분 | 일러스트 | 카드/일러 | 카드 합계 |
|------|---------|----------|----------|
| 기본 (전투/사건/우연) | 60장 | × 3종 | 180장 |
| 운명 | 20장 | × 3종 | 60장 |
| **합계** | **80장** | | **240장** |

### 런당 소모량

| 항목 | 6막/런 |
|------|--------|
| 전투 | 18장 |
| 사건 | 18장 |
| 우연 | 상황 의존 (6~18장) |
| 운명 | 6장 |
| **런당 소모** | **48~60장** |

### 스토아 팩토리 파이프라인

```
1. 일러스트 80장 생성 (AI 아트)
2. 일러스트 + 태그 규칙 → 팩토리 입력
3. 기본 일러스트 → 3장 출력 (전투/사건/우연)
   운명 일러스트 → 3장 출력 (전략/전술 조합 다른 3종)
4. 철이 검수
5. 풀에 투입
```

## 13. 서술 작성 원칙

| 규칙 | 내용 |
|------|------|
| 카드 독립 | 모든 카드는 다른 카드의 존재/결과를 전제하지 않음 |
| 권 설정만 참조 | 테오도라 정체, 서자 부대, 권의 대전제 |
| 배경 독립 | 카드 서술은 특정 장소/계절에 의존하지 않음 |
| 태그 효과를 서술에서 전달 | 태그 미노출이므로 서술이 효과를 암시 |
| 같은 일러스트 3종 서술 차별화 | 같은 그림에서 전투/사건/우연 서술이 각각 다른 상황 |

## 14. 아트 원칙

| 원칙 | 내용 |
|------|------|
| 권 단위 통일 | 뒷면, 프레임, 타이포그래피 공용 |
| 뒷면 동일 | 전투/사건/우연 구분 불가 (블라인드 전제) |
| 운명 뒷면 별도 | 금색 테두리 |
| 일러스트 1개 = 3종 | 같은 그림에서 전투/사건/우연 카드 생성 |
| 기만 레벨 | 카드마다 일러스트 정직도 차등. 의도적 기만 카드 존재 |
| 홀드 탭 | 뒷면 상태에서 일러스트 일렁임. 희미하게 유추 가능 |

## 16. 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 풀 구조인가? | 카드 자기 완결 + 적 테이블 공용이면 팩 불필요. 극단적 단순함과 확장성 |
| 왜 블라인드 선택인가? | "정보는 부족하고 현장은 이미 달라져 있다" — 핵심 경험의 구조적 구현 |
| 왜 홀드 탭인가? | 블라인드에 스킬 개입 지점. 완전한 정보도 완전한 무지도 아닌 상태 |
| 왜 일러스트 1개 = 3종인가? | 기만 구조 + 아트 효율 + 도감 단위 + 팩토리 생산 단위 |
| 왜 주사위 + 추종자인가? | 슬더스의 카드+유물 대응. 전투 도구와 패시브 수정자 이원화 |
| 왜 업적/위업을 폐기했는가? | 추종자가 성장 담당. 별도 시스템 불필요 |
| 왜 추종자 2택 1인가? | 빌드 판단. 랜덤이면 성장에 선택이 없음 |
| 왜 추종자가 틀릴 수 있는가? | 이름이 있으면 관점이 있고 관점이 있으면 편향. Named 문법 |
| 왜 불운 전투 승리에 보상 없는가? | 서자부대에게 불리한 전투 승리의 보상은 살아남은 것 자체 |
