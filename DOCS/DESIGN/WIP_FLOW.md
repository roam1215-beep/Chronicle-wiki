## 1. 최상위 구조 — 5층

```
인물 (Character) ── 테오도라 (+미래 인물 DLC)
  └─ 대명령 (Order) ── 런 1회. 시나리오. 순차 해금.
       └─ 작전 (Chapter) ── 트위스트 1개. 보급 1회.
            └─ 국면 (Stage) ── 운명 1장 + 중앙 카드 덱.
                 └─ 전투 (Battle) ── 7스텝 주사위. 안정된 엔진.
```

### 각 층위의 역할

| 층위 | 플레이어 체감 | 게임 역할 |
|------|-------------|----------|
| 인물 | 선택 화면 | 영웅 2명 + 사이드킥 + 병종 풀 결정. DLC 단위. |
| Order | 시나리오 선택 | 런 전체 목표. 연대기(신참→성기사). 챕터 수/구성 결정. |
| Chapter | 작전 수행 | 트위스트 1개 + 보급 선택 + 스테이지 6개(분기-수렴). |
| Stage | 임무 수행 | 운명(목표) 1장 + 중앙 카드 덱(선택+우연). |
| Battle | 전투 | 7스텝 주사위. 카드 덱/트위스트가 조건만 바꿈. 규칙 불변. |

## 2. 사서(史書) 프레임

> Holy Orders = 기록되지 않은 자들의 영웅전.

| 요소 | 설명 |
|------|------|
| 타이틀 | "Holy Orders." — 복수형 + 마침표 = 완결된 기록의 모음집. |
| 런 실패 | 기록 없음. 테오도라는 역사에 없는 사람. |
| 런 성공 | 플레이 결과가 기록됨. 그게 테오도라의 역사. |
| 시대축 교차 | 테오도라 Order 2와 다른 인물 Order 1이 같은 전쟁의 다른 전선. |
| 로그 | 매 턴 사건이 깃펜으로 사서에 기록. 선택/우연/운명 구분 없이 역사로 남음. |

## 3. 중앙 카드 덱 — 선택 / 우연 / 운명

> **모든 카드 = 사건.** 카테고리(교전/정찰 등) 없음. 도착 방식만 다름.

### 삼분법

| 방식 | 정의 | 플레이어 체감 |
|------|------|-------------|
| **선택** | 3장 제시 → 1장 고른다. 나머지 잔류. | "내가 골랐다." |
| **우연** | 덱에 섞여 있다가 뽑히면 즉시 발동. | "어쩔 수 없었다." |
| **운명** | 스테이지 목표. 1장. 시작부터 공개. N턴 제한. | "처음부터 알고 있었다." |

### 운명

| 필드 | 내용 |
|------|------|
| 수량 | 스테이지당 1장. |
| 공개 시점 | 스테이지 시작 시 즉시. |
| 표시 | 화면 상단. 목표 텍스트 + 남은 턴. |
| 미달성 | 런 실패. 기록 없음. |
| 대명령 연결 | "서자 기사 테오도라에게 명한다. ___하라." = 운명. |

### 잔류 처리 (확정)

| 필드 | 내용 |
|------|------|
| 규칙 | 잔류가 슬롯을 먹는다. 매 턴 보이는 건 항상 3장. |
| 잔류 있으면 | 잔류가 먼저 슬롯 차지. 나머지만 새로 뽑음. |
| 안정점 | 잔류는 항상 2장으로 안정. 폭발 안 함. |
| 대가 | 미루면 새 카드 볼 기회가 줄어듦 = 시야 좁아짐. |
| 밸런싱 | "무시하면 악화되는 카드"를 섞어서 방치 방지. 밸런스 영역. |

### 우연 빈도 (확정)

| 필드 | 내용 |
|------|------|
| 방식 | 덱 구성 비율로 조절. 타이밍은 셔플이 결정. |
| 예시 | 10턴 스테이지 → 선택 ~8장 + 우연 ~2장. |
| 체감 | 평균 5턴에 1번. 연속 가능, 안 나올 수도 있음. |

### 턴 구조 (확정 — STAGE-CARD-001 v1.0)

```
반나절 시작 (홀수=낮, 짝수=밤)
  → 덱에서 1장 뒤집는다
    → 사건 카드: 분기 2~3개 표시. 1개 선택. 효과 적용.
    → 우연 카드: 즉시 발동. 선택 없음.
  → 카드 → 버림
  → 운명 타이머 -1
턴 종료
```

### 카드 해상도 (확정)

```
덱: 30장 (사건 + 우연 혼합, 셔플)
턴 상한: 10턴
비복원: 버림 카드 재등장 없음

사건 카드: 상황 서술 + 분기 2~3개. 플레이어가 고른다.
우연 카드: 즉시 발동. 선택 없음. 행운 또는 불운.
운명: 상단 공개. 덱에 안 섞임. 누적 조건으로 달성.

→ 상세: 03_스테이지/카드해상도.md (STAGE-CARD-001)
```

### 로그 기록

```
📜 "탈영병이 발생하다."           ← 우연
📜 "테오도라 대, 동쪽 길목을 택하다." ← 선택
📜 "적 지휘관을 처치하다."         ← 운명 달성
```

읽는 사람은 뭐가 선택이고 뭐가 우연인지 모른다. 그냥 역사다.

## 4. 전체 플로우차트

```
[타이틀]
  │
  ▼
[인물 선택] ── 테오도라 (+ 미래 인물 잠금)
  │
  ▼
[Order 선택] ── 순차 해금.
  │              Order = 테오도라와 앰버의 연대기.
  │              DLC로 Order/인물 추가 가능.
  │
  ▼
[Order 시작 화면] ── 3분할
  │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  │ THEODORA │  │  AMBER   │  │ ████████ │
  │  │ 영웅/보병 │  │ 영웅/궁병 │  │→ T1 랜덤 │
  │  │ 패시브    │  │ 패시브    │  │  (뒤집기) │
  │  │ (긁기)   │  │ (긁기)   │  │          │
  │  │ 주사위면  │  │ 주사위면  │  │ 주사위면  │
  │  └──────────┘  └──────────┘  └──────────┘
  │
  │  초기 상태:
  │    부대: 3개 (테오도라 + 앰버 + T1 랜덤)
  │    부대 상한: 10 (사실상 도달 안 함)
  │    보급: 0장 (챕터 시작 시 선택)
  │
  │  대명령 공개:
  │    "서자 기사 테오도라에게 명한다. ___하라."
  │
  ▼
[Chapter 시작]
  │
  ├─ 챕터 트위스트 공개
  │    - 챕터 전체에 규칙 1개. 카드 덱/보급만 건드림. 전투 규칙 불변.
  │
  ├─ 보급 선택 (챕터당 1회)
  │    - 트위스트 확인 후 판단. 챕터 전체분 N장. 이월 불가.
  │
  ▼
[챕터 내 스테이지 흐름] ── 분기-수렴 고정 구조

      ┌─ [1] ─┐
      │       ├─ [3] ─┬─ [4] ─┐
      └─ [2] ─┘       │       ├─ [6]
                      └─ [5] ─┘

  자동판정 (미선택 구역):
  - 소비턴 × 1d6: 1~2 패(적+2) / 3~4 교착 / 5~6 승(아군+1)
  │
  ▼
[브리핑] ── 매 스테이지 진입 전
  │  작전지도 (정보 공간) + 명령서 + 스테이지 택1
  │
  ▼
[Stage 진입]
  │
  ├─ 운명 공개: "적 지휘관을 처치하라." (N턴)
  │
  ├─ 중앙 카드 덱 진행 (턴 반복)
  │    → [우연] 뽑히면 즉시 발동
  │    → [선택] 잔류 + 새 카드 = 3장. 1장 선택.
  │    → 남은 턴 -1
  │
  ├─ 전투 발생 시 → Battle (7스텝)
  │    기존 위키 문서 유효: 전투구조 v0.3, 다이스규칙 v0.5
  │
  ├─ 운명 달성 → 스테이지 클리어
  ├─ 턴 소진 → 런 실패 (기록 없음)
  │
  ▼
[스테이지 종료 → 다음 브리핑 or 챕터 종료]
  │
  ▼
[다음 Chapter] ── 병력 이월, 새 트위스트
  │
  ▼
[Order 완수 / 실패 — 엔딩]
```

## 5. 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 전투 엔진 불변 | 7스텝 + 4종 주사위면. 트위스트/특수규칙이 전투 규칙을 건드리지 않음. |
| 변주는 전투 밖 | 어떤 전투를, 언제, 어떤 조건에서, 뭘 들고 들어가느냐가 게임. |
| 세 채널 분리 | 선택(슬롯) / 우연(즉시) / 운명(상단 표시). 서로 안 섞임. |
| Order = DLC 단위 | 인물 + Order 체인으로 콘텐츠 확장. |
| 보급은 귀하다 | 챕터당 1회. 이월 불가. |
| 부대는 귀하다 | 3개 시작. 충원은 극저확률. 잃으면 퍼마데스. |
| 사서 프레임 | 모든 사건은 로그로 기록. 선택/우연 구분 없이 역사. |

## 6. 폐기/변경 항목

| 기존 | 변경 | 사유 |
|------|------|------|
| 카드 카테고리 (교전/정찰/병참/돌발) | **폐기.** 모든 카드 = 사건. | 카테고리가 선택을 미리 분류하면 판단 깊이 줄어듦. |
| 압박 카드 / 기회 카드 구분 | **폐기.** 선택/우연/운명으로 대체. | 도착 방식이 카드 정체성을 결정. |
| 운명 카드 복수장 + 카운트다운 | **변경.** 운명 1장 = 스테이지 목표. | 복수장은 인지 부하 과다. 1장이 목적 그 자체. |
| 잔류 상한 없음 (무한 축적) | **변경.** 잔류가 슬롯을 먹음 (항상 3장). | 매 턴 2장씩 폭발하는 문제 해결. |
