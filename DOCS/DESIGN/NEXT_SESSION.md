# 다음 세션 안건

> **최종 갱신:** 2026-02-27 정합성 수정 (턴 수 확정 반영, 토큰 잔재 제거, 버전 갱신)

## 확정 사항 (참고)

- 5층 구조: 인물 → Order → Chapter → Stage → Battle
- 사서 프레임: 모든 사건은 역사로 기록
- **스테이지카드규칙 (STAGE-CARD-002 v0.4):**
  - 5턴: 턴 1~4 카드 뒤집기 + 턴 5 운명 전투 자동 발동.
  - 덱 9장 (전투 4 + 비전투 4 + 우연 1). 4장 뒤집기, 5장 잔여.
  - 사건(분기 선택) / 우연(즉시 발동). 뒷면 완전 블라인드.
  - 운명 상단 공개. 덱에 안 섞임.
  - 분기 효과가 유일한 보상. 버프 슬롯 1개 (덮어쓰기).
  - 전투: 스테이지 낮/밤 상속. 전투 내 교대 없음.
  - 겪은 카드 앞면 열람 가능. 남은 카드 숫자만 표시.
- **덱빌딩 구조 (STAGE-DECK-001 v0.2):**
  - "겪은 것이 덱이 된다." 카드 1장 = 이야기 + 재료 + 기록.
  - 분기 효과가 유일한 보상. 토큰 체계 전면 폐기 (v0.2).
  - 유물 압축: 스테이지 카드 → 챕터 카드 → 오더 카드.
- **카드 타입 체계 (COMBAT-UNIT-CARD v0.1):**
  - 인물(Figure) / 사건(Event) / 기록(Record) 3타입.
  - 등급: Nameless(무명) → Named(유명) → Hero(영웅).
  - 이름 유무가 곧 등급. 카드 표면에 등급 태그 없음.
  - Named만 ★ 면 + 2단계 부상 생존.
  - 패시브: 모든 인물 카드에 적용. 초기 비어있음. 스테이지 보상 획득. 최대 3슬롯.
  - 전환 메카닉 → 패시브로 흡수 (보병: 전열 교대, 창병: 반격, 궁병: 선제 공격).
  - 카드 레이아웃 5영역: 일러스트/명칭/플레이버/패시브/다이스면.
- **Named 인물 (COMBAT-UNIT-HERO v0.3):**
  - 테오도라 / 기사 (창병 계열): ★⚔🛡🛡✕✕, 패시브=반격.
  - 앰버 / 궁병: ⚔⚔⚔★✕✕, 패시브=선제 공격.
  - 패시브 초기 비어있음. 스테이지 보상 획득.
- **전투 구조 v0.6 (COMBAT-STRUCT-001):**
  - 7스텝. 3페이즈. 낮/밤 교대 삭제. 스텝2 버프 소모, 스텝4 리롤 버프. 유닛 전환 Nameless/Named 체계 정합.
- **로비 씬:**
  - 비활성 런: [새 게임] [기록] [설정]
  - 활성 런: [새 게임] [이어하기] [기록] [설정]
  - 런 슬롯 1개. [새 게임]+활성 런 = 덮어쓰기 경고.
  - [기록] = 완료된 오더 카드(성적표) 열람.
- **폐기 완료:** T2 병종, 정예화, 보병전환, 보급, 작전카드, 야영, 토큰 3종, 카드해상도 v1.0, WIP_FLOW.

## 우선순위 P0

### 1. Order 1 이야기 뼈대

- 테오도라의 첫 시련. 증명과 명예의 시작.
- Chapter → Stage 쪼개기.
- Stage별 사건 카드 도출의 기반.
- 사건 카드 계열 (전투/비전투) 서사 구체화.

### 2. 사건 카드 실물 만들기

- Order 1 첫 스테이지 기준 사건 카드 9장 초안 (전투 4 + 비전투 4 + 우연 1).
- 운명 조건 1개.
- 분기 효과 → 전투 연결 구체화.
- 카드 앞면 레이아웃 검증 (STAGE-CARD-002 ⑧ 기준).

## 우선순위 P1

### 3. 유물 테이블 구조

- 인풋: 겪은 사건 내역 (타입별 비율) + 전투 결과.
- 아웃풋: 성향별 효과 풀.
- 규모: 계열당 후보 몇 개.

### 4. 운명 달성 조건

- 조건 유형 목록 (교전 N회 승리, N턴 생존, 특정 선택 N회 등).
- 추적 방식 (카운터 vs 체크리스트).
- 운명 보상 구체화 (면교체 + 유물 + Named 승급 + 패시브 획득).

### 5. 캐릭터 선택 화면

- [새 게임] → 캐릭터 선택 → 편성 화면 흐름.
- 초기 편성 구성 (Named 2 + Nameless 몇?).

### 6. 편성 화면 설계

- 전투 전 편대 구성 UI.
- 인물 카드 배치, 패시브 확인.
