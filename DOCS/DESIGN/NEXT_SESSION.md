# 다음 세션 안건

> **최종 갱신:** 2026-02-27 카드 시스템 설계 세션 (게임 플로우 + 인물 카드 체계)

## 확정 사항 (참고)

- 5층 구조: 인물 → Order → Chapter → Stage → Battle
- 사서 프레임: 모든 사건은 역사로 기록
- **카드 해상도 v2.0 (STAGE-CARD-001):**
  - 매 턴 1장 뒤집기. 사건(분기 선택) / 우연(즉시 발동).
  - 운명 상단 공개. 덱에 안 섞임.
  - 덱 30장. 10턴 상한 (축소 검토 중).
  - 전투: 스테이지 낮/밤 상속. 전투 내 교대 없음.
  - **겪은 카드 → 내 패로 축적 (v2.0 변경).**
- **덱빌딩 구조 (STAGE-DECK-001 v0.2):**
  - "겪은 것이 덱이 된다." 카드 1장 = 이야기 + 재료 + 기록.
  - 분기 효과가 유일한 보상. 토큰 체계 전면 폐기 (v0.2).
  - 유물 압축: 스테이지 카드 → 챕터 카드 → 오더 카드.
- **카드 타입 체계 (COMBAT-UNIT-CARD v0.1):**
  - 인물(Figure) / 사건(Event) / 기록(Record) 3타입.
  - 등급: Nameless(무명) → Named(유명) → Hero(영웅).
  - 이름 유무가 곧 등급. 카드 표면에 등급 태그 없음.
  - Named만 ★ 면 + 2단계 부상 생존.
  - 패시브: 모든 인물 카드에 적용. 초기 비어있음. 스테이지 보상 획득. 최대 3슬롯.
  - 전환 메카닉 → 패시브로 흡수 (보병: 전열 교대, 창병: 반격, 궁병: 선제 공격).
  - 카드 레이아웃 5영역: 일러스트/명칭/플레이버/패시브/다이스면.
- **Named 인물 (COMBAT-UNIT-HERO v0.3):**
  - 테오도라 / 기사 (창병 계열): ★⚔🛡🛡✕✕, 패시브=반격.
  - 앰버 / 궁병: ⚔⚔⚔★✕✕, 패시브=선제 공격.
  - 패시브 초기 비어있음. 스테이지 보상 획득.
- **전투 구조 v0.4 (COMBAT-STRUCT-001):**
  - 7스텝. 3페이즈. 낮/밤 교대 삭제.
- **로비 씬:**
  - 비활성 런: [새 게임] [기록] [설정]
  - 활성 런: [새 게임] [이어하기] [기록] [설정]
  - 런 슬롯 1개. [새 게임]+활성 런 = 덮어쓰기 경고.
  - [기록] = 완료된 오더 카드(성적표) 열람.
- **폐기 완료:** T2 병종, 정예화, 보병전환, 보급, 작전카드, 야영, WIP_FLOW.

## 우선순위 P0

### 1. Order 1 이야기 뼈대

- 테오도라의 첫 시련. 증명과 명예의 시작.
- Chapter → Stage 쪼개기.
- Stage별 사건 카드 도출의 기반.
- 사건 계열 분류 (전투/탐색/외교) 구체화와 연동.

### 2. 사건 카드 실물 만들기

- Order 1 첫 스테이지 기준 사건 카드 초안.
- 뒷면 아이콘 (사건 종류 암시) 구체화.
- 우연 카드 포함.
- 분기 효과 → 전투 연결 구체화.

### 3. 턴 수 확정

- 10턴 → 5턴 축소 방향 검토.
- 덱 크기 연동 (30장 유지? 15장으로 축소?).
- 유물 획득 빈도와 챕터 내 스테이지 수 조정.

## 우선순위 P1

### 4. 유물 테이블 구조

- 인풋: 겪은 사건 내역 (타입별 비율) + 전투 결과.
- 아웃풋: 성향별 효과 풀.
- 규모: 계열당 후보 몇 개.

### 5. 운명 달성 조건

- 조건 유형 목록 (교전 N회 승리, N턴 생존, 특정 선택 N회 등).
- 추적 방식 (카운터 vs 체크리스트).
- 운명 보상 구체화 (면교체 + 유물 + Named 승급 + 패시브 획득).

### 6. 캐릭터 선택 화면

- [새 게임] → 캐릭터 선택 → 편성 화면 흐름.
- 초기 편성 구성 (Named 2 + Nameless 몇?).

### 7. 편성 화면 설계

- 전투 전 편대 구성 UI.
- 인물 카드 배치, 패시브 확인.

## 우선순위 P2

### 8. 챕터 카드 합치기 규칙

- 스테이지 카드들이 묶일 때 효과 결정 방식.
- Order 1 챕터 구조 확정 후 설계 가능.

### 9. 초기 패 설계

- 편성 시 2~3장. "테오도라가 이미 가진 경험."
- 오더별 고정? 플레이어 선택?

### 10. 아트 문서 정합성

- Named/Nameless 카드 뒷면 시안 필요.
- "선택 카드 3장" → 1장으로 변경 반영.
- 보급 관련 시안 갱신 (보급 폐기 반영).
