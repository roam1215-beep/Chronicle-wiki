## 확정 사항 (참고)

- 5층 구조: 인물 → Order → Chapter → Stage → Battle
- 사서 프레임: 모든 사건은 역사로 기록
- **카드 해상도 확정 (STAGE-CARD-001 v1.0):**
  - 매 턴 1장 뒤집기. 사건(분기 선택) / 우연(즉시 발동).
  - 운명 상단 공개. 덱에 안 섞임.
  - 덱 30장. 10턴 상한. 비복원.
  - 전투: 스테이지 낮/밤 상속. 전투 내 교대 없음.
  - 챕터 트위스트가 덱 구성 변경.
- 턴 구조: 1턴 = 반나절. 2턴 = 하루. 홀수 = 낮, 짝수 = 밤.
- 테오도라 정의: 증명과 명예 / 신분·차별·이용 / 인간성 상실 위험.
- 인물 모티프: 뒤누아(전장 증명) + 비잔틴 테오도라(의도를 읽는 눈).
