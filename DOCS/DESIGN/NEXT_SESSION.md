  - 보급 폐기. 야영 폐기 (운명 달성이 대체).
- **전투 구조 v0.4 (COMBAT-STRUCT-001):**
  - 7스텝. 3페이즈. 낮/밤 교대 삭제.
  - 스텝2: 토큰 소모 (작전카드 대체). 스텝4: 탐색 토큰 리롤.
- **면 교체:** ✕ → ⚔/🛡/✕ 랜덤. 매 스테이지 클리어 시 1회.
- **프로모션:** T1→T2. 운명 보상 한정. 귀하게.
- **브리핑:** 전술회의(막사). 스테이지 분위기 암시 + 운명 공개 + 경량 보급.

## 우선순위 P0

### 1. 토큰 3종 구체 효과 설계

- 전투 토큰: 스텝2에서 뭘 하는가. ⚔/🛡 확정? 카드락?
- 탐색 토큰: 스텝4에서 리롤 추가. 적 주사위 리롤도?
- 외교 토큰: 카드 페이즈에서 뭘 하는가. 카드 새로고침? 우연 무효화?
- 선행 조건: 전투 프로토타입에서 검증 필요.

### 2. 턴 수 확정

- 10턴 → 5턴 축소 방향 검토.
- 덱 크기 연동 (30장 유지? 15장으로 축소?).
- 유물 획득 빈도와 챕터 내 스테이지 수 조정.

### 3. Order 1 이야기 뼈대

- 테오도라의 첫 시련. 증명과 명예의 시작.
- Chapter → Stage 쪼개기.
- Stage별 사건 카드 도출의 기반.
- 사건 계열 분류 (전투/탐색/외교) 구체화와 연동.

## 우선순위 P1

### 4. 사건 카드 실물 만들기

- Order 1 첫 스테이지 기준 사건 카드 초안.
- 뒷면 아이콘 (사건 종류 암시) 구체화.
- 우연 카드 포함.

### 5. 유물 테이블 구조

- 인풋: 겪은 사건 내역 (타입별 비율) + 잔여 토큰 + 전투 결과.
- 아웃풋: 성향별 효과 풀.
- 규모: 계열당 후보 몇 개.

### 6. 운명 달성 조건

- 조건 유형 목록 (교전 N회 승리, N턴 생존, 특정 선택 N회 등).
- 추적 방식 (카운터 vs 체크리스트).
- 운명 보상 구체화 (면교체 + 유물 + 프로모션 조건).

### 7. 경량 보급 설계

- 브리핑에서 챙기는 생존 소모품.
- 토큰과 역할 겹치지 않는 것.
- 붕대(부상 치유) 외에 뭐가 있는지.
