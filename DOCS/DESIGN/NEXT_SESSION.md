# 다음 세션 안건

## 우선순위 P0

### 1. 카드 해상도 — "카드 1장이 뭘 하는가"

- 카드를 골랐다. **그래서 뭐가 일어나는가?**
- 전투가 발생하나? 버프를 받나? 자원을 얻나? 부대 상태가 바뀌나?
- 카드와 전투(7스텝)는 어떻게 연결되는가?
- 우연 카드의 "즉시 발동"도 마찬가지 — 구체적으로 뭐가 바뀌는가?
- 선행 조건: 게임 상태 정의 (카드가 건드릴 수 있는 상태 목록)

### 2. 카드 풀 — "덱이 어디서 오는가"

- 스테이지별 고유 덱? 공용 풀에서 조합?
- 보급 선택이 덱에 영향을 주는가?
- 챕터 트위스트가 덱 구성을 바꾸는가?

### 3. 게임 상태 정의

- 부대, 보급, 전투 조건, 운명 진척도 외에 뭐가 있는가?
- 카드가 건드릴 수 있는 변수 목록 확정

## 우선순위 P1

### 4. 챕터 트위스트 목록
- 카드 해상도 확정 후 설계 가능.

### 5. 보급 풀 세부
- 카드 종류, 선택 장수, 사용 타이밍.

### 6. 야영 시스템
- 위치·빈도·역할.

## 확정 사항 (참고)

- 5층 구조: 인물 → Order → Chapter → Stage → Battle
- 사서 프레임: 모든 사건은 역사로 기록
- 카드 덱 삼분법: 선택(3장→1장) / 우연(즉시 발동) / 운명(스테이지 목표 1장, N턴 제한)
- 잔류 처리: 잔류가 슬롯을 먹음. 항상 3장.
- 턴 구조: 우연 즉시 → 선택 3장 중 1장 → 남은 턴 -1
- 우연 빈도: 덱 구성 비율로 조절
- 세 채널 완전 분리: 선택(슬롯) / 우연(즉시) / 운명(상단)

## 개발 환경

- Unity 6 LTS (6.3) 설치 완료 예정
- VS Code + C# Dev Kit + Unity 확장
- TDD: Core(순수 C#) / Unity(MonoBehaviour) 분리
- 구현 시작 가능 대상: 전투 7스텝 엔진 (카드 덱과 독립)
