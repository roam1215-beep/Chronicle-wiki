## 최근 작업

### 카드 방식 전면 변경

- **세 박자 재정의:** 붙잡기/뒤집기/감내 → **정찰/판단/감내**
  - 정찰: 뒷면 3장 중 1장 공개. 전투·사건=완전정보, 우연="우연 카드"만
  - 판단: 3장 중 1장 버림 (공개 카드 포함 어디든)
  - 감내: 남은 2장 순차 즉발
- **분기 폐기.** 카드당 태그 1세트. 뒤집으면 즉발. 에이전시는 정찰-판단(카드 레벨) + 대형/리롤/방진(전투 레벨)으로 완전 분리
- **적 구성: 카드 고정 → 적 테이블 Lv 참조.** 같은 카드도 챕터 위치(Lv1/2/3)에 따라 적 난이도 변동
- **홀드 탭 폐기.** 정찰이 유일한 정보 수단
- **뒷면: 2종(전투/사건)+우연위장 → 팩당 1종+운명 1종.** 정찰 전 정보 0
- **우연 위장 폐기.** 뒷면 1종이므로 위장 개념 소멸
- **333 유형 보장 폐기.** 팩 내 유형 비율(금형)에 의존
- **겪기 2장 순서: 자동 순차.** 미지 카드 순서 정하기는 의미 없는 판단
- **일러스트 3종 1세트 폐기**
- **추종자 조언 폐기**

### 팩·금형 구조

- **챕터 팩 9개 × 90장 = 810장/권.** 런마다 9개 중 3개 랜덤 배정. C(9,3)=84가지 조합
- **팩 내부:** 일반 81장(전투/사건/우연) + 운명 9장. 운명 별도 풀 폐기
- **공간 금형 6종:** 다리/협곡/평원/숲/산지/분지. 금형 = 팩의 뼈대(유형 비율+태그 분포+특수 규칙)
- **금형 개성:** 전투 ~50% 공통. 사건/우연 비율이 금형마다 다름. 금형별 특수 규칙(7스텝 외부 조건)
- **뒷면:** 팩당 1종(팩 아이덴티티). 9팩=9종 뒷면. 운명 뒷면 별도 1종
- **적 테이블 Lv:** 챕터 난이도 3단계. 카드 N장 × Lv3 = 실질 3배 전투 다양성
- **12과업 구조:** 챕터 팩 = 하나의 이야기. 지명이 팩을 호출. 헤라클레스 12과업 원형

### 런 구조 변경

- **3×3×3:** Chapter 3 × Stage 3 × 페이즈 3 = 27페이즈/런
- **Stage/런:** 6→9. 운명/런: 6→9
- **패배 체크:** Stage 2,4,6 → **모든 운명 전투 패배 = 게임오버**
- **겪기/런:** 63장 (일반54+운명9). 버림/런: 27장 (전해지지 않은 이야기)
- **팩 소모율:** 30/90 = 33%. 67%가 매 런 미사용 → 리플레이 다양성
- **공개 순서:** 장소(팩 뒷면) → 계절 → 동료
