# 2026-03-07 라벨-태그 재편 + 배경 시스템 설계 세션

## 결정 사항

### 1. 용어 체계 확정

- 상위 = 라벨 (카드/분기 효과), 하위 = 태그 (주사위 면 변환)
- "태그"로 혼용되던 모든 개념을 분리
- 이야기 카드 = 전체 카드 체계 명칭 (기존 "사건 카드" 상위)

### 2. 이야기 카드 4종

- 전투 카드 (전략+전술+결과 라벨)
- 사건 카드 (비전투 라벨)
- 우연 카드 (우연 라벨)
- 운명 카드 (전략+전술+결과 라벨 + 운명 조건)

### 3. 라벨 6분류 17개 확정

- 전략 4: [기습][역습][지원군][포위]
- 전술 3: [봉쇄][결투][난전]
- 결과 3: [약탈][전리품][귀순]
- 비전투 4: [증원][합류][훈련][단련]
- 우연 3: [복잡한 운명][탈영][복병]

### 4. 주사위 태그 4종 확정

- [연마] ✕→판정 (★10/⚔30/🛡30/✕30)
- [열화] ⚔🛡→판정 (⚔33/🛡33/✕33). ★ 제외
- [단조] 열화→연마 순차
- [보강] ✕→⚔/🛡 확정 (플레이어 선택)

### 5. 전투 규칙 확정

- [결투]: ⚔ 수 비교, 🛡 방어 작동, 카드락/B풀 미적용
- [지원군]/[포위]: 완전한 유닛, 전 스텝 참여, 전투 후 사라짐
- 카드락: 아군 첫 굴림 시 적용. 굴리지 못하면 카드락 못함
- [역습] 시 카드락: R2 보류 적용
- 선제 불발 궁병: 격돌 합류 (밤 전투와 동일)
- [난전] × 기사: 패시브 기준. 기사도 보유 패시브에 따라 무력화
- 부상 자동 회복: 전투 종료 즉시. 스냅샷 복원
- 지휘: 리롤의 플레이어 대면 명칭
- 결과 라벨 타이밍: 전투 종료 → 부상 회복 → 결과 라벨

### 6. 유닛/면 추적

- 유닛 = 주사위 1개. 면 상태 개별 추적
- Nameless ★ 체이닝: Named와 동일
- [귀순] 유닛: 기본 면으로 합류
- 전투 중 면 변환 없음 (모든 태그는 전투 외 발동)

### 7. 설계 원칙 확정

- 예외처리 최소화. 기존 구조 안에서 해결
- 라벨은 7스텝 호환만. 안 되는 건 배경으로
- 보수적 확장. 금형 정밀도 우선

### 8. 배경 시스템 신규

- 배경 = 장소 + 계절 + 상황. 챕터 단위
- 7스텝으로 안 되는 것을 배경에서 품는 구조
- 계절: 가을(유리)/겨울(불리)/봄·여름(미정)
- 스토리 팩 연동: 16배경 × 6×6×6팩 = 3,456 런 조합

### 9. 추종자 시스템 신규

- 비전투 Named. 유물 격. 런 전체 지속. 상한 10명
- 라벨/태그 효과 수정 패시브
- 라벨 확정 후 상세 설계

### 10. 폐기/변경

- 기존 [결전] 라벨 제거
- 기존 [수습][치료][재편] 라벨 제거
- 기존 [불운][표류] 우연 라벨 제거
- [사기진작] 제안 후 제거
- 부상 스테이지 간 이월 → 전투당 자동 회복으로 변경
