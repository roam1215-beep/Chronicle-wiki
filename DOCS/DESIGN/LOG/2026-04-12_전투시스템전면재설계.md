# 세션 로그: 전투 시스템 전면 재설계 — 2026-04-12

> **세션 유형:** 기획 세션
> **참여:** 철 + Claude (claude.ai)
> **시간:** 약 3시간
> **상태:** 방향 확정 / 상세 미확정

---

## 배경

기존 전투 시스템(7스텝 + ⚔/🛡/✕/★ 면 + 색 매칭·킵)의 확장성 한계를 진단하고, 전면 재설계 방향을 탐색한 세션.

### 진단한 문제

1. **판정이 단일 축 뺄셈.** ⚔ 합 - 🛡 합 = 피해. 색/킵/지형을 얹어도 같은 방정식에 항을 추가하는 것뿐. 시스템을 3개 쌓아도 깊이는 1.
2. **맥락이 판단을 안 바꿈.** 다리든 평원이든 숲이든 플레이어가 하는 4개 판단(대형/리롤/방진/킵)이 동일. 전투마다 같은 풀에서 같은 판단 반복.
3. **포기가 없음.** 리롤도 하고 방진도 하고 킵도 챙겨. 전부 다 해. 하나를 위해 다른 하나를 버리는 순간이 없어서 "잘한 선택"이 성립 안 함.
4. **반응형 패시브(방진/반격)가 선언식 전투와 충돌.** 결과를 보고 조정하는 구조는 선언식 모델과 맞지 않음.

## 탐색 경로

세션 중 여러 방향을 탐색·폐기함:

| 탐색 | 결과 | 사유 |
|------|------|------|
| 면 종류 확장 (칼/활/창/도끼/방패 등 고유 심볼) | 폐기 | 병종마다 고유 규칙 → 병종 추가 시 규칙 선형 증가. 확장성 반대 |
| 숫자면 도입 (1~6 중립 숫자 + 공수 배분) | 부분 채택 → 진화 | 배분 모델의 기초가 됨 |
| 심볼별 상성 매트릭스 | 폐기 | 1:1 매칭이 매 라운드 조합 퍼즐이 되어 인지부하 폭발 |
| 심볼 자동 해상도 + 순서 | **채택** | 페이즈 구분 없이 심볼 순서대로 처리. 규칙 하나 통째로 빠짐 |
| 전열/후열 2줄 | 채택 → 확장 | 좌익/중앙/우익 행 추가로 격자 구조 확정 |
| 3열(전열/2열/후열) | 탐색 후 유동적 | 맵이 열 수를 결정하는 방식으로 전환 |

## 확정된 방향

### 1. 전투 패러다임: 선언식

| 항목 | 기존 | 신규 |
|------|------|------|
| 모델 | 반응형 (굴리고 → 보고 → 조정) | **선언식** (선언 → 굴림 → 자동 해상도) |
| 판정 | ⚔ 합 - 🛡 합 = 단일 축 뺄셈 | **심볼별 해상도 순서 + 방패 즉시 상쇄** |
| 페이즈 | 선제/격돌 분리 | **페이즈 없음.** 심볼 순서대로 처리 |
| 깊이 원천 | 주사위 면 종류/패시브 | **배치(어디에) + 배분(공/수)** |

### 2. 주사위

| 유형 | 구성 | 대성공 |
|------|------|--------|
| Nameless d6 | 심볼 3, ✕ 3 | 없음 |
| Named d6 | 심볼 2, ✕ 3, ★ 1 | 심볼 확정 + 재굴림 |

- 심볼 종류 차이는 이 해상도에서 의미 없음. 색/시너지 레이어에서 풀 예정.
- Named / Nameless 분리로 "이름이 곧 등급" 체현.

### 3. 전장 구조: 행(좌익/중앙/우익) × 열(전열~후열) 격자

```
         좌익      중앙      우익
후열  [       ] [       ] [       ]
전열  [       ] [       ] [       ]
```

- **맵(타일)이 격자를 결정.** 열 수, 칸별 사용 가능/불가.
- 맵에 따라 2열~4열, 칸 차단(강, 절벽 등) 변동.
- **이것이 금형의 구체적 실체.** 같은 규칙에서 다른 전장.
- **인접 구역 공격 가능.** 좌익 → 적 좌익 + 적 중앙. 집중 배치 돌파 전략.

### 4. 타일 시스템

- 챕터 팩(장소)이 타일 풀을 결정.
- 전투마다 타일 풀에서 하나 배정.
- 타일이 격자 구조(열 수, 칸 차단, 지형 속성)를 정의.
- 예: "다리 위의 서자들" → 다리 관련 타일 풀. 다리/강변/접근로 등 변형.

### 5. 병종 (6종 + 네임드)

| 병종 | 위치 | 공/수 | 특이사항 |
|------|------|-------|----------|
| 민병 | 전열 고정 | **랜덤** (유닛마다) | 통제 불능 소모품 |
| 보병 | 전열 고정 | **선택** | 신뢰할 수 있는 전열 |
| 창병 | 배치 선택 | **선택** | 기병 상쇄 역할 (상세 미확정) |
| 궁병 | 후열(낮)/전열(밤) | 공격 고정 | 타겟 열/구역 선택 |
| 기병 | 열 선택 | 공격 고정 | 구체적 작동 미확정 |
| 용병 | 열 선택 | **열이 결정** | 놓는 곳이 역할 (DLC) |
| 네임드 | 병종 규칙 | **선택** | 기사 병종은 전열 고정 사거리 0 |

- **방패병 삭제.** 방어는 보병의 방패면이 담당.
- 병종 에이전시 스펙트럼: 민병(0) → 보병/궁병(1) → 창병/기병(2) → 네임드(2+).

### 6. 심볼 해상도 순서

심볼이 순서대로 풀리고, **방패는 매 순위마다 즉시 상쇄:**

| 순위 | 심볼 | 처리 |
|------|------|------|
| 1 | 활 | 타겟 열에 피해 → 해당 열 방패 즉시 상쇄 |
| 2 | 기병 | 공격 → 해당 열 방패 즉시 상쇄 |
| 3 | 창 | 공격 → 해당 열 방패 즉시 상쇄 |
| 4 | 칼/민 | 공격 → 해당 열 방패 즉시 상쇄 |

방패가 유한하므로, 앞 순위에서 방패가 소모되면 뒤 순위는 무방비.

### 7. HP

| 유형 | HP |
|------|-----|
| 전 Nameless | 1 |
| 네임드 | 2 |

### 8. 피해 규칙

- 심볼 1:1 상쇄.
- 상쇄 후 남은 공격 = 해당 열 피해.
- 피해는 해당 열 전열부터 HP 순서로 적용.
- **넘침 없음.** 한 라운드에 한 열 내에서만 적용.

### 9. 라운드 흐름

```
선언 → 굴림 → 심볼 순서대로 자동 해상도 → 다음 라운드 or 전투 종료
```

**선언에서 플레이어가 하는 것:**
- 유닛을 격자 칸에 배치 (행 + 열)
- 보병/창병/네임드의 공/수 배분
- 궁병 타겟 선택 (열/구역)
- 기병/용병/네임드 열 선택

나머지 전부 자동.

## 미확정 사항

| 항목 | 현재 상태 | 우선순위 |
|------|----------|----------|
| 기병 구체적 작동 | 방향만 (어디에서든 적 전열 타격). 후열 배치 시 이점/비용 미확정 | 높음 |
| 창병 고유 역할 | "기병 상쇄" 방향. 구체적 메카닉 미확정 | 높음 |
| 타일 지형 속성 | 격자 구조(열 수, 칸 차단)는 확정. 칸별 지형 효과(숲, 고지 등) 미확정 | 중간 |
| 심볼 간 상쇄/상성 구체 | 방패의 상쇄 대상 범위 미확정 | 높음 |
| 도끼병 등 추가 병종 | 철이 도끼병 희망. 현 6종에서 빈자리 검토 필요 | 낮음 |
| 색/시너지 레이어 | 카드에 색을 태우는 방향. 구체 미확정 | 중간 |
| 결사 (장기전 압박) | 기존 R5~ 결사 개념의 신규 구조 대응 미확정 | 중간 |
| 밤/낮 | 궁병 밤에 전열 이동은 논의됨. 신규 구조에서 재정의 필요 | 중간 |
| 인접 구역 공격 상세 | B안(인접 공격 가능) 채택. 궁병만 타겟 선택 vs 전체 선택 미확정 | 높음 |
| 적 AI 배치 | 적도 같은 격자 구조. AI 배치 로직 미확정 | 낮음 |
| Named 면 구성 | Named d6 (심볼2 ✕3 ★1) 확정. 병종별 심볼 차이 미확정 | 중간 |
| 전투 종료 조건 | 기존 "적 전멸/아군 전멸/테오도라 사망/8라운드 상한" 재검토 필요 | 중간 |

## 핵심 설계 원칙 (이번 세션에서 도출)

| 원칙 | 내용 |
|------|------|
| 규칙은 적게, 상황은 많게 | 병종마다 고유 규칙이 아니라, 같은 규칙에서 맵/조건이 다른 전투를 만든다 |
| 선언이 판단, 해상도는 자동 | 플레이어는 배치와 배분만. 나머지는 지켜본다 |
| 포기가 있어야 잘함이 있다 | 열세인 테오도라 진영이 어디를 버리고 어디에 집중할지가 게임 |
| 맵이 금형 | 전장 격자 자체가 달라지면 같은 규칙에서 다른 전투. 규칙 추가 없는 확장 |
| 병종 통제도 = 서사 | 민병(통제 불능) → 네임드(완전 유연). 규칙이 서사를 체현 |
