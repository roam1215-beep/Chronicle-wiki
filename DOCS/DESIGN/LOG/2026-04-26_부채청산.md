## 결정 사항

### 1. 전투 방향: 7스텝 부활 + 다층 입력

| 항목 | 결정 |
|------|------|
| 그릇 | **7스텝 골격 부활.** 단순함의 미학 회복 |
| 면 종류 | ⚔🛡✕★ 4종 부활 |
| ★ 체이닝 | 부활 |
| 격자 / 좌우익 / 열 / 심볼 해상도 / 공격 대상 지정 | **폐기.** SRPG 하위호환적 변용 |
| 색 매칭 / 색 시스템 | **폐기** |
| 산개 / 밀집 (대형) | **폐기.** "카드 = 주사위 1개 = 유닛 1기" 단순화 |
| 공격력 / 방어력 스칼라 | **신설.** 같은 ⚔/🛡이 카드마다 다른 값 |
| 면 비율 통합 | 방향 (구체 미정) |

### 2. 깊이 원천: 다층 입력 모델

```
[카드 면]      ← 인물별 기본 주사위
[공/방]        ← 카드별 스칼라
[시너지]       ← 카드 조합 (TODO)
[환경]         ← 챕터/계절/지형 (TODO)
[추종자]       ← 영구 자산
[일화]         ← 즉발 태그 효과
        ↓
   ⚔합 - 🛡합 = 피해 (그릇은 한 줄)
```
