## 큰 결 박힘

### 1. 사건 카드 분기 폐기 (5-11+ 박힘)

```yaml
옛 결 (5-7):
  사건 카드 = 선택형 (분기 a/b/c) + 결과형 (즉발) 두 분류
  Type 노출 시: 선택형 = 분기 라벨까지 공개 / 결과형 = 결과 공개
  발화 시: 선택형 = 분기 선택 (플레이어 개입) / 결과형 = 자동 즉발
  내부 라벨 (선택/결과) 카드 데이터에 박힘

새 결 (5-11+):
  사건 카드 = 결과형 단일
  Type 노출 시: 텍스트 + 결과 공개
  발화 시: 자동 즉발 (개입 X)
  내부 라벨 폐기

근거 (본인 박은 결):
  - "분기라는걸 제외할거야 전투 카드도 사건카드에서도 마찬가지야"
  - 분기 폐기로 사건 = 일어나는 일 결로 박힘 (내부 결)
  - Phase의 외부 결단 = 선택-거부만 남음 (발화 시 결단 자리 작아짐)

연쇄 정정:
  - 비율 결 (선택형/결과형 30/30 잠정) → 폐기 (단일 결로)
  - 내부 라벨 (카드 데이터 "선택/결과") → 폐기
  - 발화 시 플레이어 개입 (사건 자리) → 폐기 (우연 축복/저주만 남음)
```

### 2. 우연 카드 분기 살림 (5-11+ 확인)

```yaml
옛 결 (5-7) 유지:
  5 자리: 위기/기회/축복/저주/예언
  축복/저주 = 분기 (a/b/c — 무엇을 가져갈지·무엇으로 손해볼지)

근거 (본인 박은 결):
  "우연은 분기 살리고 사건에서 폐기야"

결의 결 (본인 박은 결로 정합):
  사건 = 일어나는 일 (내부 결) → 분기 X
  우연 = 외부 결 (신의 결, 신적 자리) → 작은 결단만 살림
  → 작품 결로 정합 깊음 (그리스 신화 결 — 신의 외부 결 + 인간의 작은 결단)
```

### 3. 적 정보 노출 결 (5-11+ 박힘)

```yaml
옛 결 (5-7):
  전투 카드 = 낮/밤 표기. 낮 = 적 완전 공개 / 밤 = 부분 공개
  시간대 카드별 박힘
  
중간 결 (5-9):
  카드별 시간대 표기 폐기. 시간대 = 페이즈 단위 결로 흡수.
  → 적 정보 공개 결의 자리 펜딩

새 결 (5-11+):
  시간대 차등 X (페이즈가 이미 정보 차단)
  Type 노출 시: 적 부대 다 공개 (정찰 결과)
  
  적 유닛 모형 위 노출:
    노출:   위계 (인간/영웅/무리/재앙) + 자기 시간대 + hp 바 + 보호막 바(있을 때만) + 직업 아이콘
    비노출: 등급 (굴림 시 주사위 수로 자연 드러남), 능력치 (공·방·속)

  예: "무리, 밤, hp 바, 직업(사냥꾼 아이콘) / 고블린 척후대"

근거 (본인 박은 결):
  - "어차피 사건 카드(전투)는 뒤집는 시점에서 전투가 시작될테니까, 낮 밤 경계 등의 시간에 따라 정보 공개에 차등이 있을 필요 없이 다 공개로 하면 되고 (페이즈에서 어차피 정보 차단이 이뤄짐)"
  - 위계 = 게임 노출 어휘 결 (작품 결로 박힌 결)
  - 자기 시간대 = 시간대 보정 + 박힘 면 결 추측 가능
  - 등급은 굴림 시 자연 드러남 (주사위 수 = 등급)
```

### 4. 정보 비대칭 결 (5-11+ 박힘)

```yaml
새 결:
  아군 인물:
    hp 바 + 숫자 (정확한 결)
    보호막 바 + 숫자 (정확한 결)
  
  적 인물:
    hp 바만 (수치 X, 유추 결)
    보호막 바만 (있을 때, 유추 결)

근거 (본인 박은 결):
  - "hp인데 이거는 내 진영에 있는 애들은 숫자까지 보이고 적은 hp 게이지로 유추만 가능하게 하는 것도 포인트야"
  - "보호막도 같은 결"
  
결의 결:
  진영 차별 결. 작품 결 (사서 결 = 내 진영 = 정확한 기록 / 적 = 추측)
  플레이어 자리 결 (아테나 결 = 내 인물 신적 시점)
```
