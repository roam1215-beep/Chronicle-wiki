# 세션 로그: 2026-02-26 카드 덱 확정 (2차)

## 세션 목표

무른 점 4개 해결 (잔류, 운명, 우연 빈도, 겹침). 개발 환경 세팅 시작.

## 결정 사항

### 1. 잔류 처리 확정

| 필드 | 내용 |
|------|------|
| 규칙 | 잔류가 슬롯을 먹는다. 매 턴 항상 3장 (잔류 + 새 카드). |
| 안정점 | 잔류는 2장으로 안정. 폭발 안 함. |
| 대가 | 미루면 새 카드 1장만 봄. 시야 좁아짐. |
| 밸런싱 | "무시하면 악화되는 카드"로 방치 방지. 밸런스 영역. |

### 2. 운명 재정의 — 스테이지 목표 1장

| 필드 | 내용 |
|------|------|
| 기존 | 운명 카드 복수장 + 별도 트랙 + 카운트다운 |
| 변경 | 운명 = 스테이지 목표 1장. 시작부터 공개. N턴 제한. |
| 미달성 | 런 실패. 기록 없음. |
| 대명령 연결 | 운명 = 명령. "적 지휘관을 처치하라." |
| 의의 | 운명 트랙 불필요. 인지 부하 대폭 감소. 테마=구조. |

검토 과정:
- A안(즉시 발동): 구조 깔끔하지만 운명과 우연의 차이가 타이밍뿐.
- B안(카운트다운): 판타지에 맞지만 잔류 슬롯 충돌 + 인지 부하 폭발.
- 최종: 운명을 "사건"이 아니라 "목적"으로 격상. 스테이지 존재 이유 = 운명.

### 3. 우연 빈도 확정

| 필드 | 내용 |
|------|------|
| 방식 | 덱 구성 비율로 조절. 셔플이 타이밍 결정. |
| 원칙 | 빈도 높지 않게. 예측 불가능하게. |

### 4. 겹침 문제 해소

- 운명이 스테이지 목표가 되면서 턴 안에서 겹칠 게 우연+선택 최대 2개뿐. 과부하 없음.

### 5. 카드 카테고리 폐기

- 교전/정찰/병참/돌발 → 폐기.
- 압박 카드/기회 카드 → 폐기.
- 모든 카드 = 사건. 도착 방식(선택/우연)만 다름.

### 6. 카드 해상도 부재 발견

- 카드 한 장이 게임 상태에 뭘 하는지 통째로 비어있음.
- 전투와 어떻게 연결되는지 미정.
- 덱이 어디서 오는지 미정.
- → 다음 세션 P0.
