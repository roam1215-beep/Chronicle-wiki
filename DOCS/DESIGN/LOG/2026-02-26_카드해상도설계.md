# 세션 로그: 2026-02-26 카드 해상도 설계

## 세션 목표

P0 안건: 카드 해상도 — "카드 1장이 뭘 하는가" 확정.

## 핵심 결정 과정

### 1단계: 기능적 접근 시도 → 폐기

- 카드 효과 6유형(교전/병참/인사/지형/정보/시간) 분류 시도.
- "기능적인 면으로 풀지 말자" — 이야기 구조를 먼저 상정하고 카드를 도출해야.

### 2단계: 인물 정의 선행

- 헤라클레스 12과업 비유: 인물 정의 → 갈등 → 시련 → Order.
- 테오도라 정의 확정:
  - 원하는 것: 증명과 명예
  - 부딪히는 것: 신분, 차별, 이용(소모품 취급)
  - 잃을 수 있는 것: 인간성 (부딪히는 것들과 비슷해질 수 있음)
- 인물 모티프: 뒤누아(전장 증명) + 비잔틴 테오도라(명령 뒤의 의도를 읽는 눈).

### 3단계: 카드 = 사건이자 이야기

- 카드는 기능 전달 수단이 아니라 장면.
- 스테이지 고유 덱: 해당 상황에서 일어날 수 있는 사건들.
- 개연성: "왜 이게 지금?"이 자연스러움.

### 4단계: 카드 딜 방식 탐색 (3장 → 2장 → 1장)

| 구조 | 장점 | 단점 | 결과 |
|------|------|------|------|
| 3장 공개 → 1장 선택 | 비교 가능 | 퍼즐. 뒤집기 긴장 없음. | 폐기 |
| 3장 엎고 뒤집기 | 긴장감 | 묶음 필요 → 리플레이 감소 | 폐기 |
| 묶음 2장 + 우연 주사위 | 설계 통제 | 뒤집기 맛 소멸. 빈 카드. | 폐기 |
| 묶음 3장 (우연 분리) | 딜레마 보장 | 리플레이 해침 | 폐기 |
| 낱장 3장 셔플 딜 | 리플레이 | 비슷한 카드 가능 | 폐기 |
| 낱장 2장 딜 | 깔끔 | 뒤집기 긴장 부재 | 폐기 |
| **1장 + 분기** | 단순. 날카로움. | 기획 난이도 높음. | **확정** |

### 5단계: 최종 구조 확정

- 매 턴 1장 뒤집기.
- 사건 카드: 분기 2~3개. 선택.
- 우연 카드: 즉시 발동. 선택 없음.
- 운명: 상단 공개. 덱 밖.
- 전투: 스테이지 낮/밤 상속. 전투 내 교대 삭제.

### 6단계: 부수 결정

- 챕터 트위스트가 우연 비율/덱 구성 변경 담당 (미풍/소용돌이 흡수).
- 덱 30장, 10턴 상한.
- 비복원. 한 번 나온 카드 재등장 없음.
- 운명 달성은 특정 카드 의존 아님. 누적 상태 의존.
