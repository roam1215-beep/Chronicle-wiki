# 2026-03-10 배경 전면 재설계 세션

## 세션 목표

배경 관련 내용을 완전히 확정하고 엣지 케이스 커버.

## 실제 진행

배경 시스템 교차 검증 중 풀 소진 블로커(B-8) 발견 → 장소 시스템 근본 재검토 → 카드 방식 전면 재설계로 확대.

## 결정 과정

### 1. 풀 소진 블로커 발견

기존 장소별 풀 60장(유형별 20장)에서 1 Chapter(6막) 소모 시 유형별 20장 초과. 3개 장소 전부 터짐. γ 세트(뽑기 비율)와 유형별 균등 풀의 구조적 충돌.

### 2. 장소 → 공간 금형 전환

- 지명보다 공간이 메카닉을 결정. "헬름 협곡"에서 핵심은 협곡.
- 금형 6종: 다리/협곡/평원/숲/산지/분지
- 금형이 팩의 뼈대(유형 비율+태그 분포+특수 규칙)
- 일러스트 3종 1세트 폐기

### 3. 카드 배분 고정 (하스스톤 마나 코스트급)

- 배분 규칙은 불변. 금형이 뭐든 안 바뀜
- 금형 개성 = 같은 슬롯에 들어가는 카드의 내용 (태그 분포)

### 4. 333 → 폐기 → 정찰 루프 도입

- 333 유형 보장 논의 → 보장 없어야 맛이 산다
- "페이즈=카드1장" 시도 → 준비량 부족으로 폐기
- 분기 불필요 발견: 3장 중 2장을 골랐는데 또 분기가 필요한가?
- 최종: 3장 제시 → 1장 정찰(공개) → 1장 버림 → 2장 즉발

### 5. 정찰 정보 비대칭

- 전투·사건 = 완전 정보 (태그+적+보상)
- 우연 = "우연 카드"만. 세부 미공개
- 금형 개성: 우연 비율 높은 금형은 정찰 가치 낮음

### 6. 적 테이블 Lv

- 적 카드 고정 → 적 테이블 참조로 복귀
- 챕터 위치(Lv1/2/3)에 따라 같은 카드도 적 난이도 변동
- 팩 범용성 보장 (9팩 어디든 아무 챕터에 배정)

### 7. 팩 뒷면 = 팩 아이덴티티

- 같은 팩이면 같은 뒷면 (하스스톤 뒷면 장식)
- 정찰 전 유형 정보 0 유지
- 운명 뒷면은 별도 1종

### 8. 런 구조 변경

- 1 Chapter = 3 Stage (기존 2). 런 = 9 Stage
- 모든 운명 전투 패배 = 게임오버
- 팩 소모: 30/90 = 33%. 리플레이 건재

### 9. 챕터 팩 9개

- 1권 = 9팩 × 90장 = 810장
- 런마다 9개 중 3개 랜덤. C(9,3)=84가지
- 12과업 서사 구조 (헤라클레스 원형)
