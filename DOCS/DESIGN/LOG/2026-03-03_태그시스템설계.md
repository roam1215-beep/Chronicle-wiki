# 2026-03-03: 스토아 팩토리 태그 시스템 설계

## 세션 목표

Chronicle 카드 시스템의 메카닉을 태그로 통합. AI 파이프라인(스토아 팩토리)의 전제 조건 확립.

## 주요 결정

### 1. 분기 효과 enum 폐기 → 태그 통합

- 기존: 분기 효과 풀(면확정/리롤추가/적정보/선제 + 병종추가/면교체/부상/병력손실)
- 변경: **카드 = 서술 + 태그 배열.** 태그가 메카닉 금형, 서술이 서사

### 2. 2레이어 구조 확정

- 카드 태그: 전황(세계가 정한 것). 뒤집으면 확정
- 분기 태그: 전술/전투후/비전투(플레이어가 고른 것)
- 설계 철학: "소규모 부대가 전황을 바꿀 수 없지만 전술은 선택할 수 있다"

### 3. 태그 5분류 19개 확정

| 분류 | 개수 | 레이어 |
|------|------|--------|
| 전황 | 3 | 카드 (최대 1개) |
| 전술 | 3 | 분기 (최대 1개) |
| 전투 후 | 3 | 분기/운명 (최대 1개) |
| 비전투 | 5 | 분기 (최대 1개) |
| 우연 | 5 | 카드 (1개) |

서브 메카닉 3개: [연마] [열화] [단조] (대장장이 메타포)

### 4. 우연 3분위

행운(아군 이득) / 불운(아군 손해) / 전투(강제 전투). 덱 설계 시 스테이지별 우연 기대값 조절 가능.

### 5. 전리품 → 업적 카드 이관

- 기존: 전투 후 태그 [전리품:칼/방패/책]. 영구 효과가 런 중 무한 축적 가능
- 변경: 업적 카드(Chapter 전환 시 3종 택1, 런당 2회)로 이관. 영구 효과 총량 통제

### 6. 이름 확정 과정

| 최종 | 변경 이력 |
|------|----------|
| [기습]/[역습] | 전황. 선공/피공 → 기습/피습 → 기습/역습 |
| [봉쇄] | 전술. 매복(기습과 혼동) → 선점 → 고지 → 봉쇄 |
| [매복]/[복병] | 매복(전술, 아군 유리) → 봉쇄로 교체. 복병(우연, 적 유리) |
| [단조] | 서브 메카닉. 담금질 → 단조 |
