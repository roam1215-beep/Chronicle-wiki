### 묶음 1 — 주사위 시스템 (확정)

```yaml
주사위:
  d6, 6면 모두 시간대 면
  공백·실패·별 없음

출신 3종 = 신앙 = 팩션:
  미궁 (밤 신앙):  밤 3 / 황혼 2 / 낮 1
  도시 (낮 신앙):  낮 3 / 황혼 2 / 밤 1
  경계 (신앙 X):   황혼 2 / 낮 2 / 밤 2  (균등)

시간대 인접: 선형 (낮 ─ 황혼 ─ 밤)

페이즈 시간대:
  일반 페이즈 3개 = 낮 / 황혼 / 밤 (페이즈마다 진행)
  운명 페이즈 = 작가 결 (시간대 시퀀스 펜딩)
  카드별 시간대 X (페이즈가 시간대 가짐)

매칭 점수:
  미궁/도시: 자기 시간대 면 = 2점, 그 외 = 0점
    → "신앙은 자기 시간대에서만 작동"
  경계: 모든 면 = 1점
    → "신을 믿지 않으니 시간대 무관"

별:
  출신 주사위에 없음
  덕목 주사위 자리 (묶음 4)

어휘:
  영웅 (주사위 N개) / 인간 (주사위 1개)
  영웅 = 카타스테리스모스 (별이 된 자)
```

#### 결정 근거 풀이

- **칼/방패 폐기**: 본인 진단 — *"칼 방패가 작품의 유연성을 억압"*. 행동 종속 면을 폐기하고 *면 = 계산기*로 전환.
- **모든 면 시간대**: 실패면(공백) 폐기. 모든 면이 무엇인가 함.
- **자기/인접/반대 점수 격차**: 본인 직관 — *"낮에 밤이 활약하는 것은 이상해"*. 반대 시간대 = 0점.
- **경계 = 신앙 무관**: 본인 결 — *"애초에 이들은 신을 믿지 않는 자들"*. 시간대 무관 1점 균일.
- **시간대 시퀀스 ㉡**: 페이즈 진행 자동 (낮 → 황혼 → 밤). 운빨 X. 모든 출신 한 스테이지 안에 자기 시간대 한 번씩 만남.

#### 펜딩

- 운명 페이즈 시간대 (스테이지 4페이즈 = 일반 3 + 운명 1)

### 묶음 2 — 체력·등급·팩션·세계관 (확정)

```yaml
영구 손실 (모두):
  영웅 hp 0 = 영구 손실 + 게임 오버
  인간 hp 0 = 영구 손실
  재앙 hp 0 = 멸절 + 운명 전투 클리어 + 영웅에 덕목 박힘
  무리 hp 0 = 영구 손실

체력:
  모든 캐릭터 hp 보유. 1격사 X.
  한 스테이지 내 유지. 운명 후 풀 회복.
  수치 = 팩션별 차별. 잠정 펜딩.

등급 4종:
  영웅 (Heroes) — 인간의 상위. 주사위 N개. hp 큼. 이름 박힌 자
  인간 (Humans) — 정예. 주사위 1개. hp 보통. 수 적음
  재앙 (Calamity) — 무리의 상위. 주사위 N개. hp 큼. 이름 박힌 위협
  무리 (Horde) — 떼. 주사위 1개. hp 작음. 수 많음

대비 결:
  영웅 ↔ 재앙 (이름 박힌 자, 큰 자리)
  인간 ↔ 무리 (이름 없는 자, 작은 자리)
  카타스테리스모스 (별이 됨) ↔ 멸절

명성 (영웅 등극):
  업 쌓이면 인간 → 영웅 등극
  표현 = 덕목 주사위 추가
  메커니즘 = 운명 전투 (재앙 처치) 클리어 시 덕목 주사위 1개
  사건/우연도 가능 (R 결)
  카타스테리스모스 결

팩션 결 (스타크래프트 결):
  미궁: 무리 + 재앙 (몬스터 외형, 싸고 많음, 저그 결)
  도시: 인간 + 영웅 (정예, 균형, 테란 결)
  경계: 인간 + 영웅 (통제 안 됨, 끄나풀 가능성)

세계관 결 — 미궁 = 몬스터:
  표층 = 미궁 = 몬스터 (시각·시스템)
  심층 = 정치 단위 (작품 결 그대로)
  → "표층/심층 분리" 결 폐기 (잘못하면 뻔해짐)
  → 미궁 = 몬스터로 *시스템에 박힘*

폭로 결 (2층화):
  1층 (Order 1 종결): 공헌제 = 거짓 명예 + 인신공양
  2층 (시점 펜딩): 미궁 경계 도시 인간 = 몬스터 끄나풀
  → 양쪽 다 거짓. 누구도 결백하지 않음
```

#### 결정 근거 풀이

- **영웅·재앙 평행**: 본인 결 — *"인간-영웅 처럼 몬스터도 그렇게 2종이 들어가서 대비"*. 카타스테리스모스 ↔ 멸절 대비.
- **무리/재앙 어휘**: 본인 결 — *"네메아의 사자는 재앙인데 이리같은건 그냥 무리의 일부"*. 이름 박힌 큰 자(재앙) vs 떼(무리).
- **재앙 처치 = 영웅 등극 메커니즘**: 운명 전투 = 재앙 처치 = 별 박힘 = 카타스테리스모스 작동.
- **팩션 결**: 본인 결 — *"스타크래프트 같은 팩션 결"*. 미궁 = 저그 결 (싸고 많고 약함).
- **인간 vs 무리**: 본인 결 — *"인간쪽이 수는 적지만 정예, 무리쪽이 수는 많지만 개별 능력은 약함"*. 차별 = hp + 수.
- **미궁 = 몬스터**: 본인 결 — *"미궁 애들이 몬스터가 되도 되지 않나"*. 표층 결로 박음. 폭로는 다른 자리에서 (공헌제·끄나풀).

#### 펜딩

- hp 잠정 시드 (팩션별 + 등급별)
- 비용 결 (편성 부활?)
- 팩션별 능력 차별 디테일
- 미궁 몬스터 시각·외형
- 2층 폭로 시점 (어느 Order에서?)
- 재앙 처치 = 덕목 부여 메커니즘 디테일
- 인간/무리 수 비율 잠정 시드

```yaml

  카드가 행동을 가짐

공통 행동 (모든 직업·종족):
  공격 (1칸)
  방어 (1칸)

직업 / 종족:

  미궁 팩션 = "종족" (또는 다른 어휘 — 펜딩)
    행동 결 동일. 어휘만 다름.

행동 선언 시점 (결 ㅈ):
  매 라운드 시작 시 각 카드 행동 선언

타겟 시스템 (잠정):
  거리 = 근접/원거리
  배치 = 자동 (직업/종족 종속)
  타겟 = 직업별 제약
    근접 행동 = 자기 전열 → 적 전열

  이동 = 없거나 자동

  공격 점수 합 - 방어 점수 합 = 피해
  hp 깎임
```

#### 결정 근거 풀이

- **면 = 계산기**: 본인 결 — *"캐릭터의 행동... 카드락... 주사위 구성면은 그걸 계산하게만 해주는 거"*. 큰 결의 자리.
- **행동 카드락**: 카드 = 인물 = 행동. 직업이 행동 풀을 결정.
- **공통 행동 = 1칸짜리**: 본인 결 — *"공통 행동은 공격/방어(칸 1개짜리)"*. 큰 행동(2칸)은 직업 고유 자리.
- **거리·타겟**: 본인 결 — *"이동은 없거나 자동, 타겟 지정 정도는 괜찮다"*. 최소 거리 결.
- **무리 = 직업과 동일 형식**: 본인 결 — *"이 직업과 행동은 무리 쪽도 동일하게 가져가 보자, 물론 개별 직업은 두겠지만 무리쪽은 종족이나 다른 걸로"*.

- 직업/종족별 고유 행동 풀

### 묶음 4 — 변주·덕목 시스템 (큰 그림 박힘)

```yaml
변주 ≠ 덕목 (분리, 결 2):
  변주 = 카드 풀의 결 (작가 결로 짠 한 회차의 카드 묶음)
  덕목 = 덕목 주사위 (별개 풀)

변주 = 카드 풀 결 (결 X):
  변주 = 가능세계 = 같은 인물의 다른 인격이 짠 카드 풀
  Order 1 변주 = 용맹 / 지혜 / 광명
  첫 회차 = 용맹 고정. 광명 = 1·2 클리어 시 해금
  명명: "서자, 테오도라 — 용맹"

덕목 풀:
  변주와 별개 어휘 풀
  그리스 4주덕 결 가능 (지혜/용기/절제/정의 등)
  광명 변주에서만 해금되는 덕목 = 펜딩

덕목 획득 (결 R):
  운명 전투 클리어 (재앙 처치) 시 보장 1개
  사건/우연 카드도 분기로 획득 가능
  메시지 결: "[용기] 주사위를 획득했다"
  플레이버 텍스트 X

덕목 보유:
  회차 누적, 다음 회차 초기화 (결 D)
  상한 = 펜딩

덕목 효과:
  덕목 주사위 = 별 면 보유
  별 = ⚔로 작동 + 추가 굴림 (체이닝)
  체이닝 = 영웅이 영웅다워 보이는 자리
  덕목별 별 효과 차별 = 펜딩 (b vs c 결)
  체이닝 상한 = 펜딩
```

#### 결정 근거 풀이

- **변주 ≠ 덕목**: 본인 결 — *"변주는 변주 덕목은 덕목이야 로그라이크니까"*. 카드 풀 결과 덕목 결을 분리.
- **덕목 = 별개 풀**: 그리스 4주덕 같은 결 가능. 변주(인격)와 다른 자리.
- **회차 누적/초기화**: 로그라이크 결.
- **체이닝 = 영웅의 표현**: 본인 결 — *"체이닝 경험. 영웅이 영웅다워보이길 바라는 거"*. 5-5 폐기된 ★ 체이닝 결을 *명성 결*로 부활.

#### 펜딩

- 덕목 어휘 풀 (그리스 4주덕? 다른 결?)
- 광명 해금 덕목
- 덕목 보유 상한
- 덕목별 별 효과 차별 (b vs c)
- 체이닝 상한
- 사건/우연 카드 덕목 획득 결 디테일
