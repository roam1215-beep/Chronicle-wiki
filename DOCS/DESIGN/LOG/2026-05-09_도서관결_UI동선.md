## 진척도 시각화 (2·3번)

```yaml
공간 분위기 결:
  어둠/램프 결로 박힘
  진척도 게이지 X — 공간 자체가 진척 시각화
  
첫 진입 결:
  너무 어둡지 않은 *어둑한* 자리
  램프 작은 불빛
  책상 + 활성 책 (테오도라) 처음부터 보임
  어두운 자리 = 책상 너머 자리 (책꽂이 / 다른 책들 / 소품)

진척 단계:
  Order 1개 클리어 = 1단계 박힘
  램프 불 세짐. 어둠 물러남. 묻혀 있던 자리들 드러남
  
  단계 0 (첫 진입): 책상 + 활성 책 보임
  단계 N (진행):    책꽂이 일부 / 다른 인물의 책 드러남
  단계 max:         도서관 환하게 박힘 (시리즈 클리어)

정합:
  - 카타스테리스모스: 별이 박힐수록 밤하늘 밝아지는 결
  - 사서 프레임: 기록 쌓이는 결 = 빛 누적되는 결
  - 미궁 = 어둠: 폭로될수록 빛 박히는 결
  - 게이지·% 시각화 X — 사서 톤 정합 (5-8 LOG 결 그대로)

근거:
  - 본인 결: "처음은 너무 어둡지 않은. 램프 불이 더 세지는 느낌"
  - 5-8 LOG 결: "진척도 안 보여줌. 시스템이 기억. 사후 발견"과 정합
```

## UI 결 (4·5·7번) — KFM 차용

```yaml
KFM 결:
  중심: 호버/선택된 책 표지 (한 책만 박힘)
  옆 (오른쪽): 메뉴 + 항목 목록 (텍스트)
  소품: 책상 결 (깃펜 / 잉크병 / 소품들)
  분위기: 어두움 + 따뜻한 책상 자리
  
  상호작용:
    메뉴 항목 호버 → 중심 책이 그 항목의 책으로 전환
    중심 책 클릭 → 책 펼침 (다음 자리)

Chronicle 결로 정합:
  중심: 활성 책 (현재 진행 중 또는 디폴트 = 테오도라)
  옆: 메뉴
    - [이야기]      ← 인물 목록 진입
    - [이어하기]   (활성 시)
    - [기록]       (완료 책들 — 정사)
    - [설정]
    - [종료]
  
  [이야기] 클릭 → 인물 목록 자리:
    중심: 호버된 인물의 책
    옆: 해금된 인물 이름 목록 (테오도라 / [기타 미해금이면 안 보임])
    호버 → 책 전환
    클릭 → 책 펼침 (인물 페이지)

미해금 결:
  안 보임 (책구조.md 5-7 결 유지)
  어둠에 묻힘 = 자리 자체가 안 보임
  해금 시 = 빛이 닿음 = 책이 드러남

활성 책 결:
  첫 회차:    테오도라 책 (디폴트)
  진행 중:    마지막 본 인물 책
  [이어하기] 결과 정합 — 활성 책 = 진행 중 책
```
