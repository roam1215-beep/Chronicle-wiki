## 1. 전투 결산 결의 큰 정정

### 격돌 결 = 하스스톤 전장식 흡수

```yaml
폐기:
  ✗ 박힌 면 × 공격력 = 공격 점수 (다이시 테일즈식 결산 폐기)
  ✗ 박힌 면 × 방어력 = 방어 점수
  ✗ 졸전 결 (×0.5)
  ✗ 변형 결 (×1.5 어휘만 — 실제 변형은 행동 종류로 정정)

새 결:
  공격력 = 상대 hp 직격 (하스스톤 전장식)
  체력 = 인물 고유 (정해진 결, 변동 X)
  방어력 능력치 = 폐기 → 방어도/보호막 두 자리로 분리

본인 결:
  "체력은 정해져 있어. 날씨대에 따라 출력(주로 공격력 부분)이 달라지는 것 같아"
  "하스스톤식이 맞는 것 같아. 동시 전투 하는 것도 그렇고, 굳이 따지고 보면 전장식이 맞겠네"
```

### 동시 결산 = 거울속 기억 모드 결

```yaml
양 진영 동시 굴림
양 진영 동시 결산 (페이즈 결로)

페이즈 1 (보호·축복·저주):  진영별 결산 (우리 → 적)
페이즈 2 (사격):              동시 결산 (양쪽 다 사망 가능)
페이즈 3 (격돌):              동시 결산 (좌→우는 자기 진영 안)

본인 결:
  "동시 결산은 거울속 뭐시기 모드처럼 가는게 좋아보이고"
  "라운드의 결과는 각각이 미리 한 선언의 결과를 확인 받는 것에 가까워"
```

### 격돌 결산 자리

```yaml
공격 대상 = 적 좌측만 (모든 우리 전사가 같은 자리)
좌→우 순서 = 자기 진영 안에서만 (양 진영은 동시)
적 좌측 사망 시 = 다음 좌측으로 자연 이동
```

## 2. 주사위 결의 큰 정정

### 굴림 결산 = 면별 3단계

```yaml
별 면:                         통상 행동 1번 (스탯대로)
자기 시간대 면 + 자기 라운드:  대성공 1번 (행동 변형)
자기 시간대 면 + 반대 라운드:  통상 행동 1번 (case 2, 깡)
반대 시간대 면:                 실패
  격돌 직업 (전사·수호자):  수동 격돌 (자기 스탯 자동 반응)
  원거리·사제 (사냥꾼·사제): 행동 X

우선순위: 대성공 > 통상 > 실패 (개별 주사위마다 적용)

본인 결:
  "핵심은 자기 시간대 면 일치가 대성공, 별은 통상 성공, 나머지는 실패야"
  "별은 통상 행동을 하긴 하는거야"
  "실패면 원거리나 사제는 아무것도 안하고 공격은 자기 스탯대로 패시브하게 반응해"
```

### 주사위 수 = 등급 + 행동 횟수

```yaml
필멸 1개 / 반신 2개 / 신성 3개 / 번외 4+개

주사위 ×N개의 결:
  - 행동 ×N번 (각 주사위가 독립 행동, 발더스 결: 공격 횟수 늘어남)
  - 가호 수와 정합 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
  - 대성공 확률에 영향

각 주사위 = 독립 결과:
  하나가 실패 = 대기
  하나가 대성공 = 그것은 대성공
  같은 행동 ×N번 반복 (대상은 같은 자리)

본인 결:
  "주사위가 행동 수도 결정하게 해보자. 발더스게이트에서 행동 회수 늘어난 것과 같아"
  "각 주사위 = 각 행동의 결과"
  "행동 여러번은 같은 행동을 한다고 보면 되고"

자기 굴림이 자기 피해 ×N되는 자리 X:
  본인 행동 횟수 = 자기 능동 결 (자기 굴림)
  본인 피격 횟수 = 적의 능동 결 (적의 굴림)
  → 격돌 동시 결산이지만 자기 굴림 ×N → 자기 피해 ×N 정합 X
```

## 3. 4축 결 정립

```yaml
진영 (3종): 지상 / 미궁 / 경계
종족 (2종): 인간 / 무리
태생 (4종): 한낮 / 여명 / 황혼 / 심야
위계 (4종): 인간 / 영웅 / 무리 / 재앙
등급 (4종): 필멸 / 반신 / 신성 / 번외 (내부 결, 게임 노출 X)

조합:
  지상 + 인간 + 한낮 태생 + (인간↔영웅)
  경계 + 인간 + 여명 태생 + (인간↔영웅)
  경계 + 무리 + 황혼 태생 + (무리↔재앙)
  미궁 + 무리 + 심야 태생 + (무리↔재앙)

직업: 자유 (4축 무관, 모든 조합 가능)

태생의 결:
  한낮 = 지상 정통 (낮)
  여명 = 경계 인간 (낮으로 가는 결)
  황혼 = 경계 무리 (밤으로 가는 결)
  심야 = 미궁 정통 (밤)

  → 시간 속성의 비유 그 자체
  → 본인 결: "경계는 인간인데 지상에 속하지 못한자,
            무리인데 밤에 미궁에 속하지 못한자야.
            여명과 황혼 둘다 낮도 밤도 섞여있는거잖아"

시간대 결 = 3종 (낮/경계/밤) 유지 (태생과 별도)
주사위 면 결 = 6면 그대로 (태생 영향 X)
```

### 변동 시점

```yaml
위계 (Order 클리어 시):
  인간 → 영웅 / 무리 → 재앙
  카타스테리스모스 결 (신성 X → 신적 결로 승천)
  게임 노출: 인물 카드 위계 어휘만

등급 (챕터 클리어 시):
  필멸 → 반신 → 신성 → 번외
  의지 +1 + 가호 +1 (한 박자에)
  게임 노출 X (가호 결로 체감)

태생 = 변동 X (등극 시도 자기 결 유지)
```

### 가호 유형 = 태생 정합

### 가호 영역 (광역)

```yaml
- 기본 스탯 +N (시작 시)
- 대성공 시 스탯 +N
- 버프 (라운드·열·공격·피격 기반)
  · 라운드 기반: 첫 라운드 +α, 라운드 진행마다 +α
  · 열 기반: 소속 열에 따라 +α
  · 공격·피격 기반: 맞을 때마다·때릴 때마다 +α
- (작가 결로 더 박힐 자리)

본인 결:
  "대성공 시에 스탯 오르는건 가호의 정말 일부 영역이고,
   기본 스탯을 올려주거나 버프를 주거나 여러가지를 할 수 있는걸로
   영역을 더 넓게 확장하고"
```

### 가호 어휘 예시 (임시, 실제는 작가 결)

```yaml
한낮:   생명력 +N (방어 결)
심야:   공격력 +N (공세 결)

황혼:   생명력 더 + 공격력 조금 (방어 기울)

→ 어휘 자리만. 실제 가호 콘텐츠 = 펜딩 (작가 결)
```

## 10. 폐기 자리 통째

```yaml

  ✗ 행동 풀의 변형 결 어휘 (대성공 = 1 라운드만 발동)

정정:
  - 격돌식 = 하스스톤 결 (공격력 직격)
  - 사냥꾼 = 열 기준 거리, 자기 피해 X

새 박음:
  - 4축 결 (진영·종족·태생·위계·등급)
  - 격파·수호·저격·축성 (직업별 대성공 변형)
```
