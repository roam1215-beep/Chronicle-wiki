    이번 라운드 속도 = 시간대 +2 + 인물 속도 2 + 인도(속도) 2×1 = 6

## 사거리 결 박음 (5종)

```yaml
근접:           1열 → 적 1열만
원거리:         1열 또는 2열 → 적 1·2열 선택 (1명만)
광역-세로:      1열 적 모두 타격
광역-가로:      1·2열 적 1명씩 (2명 타격)
광역-전체:      1·2열 적 모두 타격

직업 ↔ 사거리 결 (기본):
  전사:    근접
  수호자:  근접
  용병:    위치 종속 (1열 = 근접 / 2열 = 원거리)
  사냥꾼:  원거리
  사제:    공격 X (방어 결만)

광역 결: 인물 카드에 박힘 (영웅·재앙 자리)
  결의 결: 필살기·패턴 결 (펜딩 — 무거운 덩어리)
  무리·인간 = 기본 광역 X
```

            호메로스 결 정합 (사제의 결이 영웅에게 임함)

미궁 종족 어휘: 직업 어휘 일단 사용 (사냥꾼/용병/전사/수호자/사제)
              어휘 정정 = 펜딩 (CON-4)

## 5 패러미터 + 행동/인도 주사위 수 정정

```yaml
5 패러미터 = 인물별:
  공격력 / 방어력 / 생명력 / 속도 / 신성력 (어휘 그대로 — 임시)

행동 주사위 수 = 인물별 (5 패러미터와 다른 층위):
  결: 신과 무관한 개인 존재의 역량/그릇
  명칭 = 펜딩 (더 좋은 결 못 찾음)
  무리도 행동 결 많을 수 있음 (등급 결 X — 인물별)

인도 주사위 수 = 인물별:
  영웅·재앙만 (인간·무리 = 0)
  보유 자체 = 등급 결 / 수치 = 인물별

→ 등급 = *신성 보유 여부*만 결정
→ 5 패러미터·행동·인도 = 인물별 결로 박힘
→ 결의 결 = 자유 조합 (느린 사냥꾼 / 빠른 사제 / 행동 큰 무리 등)
```

챕터 클리어 결 정정:
  옛 결: 챕터 클리어 = 덕목 박힘
  새 결: 챕터 클리어 = 신성 주사위 *획득 계기*
        덕목 = 변동 X (살아내는 결)
        신성 주사위 = 챕터 진행 결로 누적

→ 두 결 분리:
  덕목 (변동 X) = 살아내는 결
  신성 주사위 (누적 결) = 챕터 진행 결로 박힘

변주 ↔ 덕목 결 정합 (Order 1):
  용맹한 테오도라 → 용기 살아냄
  지혜로운 테오도라 → 지혜 살아냄
  빛나는 테오도라 → 정의 살아냄
  절제 = 다른 Order 영웅 자리 (시리즈 결, 펜딩)

변주 표기:
  "용맹한" / "지혜로운" / "빛나는" — 유지
  덕목 어휘와 분리 (변주 = 인격 어휘 / 덕목 = 그리스 4주덕)
