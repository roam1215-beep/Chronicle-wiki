## L3 병종 패시브 1:1

```yaml
민병:  없음
보병:  굳건 — 라운드 시작 시 🛡합 +1   ← 신규 (방진 자리 대체)
창병:  반격 — 피해 받으면 ⚔ 추가 (라운드당 1회)
궁병:  선제 — 라운드 시작 전 ⚔ 1발 사전 굴림
기병:  쇄도 — ★ 발생 시 추가 ⚔ +1
용병:  자유선택 — 위 4개 중 1개

근거:
  - 방진 폐기 → 보병 패시브 자리가 비어 있었음
  - "굳건" 명칭: 굳건한 특성과 음운 충돌 가능성 있으나 의미 분리
    (특성 = Named 보유, 패시브 = 병종 본질)
  - 5병종 + 용병 = 6 카드 타입에 4 패시브 + 없음 + 자유선택 = 6 매핑
```
