# 2026-03-04 업적 시스템 설계 세션

## 결정 사항

### 1. 업적 2풀 체계

- 기존 "테오도라 전용 3종 택1" → A/B 2풀 체계로 전면 재설계
- A풀 = 미덕 (테오도라 전용, Chapter 전환 랜덤 부여)
- B풀 = 악덕 (적/아군 Named 공통, 처음부터 보유)
- 풀 침범 불가. 분리 근거 = 미덕/악덕 서사 기반

### 2. A풀 — 미덕 5종

| 미덕 | 효과 |
|------|------|
| 용감한 | 아군 주사위 1개 ⚔ 카드락 |
| 충직한 | 아군 주사위 1개 🛡 카드락 |
| 고결한 | 아군 주사위 1개 ★ 카드락 (Named/기사만, 가중치 낮음) |
| 지혜로운 | 리롤+1 |
| 자비로운 | 매 라운드 아군 전체 ✕ 결과 1개 → ⚔/🛡 랜덤(50:50) (가중치 낮음) |

### 3. B풀 — 악덕 6종

| 악덕 | 효과 |
|------|------|
| 잔혹한 | 격돌 ⚔+1 확정 |
| 고집센 | 격돌 🛡+1 확정 |
| 겁이 많은 | 선제 🛡+1, 피격 흡수 시 영구 소멸 |
| 교활한 | 선제 ⚔+1 (궁병 Named만) |
| 집요한 | 부상 1회 완전 무효 |
| 위선적인 | 매 라운드 해당 진영 전체 ✕ 결과 1개 → ⚔/🛡 랜덤(50:50) |

### 4. 카드락 정의 확정

- 굴리기 전 주사위 1개 결과 확정. 면 구성 무관
- 선제 불가. 아군 전체 대상 (유닛 선택은 플레이어)
- 전투 진입 시 자동 적용 (스텝2 버프와 분리)
- ★ 카드락 재굴림은 자유 (첫 결과만 ★ 확정)

### 5. B풀 상호작용 확정

- 쇄도 대상 아님
- 결사 🛡→⚔ 전환 적용
- 부상 무관
- 전황 적용 (기습/역습 시 R2부터)
- [자비로운]/[위선적인] 타이밍: 스텝4 후 스텝5 전
- [집요한]: 부상 자체를 막음 (면 전환 없음, 선제 포함)
- [겁이 많은]: 선제 피격 1발만 방어

### 6. 보유 규칙

- Named 1기당 1개 (추후 복수 확장, 최대 3개)
- 테오도라 실질 최대 2개 (Chapter 전환 2회)
- 적 Named 최대 3개 가능

### 7. 플레이버 구조

- "형용사 + 이름" 표기
- A풀 미덕 톤: 용감한 테오도라, 지혜로운 테오도라
- B풀 악덕 톤: 잔혹한 마르쿠스, 집요한 발레리안

### 8. 폐기

- 기존 업적 카드 "3종 택1" 구조
- 버프 카드락 (스텝2) → 카드락은 업적 전용
- A풀 "행동형/상시형" 분리 근거 → 미덕/악덕 서사 기반으로 변경
