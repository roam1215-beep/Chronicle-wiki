# 세션 로그: 2026-02-26 스테이지 구조 설계

## 세션 목표

P0 안건 ②③ 미션 구조 + 진행 구조 구체화. 추상화 단위 재정비.

## 결정 사항

### 추상화 단위 재정비 — "재미있는 지점까지만 추상화"

- 문제: 7개 시스템(맵이동, 시야, 날씨, 지형, 징집병, 보급, 위업)이 세계관 기반 나열이지 플레이어 판단 최소 단위 아님
- 방향: DD처럼 "쳐내고 압축". 브리핑 + 스테이지로 이분화
- DD 마을 = HO 브리핑: 명령 수령(주어짐) + 접근 계획(핵심 판단) + 보급 선택(계획 뒷받침)
- 핵심: 명령은 하달(선택 아님). "어떻게"가 플레이어 몫 = "제약 안의 자유"

### 런-챕터-스테이지 3층 구조 확정

| 단위 | 대응 | 내용 |
|------|------|------|
| 런 | SlS 런 | 내전 종식 (테오도라의 전쟁 전체) |
| 챕터 | SlS 막 | 군사 작전 (수성전, 공성전 등) |
| 스테이지 | SlS 노드 | 작전의 한 국면 (동쪽 수비, 추격 등) |

- 스테이지 모듈화: 테이블에서 조합. 콘텐츠 10개로 조합 수십 개 챕터 생성
- 병력 이월: Homeworld식. 이전 스테이지 생존 병력 = 다음 출발 전력

### 지형 시스템 — 타일(바닥) + 지물(배치) 분리

- 타일 3종: 고지(✕→⚔), 엄폐(✕→🛡), 평지(전환불가). 전투 스텝5에만 영향
- 지물: 망루, 사다리, 함정, 바리케이드 등. 기존 7스텝 숫자만 변경
- 새 규칙 없음. 전부 기존 스텝에 숫자 더하거나 빼기만

| 지물 | 효과 | 7스텝 위치 |
|------|------|-----------|
| 고지(망루, 성벽 위) | 궁병 선제 +1기 | 스텝1 선제 |
| 엄폐(숲, 바리케이드) | ✕→🛡 전환 | 스텝5 지형전환 |
| 좁은 길목 | 동시 교전 주사위 상한 | 주사위 수 제한 |
| 함정 | 전투 시작 전 적 1기 제거 | 스텝1 이전 |

### 챕터 트위스트 + 스테이지 특수규칙 이중 구조

- 챕터 트위스트: 챕터 전체에 규칙 1개 (예: "겨울 — 첫 턴 밤 강제")
- 스테이지 특수규칙: SC2식 스테이지당 고유 규칙 1개
- 매 런마다 트위스트 조합이 달라 같은 수성전도 다른 판

### 미선택 구역 자동 판정

- 플레이어가 선택한 스테이지 진행 중, 나머지 구역은 자동 시뮬
- 소비 턴 수만큼 1d6 굴림: 1~2 패(적+2), 3~4 교착(적+1/아군+1), 5~6 승(아군+1)
- 빨리 끝내면 굴림 횟수 감소 = 빨리 끝내는 게 유리
- 스테이지 간 시간축 연결

### 적 이월 (Ardennes Assault식)

- 이전 스테이지 도주적 → 다음 스테이지 합류
- 미선택 구역 패배분도 다음에 추가

### 스테이지 진행 방식 — 중앙 카드 덱 기반 (방향 확정, 구조 미확정)

- 이동·사건·전투가 전부 중앙 카드 덱에서 나옴
- 매 턴 3장 제시 → 1장 선택
- BoR "쫓아오는 카드" 구조 참고 — 미선택 카드가 남아서 슬롯 좁히는 긴장감
- 카드 처리 방식(버림/잔류/강제발동) 미확정 → 다음 세션 핵심 안건

### 부대 분할 불가 확정

- 한 덩어리. 안 쪼갬.

### 이동 시스템 불필요 확정

- 이동이 가져가는 변수(배분, 우선순위, 조우, 시간)를 카드 덱이 흡수

### Banner of Ruin 실패 분석 → 회피 방법

| BoR 문제 | HO 회피 방법 |
|----------|-------------|
| 선택지 간 차이 작음 | 방패 2장 vs 깃발 2장 = 전투 경험 확 다르게 |
| 선택이 이후에 영향 안 줌 | 퍼마데스 + 보급 이월불가 + 적 이월 |
| 이벤트가 전투와 분리 | 이벤트 = 전투 규칙 자체 변형 |
