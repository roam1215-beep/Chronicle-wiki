## 발화 순서 (4번) + 비가역 (5번)

```yaml
발화 순서:
  1번 발화 → 2번 발화 → 거부 카드 (뒷면 상태로 버림 패. 영구 미공개)
  거부 카드 = Type 본 후라도 발화 X. "전해지지 않은 이야기"

비가역:
  1차 [선택]: 카드를 정하면 취소 X
  2차 [거부]: 카드를 정하면 취소 X
  "취소하고 3장 다 보기" = 불가
  한 번 정하면 그대로 굴러감

대가 구조:
  1번 (선택) = Type 알고 겪음
  거부 카드  = Type 알고 버림 (영구 미공개)
  2번 (감내) = Type 모르고 받음 ← 선택·거부의 대가

근거:
  - 본인 결: "처음 선택한 집기 카드는 적어도 힌트는 알고 겪게되지만,
              남은 카드는 모르고 받는거야 어떤 타입인지"
  - 비가역 = 정찰의 무게. 사서 프레임 정합
    "역사는 되돌릴 수 없음. 정찰의 무게가 사서의 무게"
  - 발화 순서 = 1번/2번이 페이즈 본체. 거부는 페이즈를 구성하지 않음
```
