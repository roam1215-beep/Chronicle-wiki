## 주요 결정

### 게임 플로우

- 로비 씬 확정: [새 게임] [이어하기] [기록] [설정]
- 런 슬롯 1개, 덮어쓰기 경고
- [기록] = 완료 오더 카드(성적표) 열람

### 카드 타입 체계

- 인물(Figure) / 사건(Event) / 기록(Record) 3타입 확정
- 인물 카드만 이번 세션에서 상세 설계

### Named/Nameless 등급

- "영웅"이라는 시작 등급 폐기 → "기록되지 않은 자들의 영웅전" 주제와 충돌
- Nameless(무명) → Named(유명) → Hero(영웅) 3단계
- 이름 유무가 곧 등급. 카드 표면에 등급 태그 없음
- Named만 ★ 면 + 부상 생존

### 테오도라 재설계

- 보병 계열 → 기사 (창병 계열) 변경
- 면: ★⚔🛡🛡✕✕ (구: ⚔🛡🛡★✕✕)
- 전환 방향: 🛡→⚔ (구: ⚔→🛡)
- 돌파 패시브 → 반격 패시브로 변경

### 패시브 시스템 전면 도입

- 모든 인물 카드에 패시브 슬롯 3개
- 초기 비어있음. 테오도라/앰버 포함
- 스테이지 운명 달성 보상으로 획득
- 기존 전환 메카닉(보병전환.md)이 패시브로 흡수
- 병종별: 궁병=선제 공격, 창병=반격, 보병=전열 교대, 민병=없음

### T2/정예화 폐기

- Named 전환이 T2 역할 대체
- 정예화(2스테이지 생존) 폐기 → Named 승급으로 대체
