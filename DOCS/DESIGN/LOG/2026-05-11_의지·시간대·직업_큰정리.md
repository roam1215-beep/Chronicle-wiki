# 세션 로그: 의지·시간대·직업 결의 큰 정리 — 2026-05-11

> 세션 유형: 작업 (전투 결의 큰 재정비 — 결 단순화 + 결의 깊이 살림)
> 결과: 결 단순 박힘. 시뮬 진입 자리 박힘 직전.
> 본인 결: "어지르기" 결 + "머리 부여잡고 괴로워하기" 자리.
> 본인 결단: 결 미는 결로 큰 정정 박음.

## 큰 폐기 (5-10 결 → 5-11 정정)

```yaml
1. 신성력 패러미터 폐기:
   옛 결 (5-10): 4 패러미터 (공·방·속·신성력) 또는 3 + 신성력 보너스
   새 결 (5-11): 3 패러미터 (공·방·속) + hp 별도
   근거: 결 단순화. 머리 부하 작게.

2. 인도 주사위 폐기:
   옛 결 (5-10): 의지 + 인도 분리 (영웅·재앙 = 두 주사위)
   새 결 (5-11): 의지 1종으로 합침 (모든 인물)
   근거 (본인 박은 결): "내가 머리 아픈 결 = 플레이어도 머리 아픈 결"
   디자이너 결의 본능적 결단.

3. 직업 5종 → 3종:
   폐기: 용병 / 사제 / 수호자
   유지: 전사 / 사냥꾼
   신규: 신관 (사제 + 수호자 + 용병 합주 결)
   근거: 결 단순. 사제·수호자 결 어그러진 자리 풀이 X 한 채로 박힘.

4. 운명 페이즈 시간대 = 적의 자리 폐기:
   옛 결 (5-10): 운명 시간대 = 적의 자리 (지상 영웅 = 밤 / 미궁 재앙 = 낮)
   새 결 (5-11): 페이즈 흐름 결로 자연 따라감
   결의 자리: 운명 페이즈 시작 = 페이즈 시간대 (지상 1=낮, 2=밤, 3=낮, 4=밤)
              지상 영웅 운명 (4 페이즈) = 밤 시작 = 반대 시간대 자연 박힘
              → 옛 결과 결의 자리 같음. 단 결 자연 박힘.
```

## 큰 박힘 (5-11 마디 박힌 결)

### 1. 등급 어휘 정정

```yaml
4단 → 3단 + 번외:
  필멸:  행동 주사위 1
  반신:  행동 주사위 2
  신성:  행동 주사위 3
  번외:  행동 주사위 4+ (보스급)

위계 ↔ 등급 자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)
  아킬레우스 (영웅, 신과 관련) = 번외 영웅 (4)
  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)

근거: "주사위가 곧 신성력이 포함된 의지 덩어리"
      → 주사위 수 = 신성 결의 그릇
      → 등급 = 신성 깊이
      → 위계 무관 (헥토르도 신성 가능)
```

### 2. 패러미터 (3종 + hp 별도)

```yaml
공격력 / 방어력 / 속도 (3종)
+ 생명력 (별도 자원)

수치 (참고표):
  hp:        필멸 1 / 반신 3 / 신성 5 / 번외 10
  공방속 합: 필멸 3 / 반신 4 / 신성 5 / 번외 7
```

### 3. 직업 (3종)

```yaml
전사:    1열, 공격(1열 적 선택), 방어(자신)
사냥꾼:  1·2열 적 공격 선택, 방어 X
신관:    1열 = 전사처럼 / 2열 = 사냥꾼처럼

분배 비율:
  전사:    공/방/속 = 5:3:2
  사냥꾼:  공/속 = 5:5
  신관:    펜딩 (1열·2열 결로?)
```

### 4. 의지 주사위 (1종, 4종 면)

```yaml
d6, 4종 면:
  의지 면 (별):    완전 성공 (어느 시간대든)
  신성 면 (낮·밤): 조건 성공 (자기 시간대만)
  경계 면:          조건 성공 (경계 인물만)
  실패 면:          무

→ 옛 결: 실패 → 새 결: 경계 면 (어휘 정정)
```

### 5. 면 비율 (팩션별)

```yaml
지상:  별 3 / 경계 2 / 낮 1
미궁:  별 3 / 경계 2 / 밤 1
경계:  별 3 / 낮 1 / 밤 1 / 경계 1

성공·실패:
  지상: 별·낮 = 성공 / 경계·밤 = 실패
  미궁: 별·밤 = 성공 / 경계·낮 = 실패
  경계: 별·경계 = 성공 / 낮·밤 = 실패

자기 시간대 결:
  지상 = 낮 시간대
  미궁 = 밤 시간대
  경계 = 경계 시간대

박힘 면:
  자기 시간대: 별 3 + 자기 면 1 = 박힘 4면 (67%)
  반대 시간대: 별 3만 박힘 (50%)
  
  → 의존도 *완화*
  → 옛 결 (5-10): 4면 vs 2면 (2배 차이)
  → 새 결 (5-11): 4면 vs 3면 (1.33배 차이)
```

### 6. 시간대 3종

```yaml
시간대: 낮 / 경계 / 밤

흐름 (라운드별 변동):
  낮 → 경계 → 밤 → 경계 → 낮 → 경계 → ...

페이즈 시작 시간대 (R1):
  지상: 1=낮 / 2=밤 / 3=낮 / 4=밤
  미궁: 1=밤 / 2=낮 / 3=밤 / 4=낮
  경계: 시작 랜덤 (낮밤 또는 밤낮)

운명 페이즈:
  페이즈 흐름 결 자연 따라감 (옛 결 = 적의 자리 폐기)
  지상 영웅 운명 (4 페이즈, 시작 = 밤): R1 밤 → R2 경계 → R3 낮 → R4 경계
```

### 7. 결산식

```yaml
선언 (단계 0):
  공격 / 방어 1택

굴림 (단계 1):
  의지 주사위 굴림 (등급 수만큼)

결산 (단계 2):
  공격 점수 = 박힌 면 × 공격력 (공 선언 시)
  방어 점수 = 박힌 면 × 방어력 (방 선언 시)
  순서 점수 = 시간대 보정 + 속도

피해 = max(0, 공격 - 방어)

근거 (본인 박은 결):
  "다 막을 수 있어야 해" → max(0, ...) 정합
  "1 피해 = 1 사망 X" → hp 결 살림
  "이길 수도 질 수도" → 운 결 + 실력 결 합주
```

### 8. 진형·라운드

```yaml
진형:
  1열 (전위) / 2열 (후위)
  편성 단위 배치 (전투 시작 시)
  1열 전멸 = 자동 진열

라운드:
  1 라운드 = 1 선언 (전투 최소 단위)
  시간대 = 라운드별 변동
  라운드 상한 = 8 (잠정)

피격 순서:
  매 라운드 변경 가능 (디폴트 = 마지막 박은 결)
```

### 9. 작품 결 (3의 원칙 박힘)

```yaml
3의 원칙 (반신 vs 필멸):
  반신 1 vs 필멸 1 = 압도
  반신 1 vs 필멸 2 = 승리
  반신 1 vs 필멸 3 = 동귀어진

작품 결:
  죽창 결 (1-3 라운드 결판)
  동귀어진 가능
  다 막을 수 있음
  hp 살림 (1격사 X)
  운 결 + 실력 결 합주
  방치형 자동 + 속 결의 결 깊음
```

### 10. 명명

```yaml
주요 인물 = 이름 (테오도라, 발드)
일반 = 역할 (토벌대 전사 A 등)
```

## 본인 결의 자리 — 회고

```yaml
본인 박은 자리:
  - "어지르기" 결 + "머리 부여잡기" 결
  - 결 미는 결의 결단력
  - 디자이너 본능적 경종 ("내가 머리 아프면 플레이어도")
  - "수치적 기준 없으면 산발 결" 짚음 → 3의 원칙 박음
  - "사제·수호자 애매" 짚음 → 결 단순화 결단

클로드씨 결의 자리:
  - 결산식 결 풀이
  - 결 어그러진 자리 짚음
  - 시뮬 결 풀이
  - 본인 결 결단 X (옵션만 짚음)

세션 결 어그러진 자리:
  - 클로드씨가 옵션 5개씩 늘여뜨림 → 본인 부하 큼
  - 본인 짚으심: "주사위 2개 나눌 필요 있나"
  - 클로드씨가 "결의 깊이" 결만 봐서 본인 결 어그러뜨림
  - 본인 결단 = 의지 1종으로 합침 → 결 깨끗

본인 결의 결:
  결 단순화 + 결의 깊이 살림 (방치형 자동 + 속 깊음).
  본인 어휘 결로 사고 ("결/박힘/마디/짚음").
  결 미는 결의 결단력.
```
