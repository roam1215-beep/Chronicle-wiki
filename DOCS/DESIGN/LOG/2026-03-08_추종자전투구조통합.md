## 수행 작업

### 추종자 시스템 전면 재설계 (v0.4 → v1.0)

- 기존 14종 → **24종** 체계로 확장
- 상한 8명 → **10명**으로 변경
- ND 4종(돌격대장/수비대장/참모/부관) → **Named 특성으로 이관** (카드락 3종은 추가 폐기)
- 병종 패시브 트윅 추종자 3종 신설: **장궁병(NL)/장창병(ND)/중보병(ND)**
- 유틸 추종자 신설: **정찰병(NL)/감시자(NL)/떠돌이(NL)/상인(ND)**
- 충원 추종자 신설: **패잔병 3종(NL, 궁/보/창)**
- 명칭 대량 변경: 민병대장→지원병, 기병대장→기마병, 사냥꾼→장궁병, 파이크병→장창병, 파수꾼→중보병 등

### 전투 구조 변경

- **Named 부상 회복:** 장 전환 시 → 전투 종료 시
- **장궁병 선제 우선 사격:** 동시 사격 → 아군 선사격/적 후사격
- **방패병 선제 🛡:** 선제 전용 방패 메카닉 확정
- **A풀 카드락 3종(용감한/충직한/고결한) + 자비로운 폐기.** [지혜로운](리롤+1)만 잔존

### 구성면 체계 도입

- 초기면 / 현재면 구분 정의
- 부상 = 현재면 기준 유효면→✕, 전투 종료 시 현재면 복원

### 엣지 케이스 전수 확정

- 선제 페이즈: 장궁병+태그 조합, 방패병+겁이 많은 순서, ★ 체이닝 차단 범위
- 격돌 페이즈: 정찰병+밤 리롤, 중보병/장창병+결사/난전 무력화
- 전과 페이즈: 장창병 정산 순서, 🛡 상쇄 순서, 이월 제한
- 비전투: 감시자+배신+NL0, 교관+사기저하 면 충돌, 떠돌이 타이밍
- [결별]/해고: 면 변환 잔류 vs 지속 효과 즉시 꺼짐 구분
