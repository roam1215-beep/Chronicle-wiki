## 큰 결정 (이전 5-9 코어 위에 추가)

```yaml
1. 인물 카드 = 5 패러미터:
   공격력:    행동 칼 면 / 가호 공 결산 곱셈치 (인물별)
   방어력:    행동 방패 면 / 가호 방 결산 곱셈치 (인물별)
   생명력:    hp (인물별)
   속도:      순서 점수 (행동/결과 무관, 시간대 보정과 합산)
   신성력:    신성 주사위 가호 결산 곱셈치 (영웅·재앙만 의미)

2. 별도 속성:
   행동 주사위 수: int (모두 보유. 무리 = 1)
   신성 주사위 수: int (영웅·재앙만)

3. 가호 결산 정정:
   옛 결: 가호 1개 = 인물 공·방 수치
   새 결: 가호 1개 = *신성력*만큼
   → 행동 결산과 가호 결산이 *완전 분리*
   → 인간의 결 (공·방) ≠ 신의 결 (신성력)

4. 순서 시스템:
   순서 점수 = 시간대 보정 + 인물 속도
   → 행동 굴림 무관. 신성 무관 (정정).
   → 매 라운드 일정 (페이즈 안에서)
   → "느린 거인 / 빠른 자객" 결 살아남

5. 시간대 보정:
   지상 인물 + 낮 페이즈 = +2
   지상 인물 + 밤 페이즈 = 0
   미궁 인물 + 낮 페이즈 = 0
   미궁 인물 + 밤 페이즈 = +2
   경계 인물 = +1 (낮·밤 무관)

6. 동점 처리:
   같은 점수 = 같은 진영 (자연 결로) = 동시 행동
   3단 우선순위 (옛 결: 점수 → 시간대 → 선언) 폐기

7. 피해 받는 순서:
   선언 = 매 라운드 시작 (전열 → 후열)
   적 공격 = 선언 1번부터 hp 깎임
   앞 인물 hp 0 = 다음 인물 노출
   → 매 라운드 *판단 자리*
   → 본인이 짚으신 "유저 선언이 의미 있어야"의 자리

8. 결 a (트로이 결) 박힘:
   적 사망 시 적 결산 무화
   → 빠른 쪽이 결정적 자리
   → 호메로스 결과 살짝 절충 (단 결의 결 깊음)

9. 변동성 결:
   변동성 = 큼. 단 *예측 가능 범주*.
   페이즈 + 5 패러미터로 기댓값 추정 가능
   매 굴림 = 변동
   → 본인 박은 "예측 가능 변동성" 결 정합

10. 주사위 수 잠정 시드:
    N대N 전체 (적+아군 합산):
    최소: 2개 / 최대: 60개 (잠정)
```

## 결의 결 — 5축 분리

```yaml
공격력:        위력 결 (공)
방어력:        위력 결 (방)
생명력:        견딤 결
속도:          순서 결 (템포)
신성력:        가호 결의 결 (신의 깊이)

→ 5축 모두 *분리*됨
→ 결의 결 풍부:
  - 빠른 거인 (공 큼, 속도 작음, 방 작음)
  - 느린 자객 (공 작음, 속도 큼, 방 작음)
  - 강한 영웅 (다 큼)
  - 약한 무리 (다 작음)
  - 견디는 사제 (방 큼, hp 큼, 속도 작음)
  - 신성 깊은 영웅 (신성력 큼)
  
→ 인물 차별화 = 5축 조합으로 완전 결의 결 박힘
```

## 결산 결 정리

```yaml
한 라운드:

1. 순서 점수 계산:
   각 인물 = 시간대 보정 + 속도
   = 라운드 시작 시 정해짐 (행동·신성 무관)

2. 굴림 (자동):
   모두 행동 주사위 굴림
   영웅·재앙은 신성 주사위도 굴림
   별 면 = 신성 재굴림 (무한)

3. 가호 박힘:
   신성 면 = 페이즈 시간대 + 자기 신앙 일치 시
   별 면 = 무조건 가호

4. 가호 선언 (영웅·재앙):
   동시 선언 (정보 비대칭 보존)
   공 또는 방 1택

5. 결산:
   공격 점수 = 행동 칼 × 공격력 + 가호(공) × 신성력
   방어 점수 = 행동 방패 × 방어력 + 가호(방) × 신성력
   실패 = 무

6. 순서대로 행동:
   순서 점수 큰 쪽 먼저
   동점 = 같은 진영 = 동시 행동
   적 사망 시 = 적 결산 무화 (트로이 결)

7. 피해 입력:
   피해 = max(0, 자기 공격 - 상대 방어)
   상대 선언 1번부터 hp 깎임
   앞 인물 hp 0 = 다음 인물 노출
```

## 한 라운드 시뮬 (책상 결)

```yaml
편성: 테오도라 (영웅) + 인간 전사 + 인간 사냥꾼 vs 미궁 무리 전사 3명

낮 페이즈

테오도라 (지상 영웅, 공 3 / 방 2 / hp 10 / 속도 3 / 신성력 2):
  행동 주사위 1, 신성 주사위 1
  순서 점수 = 시간대 +2 + 속도 3 = 5
  
인간 전사 (지상, 공 2 / 방 2 / hp 5 / 속도 1 / 신성력 0):
  행동 주사위 2, 신성 주사위 0
  순서 점수 = +2 + 1 = 3
  
인간 사냥꾼 (지상, 공 3 / 방 1 / hp 4 / 속도 4 / 신성력 0):
  행동 주사위 2, 신성 주사위 0
  순서 점수 = +2 + 4 = 6

미궁 무리 전사 A (공 1 / 방 1 / hp 3 / 속도 1 / 신성력 0):
  행동 주사위 1, 신성 주사위 0
  순서 점수 = 0 + 1 = 1

미궁 무리 전사 B, C: 같은 결 = 1

순서:
  사냥꾼(6) → 테오도라(5) → 전사(3) → 무리 A,B,C 동시(1)
  
플레이어 선언 (피해 받는 순서):
  전열 = 인간 전사 (공·방 균형, hp 5)
  중열 = 테오도라
  후열 = 사냥꾼

굴림:
  사냥꾼 행동 [칼/실패] = 칼 1
  테오도라 행동 [칼] = 칼 1
            신성 [낮] = 가호 1 (낮 페이즈 + 지상 신앙)
            플레이어 선언: "공으로"
  전사 행동 [칼/방패] = 칼 1, 방패 1
  무리 A 행동 [칼] = 칼 1
  무리 B 행동 [방패] = 방패 1
  무리 C 행동 [실패] = 0

결산:
  사냥꾼 공격: 칼 1 × 공 3 = 3
  테오도라 공격: 칼 1 × 공 3 + 가호 1 × 신성력 2 = 3 + 2 = 5
  전사 공격: 칼 1 × 공 2 = 2 / 방어: 방패 1 × 방 2 = 2
  무리 A 공격: 1 × 1 = 1
  무리 B 방어: 1 × 1 = 1
  무리 C: 0

순서 행동:
  사냥꾼 먼저: 무리 A에 3 피해 (선언 1번 = A) → 무리 A hp 0 → 사망
              사망한 A 결산 무화 (트로이 결)
  테오도라: 무리 B에 5 피해 (선언 2번) → 무리 B hp 0 → 사망 + 무화
  전사: 무리 C에 2 피해 → 무리 C hp 1
  무리 C 살아남: 공격 0 → 무 (실패면)

→ 한 라운드 = 무리 A, B 사망 / C 빈사
→ 다음 라운드 = 무리 C가 인간 전사 향해 공격
→ 트로이 결 깊이 (강한 자가 먼저 휘둘러 적이 *말을 못하고* 죽음)
```
