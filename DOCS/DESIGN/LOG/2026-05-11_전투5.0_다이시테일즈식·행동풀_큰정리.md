# 세션 로그: 전투 5.0 — 다이시 테일즈식 + 행동 풀 — 2026-05-11

> 세션 유형: 작업 (전투 4.0 → 5.0 큰 재정비 — 결 본질 풀이 + 다이시 테일즈식 흡수)
> 결과: 결 골격 박힘. 다음 마디 시뮬 진입 자리.
> 본인 결: 머리 아파하면서도 결의 본질 직관으로 짚어낸 자리. 무의식 결로 다이시 테일즈 가져온 결.
> 본인 결단: 게임 본질 결로 박음 — "주어진 자원 안에서 잘 골라서 경영. 과부하 X, 가위바위보보다는 풀 큼."

## 게임 본질 결 (본인 박은 자리)

```yaml
핵심 = 자원 경영의 결
  주어진 자원: 한정 (의지 주사위)
  풀: 가위바위보보다 큼 (다이시 테일즈식)
  부담: 과부하 X (단순함과 복잡함의 사이)
  손해: 퍼마데스로 누적 (회복 X)
  실력: 풀 안에서 잘 고르는 결

플레이어 결의 자리 (본인 박은 결):
  외부:  편성·선언 단계 (큰 결 박는 자리)
  내부:  굴림 결과만 봄 (운의 결)
  "외부 선언 단계에 하는 걸 지켜보고 결과가 나오는 걸 보지만, 그 사이에 운도 중요"
```

작품 결의 *방치형 자동 + 속 깊음* 결의 자리가 시스템 결로도 살아남.

## 큰 폐기 (5-11 옛 결 → 5-11+ 정정)

### 1. 직업 3종 → 4종 (신관 폐기, 수호자·사제 부활)

```yaml
옛 결 (5-11): 직업 3종 (전사 / 사냥꾼 / 신관)
              신관 = 사제 + 수호자 + 용병 합주 결, 1·2열 자유

새 결 (5-11+): 직업 4종 (전사 / 수호자 / 사냥꾼 / 사제)
              모두 위치 고정 (1열 또는 2열)
              5-10에 폐기한 사제·수호자 결의 부활

근거 (본인 박은 결):
  - 신관 위치 자유 = 너무 좋음 + 결정 부담 큼
  - "신관을 신관 전사와 사제로 나누고 열 배치 곤란함을 풀어버리면 어떨까"
  - 약화 X로 4개로 갈리는 결 — 트레이드 오프 = 위치 + 행동 풀
```

### 2. 공·방 1택 결 폐기 → 다이시 테일즈식

```yaml
옛 결 (5-11): 단계 0에서 공·방 1택 선언
              굴림 결과 모르고 박는 결 (맹목)

새 결 (5-11+): 면 종류가 행동 결정
              별 면 = 기본 행동 (직업별 자기 행동)
              시간대 면 = 변형 행동
              반대 시간대 면 = 졸전 (작게 박힘)

근거 (본인 박은 결):
  - "공격 방어 고르게 하기가 무의식적으로 별로 의미 없다는 걸 눈치챔"
  - "행동의 수나 질도 능력"
  - 다이시 테일즈가 본인 마지막 인디 게임, 가져가고 싶은 결
  - "굴려서 나온 면으로 뭔가를 한다는 게 좋아 보임"
```

### 3. 매 라운드 행동 선택 → 작은 AI + 영웅 결단만

```yaml
옛 결 (잠정): 매 라운드 굴림 후 행동·대상 선택
              결정 부담 큼

새 결 (5-11+): 인물 카드 = 작은 AI
              필멸: 카드 우선순위로 자동
              영웅·반신: 라운드당 1회 결단 (선언 시점 작은 판단)
              굴림 → 자동 발동 → 결산

근거 (본인 박은 결):
  - "매번 주사위 눈 보고 뭐할지 누구한테 할지 고르는 건 좀 그렇잖아"
  - "그건 주고 싶은 경험이 아니야"
  - "작은 AI + 내가 선언 시점에 작은 판단을 할 수 있음"
  - 작품 결인 방치형 자동과 정합
```

### 4. 실패 면 어휘 폐기 (실질 변동 X)

```yaml
옛 결 (5-11): 면 4종 = 의지·신성·경계·실패

새 결 (5-11+): 면 4종 = 의지·신성·경계만
              실패 면 어휘 폐기

근거 (본인 짚은 결):

  - 실제 면 비율엔 실패 면 없음 (4종으로 6면 구성)
  - "실패"는 면 종류가 아니라 결산 상태
```

## 큰 박힘 (5-11+ 마디 박힌 결)

### 1. 직업 4종 + 행동 5종

```yaml
직업 (위치 고정):
  전사:        1열 / 격돌 결
  수호자:      1열 / 격돌 + 보호 결
  사냥꾼:      2열 / 사격 결 (방 0)
  사제:        2열 / 계통별 행동 풀 (팩션 결)

행동 5종 (편의상 분류):
  1. 격돌:    전열에서 직접 전투. 받기·주기 양방향
  2. 사격:    원거리, 일방적 피해
  3. 보호:    방어 능력 지원 (본인·아군)
  4. 축복:    아군 버프
  5. 저주:    적 디버프 (그리스 신화 결: 변신 포함)

상태 이상:
  모든 직업이 잠재적으로 보유
  예: 측면 강타 (별 1, 데미지 X, 기절 부여)
  "단순히 막는다 때린다가 아니게 될 수 있어"
```

### 2. 사제 계통 = 팩션 결

```yaml
지상 사제 (인격신, 보호의 결):
  보호 + 축복 중심

미궁 사제 (자연신, 저주의 결):
  저주 + 사격 중심
  그리스 결: 사람을 사슴으로 만들거나 죽이는 신적 행위
  
경계 사제: X (사제·수호자 둘 다 X)

근거 (본인 박은 결):
  - "그리스 신화 보면 갑자기 사람을 사슴으로 만들거나 죽인다거나"
  - 그리스 결: 신마다 다른 능력 (아폴론·데메테르·헤카테 등)
  - 사제 = 계통이라는 차원 하나 더
```

### 3. 경계 = 전사 + 사냥꾼만 (희미함 결)

```yaml
경계 직업: 전사 / 사냥꾼만
경계 결의 결: 균형 + 희미함

근거 (본인 박은 결):
  - "본디 숫자가 적어 양쪽에 속하지 않은 인물"
  - "균형 잡힌 쪽에 가까운 사냥꾼과 전사가 많음"
  - "희미한 거 자체가 팩션의 개성"

게임 결 합주:
  지상 = 낮 강함 / 미궁 = 밤 강함 / 경계 = *항상 그저 그런 결*
  → 시스템과 작품 결 정합
```

### 4. 행동 풀 (면 → 행동 결)

```yaml
면 종류가 행동을 결정:
  별 면:        직업 기본 행동 (격돌·사격·보호 등)
  자기 시간대 면: 변형 행동 또는 추가 효과
  반대 시간대 면: 졸전 (작게 박힘, 결산 X 아님)

예 (인간 전사 잠정):
  별 → 격돌 (기본 결)
  낮 → 강타 또는 다른 변형 (펜딩)
  밤 → 졸전 (안 싸우는 건 아니지만 퍼포먼스 낮음)

전사 행동 풀 (잠정):
  돌진 (별 1):      1열 1명 공격
  수비 (별 1):      자기 방어
  측면 강타 (별 1): 1열 1명, 데미지 X, 기절 부여
  강타 (낮 1):      변형 공격 (지상)
  야습 (밤 1):      변형 공격 + 디버프 (미궁)
```

### 5. 결산 결 — 매끄러움 + 메타 분리

```yaml
스탯: 공·방 분리 + hp + 의지 주사위 수 + 보호막
결산: 박힌 면 수 × 결산치
  격돌 = 공·방 양쪽 살아남 (한쪽 선택 X)
  사격 = 공만
  수비 = 방만
  
변형 결 (잠정):
  강타: 결산치 × 1.5
  졸전: 결산치 × 0.5
  
예 (필멸 인간 전사, 공1/방1, 의지 주사위 1):
  별 면 박힘:  격돌, 공=1×1=1, 방=1×1=1
  낮 면 박힘:  강타, 공=1×1×1.5=1.5 (반올림 2)
  밤 면 박힘:  졸전, 공=1×1×0.5=0.5 (반올림 1)

예 (반신 영웅 전사, 공2/방1, 의지 주사위 2개, 자기 시간대):
  굴림 별×2: 격돌, 공=2×2=4
  굴림 별+낮: 강타, 공=2×2×1.5=6 (필살 결)
  굴림 별+밤: 격돌 1면+졸전 1면, 공=1×2+1×2×0.5=3

근거 (본인 박은 결):
  - "지금의 매끄러운 감각을 유지하면서 동시에 메타 분리"
  - "롤토체스 같기도 하고, 전열 강타 전사덱 같은 메타"
```

### 6. 영웅·반신 결단 결의 결

```yaml
필멸: 결정 자리 X. 인물 카드 우선순위로 자동.
영웅·반신: 라운드당 1회 결단 (행동 + 대상 결)

결단 결의 결 (잠정):
  본인 박음: "결정할 게 좀 더 많으면 좋겠고"
  - 행동 1택 (보유 행동 중)
  - 대상 1택 (1열 적 중)
  - 면 안 박히면 자동 결로 발동 또는 발동 X (펜딩)

호메로스 결 살아남:
  결단 박음 → 굴림 → 결산
  인간이 결 박고 신(굴림)이 응답
```

```yaml
보호막:
  층위:   hp 위 별도 그릇
  결산:   max(0, 공격 - (방어 + 보호막)) → hp 직격

출처:    사건 카드 / 장비(가호) / 사제 부여
보유:    모든 인물
```
