# 2026-04-08 색 매칭·킵 기획 세션

## 세션 유형
문서화 세션 (기획 결정 → 위키 반영 + 커밋)

## 안건
전투 시스템에 색상 체계 + 킵 시스템 도입. 아르멜로 다이스 배틀과의 차별화. 이벤트/성장/리플레이 깊이 확보.

## 결정 사항

### 1. 색상 체계 도입
- 3색: 빨강(⚔), 파랑(🛡), 검정(✕) + 무색
- DLC: 금색(★). 비전투: 초록(별도 체계)
- Named/Nameless 모두 색 보유 가능
- 적은 대부분 무색, 보스/운명급만 유색 → 레벨 디자인으로 밸런스 통제

### 2. 색 매칭 규칙
- 색과 결과면 일치 시에만 매칭 (빨강+⚔, 파랑+🛡, 검정+✕)
- 매 라운드 리셋
- 매칭 2개마다 킵 1개 생산
- 밀집: 유닛 수만큼 카운트
- 타이밍: 스텝5(방진/반격) 후 = 신규 스텝6

### 3. 킵 시스템
- 킵 칼(확정 ⚔) / 킵 방패(확정 🛡) / 킵 리롤(추가 리롤)
- 킵 상한 = 챕터 수 (Ch1=1, Ch2=2, Ch3=3), 총합
- 상한 초과분 즉시 사용
- 스텝6에서 즉시 사용 or 킵 선택 (수동)
- 킵은 전투 간·라운드 간 유지
- 다음 전투: 7스텝 전에 확정 면으로 배치 / 킵 리롤은 스텝3에서 합산
- 킵 = 무색, 주사위 아님. 쇄도/리롤/방진/결사 대상 아님. 스텝7 합산만

### 4. 7스텝 재구성
- 구 스텝2(예약석) 삭제
- 신규: 1선제→2전체굴림→3리롤→4쇄도→5방진반격→6색매칭→7전과
- 수동 3→4개 (킵 사용 여부 추가)

### 5. 인물카드 스키마
- color 필드 추가: red/blue/black/colorless
