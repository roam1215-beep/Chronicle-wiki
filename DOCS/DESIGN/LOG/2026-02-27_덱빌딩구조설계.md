## 핵심 돌파

### 1. "겪은 것이 덱이 된다" — 카드의 네 얼굴

카드 1장이 이야기이고, 단기 자원(토큰)이고, 장기 재료(유물)이고, 기록이다. 분리된 시스템이 아니라 하나의 객체가 층위에 따라 역할을 바꾸는 구조.

설계 원칙: "새 시스템이 필요하면 카드에 얼굴을 하나 더 붙여라. 시스템을 하나 더 만들지 마라."

### 2. 토큰 3종 — 사건이 전투 자원이 된다

사건 타입(전투/탐색/외교)에 따라 소모 토큰 지급. 전투 7스텝 내 해당 스텝에서 소모. 이월 가능.

- 전투 토큰 → 스텝2 (작전카드 대체)
- 탐색 토큰 → 스텝4 (리롤 추가)
- 외교 토큰 → 스테이지 카드 페이즈

### 3. 유물 압축 — 5층 카드 대응

겪은 사건 → 스테이지 카드(유물) → 챕터 카드 → 오더 카드(성적표). 묶임이지 희생이 아님. 종이가 쌓여 역사가 된다.

### 4. 헤라클레스 방식 칭호

추상 덕목(용맹 Lv3)이 아니라 구체 사건(부서진 다리의 테오도라). 군공이 곧 이름. 사서 프레임과 정합.

### 5. 야영/보급 폐기

- 보급(붕대/방패/검/깃발) → 토큰 3종으로 대체.
- 야영 → 운명 달성 결산으로 대체 (회복+유물+면교체).
- 별도 페이즈 삭제. 겪는 것이 보급이고, 달성이 야영.

### 6. 면 교체 — 슬더스식 카드 제거의 번역

✕ 면 교체 = 실패면 제거. ⚔/🛡/✕ 중 하나로 랜덤 교체. 확정 강화가 아니라 가능성이 바뀌는 것. 주사위 게임 문법.

### 7. 브리핑 재정의

맵 반쪽 공개 → 막사 전술회의. 모형이 올라간 탁상. 스테이지 분위기 암시 수준.

## 검토한 무른 점과 결정

| 무른 점 | 판단 |
|---------|------|
| 10장 패시브 주렁주렁 | 낱개 효과 없음 → 토큰(단일 소모)으로 해결 |
| 스테이지 내 성장 체감 0 | 토큰이 쌓이는 게 보이므로 해결 |
| 스텝2 빔 | 토큰 소모로 채움 |
| 스테이지-전투 분리 | 토큰이 연결 |
| 빌드 제어력 | 분기 선택이 토큰 타입 결정 + 유물 성향 결정 |
| 소멸 딜레마 | 토큰은 소모, 카드는 재료로 남음 |
| 게이지 짜침 | 진척도 안 보여줌. 시스템이 기억. 사후 발견. |
| 패시브 덕목 짜침 | 헤라클레스 방식으로 대체 |
| 카드 수지 (초반 전투) | 턴 수 축소(5턴) + 초기 패 검토 |
| 메타 계산 침투 | 장르적 특성으로 수용. 반복 학습은 합격. |
