# 태그 체계 재편 초안

> **작성일:** 2026-03-07 · **상태:** 초안 (기획 세션 산출물) · **문서화 세션에서 위키 반영 필요**
> **이전 버전:** 태그규칙.md v1.0 (라벨 17개 + 태그 4종 → 라벨 28개) → 본 문서로 대체

---

## 1. 구조 개요

기존 라벨-태그 2레이어를 **배틀/이벤트/포츈 3분류 + 운명 전용 보상**으로 전면 재편.

```
태그 31종
 ├─ 배틀 태그 (8종) — 전투 규칙 수정
 ├─ 이벤트 태그 (10종) — 부대 상태 변경
 ├─ 포츈-배틀 (5종) — 우연 전투
 ├─ 포츈-이벤트 (6종) — 우연 이벤트 (기존 태그의 진폭 확대)
 └─ 운명 전용 보상 (2종) — 운명 전투 승리 보상
```

### 핵심 변경

| 이전 | 이후 |
|------|------|
| 라벨 = 카드 효과, 태그 = 주사위 면 변환 | 통합. 전부 "태그" |
| 라벨 6분류 17개 + 태그 4종 | 배틀 8 + 이벤트 10 + 포츈 11 + 운명 2 = 31종 |
| 라벨이 유저에게 노출 | **태그 유저 미노출. 서술로만 유추** |
| 비전투 라벨 전부 긍정 | 모든 분류에 긍정/부정/양면 혼재 |
| 카드 유형별 라벨 분류 고정 | 태그 조합 자유. 카드 유형별 슬롯 규칙으로 제약 |

## 2. 배틀 태그 (8종) — 전투 규칙 수정

전투 카드와 운명 카드에 붙음. 전투의 규칙을 바꿈.

### 전략 레이어 (4종)

| 태그 | 효과 | 성격 |
|------|------|------|
| [기습] | R1 아군만 공격 | 긍정 |
| [역습] | R1 적만 공격 | 부정 |
| [우세] | 아군 유닛 추가 (전투 한정, 전투 후 사라짐) | 긍정 |
| [열세] | 적 유닛 추가 (전투 한정, 전투 후 사라짐) | 부정 |

### 전술 레이어 (4종)

| 태그 | 효과 | 성격 |
|------|------|------|
| [봉쇄] | 전 라운드 아군만 선제 | 긍정 |
| [함정] | 전 라운드 적만 선제 | 부정 |
| [결투] | Named 1:1 판정 후 7스텝 | 양면 |
| [난전] | 선제 제외 패시브 무력화 | 양면 |

### 배틀 태그 규칙

| 규칙 | 내용 |
|------|------|
| 전투 카드 | 배틀 태그 최소 1개 필수. 전략 0~1 + 분기별 전술 1(필수) |
| 운명 카드 | 전략 1(필수) + 전술 1(필수) |
| 조합 제한 | [기습]+[역습] 금지. [우세]+[열세] 금지 |
| 전략 레벨 | 카드 레벨 (분기 공통) |
| 전술 레벨 | 분기 레벨 (분기별 다름) |

## 3. 이벤트 태그 (10종) — 부대 상태 변경

전투 카드 리절트, 사건 카드 분기에 붙음. 부대 상태를 바꿈.

### 주사위 면 변환 (6종)

| 태그 | 대상 | 효과 | 성격 |
|------|------|------|------|
| [연마] | Named | ✕ → ★10/⚔30/🛡30/✕30 판정 | 긍정 |
| [사기 진작] | Nameless | ✕ → ★10/⚔30/🛡30/✕30 판정 | 긍정 |
| [열화] | Named | ⚔/🛡 → ⚔33/🛡33/✕33 판정 (★ 제외) | 부정 |
| [사기 저하] | Nameless | ⚔/🛡 → ⚔33/🛡33/✕33 판정 (★ 제외) | 부정 |
| [단조] | Named | 열화→연마 순차 | 양면 |
| [단련] | Nameless | 사기 저하→사기 진작 순차 | 양면 |

### Named/Nameless 대칭

| 효과 | Named | Nameless |
|------|-------|----------|
| 확률적 강화 | [연마] | [사기 진작] |

| 양면 (약화→강화) | [단조] | [단련] |

### 주사위 획득/제거 (4종)

| 태그 | 효과 | 성격 |
|------|------|------|
| [징집] | 민병 2기 획득 | 긍정 |
| [모병] | 보/창/궁 중 선택 1기 획득 | 긍정 |
| [용병] | 민/보/창/궁 중 랜덤 1기 획득 | 양면 |
| [이탈] | Nameless 랜덤 1기 제거 | 부정 |

### 면 변환 공통 규칙

| 규칙 | 내용 |
|------|------|
| 발동 타이밍 | 전투 후 또는 비전투. 전투 중 없음 |
| 대상 | 유닛 1기의 면 10개 중 해당 면. 유닛 = 주사위 1개 |
| 중복 적용 | 가능. 같은 유닛에 같은 태그 여러 번 |
| ★ 체이닝 | Nameless도 Named도 동일 적용 |
| 면 추적 | 변환 후 면은 기존 면과 동일 취급 |
| 유닛 사망 | 면 추적 삭제 |

### 엣지 케이스

| 상황 | 처리 |
|------|------|
| [이탈] 발동 시 아군 NL 0 | 불발. 나머지 정상 진행 |
| 동일 태그 중복 ([연마]+[연마]) | 허용. 검수 과정에서 밸런스 확인 |

## 4. 포츈-배틀 (5종, 택 1) — 우연 전투

우연-전투 카드에만 붙음. 5종 중 1개만 선택. 모든 포츈-배틀 태그는 강제 전투를 내포.

| 레이어 | 태그 | 효과 | 성격 |
|--------|------|------|------|
| 중립 | [돌발상황] | 강제 전투 | 중립 |
| 행운 | [기습] | 강제 전투 + R1 아군만 공격 | 긍정 |
| 행운 | [회유] | 강제 전투 + 적 랜덤 NL → 아군. 디폴트 면. 전투 후 영구 유지 | 긍정 |
| 불운 | [역습] | 강제 전투 + R1 적만 공격 | 부정 |
| 불운 | [배신] | 강제 전투 + 아군 랜덤 NL → 적. 면 그대로 전환 | 부정 |

> 포츈-배틀 [기습]/[역습]은 배틀 태그 [기습]/[역습]을 참조 (동일 효과).

### 포츈-배틀 규칙

| 규칙 | 내용 |
|------|------|
| 택 1 | 5종 중 1개만. 추가 배틀 태그 없음 |
| 전술 없음 | 우연 전투에 전술 슬롯 없음. "갑자기 닥친 전투라 전술을 세울 여유 없음" |
| 전투 후 이벤트 | 이벤트 태그 1개 (성격 제약 없음. 긍정/부정 랜덤) |
| [명예] 가능 | 불운(역습/배신) 승리 시 전투 후 슬롯이 [명예]로 채워질 수 있음 |

### 엣지 케이스

| 상황 | 처리 |
|------|------|
| [배신] 발동 시 아군 NL 0 | 강제 전투 발생. 배신 효과만 불발 |
| [회유] 발동 시 적에 NL 없음 | 강제 전투 발생. 회유 효과만 불발 |
| [회유]로 적 기병 획득 | 허용. 기병 디폴트 면으로 합류. 기병 획득의 유일한 경로 (극히 희귀) |

## 7. 카드별 태그 슬롯

### 전투 카드

```
전략 0~1 (카드 레벨, 분기 공통)
분기 A: 전술 1(필수) + 전투 후 리절트 이벤트 태그 1(필수)
분기 B: 전술 1(필수) + 전투 후 리절트 이벤트 태그 1(필수)
양 분기는 전술도 리절트도 달라야 함.
이벤트 태그 단독 불가.
```

### 사건 카드

```
분기 A: 이벤트 태그 1~2개
분기 B: 이벤트 태그 1~2개
배틀 태그 불가.
동일 태그 중복 허용 (예: [연마]+[연마]).
순수 긍정/순수 부정 분기 허용.
```

### 우연-전투 카드

```
포츈-배틀 택 1 (= 전략 레이어. 강제 전투 내포)
전투 후 이벤트 태그 1개 (성격 제약 없음)
전술 슬롯 없음.
불운 승리 시 전투 후 슬롯이 [명예]로 채워질 수 있음.
```

### 우연-이벤트 카드

```
포츈-이벤트 1~2개 (즉시 발동, 분기 없음)
행운+불운 혼합 허용. [운명적 이끌림]+[결별] 금지.
```

### 운명 카드

```
전략 1(필수) + 전술 1(필수)
전투 후 보상: [이끌림] + [명예] 확정
패배 = 게임 오버
```

## 9. 설계 원칙

| 원칙 | 내용 |
|------|------|
| 태그 유저 미노출 | 유저는 서술로만 유추. 태그명/수치 비공개 |
| Named 태그로 획득/제거 불가 | Named는 전투 사망과 동료 시스템만이 경로 |
| 기병 편성/모병 불가 | [회유]로만 획득 가능 (극히 희귀) |
| 전투 카드에 이벤트 태그 단독 불가 | 배틀 태그 필수. 전투 후 슬롯에만 이벤트 태그 가능 |
| 사건 카드에 배틀 태그 불가 | 이벤트 태그만 |
| 우연-전투에 전술 없음 | 갑자기 닥친 전투라 전술을 세울 여유 없음 |
| 순수 긍정/순수 부정 허용 | 트레이드오프 강제 없음. 풀 비율로 관리 |
| 정보 태그 의도적 배제 | 정보 조작은 태그 밖. 추종자에서 극히 희귀하게만 |
| 포츈 = 기존 태그의 진폭 확대 | 새 메카닉이 아니라 기존의 상위/하위 |
| 운명 전투 패배 = 게임 오버 | 홀짝 이원화 폐기 |
| 면 교체 2개 ≈ 주사위 1개 | 밸런스 기준선 |

## 10. 폐기 사항

| 항목 | 사유 |
|------|------|
| 라벨-태그 2레이어 | 배틀/이벤트/포츈 3분류로 통합 |
| 라벨 6분류 (전략/전술/결과/비전투/우연) | 카드 유형별 분류 → 태그 역할별 분류로 전환 |
| 결과 라벨 (약탈/전리품/귀순 등) | 이벤트 태그로 흡수 |
| 비전투 라벨 (증원/합류/훈련 등) | 이벤트 태그로 흡수 |
| 우연 라벨 (복잡한 운명/탈영/호기/복병) | 포츈-배틀 + 포츈-이벤트로 재편 |
| "승리 시만 발동" 조건 | "전투 후" 발동으로 변경 (패배 = 게임오버이므로 무관) |
| 홀수=패널티/짝수=패배 이원화 | 운명 전투 패배 = 전부 게임 오버 |
| [지원군]/[포위] 명칭 | [우세]/[열세]로 변경 |
| 라벨 유저 노출 | 태그 미노출. 서술로만 유추 |

## 11. 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| [명예]의 실체 | "임의의 업적 획득"이나 업적 시스템 미확정 | 업적/성장 시스템 재설계 |
| 추종자 시스템 상세 | 런당 6명 획득 확정. 패시브/풀/역할 미설계 | 추종자 전용 세션 |
| 서사 분류 | 미확정. 스토아 팩토리 프롬프트 구축 시 귀납적 도출 | 팩토리 프롬프트 설계 |
| 운명 조건 다양성 | 미설계. 운명 24장 개별 설계 필요 | 운명 카드 설계 세션 |
| 풀 내 태그 비율 | 긍정/부정/양면 비율, 면 변환 vs 획득/제거 비율 미정 | 프로토타입 + 시뮬레이션 |
| 카드 분기 설계 가이드라인 | 양 분기 전술+리절트 다를 것. 스토아 팩토리 제약 조건 | 카드 금형 세션 |
| 기존 전투 세부 규칙 정합 | [결투] 판정, 카드락, 결사 등과 새 태그 체계 정합 필요 | 문서화 세션 |
