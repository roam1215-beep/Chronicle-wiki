# 태그 체계 재편 초안

> **작성일:** 2026-03-07 · **상태:** 초안 (기획 세션 산출물) · **문서화 세션에서 위키 반영 필요**
> **이전 버전:** 태그규칙.md v1.0 (라벨 17개 + 태그 4종) → 본 문서로 대체

## 1. 구조 개요

기존 라벨-태그 2레이어를 **배틀/이벤트/포츈 3분류 + 운명 전용 보상**으로 재편.

```
카드 = 서술 + 태그 조합 + (서사 분류: 스토아 팩토리용 메타데이터)

태그 31종:
 ├─ 배틀 태그 (8종) — 전투 규칙 수정
 ├─ 이벤트 태그 (10종) — 부대 상태 변경
 ├─ 포츈-배틀 (5종) — 우연 전투
 ├─ 포츈-이벤트 (6종) — 우연 이벤트 (기존 태그의 진폭 확대)
 └─ 운명 전용 보상 (2종) — 이끌림, 명예
```

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| 역할 분리 | 배틀 = 전투 규칙 변경, 이벤트 = 부대 상태 변경, 포츈 = 이벤트의 진폭 확대 |
| 태그 유저 미노출 | 유저는 서술로만 유추. 수치 최적화 불가 |
| 카드 유형 벽 유지 | 전투 카드에 이벤트 태그 단독 불가. 사건 카드에 배틀 태그 불가 |
| Named 보호 | Named는 태그로 획득/제거 불가 |
| 기병 보호 | 기병은 편성/모병 불가. [회유]로만 획득 가능 |
| 즉시 효과만 | 지속 효과 없음. 면 변환/유닛 변동은 영구 |
| 정보 태그 없음 | 정보 조작은 태그 체계 밖. 추종자 극히 희귀 효과로만 |

## 2. 배틀 태그 (8종) — 전투 규칙 수정

### 전략 레이어 (4종) — 카드 레벨, 분기 공통

| 태그 | 효과 | 성격 |
|------|------|------|
| [기습] | R1 아군만 공격 | 긍정 |
| [역습] | R1 적만 공격 | 부정 |
| [우세] | 아군 유닛 추가 (전투 한정, 전투 후 사라짐) | 긍정 |
| [열세] | 적 유닛 추가 (전투 한정, 전투 후 사라짐) | 부정 |

### 전술 레이어 (4종) — 분기 레벨, 분기별 다름

| 태그 | 효과 | 성격 |
|------|------|------|
| [봉쇄] | 전 라운드 아군만 선제 | 긍정 |
| [함정] | 전 라운드 적만 선제 | 부정 |
| [결투] | Named 1:1 판정 후 7스텝 | 양면 |
| [난전] | 선제 제외 패시브 전부 무력화 | 양면 |

### 조합 규칙

| 규칙 | 내용 |
|------|------|
| 전략 | 카드당 0~1개 |
| 전술 | 분기당 1개 **필수** |
| 전략 0 | 허용. 조건 없는 순수 전투. 전술만으로 전투 성격 결정 |
| 배타 | [기습]+[역습] 금지, [우세]+[열세] 금지 |

## 3. 이벤트 태그 (10종) — 부대 상태 변경

|------|------|------|------|

| 태그 | 대상 | 효과 | 성격 |
|------|------|------|------|
| [징집] | — | 민병 2기 획득 | 긍정 |
| [모병] | — | 보/창/궁 중 선택 1기 획득 | 긍정 |
| [용병] | — | 민/보/창/궁 중 랜덤 1기 획득 | 양면 |
| [이탈] | Nameless | 랜덤 1기 제거 | 부정 |

### 태그 공통 규칙

| 규칙 | 내용 |
|------|------|
| 발동 타이밍 | 전투 후 또는 비전투. 전투 중 없음 |
| 면 변환 대상 | 유닛 1기의 면 10개 중 해당 면 |
| 중복 적용 | 가능. 같은 유닛에 같은 태그 여러 번. 같은 태그 2개도 허용 |
| ★ 체이닝 | Nameless도 Named도 동일 |
| 면 추적 | 변환 후 기존 면과 동일 취급. 별도 표시 없음 |
| 유닛 사망 | 면 추적 삭제 |

### 면 변환 밸런스 기준

> 면 교체 2개 ≈ 주사위 1개분의 전력 가치.

## 4. 포츈-배틀 (5종, 택 1) — 우연 전투

| 레이어 | 태그 | 효과 | 성격 |
|--------|------|------|------|
| 중립 | [돌발상황] | 강제 전투 | 중립 |
| 행운 | [기습] | 강제 전투 + R1 아군만 공격 | 긍정 |
| 행운 | [회유] | 강제 전투 + 전투 시작 시 적 랜덤 NL → 아군. 병종 디폴트 면. 전투 후 영구 유지 | 긍정 |
| 불운 | [역습] | 강제 전투 + R1 적만 공격 | 부정 |
| 불운 | [배신] | 강제 전투 + 전투 시작 시 아군 랜덤 NL → 적 전환. 면 그대로 | 부정 |

### 규칙

| 규칙 | 내용 |
|------|------|
| 택 1 | 우연-전투 카드에 포츈-배틀 태그 1개만 |
| 전술 없음 | 우연-전투에는 전술 슬롯 없음. 갑자기 닥친 전투라 전술을 세울 여유 없음 |
| 전투 후 이벤트 | 1개. 성격 제약 없음 (긍정/부정 랜덤) |
| [명예] | 불운(역습/배신) 전투 승리 시 전투 후 슬롯이 [명예]로 채워질 수 있음. 동일 확률 |
| [기습]/[역습] 참조 | 배틀 태그 [기습]/[역습]과 동일 효과 |
| NL 0 시 | [배신]/[회유] 불발. 강제 전투만 발생 |

## 7. 카드별 태그 슬롯

### 전투 카드

```
전략 0~1 (카드 레벨, 분기 공통)
분기 A: 전술 1(필수) + 전투 후 리절트 이벤트 태그 1(필수)
분기 B: 전술 1(필수) + 전투 후 리절트 이벤트 태그 1(필수)
양 분기는 전술 또는 리절트 중 최소 하나가 달라야 함.
```

### 사건 카드

```
분기 A: 이벤트 태그 1~2개
분기 B: 이벤트 태그 1~2개
배틀 태그 불가.
동일 태그 중복 허용.
순수 긍정/순수 부정 분기 허용.
```

### 우연-전투 카드

```
포츈-배틀 택 1 (= 전략 레이어)
전투 후 이벤트 1개 (성격 제약 없음)
전술 슬롯 없음.
```

### 우연-이벤트 카드

```
포츈-이벤트 태그 1~2개
즉시 발동. 분기 없음.
행운+불운 혼합 허용.
[운명적 이끌림]+[결별] 동시 불가.
```

### 운명 카드

```
전략 1(필수) + 전술 1(필수)
전투 후 보상: [이끌림](확정) + [명예](해당 시)
패배 = 게임 오버.
```

## 8. 엣지 케이스 처리

| 상황 | 처리 |
|------|------|
| [배신] 발동 시 아군 NL 0 | 배신 불발. 강제 전투만 발생 |
| [회유] 발동 시 적에 NL 0 | 회유 불발. 강제 전투만 발생 |
| [이탈] 발동 시 아군 NL 0 | 불발 |
| [결별] 발동 시 추종자 0 | 불발 |
| [회유]로 적 기병 획득 | 허용. 기병 디폴트 면으로 영구 합류. 기병 획득의 유일한 경로 |
| 포츈-이벤트 2개 발동 순서 | 카드 기재 순서대로 순차 발동 |
| 통칙 | 해당 태그 효과만 불발, 나머지 정상 진행 |

## 9. 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 라벨을 폐기하고 태그로 통합했는가? | 기존 라벨 28개 중 메카닉 중복이 6쌍. 실질 고유 메카닉 16개. 태그+파라미터로 환원하면 중복 소멸 |
| 왜 배틀/이벤트/포츈 3분류인가? | 배틀=규칙 변경, 이벤트=상태 변경, 포츈=이벤트의 진폭 확대. 역할이 완전 분리 |
| 왜 포츈이 기존 태그의 상위/하위인가? | 새 메카닉 없이 체감 다양성을 만듦. 구현 복잡도 0 추가 |
| 왜 태그를 유저에게 안 보여주는가? | 수치 최적화 불가능하게. "서술이 더 나아 보이니까"로 고르게. 시스템이 아니라 이야기로 체험 |
| 왜 정보 태그가 없는가? | 블라인드 선택의 순도 유지. 정보가 풀리면 블라인드의 의미 소멸 |
| 왜 Named를 태그로 건드리지 않는가? | "이름의 유무"가 게임 전체 문법. 이름 있는 자가 태그 하나로 사라지면 이름의 무게가 없어짐 |
| 왜 [명예]가 불운 전투 승리에서 나오는가? | "서자부대가 인정받으려면 더 어려운 조건에서 해내야" |
| 왜 순수 긍정/부정 분기를 허용하는가? | "이번은 운이 좋았다/나빴다"의 변주. 대부분은 트레이드오프, 가끔 순수 |
| 왜 우연-전투에 전술이 없는가? | 갑자기 닥친 전투. 전술을 세울 여유가 없다 |

## 10. 폐기 사항

| 항목 | 사유 |
|------|------|
| 기존 라벨 28개 체계 | 태그 31종 체계로 대체 |
| 라벨-태그 2레이어 | 배틀/이벤트/포츈 3분류로 대체 |
| "라벨" 용어 | "태그"로 통일 |
| 결과 라벨 (약탈/전리품/귀순) | 이벤트 태그로 흡수 |
| 비전투 라벨 (증원/합류/훈련/단련) | 이벤트 태그로 흡수 |
| 우연 라벨 (복잡한 운명/탈영/호기/복병) | 포츈 태그로 재편 |
| 운명 패널티/패배 이원화 (홀수=패널티, 짝수=패배) | 운명 전투 패배 = 전부 게임 오버 |
| "승리 시" 발동 조건 용어 | "전투 후" 발동으로 변경 |
| 사건 카드에서 추종자 획득 | [이끌림]은 운명/우연에서만 |
| 행운에 행운, 불운에 불운 겹치기 강제 | 폐기. 성격 제약 없음 |
