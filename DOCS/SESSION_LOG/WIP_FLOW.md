## 1. 최상위 구조 — 5층

```
인물 (Character) ── 테오도라 (+미래 인물 DLC)
  └─ 대명령 (Order) ── 런 1회. 시나리오. 순차 해금.
       └─ 작전 (Chapter) ── 트위스트 1개. 보급 1회.
            └─ 국면 (Stage) ── 중앙 카드 덱 진행.
                 └─ 전투 (Battle) ── 7스텝 주사위. 안정된 엔진.
```

### 각 층위의 역할

| 층위 | 플레이어 체감 | 게임 역할 |
|------|-------------|----------|
| 인물 | 선택 화면 | 영웅 2명 + 사이드킥 + 병종 풀 결정. DLC 단위. |
| Order | 시나리오 선택 | 런 전체 목표. 연대기(신참→성기사). 챕터 수/구성 결정. |
| Chapter | 작전 수행 | 트위스트 1개 + 보급 선택 + 스테이지 6개(분기-수렴). |
| Stage | 임무 수행 | 특수규칙 1개 + 중앙 카드 덱 + 전투 복수 회. |
| Battle | 전투 | 7스텝 주사위. 카드 덱/트위스트가 조건만 바꿈. 규칙 불변. |

## 2. 전체 플로우차트

```
[타이틀]
  │
  ▼
[인물 선택] ── 테오도라 (+ 미래 인물 잠금)
  │
  ▼
[Order 선택] ── 순차 해금. 클리어/업적 표시.
  │              Order = 테오도라와 앰버의 연대기.
  │              예: Order 1 신참자 / Order 2 생존자 / Order 3 성기사
  │              DLC로 Order 추가 가능. 인물 추가도 가능.
  │
  ▼
[Order 시작 화면] ── 3분할
  │
  │  ┌──────────┐  ┌──────────┐  ┌──────────┐
  │  │ THEODORA │  │  AMBER   │  │ ████████ │
  │  │ 영웅/보병 │  │ 영웅/궁병 │  │→ T1 랜덤 │
  │  │ 패시브    │  │ 패시브    │  │  (뒤집기) │
  │  │ (긁기)   │  │ (긁기)   │  │          │
  │  │ 주사위면  │  │ 주사위면  │  │ 주사위면  │
  │  └──────────┘  └──────────┘  └──────────┘
  │
  │  유저 행동:
  │    1. 테오도라 패시브 긁기
  │    2. 앰버 패시브 긁기
  │    3. T1 카드 뒤집기 (랜덤, 선택권 없음)
  │    4. [출정]
  │
  │  대명령 공개: Order 시작 전 또는 동시.
  │    "서자 기사 테오도라에게 명한다. ___하라."
  │
  │  초기 상태:
  │    부대: 3개 (테오도라 + 앰버 + T1 랜덤)
  │    부대 상한: 10 (사실상 도달 안 함)
  │    보급: 0장 (챕터 시작 시 선택)
  │
  ▼
[Chapter 시작]
  │
  ├─ 챕터 트위스트 공개
  │    - 챕터 전체에 규칙 1개 선언. 변하지 않음.
  │    - 카드 덱/보급 쪽만 건드림. 전투 규칙(7스텝)은 불변.
  │    - 예: "포위 — 압박 카드 비율 증가"
  │    - 예: "보급선 차단 — 기회 카드 삭제"
  │    - 예: "고립 — 보급 선택 N-1장"
  │
  ├─ 보급 선택 (챕터당 1회)
  │    - 트위스트 확인 후 판단.
  │    - 챕터 전체분 N장 선택. 이월 불가.
  │    - 보급 카드: 검(⚔+1), 방패(🛡+1), 깃발(리롤+1), 붕대(부상치유)
  │    - 군마: 재정의 필요 (이동 삭제로 효과 없음)
  │    - 스테이지 안 병참 카드로 간이 보급 가능 (럭키)
  │
  ▼
[챕터 내 스테이지 흐름] ── 분기-수렴 고정 구조

      ┌─ [1] ─┐
      │       ├─ [3] ─┬─ [4] ─┐
      └─ [2] ─┘       │       ├─ [6]
                      └─ [5] ─┘

  - 1,2: 택1. 선택한 쪽 플레이, 반대쪽 자동판정.
  - 3: 수렴. 양쪽 다 거침.
  - 4,5: 택1. 동일 패턴.
  - 6: 수렴. 챕터 마무리.
  - 분기 구조는 일단 고정. 챕터마다 달라질 수 있음(PENDING).

  자동판정 (반대쪽):
  - 플레이어가 스테이지 플레이하는 동안 반대쪽 자동 굴림.
  - 소비턴 × 1d6: 1~2 패(적+2) / 3~4 교착(적+1,아군+1) / 5~6 승(아군+1)
  - 빨리 끝내면 굴림 횟수 감소 = 빨리 끝내는 게 유리.
  - 자동판정 끝난 뒤 반대쪽도 직접 플레이 (피해 이어받기).

  적 이월 (Ardennes식):
  - 이전 스테이지 도주적 → 다음 스테이지 합류.
  - 미선택 구역 패배분도 추가.
  │
  ▼
[브리핑] ── 매 스테이지 진입 전
  │
  │  구성:
  │    1. 작전지도 (LoL 챔프셀렉트식 맵 UI)
  │       - 플레이 공간 아님. 정보 공간.
  │       - 섹터 간 관계(분기/수렴) 시각화.
  │       - 상태 표시: ● 선택가능 / ◉ 진행중 / ◆ 완료 / ✕ 함락
  │       - 자동판정 구역 실시간 상태 변화.
  │
  │    2. 명령서 (텍스트)
  │       - 적 정보 힌트
  │       - 지형 힌트
  │       - 추천 보급 구성
  │       - 하급 지휘관에게 공개되는 정보는 원래 많지 않음.
  │
  │    3. 스테이지 택1 (분기 구간에서)
  │
  │  ※ 보급 선택은 여기서 안 함 (챕터 시작 시 완료).
  │
  ▼
[Stage 진입]
  │
  ├─ 스테이지 특수규칙 공개 (SC2식, 1개)
  │
  ├─ 중앙 카드 덱 진행
  │    - 매 턴 3장 제시 → 1장 선택
  │    - 미선택 카드: 잔류 (슬롯에 남음, 상한 없음)
  │    - 카드 타입:
  │        압박 카드: 잔류 + 카운트다운. 0 되면 강제발동.
  │        기회 카드: 잔류. 카운트다운 없음.
  │    - 강제발동은 시스템 규칙이 아닌 카드 속성.
  │      개연성 있는 상황에서만. (예: 공성부대 ③②①→성문 돌파)
  │
  │  카드 카테고리 (검토중, 미확정):
  │    - 교전: 주사위 전투 돌입
  │    - 정찰: 정보 획득. 다음 교전 조건에 영향.
  │    - 병참: 자원 획득/손실.
  │    - 돌발: 예측 못한 상황. 조건부 전투 or 전투 조건 변경.
  │
  │  부대 충원:
  │    - 스테이지 보상 or 중앙 덱 극저확률.
  │    - 럭키. 의도적으로 귀하게.
  │
  ├─ 전투 발생 시 → Battle (7스텝)
  │    - 전투 규칙은 불변. 트위스트/특수규칙이 건드리지 않음.
  │    - 기존 위키 문서 그대로 유효:
  │      COMBAT-STRUCT-001 (전투구조 v0.3)
  │      COMBAT-DICE-001 (다이스규칙 v0.5)
  │
  ├─ 승리/패배 조건 충족 → 스테이지 종료
  │
  ▼
[스테이지 종료 → 다음 브리핑 or 챕터 종료]
  │
  ▼
[야영?] ── 미정
  │  - 위치: 챕터 끝? 스테이지 사이?
  │  - 역할: 유닛 강화, 주사위 면 교체, 영입 등
  │
  ▼
[다음 Chapter] ── 병력 이월, 새 트위스트
  │
  ...반복...
  │
  ▼
[Order 완수 / 실패 — 엔딩]
  │
  ▼
[Order 선택 화면 복귀]
```

## 3. 핵심 설계 원칙 (이번 세션 확정)

| 원칙 | 내용 |
|------|------|
| 전투 엔진 불변 | 7스텝 + 4종 주사위면. 트위스트/특수규칙이 전투 규칙을 건드리지 않음. |
| 변주는 전투 밖 | 어떤 전투를, 언제, 어떤 조건에서, 뭘 들고 들어가느냐가 게임. |
| Order = DLC 단위 | 인물 + Order 체인으로 콘텐츠 확장. 비즈니스 구조 내장. |
| 보급은 귀하다 | 챕터당 1회. 스테이지 내 간이 보급은 럭키. |
| 부대는 귀하다 | 3개 시작. 충원은 극저확률. 잃으면 퍼마데스. |
| 브리핑 맵 = UI | 플레이 공간 아님. 정보 공간. LoL 챔프셀렉트식. |
| 분기-수렴 고정 | 1,2→3→4,5→6. 챕터마다 변경 가능성은 열어둠. |

## 5. 레퍼런스 대응

| Holy Orders 요소 | 레퍼런스 | 차이점 |
|-----------------|----------|--------|
| 인물 연대기 + Order | Banner Saga 3부작 | BS는 일직선. HO는 Order 선택. |
