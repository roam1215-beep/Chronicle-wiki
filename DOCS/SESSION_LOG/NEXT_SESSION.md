# 다음 세션 안건

## 우선순위 P0

### 1. ③ 큰 선택 — 명령 변경 메커니즘
- 방향: 스테이지 중간에 명령이 변경되어 "이미 커밋한 계획 vs 바뀐 현실" 판단
- 미해결: 매번 유연책이 정답이 되는 지배 전략 문제
- 필요: 명령 변경이 오지 않는 스테이지도 있어야 함. 변경 여부를 읽는 단서 설계.

### 2. 미션 구조 구체화
- 현재: 방어/도달/섬멸 — 너무 뻔함
- 방향: 명령은 명료하되, 현장 상황이 전제를 뒤집는 구조
- 필요: 미션 타입별 브리핑 정보 차이, 적응 요소, 선택 분기 설계

### 3. 코어 루프 (CORE-002) 초안
- 의존: ①②가 진전되면 작성 가능
- 내용: 런 구조, 스테이지 간 연결, 야영 역할, 비용-보상 순환

## 우선순위 P1

### 4. 야영/성장 시스템 (META-*)
- 야영 = 매 스테이지 사이 성장 단계 (주사위 면 교체, 유닛 강화, 영입 등)
- 위업 보상이 야영에 영향
- 보급 시스템과의 연결 (야영 성장이 다음 보급 풀에 영향 가능)

### 5. 보급 풀 세부 설계
- 풀 공개 조건 확정
- 선택 장수 (N) 확정
- 붕대 사용 타이밍 확정
- 추가 카드 종류 검토 (횃불, 시야 확장 등 — 보류 상태)

## 참고

- 코어 판타지: "명령은 명료하다. 하지만 하급 지휘관에게 주어진 정보는 부족하고 현장은 이미 달라져 있다. 변하는 흐름을 읽고, 유추하고, 스스로 판단한다."
- 세 박자: 읽기 → 적응 → 선택 (스테이지 단위)
