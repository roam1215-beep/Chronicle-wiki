## 우선순위 P0

### 1. 중앙 카드 덱 구조 설계
- 확정: 스테이지 진행이 전부 중앙 카드 덱에서 나옴. 매 턴 3장 → 1장 선택
- 미확정: 미선택 카드 처리 (버림 / 잔류 / 강제발동)
- 미확정: "쫓아오는 카드" 구현 방식 (BoR 참고)
- 미확정: 카드 종류 (전투, 사건, 기회, 위기 등)
- 미확정: 덱 구성 규칙 (스테이지별 고정분 + 랜덤분?)
- 준비: BoR 한 판 돌려보며 "이 카드가 전투를 바꿨다 / 의미 없었다" 메모

### 2. 브리핑-카드 덱 관계
- 브리핑이 카드 덱과 별도인지, 첫 몇 장이 브리핑 역할인지
- 보급 선택 위치: 브리핑에서 고르는지, 카드로 나오는지
- 위업 위치: 브리핑에서 거는지, 카드로 등장하는지

### 3. ③ 큰 선택 — 명령 변경 메커니즘
- 카드 덱 구조 확정 후 재설계 가능
- 가설: "명령 변경" 카드가 덱에서 등장하는 구조?
- 미해결: 매번 유연책이 정답이 되는 지배 전략 문제
