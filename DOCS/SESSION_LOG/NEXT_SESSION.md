## ⚠️ 작업 규칙 (필독)

1. **파일 로드:** `cat file1 file2 file3` 한 방으로 일괄 로드. 절대 하나씩 읽지 말 것.
2. **수정:** `file_create`로 전체 파일 덮어쓰기. str_replace 여러 번 쓰지 말 것.
3. **검증:** 수정 후 `git diff --stat && git diff` 로 반드시 검증.
4. **커밋:** 1회. 분할 커밋 금지.
5. **세션 로그 신뢰:** 세션 로그에 "어디를 어떻게 바꿔라"가 적혀 있으면 원본 정독하지 말고 바로 수정. 세션 로그가 곧 지시서.

## 코어 루프

```
브리핑 (작전 목표 + 적 예상 배치 + 날씨 예보 + 지형 확인)
  ↓
스테이지 (3일 = 6턴)
  ├─ 매 턴: 낮/밤 교대
  ├─ 매일: 날씨 주사위
  ├─ 매 턴:
  │   ① 이동 주사위 굴림
  │   ② 경로 선택
  │   ③ 시야/신호 확인
  │   ④ 전투 진입 or 회피 판단
  │   ⑤ 전투 시 → 전투 페이즈 (7스텝: 선제→본전투→대응)
  │   ⑥ AI 부대 이동/행동
  ↓
야영 (면 교체 도박 / 부상 회복 / 병종 추가 — 택 1)
  ↓
다음 스테이지
```

## 핵심 원칙

- 주사위가 게임 문법. 이동, 날씨, 전투, 야영 전부 주사위로 통일
- 유닛 수 = 주사위 수. 유닛 사망 → 주사위 감소 → 전력 약화. 이 연결이 퍼마데스의 무게를 만든다
- 전투 전 판단이 핵심. 전투 중 판단은 최소화(카드 1장, 리롤 1회, 지형 전환 1회, 유닛 전환). 편성과 장비와 전투 진입 타이밍(낮/밤)이 승부를 결정
- 철수 없음. 전투 진입 = 끝까지 싸운다. 전투 회피는 맵 단계(시야, 소리, 정찰, 행군)에서
- 낮 = 적 주사위 보임, 밤 = 안 보임 (정보 비대칭)
- 낮 = 선제 페이즈 있음 (궁병 교전), 밤 = 선제 스킵

## 게임 정체성

- **한 줄:** 수치도 미니맵도 없이, 죽창부대를 이끌고 전쟁의 구멍을 때우는 턴제
- **핵심 경험:** 정보 없고, 자원 없고, 장비 없다. 판단만으로 구멍을 막는다
- **"서자니까"** = 모든 메카닉의 근거 (안개→정보 안 줌, 수치 없음→장비 없음, 퍼마데스→장비 구림)
- **서사:** 가르치지 않는다. 순응하는 삶을 살아간 기사 테오도라의 이야기를 보여줄 뿐. 기록 한 줄 vs 일기 한 권. 악의가 아니라 관성.
