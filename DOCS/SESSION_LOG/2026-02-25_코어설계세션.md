# 세션 로그: 2026-02-25 코어 설계 세션

## 세션 목표

코어 판타지 정의 + 전략층 설계 착수

## 결정 사항

### 코어 판타지 확정 (CORE-001)

> 명령은 명료하다. 하지만 하급 지휘관에게 주어진 정보는 부족하고 현장은 이미 달라져 있다. 변하는 흐름을 읽고, 유추하고, 스스로 판단한다.

### 스테이지 세 박자 확정

| 박자 | 이름 | 내용 |
|------|------|------|
| ① | 읽기 | 브리핑에서 맵·미션·적 정보를 읽고 보급 선택 + 위업 판단 |
| ② | 적응 | 현장에서 브리핑과 다른 현실에 대응, 계획 수정 |
| ③ | 선택 | 스테이지 안에서 불가역적 판단 |

### 보급 시스템 신설 (STAGE-SUPPLY)

- 기존 작전카드(COMBAT-ACT-003) 폐기
- 코스트 제거 (전부 동일 가치), 멀리건 제거, 카테고리 제거
- 보급 카드 5종: 붕대, 방패, 검, 군마, 깃발(리롤)
- 풀에서 조건부 공개 → N장 선택 → 스테이지 내 소진

### 위업 시스템 신설 (STAGE-FEAT)

- 보급과 별도 시스템
- 브리핑에서 자발적 조건 수락, 위반 시 소멸, 달성 시 야영 보상 증가
- 위업 2종: 전원 생존, 부상 클리어

### 작전카드 폐기 (COMBAT-ACT-003)

- 9장 대칭 구조 (행군/공격/수비 × 1/2/3pt) 전체 폐기
- 사유: 보급 시스템이 브리핑 전략 선택을 더 넓은 범위로 담당
