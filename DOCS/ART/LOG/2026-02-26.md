## 논의 (미확정)

### 주사위 시각 디자인 — 브레인스토밍

아트 세션에서 자유 논의했으나, **기획 의존성이 높아 아트 단독 확정 불가.**

#### 나온 아이디어

- 주사위 재질 방향: 뼈(bone), 석재(stone), 흑단(ebony) 등 → 이건 스킨 1종일 뿐, 시스템이 아님
- 주사위 시각 구조를 판독/정체성/장식 3레이어로 분리하는 안
- 병종 구분을 문장(heraldry)으로 하는 안
- ★ 면에 피색(accent-blood)을 고정하는 안

#### 기획 선행 필요 사항

| 질문 | 왜 아트가 못 정하는가 |
|------|---------------------|
| 스킨 시스템 존재 여부 | 수익화/보상 설계 = 기획 영역 |
| 병종별 주사위 차별화 범위 | 형태/문양/색조 중 뭘로 구분할지는 게임 정보 설계 |
| 주사위 커스터마이징 깊이 | 면 단위? 주사위 단위? 세트 단위? = 시스템 설계 |
| 기본 스킨의 톤 방향 | 위 결정 후 아트가 잡는 것 |

#### 아트가 선행 확정 가능한 것 (기획 무관)

- 면 기호 4종(⚔🛡★✕)의 **최소 판독 요건** (대비비, 최소 크기)
- ★에 피색을 쓸지 여부 (색상 토큰 확장)

→ 기획 트랙에서 주사위 스킨/커스터마이징 방향이 잡히면 아트 세션에서 후속.
