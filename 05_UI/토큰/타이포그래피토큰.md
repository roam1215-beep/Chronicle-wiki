# 디자인 토큰 — 타이포그래피

> **상태:** ✅ 확정 · **버전:** 1.0 · **수정일:** 2026-02-26  
> **근거:** [ART-002 타이포그래피](../결정/ART-002_타이포그래피.md)

---

## 핵심 원칙

> **"Cinzel은 명령이고, Noto Sans KR은 기록이다. 문장 안에서 폰트를 바꾸지 않는다."**

- font-ritual (Cinzel) — 의식, 명령, 영문 전용 요소
- font-chronicle (Noto Sans KR) — 기록, 서술, 한글 포함 모든 문장
- 한 텍스트 블록 안에서 폰트 전환 금지

---

## 폰트 패밀리

| 토큰 | 값 | 역할 |
|------|-----|------|
| font-ritual | `'Cinzel', serif` | 게임 제목, 카드 이름, 라벨, 독립 수치 |
| font-chronicle | `'Noto Sans KR', sans-serif` | 본문, 효과 텍스트, 사서 로그, 한글 포함 문장 |

### 웨이트 사용 범위

| 패밀리 | 사용 웨이트 |
|--------|-----------|
| Cinzel | 400 (라벨), 600 (카드 이름), 700 (제목/수치) |
| Noto Sans KR | 300 (캡션), 400 (본문), 500 (소제목/강조) |

---

## 타입 스케일

| 토큰 | 패밀리 | 크기 | 웨이트 | 행간 | 자간 | 색상 | 용도 |
|------|--------|------|--------|------|------|------|------|
| display | font-ritual | 48px | 700 | 1.15 | 0.2em | text-heading | 게임 제목 전용 |
| title-lg | font-ritual | 28px | 700 | 1.15 | 0.2em | text-heading | 대형 수치, 턴 카운터 |
| title-md | font-ritual | 20px | 600 | 1.15 | 0.12em | text-heading | 카드 이름, 패널 제목 |
| title-sm | font-chronicle | 16px | 500 | 1.5 | 0 | text-heading | 소제목, 툴팁 제목 |
| body | font-chronicle | 15px | 400 | 1.7 | 0 | text-body | 본문, 카드 효과, 일반 텍스트 |
| caption | font-chronicle | 12px | 300 | 1.5 | 0 | text-body | 보조 정보, 툴팁 본문 |
| label | font-ritual | 10px | 400 | 1.5 | 0.35em | text-sub | 라벨, 태그, 메타 (uppercase) |

---

## 행간 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| leading-tight | 1.15 | Cinzel 제목 계열 |
| leading-normal | 1.5 | Cinzel 중간, 캡션 |
| leading-relaxed | 1.7 | Noto Sans KR 본문 |
| leading-loose | 1.85 | 사서 로그 (장문 서술) |

## 자간 토큰

| 토큰 | 값 | 용도 |
|------|-----|------|
| tracking-wide | 0.35em | Cinzel 라벨 (대문자) |
| tracking-mid | 0.2em | Cinzel 제목 |
| tracking-normal | 0 | Noto Sans KR 본문 기본 |
| tracking-kr-sub | 0.08em | Noto Sans KR 부제 (미세 확장) |

---

## 한/영 혼용 규칙

| 규칙 | 설명 | 예시 |
|------|------|------|
| 영문 전용 요소 → Cinzel | 카드 이름, 라벨, 독립 수치 등 단독 표시 요소 | 카드 상단 "Shield Wall" → Cinzel |
| 한글 포함 문장 → Noto | 한글 문장 안의 영문·숫자는 Noto Sans KR을 따른다 | "Shield Wall을 시전합니다" → Noto 유지 |
| 문장 안 폰트 전환 금지 | 한 텍스트 블록 안에서 Cinzel↔Noto 전환하지 않는다 | — |
| 독립 수치 → Cinzel 700 | 단독 표시되는 숫자, 로마 숫자 | 턴 카운터 VII, 피해 −3 |
| 인라인 수치 → Noto 유지 | 한글 문장 안 숫자는 폰트 전환하지 않는다 | "피해 감소 2" → Noto |
| 대문자 라벨 → Cinzel + uppercase | UI 라벨은 tracking-wide와 함께 사용 | CHOICE, CHANCE, FATE, TURN |
| 사서 로그 → leading-loose | 장문 서술은 행간 1.85. 강조는 weight 500 + text-heading | "제1 창병대가 전열을..." |

### 구현 참고 (Unity TMP)

- 한 텍스트 블록 = 하나의 TMP 컴포넌트 = 하나의 폰트
- Cinzel 요소와 Noto 요소는 별도 TMP 컴포넌트로 분리
- Rich Text `<font>` 태그로 인라인 전환하지 않는다

## 색상 토큰과의 교차 규칙

| 주의 사항 | 내용 |
|----------|------|
| accent-blood-text 사용 제한 | #C4756F는 bg-deep (#0A0A0E) 위에서만 텍스트로 사용. bg-card (#151319) 이상에서는 대비비 ~4.0:1로 미달. |
| 텍스트 색상 기본 배정 | display~title-md → text-heading, body~caption → text-body, label → text-sub |
