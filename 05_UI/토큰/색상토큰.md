# 디자인 토큰 — 색상

> **상태:** ✅ 확정 · **버전:** 1.0 · **수정일:** 2026-02-26  
> **근거:** [ART-001 톤시안](../결정/ART-001_톤시안.md)

---

## 핵심 원칙

> **"어둠은 배경이 담당하고, 정보는 반드시 읽힌다."**

- 절제 = 밝기를 죽이는 게 아니라 **밝기를 쓸 곳을 줄이는 것**
- 유채색은 하나만 (#5C2A2A 피색)
- 분위기: 촛불이 켜진 어두운 서재
- 반드시 아닌 것: 왕궁, 골드, 하이 판타지

---

## 배경 레이어

| 토큰 | 값 | 용도 |
|------|-----|------|
| bg-deep | #0A0A0E | 최하층 배경 |
| bg-card | #151319 | 카드, 패널 배경 |
| bg-elevated | #1E1B22 | 모달, 툴팁, 호버 |
| border-subtle | #2C2A28 | 기본 테두리, 구분선 |
| border-warm | #352F2A | 강조 테두리 (미세한 따뜻함) |

## 텍스트 레이어

| 토큰 | 값 | 용도 | vs bg-deep | vs bg-card |
|------|-----|------|-----------|-----------|
| text-body | #9E9A95 | 본문. 장시간 읽힘. | 7.8:1 ✓ | 5.9:1 ✓ |
| text-heading | #BDB8B0 | 제목, 명령. 마른 석재. | 11.1:1 ✓ | — |
| text-sub | #6B6865 | 라벨, 메타 정보. 대형 텍스트 한정. | 3.5:1 ✓ | — |

## 유채색 (피색 — 단 하나)

| 토큰 | 값 | 용도 | vs bg-deep |
|------|-----|------|-----------|
| accent-blood | #5C2A2A | 테두리, 배경 장식 전용. 텍스트 금지. | — |
| accent-blood-border | #6E3333 | 우연 카드 테두리, 부상 표시 | — |
| accent-blood-text | #C4756F | 피색 텍스트. "즉시 발동" 등 읽혀야 하는 정보. | 5.2:1 ✓ |

### 피색 사용 규칙

| 상황 | 사용할 토큰 |
|------|-----------|
| 우연 카드 테두리 | accent-blood-border |
| "즉시 발동", "병력 -1" 등 태그 텍스트 | accent-blood-text |
| 사서 로그에서 우연 기록 | accent-blood-text |
| 부상 유닛 상태 텍스트 | accent-blood-text |
| 카드 상단 미세 그라데이션 | accent-blood (rgba, 낮은 불투명도) |

## WCAG 대비비 요약

| 기준 | 규칙 |
|------|------|
| 본문 텍스트 | 최소 4.5:1 (AA) — text-body, accent-blood-text |
| 대형 텍스트/제목 | 최소 3:1 — text-heading, text-sub |
| 장식 요소 | 대비비 미적용 — accent-blood, accent-blood-border |

## 선택 / 우연 / 운명 시각 구분

| 채널 | 구분 방식 | 색상 |
|------|----------|------|
| 선택 (Choice) | 밝기로 구분. 평온함. | 테두리 border-subtle |
| 우연 (Chance) | 유일한 유채색. 피가 번지는 느낌. | 테두리 accent-blood-border |
| 운명 (Fate) | 위치로 구분. 상단 고정. | 텍스트 text-heading |
| 잔류 (Residual) | opacity 0.5. 흐릿하게. | 기존 색상 유지 |

## 분위기 요소

| 요소 | 구현 |
|------|------|
| 촛불 광원 | 상단 중앙 radial-gradient, 따뜻한 톤 (rgba 45,35,25) |
| 양피지 질감 | SVG noise 텍스처, opacity 0.025 |
| 카드 깊이감 | box-shadow rgba(0,0,0, 0.2~0.35) |
| 패널 빛 반사 | 상단 1px linear-gradient (text-heading rgba 0.12) |
