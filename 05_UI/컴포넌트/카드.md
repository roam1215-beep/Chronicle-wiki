| 필드 | 값 |
|------|-----|
| **타겟 해상도** | 1920×1080 (16:9) |
| **카드 비율** | 2:3 (포커 카드 기준) |

> 미니 카드 폐기. 전투 중에도 풀 카드 사용 검토 중. 전투 씬 UI 설계 시 확정.

## ③ 인물 카드 — 진영 색상 체계

인물 카드는 병종별 고유색을 쓰지 않는다. **진영 3색**으로 통일한다.

| 진영 | 대상 | 테두리/스트립/배지 | Named 이름/특성 |
|------|------|-------------------|----------------|
| **테오도라 부대** | 아군 주력 | 회색 (#4A4A4A / #888) | 밝은 회색 (#CDCDCD) |
| **아군** | 비테오도라 아군 | 파랑 (#2A4A6E / #2980B9) | 밝은 청색 (#A0B8D4) |
| **적** | 적 전체 | 빨강 (#6E3333 / #8B2020) | 밝은 적색 (#D4A0A0) |

> 적/아군 모두 동일 병종 체계(민병/보병/창병/궁병/기병). 진영색만 다르다.
> 개별 유닛 구분은 일러스트 + 주사위 구성 차이로 한다.

## ④ 인물 카드 — 풀사이즈 앞면 (확정)

### Named 앞면

```
┌──────────────────────────┐ ─┐
│  🎲×1  테오도라 / 기사    │  │ ②③ 상단 좌측: 배지+이름+병종
│  서자의 칼은 아직 증명되지 │  │     + 플레이버
│  않았다.                   │  │
│ ┌──────────────────────┐ │  │
│ │                      │ │  │ ① 일러스트 (중앙)
│ │   [고유 인물 초상]    │ │  │   최소 높이 160px 보장
│ │                      │ │  │
│ └──────────────────────┘ │ ─┤
│                          │  │ ④ 특성 (Named만, 획득분만 표시)
│ ✦ 선봉의 맹세             │  │   ✦ 이름 + 설명 인라인
│   매 전투 첫 라운드,       │  │   미획득 = 표시 안 함
│   리롤 +1회.               │  │
│                          │  │
│  패시브                   │  │ ⑤ 패시브 (획득분만 표시)
│  반격                     │  │   이름
│  스텝6에서 🛡→⚔ 전환.    │  │   [상세 설명 텍스트]
│                          │  │     (2px 간격)
│  🛡 🛡 🛡 🛡 🛡 🛡 ★ ✕ ✕ ✕ │  │ ⑥ 다이스 면 5+5 + 비율 바
└──────────────────────────┘ ─┘
```

### Nameless 앞면

```
┌──────────────────────────┐ ─┐
│  🎲×3  보병대             │  │ ②③ 상단 좌측: 배지+병종명
│  전선의 이름 없는 방패들.   │  │     + 플레이버
│ ┌──────────────────────┐ │  │
│ │                      │ │  │ ① 일러스트 (중앙)
│ │   [대표 병사]          │ │  │   최소 높이 160px 보장
│ │                      │ │  │
│ └──────────────────────┘ │ ─┤
│                          │  │
│  패시브                   │  │ ④ 패시브 (획득분만 표시)
│  전열 교대                │  │   Nameless는 특성 없음
│  스텝6에서 ⚔→🛡 전환.    │  │   패시브 없으면 영역 자체 없음
│  ⚔ ⚔ ⚔ 🛡 🛡 🛡 ✕ ✕ ✕ ✕ │  │ ⑤ 다이스 면 5+5 + 비율 바
└──────────────────────────┘ ─┘
```

### 영역 상세

| 영역 | 위치 | 내용 | Named | Nameless |
|------|------|------|-------|----------|
| **② 주사위 배지** | 좌측 상단 | 주사위 수 표시 | d10 다면체 SVG ×1 | 🎲 이모지 ×N |
| **② 이름+병종** | 배지 우측 | 이름 / 역할 | "테오도라 / 기사" | "보병대" |
| **③ 플레이버** | 이름 아래 | 서사 문구 1줄 | 고유 문구 | 병종 공통 문구 |
| **① 일러스트** | 중앙 | 인물 초상 | 고유 인물 | 대표 병사 |
| **④ 특성** | 하단 (Named만) | ✦ + 이름 + 설명 | 획득분만 표시 | 없음 |
| **⑤ 패시브** | 하단 | 이름 + [설명] | 획득분만 표시 | 획득분만 표시 |
| **⑥ 다이스 면** | 최하단 | 5+5 배치 + 비율 바 | ★ 포함 | ★ 없음 |

> **빈 슬롯 미표시 원칙:** 특성은 획득된 것만 표시. 패시브는 민병 외 항상 표시. 민병(패시브 없음)은 일러스트 아래 바로 다이스.

> **일러스트 최소 높이 160px:** 특성/패시브가 늘어나도 일러스트가 160px 이하로 압축되지 않음.

> **패시브↔다이스 간격: 2px.** 붙되 완전히 겹치지는 않음.

### Named vs Nameless 시각 구분

| 요소 | Named | Nameless |
|------|-------|----------|
| **테두리** | 진영 Named 색 (1.5px) | 진영 기본색 (1px) |
| **상단 스트립** | 진영 Named 색 그라데이션 | 진영 기본색 (opacity 0.5) |
| **주사위 배지** | d10 다면체 SVG, 진영 Named 색 | 🎲 이모지, 진영 기본색 |
| **이름 색** | 진영 Named 색 (#CDCDCD 등) | 진영 기본 텍스트색 |
| **특성 섹션** | 있음 | 없음 |
| **내부 프레임** | 진영 Named 색 0.5px 서브프레임 | 없음 |
| **양피지 노이즈** | 있음 | 없음 |

### 뒷면

```
┌──────────────────────────┐
│                          │
│                          │
│       [질감 배경]         │
│                          │
│      「CHRONICLE」        │  ← 전 카드 공통
│                          │
│                          │
│                          │
└──────────────────────────┘
```

| 요소 | Named | Nameless |
|------|-------|----------|
| **질감** | 양피지 노이즈 | 크로스해치 거친 종이 |
| **텍스트** | "CHRONICLE" 각인 | "CHRONICLE" 각인 |
| **봉인** | 원형 ✦ 봉인 + 내부 프레임 | 없음 |
| **테두리** | 진영 Named 색 | 진영 기본색 |
| **상단 스트립** | 진영 Named 색 | 진영 기본색 |

## ⑤ 인물 카드 — 상태별 변형

### 건강 (기본)

카드 온전. 위 레이아웃 그대로.

### 부상 (Named만)

| 요소 | 표현 |
|------|------|
| **카드 프레임** | 대각선 균열 오버레이 |
| **일러스트** | 금이 간 오버레이 (적색 빛) |
| **손실 면** | 원래 면 위에 취소선 + ✕ 표시 |
| **색상** | 균열 부분만 적색, 전체는 유지 |

### 사망 (퇴장)

| 단계 | 연출 |
|------|------|
| 1 | 카드 중앙에서 세로로 찢어짐 시작 |
| 2 | 양쪽으로 벌어지며 퇴장 |
| 3 | 카드 자리 빈 공간 (흔적만) |

### Nameless 병력 감소

| 요소 | 표현 |
|------|------|
| **주사위 배지** | 🎲×N 숫자가 생존 수에 맞게 감소 (3→2→1) |
| **다이스 면** | 미정 — 전투 씬 UI 설계 시 확정 |

## ⑥ 사건 카드 — 풀사이즈

Stage 씬 [C] 카드 영역에서 사용. 덱에서 뒤집히는 카드.

### 뒷면 (공통)

```
┌──────────────────────────┐
│                          │
│                          │
│       [스테이지 문양]     │  모든 사건/우연 카드 동일
│                          │
│      「CHRONICLE」        │
│                          │
│                          │
│                          │
└──────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **디자인** | 모든 카드 동일. 전투/비전투/우연 구분 불가 |
| **문양** | 스테이지별 공통 문양 |
| **텍스트** | "CHRONICLE" 각인 |
| **컬러** | 어두운 남색 + 금색 문양 |

### 앞면 — 전투 사건

```
┌──────────────────────────┐ ─┐
│ ┌──────────────────────┐ │  │
│ │                      │ │  │ ① 일러스트 (35%)

│                          │  │
│  「강변의 보초」          │  │ ② 카드 제목 (8%)
│ ─────────────────────── │ ─┤
│  다리 이쪽 끝에 적        │  │ ③ 상황 서술 (12%)
│  보초 둘이 서 있다.       │  │   1~2문장

│                          │  │

│     ▸ 선제 1라운드        │  │   각 분기:
│     ▾ 발각 시 증원        │  │    - 적 정보 힌트
│  ───────────────────    │  │    - ▸ 이득
│  B. 우회한다              │  │    - ▾ 비용/리스크
│     적: 본대 일부         │  │
│     ▸ 리롤 +1 획득       │  │
│     ▾ 선제 없음           │  │
│                          │  │
└──────────────────────────┘ ─┘
```

## ⑦ 카드 인터랙션

### 뒤집기 (사건 카드)

| 단계 | 동작 | 시각 |
|------|------|------|
| **대기** | 카드 뒷면 중앙 배치. "터치하여 뒤집기" | 미세한 부유 애니메이션 |
| **길게 누르기** | 누르는 동안 카드 하단부터 들림 | 0~70%: 앞면 일부 노출 |
| **70% 초과** | 자동 완전 뒤집기 | 뒤집기 완료 사운드 |
| **스페이스/더블탭** | 즉시 뒤집기 | 빠른 플립 연출 |
| **되돌리기** | 70% 미만에서 손 떼면 원위치 | 카드 다시 덮임 |

### 분기 선택 (사건 카드)

| 단계 | 동작 | 시각 |
|------|------|------|
| **표시** | 분기 A/B (C) 나열 | 각 분기 터치 가능 |
| **호버/터치** | 분기 하이라이트 | 선택 분기 밝게, 나머지 디밍 |
| **선택** | 분기 터치 | 확인 팝업 표시 |
| **확인** | [확인] 터치 | 효과 적용 → 카드 이동 |
| **취소** | [취소] 터치 | 분기 선택 화면 복귀 |

### 유닛 상세 (인물 카드)

| 동작 | 효과 |
|------|------|
| **카드 터치** | 상세 팝업 or 확대. 면 구성, 패시브, 특성, 부상 상태 전부 표시 |
| **팝업 외부 터치** | 팝업 닫기 |
| **전투 중 적 카드 터치** | 적 유닛 면 구성 확인 (정보 공개 범위 내) |

> 미니 카드 폐기. 전투 중에도 풀 카드 사용 검토 중. 전투 씬 UI 배치 설계 시 확정.

│                          │

## ⑨ 설계 근거

**Q. 왜 카드 비율이 2:3인가?**
포커 카드 표준. 플레이어가 무의식적으로 익숙한 비율. 세로형 모바일 화면에서 카드 3장 나란히 배치 가능.

**Q. 왜 이름/병종/주사위가 상단 좌측인가?**
전투 화면에서 카드 하단이 가려져도 "누구인가"가 즉시 보인다. 일러스트 영역을 이름이 침범하지만, 상단 어두운 그라데이션으로 가독성 확보.

**Q. 왜 진영 3색인가?**
병종별 5색(민병/보병/창병/궁병/기병)은 "이 색이 뭔 의미인가" 인지 비용이 높았다. 진영색은 색=적/아군이라는 단일 규칙. 병종 구분은 일러스트+주사위로 한다.

**Q. 왜 Named 주사위 배지가 다른가?**
Named d10 다면체 SVG vs Nameless 🎲 이모지. "이름의 무게"를 시각적으로 표현. Named는 고유한 주사위를 가진 존재.

**Q. 왜 빈 슬롯을 안 보여주는가?**
빈 박스는 "아직 안 채움"인지 "못 받음"인지 모호하다. 패시브 없는 민병은 빈 칸 없이 바로 다이스가 나와야 "이 유닛은 패시브가 없다"가 명확하다.

**Q. 왜 미니 카드를 폐기했는가?**
전투 중에도 풀 카드를 보여주는 게 정보 밀도와 체험 면에서 나을 수 있다. 전투 씬 UI 레이아웃 설계 시 풀 카드 배치 방식을 확정한다.

**Q. 왜 사건 카드 뒷면이 전부 동일한가?**
"뒤집어야 안다." 뒷면에서 전투/비전투를 알 수 있으면 플레이어가 순서를 계산하게 되고, 순서 선택 불가 규칙과 충돌. 완전 블라인드가 핵심 경험("닥친 상황에 적응")에 필수.

**Q. 왜 부상이 면 취소선인가?**
면이 ✕로 바뀌는 게 규칙. 원래 면을 취소선으로 남기면 "무엇을 잃었는지" 플레이어가 기억. 순수 ✕로만 표시하면 원래 🛡였는지 ⚔였는지 모름.

**Q. 왜 편성 풀에서 실루엣인가?**
선택 전에는 "어떤 병종인지"만 보여주고, 구체적 인물은 아직 없음 (Nameless). 실루엣 = 아직 이름 없는 존재. 선택 후 뒤집기로 대표 병사 초상 공개.
