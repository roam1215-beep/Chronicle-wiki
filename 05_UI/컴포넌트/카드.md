## ③ 인물 카드 — 풀사이즈

### Named 앞면

```
┌──────────────────────────┐ ─┐
│ ┌──────────────────────┐ │  │
│ │                      │ │  │ ① 일러스트 (50%)
│ │   [고유 인물 초상]    │ │  │   - Named: 고유 인물
│ │                      │ │  │   - Nameless: 대표 병사
│ └──────────────────────┘ │ ─┤
│                          │  │
│  테오도라 / 창병          │  │ ② 명칭 (10%)
│ ─────────────────────── │ ─┤   - Named: 이름 / 역할
│  서자의 칼은              │  │   - Nameless: 병종+대
│  아직 증명되지 않았다      │  │ ③ 플레이버 (10%)
│ ─────────────────────── │ ─┤
│  반격 🛡→⚔              │  │ ④ 패시브 (15%)
│  ▪ ▪ ▪                  │  │   최대 3슬롯
│ ─────────────────────── │ ─┤   빈 슬롯: ▪ 표시
│  🛡  🛡  🛡  🛡  🛡  🛡  ★  ✕  ✕  ✕  │  │ ⑤ 다이스 면 (15%)
│                          │  │   d10 아이콘 1열
└──────────────────────────┘ ─┘
```

### 영역 상세

| 영역 | 높이 비율 | 내용 | Named | Nameless |
|------|-----------|------|-------|----------|
| **① 일러스트** | 50% | 인물 초상 | 고유 인물 | 대표 병사 |
| **② 명칭** | 10% | 이름+역할 or 병종+대 | "테오도라 / 창병" | "보병대" |
| **③ 플레이버** | 10% | 서사 문구 1~2줄 | 고유 문구 | 병종 공통 문구 |
| **④ 패시브** | 15% | 패시브 슬롯 최대 3개 | 동일 | 동일 |
| **⑤ 다이스 면** | 15% | d10 면 아이콘 1열 | ★ 포함 | ★ 없음 |

### 뒷면

```
┌──────────────────────────┐
│                          │
│                          │
│       [질감 배경]         │
│                          │
│      「CHRONICLE」        │  ← Named만
│                          │
│                          │
│                          │
└──────────────────────────┘
```

| 요소 | Named | Nameless |
|------|-------|----------|
| **질감** | 양피지 | 거친 종이, 어두운 단색 |
| **텍스트** | "CHRONICLE" 각인 | 없음 |
| **모서리** | 금색 테두리 | 테두리 없음 |

## ④ 인물 카드 — 상태별 변형

### 건강 (기본)

```
┌──────────────────────────┐
│  [일러스트]               │  카드 온전
│  테오도라 / 창병           │
│  플레이버                 │
│  패시브                   │
│  🛡  🛡  🛡  🛡  🛡  🛡  ★  ✕  ✕  ✕  │
└──────────────────────────┘
```

### 부상 (Named만)

```
┌──────────────────────────┐
│  [일러스트 — 금 간 효과]   │  카드 반파
│  테오도라 / 창병           │  
│  플레이버                 │  손실 면 시각 표시
│  패시브                   │  
│  🛡  🛡  🛡  🛡  🛡  ~~🛡~~  ★  ✕  ✕  ✕  │  ← 🛡 하나가 ✕로 (취소선)
└──────────────────────────┘
    ↑ 카드 오른쪽 모서리 찢김 표현
```

| 요소 | 표현 |
|------|------|
| **카드 프레임** | 오른쪽 상단 모서리 찢김 |
| **일러스트** | 금이 간 오버레이 |
| **손실 면** | 원래 면 위에 취소선 + ✕ 표시 |
| **색상** | 카드 전체 약간 어두워짐 |

### 사망 (퇴장)

| 단계 | 연출 |
|------|------|
| 1 | 카드 중앙에서 세로로 찢어짐 시작 |
| 2 | 양쪽으로 벌어지며 퇴장 |
| 3 | 카드 자리 빈 공간 (흔적만) |

## ⑧ 카드 인터랙션

### 뒤집기 (사건 카드)

| 단계 | 동작 | 시각 |
|------|------|------|
| **대기** | 카드 뒷면 중앙 배치. "터치하여 뒤집기" | 미세한 부유 애니메이션 |
| **길게 누르기** | 누르는 동안 카드 하단부터 들림 | 0~70%: 앞면 일부 노출 |
| **70% 초과** | 자동 완전 뒤집기 | 뒤집기 완료 사운드 |
| **스페이스/더블탭** | 즉시 뒤집기 | 빠른 플립 연출 |
| **되돌리기** | 70% 미만에서 손 떼면 원위치 | 카드 다시 덮임 |

### 분기 선택 (사건 카드)

| 단계 | 동작 | 시각 |
|------|------|------|
| **표시** | 분기 A/B (C) 나열 | 각 분기 터치 가능 |
| **호버/터치** | 분기 하이라이트 | 선택 분기 밝게, 나머지 디밍 |
| **선택** | 분기 터치 | 확인 팝업 표시 |
| **확인** | [확인] 터치 | 효과 적용 → 카드 이동 |
| **취소** | [취소] 터치 | 분기 선택 화면 복귀 |

### 유닛 상세 (인물 카드)

| 동작 | 효과 |
|------|------|
| **미니 카드 터치** | 풀사이즈 팝업. 면 구성, 패시브, 부상 상태 전부 표시 |
| **팝업 외부 터치** | 팝업 닫기 |
| **전투 중 적 카드 터치** | 적 유닛 면 구성 확인 (정보 공개 범위 내) |

## ⑫ 설계 근거

**Q. 왜 카드 비율이 2:3인가?**
포커 카드 표준. 플레이어가 무의식적으로 익숙한 비율. 세로형 모바일 화면에서 카드 3장 나란히 배치 가능.

**Q. 왜 사건 카드 뒷면이 전부 동일한가?**
"뒤집어야 안다." 뒷면에서 전투/비전투를 알 수 있으면 플레이어가 순서를 계산하게 되고, 순서 선택 불가 규칙과 충돌. 완전 블라인드가 핵심 경험("닥친 상황에 적응")에 필수.

**Q. 왜 우연 카드에 ⚡ 태그가 앞면에만 있는가?**
뒤집기 전에는 구분 불가 (뒷면 동일). 뒤집힌 순간 ⚡로 "이건 우연이다, 선택권 없다"를 즉시 전달. 분기 UI가 없으므로 태그 없이는 사건과 혼동.

**Q. 왜 부상이 면 취소선인가?**
면이 ✕로 바뀌는 게 규칙. 원래 면을 취소선으로 남기면 "무엇을 잃었는지" 플레이어가 기억. 순수 ✕로만 표시하면 원래 🛡였는지 ⚔였는지 모름.

**Q. 왜 인물/사건 미니 카드 크기가 같은가?**
부대 바(인물 미니)와 겪은 카드(사건 미니)가 같은 행에 나란히 올 수 있음. 크기가 다르면 시각적 불일치.

**Q. 왜 편성 풀에서 실루엣인가?**
선택 전에는 "어떤 병종인지"만 보여주고, 구체적 인물은 아직 없음 (Nameless). 실루엣 = 아직 이름 없는 존재. 선택 후 뒤집기로 대표 병사 초상 공개.
