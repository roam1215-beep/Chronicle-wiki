# ART-001: 톤 & 색상 시안

> **상태:** 🔄 진행중 · **버전:** 0.1 · **ID:** ART-001 · **수정일:** 2026-02-26

---

## ① 한 줄 요약

Holy Orders 전체 UI의 색상 톤을 확정한다. 핵심 과제: "어둠은 배경이 담당하고, 정보는 반드시 읽힌다."

---

## ② 제약 조건

| 필드 | 내용 |
|------|------|
| **비타협** | WCAG 본문 4.5:1, 제목 3:1. 어떤 시안에서든 미충족 시 기각. |
| **목표 분위기** | 기록관, 연대기, 재 위의 글자, 촛불이 켜진 어두운 밤 |
| **반드시 아닌 것** | 왕궁, 화려함, 금장식, 하이 판타지 |
| **유채색** | #5C2A2A (피색) 단일. 나머지 무채색~극저채도. |
| **절제의 정의** | 밝기를 죽이는 게 아니라 밝기를 쓸 곳을 줄이는 것 |

## ③ 시안 이력

| 시안 | 방향 | 결과 | 원인 분석 |
|------|------|------|-----------|
| 시안 1 | 세 방향 무드보드 (연대기/서재/석판). C의 절제를 선호. | ❌ 실패 | **톤 실패.** 골드 톤이 과했음. 골드 = 왕궁 연상. 게임의 "기록관/서재" 톤과 불일치. |
| 시안 2 | 골드 전면 제거. ash amber 대체. 최대 밝기 #B0A090. | ❌ 실패 | **기능 실패.** 완전히 안 읽힘. 분위기가 좋아도 안 읽히면 UI로서 죽은 것. |
| 시안 3 | 시안 2의 채도(낮음) 유지 + 밝기 ~30% 올림 | 🔄 진행중 | "읽히는데 골드는 아닌" 지점을 찾는 것이 목표. |

### 핵심 교훈: 채도 vs 밝기

**문제는 밝기가 아니라 채도였다.**

| 구분 | 설명 |
|------|------|
| 골드(Gold) | 채도가 높아서 "왕궁"을 연상 → 기록관/서재 톤과 불일치 |
| 같은 밝기 + 저채도 | "마른 석재" 느낌 → 맞는 방향 |
| 시안 2의 실수 | 채도를 낮추면서 밝기까지 같이 죽임 → 가독성 사망 |
| 해법 | 시안 2의 낮은 채도 유지 + 밝기를 올림 |

## ⑤ 설계 근거

**Q. 왜 골드를 쓰지 않는가?**
골드는 채도가 높아 "왕궁, 금장식, 하이 판타지"를 연상시킨다. Holy Orders의 톤은 "기록관이 촛불 아래에서 연대기를 적는" 장면이다. 같은 밝기여도 채도를 낮추면 "마른 석재"가 되어 맞는 방향.

**Q. 왜 WCAG 기준을 비타협으로 두는가?**
시안 2에서 증명됨 — 분위기가 아무리 좋아도 안 읽히면 UI로서 죽은 것이다. 어둠은 배경이 담당하면 되고, 텍스트는 반드시 읽혀야 한다.

**Q. 유채색을 왜 하나만 쓰는가?**
절제는 밝기를 죽이는 게 아니라 밝기를 쓸 곳을 줄이는 것. 색상도 마찬가지 — 색을 쓸 곳을 하나로 줄여서, 그 하나(피색)가 의미를 가지게 한다.

### 참고: 기존 와이어프레임 컬러 맵 (시안 3의 출발점)

이전 와이어프레임에서 사용한 색상. **이대로 쓰지 않음** — 골드가 과함.

| 용도 | 값 | 문제 |
|------|----|------|
| 배경 | #0a0a0f | 유지 가능 |
| 카드 배경 | #1e1b16 ~ #151310 | 유지 가능 |
| 테두리 | #3d3628, #2a2520 | 유지 가능 |
| 본문 텍스트 | #c4b99a | ⚠️ 골드 느낌 → 채도 낮춰야 함 |
| 강조/제목 | #e8dcc8 | ⚠️ 채도 확인 필요 |
| 서브 텍스트 | #8a7d65, #6b6252 | 대비비 확인 필요 |
| 골드 악센트 | #c4a46a | ❌ "튀는" 원인. 제거. |
| 선택(Choice) | #8a9a6b | ⚠️ 유채색 단일 원칙 위반 여부 확인 |
| 우연(Chance) | #9a6b6b | ⚠️ 피색(#5C2A2A)과의 관계 정리 필요 |

이 색상들에서 **채도를 빼고 밝기를 조정한 버전**이 시안 3의 출발점.
