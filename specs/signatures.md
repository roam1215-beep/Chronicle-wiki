# 특기 (Signature Skill) — 단일 정본

> ⛔ **[폐기 방향]** 대적자 특기·의지비용·8방향 사거리는 옛 체스+하스스톤 전투용이다. 현 코어에 '특기' 개념은 미정(판정 = 주사위 예산, `specs/dice.md`). 재정렬/폐기 대기. 아래는 옛 정본, 참조 금지.
>
> 대적자(영웅) 전용 능력으로, 하스스톤 영웅 스킬 참고
> Character.signature_skill 필드 ↔ 이 정본. cards.md 직업 정의는 포인터만 둠.

## 공통 규칙

```yaml
보유:  category=adversary 만 (normal = null 강제)
발동:  능동 — 내 턴, 플레이어 결정 (의지 단계)
비용:  의지 2 (모든 특기 공통. 카드·키워드로 변동 가능)
횟수:  턴당 1회만 (카드·키워드로 변동 가능)
동조:  특기 발동 직후 → 자기편 인물 〈동조〉 트리거 발동
```

## 사거리 공통 — 저격, 회복

```yaml
범위:  대적자 기준 8방향(상하좌우 + 대각) 2칸 이내
```

## 4직업 특기 (오더 1)

```yaml
수비  (전사)    cost 2
  본인 방어도 +1 (그 배틀 누적, 보호막 X)

저격  (사냥꾼)    cost 2
  〈저격 1〉 발동 — mechanics.md 메커니즘 키워드 〈저격〉(8방향 2칸 1회 공격)
  - 활/장궁으로 피해 강화(조악한 활 +1·장궁 +2), 당겨진 활시위로 그 턴 비용 0·피해 +1

회복  (사제)    cost 2
  대적자를 기준으로 상하좌우 대각선 2칸 이내에 1명의 대상을 지정하여 (적 등장중인 인물, 적대적자, 내 등장중인 인물, 내 대적자 모두 가능) 생명력을 1 회복시킴
생명력은 최대 체력보다 더 높게 회복시킬 수 없음

지휘  (군주)    cost 2
  거리 무관 내 등장중인 인물 1명 지정 → 임시 공격력 +1 (그 턴만)
  - 본인(대적자) 제외 / 단일 대상
```
