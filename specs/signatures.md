# 특기 (Signature Skill) — 단일 정본

> 대적자(영웅) 전용 능동 능력. 하스스톤 영웅 능력 결.
> Character.signature_skill 필드 ↔ 이 정본. cards.md 직업 정의는 포인터만 둠.

## 공통 규칙

```yaml
보유:  category=adversary 만 (normal = null 강제)
발동:  능동 — 내 턴, 플레이어 결정 (배치 페이즈)
비용:  의지 2 (모든 특기 공통. 카드·키워드로 변동 가능)
횟수:  턴 1회 (카드·키워드로 변동 가능)
동조:  특기 발동 직후 → 자기편 인물 〈동조〉 트리거 발동
인격:  같은 인물도 인격별로 직업·특기가 다름 (theodora_courage=전사=수비 등)
```

## 사거리 공통 — 사격·저주

```yaml
범위:  대적자 기준 8방향(상하좌우 + 대각) 2칸 이내
시야:  사이에 말이 있으면 못 침 (직선 시야 막힘)
```

## 5직업 특기 (오더 1)

```yaml
수비  (전사)    cost 2
  본인 방어도 +1 (그 배틀 누적, 보호막 X)

사격  (사냥꾼)  cost 2
  그 턴 본인 공격력 +1 → 8방향 2칸 적에 (그 턴 공격력)만큼 일방 피해 (시야 막힘)
  - 임시 공격력은 그 턴만 (누적 X) → 맨몸이면 기본 1 피해
  - 단 공격력 버프 받으면 그만큼 비례 증가 (본인 직접 사격 = 사격·공격 계통 키워드 연계 여지)

봉헌  (사제)    cost 2
  의식 스택 +1
  - 의식 = 사제 사이드 자원 (의지와 별개, 누적). 은총·축복으로 소모. 자원 상세 = cards.md 의식 섹션

저주  (예언자)  cost 2
  8방향 2칸 적 인물에 피해 1 (적 대적자 가능, 시야 막힘)
  - 고정 1 (스케일링·시너지 X) → 빌드 무관 단발 견제

지휘  (군주)    cost 2
  거리 무관 내 인물 1명 지정 → 임시 공격력 +1 (그 턴만)
  - 본인(대적자) 제외 / 단일 대상
```
