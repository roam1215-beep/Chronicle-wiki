# specs/ — 결정론적 명세

> Claude Code + claude.ai 공용. 구현 대상.

## 원칙

```yaml
- 본문 = 명세만 (결정론적 규칙·스키마·수치·알고리즘)
- 결의 의도·왜 그렇게 결정했나 = design/ 으로 이동
- 한 개념 = 한 정본 (SSOT). 다른 파일은 링크만
- 결정론적이지 않은 문장이 들어가면 design/ 이동
```

## 파일

```yaml
cards.md:        카드 스키마 — 전승 base(인물·기도·장비·책략) / 기록 base(스토리·기원) + 키워드
                 직업 7종 / 타입 5종 / 등급 5종 / 트리거 6종(턴제 재매핑 펜딩) / 카드 꼬리표 order·persona
combat.md:       턴제 전투 (격돌·사격·소환·이동·시야·시간대·적 행동) — 완전 턴제, 번갈아 (체스 결)
                 맵·시작 배치·전장의 안개
structure.md:    5층 구조 (Order/Chapter/Stage/Phase/Battle/Turn)
                 인격·카타스테리스모스·정보 공개 + 드래프트·강화·편성
environment.md:  Stage 단위 환경 (location / weather / 우호 NPC)
                 시간대 SSOT는 combat.md
```

## 펜딩 (큰 항목, STATE.md와 정합)

```yaml
시스템:
  - [피해 효과] 어휘 (옛 "사격" 폐기됨)
  - 기습 결 세부 (배치 위치·공격 타입)
  - 소환 대상 결
  - 트리거 6종 턴제 재매핑 (인내·동조·강림·기습)
  - 책략 카드 스키마·효과·영문
  - 직업 7종별 덱 특색 결
  - 보상 풀 등급 정합

수치 (시뮬 후):
  - 능력치 결 (3패러미터, 첫 구현 시도 후)
  - 키워드 강도 (등급별 차등)
  - 정확한 칸수 (전령 대각 등)

구조:
  - 카타스테리스모스 정확한 시점 (Order 안 어디서?)
  - 인격 해금 결의 구체
```
