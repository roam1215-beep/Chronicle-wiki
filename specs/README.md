# specs/ — 결정론적 명세

> 클로드 코드 + claude.ai 공용. 구현 대상.

## 원칙

```yaml
- 본문 = 명세만 (결정론적 규칙·스키마·수치·알고리즘)
- 결의 의도·왜 그렇게 결정했나 = design/ 으로 이동
- 한 개념 = 한 정본 (SSOT). 다른 파일은 링크만
- 결정론적이지 않은 문장이 들어가면 design/ 이동
```

## 파일

```yaml
cards.md:      카드 데이터 스키마 + 예시 (인물·전투·사건·우연·운명)
combat.md:     전투 결산 알고리즘 (의사코드, 페이즈 1~3, 피해 흐름)
structure.md:  5층 구조, 카드 단위, 인격 시스템, 위계 변동, 정보 공개
```

## 펜딩 결

```yaml
잠정 시드 (구현 후 시뮬 검증):
  - 능력치 합 4/9/16/25
  - 태생 분배 비율 (3:7 / 4:6 / 6:4 / 7:3)
  - 격파·축성·저격·수호 보너스 (잠정 +1)

명세 펜딩:
  - 미궁 사제 저주 대성공 효과
  - 보호막 부여 결 (사제 행동? 가호?)
  - 가호 콘텐츠 풀
  - 좌석 수 (전열·후열 N자리)
  - 위계 등극 정확한 시점
  - 인격 해금 결의 구체
```
