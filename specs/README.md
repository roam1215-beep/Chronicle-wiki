# specs/ — 결정론적 명세

> Claude Code + claude.ai 공용. 구현 대상.

## 원칙

```yaml
- 본문 = 명세만 (결정론적 규칙·스키마·수치·알고리즘)
- 결의 의도·왜 그렇게 결정했나 = design/ 으로 이동
- 한 개념 = 한 정본 (SSOT). 다른 파일은 링크만
- 결정론적이지 않은 문장이 들어가면 design/ 이동
```

## 파일

```yaml
cards.md:        카드 스키마 (인물·기도·장비·기록) + 키워드 시스템
                 직업 8종 / 타입 6종 / 등급 5종 / 트리거 6종
combat.md:       전투 결산 (라운드 2단계 — 선언 + 전투 5단계)
                 시야·전장의 안개·자동 진군·맵·시작 배치·시간대
structure.md:    5층 구조 (Order/Chapter/Stage/Phase/Battle/Round)
                 인격·카타스테리스모스·정보 공개
environment.md:  Stage 단위 환경 (location / weather / 우호 NPC)
                 시간대 SSOT는 combat.md
```

## 펜딩 (큰 항목, STATE.md와 정합)

```yaml
시스템:
  - [피해 효과] 어휘 (옛 "사격" 폐기됨)
  - 기습 결 세부 (배치 위치·공격 타입)
  - 소환 대상 결
  - 전령 타입 이동·전투·시야 결
  - 용병 타입 이동·전투·시야 결
  - 보호막·방어도 결산 결 본문화 (combat.md)
  - 배치 영역 결 (combat.md TODO)
  - 대적자별 배치 가능 칸 조건
  - 자기편 점유 충돌 (배치 순서·이동 순서)
  - 직업 8종별 덱 특색 결
  - 보상 풀 등급 정합

수치 (시뮬 후):
  - 능력치 결 (3패러미터, 첫 구현 시도 후)
  - 키워드 강도 (등급별 차등)

구조:
  - 카타스테리스모스 정확한 시점 (Order 안 어디서?)
  - 인격 해금 결의 구체
```
