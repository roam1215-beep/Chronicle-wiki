# 맵 프리셋 (Map Presets)

> ⛔ **[폐기 방향]** 맵·좌표·왕 배치·보병 돌파는 옛 체스 전투의 판이다. 현 코어는 공간/맵 개념이 없다(판정 = 주사위 예산, `specs/dice.md`). 폐기 또는 보류 — 재정렬 대기. 아래는 옛 정본, 참조 금지.
>
> 전투가 벌어지는 판의 단일 정본. 크기(축1)와 왕 배치(축2)를 **독립 축**으로 둔다.
> battle · fate · 전투형 chance 기록 카드가 두 축을 각각 지정해 조합한다 (스키마 = specs/cards.md "기록 카드").
> 좌표계 = 체스 표준 (가로 알파벳 a~ / 세로 숫자 1~), 범위는 크기 프리셋을 따른다.
> 시작 = 양 왕 마주 본 채 + 오프닝 기물이 깔린 채. 일반 말은 배치(놓기)→등장으로 전개 (오프닝 자동 배치 / 전투 지정 preplaced).

## 시작 세팅의 의미 (왜 두는가)

```yaml
난이도 레버를 카드 밖으로:
  지금까지 난이도는 카드 수치(hp·공격력)에 묶여, 어렵게 만들려면 적 카드를 세게 해야 했다(밸런스 붕괴 위험).
  시작 세팅이 생기면 — 카드는 그대로 두고 "판을 기울여" 난이도를 준다.
  → 직업·카드는 서로 안 깨지기만 하면 되고, 난이도는 세팅이 짊어진다.

세팅이 한 번에 푸는 것:
  - PvE 난이도: 세팅을 적 유리로 기울여 기본 난이도↑, 전투마다 조절
  - 스톨링(질질 끌고 한 방): 시작부터 불리하면 쌓을 여유 없음 — 쌓기 전에 대응 강요
  - 늘어짐: 빈 판 눈치보기 시간 제거, 선배치로 첫 턴부터 판이 살아 있음
  - AI 하방: 적 AI가 허술해도 시작이 유리하면 최소 위협 보장 (세팅이 AI 부족분을 메움)
  - 로그라이크 변주: 같은 대적자라도 세팅 따라 전혀 다른 전투

억지스럽지 않음: 적도 같은 판·같은 규칙을 쓴다 → 외부 페널티가 아니라 "판이 기운" 것이라 납득된다 (가역·통제 가능·점진).
```

## 축 1 — 크기 프리셋 (6종)

```yaml
표준 = 정사각. 회랑 = 같은 세로의 표준에서 가로만 2칸 좁힘 (우회 봉쇄·정면 강제, 보병 전진 거리 불변).
세로 5 미만 = 양 끝 2줄(배치 구역)이 맞붙어 중립지대 0 + 보병이 배치 다음 턴 즉시 돌파 → 보병 결 붕괴라 후보 제외.
```

| 표시명 | id | 가로×세로 | 중립지대 | 보병 돌파 |
|--------|-----|----------|---------|----------|
| 표준-소형 | `standard_small` | 6×6 | 2줄 | 2턴 |
| 표준-중형 | `standard_medium` | 7×7 | 3줄 | 3턴 |
| 표준-대형 | `standard_large` | 8×8 | 4줄 | 3턴 |
| 회랑-소형 | `corridor_small` | 4×6 | 2줄 | 2턴 |
| 회랑-중형 | `corridor_medium` | 5×7 | 3줄 | 3턴 |
| 회랑-대형 | `corridor_large` | 6×8 | 4줄 | 3턴 |

```yaml
# 중립지대 = 양 끝 2줄(배치 구역) 뺀 가운데 줄 수.
# 보병 돌파 = 2랭크 배치 → 적 끝줄 최소 전진 턴 (보병 앞 1~2칸 기준, 배치 [대기] 별도).
# 회랑 = 가로 압축형(우회 봉쇄)만 안전. 세로 압축형(돌파 단축)은 마지노선 5에 막힘.
#   빠른 러시 맵이 필요하면 가로 넓고 세로 5 (예: 8×5·7×5) — 세로는 5 밑으로 내리지 않는다.
```

## 축 2 — 왕 배치 (4종)

```yaml
절대 좌표가 아니라 "중앙 기준 대칭 규칙" — 맵 크기가 바뀌어도 같은 규칙으로 결정.
세로:
  표준  = 양 끝줄      (내 1랭크 / 적 최상랭크)
  전진  = 한 칸 안쪽    (내 2랭크 / 적 최상-1랭크)
  → 위아래 대칭
가로:
  짝수 가로 = 중앙 왼칸(좌) / 중앙 오른칸(우)
  홀수 가로 = 정중앙 한 열 (좌·우 구분 없음 — 둘이 같은 칸)
```

| 배치 | id | 세로 | 가로 (짝수 맵) |
|------|-----|------|--------------|
| 표준-좌 | `standard_left` | 양 끝줄 | 중앙 왼칸 |
| 표준-우 | `standard_right` | 양 끝줄 | 중앙 오른칸 |
| 전진-좌 | `advance_left` | 끝줄 한 칸 안 | 중앙 왼칸 |
| 전진-우 | `advance_right` | 끝줄 한 칸 안 | 중앙 오른칸 |

```yaml
# 전진 = 적에 빨리 닿지만 노출↑ · 왕 인접 배치 구역이 한 칸 앞으로(중립지대 잠식) = 트레이드오프 다이얼.
#   보병 결엔 무관 (왕은 별개 말, 보병 전진과 무관).
```

### 크기 × 배치 적용 예 (내 왕 / 적 왕)

| 크기 | 표준-좌 | 표준-우 | 전진-좌 | 전진-우 |
|------|--------|--------|--------|--------|
| 8×8 | d1 / d8 | e1 / e8 | d2 / d7 | e2 / e7 |
| 6×6 | c1 / c6 | d1 / d6 | c2 / c5 | d2 / d5 |
| 7×7 (홀수) | d1 / d7 | d1 / d7 | d2 / d6 | d2 / d6 |
| 4×6 | b1 / b6 | c1 / c6 | b2 / b5 | c2 / c5 |
| 5×7 (홀수) | c1 / c7 | c1 / c7 | c2 / c6 | c2 / c6 |
| 6×8 | c1 / c8 | d1 / d8 | c2 / c7 | d2 / d7 |

```yaml
# 홀수 가로(7·5)는 좌/우가 같은 정중앙 열.
# 옛 고정값 "테오도라 e1 / 발드 e8" = 표준-대형 + 표준-우의 한 사례.
```

## 기록 카드 연동

```yaml
battle · fate · 전투형 chance(불운→ordeal→조우) 카드가 지정:
  map_preset:  축1 크기 (필수)
  king_layout: 축2 왕 배치 (필수)
  preplaced:   이 전투 고유 선배치 (없으면 []. 프리셋 아님 — 적 카드색이라 재사용 X)
스키마 = specs/cards.md "기록 카드".

챕터 진행에 따른 맵 경향(소형→중형→대형)은 별도 규칙 없이 데이터 관행으로:
  챕1 전투들은 표준-소형·회랑-소형, 챕3은 표준-대형 식으로 작가가 프리셋을 고름.
```

## 펜딩

```yaml
- 크기-용도 매핑 (어느 챕터·전투에 어느 프리셋·왕 배치·선배치 — 콘텐츠 결, 작가 박음)
- 특수 칸 종류 / 비대칭 맵 규칙 (크기·왕위치 외 변형)
- 선배치 농도 가이드 (전투당 몇 기·어느 강도 — 시뮬 후)
```
