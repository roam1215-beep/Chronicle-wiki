# 전투 시스템

> Battle·Round 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.

## 단위

```yaml
Battle: 스토리 카드 1장 = 1 전투 인스턴스
Round:  Battle 최소 단위. 선언 → 전투
```

## 맵

```yaml
크기: 6x6 기본 (더 넓어질 수 있음, 작가 정의)
스토리 카드(battle / fate 포함)가 맵을 정의
맵 정보 = 시작 배치·시작 시간대·맵 특수 결 (작가 정의)
```

## 진영

```yaml
3 진영:
  지상     (surface)
  미궁     (labyrinth)
  경계     (border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 시간대

```yaml
3 시간대: 낮 / 경계 / 밤

진영 자기 시간대:
  지상 = 낮
  경계 = 경계
  미궁 = 밤

흐름:
  매 라운드 시작 시 시간대 변경
  다음 라운드만 미리 보임 (예고 결)
  순환 패턴 = 작가 정의 (맵·스토리 카드)

강림 자격:
  카드 태생 → 시간대 매핑 (cards.md 참조)
  카드 시간대 = 현재 시간대일 때 강림 트리거 발동 자격
```

## 의지

```yaml
의지 = 자원
  라운드 번호만큼 충전 (1라운드 의지 1, 2라운드 의지 2, …)
  상한 7 (8라운드 이후도 7)
  라운드 사이 이월 X (매 라운드 새로 충전)

사용처:
  - 패에서 카드 배치 (카드별 비용)
  - 특기 발동 (기본 1, 카드·키워드 결로 변동)
  - 기도 카드 발동 (카드별 비용)
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    인물 카드 — 대적자 / 일반 인물
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  스토리  덱이 아님 — battle / event / chance / fate

덱 구성: 인물 + 기도 + 장비
스토리 카드: 페이즈 진행 단위 (선택-거부-감내)
```

## 라운드 구조

```yaml
선언 단계:
  - 의지 충전 (라운드 번호만큼, 상한 7)
  - 시간대 변경 (작가 정의 흐름)
  - 양쪽 비공개 선언:
    - 인물 카드 배치
    - 기도 카드 발동
    - 특기 발동
  - 의지 차감 (선언 시점)
  - 동시 공개 → 전투 단계

전투 단계 (5 단계):

  1. 대기 단계
     1a. 양쪽 선언된 인물 카드 동시 배치
     1b. 등장 트리거 발동 (모든 등장 인물)
     1c. 강림 트리거 발동 (시간대 일치 인물)

  2. 준비 단계
     기도 + 특기 발동
     동조 트리거 발동 (각자 자기 진영 대적자 특기 시)

  3. 이동 단계
     자동 추적 (가장 가까운 적 방향)
     동시 진행
     충돌 시 둘 다 자기 자리 멈춤

  4. 전투 단계
     4a. 사거리 안 적 동시 공격
     4b. 피해 동시 적용 (사망 처리 전)
     4c. 치명타 트리거 발동 (0 hp 이하 되는 인물)
     4d. 사망 처리
     4e. 퇴장 트리거 발동

  5. 결산 단계
     인내 트리거 발동 (라운드 끝까지 생존)
     라운드 효과 소멸
     다음 라운드 선언으로
```

## 결산 원칙

```yaml
층 사이: 명시 순서
  5 단계의 번호 순서대로 처리
  앞 단계 끝나야 다음 단계 시작
  전투 단계 안 (4a~4e)도 안 결의 순서

층 안: 동시 적용, 결과 누적 (α 결)
  같은 단계 안의 효과는 동시 적용
  결과는 누적

배치 원칙 (새 트리거·새 카드 효과의 단계 결정 기준):
  준비 → 행동   (대기·준비 → 이동·전투)
  발생 → 반응   (피해 → 사망, 전투 단계 안)
  직접 → 간접   (공격 → 치명타)
```

## 충돌 풀이

```yaml
이동 충돌:
  두 인물이 같은 칸으로 이동 시도
  → 둘 다 자기 자리에 멈춤

동시 사망 (양쪽 0 hp):
  둘 다 사망 처리 (α 결)
  단 양쪽 대적자가 동시 0 hp
    → 게임 오버 (패배)

기도·특기 효과 충돌:
  같은 인물·같은 칸·같은 자원에 작용 시
    동시 적용, 결과 누적
  음수 결과 처리:
    hp 만 0 으로 박힘
    의지·공격력 등은 음수 X (최소 0)
```

## 피해 흐름

```yaml
피해 적용 순서 (4b 단계):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 ≤ 방어도 → 방어도 차감
     - 피해 > 방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 영구 사망 (퍼마데스)

자원 지속:
  보호막·방어도:
    기본 = 그 라운드만 (라운드 종료 시 정리)
    키워드·장비·기도 효과로 라운드 지속 변동 가능
    배틀 종료 시 자동 정리
  hp:
    배틀 종료 후 회복
    0 이하 = 영구 사망 (배틀·회차 통째 X)

부여 결:
  보호막·방어도 = 키워드·장비·기도 효과로 부여
```

## 자동 진군

```yaml
일반 인물:
  매 라운드 자동 이동 (3단계)
  세로 직진 (자기 열로)
  적 대적자 방향
  역할(타입)별 패턴이 곧 카드 정체성
    예: 보병·궁수·전차·신전 등 (작가 정의)

대적자:
  자동 이동 X
  플레이어가 직접 1칸 이동 결정
  적 대적자 = 직업 결에 따라 자동 (전투형 / 가만형)

이동 결의 무게:
  플레이어 결정 = 배치·대적자 이동·의지 분배
  자동 = 일반 인물 이동·공격
  인지 부하 ↓, 결정 무게는 배치·대적자·의지에 집중
```

## 승리 조건

```yaml
배틀 승리:
  적 대적자 사망
  OR 적 인물 전멸

배틀 패배:
  플레이어 대적자 사망
  OR 양쪽 대적자 동시 사망

자동 진군 결로 자연 결산:
  적 인물이 우리 방향 진군
  우리 인물이 적 대적자 방향 진군
  → 자연스럽게 대적자 사망 결로 풀림 (전멸 결은 비주류)
```
