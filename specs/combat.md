# 전투 시스템

> Battle·Turn 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.
>
> 정체: "하스스톤을 체스판 위에서" — 체스 움직임이 바닥, 카드·공격력·체력이 그 위에 얹힘.

## 단위

```yaml
Battle: 스토리 카드 1장 = 1 전투 인스턴스
Turn:   Battle 최소 단위. 한 쪽이 자기 턴을 다 쓰고 상대 턴으로 (번갈아)
```

## 맵

```yaml
크기: 6x6 기본 (더 넓어질 수 있음, 작가 정의)
좌표: 가로 1~6 / 세로 a~f
스토리 카드(battle / fate)가 맵을 정의 (시작 시간대·맵 특수 결)

시작:
  빈 판 — 양 진영 대적자(킹)만 마주 본 채 시작
  대적자 시작 위치 = 자기 진영 마지막 줄 (정확한 칸 펜딩)
  일반 말은 시작 시 판에 없음 — 소환으로 전개
```

## 진영

```yaml
3 진영: 지상(surface) / 미궁(labyrinth) / 경계(border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 시간대

```yaml
3 시간대: 낮 / 경계 / 밤

진영 자기 시간대: 지상=낮 / 경계=경계 / 미궁=밤

흐름:
  매 턴 시작 시 시간대 변경
  다음 턴만 미리 보임 (예고 결)
  순환 패턴 = 작가 정의 (맵·스토리 카드)

강림 자격 (트리거 펜딩):
  카드 태생 → 시간대 매핑 (cards.md 참조)
  카드 시간대 = 현재 시간대일 때 강림 트리거 발동 자격
  # ※ 트리거 6종 턴제 재매핑 펜딩
```

## 의지

```yaml
의지 = 카드 통화 (이동은 공짜 — 의지 X)
  매 턴 시작 시 그 턴 한도 충전
  1턴 1, 매 턴 +1, 상한 7 (이후 계속 7)
  턴 사이 이월 X (매 턴 새로 충전)

사용처 (전부 카드/자원 발동):
  - 소환 (인물 카드를 킹 8칸에)
  - 기도 카드 발동
  - 장비 부착
  - 대적자 특기 발동

이동에는 의지가 들지 않는다 (체스 통화).
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    대적자 / 일반 인물 (소환해서 판에 놓음)
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  스토리  덱이 아님 — battle / event / chance / fate (페이즈 진행 단위)

덱 구성: 인물 + 기도 + 장비
스토리 카드: 페이즈 진행 단위 (선택-거부-감내)
```

## 턴 구조

```yaml
완전 턴제 — 번갈아. 한 쪽 턴이 끝나야 상대 턴.

내 턴 시작 시 (순서):
  1. 시야 갱신
  2. 시간대 변경 (작가 정의 흐름)
  3. 의지 충전 (턴 번호만큼, 상한 7)
  4. 드로우 (1장)

내 턴 행동 (순서·횟수 자유, 의지·이동 한도 안에서):
  - 이동: 판 위 말 이동 (공짜, 말마다 1회)
  - 소환: 패에서 인물 → 킹 8칸 (의지)
  - 기도: 패에서 기도 발동 (의지)
  - 장비: 패에서 장비 부착 (의지)
  - 특기: 대적자 특기 발동 (의지, 턴 1회)

내 턴 종료 → 상대 턴
```

## 이동 (체스 문법)

```yaml
타입별 이동 모양 (cards.md 정본):
  병사 = 폰 (앞 1칸) / 기수 = 나이트 (ㄱ자) / 전령 = 비숍 (대각)
  사수 = 우리 말 (이동 1칸 가로세로) / 대적자 = 킹 (8방향 1칸)

횟수:
  모든 말 = 한 턴 1회 이동 (트리거 효과로 n회 가능)
  같은 말 같은 턴 두 번 이동 X (트리거 없으면)
  소환된 턴 = 멀미 (이동 X, 트리거로 해제)

플레이어 (전군 자유):
  내 말 전부를 자유롭게 움직임 (각자 1회씩)

적 (비대칭):
  같은 규칙으로 두지 X — 말마다 단순 규칙 + 회차 인격 ("## 적 행동" 참조)
  적 말도 한 턴 1회 이동 (틀은 동일)
  → "전군 최적해 AI" 안 짬. 비대칭이 1인 구현·QA 검증을 가능케 함

1칸 1말 결 (배치·이동 시 정합 강제)
```

## 격돌 (근접 전투)

```yaml
정의:
  근접 말(폰·나이트·비숍 등)이 적 칸으로 들어가려 시도할 때만 발생
  능동 진입 시도일 때만 — 옆에 붙어만 있으면 격돌 X (자동 전투 없음)

결산 (동시 교환):
  1. 양쪽이 공격력만큼 서로에게 피해 (반격 있음)
  2. 피해 적용 (보호막 → 방어도 → hp, "## 피해 흐름" 참조)
  3. 사망 판정 (동시)

결과 4종:
  a. 적만 죽음     → 공격자가 그 칸 차지
  b. 공격자만 죽음 → 적 제자리, 공격자 소멸
  c. 둘 다 죽음     → 빈 칸
  d. 둘 다 생존     → 둘 다 제자리 (공격자 원위치)

피해 누적:
  못 죽인 적의 깎인 체력은 그대로 유지 (턴 경과 회복 X)
  다음 격돌로 이어짐 → 1대1로 강한 말 못 잡음, 여럿이 갈아내야 함

대적자 격돌:
  대적자(킹) = 공격력 0 → 격돌 시 반격으로 0을 줌
  즉 킹을 치는 적 말은 안전하게 킹을 깎음 (킹 = 약한 심장)
  킹은 직접 못 싸움, 병력으로 지켜야 함
```

## 사격 (원거리 전투)

```yaml
사수의 일방 공격 — 반격 없음
  사수는 이동 안 하므로 자기 자리 유지
  시야 안 적만 (안 보이면 사격 X)
  피해 = 보호막 → 방어도 → hp (격돌과 동일 흐름, 단 일방)
  피해 누적 (회복 X)

사격 시 노출:
  사수가 사격하면 그 사수 위치가 적에게 드러남
  → "숨어서 안전하게 쏜다"의 약점: 쏘면 들킨다
```

## 피해 흐름

```yaml
피해 적용 순서 (격돌·사격 공통):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 <= 방어도 → 방어도 차감
     - 피해 >  방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 그 배틀 사망
     # 옛 "영구 사망(퍼마데스)" 결 폐기됨. 배틀 안 사망 = 묘지 →
     #   배틀 끝 셔플 후 덱 복귀 (cards.md 카드 생애). 폐기(discard)만 영구 손실.

자원 지속:
  보호막·방어도:
    기본 = 그 턴만 (턴 종료 시 정리)
    키워드·장비·기도 효과로 지속 변동 가능
    배틀 종료 시 자동 정리
  hp:
    배틀 안 깎인 건 누적, 배틀 종료 후 회복
    0 이하 = 그 배틀 사망 (묘지 → 배틀 끝 덱 복귀)

부여 결:
  보호막·방어도 = 키워드·장비·기도 효과로 부여
```

## 소환

```yaml
위치: 킹(대적자) 인접 8칸의 빈 칸 (킹 이동 범위와 동일)
비용: 의지 지불 (카드 cost)
멀미: 소환한 턴엔 이동·격돌 X (트리거로 해제 가능)
장수: 한 턴 소환 수 = 의지가 제한
정합: 1칸 1말 (빈 칸에만)

킹 포위 = 중심 전장:
  적이 킹 8칸을 잠식하면 → 소환 공간 줄어듦 + 킹도 깎임 (눈덩이)
  킹 주변 공간을 누가 쥐느냐가 승부의 중심
  # 눈덩이 완충 = 뒷줄 보급선 풀지 (시뮬 후 펜딩)
```

## 시야·전장의 안개

```yaml
시야:
  타입별 결 (cards.md 참조)
  진영 공유 — 우리편 누구라도 본 칸은 다 보임
  시야 안 적 = 정보 공개 (structure.md 참조)

전장의 안개:
  시야 밖 = 안개 (적 정보 X)
  잔여 시야 = 우리편이 봤던 칸의 적 = 실루엣·? 표시
  안 보이는 적은 공격(격돌·사격) 불가

갱신:
  내 턴 시작 시 시야 갱신
  적 사수는 사격 시 위치 노출

사수 운영 결 (의도된 결):
  사수 시야 1 + 사격 2칸 = 단독으론 1칸까지만 사격
  2칸 사거리 = 부대 시야 공유로 발현 (동료 곁 또는 전열 결)
  → 사수 운영 = 시야 잘 쓰거나 전열 결 갖춰야 (강하지만 약점 있음)
```

## 적 행동 (비대칭 AI)

```yaml
원칙:
  플레이어는 전군 자유 (사람이 둠 — AI 부담 0)
  적은 "최적해 사령관 AI"가 아니라 — 말마다 단순 규칙 + 회차 인격
  → 1인 구현 가능, QA 검증 가능 (상태 X → 행동 Y 명확)
  → 적의 예측 가능함이 곧 퍼즐 (읽고 역이용)

층 1 — 말 하나의 기본 본능 (구체 펜딩):
  예: "가장 가까운 적(또는 킹)을 향해 한 칸 다가가고, 격돌 범위면 친다"
  타입별 변형 (사수 = 안 움직이고 사거리 안 적 사격 등)
  적 말도 한 턴 1회 이동

층 2 — 회차 인격이 전군 기조:
  인격 = 적 개별 말이 아니라 그 회차(오더) 전체에 깔리는 결
  용기 = 안개 속 + 공격 (저돌적 직진, 매복에 약함)
  지혜 = 안개 속 + 수비 (라인 유지·지구전, 안 보이는 건 모름)
  정의 = 안개 없음(투시) + 공격/수비는 배틀 진입 시 시스템이 정함
         (플레이어 화면엔 늘 "정의"로만 표시 — 내부 결정)
         → "더 똑똑한"이 아니라 "더 잘 보는" 적 (매복 안 통함)
  서사 정합: 용기·지혜·정의가 테오도라 인격이자, 세계가 시험하는 방식

# ※ 층 1 본능·타입별 변형 구체화 = 펜딩
```

## 멀리건·드로우

```yaml
드로우:
  매 턴 시작 시 1장

멀리건:
  각자 자기 첫 턴에 1회 (시작 패 교체 선택)
    - 다 바꿈 / 일부 바꿈 / 그대로 중 선택
    - 교체한 패는 다시 못 돌림
  적 (AI): 멀리건 교체 안 함 (시작 패 그대로 진행)
  # 교체 장수·드로우 상한 등 세부 펜딩
```

## 승리 조건

```yaml
승리: 적 대적자(킹) 체력 0
패배: 내 대적자 체력 0
  대적자 = 공격력 0, 격돌당하면 깎임 (병력으로 지켜야 함)
  인물 전멸 결 폐기 — 대적자 사망으로만 승부

킹 포위 결판:
  적이 킹 8칸을 잠식 → 소환 막힘 + 킹 깎임 → 무너짐
  킹 주변 공간 다툼이 승부의 중심 전장
```
