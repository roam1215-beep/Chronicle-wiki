# 전투 시스템

> Battle·Turn 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.
>
> 정체: "하스스톤을 체스판 위에서" — 체스 움직임이 바닥, 카드·공격력·체력이 그 위에 얹힘.

## 단위

```yaml
Battle: 기록 카드 1장 = 1 전투 인스턴스
Turn:   Battle 최소 단위. 한 쪽이 자기 턴을 다 쓰고 상대 턴으로 (번갈아)
```

## 맵

```yaml
크기·대적자 위치 = 맵 프리셋 (크기 6종 × 왕 배치 4종 = specs/maps.md SSOT)
좌표: 체스 표준 (가로 알파벳 a~ / 세로 숫자 1~) — 범위는 프리셋 크기를 따름
기록 카드(battle / fate / 전투형 chance)가 맵 프리셋·왕 배치·오프닝을 지정 (cards.md 스키마)

시작:
  양 진영 대적자(킹)는 왕 배치(maps.md)대로 마주 본 채 + 오프닝 기물이 깔린 채 시작
  대적자 시작 위치 = 왕 배치(maps.md) — 표준-대형+표준-우면 플레이어 e1 / 적 e8 (옛 고정값 = 이 한 사례)
  오프닝 = 배틀 시작 시 덱에서 자동으로 나와 배치 영역에 깔림 ([대기] 상태) — "## 배치·등장" 참조
```

## 진영

```yaml
3 진영: 이오니아(ionia) / 도리아(doria) / 경계(border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 의지

```yaml
의지 = 카드 통화 (이동은 공짜 — 의지 X)
  매 턴 시작 시 그 턴 한도 충전
  1턴 1, 매 턴 +1, 상한 7 (이후 계속 7)
  턴 사이 이월 X (매 턴 새로 충전)

사용처 (전부 카드/자원 발동):
  - 등장 (필드의 [대기] 인물 활성화)   # 전승 카드(인물) — 배치(놓기) 자체는 비용 없음, 배치는 1턴에 1개 인물만 가능
  - 기도 카드 발동                     # 전승 카드(기도)
  - 권능 카드 발동                     # 전승 카드(권능)
  - 장비 부착                          # 전승 카드(장비)
  - 대적자 특기 발동                    # 특기 (카드 아님, 대적자 능력)

이동에는 의지가 들지 않는다 (체스 통화).
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    대적자 / 일반 인물 (배치해서 판에 놓고, 등장으로 활성화)
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  기록  덱이 아님 — battle / event / chance / fate (페이즈 진행 단위)

덱 구성: 인물 + 기도 + 권능 + 장비
기록 카드: 페이즈 진행 단위 (선택-버림-감내)
```

## 턴 구조

```yaml
완전 턴제 — 번갈아. 한 쪽 턴이 끝나야 상대 턴.
한 턴 = 의지 단계 → 전투 단계 (2단계 — 동시 결정 부하 절반. types.md "## 한 턴의 모양")

내 턴 시작 시 (순서):
  1. 의지 충전 (턴 번호만큼, 상한 7)
  2. 드로우 (1장)

의지 단계 (의지 통화 — 순서·횟수 자유, 의지 한도 안에서):
  - 배치(놓기): 덱에서 뽑은 인물을 배치 영역에 놓음 (공짜, 턴당 1기) — [대기] 상태
  - 등장(활성화): 필드의 [대기] 말에 의지 지불 → 깨어남 (영구). 등장한 말은 그 턴 전투 단계부터 행동
  - 기도: 패에서 기도 발동 (의지)
  - 권능: 패에서 권능 발동 (의지)
  - 장비: 패에서 장비 부착 (의지)
  - 특기: 대적자 특기 발동 (의지, 턴 1회) — 상태를 켬, 전투 단계에 씀

전투 단계 (이동 통화 — 공짜, 말마다 1회):
  - 이동: 판 위 등장 말 이동 (타입별 모양 = types.md)
  - 격돌: 근접 말 적 칸 진입 (능동격돌 방향 = types.md, 결산 = "## 격돌")

내 턴 종료 → 상대 턴
```

## 이동 (전투 단계)

```yaml
타입별 이동 모양 = types.md "## 6종 정의" SSOT

횟수:
  모든 등장 말 = 한 턴 1회 이동 (트리거 효과로 n회 가능)
  같은 말 같은 턴 두 번 이동 X (트리거 없으면)
  [대기] 말은 이동·격돌 불가 (등장해야 행동 — 등장한 턴부터 바로 행동)

플레이어 (전군 자유):
  대적자와 내 등장 말을 한턴에 1개를 자유롭게 움직임
  대적자를 움직이면 인물을 못 움직이고 인물을 움직이면 대적자를 못 움직임

```

## 격돌 (근접 전투)

```yaml
정의:
  근접 말이 적 칸으로 들어가려 시도할 때만 발생 (능동 진입)
  옆에 붙어만 있으면 격돌 X (자동 전투 없음)

능동 / 수동 (방향 결 = types.md):
  능동격돌 = 내가 친다: 내 타입의 능동격돌 방향만 (갈 수 있는 방향의 적만 선제공격)
  수동격돌 = 걸린다(적이 내 칸 진입): 방향 무관, 동시 교환이라 어느 방향서든 반격
    → 타입 방향 약점은 "선제 못 침"이지 "무저항" 아님

[대기] 예외 (등장 전 말):
  [대기] 말은 격돌 시 공격력 처리 X — 반격 0, 일방적으로 맞음 (= 샌드백)
  ([대기] = 코스트 미지불 상태. 깨우려면 등장(의지) — "## 배치·등장" 참조)

결산 (동시 교환):
  1. 양쪽이 공격력만큼 서로에게 피해 (반격 있음 — 단 [대기]·공격력0은 반격 0)
  2. 피해 적용 (보호막 → 방어도 → hp, "## 피해 흐름" 참조)
  3. 사망 판정 (동시)

결과 4종:
  a. 적만 죽음     → 공격자가 그 칸 차지
  b. 공격자만 죽음 → 적 제자리, 공격자 소멸
  c. 둘 다 죽음     → 빈 칸
  d. 둘 다 생존     → 둘 다 제자리 (공격자 원위치)

피해 누적:
  못 죽인 적의 깎인 체력은 그대로 유지 (턴 경과 회복 X)
  다음 격돌로 이어짐 → 1대1로 강한 말 못 잡음, 여럿이 갈아내야 함

대적자 격돌:
  대적자(킹) 공격력 0 → 반격 0 (약한 심장, 안전하게 깎임)
  무기·특기로 공격력을 가진 대적자 → 격돌 시 반격함 (= 킹 무장이 억지력)
  킹은 기본적으로 직접 못 싸움, 병력으로 지켜야 함
```

## 피해 흐름

```yaml
피해 적용 순서 (격돌 공통):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 <= 방어도 → 방어도 차감
     - 피해 >  방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 사망 → 덱에서 영구 제거 (소모성 — 배틀 복귀 X. cards.md 카드 생애)

자원 지속:
  보호막·방어도:
    기본 = 그 턴만 (턴 종료 시 정리)
    키워드·장비·기도 효과로 지속 변동 가능
    배틀 종료 시 자동 정리
  hp (일반 말):
    배틀 안 깎인 건 누적, 배틀 종료 시 정리
    생존 말 = 다음 배틀 풀피로 덱 복귀 / 사망 말 = 덱에서 영구 제거 (소모성)
  hp (대적자 = 예외):
    스테이지 단위 지속 — 배틀 끝나도 회복 X, 챕터 바뀌면 풀피
    ("## 대적자 체력 지속" 참조)

부여 결:
  보호막 = 키워드·장비·기도 효과로 부여 (일반 인물도 가능)
  방어도 = 대적자 전용 자원 (일반 인물 바닐라에 없음 — 상세 = mechanics.md)
```

## 배치·등장

```yaml
배치(놓기): 덱에서 뽑은 인물 카드를 배치 영역의 빈 칸에 놓음
  비용 없음 (공짜) · 턴당 1기 · [대기] 상태로 들어감
  배치 영역 (2군데):
    ① 대적자(킹) 인접 8칸의 빈 칸 (킹 이동 범위와 동일) — 본진 방어 전개
    ② 자기 진영 끝 2줄의 빈 칸 (맵 크기에 상대) — 측면 전개
    ※ 자기 진영 끝에서만. 순간이동 X — 적 진영까지 다시 기어 올라가야 함
  정합: 1칸 1말 (빈 칸에만)

등장(활성화): 필드의 [대기] 말에 의지(카드 cost)만큼 지불 → 깨어남
  cost 0 인 말은 의지 없이 즉시 등장 가능 / cost 있는 말은 그만큼 의지 소모
  영구 지속 (한번 등장하면 계속 활성) · 언제 깨울지 자유
  배치한 그 턴에 바로 등장 가능 — 등장한 말은 그 턴부터 행동
  등장 수 = 의지가 제한 (0코스트는 제한 없이)
  # 등장 트리거는 이 시점 발동 (트리거 7종 = mechanics.md)

[대기] 말: 등장 전 상태 — 이동·격돌 불가, 격돌 시 반격 0 (샌드백), 트리거 발동 X

오프닝 (배틀 시작 자동 배치):
  배틀 시작 시 오프닝 지정 인물이 덱에서 자동으로 배치 영역에 깔림 ([대기] 상태)
  등장 비용 = 카드 cost — 0코스트 오프닝은 첫 턴 의지 없이 바로 등장 / 그 외는 의지 소모
  수 = 설정값 (초기 1, 카드/맵 스키마 — cards.md)
  시작 손패 3장과 별개 (겹치지 않음) · 덱 드로우 풀에 미포함
```

## 멀리건·드로우

```yaml
시작 손패:
  3장 (오프닝 기물과 별개 — 오프닝은 덱에서 자동 배치, 손패엔 안 옴)

드로우:
  매 턴 시작 시 1장 (손이 천천히 참 — 한 장 한 장이 무거움)

덱 고갈 (탈진):
  소모성 — 사망 카드는 안 돌아옴 → 긴 배틀에서 덱이 마름
  덱이 빈 뒤 드로우 = 뽑을 게 없음 → 대적자 hp 탈진 피해 (장기전 강제 종결)
  배틀은 덱 고갈 전 끝나도록 짧게 설계가 기본

멀리건:
  각자 첫 턴 시작 전 1회 — 처음 받은 3장 중 교체할 카드를 개별 선택 (하스스톤 결)
    - 고른 카드를 덱에 섞은 뒤, 교체한 수만큼 새로 뽑음
    - 덱에 섞인 카드는 다시 뽑힐 수 있음 (하스스톤과 동일)
  적도 덱이라 멀리건 함 (플레이어와 동일; 시뮬은 사람이 적 멀리건 운영)
```

## 승리 조건

```yaml
승리: 적 대적자(킹) 체력 0
패배: 내 대적자 체력 0
  대적자 = 기본적으로 자체 공격력 0, 격돌당하면 깎임 (병력으로 지켜야 함)

대적자 깎기 = 격돌:
  근접 말이 대적자 칸에 진입 (대적자 공격력 0이면 일방 / 무기·특기로 공격력 있으면 반격)
  → 왕을 직접 잡으려면 그 앞 병력을 먼저 녹여야 함 (체스 메이트 결)

전투 정체성 = 킹 배치:
  두 왕의 맵상 위치·거리가 그 전투의 양상을 가름 (공격적 진격 / 방어적 농성 등)
  진형은 별도 규칙 X — BattleSetup 배치 변주 (king_layout, cards.md)
```

## 대적자 체력 지속 (스테이지 단위)

```yaml
지속 범위:
  대적자 hp = 스테이지 단위로 이어짐 (배틀 끝나도 회복 X, 다음 배틀로 누적 소모)
  챕터 바뀌면 풀피 복구
  ※ 대적자 hp만 해당. 일반 말(인물 카드)은 생존 시 배틀 사이 덱 복귀(각 배틀 풀피) / 사망 시 영구 제거
  ※ 보호막·방어도는 배틀 단위 (새 배틀 시작값 복귀 — 위 "보호막·방어도" 참조)

의미:
  "이기느냐"만이 아니라 "얼마나 안 다치고 이기느냐" = 소모 관리가 긴 축
  저소모 전략(우회·회피)이 직접 힘싸움보다 유리할 수 있음
  스테이지 후반 = hp 빠듯 (긴장) / 챕터 전환 = 풀피 (이완) → 긴장·이완 파동

회복 수단:
  - 회복 효과를 보유한 인물, 기도, 권능, 장비 카드 — 배틀 안에서 대적자 hp 회복 (죽음의 나선 완충)
  → 회복 길이 있어야 소모 관리가 '전략'이 됨 (없으면 추락 — 밸런스 핵)
```
