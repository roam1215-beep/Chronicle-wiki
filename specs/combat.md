# 전투 시스템

> Battle·Turn 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.
>
> 정체: "하스스톤을 체스판 위에서" — 체스 움직임이 바닥, 카드·공격력·체력이 그 위에 얹힘.

## 단위

```yaml
Battle: 스토리 카드 1장 = 1 전투 인스턴스
Turn:   Battle 최소 단위. 한 쪽이 자기 턴을 다 쓰고 상대 턴으로 (번갈아)
```

## 맵

```yaml
크기: 8x8 (가로 a~h / 세로 1~8). 작가가 더 넓힐 수 있음
좌표: 가로 a~h / 세로 1~8 (체스 표준)
스토리 카드(battle / fate)가 맵을 정의 (시작 시간대·맵 특수 결)

시작:
  빈 판 — 양 진영 대적자(킹)만 마주 본 채 시작
  대적자 시작 위치 = 체스 킹 위치 고정 (플레이어 e1 / 적 e8)
  일반 말은 시작 시 판에 없음 — 소환으로 전개
```

## 진영

```yaml
3 진영: 지상(surface) / 미궁(labyrinth) / 경계(border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 시간대

```yaml
3 시간대: 낮 / 경계 / 밤

진영 자기 시간대: 지상=낮 / 경계=경계 / 미궁=밤

흐름:
  매 턴 시작 시 시간대 변경
  순환: 낮 → 경계 → 밤 → 낮 ... (모의 기준. 작가가 맵별 변형 가능)
  다음 턴만 미리 보임 (예고 결)

시야 효과 (5/31 — 시간대 = 시야 개념):
  낮:   판 전체 보임 (나·적 둘 다) — 안개 없음, 정보 완전
  경계: 시야 줄고 실루엣 남음 (기존 안개 결 — 잔여 시야 ?표시)
  밤:   내 말은 보이되, 말이 제공하던 주변 1칸 시야가 사라짐
        → 말 사이 틈이 깜깜, 실루엣도 없음, 사수 효용 급감
        → 낮에 봐둔 적 위치를 기억으로 더듬어 둠
  ※ 시간이 곧 자원·긴장 — "다음 턴 밤이니 지금 쏴두자" 식 선행 판단

강림 자격 (트리거 펜딩):
  카드 태생 → 시간대 매핑 (cards.md 참조)
  카드 시간대 = 현재 시간대일 때 강림 트리거 발동 자격
  # ※ 트리거 6종 턴제 재매핑 펜딩
```

## 의지

```yaml
의지 = 카드 통화 (이동은 공짜 — 의지 X)
  매 턴 시작 시 그 턴 한도 충전
  1턴 1, 매 턴 +1, 상한 7 (이후 계속 7)
  턴 사이 이월 X (매 턴 새로 충전)

사용처 (전부 카드/자원 발동):
  - 소환 (인물 카드를 킹 8칸에)
  - 기도 카드 발동
  - 장비 부착
  - 대적자 특기 발동

이동에는 의지가 들지 않는다 (체스 통화).
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    대적자 / 일반 인물 (소환해서 판에 놓음)
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  스토리  덱이 아님 — battle / event / chance / fate (페이즈 진행 단위)

덱 구성: 인물 + 기도 + 장비
스토리 카드: 페이즈 진행 단위 (선택-거부-감내)
```

## 턴 구조

```yaml
완전 턴제 — 번갈아. 한 쪽 턴이 끝나야 상대 턴.

내 턴 시작 시 (순서):
  1. 시야 갱신
  2. 시간대 변경 (작가 정의 흐름)
  3. 의지 충전 (턴 번호만큼, 상한 7)
  4. 드로우 (1장)

내 턴 행동 (순서·횟수 자유, 의지·이동 한도 안에서):
  - 이동: 판 위 말 이동 (공짜, 말마다 1회)
  - 소환: 패에서 인물 → 킹 8칸 (의지)
  - 기도: 패에서 기도 발동 (의지)
  - 장비: 패에서 장비 부착 (의지)
  - 특기: 대적자 특기 발동 (의지, 턴 1회)

내 턴 종료 → 상대 턴
```

## 이동 (체스 문법)

```yaml
타입별 이동 모양 (cards.md 정본):
  보병 = 앞으로 1~2칸 (방향성, 격돌은 앞만) / 기수 = 룩 (직교 1~2칸)
  전령 = 비숍 (대각 1~2칸) / 사수 = 이동 1칸 가로세로
  대적자 = 킹 (8방향 1칸)
  ※ 보병·기수·전령 다 막힘(통과 X). 보병 끝줄 자폭 = "## 승리 조건" 참조

횟수:
  모든 말 = 한 턴 1회 이동 (트리거 효과로 n회 가능)
  같은 말 같은 턴 두 번 이동 X (트리거 없으면)
  소환된 턴 = 멀미 (이동 X, 트리거로 해제)

플레이어 (전군 자유):
  내 말 전부를 자유롭게 움직임 (각자 1회씩)

적 (비대칭 — 타임라인 스크립트):
  적은 카드 안 뽑음 — 맵 좌표+타임라인으로 미리 설계된 파도 ("## 적 행동" 참조)
  배틀(전투 카드)마다 작가가 스폰·이동·목표를 고유 설계
  → "전군 최적해 AI" 안 짬. 정해진 조임이 곧 퍼즐. 1인 구현·QA 검증 쉬움

1칸 1말 결 (배치·이동 시 정합 강제)
```

## 격돌 (근접 전투)

```yaml
정의:
  근접 말(보병·기수·전령 등)이 적 칸으로 들어가려 시도할 때만 발생
  능동 진입 시도일 때만 — 옆에 붙어만 있으면 격돌 X (자동 전투 없음)
  ※ 보병 = 바로 앞 칸만 격돌 (옆·대각·뒤 공격 X) → 옆구리 약점

결산 (동시 교환):
  1. 양쪽이 공격력만큼 서로에게 피해 (반격 있음)
  2. 피해 적용 (보호막 → 방어도 → hp, "## 피해 흐름" 참조)
  3. 사망 판정 (동시)

결과 4종:
  a. 적만 죽음     → 공격자가 그 칸 차지
  b. 공격자만 죽음 → 적 제자리, 공격자 소멸
  c. 둘 다 죽음     → 빈 칸
  d. 둘 다 생존     → 둘 다 제자리 (공격자 원위치)

피해 누적:
  못 죽인 적의 깎인 체력은 그대로 유지 (턴 경과 회복 X)
  다음 격돌로 이어짐 → 1대1로 강한 말 못 잡음, 여럿이 갈아내야 함

대적자 격돌:
  대적자(킹) = 공격력 0 → 격돌 시 반격으로 0을 줌
  즉 킹을 치는 적 말은 안전하게 킹을 깎음 (킹 = 약한 심장)
  킹은 직접 못 싸움, 병력으로 지켜야 함
```

## 사격 (원거리 전투)

```yaml
사수의 일방 공격 — 반격 없음
  사수는 이동 안 하므로 자기 자리 유지
  시야 안 적만 (안 보이면 사격 X)
  피해 = 보호막 → 방어도 → hp (격돌과 동일 흐름, 단 일방)
  피해 누적 (회복 X)

사격 시 노출:
  사수가 사격하면 그 사수 위치가 적에게 드러남
  → "숨어서 안전하게 쏜다"의 약점: 쏘면 들킨다
```

## 피해 흐름

```yaml
피해 적용 순서 (격돌·사격 공통):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 <= 방어도 → 방어도 차감
     - 피해 >  방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 그 배틀 사망
     # 옛 "영구 사망(퍼마데스)" 결 폐기됨. 배틀 안 사망 = 묘지 →
     #   배틀 끝 셔플 후 덱 복귀 (cards.md 카드 생애). 폐기(discard)만 영구 손실.

자원 지속:
  보호막·방어도:
    기본 = 그 턴만 (턴 종료 시 정리)
    키워드·장비·기도 효과로 지속 변동 가능
    배틀 종료 시 자동 정리
  hp:
    배틀 안 깎인 건 누적, 배틀 종료 후 회복
    0 이하 = 그 배틀 사망 (묘지 → 배틀 끝 덱 복귀)

부여 결:
  보호막·방어도 = 키워드·장비·기도 효과로 부여
```

## 소환

```yaml
위치 (2군데, 5/31 확정):
  ① 대적자(킹) 인접 8칸의 빈 칸 (킹 이동 범위와 동일) — 본진 방어 전개
  ② 자기 진영 맨 끝줄의 빈 칸 (플레이어 1열 / 적 8열) — 측면 전개
  ※ 자기 줄 끝에서만. 순간이동 X — 적 진영까지 다시 기어 올라가야 함
비용: 의지 지불 (카드 cost)
멀미: 소환한 턴엔 이동·격돌 X (트리거로 해제 가능)
장수: 한 턴 소환 수 = 의지가 제한
정합: 1칸 1말 (빈 칸에만)

킹 포위 = 중심 전장:
  적이 킹 8칸을 잠식하면 → 소환 공간 줄어듦 + 킹도 깎임 (눈덩이)
  킹 주변 공간을 누가 쥐느냐가 승부의 중심
  # 눈덩이 완충 = 뒷줄 보급선 풀지 (시뮬 후 펜딩)
```

## 시야·전장의 안개

```yaml
시야:
  타입별 결 (cards.md 참조)
  진영 공유 — 우리편 누구라도 본 칸은 다 보임
  시야 안 적 = 정보 공개 (structure.md 참조)

전장의 안개:
  시야 밖 = 안개 (적 정보 X)
  잔여 시야 = 우리편이 봤던 칸의 적 = 실루엣·? 표시
  안 보이는 적은 공격(격돌·사격) 불가

갱신:
  내 턴 시작 시 시야 갱신
  적 사수는 사격 시 위치 노출

사수 운영 결 (의도된 결):
  사수 시야 1 + 사격 2칸 = 단독으론 1칸까지만 사격
  2칸 사거리 = 부대 시야 공유로 발현 (동료 곁 또는 전열 결)
  → 사수 운영 = 시야 잘 쓰거나 전열 결 갖춰야 (강하지만 약점 있음)
```

## 적 행동 (타임라인 스크립트 — 5/31 전환)

```yaml
패러다임:
  적은 "카드를 뽑아 소환하는" 플레이어와 다른 게임을 한다.
  적 = 맵 좌표 + 타임라인으로 미리 설계된 파도.
       "T1에 (좌표)에 보병, T3에 (좌표)에 기수..." 식 스폰·행동 스크립트.
  → AI 안 짬. 작가가 배틀마다 손으로 설계 (1인 구현·QA 검증 쉬움).
  → 적의 정해진 조임이 곧 퍼즐 — 플레이어는 크로니클식 체스(카드·소환·진형)로 받아침.

비대칭:
  나  = 크로니클식 체스 (드로우·소환·진형·보병 관통)
  적  = 정해진 타임라인에 정해진 유닛이 정해진 방식으로 조여옴
  → 같은 규칙으로 두지 않는다 (STATE "적=비대칭" 정합)

설계 단위:
  배틀(전투 스토리 카드) 1장 = 고유 스크립트 1개
  각 전투 카드마다 적 스폰·이동·목표를 하나씩 고유 설계
  = 손으로 짠 시나리오/퍼즐 (매 배틀 다른 문제 → PvE 반복성 확보)

스크립트 구성 요소 (배틀마다 작가 정의):
  - 스폰 타임라인: 어느 턴 / 어느 좌표 / 어떤 타입·스탯 유닛
  - 행동 규칙: 그 유닛이 정해진 방식으로 움직임/조임 (단순·예측 가능)
  - 적 대적자: 스크립트의 한 축 (사망 시 그 배틀 승리)
  - 시간대 순환: 맵·스토리 카드가 정의 (강림 트리거와 묶임)

서사 정합 (인격 = 스크립트 톤):
  회차 인격(용기·지혜·정의)은 적 스크립트의 설계 기조로 흡수
  용기 = 저돌적으로 직진해 조임 (매복에 약함)
  지혜 = 라인 유지·지구전으로 조임
  정의 = 투시 전제(안개 무효 가정)로 조임 — 매복 안 통함
  → 같은 지점 다른 인격 = 다른 스크립트 (다른 가능세계)

# ※ 구체 스크립트는 각 전투 카드 콘텐츠에서 작가 박음 (펜딩)
```

## 멀리건·드로우

```yaml
시작 손패:
  3장

드로우:
  매 턴 시작 시 1장 (손이 천천히 참 — 한 장 한 장이 무거움)

멀리건:
  자기 첫 턴 1회 — 처음 받은 3장을 [그대로 전부] 또는 [전부 교체] 중 택1
    - 일부 교체 X (전부 받거나 전부 무르거나 — 도박적 선택)
    - 교체한 패는 다시 못 돌림
  적 = 타임라인 스크립트라 멀리건 개념 없음 (정해진 순서로 전개)
```

## 승리 조건

```yaml
승리: 적 대적자(킹) 체력 0
패배: 내 대적자 체력 0
  대적자 = 공격력 0, 격돌당하면 깎임 (병력으로 지켜야 함)
  인물 전멸 결 폐기 — 대적자 사망으로만 승부

대적자 깎는 세 길:
  1. 격돌 — 근접 말이 대적자 칸에 진입 (대적자 공격력 0이라 일방으로 깎음)
  2. 사격 — 사수가 시야 안 대적자를 사격 (일방, 반격 없음)
  3. 보병 관통 — 보병이 적 마지막 줄에 서면 적 대적자에게 보병 공격력만큼 피해 후 자동 소멸
     (나·적 동일. 자폭 타이밍 = 플레이어 선택. 공격형 보병일수록 자폭 가치 큼)
  → 직접 (격돌·사격)은 빠르나 붙어야 함 / 보병 관통은 느리나 도달만으로 (안전한 장기 투자)
```
