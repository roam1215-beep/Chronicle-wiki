# 전투 시스템

> Battle·Round 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.

## 단위

```yaml
Battle: 스토리 카드 1장 = 1 전투 인스턴스
Round:  Battle 최소 단위. 선언 → 전투
```

## 맵

```yaml
크기: 6x6 기본 (더 넓어질 수 있음, 작가 정의)
좌표: 가로 1~6 / 세로 a~f
스토리 카드(battle / fate 포함)가 맵을 정의
맵 정보 = 시작 배치·시작 시간대·맵 특수 결 (작가 정의)

시작 배치 (1라운드 선언 단계):
  적 진영: 1·2줄 (세로 자유)
  내 진영: 5·6줄 (세로 자유)
  대적자 위치 = 비밀 선언, 동시 공개, 무료
```

## 진영

```yaml
3 진영:
  지상     (surface)
  미궁     (labyrinth)
  경계     (border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 시간대

```yaml
3 시간대: 낮 / 경계 / 밤

진영 자기 시간대:
  지상 = 낮
  경계 = 경계
  미궁 = 밤

흐름:
  매 라운드 시작 시 시간대 변경
  다음 라운드만 미리 보임 (예고 결)
  순환 패턴 = 작가 정의 (맵·스토리 카드)

강림 자격:
  카드 태생 → 시간대 매핑 (cards.md 참조)
  카드 시간대 = 현재 시간대일 때 강림 트리거 발동 자격
```

## 의지

```yaml
의지 = 자원
  라운드 번호만큼 충전 (1라운드 의지 1, 2라운드 의지 2, …)
  상한 7 (8라운드 이후도 7)
  라운드 사이 이월 X (매 라운드 새로 충전)

사용처:
  - 패에서 카드 배치 (카드별 비용)
  - 특기 발동 (기본 1, 카드·키워드 결로 변동)
  - 기도 카드 발동 (카드별 비용)

1라운드 3택:
  의지 1로 셋 중 하나 선택
    - 1의지 인물 카드 배치
    - 특기 발동
    - 1의지 기도 카드 발동
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    인물 카드 — 대적자 / 일반 인물
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  스토리  덱이 아님 — battle / event / chance / fate

덱 구성: 인물 + 기도 + 장비
스토리 카드: 페이즈 진행 단위 (선택-거부-감내)
```

## 라운드 구조

```yaml
선언 단계:
  - 의지 충전 (라운드 번호만큼, 상한 7)
  - 시간대 변경 (작가 정의 흐름)
  - 양쪽 비공개 선언:
    - 인물 카드 배치
    - 기도 카드 발동
    - 특기 발동
  - 의지 차감 (선언 시점)
  - 동시 공개 → 전투 단계

전투 단계 (5 단계):

  1. 대기 단계
     1a. 양쪽 선언된 인물 카드 동시 배치
     1b. 등장 트리거 발동 (모든 등장 인물)
     1c. 강림 트리거 발동 (시간대 일치 인물)

  2. 준비 단계
     기도 + 특기 발동
     동조 트리거 발동 (각자 자기 진영 대적자 특기 시)

  3. 이동 단계
     자기 열 직진 (최대 이동력, 땅따먹기 결)
     동시 진행
     멈춤 결: 접촉 교착 + 전선 교착 (자동 진군 결 참조)

  4. 전투 단계
     4a. 타입 전투 범위 안 적 동시 공격 (시야 안 적 한정)
     4b. 피해 동시 적용 (사망 처리 전)
     4c. 치명타 트리거 발동 (0 hp 이하 되는 인물)
     4d. 사망 처리
     4e. 퇴장 트리거 발동

  5. 결산 단계
     인내 트리거 발동 (라운드 끝까지 생존)
     라운드 효과 소멸
     다음 라운드 선언으로
```

## 결산 원칙

```yaml
층 사이: 명시 순서
  5 단계의 번호 순서대로 처리
  앞 단계 끝나야 다음 단계 시작
  전투 단계 안 (4a~4e)도 안 결의 순서

층 안: 동시 적용, 결과 누적 (α 결)
  같은 단계 안의 효과는 동시 적용
  결과는 누적

배치 원칙 (새 트리거·새 카드 효과의 단계 결정 기준):
  준비 → 행동   (대기·준비 → 이동·전투)
  발생 → 반응   (피해 → 사망, 전투 단계 안)
  직접 → 간접   (공격 → 치명타)
```

## 충돌 풀이

```yaml
동시 사망 (양쪽 0 hp):
  둘 다 사망 처리 (α 결)
  단 양쪽 대적자가 동시 0 hp
    → 게임 오버 (패배)

기도·특기 효과 충돌:
  같은 인물·같은 칸·같은 자원에 작용 시
    동시 적용, 결과 누적
  음수 결과 처리:
    hp 만 0 으로 박힘
    의지·공격력 등은 음수 X (최소 0)
```

## 피해 흐름

```yaml
피해 적용 순서 (4b 단계):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 ≤ 방어도 → 방어도 차감
     - 피해 > 방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 영구 사망 (퍼마데스)

자원 지속:
  보호막·방어도:
    기본 = 그 라운드만 (라운드 종료 시 정리)
    키워드·장비·기도 효과로 라운드 지속 변동 가능
    배틀 종료 시 자동 정리
  hp:
    배틀 종료 후 회복
    0 이하 = 영구 사망 (배틀·회차 통째 X)

부여 결:
  보호막·방어도 = 키워드·장비·기도 효과로 부여
```

## 시야·전장의 안개

```yaml
시야:
  타입별 결 (cards.md 참조)
  병사·사수·기수·용병·대적자 = 시야 1
  전령                       = 시야 2 (정찰 결)
  진영 공유 — 우리편 누구라도 본 칸은 다 보임
  시야 안 적 = 정보 전부 공개 (structure.md 참조)

전장의 안개:
  시야 밖 = 안개 (적 정보 X)
  잔여 시야 = 우리편이 봤던 칸에 있던 적
    = 실루엣·? 표시
  안 보이는 적은 공격 불가
    예: 사수의 전투 범위 2칸이라도 시야 안 적이어야 쏠 수 있음

사수 운영 결 (의도된 결):
  사수 시야 1 + 전투 2칸 = 단독으로 1칸까지만 사격
  2칸 사거리 = 부대 시야 공유로 발현 (전령 곁 또는 전열 결)
  → 사수 운영 = 시야 잘 쓰거나 전열 결 갖춰야 살아남
```

## 자동 진군 (땅따먹기 결)

```yaml
일반 인물 (병사·사수·기수·전령·용병):
  기본 결:
    배치된 자기 열(세로)에서 최대 이동력으로 전진
    (타입의 이동 결과 무관 — 자동 진군은 세로 직진만)
  
  멈춤 결 (교착, 풀리지 않음):
    a. 접촉 교착: 사정거리 안 적 = 그 자리 멈춤 + 공격
    b. 전선 교착: 자기 열 앞에 자기편 = 그 자리 멈춤
    한 번 교착이면 처치될 때까지 그 자리에서 싸움
    앞쪽 자기편이 죽으면 다음 라운드부터 진군 재개
  
  시야 결:
    자기 열 결 우선 — 시야 안 적 대적자 보여도 자기 열 직진
  
  1칸 1인물 결:
    한 칸에 1명만. 배치·이동 시 정합 강제.
  
  플레이어 결로 깨는 자리 (펜딩):
    - 키워드 효과 (이동·재배치 결, 펜딩)
    - 책략 카드 (선언 단계, 펜딩)

대적자 (킹 결):
  매 라운드 선언 단계에 1칸 이동 (8방향, 무료)
  배치 가능 칸 = 대적자별 조건 (펜딩)
  특기 = 의지 1, 라운드 1회 (카드·키워드로 변동 가능)
  결판 결: 적 일반 인물 사정거리에 박히면 사망 (막다른 길)

타겟팅 우선순위:
  1. 수호 보유 적 (상태 키워드 결)
  2. 가장 가까운 적

자연 결판:
  자기 열 직진 + 교착 결로 전선 형성
  땅 좁아질수록 대적자가 적 인물 사정거리에 박힘 = 결판

결정 무게:
  플레이어 결정 = 첫 배치·추가 배치·대적자 이동·의지 분배·특기·기도·책략(펜딩)
  자동 = 일반 인물 이동·공격
```

## 배치 영역

```yaml
첫 배치 (1라운드 선언 단계):
  내 진영: 5·6줄 (세로 자유)
  대적자 위치 = 비밀 선언, 동시 공개, 무료

추가 배치 (2라운드 이후):
  배치 가능 자리 (둘 중 어디든):
    - 자기 대적자 근처 8칸
    - 시작 2칸 (5·6줄)
  1칸 1인물 결 강제 (빈 자리에만)

적 영역 침투:
  적 일반 인물의 자리 = 배치 X (1칸 1인물 결)
  배치 가능 자리는 위 후보 자리만 (영역 외 X)
```

## 멀리건·드로우

```yaml
멀리건:
  시작 1라운드만
  첫 패 3장 받은 후 1회 교체 선택
    - 3장 다 바꿈
    - 일부만 바꿈
    - 그대로 진행
  교체한 패는 다시 못 돌림

드로우:
  매 라운드 시작 시 1장
```

## 정보 공개

```yaml
예고 결:
  양쪽 다 X — 상대 선언 미리 못 봄
  대적자 첫 배치 = 비밀 선언, 동시 공개

라운드 시작 정보:
  현재 시간대
  다음 라운드 시간대 (1라운드 앞만)
  의지 잔량 (자기 진영만)

적 유닛 모형 (structure.md 참조):
  공개 = 타입(type)·시간대·hp·보호막·방어도
  대적자만 추가 공개 = 직업(class)·등급(서사)
  비공개 = 공격력·키워드 상세

시야 안에 들어와야 정보 공개:
  시야 밖 = 안개 (모름)
  잔여 시야 = 실루엣·? 표시 (마지막 본 정보)
```

## 승리 조건

```yaml
배틀 승리:
  적 대적자 사망 → 적 인물 자동 전멸

배틀 패배:
  플레이어 대적자 사망 → 우리편 자동 전멸 → 게임 오버
  양쪽 대적자 동시 사망 → 게임 오버

자연 결판:
  자기 열 직진 + 교착 결로 전선 형성
  땅 좁아질수록 대적자가 적 인물 사정거리에 박힘 = 결판
  대적자 사망 외 승리 결 X (인물 전멸 결 폐기)
```
