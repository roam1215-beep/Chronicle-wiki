# 전투 시스템

> Battle·Turn 단위 명세. 상위 단위(Order·Chapter·Stage·Phase)는
> `structure.md` 참조.
>
> 정체: "하스스톤을 체스판 위에서" — 체스 움직임이 바닥, 카드·공격력·체력이 그 위에 얹힘.

## 단위

```yaml
Battle: 스토리 카드 1장 = 1 전투 인스턴스
Turn:   Battle 최소 단위. 한 쪽이 자기 턴을 다 쓰고 상대 턴으로 (번갈아)
```

## 맵

```yaml
크기: 8x8 (가로 a~h / 세로 1~8). 작가가 더 넓힐 수 있음
좌표: 가로 a~h / 세로 1~8 (체스 표준)
스토리 카드(battle / fate)가 맵을 정의 (시작 시간대·맵 특수 결)

시작:
  빈 판 — 양 진영 대적자(킹)만 마주 본 채 시작
  대적자 시작 위치 = 체스 킹 위치 고정 (플레이어 e1 / 적 e8)
  일반 말은 시작 시 판에 없음 — 소환으로 전개
```

## 진영

```yaml
3 진영: 지상(surface) / 미궁(labyrinth) / 경계(border)

회차 안:
  플레이어 = 한 진영 고정
  적       = 적 진영 (작가 정의, 같은 진영 분파도 가능)

대적자 = 양 진영 공용 어휘
  플레이어 대적자 사망 → 게임 오버
  적 대적자 사망       → 그 배틀 승리
```

## 시간대

```yaml
3 시간대: 낮 / 경계 / 밤

진영 자기 시간대: 지상=낮 / 경계=경계 / 미궁=밤

흐름:
  매 턴 시작 시 시간대 변경
  순환: 낮 → 경계 → 밤 → 낮 ... (모의 기준. 작가가 맵별 변형 가능)
  다음 턴만 미리 보임 (예고 결)

시야 효과 (5/31 — 시간대 = 시야 개념):
  낮:   판 전체 보임 (나·적 둘 다) — 안개 없음, 정보 완전
  경계: 시야 줄고 실루엣 남음 (기존 안개 결 — 잔여 시야 ?표시)
  밤:   내 말은 보이되, 말이 제공하던 주변 1칸 시야가 사라짐
        → 말 사이 틈이 깜깜, 실루엣도 없음, 사수 효용 급감
        → 낮에 봐둔 적 위치를 기억으로 더듬어 둠
  ※ 시간이 곧 자원·긴장 — "다음 턴 밤이니 지금 쏴두자" 식 선행 판단

강림 자격 (트리거 펜딩):
  카드 태생 → 시간대 매핑 (cards.md 참조)
  카드 시간대 = 현재 시간대일 때 강림 트리거 발동 자격
  # ※ 트리거 6종 턴제 재매핑 펜딩
```

## 의지

```yaml
의지 = 카드 통화 (이동은 공짜 — 의지 X)
  매 턴 시작 시 그 턴 한도 충전
  1턴 1, 매 턴 +1, 상한 7 (이후 계속 7)
  턴 사이 이월 X (매 턴 새로 충전)

사용처 (전부 카드/자원 발동):
  - 소환 (인물 카드를 킹 8칸에)
  - 기도 카드 발동
  - 장비 부착
  - 대적자 특기 발동

이동에는 의지가 들지 않는다 (체스 통화).
```

## 카드 종류 (간략)

```yaml
4 종류 (자세한 결은 cards.md 참조):
  인물    대적자 / 일반 인물 (소환해서 판에 놓음)
  기도    의지 지불해 발동 — 직업 전용 + 중립
  장비    인물에 부착, 영구 효과
  스토리  덱이 아님 — battle / event / chance / fate (페이즈 진행 단위)

덱 구성: 인물 + 기도 + 장비
스토리 카드: 페이즈 진행 단위 (선택-거부-감내)
```

## 턴 구조

```yaml
완전 턴제 — 번갈아. 한 쪽 턴이 끝나야 상대 턴.

내 턴 시작 시 (순서):
  1. 시야 갱신
  2. 시간대 변경 (작가 정의 흐름)
  3. 의지 충전 (턴 번호만큼, 상한 7)
  4. 드로우 (1장)

내 턴 행동 (순서·횟수 자유, 의지·이동 한도 안에서):
  - 이동: 판 위 말 이동 (공짜, 말마다 1회)
  - 소환: 패에서 인물 → 킹 8칸 (의지)
  - 기도: 패에서 기도 발동 (의지)
  - 장비: 패에서 장비 부착 (의지)
  - 특기: 대적자 특기 발동 (의지, 턴 1회)

내 턴 종료 → 상대 턴
```

## 이동 (체스 문법)

```yaml
타입별 이동 모양 (cards.md 정본):
  보병 = 앞뒤 1~2칸 (세로 직진, 격돌은 앞뒤 / 좌우 X) / 기수 = 룩 (직교 1~2칸)
  전령 = 비숍 (대각 1~2칸) / 사수 = 이동 1칸 가로세로
  대적자 = 킹 (8방향 1칸)
  ※ 보병·기수·전령 다 막힘(통과 X). 인물 끝줄 점령 = "## 승리 조건" 참조
  # [2026-05-31 확정] 보병 앞뒤 이동·격돌 허용 (끝줄 점령 적 탈환 위해 뒤 격돌 필요). 좌우는 여전히 X

횟수:
  모든 말 = 한 턴 1회 이동 (트리거 효과로 n회 가능)
  같은 말 같은 턴 두 번 이동 X (트리거 없으면)
  소환된 턴 = 멀미 (이동 X, 트리거로 해제)

플레이어 (전군 자유):
  내 말 전부를 자유롭게 움직임 (각자 1회씩)

적 (대칭 — 덱 기반):
  적도 자기 덱에서 뽑아 소환·이동·격돌 (플레이어와 같은 규칙; "## 적 행동" 참조)
  적 = 적 진영 풀 (우리와 카드 풀만 다름). 적 대적자(킹) + enemy_deck.
  → 시뮬은 사람이 적을 둠. 본 게임 PvE 적 운영은 펜딩.

1칸 1말 결 (배치·이동 시 정합 강제)
```

## 격돌 (근접 전투)

```yaml
정의:
  근접 말(보병·기수·전령 등)이 적 칸으로 들어가려 시도할 때만 발생
  능동 진입 시도일 때만 — 옆에 붙어만 있으면 격돌 X (자동 전투 없음)
  ※ 보병 = 앞뒤 칸 격돌 (좌우·대각 X) → 측면(좌우) 약점

결산 (동시 교환):
  1. 양쪽이 공격력만큼 서로에게 피해 (반격 있음)
  2. 피해 적용 (보호막 → 방어도 → hp, "## 피해 흐름" 참조)
  3. 사망 판정 (동시)

결과 4종:
  a. 적만 죽음     → 공격자가 그 칸 차지
  b. 공격자만 죽음 → 적 제자리, 공격자 소멸
  c. 둘 다 죽음     → 빈 칸
  d. 둘 다 생존     → 둘 다 제자리 (공격자 원위치)

피해 누적:
  못 죽인 적의 깎인 체력은 그대로 유지 (턴 경과 회복 X)
  다음 격돌로 이어짐 → 1대1로 강한 말 못 잡음, 여럿이 갈아내야 함

대적자 격돌:
  대적자(킹) = 공격력 0 → 격돌 시 반격으로 0을 줌
  즉 킹을 치는 적 말은 안전하게 킹을 깎음 (킹 = 약한 심장)
  킹은 직접 못 싸움, 병력으로 지켜야 함
```

## 사격 (원거리 전투)

```yaml
사수의 일방 공격 — 반격 없음
  사거리 = 본인 기준 8방향(상하좌우+대각) 1칸  # [2026-06-01] 가로세로 2칸 → 8방향 1칸
  사수는 사격 (이동과 별개 행동 — 이동≠공격)
  시야 안 적만 (안 보이면 사격 X)
  피해 = 보호막 → 방어도 → hp (격돌과 동일 흐름, 단 일방)
  피해 누적 (회복 X)

사격 시 노출:
  사수가 사격하면 그 사수 위치가 적에게 드러남
  → "숨어서 안전하게 쏜다"의 약점: 쏘면 들킨다
```

## 피해 흐름

```yaml
피해 적용 순서 (격돌·사격 공통):
  1. 음수 피해 = 0 처리 (피해 없음)
  2. 보호막 (shields):
     - 이진 자원, 1번 무효 (피해량 무관)
     - 사용 시 1개 소멸
  3. 방어도 (armor):
     - 감산 자원
     - 피해 <= 방어도 → 방어도 차감
     - 피해 >  방어도 → 방어도 전부 소진 + 남은 피해 hp로
  4. hp:
     - 남은 피해 차감
     - 0 이하 = 그 배틀 사망
     # 옛 "영구 사망(퍼마데스)" 결 폐기됨. 배틀 안 사망 = 묘지 →
     #   배틀 끝 셔플 후 덱 복귀 (cards.md 카드 생애). 폐기(discard)만 영구 손실.

자원 지속:
  보호막·방어도:
    기본 = 그 턴만 (턴 종료 시 정리)
    키워드·장비·기도 효과로 지속 변동 가능
    배틀 종료 시 자동 정리
  hp (일반 말):
    배틀 안 깎인 건 누적, 배틀 종료 시 정리 (사망 말은 묘지 → 배틀 끝 덱 복귀)
  hp (대적자 = 예외):
    스테이지 단위 지속 — 배틀 끝나도 회복 X, 챕터 바뀌면 풀피
    ("## 대적자 체력 지속" 참조)

부여 결:
  보호막·방어도 = 키워드·장비·기도 효과로 부여
```

## 승리 조건

```yaml
승리: 적 대적자(킹) 체력 0
패배: 내 대적자 체력 0
  대적자 = 공격력 0, 격돌당하면 깎임 (병력으로 지켜야 함)
  인물 전멸 결 폐기 — 대적자 사망으로만 승부

대적자 깎는 세 길:
  1. 격돌 — 근접 말이 대적자 칸에 진입 (대적자 공격력 0이면 일방, 무기·특기로 공격력 있으면 반격)
  2. 사격 — 사수가 시야 안 대적자를 사격 (일방, 반격 없음)
  3. 끝줄 점령 — 인물이 적 끝줄(상대 시작 줄)에 도달해 자리잡으면, 그 다음 턴부터
     매 턴 적 대적자와 "원격 격돌"로 점령 유지 (= 관통의 점령 결, 5/31 재설계)
  → 직접 (격돌·사격)은 빠르나 붙어야 함 / 끝줄 점령은 느리나 도달 후 지속 압박

## 끝줄 점령 (관통 재설계 — 5/31 확정)

```yaml
점령 성립:
  인물(보병·기수·전령·사수 전부)이 적 끝줄(상대 시작 줄)에 이동 도달
  도달 자체로 1턴 소모 (자리잡기 = 그 턴은 격돌 없음, 멀미처럼)
  → 다음 턴부터 매 턴 적 대적자와 "원격 격돌" 발동

원격 격돌 (블루투스 격돌):
  점령 유닛 ↔ 적 대적자가 매 턴 격돌 (일반 격돌과 동일한 동시 교환 판정)
  위치 무관 — 점령 유닛이 끝줄 어느 칸에 있든, 대적자가 판 어디 있든 격돌 걸림
  대적자 공격력 0(맨몸) → 반격 0 → 점령 유닛이 일방으로 대적자 깎음
  대적자 공격력 있음(전위·전투형, 무기·특기) → 반격 → 점령 유닛도 깎임
  점령 유닛은 소멸하지 않음 (옛 "1회 자폭 후 소멸" 폐기) — 살아있는 한 매 턴 격돌

점령 탈환:
  이미 유닛 있는 칸엔 배치 X → 점령 적은 앞/뒤 인접 칸 유닛으로 격돌해 밀어냄
  보병 앞뒤 격돌 허용이 탈환 핵심 수단 (내 끝줄 점령 적을 내 보병이 뒤 격돌로 처리)

타입 결:
  보병·기수·전령 = 점령 돌파 주력
  사수 = 이동 1칸이라 끝줄 데려가기 비효율 → 본대 화력 역할로 자연 유도 (점령 강제 X)
```

승부 중심 (킹 포위 폐기 — 5/31):
  옛 "킹 포위 결판" 폐기 (끝줄 소환으로 8칸 봉쇄가 무의미해짐)
  대적자는 위 세 길(격돌·사격·끝줄 점령)로 깎여 죽음 — 포위 눈덩이 개념 없음
  끝줄 점령전 = 게임 핵심 축 (점령 vs 탈환의 줄다리기)
```

## 대적자 체력 지속 (스테이지 단위 — 5/31)

```yaml
지속 범위:
  대적자 hp = 스테이지 단위로 이어짐 (배틀 끝나도 회복 X, 다음 배틀로 누적 소모)
  챕터 바뀌면 풀피 복구
  ※ 대적자 hp만 해당. 일반 말(인물 카드)은 배틀 사이 셔플 복귀 (각 배틀 새로)
  ※ 보호막·방어도는 배틀 단위 (새 배틀 시작값 복귀 — 위 "보호막·방어도" 참조)

의미:
  "이기느냐"만이 아니라 "얼마나 안 다치고 이기느냐" = 소모 관리가 긴 축
  저소모 전략(끝줄 점령·우회, 회피)이 직접 힘싸움보다 유리할 수 있음
  스테이지 후반 = hp 빠듯 (긴장) / 챕터 전환 = 풀피 (이완) → 긴장·이완 파동

회복 수단:
  - 신상(맵 오브젝트) 상호작용 — 전투 중 회복 (펜딩: 효과·배치)
  - 정의 인격 특기 — 아군/본인 hp +1
  - event 스토리 카드 — 배틀 밖에서 대적자 hp 회복 (죽음의 나선 완충)
  → 회복 길이 있어야 소모 관리가 '전략'이 됨 (없으면 추락 — 밸런스 핵)
```
