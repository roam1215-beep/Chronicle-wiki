## 판정 언어

| 용어 | 정의 |
|---|---|
| 행동 | 활성 주사위 **전체**를 굴린다. 일부만 골라 굴릴 수 없다 |
| 다시 하기 | 미달 결과에서 참여 중인 주사위 일부·여럿·전부를 골라 재굴림. 몇 개를 굴리든 **1회** |
| 성공 | 요구 결과면 충족 |
| 실패 | 미달을 플레이어가 수용 |
| 희망 | `다시 하기` 1회의 고갈 비용을 면제 |

```yaml
희망: Episode 시작 시 1. 최대 1 — 이월·누적 없음.
난이도:
  기록 — 희망 있음
  사실 — 희망 없음
  # 최종 Fate 진입 시 고갈 처리도 난이도에 따라 갈린다 (→ ## 최종 Fate).
```

## 다시 하기

```yaml
수행 조건: 요구 미달 상태.
상한: 일반 Decision 판정 하나에서 최대 3회. 희망으로 수행한 다시 하기도 이 3회에 포함한다.
      # 이 상한은 일반 Decision 판정의 규칙이다.
      #   최종 Fate — 적용하지 않는다 (→ ## 최종 Fate).
      #   중간 Fate — 미정.

절차:
  참여 중인 주사위 중 일부·여럿·전부를 선택 → 선택한 것만 재굴림
    선택하지 않은 주사위 = 결과 유지
    선택한 주사위     = 기존 결과를 새 결과로 대체
  몇 개를 재굴림하든 다시 하기 1회.
  재굴림 결과 확인
    → 유료 다시 하기였다면 비용 정산 (성공·미달과 무관하게 반드시)
       고갈 대상 선택 → 상한 계산 → 가호 → 적용
       희망을 쓴 다시 하기는 비용이 없으므로 이 단계를 건너뛴다
    → 정산 후 현재 결과 전체로 요구 충족 여부를 확정
       성공 → 판정 종료
       미달 → 횟수가 남아 있으면 다시 선택 가능

희망:
  희망이 남아 있는 상태에서 다시 하기를 선택하면 희망을 반드시 먼저 자동 소비한다.
  희망을 보존하고 고갈을 대신 지불할 수 없다.
  희망은 그 다시 하기 1회의 고갈 비용을 면제한다.
```

## 고갈

```yaml
고갈 N: 개별 주사위에 적용. 이후 N개 Phase 동안 `행동`·`다시 하기`에 쓸 수 없다.
       단, 현재 Phase에서 새로 받은 고갈은 그 Phase 안에서 해당 주사위를
       즉시 사용 불가로 만들지 않는다.

상한: 개별 주사위의 고갈 값은 0~3만 존재한다.
      어떤 원인으로도 3을 초과하지 않는다. 초과분은 소멸한다.
      초과분을 다른 주사위로 이전하거나 예약하지 않는다.
      # 다시 하기 3회와 고갈 3은 서로 다른 규칙이다.
      #   다시 하기 3회 = 일반 Decision 판정 하나의 늘어짐 제한
      #   고갈 3        = 한 주사위를 무한 비용 대상으로 쓰는 것 제한 (Fate 포함 전역)

유지: 구조 경계에서 자동 초기화되지 않는다.

감소:
  기준은 "그 Phase에서 고갈 때문에 사용 불가였는가"다. 새 고갈을 받았는지가 아니다.
  Phase 종료 시, 그 Phase에서 고갈로 사용 불가였던 주사위의 고갈을 1 감소.
    잠긴 채 그 Phase에 추가 고갈을 받았더라도, 종료 시 현재 고갈에서 1 감소한다.
    그 Phase에서 사용 가능했던 주사위는 새 고갈을 받았더라도 종료 감소가 없다.

다시 하기 비용:
  희망 없이 다시 하기 1회를 수행하면 고갈 +1.
  재굴림 결과를 먼저 확인한 뒤, 비용을 받을 주사위 하나를 선택한다.
    비용 대상은 실제로 재굴림한 주사위일 필요가 없다.
    그 Phase에서 사용할 수 있는 주사위 중 현재 고갈 < 3인 것 하나를 고른다.
    고갈 3인 주사위에는 다시 하기 비용을 더 추가할 수 없다.
  같은 Phase에서 한 주사위에 0→1→2→3까지 몰아 중첩할 수 있다.
  유료 다시 하기의 비용은 성공·미달과 무관하게 반드시 정산한다.

카드 효과 고갈:
  이미 고갈 중인 주사위에도 중첩 가능. 개별 상한 3은 카드 효과에도 동일하게 적용.
  선택형   — 현재 고갈 3인 주사위는 유효 대상에서 제외한다.
             플레이어가 고갈 3인 주사위를 골라 부정 효과를 무효화할 수 없다.
  무작위형 — 카드가 정한 후보군에서 고갈 3인 주사위를 제거한 뒤 무작위 선택한다.
             유효 후보가 없으면 그 고갈 효과 부분은 적용되지 않는다.
  # 예) 현재 고갈 2 + 카드 고갈 3 → 최종 고갈 3. 초과분 소멸.
  # TODO: 무작위형의 기본 대상 모집단 미정.
```

## 가호 · 축복

```yaml
가호 N: 고갈이 적용되기 직전, 발생할 고갈을 N 감소 (예방).
축복 N: 이미 존재하는 고갈을 N 감소 (회복).
둘 다 필요한 만큼 부분 소비한다.

고갈 사건 처리 순서:
  ① 명목 고갈량과 대상 확정
  ② 현재 고갈과 상한 3을 기준으로 실제 적용 가능한 고갈량 계산
  ③ 그 실제 적용량에 대해 가호 사용 여부·사용량 결정
  ④ 남은 고갈 적용
  # 예) 현재 고갈 2 + 명목 고갈 3 → 실제 적용 가능 +1
  #     → 가호 1을 쓰면 최종적으로 고갈이 증가하지 않는다.
  보유량이 실제 적용량보다 적어도 부분 경감 여부를 묻는다.

축복 사용 시점:
  카드 3장 서사 공개 후, 1장을 선택하기 전에만.
  요구 결과면을 본 뒤에는 쓸 수 없다.
  → 서사를 읽고 선제적으로 거는 판단이어야 한다.
```

## 패배

```yaml
원칙:
  정확한 요구가 공개된 뒤, 현재 판정에서 사용할 수 있는 주사위로
  성공할 가능성이 전혀 없으면 즉시 패배.
  성공 가능한 결과가 하나라도 존재하면 판정은 가능하다.
  확률이 낮은 것과 불가능한 것은 다르다.

검사 기준:
  사용할 수 있는 주사위들의 실제 면 결과 조합.
  총량 산술이 아니다 — 한 주사위는 한 면만 낸다.

검사 시점: 요구 결과면 공개 직후, 행동 전.

불가능 판정 시:
  가능성 검사에서 불가능으로 판정되면 즉시 패배하며,
  행동·다시 하기 단계로 진입하지 않는다. 희망도 사용할 수 없다.
  다시 하기와 희망은 가능한 판정을 재시도하는 수단이지 불가능을 가능하게 만들지 않는다.

주사위가 0개여서 요구를 만족할 수 없는 경우도 이 규칙으로 처리한다.
  "활성 주사위 0 = 패배"라는 별도 규칙을 두지 않는다.

최종 Fate의 가능성 재검사도 동일한 검사 규칙을 사용한다. 상세 = ## 최종 Fate.
```

```text
판정 가능성 검사 — 도달 가능 상태 탐색

  상태 = 역량별 기호 수의 조합. 각 역량 값은 요구량에서 clamp (초과분은 저장하지 않는다).
  시작 = 모든 역량 0인 상태 하나.

  사용 가능한 주사위를 하나씩 처리한다:
    현재 상태 각각에 대해, 그 주사위의 실제 각 면을 더한 새 상태를 만든다.
    같은 상태는 중복 제거한다.

  요구를 충족하는 상태에 도달 가능하면 true, 아니면 false.

# 특정 전문면 배열에 종속된 별도 보충 공식은 두지 않는다.
```

## Phase 처리 순서

```text
① Phase 시작 — 주사위 상태 확정 (고갈 0 = 활성 / N>0 = 잠김)
② 결정 카드 3장 공개 — 행동·서사만. 정확한 요구와 성공·실패 결과 서사·효과는 가림. 잠긴 선택지는 잠긴 채 표시
③ 축복 사용 여부
④ 카드 1장 선택 (되돌릴 수 없음)
⑤ 요구 결과면 공개
⑥ 가능성 검사 → 불가능이면 즉시 패배
⑦ 행동 — 활성 풀 전체 굴림
⑧ 충족?
   ├ YES → 성공 확정 — 성공 결과 서사 공개. 기계 효과가 있으면 공개·적용
   └ NO  → 미달 (아직 실패 확정 아님) — 실패 결과 서사·효과는 공개하지 않는다
           → [수용] 또는 [다시 하기 — 잔여 횟수가 있을 때만 선택 가능]
             다시 하기 → 대상 선택·재굴림 → 결과 확인
                       → 유료였다면 비용 정산 (성공·미달과 무관하게 반드시)
                         고갈 대상 선택 → 상한 계산 → 가호 → 적용
                         (희망을 쓴 다시 하기는 비용 면제 — 이 단계를 건너뛴다)
                       → 정산 후 충족 여부 확정 → 성공이면 ⑧의 YES / 미달이면 ⑧의 미달 상태로 복귀
                       → 일반 Decision 판정은 최대 3회 (희망 사용분 포함).
                         소진하면 다시 하기를 고를 수 없을 뿐, 자동으로 실패가 확정되지 않는다
           → 수용 → 실패 확정 — 실패 결과 서사 공개. 기계 효과가 있으면 공개·적용
⑨ Phase 종료 — 고갈 감소 판정
```

## 정보 공개

```yaml
# 런타임 공개 순서의 정본. 가려도 납득되게 쓰는 기준 = cards.md §결정 카드 — 의미와 원칙.

선택 전:
  공개   — 그 행동이 무엇인가 (행동·서사).
  비공개 — 정확한 요구 기호.
           성공 결과 서사와 효과. 실패 결과 서사와 효과.

선택 후:
  Decision 하나를 선택·확정한 뒤 정확한 요구 기호를 공개한다.
  공개 직후 현재 사용 가능한 주사위로 가능성 검사를 하고, 가능하면 행동 판정을 수행한다.

미달:
  요구 미달은 아직 실패 확정이 아니다.
  실패 결과 서사와 효과를 공개하지 않은 상태에서 플레이어가 수용/다시 하기를 결정한다.
  다시 하기를 반복하는 동안에도, 실패를 수용하기 전까지 실패 결과는 공개하지 않는다.

확정:
  성공 확정 — 성공 결과 서사를 공개하고, 기계 효과가 있다면 공개·적용한다.
  실패 확정 — 실패 결과 서사를 공개하고, 기계 효과가 있다면 공개·적용한다.

숙련:
  반복 플레이로 서사와 요구·결과 사이의 패턴을 학습하는 것은 의도된 숙련이다.
```

## 최종 Fate — 판정이 발생하는 경우

> Fate의 의미·중간 Fate = `specs/cards.md` §운명 카드. 여기선 판정 규칙만.

```yaml
진입 처리:
  기록(보통)   — 보유한 모든 주사위의 고갈을 0으로 만든다.
  사실(어려움) — 기존 고갈을 그대로 유지한다.
  이 처리는 고갈만 다룬다. 희망·가호·축복 등 다른 자원의 자동 회복을 뜻하지 않는다.

다시 하기:
  일반 Decision의 3회 상한을 적용하지 않는다.
  # 최종 Fate 자체의 다시 하기 상한 유무는 미정.

유료 다시 하기:
  ① 재굴림
  ② 결과 확인
  ③ 성공·미달과 무관하게 고갈 비용과 가호를 정산
  ④ 성공이면 성공으로 종료
  ⑤ 여전히 미달이면 실제로 고갈을 받은 주사위를 다음 시도부터 제외
     가호가 고갈을 전부 막았다면 그 주사위는 제외되지 않는다.
  ⑥ 남은 풀로 가능성 검사 (§패배 — 동일한 검사 규칙)
```
