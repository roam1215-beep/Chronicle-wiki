## 역량 — 다섯, 전부 주사위

```yaml
힘 · 민첩 · 지식 · 지혜 · 행운

관리 자원(HP·건강) 없음. 역량은 곧 주사위이고, 주사위의 가용 상태가 곧 인물의 상태다.
행운도 다른 넷과 동등한 역량 — 와일드 아님.
```

## 주사위 — 6면, 공통 5 + 별면 1

```yaml
모든 주사위: [힘 · 민첩 · 지식 · 지혜 · 행운] + 별면 1
별면 = 그 주사위 종류의 역량 2개. (힘 주사위의 별면 = 힘 2)

종류 5:
  힘 주사위   [힘 민첩 지식 지혜 행운 · 힘★]
  민첩 주사위 [힘 민첩 지식 지혜 행운 · 민첩★]
  지식 주사위 [힘 민첩 지식 지혜 행운 · 지식★]
  지혜 주사위 [힘 민첩 지식 지혜 행운 · 지혜★]
  행운 주사위 [힘 민첩 지식 지혜 행운 · 행운★]

실패면 없음 — 요구에 맞지 않는 면이 곧 실패다.
어떤 주사위도 모든 역량을 낼 수 있다. 종류는 확률 편향일 뿐 배타가 아니다.
```

## 인물 = 시작 주사위 구성

```yaml
인물의 변주는 별도 스탯이 아니라 시작 주사위 구성 그 자체다.
  용맹한 테오도라   : 힘 2 · 민첩 1
  지혜로운 테오도라 : 지혜 2 · 민첩 1
# 구체 구성 = content/. 이 문서는 형식만 정의.
```

## 판정 언어

| 용어 | 정의 |
|---|---|
| 행동 | 활성 주사위 **전체**를 굴린다. 일부만 골라 굴릴 수 없다 |
| 다시 하기 | 미달 결과에서 일부 또는 전체를 재굴림. 주사위 단위가 아니라 **1회 단위** |
| 성공 | 요구 결과면 충족 |
| 실패 | 미달을 플레이어가 수용 |
| 희망 | 고갈 없이 `다시 하기`를 1회 수행 |

```yaml
희망: Episode 시작 시 1. 최대 1 — 이월·누적 없음.
난이도:
  기록 — 희망 있음
  사실 — 희망 없음
```

## 고갈 — 유일한 자원

```yaml
고갈 N: 개별 주사위에 적용. 이후 N개 Phase 동안 `행동`·`다시 하기`에 쓸 수 없다.

유지: Episode·Chapter를 넘어도 유지. 새 Chapter 첫 Phase에도 그대로.

감소:
  Phase 종료 시, 그 Phase에서 고갈로 판정에 참여하지 못한 주사위의 고갈을 1 감소.
  그 Phase에 실제로 사용한 주사위는 감소하지 않는다.

누적:
  다시 하기 고갈 — 같은 Phase 안에서는 한 주사위에 몰아 쌓을 수 있다 (그 Phase에선 계속 사용 가능).
                   다음 Phase부터, 이미 고갈 중인 주사위에는 얹을 수 없다.
                   → 비용은 현재 활성인 주사위가 받는다.
  카드 효과 고갈 — 기존 고갈에 중첩 가능.
                   대상: 선택형(플레이어가 고름) / 무작위형(카드가 지정)

비용 시점:
  다시 하기는 성공해도 비용을 낸다. 희망을 쓴 다시 하기만 고갈이 없다.
```

## 가호 · 축복

```yaml
가호 N: 고갈이 적용되기 직전, 발생할 고갈을 N 감소 (예방).
축복 N: 이미 존재하는 고갈을 N 감소 (회복).
둘 다 필요한 만큼 부분 소비한다.

가호 사용 시점:
  고갈 원인 확정 → 대상 주사위 확정 → 고갈량 확정 → "사용합니까" → 감소 → 남은 양 적용
  보유량이 고갈량보다 적어도 부분 경감 여부를 묻는다.

축복 사용 시점:
  카드 3장 서사 공개 후, 1장을 선택하기 전에만.
  요구 결과면을 본 뒤에는 쓸 수 없다.
  → 서사를 읽고 선제적으로 거는 판단이어야 한다.
```

## 패배

```yaml
요구 심볼 총량 > 활성 주사위 수 이고, 부족분을 별면으로 메울 수 없으면 즉시 패배.

  활성 수 ≥ 요구 총량  → 가능 (확률이 낮을 뿐)
  활성 수 < 요구 총량  → 모자란 만큼 별면이 필요. 별면은 자기 역량에만 쓰이므로
                         해당 종류 주사위를 보유해야 성립.

검사 시점: 요구 결과면 공개 직후, 행동 전.
이 판정에는 다시 하기도 희망도 쓸 수 없다.
  (다시 하기는 가능한 판정을 재시도하는 기능이지, 불가능을 가능으로 만들지 않는다)
```

## Phase 처리 순서

```text
① Phase 시작 — 주사위 상태 확정 (고갈 0 = 활성 / N>0 = 잠김)
② 결정 카드 3장 공개 — 서사·행동만. 요구·효과 가림. 잠긴 선택지는 잠긴 채 표시
③ 축복 사용 여부
④ 카드 1장 선택 (되돌릴 수 없음)
⑤ 요구 결과면 공개
⑥ 가능성 검사 → 불가능이면 즉시 패배
⑦ 행동 — 활성 풀 전체 굴림
⑧ 충족?
   ├ YES → 성공 서사·효과 공개·적용
   └ NO  → [수용] 또는 [다시 하기]
            다시 하기 → 일부/전체 재굴림 → 결과 확인
                      → 고갈 대상 선택 → 가호 → 고갈 적용 → ⑧로
⑨ Phase 종료 — 고갈 감소 판정
```

## 정보 공개

```yaml
카드 제시: 서사와 행동만.
가림:     요구 결과면 · 성공 효과 · 실패 효과.
공개:     카드 선택 후 요구 결과면 / 결과 확정 후 해당 서사·효과.

원칙: 숨긴 요구와 효과는 카드 서술로부터 인과적으로 납득 가능해야 한다.
      반복 플레이로 "이런 사건엔 이런 결과가 있다"를 익히는 것은 의도된 숙련.
```
