# 타입 (Type) — 체스말 결

> 말이 **어떻게 움직이고 어떻게 싸우는가**의 단일 정본.
> 이동·격돌·페이즈 흐름의 SSOT. 능력치 수치는 cards.md "## 능력치 기준선" 참조.
> [2026-06-06 신설] 사수 타입 폐기 → 사격은 키워드(사냥꾼 직업색). 타입 정의를 cards/STATE/combat에서 이 문서로 단일화.

## 설계 원칙

```yaml
- 타입 = 이동하는 모양 (체스 기물의 명료함). 카드 = 그 말의 영혼 (능력치·키워드 = 덱빌딩 개성).
- 강점엔 약점을 박는다 — 강점만 있는 말은 만들지 않는다 (균형의 핵).
- 전진·후퇴 개념 X (대적자·기수·전령·척후는 후퇴 가능) — 매 턴 어느 말을 움직일지 일일이 선택.
- 위협 위계 = 기동 도달성에서 (화력 아님). 보병이 바닥 고정점, 대적자가 천장 고정점.
- 사거리 어휘 폐기 — 타입 자체가 거리.
```

## 6종 정의

```yaml
보병   soldier   — 폰 결 (전선의 핵)
  이동:    앞으로만 1~2칸 (후퇴 불가, 막힘 — 통과 X)
  능동격돌: 앞 · 앞 좌우대각 · 뒤 (뒤는 탈환 전용 — 자리는 안 떠나고 등 뒤 적을 침)
  약점:    비가역 — 한번 민 줄은 못 무름 (전진은 신중한 약속)
  계수:    ×3 (느리고 두꺼움)
  역할:    정면 압박 · 전선 고정 · 본대 결전

기수   rider     — 룩 결 (빠른 기동)
  이동:    직교(상하좌우) 1~3칸 (후퇴 가능, 막힘 — 통과 X)
  능동격돌: 가는 길(직교)
  약점:    얇은 스탯(계수 ×2.5, 잘 죽음) — 정면 힘싸움 약함, 치고 빠지기용
  역할:    빠른 기동 · 유인 · 측면 견제

전령   herald    — 비숍 결 (기동 에이스)
  이동:    대각 1~3칸 (후퇴 가능, 막힘 — 통과 X)
  능동격돌: 가는 길(대각)
  약점:    얇은 스탯(계수 ×2.5) + 고코스트(희소) — 귀한 기동 에이스
  역할:    대각 돌파 · 유인 · 결정타

척후   scout     — 나이트의 변주 (세로 침투)
  이동:    세로(앞뒤)로만 1~2칸 + 바로 앞/뒤 한 말(적·아군 무관) 하나만 넘음
  착지:    넘은 너머 빈 칸만 (넘은 자리 막혀 있으면 멈춤). 대기 없음 (넘은 턴 바로 활동)
  시야:    착지할 칸이 보여야 넘음 — 안 보이면 불가 (밤에도 보이면 가능)
  능동격돌: 세로(앞뒤)
  약점:    세로만(가로·대각 X) + 한 겹만(두 겹 벽 못 뚫음) + 느림 + 약한 스탯 + 시야 의존
  역할:    세로축 한 겹 침투 — 보병과 한 쌍 (보병이 못 넘는 벽을 척후가 넘음). 앞뒤 다 넘어 탈환에도 쓰임
  # 명칭 척후(斥候) = 본대보다 앞서 적진에 드는 선행병 (작품 결).

대적자 adversary — 킹 결 (본대 중심)
  이동:    8방향 1칸
  능동격돌: 8방향 (공격력 0 → 반격 0, 약한 심장)
  약점:    공격력 0 (직접 못 싸움) + 죽으면 게임 끝
  역할:    지켜야 할 심장 (병력으로 지킴). 단 카드별 attack 가능 (전투형)
  # 대적자 카테고리 = 이 타입 강제 (정합). hp 위계 = cards.md.
```

## 격돌 — 능동 / 수동

```yaml
격돌 = 근접 말이 적 칸에 진입하는 동시 교환. 두 얼굴:

능동격돌 (내가 친다):
  내 타입의 능동격돌 방향만 — 갈 수 있는(혹은 지정된) 방향의 적만 선제공격
  타입별 능동격돌 방향 = 위 6종 정의 참조

수동격돌 (걸린다 = 적이 내 칸에 진입):
  방향 무관 — 동시 교환이라 어느 방향에서 와도 내 공격력으로 반격
  즉 타입의 방향 약점은 "선제 못 치는 방향"이지 "무저항"이 아님
  (예: 척후는 가로의 적을 먼저 못 치지만, 가로에서 쳐오면 반격은 함)

결산·결과 4종·피해 흐름 = combat.md "## 격돌" SSOT
```

## 막힘 · 시야

```yaml
막힘: 척후를 뺀 전 타입 — 앞에 말 있으면 그 앞에서 멈춤 (통과 X)
  척후만 예외 — 바로 앞/뒤 한 말을 넘음 (단 한 겹, 시야 조건)
시야: 진영 공유 — 우리편 본 칸은 다 보임. 시야 = 시간대 (combat.md "## 시간대" SSOT)
  이동 자체엔 시야 불필요 (안 보이는 칸으로도 이동 — 막힘만 적용)
  예외: 척후 통과(착지 칸 시야 필요) · 사격(시야 안 적만) · 단일 조준 기도/책략
```

## 사격 — 타입 아닌 키워드 (사냥꾼 직업색)

```yaml
# [2026-06-06] 사격은 더는 타입(구 사수)이 아님 — 키워드로 분리, 사냥꾼이 그 계열 직업색.
사격: 1칸 범위(8방향)의 적에게 일방 공격 (반격 X) · 시야 안 적만 · 사격 시 노출(밤 제외)
  키워드/특기로 부여 — 어떤 타입이든 사격 키워드를 가지면 쏠 수 있음
  사냥꾼 대적자 특기·사냥꾼 풀에 집중 (직업색)
  상세 = combat.md "## 사격" · cards.md "키워드 시스템"
```

## 한 턴의 모양 — 배치 / 전투 2페이즈

```yaml
# [2026-06-06] 한 턴을 두 페이즈로 — 동시 결정 부하를 절반으로 (복잡도 관리).
#   배치 = 의지 통화 / 전투 = 이동 통화. 두 통화가 한 턴 안에서 시간순으로 펼쳐짐.

내 턴 시작:  시야 갱신 → 시간대 변경 → 의지 충전 → 드로우
배치 페이즈 (의지 통화):
  소환 · 기도 · 책략 · 장비 · 특기
  소환·배치한 말은 [대기] (이 턴 전투 페이즈에 안 움직임 — 돌격 키워드로 해제)
  특기: 여기서 발동 (상태를 켬 — 예: "이번 턴 사격 가능", "방어도 +1")
전투 페이즈 (이동 통화):
  이동 · 격돌 · 사격 (배치에서 켠 상태를 여기서 씀)
내 턴 종료 → 상대 턴

# 턴 구조 상세·드로우·멀리건 = combat.md "## 턴 구조" SSOT
```
