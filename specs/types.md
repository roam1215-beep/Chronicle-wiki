# 타입 (Type)

> 인물 카드가 **어떻게 움직이고 어떻게 싸우는가**의 단일 정본 (이동·격돌과 관련된 규칙).
> 안 쥔 것: 능력치 수치·타입 계수 → specs/mechanics.md / 전투 결산 → combat.md.

## 6종 정의

```yaml
보병   soldier   — 폰 (전선)
  이동:    앞으로만 1~2칸, 빈 칸만 (후퇴 불가 · 앞 막히면 멈춤)
  능동격돌: 대각 앞 1칸만 (이동과 갈림 — 직진하되 대각 앞으로 잡음, 폰 결)
  약점:    비가역(민 줄 못 무름) · 정면 적 못 침 (대각으로만)
  역할:    정면 압박 · 전선 고정

전차   chariot   — 룩에 가까운 역할 (빠른 기동)
  이동:    직교(상하좌우) 1~3칸 (후퇴 가능, 막힘 — 통과 X)
  능동격돌: 가는 길(직교)
  약점:    얇은 스탯(잘 죽음) — 정면 힘싸움 약함, 치고 빠지기용
  역할:    빠른 기동 · 유인 · 측면 견제
  # 옛 명칭 '기수'(rider) → '전차'(chariot) 개명. 규칙 동일.

신관   cleric    — 비숍 결 (기동 에이스)
  이동:    대각 1~3칸 (후퇴 가능, 막힘 — 통과 X)
  능동격돌: 가는 길(대각)
  약점:    얇은 스탯 + 고코스트(희소) — 귀한 기동 에이스
  역할:    대각 돌파 · 유인 · 결정타

기수   cavalry   — 나이트 (도약 침투)
  이동:    L자 (직2·횡1 또는 횡2·직1), 도약 — 사이 말 전부 넘음 (아군·적·[대기] 무관)
  착지:    빈 칸이면 이동 / 적 있으면 격돌 진입 / 아군 있으면 X
  능동격돌: 착지 지점(L자 끝)
  약점:    제자리·인접 위협 약함 · 도약 뒤 고립
  역할:    벽 너머 침투 · 기동

전령   herald    — 퀸 (8방향 에이스 · 전설 전용)
  이동:    8방향(직교+대각) 1~3칸 (후퇴 가능, 막힘 — 통과 X)
  능동격돌: 가는 길(8방향)
  약점:    전설 = 덱당 1장 (희소) · 잃으면 큰 손실
  역할:    만능 기동 에이스 · 추격
  # 전설 등급 전용 — 전설 ↔ 전령 양방향 강제 (cards.md 등급 정합)

대적자 adversary — 킹 결 (본대 중심)
  이동:    8방향 1칸
  능동격돌: 8방향 (공격력 0이면 반격 0 = 약한 심장 / 무기·버프로 공격력 가지면 반격함)
  약점:    공격력 0 (직접 못 싸움) + 죽으면 게임 끝
  역할:    지켜야 할 심장 (병력으로 지킴). 단 카드별 attack 가능 (전투형)
  # 대적자 카테고리 = 이 타입 강제 (정합). hp 위계 = cards.md.
```

## 격돌 — 능동 / 수동

```yaml
격돌 = 근접 말이 적 칸에 진입하는 동시 교환. 두 얼굴:

능동격돌 (내가 친다):
  내 타입의 능동격돌 방향만 — 갈 수 있는(혹은 지정된) 방향의 적만 선제공격
  타입별 능동격돌 방향 = 위 6종 정의 참조

수동격돌 (걸린다 = 적이 내 칸에 진입):
  방향 무관 — 동시 교환이라 어느 방향에서 와도 내 공격력으로 반격
  즉 타입의 방향 약점은 "선제 못 치는 방향"이지 "무저항"이 아님
  (예: 보병은 대각 앞 외에는 먼저 못 치지만, 어느 방향서 쳐오든 반격은 함)

[대기] 예외: 등장 전([대기]) 말은 격돌 시 공격력 처리 X — 반격 0, 일방적으로 맞음 (= 샌드백)
  ([대기] = 코스트 미지불 상태. 배치·등장 = combat.md "## 배치·등장" SSOT)

결산·결과 4종·피해 흐름 = combat.md "## 격돌" SSOT
```

## 막힘

```yaml
막힘: 기수를 뺀 전 타입 — 앞에 말 있으면 그 앞에서 멈춤 (통과 X)
  기수만 예외 — L자 도약 (사이 말 전부 무시, 착지칸만 비면 됨)
이동 자체에 시야 불필요 — 시야 시스템 폐기 (판 전체 항상 보임)
```

## 한 턴의 모양 — 의지 / 전투 2단계

```yaml
# 한 턴을 두 페이즈로 — 동시 결정 부하를 절반으로 (복잡도 관리).
#   의지 단계 = 의지 통화 / 전투 단계 = 이동 통화. 한 턴 안에서 시간순으로 펼쳐짐.

내 턴 시작:  시간대 변경 → 의지 충전 → 드로우
의지 단계 (의지 통화):
  배치(놓기) · 등장(활성화) · 기도 · 권능 · 장비 · 특기
  배치(놓기):    덱에서 뽑은 인물을 판에 놓음 — 공짜, 턴당 1기, [대기] 상태로 들어감
  등장(활성화):  [대기] 말에 코스트(의지) 지불 → 깨어남 (영구). 등장한 말은 그 턴 전투 단계부터 바로 행동
  특기:          여기서 발동 (상태를 켬 — 예: "방어도 +1")
전투 단계 (이동 통화):
  이동 · 격돌
내 턴 종료 → 상대 턴

# 턴 구조 상세·드로우·멀리건·배치/등장 = combat.md "## 턴 구조" SSOT
```
