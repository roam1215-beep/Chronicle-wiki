# 게임 구조

## 5층

```yaml
Hierarchy:
  Order:     인물 1명의 호 (확장팩 단위, 270 기록 카드)
  Chapter:   큰 마디 (진행 단위, 카드 그릇 X)
  Stage:     중간 마디 (10장 = 9 일반 + 1 운명)
  Phase:     카드 시스템 (3장 또는 운명 1장)
  Battle:    전투 인스턴스 (1 전투 카드 = 1 Battle)
  Turn:      Battle 최소 단위 (번갈아 — 턴제 체스)
```

## 카드 단위 (콘텐츠 그릇)

```yaml
Order (작품 그릇) = 270 기록 카드
  └─ 3 인격 팩 × 90장

PersonaPack (한 회차) = 90장 = 9 스테이지 × 10장
  = 81 일반 + 9 운명

Stage = 10장 = 9 일반 + 1 운명
Phase 카드 = 3장 (일반 페이즈) 또는 1장 (운명 페이즈)

챕터 = 진행 단위로만 (카드 그릇 X)
인물 카드 = 카드 그릇 밖 (영구 컬렉션)
```

## Phase 진행 (선택-버림-감내)

```yaml
PhaseType:
  - normal:  3장 (선택·버림·감내)
  - fate:    1장 (운명 카드)

normal_phase_flow:
  1. 3장 unknown 노출:  [Chronicle][Chronicle][Chronicle]
  2. 한 번에 한 장만 터치 → back 공개 (종류 문양 드러남). 터치 = 취소 불가.
     - 열린 카드를 결단(선택/버림)하기 전엔 다른 카드 잠김 (동시 비교 X)
     - chance(우연)는 자기 back 없음 → 사건/전투 back 중 런타임 랜덤 위장
  3. 결단: 버림 1 · 선택 1 (각 최대 1장). 남은 1장 = 감내 (자동).
     - 버림: 즉시 "알려지지 않은 이야기"로 (unknown 그대로 — 정체 비공개, 영구 회피)
     - 선택: back 상태로 유지 (front 안 펼침 — 내용은 진행 때 공개)
     - 감내: 버림·선택 둘 다 끝나면 남은 1장이 자동 확정 (unknown 대기)
  4. 버림1·선택1 차는 즉시 진행 (별도 확정 버튼 X):
     - 선택 (back → front 공개·진행)
     - 감내 (unknown → front 공개·진행)
     # 버림은 이미 더미로 빠짐 (발화 순서: 버림 → 선택 → 감내)
  5. 비가역

뒷면(면) 3종:
  unknown:  공통 가림 — 검은 바탕 + "Chronicle". 무엇이 나올지 모름 (우연도 안 들킴)
  back:     종류 문양 — 사건(녹)·전투(빨). 우연은 자기 back 없이 사건/전투로 위장
  front:    앞면 전체 — 세부 공개 (title·그림·desc·quote·effect). 우연은 여기서 정체(문양 ?)
  (시각 참고: design/card_mockup.html)

기록 카드 5종 역할 (effect 발생 = cards.md "## 기록 카드 effect"):
  origin:  도입 컷씬 (오더 시작 1회, 페이즈 밖)
  battle:  전투 — 일반 대적자전 (적 hp10·얇은 덱). 승리 -> 일반 조우
  event:   비전투 확정 사건 -> 인연 / 교차 / 헤어짐 (1~2개 복합)
  chance:  위장된 우연 -> 행운(일반 성장) / 불운(시련, 뚫으면 일반 조우)
  fate:    스테이지 보스 -> 일반 조우+일반 성장 / 챕터 보스(3·6·9) -> 특수 조우+특수 성장

카드 성격 (페이즈 긴장 — 매 선택이 상태 의존):
  battle: 확실한 리스크(대적자 체력↓) ↔ 확실한 수급(승리 시 드래프트). 강해지려면 치러야.
  event:  전투는 확실히 회피. 단 이로운(hp 회복·강화)~해로운(전력 손실·체력↓) 폭 — 터치 전 모름.
  chance: 전투/사건으로 위장된 변수 — 신중한 계산에 끼어듦.
  → 페이즈 = 체력 걸고 벌까 / 안전하되 손해 감수 / 도박 의 3중 선택

최대 2 Battle 발생 / Phase
```

## 기록 카드 셔플 (런 구성)

```yaml
# 런 시작 시 그 인격 팩(90장)이 어떤 순서·조합으로 펼쳐지는가.

고정점 (2개뿐):
  - 오더 시작        = 기원 카드 1장 (1회, stage1 페이즈1 맨 앞에만 — 페이즈 밖)
  - 각 스테이지 끝    = 운명 카드 1장

자유 구간 = 스테이지당 일반 9장:
  - 순서 셔플: 매 런 다른 순서로 노출 (스테이지 순서 자체는 서사 고정 — 못 섞음)
  - 존재 고정 + 순서 자유: 척추 사건(예: 패잔병 전투)은 반드시 등장하되, 몇 번째일지는 런마다 다름
  - 곁가지 변주: event·chance 일부는 후보 풀에서 표집 → "알려지지 않은 이야기"가 다음 런에 나올 수 있음
    (enemy_decks의 core+variable 발상과 동형 — 척추 core, 곁가지 variable)

작성 제약 (★ 기록 카드 작성의 핵심 규칙):
  일반 카드 = 인과 사슬(A→B) X. 같은 시공간의 병렬 사건 단위 O.
  어떤 순서로 와도 그 스테이지의 이야기가 되도록.
  (서사시환 단편처럼 — 사건의 나열이 그 날의 기록을 이룸)
```

## 보상 & 성장 (effect 발생)

```yaml
# effect 정본·내용 = cards.md "## 기록 카드 effect". 여기선 발생 흐름·편성만.

드래프트(조우) = 3장 제시 -> 1택 (메커니즘). 풀 = 해당 오더 직업 고유 + 중립. 계통 제한 없음.

발생:
  battle 승리              -> 일반 조우
  fate 승리 (스테이지 보스)   -> 일반 조우 + 일반 성장
  fate 승리 (챕터 보스 3·6·9) -> 특수 조우 + 특수 성장
  event                    -> 인연 / 교차 / 헤어짐 (1~2개 복합)
  chance 행운              -> 일반 성장
  chance 불운              -> 시련 (뚫으면 일반 조우)

조우 등급: 일반(common~epic, 3장 같은 등급 도배 X) / 특수(legendary)
조우 스킵: 가능 (0장 허용) — 단 최초 편성 조우만 불가
덱 상한: 전설 = 같은 카드 1장 / 영웅·희귀·보통 = 같은 카드 2장 (고정 5장도 카운트)
  상한 도달 카드 = 제시 X / 거른 카드 = 재출현 가능
성장: 일반(공·체·첫턴) / 특수(특기·드로우·의지, 챕터 보스 전용) — 상세 cards.md
```

## 편성 시점

```yaml
오더 진입 -> 기원 카드 1회 (도입) -> 고정 5장 노출 -> 최초 조우 (일반·스킵 불가·1택 x5) -> 시작 덱 10장 -> Stage1 Phase1

고정 5장 (전 오더 공통, 직업별 동일 — 커브 분산 + 아키타입 비유도):
  1코  라코니아 풋내기 용사 (보병) · 도리아군 공용 무기 (장비)
  2코  대지의 포옹 (기도) · 약속의 징표 (기도)
  3코  산골짜기 길잡이 (기수)
```

## 인격 (Order 단위)

```yaml
인격 시스템: 그리스 4주덕
  pool: [wisdom, courage, temperance, justice]
  인물 = 3 인격 보유, 1 빠짐
  빠진 1 = 정체성

한 회차 = 1 인격 팩 (90장)
같은 지점(챕터·스테이지) 다른 인격 = 다른 가능세계
챕터·스테이지 명명도 인격마다 다를 수 있음
```

## 카타스테리스모스 (작품 결)

```yaml
Order 클리어 시:
  주연 영웅 → 별이 됨 (별자리)
  카타스테리스모스 = 작품 결의 본질
  도서관에 별자리로 박힘 (해금)

데이터 결:
  rank 결 폐기 — 게임 데이터로는 X
  작품 결로만 살아남 (서사·세계관)
  카드 데이터의 변동 X
```

## 정보 공개 (적 유닛)

```yaml
공개:
  - type (타입 아이콘): 보병 / 사수 / 기수 / 전령 / 용병 / 대적자
  - own_time (시간대 아이콘)
  - attack · defense · hp (능력치 전부)
  - shields_count
  - keywords (효과·키워드 상세)
  - class (대적자만 — 직업 아이콘 7종) · tier (등급)

조건:
  시야 안 = 위 정보 전부 공개 (적·대적자 구분 없이 카드 정보 전부)
  시야 밖 = 안개 (정보 X)
  잔여 시야 = 실루엣·? 표시

아군은 항상 정확한 숫자 다 보임 (hp + 보호막 + 방어도)
```

## 진행 흐름

```yaml
게임 시작:
  도서관 → 인물 책 클릭 → 책 펼침
  → 인격 선택 (해금 풀에서)
  → 인물 소개
  → [편성] 고정 5장 노출 → 최초 조우 (일반·스킵 불가·1택 ×5) → 시작 덱 10장
  → Chapter 1 → Stage 1 → Phase 1 → Battle 1 → Turn 1 → ...

Order 완료:
  정사 기록 → 도서관 복귀 (진척도 +1)
  영웅 등극 = 카타스테리스모스

Order 실패:
  미기록 ("쓰여지지 않았다")
  빈 상태 복귀

Order 순서: 순차 강제 (Order N 완료 시 N+1 해금)
재플레이: 완료 Order → "현재의 정사가 야사로 내려갑니다" 경고 후 가능
런 슬롯: 1 (동시 진행 1 Order)
```

## 종료 조건

```yaml
승리:     적 대적자(킹) 체력 0
패배:     내 대적자(킹) 체력 0 = 주연 영웅 사망 (테오도라 등 is_protagonist=true)
  대적자 = 공격력 0, 격돌당하면 깎임 (병력으로 지켜야 함)
  인물 전멸 결 폐기 — 대적자 사망으로만 승부 (combat.md 정본)
철수 X
```
