```yaml

트리거는 공장 고정(7종), 효과는 자유 조립 — 둘이 끼워져 카드가 양산된다.

  후속 오더 보류분(정의 보존·오더1 미사용) = ## 후속 오더 보류
```

## 트리거 (언제 발동 — 7종 고정)

```yaml
등장:  [대기] 말이 활성화(코스트 지불)되는 즉시 — combat.md "## 배치·등장"
퇴장:  사망하는 즉시 (적 턴에도). 그 칸이 비워진 뒤 효과 발동
       ※ [대기] 말은 등장한 적 없으므로 사망해도 퇴장 발동 X
개시:  내 턴 시작 시 (여럿이면 컨트롤러가 순서 선택) — 등장한 말만
종료:  내 턴 종료 시 — 등장한 말만
처치:  대적자 제외 적 인물을 직접(격돌) 처치하고 살아남으면 (적 턴에도). 동시 사망 시 불발
동조:  자기 진영 대적자 특기 발동 직후 — 등장한 말만
인도:  카드 태생 시간대가 될 때 — 그 시간대 창에만 효과 켜짐, 매 순환 반복

# 효과 내용·수치는 트리거에 안 묶임 — 아래 효과로 자유 조립.
# 트리거 간 동시 발동 우선순위 = 펜딩 (시뮬에서 확정).
# [대기] 말은 어떤 트리거도 발동 안 함 (등장 전이므로).
```

## 상태 (상시 성질 — 6종 + [대기])

```yaml
신속:  이동력 +1칸 (방향은 타입 고유 유지). [대기]는 해제 X (등장해야 행동)
신성:  단일 지정 기도(target: one) 면역 (적·아군 모두). 책략(칸 지정)엔 적중
       → 단일 지정 면역이라 아군 버프(회복 등)도 못 받음
고정:  배치된 위치에서 이동 불가 (자기 디메리트 — 점수 음수)
잠:    배치 후 적에게 공격받기 전까지 고정(이동 불가). 적에게 한 번이라도 공격받으면 그 후 이동 가능(깨어남)
       → [고정]과 달리 해제 조건 있음. 깨우기 전엔 벽, 깨우면 위협 (잠자는 동굴 곰)
패시브: 이 카드가 등장 상주하는 동안 트리거 없이 늘 켜지는 고유 효과 (단일·특정 대상 — 자기 또는 지정 1체). 퇴장(사망)·[대기] 전환 시 해제.
오라:   패시브의 범위판 — 주변·지정 범위의 여러 아군(또는 그 행동)에 상시 적용. 범위 안에 새로 등장·진입하는 말에도 지속 적용, 퇴장 시 전부 해제. 범위·수치는 카드별 표기.
       (예: 자경단 대장 = 내 등장 인물 전체 공 +1 / 아가네이아 = 같은 행 아군 공·생 +2 / 테르미아 = 내 모든 〈저격〉 +1)

[대기]:  배치된 말의 등장 전 상태. 능동 행동(이동·격돌·관통) 불가, 격돌 시 반격 0(샌드백), 트리거 발동 X
         등장(의지)으로 해제 — combat.md "## 배치·등장"
         ※ 돌파 정비(끝줄 진입 후 한 턴 쉼)도 한 턴 쉬는 상태지만 다음 턴 자동 관통 → combat.md "## 돌파·관통"
```

## 효과 (무엇을 — 범주)

```yaml
트리거에 안 묶임, 자유 조립.
점수화: 효과 점수만큼 능력치 합에서 차감 (아래 능력치 기준선).
임시 부여는 0점이라, 임시 반복 카드(인도 등)는 바닐라 스탯이 낮은 게 정상 (변동성을 스탯 할인으로 삼음).

오더 1 효과 7종:
  피해   직접 데미지
  부여   스탯·키워드 부여 (공격력·키워드 / 방어도는 대적자 대상만)
  회복   hp 회복 (방어도 X, 최대치까지)
  보호   보호막 부여 (일반 인물도 가능)
  드로우 카드 뽑기 (덱에서)
  생성   특정 카드를 손에 직접 추가 (덱 무관 — 악타이아: 그림자 칼날 2장)
  제거   대상 말을 즉시 파괴 (피해 무관 — 검은 숲 사냥꾼: 8방향 2칸 [대기] 적 제거)

# 동적 부여 ("X만큼"): 방어도·공격력·의식 등 가변값을 읽어 부여·피해 (자경단대장·아가네이아·스키아·아르타이아).
#   새 효과 아님 — 부여·피해의 가변 응용. 점수화는 시뮬 숙제.
```

## 메커니즘 키워드 (특수 규칙 — 오더 1: 4종, 수호는 정의 보존·미사용)

```yaml
저격:  8방향 2칸 이내 적 1명(대적자 포함)을 골라 피해를 주는 1회성 원거리 공격 (시야 무관·직격).
       피해량은 카드별로 〈저격 N〉 표기. 트리거([등장]·[퇴장] 등)나 사냥꾼 대적자 특기로 발동.
       사냥꾼 직업색 — 직격(번) 갈래 핵심. 점수는 피해 효과 기준(N뎀 = N점). 적 대적자 직격(거리 무관)은 저격 아님.

진형:  등장 시 상하좌우·대각선 1칸 이내 아군 인물(대적자 제외)을 강화 (범위 키워드).
       부여 수치·종류는 카드별 〈진형〉 표기 — 공격력만(견습·대장장이) 또는 공격력+생명력(교관·브론테이아).
       전사 직업색 — 미드레인지 필드 장악 갈래 핵심. 점수는 부여 효과 기준.

연전:  이 카드가 격돌해 양쪽(이 카드·상대)이 모두 생존하면 즉시 한 번 더 격돌 (추가 1회만 — 무한루프 방지).
       능동·수동·관통 격돌 전부 포함. 재격돌도 동시 교환.
       전사 직업색 — 교환 우위 도구(스테로페아).

수호:  이 카드 위치와 무관하게, 내 대적자가 격돌(능동·수동·관통)로 입을 피해를 대신 받는다.
       원격·기도·책략 피해는 대납하지 않는다. 대납 피해가 이 카드 hp를 초과해도 대적자에 이월 없이 이 카드가 사망.
       전사 직업색 — 현재 사용 카드 없음(정의 보존, 안틸로크 제거).
```

## 능력치 기준선 (바닐라 · 타입 계수)

```yaml
# types.md에서 타입 계수 이관 (06-08). types엔 역할 서술만, 계수 수치는 여기.

바닐라 합의:
  의지 1당 능력치 합 = 타입 계수
    일반 인물: 공격력 + 생명력 (방어도는 대적자 전용 — 아래)
    대적자:    공격력 + 방어도 + 생명력
  효과 없는 깡통(바닐라)의 기준선. 효과 있으면 점수만큼 차감.

타입 계수 (의지 × 계수, 버림):
  보병   ×3       느린 대신 압도적 스탯 (진형의 핵)
  전차   ×2.5     기동형 (옛 '기수')
  신관   ×2.5     기동형 (옛 '전령')
  기수   ×2       통과(특수 이동)가 본체 — 바닐라 스탯 최저 (옛 '척후'. 잠정, 시뮬 검증)
  → 전차·신관은 효과가 본체 / 기수는 통과가 본체 (바닐라보다 능력 위주)

방어도 · 생명력:
  방어도 = 대적자 전용 자원:
    일반 인물 = attack/hp 2스탯, 방어도 없음 (부여로도 못 받음)
    방어도는 대적자만 보유·운용 (바닐라·특기·장비로)
    ※ 전사 기도 1·책략 1이 일반 인물에 방어도 부여 = 이 규칙과 충돌, 철님 재설계 대기
  보호막: 일반 인물도 부여 가능 (방어도와 별개 자원)
  생명력(hp): 일반 인물의 본체 체력 (바닐라 방어 총량). 누적(스테이지 단위)은 대적자만 (combat.md)
  분포 = 일반 인물 공격 vs hp 배분 / 대적자는 + 방어도

효과 차감 (b방식):
  효과 점수만큼 합에서 차감 후 배분. 도구가 수치까지 산출, 작가가 튜닝.
  공식은 기준선이지 감옥이 아님 — 의도적 일탈은 작가 결.
```

## 의식 (사제 자원 — 누적 연료)

```yaml
# 사제 전용 자원. 비용(통화) 아님 — 봉헌·카드로 쌓아두는 연료. 특정 카드가 소모해 큰 효과.

성격:
  충전:   봉헌(특기, 발동당 +1)·카드 효과로만 (자동 X)
  이월:   누적 (턴 넘겨도 유지)
  리셋:   매 배틀 시작 시 0 (시작 보호막·방어도와 같은 배틀 단위 결)
  상한:   30 (임의값 — 시뮬 검증 전)

봉헌:  사제 특기 — 발동 시 의식 스택 +1. 특기 정의 = signatures.md

소모:  카드 effect로만 — 카드가 스택을 읽어 효과량으로 환산
       예: 스키아·아르타이아 = 등장 시 의식 전부 소모 → 스택만큼 버프/피해
# 비용 자원 아님 — ritual_cost·은총·축복 폐기(06-08). 의식은 모아서 터뜨리는 연료.
# 직업 사이드 자원 = 복제 가능한 틀 (예언자·군주 빈집 채울 때 참조)
```

## 토큰

```yaml
토큰 = 카드 풀 밖의 생성물.
  키워드(등장·개시 등)로만 필드에 생성.
  덱·패·묘지를 거치지 않음. 사망 시 덱 복귀 없이 소멸.
  예: 라키아 풋내기 신병.
```

## 후속 오더 보류 (정의 보존 · 오더 1 미사용)

```yaml
# 오더1 팔레트에선 빼되 정의·점수는 보존 (해당 직업·전투 만들 때 복귀).

상태:
  거점    5     인접 8칸을 배치 발판화 (배치 위치 확장)
  현현    6     판 전체 시간대를 선언값으로 잠금, 사망 시 해제

효과:
  봉쇄    기본 2 + (n−1)턴당 1   (n턴 지속. 1턴=2 / 2턴=3 …)
  증원    기본 2 + 토큰(공 + 생)   · 1턴 1체 · 깡통 토큰만 (구 '소환' 효과)
```
