## 키워드 시스템

```yaml
키워드 = 트리거(언제) + 효과(무엇을) 분리 조립.
카드 = 능력치 + (있을 수도 없을 수도 있는) 키워드.
트리거는 공장 고정(7종), 효과는 자유 조립 — 둘이 끼워져 카드가 양산된다.

오더 1 팔레트 (수 제한 — 오더 늘수록 확장):
  트리거 7 · 상태 5(+[대기]) · 효과 5 · 메커니즘 키워드 0
  후속 오더 보류분(정의 보존·오더1 미사용) = ## 후속 오더 보류
```

## 트리거 (언제 발동 — 7종 고정)

```yaml
등장:  배치되는 즉시
퇴장:  사망하는 즉시 (적 턴에도). 그 칸이 비워진 뒤 효과 발동
개시:  내 턴 시작 시 (여럿이면 컨트롤러가 순서 선택)
종료:  내 턴 종료 시
처치:  대적자 제외 적 인물을 직접(격돌·사격) 처치하고 살아남으면 (적 턴에도). 동시 사망 시 불발
동조:  자기 진영 대적자 특기 발동 직후
인도:  카드 태생 시간대가 될 때 — 그 시간대 창에만 효과 켜짐, 매 순환 반복

# 효과 내용·수치는 트리거에 안 묶임 — 아래 효과로 자유 조립.
# 트리거 간 동시 발동 우선순위 = 펜딩 (시뮬에서 확정).
```

## 상태 (상시 성질 — 5종 + [대기])

```yaml
신속:  이동력 +1칸 (방향은 타입 고유 유지). 소환 턴 [대기]는 해제 X
돌격:  소환 턴 [대기] 무시 (그 턴 이동·격돌·사격 가능)
신성:  단일 지정 기도(target: one) 면역 (적·아군 모두). 책략(칸 지정)엔 적중
       → 단일 지정 면역이라 아군 버프(회복 등)도 못 받음
고정:  배치된 위치에서 이동 불가 (자기 디메리트 — 점수 음수)
사수:  상시 사격 부여 — 8방향 2칸 사격(원격 일방, 반격 X·시야 안 적·쏘면 노출[밤 제외], 자기 공격력만큼 피해) — 사냥꾼 직업색. 점수 3 (상세 combat.md·types.md)
       # 사격 = 사수만의 전투 방식(행동 — 본인 무피해, 공격력만큼 피해). 사냥꾼 특기 〈저격〉 = 이 효과의 능동판(의지2·턴1회)

[대기]:  소환되거나 돌파한 그 턴의 상태. 능동 행동(이동·격돌·관통·사격) 불가, 다음 턴 해제 (돌격으로 즉시 해제)
```

## 효과 (무엇을 — 범주)

```yaml
트리거에 안 묶임, 자유 조립.
점수화: 효과 점수만큼 능력치 합에서 차감 (아래 능력치 기준선).
임시 부여는 0점이라, 임시 반복 카드(인도 등)는 바닐라 스탯이 낮은 게 정상 (변동성을 스탯 할인으로 삼음).

오더 1 효과 5종:
  피해   직접 데미지
  부여   스탯·키워드 부여 (공격력·방어도·키워드 등)
  회복   hp 회복 (방어도 X, 최대치까지)
  보호   보호막 부여
  드로우 카드 뽑기

# 동적 부여 ("X만큼"): 방어도·공격력·의식 등 가변값을 읽어 부여·피해 (자경단대장·아가네이아·스키아·아르타이아).
#   새 효과 아님 — 부여·피해의 가변 응용. 점수화는 시뮬 숙제.
```

## 능력치 기준선 (바닐라 · 타입 계수)

```yaml
# types.md에서 타입 계수 이관 (06-08). types엔 역할 서술만, 계수 수치는 여기.

바닐라 합의:
  의지 1당 능력치(공격력 + 방어도 + 생명력) 합 = 타입 계수
  효과 없는 깡통(바닐라)의 기준선. 효과 있으면 점수만큼 차감.

타입 계수 (의지 × 계수, 버림):
  보병   ×3       느린 대신 압도적 스탯 (진형의 핵)
  기수   ×2.5     기동형
  전령   ×2.5     기동형
  척후   ×2       통과(특수 이동)가 본체 — 바닐라 스탯 최저 (잠정, 시뮬 검증)
  용병   가변       그 시간대 타입 계수 (낮·경계 보병 ×3 / 밤 척후 ×2)
  → 기수·전령은 효과가 본체 / 척후는 통과가 본체 (바닐라보다 능력 위주)

방어도 · 생명력:
  같은 자원(방어 총량). 생명력은 효과 표적용 별도 태그.
  일반 인물: 방어도가 곧 체력 / 생명력은 마지막 마진(기본 1)
  누적 생명력(스테이지 단위)은 대적자만 (combat.md)
  분포 = 공격 vs 방어총량 둘 사이 배분

효과 차감 (b방식):
  효과 점수만큼 합에서 차감 후 배분. 도구가 수치까지 산출, 작가가 튜닝.
  공식은 기준선이지 감옥이 아님 — 의도적 일탈은 작가 결.
```

## 의식 (사제 자원 — 누적 연료)

```yaml
# 사제 전용 자원. 비용(통화) 아님 — 봉헌·카드로 쌓아두는 연료. 특정 카드가 소모해 큰 효과.

성격:
  충전:   봉헌(특기, 발동당 +1)·카드 효과로만 (자동 X)
  이월:   누적 (턴 넘겨도 유지)
  리셋:   매 배틀 시작 시 0 (시작 보호막·방어도와 같은 배틀 단위 결)
  상한:   30 (임의값 — 시뮬 검증 전)

봉헌:  사제 특기 — 발동 시 의식 스택 +1. 특기 정의 = signatures.md

소모:  카드 effect로만 — 카드가 스택을 읽어 효과량으로 환산
       예: 스키아·아르타이아 = 등장 시 의식 전부 소모 → 스택만큼 버프/피해
# 비용 자원 아님 — ritual_cost·은총·축복 폐기(06-08). 의식은 모아서 터뜨리는 연료.
# 직업 사이드 자원 = 복제 가능한 틀 (예언자·군주 빈집 채울 때 참조)
```

## 토큰

```yaml
토큰 = 카드 풀 밖의 생성물.
  키워드(등장·〈개시〉 소환 등)로만 필드에 생성.
  덱·패·묘지를 거치지 않음. 사망 시 덱 복귀 없이 소멸.
  예: 라키아 풋내기 신병.
```

# 오더1 팔레트에선 빼되 정의·점수는 보존 (해당 직업·전투 만들 때 복귀).

상태:
  거점    5     인접 8칸을 소환 발판화 (소환 위치 확장)

  봉쇄    기본 2 + (n−1)턴당 1   (n턴 대기. 1턴=2 / 2턴=3 …)
  소환    기본 2 + 토큰(공 + 생)   · 1턴 1체 · 깡통 토큰만
