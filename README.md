# ⚔️ Chronicle — Game Design Wiki

> **Chronicle**
> — 밤하늘에 별자리를 수놓는 이야기

> 턴제 전술 카드+주사위 로그라이크.
> 겪은 것이 덱이 된다. 카드 한 장이 이야기이고, 자원이고, 기록이다.

## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 사서 프레임 | 카드 = 이야기 + 자원 + 기록. 런 성공 = 역사. 실패 = 미기록. |
| 정찰-판단-감내 | 코어 게임 사이클. |
| 5층 구조 | 인물 → Order → Chapter → Stage → Battle. |
| 인격 변주 | 같은 자리, 다른 인격 = 가능세계. 오더 단위. |
| 카타스테리스모스 | 영웅 = 별이 됨. 명성 = 의지 결의 깊이 박힘 = 별자리 박힘. (5-8/5-11) |
| 다인물 컬렉션 | 신화 모티브 차용. 인물·Order = DLC 입자. |
| 시점 교차 | 여러 영웅의 Order가 같은 세계에서 교차. 시리즈 = 별자리 모음 = 밤하늘. (5-8) |
| 도서관 메타포 | 게임 = 도서관. 인물 = 책 한 권. 진척도 = 어둠/램프 (5-9) |
| 방치형 자동 + 속 깊음 | 기본 결 = 자동. 속 = 결의 결 깊음. 부담 작음 + 전략적 + 심오함. (5-10) |
| 죽창 결 + 동귀어진 | 1-3 라운드 결판 + 다 막을 수 있음 + 운 결 + 실력 결 합주 (5-11) |
| 의지 1종 + 신성 면 | "주사위가 곧 신성력이 포함된 의지 덩어리" — 등급 = 신성 결의 그릇 (5-11) |

## 작품 정체성

```yaml
밤하늘:    미궁 세계 (그리스 신화 결, 지상·경계·미궁 3 자리)
첫 별:     Order 1 = 테오도라 (지상 출신, 인간 → 영웅 등극 결)
별자리:    Order 누적. 영웅의 업이 별자리로 박힘
이야기:    사서 프레임 (게임 = 책 = 기록)
시리즈:    여러 별자리 = 밤하늘. 시점 교차로 미궁 세계 전체 그림

신 결 (5-10 박힘):
  지상 신 = 인격신 (그리스 올림포스 결)
  미궁 신 = 자연신 (자연 결, 인격 X)
  → 결산 결 같음 (어휘만 분리)
```

## 위계·등급 (5-11 박힘)

```yaml
팩션 (출신·신앙):
  미궁 (밤 신앙):  무리 + 재앙 (몬스터 외형, 자연신)
  지상 (낮 신앙):  인간 + 영웅 (정통, 인격신)
  경계 (신앙 X):    인간 + 영웅 (떠돌이, 끄나풀 가능성)

위계 (분류, 게임 노출):
  영웅 (Heroes)
  인간 (Humans)
  재앙 (Calamity)
  무리 (Horde)

등급 (내부 결, 의지 주사위 수):
  필멸:    1
  반신:    2
  신성:    3
  번외:    4+ (보스급)

위계 ↔ 등급 자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)
  아킬레우스 (영웅, 신과 관련) = 번외 영웅 (4)
  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)
  운명 보스 = 신성·번외 재앙

수치 참고표:
  hp:        필멸 1 / 반신 3 / 신성 5 / 번외 10
  공방속 합: 필멸 3 / 반신 4 / 신성 5 / 번외 7
```

## 전투 시스템 4.0 (5-11 마디 박힘)

```yaml
시간대 3종 (5-11):
  낮 / 경계 / 밤
  
페이즈 시작 시간대 (R1):
  지상: 1=낮 / 2=밤 / 3=낮 / 4=밤
  미궁: 1=밤 / 2=낮 / 3=밤 / 4=낮
  경계: 시작 랜덤
  
라운드별 흐름:
  낮 → 경계 → 밤 → 경계 → 낮 → ...

운명 페이즈 시간대:
  페이즈 흐름 결 자연 따라감 (5-11 박힘. 옛 5-10 = 적의 자리 폐기)

의지 주사위 1종 (5-11):
  d6, 4종 면 (의지 / 신성 / 경계 / 실패)
  주사위 수 = 등급 결 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
  
면 비율 (팩션별):
  지상:  별 3 / 경계 2 / 낮 1
  미궁:  별 3 / 경계 2 / 밤 1
  경계:  별 3 / 낮 1 / 밤 1 / 경계 1

박힘 면:
  자기 시간대 라운드: 별 + 자기 시간대 면 = 4면 박힘 (67%)
  반대 시간대 라운드: 별만 박힘 (50%)
  → 의존도 완화 (옛 결 4면 vs 2면 → 새 결 4면 vs 3면)

직업 3종 (5-11 박힘):
  전사:    1열 / 공격(1열 적 선택) + 방어(자기) / 분배 5:3:2
  사냥꾼:  2열 / 1·2열 적 공격 + 방어 X / 분배 5:5
  신관:    1·2열 선택 / 1열=전사 / 2열=사냥꾼

진형 (5-10 살림):
  1열 (전위) / 2열 (후위)
  편성 단위 배치 (전투 시작 시)
  1열 전멸 = 근접 공격이 2열도 닿음 (자동 진열)

3 패러미터 (인물별) + hp 별도:
  공격력:    의지 면 박힘 시 곱셈치 (공 선언 시)
  방어력:    의지 면 박힘 시 곱셈치 (방 선언 시)
  속도:      순서 점수 (시간대 보정과 합산)
  생명력 (hp): 별도 자원 (등급 참고표 1/3/5/10)
  → 신성력 패러미터 폐기 (5-11). 등급 자체가 신성 결의 그릇.

라운드 결산 = 3단계 (5-10 살림):
  0_선언:  ㄱ. 공격·피격 대상 (변경 시에만)
            ㄴ. 공격 / 방어 1택 (모든 인물, 5-11 정정)
  1_굴림:  의지 주사위 굴림 (등급 수만큼)
  2_결산:  속도 순서대로 결과 박힘 (트로이 결: 적 사망 시 적 결산 무화)

결산 (의지 1종):
  공격 점수 = 박힌 면 × 공격력 (공 선언 시)
  방어 점수 = 박힌 면 × 방어력 (방 선언 시)
  순서 점수 = 시간대 보정 + 인물 속도

피해 = max(0, 자기 공격 - 상대 방어)

3의 원칙 (5-11 박힘):
  반신 1 vs 필멸 1 = 압도
  반신 1 vs 필멸 2 = 승리
  반신 1 vs 필멸 3 = 동귀어진

작품 결:
  죽창 결 (1-3 라운드 결판)
  동귀어진 가능
  다 막을 수 있음 (max(0, ...))
  hp 살림 (1격사 X)
  운 결 + 실력 결 합주

플레이어 시점: 신적 (아테나 결). 호메로스 결 (의지 = 인간 결 + 신성 결 합주).
가호 (유물) 결: 덱 빌딩 / 환경 레이어 — 펜딩 (다음 마디).
```

## 덕목 결 (5-10 박힘 살림)

```yaml
덕목 = *살아내는 결* (획득 X)
변주 = 인격 = 덕목 결 (분리 X)
챕터 클리어 = 신성 결 *획득 계기* (5-11: 의지 주사위 수 박힘? 펜딩)

본인 박은 결: "인간이 신성에 가까워지는 *과정*"

Order 1 변주 ↔ 덕목:
  용맹한 테오도라 → 용기 살아냄
  지혜로운 테오도라 → 지혜 살아냄
  빛나는 테오도라 → 정의 살아냄
  절제 = 다른 Order 영웅 자리 (시리즈 결, 펜딩)

표기:
  변주 = "용맹한 / 지혜로운 / 빛나는" (5-10 유지)
  덕목 = 그리스 4주덕 (지혜 / 용기 / 절제 / 정의)
```
