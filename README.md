## 4축 결

```yaml
진영 (3): 지상 / 미궁 / 경계
종족 (2): 인간 / 무리
태생 (4): 한낮 / 여명 / 황혼 / 심야
위계 (4): 인간 / 영웅 / 무리 / 재앙
등급 (4): 필멸 / 반신 / 신성 / 번외 (내부)

직업 (4): 전사 / 수호자 / 사냥꾼 / 사제 (자유)

조합 (4 가능):
  지상 + 인간 + 한낮 + (인간↔영웅)
  경계 + 인간 + 여명 + (인간↔영웅)
  경계 + 무리 + 황혼 + (무리↔재앙)
  미궁 + 무리 + 심야 + (무리↔재앙)
```

## 게임 결

```yaml
3층 결단:
  외부 (Order): 인격 변주 — 용맹한·지혜로운·빛나는 테오도라
  중간 (Phase): 카드 시스템 (선택-거부-감내) — 리스크 관리
  내부 (Round): 인물 배치 — 테오도라 혹사 + NPC 보호

핵심: 불완전한 운에 기대는 상황에서 최선의 선택
잘한다 = 손해 최소화

테오도라 = 페이즈 대비 강력한 카드 (어그로 흡수기)
우호 NPC = 영구 손실 (살려가는 결)
덱빌딩 = NPC 태생 기반
```
