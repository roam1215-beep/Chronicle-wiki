# ⚔️ Chronicle — Game Design Wiki

> **Chronicle**
> — 밤하늘에 별자리를 수놓는 이야기

> 턴제 전술 카드+주사위 로그라이크.
> 겪은 것이 덱이 된다. 카드 한 장이 이야기이고, 자원이고, 기록이다.

## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 사서 프레임 | 카드 = 이야기 + 자원 + 기록. 런 성공 = 역사. 실패 = 미기록. |
| 정찰-판단-감내 | 코어 게임 사이클. |
| 5층 구조 | 인물 → Order → Chapter → Stage → Phase → Battle (Round). |
| 인격 변주 | 같은 자리, 다른 인격 = 가능세계. 오더 단위. |
| 카타스테리스모스 | 영웅 = 별이 됨. Order 클리어 시 위계 등극 (5-12) |
| 다인물 컬렉션 | 신화 모티브 차용. 인물·Order = DLC 입자. |
| 시점 교차 | 여러 영웅의 Order가 같은 세계에서 교차. 시리즈 = 별자리 모음 = 밤하늘. |
| 도서관 메타포 | 게임 = 도서관. 인물 = 책 한 권. 진척도 = 어둠/램프 |
| 방치형 자동 + 속 깊음 | 라운드 안 결단 X. 외부 결단 (배치·카드)만. (5-12) |
| 죽창 결 + 동귀어진 | 1-3 라운드 결판 + 운 결 + 실력 결 합주 |
| 의지 1종 + 신성 면 | "주사위가 곧 신성력이 포함된 의지 덩어리" — 등급 = 신성 결의 그릇 |
| 4축 결 (5-12) | 진영·종족·태생·위계·등급으로 인물 결의 자리 박힘 |
| 격돌 = 하스스톤 전장식 (5-12) | 공격력 = 상대 hp 직격. 동시 결산. |
| 직업 자동 매커니즘 (5-12) | 롤토체스 결. 유저 결단 = 배치만. |

## 작품 정체성

```yaml
밤하늘:    미궁 세계 (그리스 신화 결, 지상·경계·미궁 3 자리)
첫 별:     Order 1 = 테오도라 (지상 출신, 인간 → 영웅 등극 결)
별자리:    Order 누적. 영웅의 업이 별자리로 박힘
이야기:    사서 프레임 (게임 = 책 = 기록)
시리즈:    여러 별자리 = 밤하늘. 시점 교차로 미궁 세계 전체 그림

신 결 (5-10 박힘):
  지상 신 = 인격신 (그리스 올림포스 결)
  미궁 신 = 자연신 (자연 결, 인격 X)
  → 결산 결 같음 (어휘만 분리)
```

## 4축 결 (5-12 박힘)

```yaml
진영 (3): 지상 / 미궁 / 경계
종족 (2): 인간 / 무리
태생 (4): 한낮 / 여명 / 황혼 / 심야
위계 (4): 인간 / 영웅 / 무리 / 재앙
등급 (4): 필멸 / 반신 / 신성 / 번외 (내부 결, 노출 X)

진영-종족-태생 조합:
  지상 + 인간 + 한낮 태생
  경계 + 인간 + 여명 태생
  경계 + 무리 + 황혼 태생
  미궁 + 무리 + 심야 태생

직업 자유 (4축 무관): 전사 / 수호자 / 사냥꾼 / 사제

종족 ↔ 위계 정합:
  인간 종족: 인간 ↔ 영웅 (Order 클리어 시 등극)
  무리 종족: 무리 ↔ 재앙

변동 시점:
  위계 = Order 클리어 (작품 결, 카타스테리스모스)
  등급 = 챕터 클리어 (의지 +1 + 가호 +1)
  태생 = 변동 X

태생의 결:
  한낮 = 지상 정통 (낮의 자리)
  여명 = 경계 인간 (낮으로 가는 결)
  황혼 = 경계 무리 (밤으로 가는 결)
  심야 = 미궁 정통 (밤의 자리)
  → 시간 속성의 비유 (경계 = 낮·밤 섞임)
```

## 전투 시스템 (5-12 후속 마감)

```yaml
페이즈 ↔ 배틀 ↔ 라운드:
  페이즈: 카드 시스템 (선택-거부-감내 3장). 최대 2 배틀.
  배틀:   전투 카드 1장 = 1 전투 인스턴스
  라운드: 명령 → 굴림 → 결산. 상한 임시 5.

라운드 흐름:
  1. 명령 (라운드 시작 전): 모든 인물 배치 자유 변경
  2. 굴림: 의지 주사위 (등급 수만큼)
  3. 결산: 페이즈 1 (보호·축복·저주, 진영별)
           페이즈 2 (사격, 동시)
           페이즈 3 (격돌, 동시 / 좌→우 자기 진영 안)

의지 주사위 (d6):
  면 종류: 의지(별) / 신성(낮·밤) / 경계
  주사위 수 = 등급 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)

굴림 결산 (개별 주사위마다):
  별 면:                         통상 행동 (스탯대로)
  자기 시간대 면 + 자기 라운드:  대성공 (행동 변형)
  자기 시간대 면 + 반대 라운드:  통상 (case 2, 깡)
  반대 시간대 면:                 실패 (격돌만 수동)
  우선순위: 대성공 > 통상 > 실패

격돌 = 하스스톤 전장식:
  공격력 = 상대 hp 직격 (방어력 능력치 X)
  격돌 = 양 진영 동시 결산
  자기도 적 공격 받음
  자기 위치 = 적 좌측만 공격 (모든 우리 전사)

직업 자동 매커니즘:
  전사:    돌격 / 격파 (양 옆 광역)
  수호자:  방어 / 수호 (격돌 전 임시 방어도, 도발)
  사냥꾼:  사격 (자기 위치 가장 먼 적, 열 기준) / 저격
  사제 지상: 축복 (전열 좌측 방어도) / 축성
  사제 미궁: 저주 / 펜딩

배치: 모든 직업 자유 (전열·후열)
유저 결단: 매 라운드 배치 자유 변경 / 편성 X
```

## 능력치 (5-12 정정)

```yaml
공격력 + 체력만 (5-12):
  옛 5-11+: 능력치 5종 (공·방·속·hp·보호막) — 폐기
  새 5-12:  공격력 + 체력 (인물 고유)

방어도 (감산):
  부여: 시작 시 / 행동 (수호·축복) / 가호
  결산: 숫자만큼 막음

보호막 (이진, 희소):
  결: 어떤 피해든 1번 무효, 1번 사용 시 1개 소멸
  희소: 쉽게 부여 X

피해 흐름: 보호막 → 방어도 → hp
```

## 가호 (5-12 광역)

```yaml
가호 수 = 등급:
  필멸 0 / 반신 1 / 신성 2 / 번외 3

가호 폭 = 위계:
  저위계 (인간·무리) = 작은 폭
  고위계 (영웅·재앙) = 큰 폭

가호 유형 = 태생 정합:
  한낮 태생 = 한낮 가호 (지상 인간)
  여명 태생 = 여명 가호 (경계 인간)
  황혼 태생 = 황혼 가호 (경계 무리)
  심야 태생 = 심야 가호 (미궁 무리)

가호 영역 (광역):
  - 기본 스탯 +N (시작 시)
  - 대성공 시 스탯 +N
  - 라운드 기반 조건부 (첫 라운드 / 라운드 진행마다)
  - 열 기반 조건부 (소속 열에 따라)
  - 공격·피격 기반 조건부 (맞을 때마다 / 때릴 때마다)

지속:
  가호 = 영구
  대성공 행동 효과 = 1 라운드만

가호 어휘 = 임시 (실제 콘텐츠는 작가 결, 펜딩)
```
