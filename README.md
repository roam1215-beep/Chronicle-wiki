# Chronicle

> 그리스 신화 기반 턴제 전술 카드 로그라이크 (Unity 6.3).
> 사서가 영웅의 책을 펼치면 용기·지혜·정의 세 편(가능세계)의 이야기가 카드로 흐르고,
> 클리어한 영웅은 별이 된다 (카타스테리스모스).

## 이 레포

Chronicle **기획 정본**(위키) — 1인 + AI 직군 분담 게임 개발의 기획 산출물.
프로젝트 정체·직군·목표 등 운영 전반은 **CLAUDE.md**가 단일 정본이다.
