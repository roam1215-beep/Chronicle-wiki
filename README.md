## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 하나의 객체, 여러 얼굴 | 카드 1장 = 이야기 + 토큰 + 재료 + 기록. 시스템을 추가하지 않고 카드에 얼굴을 붙인다. |
| 전투 엔진 불변 | 7스텝 + 4종 주사위면. 토큰/유물이 조건만 바꿈. 규칙 불변. |
| 겪은 것이 덱이 된다 | 스테이지에서 겪은 사건이 토큰(단기)+유물(장기)이 되는 구조. |
| 서사-메카닉 일치 | 플레이 이력이 곧 빌드. 칭호가 곧 능력. |
| 사서 프레임 | 모든 사건은 로그로 기록. 런 성공 = 역사. 실패 = 기록 없음. |
