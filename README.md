# ⚔️ Chronicle — Game Design Wiki

> **Chronicle**
> — 밤하늘에 별자리를 수놓는 이야기

> 턴제 전술 카드+주사위 로그라이크.
> 겪은 것이 덱이 된다. 카드 한 장이 이야기이고, 자원이고, 기록이다.

## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 사서 프레임 | 카드 = 이야기 + 자원 + 기록. 런 성공 = 역사. 실패 = 미기록. |
| 정찰-판단-감내 | 코어 게임 사이클. |
| 5층 구조 | 인물 → Order → Chapter → Stage → Battle. |
| 인격 변주 | 같은 자리, 다른 인격 = 가능세계. 오더 단위. |
| 카타스테리스모스 | 영웅 = 별이 됨. 명성 = 덕목 누적 = 별자리 박힘. (5-8) |
| 다인물 컬렉션 | 신화 모티브 차용. 인물·Order = DLC 입자. |
| 시점 교차 | 여러 영웅의 Order가 같은 세계에서 교차. 시리즈 = 별자리 모음 = 밤하늘. (5-8) |
| 도서관 메타포 | 게임 = 도서관. 인물 = 책 한 권. 진척도 = 어둠/램프 (5-9) |

## 작품 정체성 (5-8 박힘)

```yaml
밤하늘:    미궁 세계 (그리스 신화 결, 지상·경계·미궁 3 자리)
첫 별:     Order 1 = 테오도라 (지상 출신 영웅, 카타스테리스모스 시작)
별자리:    Order 누적. 영웅의 업이 별자리로 박힘
이야기:    사서 프레임 (게임 = 책 = 기록)
시리즈:    여러 별자리 = 밤하늘. 시점 교차로 미궁 세계 전체 그림
```

## 등급·팩션 (5-9 박힘)

```yaml
팩션 (출신·신앙):
  미궁 (밤 신앙):  무리 + 재앙 (몬스터 외형)
  지상 (낮 신앙):  인간 + 영웅 (정통)
  경계 (신앙 X):    인간 + 영웅 (떠돌이, 끄나풀 가능성)

등급 = 두 축 (5-9):
  행동 주사위 수 = 인간 역량
  신성 주사위 수 = 신성 깊이
  
  영웅 (Heroes):    행동 N / 신성 N. hp 큼. 카타스테리스모스 (별이 됨).
  인간 (Humans):    행동 N / 신성 0. hp 보통. 정예.
  재앙 (Calamity):  행동 N / 신성 N. hp 큼. 멸절. 처치 = 영웅에 덕목 박힘.
  무리 (Horde):     행동 1 / 신성 0. hp 작음. 떼.
```

## 전투 시스템 4.0 (5-9 코어)

```yaml
시간대:        낮 / 밤 (2종)
페이즈 진행:   출신별 다름 (지상=낮→밤 / 미궁=밤→낮 / 경계=랜덤)

주사위 2종:
  행동 주사위 (모두): 칼2 / 방패2 / 실패2 (공통). 분화 5종.
  신성 주사위 (영웅·재앙):
    지상: 낮3 / 별1 / 밤2
    미궁: 밤3 / 별1 / 낮2

가호 박힘:     신성 면 = 페이즈 시간대 일치 + 자기 신앙 일치 시
별 면:         가호 + 신성 주사위 재굴림 (무한)
가호 결산:     플레이어 1택 (공/방). 가호 1개당 인물 공·방 수치만큼.
행동 결산:     행동 면 × 인물 공·방 수치.

플레이어 시점: 신적 (아테나 결). 호메로스 결 (가호 = 증여만).
```

| 자리 | 사유 |
|------|------|
| 8 특성 시스템 | 5-7 폐기. 5-9 행동 주사위 분화 5종으로 흡수. |

| 행동 카드 / sRPG 결 / 격투 모드 / 분기 결 | 5-9 시도 → 폐기 (단순 결로 회귀). |
