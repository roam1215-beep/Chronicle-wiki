## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 하나의 객체, 여러 얼굴 | 카드 1장 = 이야기 + 재료 + 기록. 시스템을 추가하지 않고 카드에 얼굴을 붙인다. |
| 전투 엔진 불변 | 7스텝 + 4종 주사위면. 패시브가 조건만 바꿈. 규칙 불변. |
| 겪은 것이 덱이 된다 | 스테이지에서 겪은 사건의 분기 효과가 부대를 변화시킨다. |
| 이름이 곧 등급 | Nameless와 Named. 이름의 유무가 생존력을 결정한다. Named = 테오도라 1기 고정. |
| 사서 프레임 | 모든 사건은 로그로 기록. 런 성공 = 역사. 실패 = 기록 없음. |
