# ⚔️ Chronicle — Game Design Wiki

> **Chronicle**
> — 밤하늘에 별자리를 수놓는 이야기

> 턴제 전술 카드+주사위 로그라이크.
> 겪은 것이 덱이 된다. 카드 한 장이 이야기이고, 자원이고, 기록이다.

## 핵심 설계 원칙

| 원칙 | 내용 |
|------|------|
| 사서 프레임 | 카드 = 이야기 + 자원 + 기록. 런 성공 = 역사. 실패 = 미기록. |
| 정찰-판단-감내 | 코어 게임 사이클. |
| 5층 구조 | 인물 → Order → Chapter → Stage → Battle. |
| 인격 변주 | 같은 자리, 다른 인격 = 가능세계. 오더 단위. |
| 카타스테리스모스 | 영웅 = 별이 됨. 명성 = 신성 주사위 누적 = 별자리 박힘. (5-8/5-10) |
| 다인물 컬렉션 | 신화 모티브 차용. 인물·Order = DLC 입자. |
| 시점 교차 | 여러 영웅의 Order가 같은 세계에서 교차. 시리즈 = 별자리 모음 = 밤하늘. (5-8) |
| 도서관 메타포 | 게임 = 도서관. 인물 = 책 한 권. 진척도 = 어둠/램프 (5-9) |
| 방치형 자동 + 속 깊음 | 기본 결 = 자동. 속 = 결의 결 깊음. 부담 작음 + 전략적 + 심오함. (5-10) |

## 작품 정체성

```yaml
밤하늘:    미궁 세계 (그리스 신화 결, 지상·경계·미궁 3 자리)
첫 별:     Order 1 = 테오도라 (지상 출신, 인간 → 영웅 등극 결)
별자리:    Order 누적. 영웅의 업이 별자리로 박힘
이야기:    사서 프레임 (게임 = 책 = 기록)
시리즈:    여러 별자리 = 밤하늘. 시점 교차로 미궁 세계 전체 그림

신 결 (5-10 박힘):
  지상 신 = 인격신 (그리스 올림포스 결)
  미궁 신 = 자연신 (자연 결, 인격 X)
  → 결산 결 같음 (어휘만 분리)
```

## 등급·팩션 (5-10 정정)

```yaml
팩션 (출신·신앙):
  미궁 (밤 신앙):  무리 + 재앙 (몬스터 외형, 자연신)
  지상 (낮 신앙):  인간 + 영웅 (정통, 인격신)
  경계 (신앙 X):    인간 + 영웅 (떠돌이, 끄나풀 가능성)

등급 = 신성 보유 여부 + 변동 결 (5-10):
  영웅 (Heroes):    인도 보유. 인간 → 영웅 등극 (시나리오 단위 박힘).
  인간 (Humans):    인도 0. 영웅 등극 가능.
  재앙 (Calamity):  인도 보유. 시작부터 재앙 (변동 X).
  무리 (Horde):     인도 0. 변동 X.
  
5 패러미터·주사위 수: 모두 *인물별*
```

## 전투 시스템 4.0 (5-10 마디 박힘)

```yaml
시간대:        낮 / 밤 (2종)
페이즈 진행:   출신별 다름 (지상=낮→밤 / 미궁=밤→낮 / 경계=랜덤)
운명 시간대:   적의 자리 (지상 영웅 = 밤 / 미궁 재앙 = 낮)

주사위 2종:
  행동 주사위 (모두): 칼·방패·실패 3종. 직업/종족별 분화 5종.
  인도 주사위 (영웅·재앙):
    지상 (인격신): 낮3 / 별1 / 밤2
    미궁 (자연신): 밤3 / 별1 / 낮2
    경계 (균등):    낮2 / 별2 / 밤2

직업 5종 (5-10 박힘):
  사냥꾼:   칼4/방0/실2 + 2열 고정 + 원거리
  용병:     칼3/방1/실2 + 1·2열 선택 + 위치 종속
  전사:     칼2/방2/실2 + 1열 고정 + 근접
  수호자:   칼1/방3/실2 + 1열 고정 + 근접
  사제:     칼0/방4/실2 + 2열 고정 + 공격 X + 방패 결산 부여 결

진형 (5-10 박힘):
  1열 (전위) / 2열 (후위)
  편성 단위 배치 (전투 시작 시)
  1열 전멸 = 근접 공격이 2열도 닿음 (자동 진열)

사거리 (5-10 박힘):
  근접 / 원거리 / 광역-세로 / 광역-가로 / 광역-전체
  광역 = 인물 카드에 박힘 (영웅·재앙 자리, 펜딩)

5 패러미터 (인물별. 어휘 임시):
  공격력:    행동 칼 면 / 인도(공) 결산 곱셈치
  방어력:    행동 방패 면 / 인도(방) 결산 곱셈치
  생명력:    hp
  속도:      순서 점수 (시간대 보정과 합산)
  신성력:    인도 결산 곱셈치 (영웅·재앙만 의미)

별도 속성 (인물별 — 5-10): 행동 주사위 수 / 인도 주사위 수 (영웅·재앙만)

라운드 결산 = 3단계 (5-10 박힘):
  0_선언:  ㄱ. 공격·피격 대상 (변경 시에만)
            ㄴ. 인도 보정 (공·방·속도 3축 1택, 굴림 전)
  1_굴림:  행동 + 인도 동시. 별 면 = 인도 재굴림 (무한)
  2_결산:  속도 순서대로 결과 박힘 (트로이 결: 적 사망 시 적 결산 무화)

결산 (인도 = 공·방·속도 3축):
  공격 점수 = 칼 면 × 공격력 + (인도 공 시: 인도 수 × 신성력)
  방어 점수 = 방패 면 × 방어력 + (인도 방 시: 인도 수 × 신성력)
  순서 점수 = 시간대 보정 + 인물 속도 + (인도 속도 시: 인도 수 × 신성력)

사제 결: 방패 결산 통째로 대상에 부여 (굴림 전 선언)

플레이어 시점: 신적 (아테나 결). 호메로스 결 (인도 = 증여만).
가호 (유물) 결: 덱 빌딩 / 환경 레이어 — 펜딩 (다음 마디).
```

## 덕목 결 (5-10 큰 정정)

```yaml
덕목 = *살아내는 결* (획득 X)
변주 = 인격 = 덕목 결 (분리 X)
챕터 클리어 = 신성 주사위 *획득 계기*

본인 박은 결: "인간이 신성에 가까워지는 *과정*"

Order 1 변주 ↔ 덕목:
  용맹한 테오도라 → 용기 살아냄
  지혜로운 테오도라 → 지혜 살아냄
  빛나는 테오도라 → 정의 살아냄
  절제 = 다른 Order 영웅 자리 (시리즈 결, 펜딩)

표기:
  변주 = "용맹한 / 지혜로운 / 빛나는" (5-10 유지)
  덕목 = 그리스 4주덕 (지혜 / 용기 / 절제 / 정의)
```
