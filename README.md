- 📄 [문서 작성 규칙](./00_운영/운영규칙.md) — 모든 기획 문서가 따르는 포맷

- 📝 줄글 금지. 시각 자료 없으면 미완성. TC 없으면 미완성.

## 삭제된 시스템

> COMBAT_SYSTEM 정본 §14 참조. 아래는 설계 과정에서 제거된 항목.

| 항목 | 사유 |
|------|------|
| 정찰 카드 (수색/감시/매의 눈) | 행군 카드로 대체 |
| 책략 카드 (계책/기만/대전략) | 무료 리롤로 대체 |
| 정보원 4단계 | 직접 시야 + 브리핑만 |
| 야습/신호/야영/장비 시스템 | 프로토에서 제외. 별도 설계 필요 |
