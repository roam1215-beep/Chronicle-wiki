# 폐기 어휘 레지스트리

> Chronicle이 버린 어휘의 정본. 청소의 그물이자 린터(문서 회귀 방지)의 입력.
> 원천 = STATE 진척의 폐기 기록 + 평론 청산 발견분.
> 구조: deprecated(잡을 것) / exceptions(뺄 것) / conflict_watch(정밀검사할 것).
>
> 사용:
>   - 청소: deprecated 어휘로 전 레포(wiki·game·qa) grep → 긍정 맥락 잔재 색출.
>   - 린터: deprecated가 본문에 긍정으로 나오면 실패. 단 exceptions·폐기맥락 줄은 통과,
>           conflict_watch는 단순 grep 금지(현재 살아있는 동음 어휘와 겹침 — 맥락 판정 필요).
> 갱신: 새 폐기 결정 시 여기 등록(1 폐기 = 1 줄). 이력은 git이 한다.

## exceptions — 폐기 어휘지만 특정 표현은 보존 (린터 통과)

```yaml
- term: "정찰"
  keep: "산골짜기 정찰대원 (카드 id morea_valley_scout 표시명)"
  reason: "폐기된 건 '정찰(Scout) 액션'이지 어휘 자체 아님. 카드 이름은 철님 판정으로 보존 (2026-06-04)"
```
