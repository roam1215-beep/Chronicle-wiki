# 운영규칙 v5.0

> Chronicle 위키. 단독 + Claude 1대1 워크플로우.
> AI 독자 기준. YAML/표 우선. 줄글 금지.

---

## 1. 절대 규칙

| # | 규칙 |
|---|------|
| 1 | 줄글 금지. YAML/표/리스트만. |
| 2 | 한 규칙은 한 문서에만. 다른 곳은 `@{ID}` 참조. |
| 3 | 미확정 = `TODO(이유): trigger` 마커. 자연어 자유 서술 금지. |
| 4 | 콘텐츠(카드 텍스트·서사·수치) 임의 생성 금지. 철 작성. |
| 5 | 추측 금지. 모르면 TODO. |

---

## 2. 페이지 템플릿 (4단)

```markdown
# {ID}: {이름}

> 상태: {잔재|결정정합|동결|폐기} · 의존: @{ID1}, @{ID2}

## 정의
[1~2문장. 무엇이고 왜 있는가]

## 규칙
[YAML 우선. 표는 분기/대조. 리스트는 순서]

## 시각 (선택)
[mermaid / ASCII. 구조 파악 필수일 때만]

## TODO (선택)
- TODO(이유): trigger
```

---

## 3. 상태 4종

| 값 | 의미 |
|----|------|
| 잔재 | 이전 결정 잔재. 정합 청소 필요 |
| 결정정합 | 현 결정 반영 완료. 동결 가능 |
| 동결 | 의도적 손대지 않음. 해제 트리거 명시 |
| 폐기 | DOCS/ARCHIVE/{시기}_{주제}/로 이동 |

"설계중" 폐기. 진척률 표현 안 함. 정합 여부만 표현.

## 5. 세션 유형 (2종)

| 유형 | 권한 | 산출 |
|------|------|------|
| 작업 | 읽기/쓰기 | 결정 + 문서 변경 + 커밋 (디폴트) |
| 읽기 | 읽기 | 진단/탐색만. 커밋 없음 |

기획·문서화 분리 폐기. 한 세션 내 결정-반영-커밋이 자연스러움 인정.

---

## 6. 세션 부팅 (1단계)

```bash
cat STATE.md
```

CLAUDE.md / 운영규칙은 작업 중 의문 발생 시에만 읽음. 부팅 시 읽지 않음.

---

## 7. 세션 종료 (4단계)

```yaml
1. STATE.md 갱신: 필수
2. 정합성 spot check:
   - 변경했다고 보고한 파일이 실제 변경됐는지 grep 검증
   - 부분 변환은 STATE.md "알려진 부채"에 명시
3. 일괄 승인 후 커밋: 1 작업단위 = 1 커밋
4. push + 토큰 제거
```

LOG 작성: *큰 결정*이 있는 세션만 (방향 전환, 시스템 폐기 등).

---

## 8. 커밋

| 항목 | 값 |
|------|-----|
| 형식 | `[카테고리] 내용 (상태)` |
| 예 | `[전투/구조] 7스텝 부활 + 공방 신설 (결정정합)` |
| 단위 | 1 작업단위 = 1 커밋 |
| 승인 | 한 세션 내 일괄 승인. 변경 목록 보고 후 OK 받으면 일괄 |

---

## 9. 동결 진입/해제

**진입 시 STATE.md에 박음:**

```yaml
frozen: true
freeze_start: YYYY-MM-DD
unfreeze_trigger: [날짜 또는 조건]
last_decision: 5줄 이내
first_action_after_unfreeze: 명시
```

**해제 시:** STATE.md 동결 섹션 → LOG 이관 + 새 STATE.md.

---

## 10. 메모리 vs git

Chronicle 답변 시 메모리 우선순위 최하. **git이 진실. 충돌 시 git.**

---

## 11. 폐기 정책

```yaml
archive_path: DOCS/ARCHIVE/{시기}_{주제}/
steps:
  1: 파일 git mv → ARCHIVE
  2: ARCHIVE/README.md 시기별 인덱스 갱신
  3: 본문 참조(@{ID}) 끊기
  4: LOG에 폐기 사유 (큰 폐기일 때만)
```
