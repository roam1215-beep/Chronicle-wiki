# 스토아 팩토리 (Stoa Factory)

> 상태: 결정정합 (5-8 박힘)

## 정의

1인 스튜디오. 본인 (이철) + AI 오케스트라.

## 어휘 결

### 스토아 (Stoa)
그리스 스토아 학파의 회랑 결. 표준 공정의 자리.

### 팩토리 (Factory)
공정의 결. 표준 공정으로 작품 박는 자리.

### 정합
작품 Chronicle (연대기) ↔ 스튜디오 Stoa Factory (회랑·공정)
같은 그리스 어원, 같은 추상화의 자리.

## 작품 라인업

- **Chronicle 시리즈** (효시 = Order 1: 미궁의 테오도라)
- **DLC** (Chronicle 시리즈 확장)
- **스캐빈저** (Scavenger): 망한 게임의 좋은 요소를 Chronicle IP로 후속작으로 박는 결

## 운영 결

### 자금
여유. 시간·자금 압박 X.

### 외주
에셋, 마케팅 한정.

### 결과물 발표
Steam 출시.

## 4축 동시 운영

```yaml
축 1: QA 역량 강화 (자동화)
축 2: Chronicle 데모
축 3: 멀티 LLM 오케스트라
축 4: 자동화 테스트 접목 (축 1·축 3 교차 = AI QA 분야)
```

축 1·축 3 교차 = AI QA 분야. 시대 흐름과 정합한 자리.

## 직군 매핑 — 나-AI 페어

```yaml
나-클로드씨:    기획 라인 전체 (이 위키, 작품 결, 작가 결)
나-클로드 코드:  기획과 클라이언트 (코드 박음)
나-제미니씨:    기획과 아트 (에셋 결)
나-노트북LM씨:  기획과 QA (테스트 결)
```

## 결의 핵심

- AI가 직군 대체 X
- 인간이 모든 자리 통합 주체
- *기획*이 모든 페어에 박힘 = 분리 불가
- ***오케스트라적 LLM 활용*** = 지휘자 = 본인. 각 LLM = 악기 결.
- 본인 *진짜 목적* (5-9 박힘)

## 정합

- 작품 결 ↔ 스튜디오 결: 같은 그리스 추상화
- Chronicle (연대기, 별자리, 사서 프레임) ↔ Stoa Factory (회랑, 공정, 표준)
- 작품 = 사서가 별자리 기록 / 스튜디오 = 본인이 AI 오케스트라로 기록 박음
- 매체 결 (게임)과 운영 결이 같은 자리에 박힘
