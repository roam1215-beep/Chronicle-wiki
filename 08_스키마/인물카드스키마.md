# SCHEMA-FIGURE: 인물카드 스키마 (Figure Card Schema)

> **상태:** 🔄 설계중 · **버전:** 0.2 · **수정일:** 2026-03-08

---

## ① 한 줄 요약

인물카드를 대량 생산하기 위한 필드 정의. 이 스키마를 채우면 카드 1장이 완성된다. Nameless/Named/기사 공통 구조.

---

## ② 스키마 정의

### 공통 필드 (모든 인물카드)

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| `card_id` | string | ✅ | 고유 ID. `{진영}-{등급}-{번호}` | `PLY-NL-001`, `ENE-ND-003` |
| `faction` | enum | ✅ | 진영. `player` / `enemy` / `ally` | `player` |
| `grade` | enum | ✅ | 등급. `nameless` / `named` / `knight` | `nameless` |
| `class` | enum | ✅ | 병종. `민병` / `보병` / `창병` / `궁병` / `기병` / `기사` / `용병` | `보병` |
| `display_name` | string | ✅ | 카드 표면 명칭 | `보병대` 또는 `테오도라 / 기사` |
| `dice_type` | enum | ✅ | 주사위 종류. `d10` | `d10` |
| `face_atk` | int | ✅ | ⚔ 면 수 (0~10) | `3` |
| `face_def` | int | ✅ | 🛡 면 수 (0~10) | `3` |
| `face_star` | int | ✅ | ★ 면 수 (0~10). Nameless는 0 | `0` |
| `face_null` | int | ✅ | ✕ 면 수 (0~10) | `4` |
| `passive_id` | enum | ✅ | 패시브. `none` / `방진` / `반격` / `선제공격` / `쇄도` / `방진\|반격\|쇄도` | `방진` |
| `passive_text` | string | — | 카드 텍스트 (유저 표시용) | `격돌 후, 칼을 거두고 방패를 세운다.` |
| `flavor_record` | string | ✅ | 기록 플레이버 (병종/인물 설명) | `검과 방패를 갖춘 근접 전투 병과.` |
| `flavor_card` | string | ✅ | 카드 플레이버 (서사 문구) | `그저 나아갈 뿐, 물러서는 법은 배우지 못했다.` |
| `hit_rule` | enum | ✅ | 피격 규칙. `instant_death` / `injury_2step` | `instant_death` |
| `order` | string | ✅ | 등장 Order. `order1` / `order2` / `shared` | `shared` |
| `stage_ids` | string | — | 등장 스테이지 (콤마 구분). 비워두면 편성/합류 | `1-2,1-4` |
| `art_ref` | string | — | 일러스트 참조 (파일명 또는 설명) | `infantry_nameless_01.png` |
| `notes` | string | — | 비고 | `편성 풀 포함` |

### Named 전용 필드

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| `unique_name` | string | ✅ | 고유명 | `테오도라` |
| `base_class` | enum | ✅ | 기반 병종 (기사는 `기사`) | `기사` |
| `star_source` | string | ✅ | ★ 교체 출처 | `⚔-1🛡-1→★2` 또는 `고유면` |
| `trait_id` | enum | ✅ | 특성. `용맹한` / `굳건한` / `신중한` / `예리한` / `현명한` / `고결한` / `은밀한` / `대담한` | `용맹한` |
| `death_effect` | string | — | 사망 시 특수 효과 | `게임오버` |
| `is_player` | bool | ✅ | 플레이어 조작 여부 | `true` |

### 기사 전용 필드

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|
| `passive_pool` | string | ✅ | 패시브 풀 (랜덤 배정) | `방진,반격,쇄도` |
| `passive_exclude` | string | — | 패시브 제외 | `선제공격` |
| `effective_faces` | int | ✅ | 유효면 수 (⚔+🛡+★) | `7` |

### 검증 규칙

| 규칙 | 조건 |
|------|------|
| 면 합산 | `face_atk + face_def + face_star + face_null == 10` |
| Nameless ★ | `grade == nameless` → `face_star == 0` |
| Named ★ | `grade == named \|\| grade == knight` → `face_star == 2` |
| Named ✕ 동일 | Named의 `face_null` == 기반 Nameless의 `face_null` (기사 제외) |
| 기사 제한 | `grade == knight` → `class == 기사` |
| 기사 Nameless 금지 | `class == 기사` → `grade != nameless` |
| 패시브 정합 | `class`에 따라 `passive_id` 자동 결정 (기사만 랜덤) |
| 민병 패시브 없음 | `class == 민병` → `passive_id == none` |
| 선제 기사 제외 | `grade == knight` → `passive_id != 선제공격` |
| 특성 Named 필수 | `grade == named \|\| grade == knight` → `trait_id` 필수 (8종 중 1) |
| 특성 Nameless 없음 | `grade == nameless` → `trait_id` 없음 |
| 예리한 궁병 전용 | `trait_id == 예리한` → `class == 궁병` |
| 현명한 플레이어 전용 | `trait_id == 현명한` → `faction == player` |
| 용병 패시브 | `class == 용병` → `passive_id == 유격` |
| 용병 특성 제외 | `class == 용병` → `trait_id != 예리한` |
| 용병 진영 | `class == 용병` → `faction == player` (테오도라 부대 전용) |

### card_id 규칙

```
{진영 3자리}-{등급 2자리}-{일련번호 3자리}

진영: PLY(플레이어) / ENE(적) / ALY(아군)
등급: NL(Nameless) / ND(Named) / KN(Knight)
번호: 001부터 순차

예시:
  PLY-KN-001  = 테오도라
  PLY-NL-001  = 플레이어 보병대
  ENE-NL-001  = 적 민병대
  ENE-ND-001  = 적 Named 보병 "마르쿠스"
  ENE-KN-001  = 적 기사 "발레리안"
  ALY-NL-001  = 아군 궁병대
```

## ③ 스프레드시트 연동

**위키 = 스키마 정의 (이 문서). 스프레드시트 = 데이터 입력.**

| 시트명 | 내용 |
|--------|------|
| `Nameless` | Nameless 카드 전량. 병종 × 진영 조합 |
| `Named` | Named 카드 전량. 고유명 + 면 구성 + 서사 |
| `검증` | 자동 검증 (면 합산, ★ 규칙, 패시브 정합) |

스프레드시트 파일: `chronicle-cards-figure.xlsx`

> **작업 흐름:** 스키마(이 문서) 확정 → 스프레드시트에 행 추가 → 검증 시트 통과 → 카드 완성
