# 라벨-태그 체계 (Label-Tag System)

> **상태:** 🔄 설계중 · **버전:** 1.0 · **ID:** TAG-RULE-001 · **수정일:** 2026-03-07

---

## ① 한 줄 요약

라벨 = 카드/분기에 붙는 효과. 태그 = 주사위 면 변환 하위 규칙. 태그는 라벨에서 혼용 가능. 라벨은 태그에 들어올 수 없다.

---

## ② 체계 구조

```
라벨 = 카드/분기에 붙는 효과. 6개 분류.
태그 = 주사위 면 변환 하위 규칙. 라벨이 참조. 4종.

라벨 → 태그 참조 가능 (상위→하위)
태그 → 라벨 참조 불가 (하위→상위 불가)
태그는 복수 라벨에서 혼용 가능
```

---

## ③ 이야기 카드 체계

```
이야기 카드
 ├─ 전투 카드    (전략 라벨 + 전술 라벨 + 결과 라벨)
 ├─ 사건 카드    (비전투 라벨)
 ├─ 우연 카드    (우연 라벨)
 └─ 운명 카드    (전략 라벨 + 전술 라벨 + 결과 라벨 + 운명 조건 + 적 테이블)
```

| 카드 유형 | 카드에 붙음 | 분기에 붙음 | 태그 참조 | 고유 |
|-----------|-----------|-----------|----------|------|
| 전투 카드 | 전략 0~1 | 전술 0~1 + 결과 0~1 | 결과 라벨 경유 | 분기 2개, 적 테이블 |
| 사건 카드 | — | 비전투 0~1 | 비전투 라벨 경유 | 분기 2개 |
| 우연 카드 | 우연 1 | — | 우연 라벨 경유 | 분기 없음, 즉시 발동 |
| 운명 카드 | 전략 1(필수) | 전술 0~1 + 결과 0~1 | 결과 라벨 경유 | 분기 없음, 운명 조건, 강제 전투 |

## ⑤ 주사위 태그 (4종)

| 태그 | 입력 | 출력 | 성격 |
|------|------|------|------|
| [연마] | ✕ 선택 | d10: ★10/⚔30/🛡30/✕30 | 확률적 강화 |
| [열화] | ⚔/🛡 선택 (★ 제외) | d10: ⚔33/🛡33/✕33 | 확률적 약화 |
| [단조] | 열화 먼저 → 연마 순차. 별도 면 | 위 조합 | 양방향 |
| [보강] | ✕ 선택 | ⚔ or 🛡 플레이어 선택 | 확정 강화 |

### 태그 공통 규칙

| 규칙 | 내용 |
|------|------|
| 발동 타이밍 | 전투 후 또는 비전투. 전투 중 없음 |
| 대상 | 유닛 1기의 면 10개 중 해당 면. 유닛 = 주사위 1개, 면 상태 개별 추적 |
| 중복 적용 | 가능. 같은 유닛에 같은 태그 여러 번 |
| ★ 체이닝 | Nameless도 Named도 동일 적용 |
| 면 추적 | 변환 후 면은 기존 면과 동일 취급. 별도 표시 없음 |
| 유닛 사망 | 면 추적 삭제 |
| [열화] ★ | 대상 아님. ⚔/🛡만 |

### 참조 맵

| 태그 | 참조하는 라벨 |
|------|-------------|
| [연마] | [약탈], [전리품], [훈련], [단련] |
| [열화] | [단조] 내부 + 라벨 확장 시 배정 |
| [단조] | [복잡한 운명] |
| [보강] | 라벨 확장 시 배정 |

## ⑥ 전투 세부 규칙

### [결투] 판정

| 항목 | 내용 |
|------|------|
| 선출 | 양측 Named 중 랜덤 1기. Named 없는 측은 전체 부대 주사위 중 랜덤 1개 대리 |
| 판정 | 양측 d10 1회. ★ 체이닝 적용. 🛡은 방어로 작동 |
| 승패 | 피해 = 상대⚔ - 내🛡. 기본 전투 피해 메카닉과 동일 |
| 무승부 | ⚔ 수 동일. 병력 손실 없음 |
| 카드락 | 미적용 |
| B풀 악덕 | 미적용 |

### [지원군]/[포위]

| 항목 | 내용 |
|------|------|
| 유닛 정체 | 완전한 유닛. 병종·면·패시브 전부 적용. 전 스텝 참여 |
| 전투 종료 | 사라짐. 부대 미합류 |
| [포위] × [귀순] | [귀순] 풀에 미포함 |
| 테이블 | 스테이지별 고정 테이블 |

### 카드락

| 항목 | 내용 |
|------|------|
| 타이밍 | 아군 첫 굴림 시 적용. 굴리지 못하면 카드락 못함 |
| [역습] 시 | R2에서 적용. 보류, 소멸 안 함 |

### 선제 불발 궁병

[봉쇄]/[복병] 모두 격돌 합류. 밤 전투 궁병과 동일.

### 부상 회복

전투 종료 즉시 완전 자동 회복. 전투 진입 시점 스냅샷 → 전투 종료 시 복원. Named만 부상. Nameless 피격 = 즉사.

### 지휘

리롤의 플레이어 대면 명칭. 스텝4에서 수행.
