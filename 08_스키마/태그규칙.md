# TAG-RULE-001: 태그 규칙 (Tag Rules)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** TAG-RULE-001 · **수정일:** 2026-03-03

---

## ① 한 줄 요약

태그는 카드의 메카닉 금형이다. 카드 = 서술 + 태그 배열. 서술이 살이고, 태그가 뼈다.

---

## ② 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **태그 = 금형** | 태그는 메타데이터가 아니라 메카닉 그 자체. 카드 유형 enum 없음. 태그 조합이 카드 정체성을 결정 |
| **서술 필수** | 태그 없이 서술만 가능. 서술 없이 태그만 불가. 비용은 서술로 표현 |
| **7스텝 불변** | 모든 태그는 7스텝 엔진 바깥에서 작동하거나 진입 조건만 변경. 엔진 내부 수정 없음 |
| **금형 재사용** | 같은 태그가 다른 서사에 붙으면 다른 카드. [훈련]이 "검을 갈았다"에도 "방패를 손봤다"에도 붙을 수 있음 |

---

## ③ 카드 구조

### 전투 카드

```
「카드 제목」 [전황 태그]
  "상황 서술"

  A분기: 분기 서술 [전술]-[전투 후]
     적: 적 힌트 → 적 테이블 참조

  B분기: 분기 서술 [전술]-[전투 후]
     적: 적 힌트 → 적 테이블 참조
```

- 전황: 카드 레벨. 0~1개. 뒤집으면 확정. 바꿀 수 없는 전장 상황
- 전술: 분기 레벨. 0~1개. 플레이어가 선택하는 전투 방식
- 전투 후: 분기 레벨. 0~1개. 승리 시 보상
- 전술과 전투 후는 독립 슬롯. 한쪽만 있어도 됨, 둘 다 없어도 됨
- 분기 양쪽 다 전투. 비전투 분기 불가

### 비전투 카드

```
「카드 제목」
  "상황 서술"

  A분기: 분기 서술 [비전투 태그]

  B분기: 분기 서술 [비전투 태그]
```

- 카드 레벨 태그 없음
- 비전투 태그: 분기 레벨. 0~1개
- 비용은 서술 텍스트로 표현. 별도 비용 태그 없음

### 우연 카드 — 행운/불운

```
「카드 제목」 [우연 태그]
  "상황 서술"
```

- 우연 태그: 카드 레벨. 1개. 뒤집는 순간 즉시 발동
- 분기 없음

### 우연 카드 — 전투

```
「카드 제목」 [복병]
  "상황 서술"
  적: 적 테이블 참조
```

- [복병] 선언 상태로 전투 강제 진입
- 분기 없음. 적 테이블이 카드에 포함

### 운명 카드

```
「카드 제목」 [전황]-[전투 후]
  "상황 서술"
  운명 조건: (예: 적 병력 전멸)
  적: 적 테이블 참조
```

- 전황: 카드 레벨. 1개 (필수)
- 전투 후: 카드 레벨. 0~1개
- 분기 없음. 강제 전투

### 슬롯 요약

| 카드 유형 | 카드 레벨 | 분기 레벨 |
|-----------|----------|-----------|
| 전투 | 전황 0~1 | [전술 0~1] + [전투 후 0~1] |
| 비전투 | 없음 | [비전투 0~1] |
| 우연(행운/불운) | [우연] 1개 | 없음 |
| 우연(전투) | [복병] + 적 테이블 | 없음 |
| 운명 | 전황 1(필수) + [전투 후 0~1] | 없음 |

## ④ 태그 분류

### 전황 태그 (3개)

카드 레벨. 전투/운명 카드에 붙음. 최대 1개. 뒤집으면 확정되는 전장 상황.

| 태그 | 효과 |
|------|------|
| [기습] | R1 아군만 일방적 굴림. 리롤·버프 불가. R2부터 정상 |
| [역습] | R1 적만 일방적 굴림. 리롤·버프 불가. R2부터 정상 |
| [결전] | 결사 R3부터 (기본 R5) |

### 전술 태그 (3개)

분기 레벨. 전투 분기에 붙음. 최대 1개. 플레이어가 선택하는 전투 방식.

| 태그 | 효과 |
|------|------|
| [봉쇄] | 전 라운드 아군만 선제. 적 선제 무력화 |
| [결투] | Named 1:1 판정(양측 Named 중 랜덤 선출) → 결과 반영 후 7스텝 |
| [난전] | 패시브 전부 무력화. 순수 주사위만 |

### 전투 후 태그 (3개)

분기 레벨(전투 카드) 또는 카드 레벨(운명 카드). 최대 1개. 승리 시 발동.

| 태그 | 효과 |
|------|------|
| [약탈] | 승리 시 아군 전원 중 랜덤 1기의 ✕에 [연마] |
| [귀순] | 승리 시 적 전체 풀(Named 제외)에서 랜덤 Nameless 1종 획득. 병종 유지 |
| [수습] | 승리 시 부상 Named 1기 회복 |

### 비전투 태그 (5개)

분기 레벨. 비전투 분기에 붙음. 최대 1개.

| 태그 | 효과 |
|------|------|
| [증원] | Nameless 1기 추가. 병종 선택(보/창/궁) |
| [합류] | Nameless 1기 추가. 병종 랜덤(보/창/궁) |
| [훈련] | 아군 1기의 ✕에 [연마] |
| [치료] | Named 부상 회복 |
| [재편] | Nameless 1기 병종 교체(보/창/궁 선택) |

### 우연 태그 (5개)

카드 레벨. 우연 카드에 붙음. 1개. 3분위 체계.

| 분위 | 태그 | 효과 |
|------|------|------|
| 행운 | [표류] | 랜덤 Nameless 1기 추가(민병/보병/창병/궁병/기병 5종 전부 가능) |
| 행운 | [복잡한 운명] | 아군 전원 중 랜덤 1기에 [단조] |
| 불운 | [불운] | Named 부상. 이미 부상이면 사망 |
| 불운 | [탈영] | 랜덤 Nameless 1기 제거 |
| 전투 | [복병] | 적 테이블 포함. 전 라운드 적만 선제, 아군 선제 무력화. 강제 전투 |

## ⑤ 서브 메카닉

태그가 참조하는 하위 규칙. 한 번 정의, 여러 태그에서 재사용.

| 이름 | 규칙 |
|------|------|
| [연마] | ✕ 1개 → d10 판정: ★ 10% / ⚔ 30% / 🛡 30% / ✕ 30% |
| [열화] | 유효면(⚔ 또는 🛡) 1개 → d10 판정: ⚔ 33% / 🛡 33% / ✕ 33% |
| [단조] | [연마] 1회 + [열화] 1회 동시 수행. 각각 별도 면에 적용 |

서브 메카닉을 참조하는 태그: [훈련], [약탈] → [연마]. [복잡한 운명] → [단조].

비유: 대장장이 메타포. 연마(숫돌에 간다) / 열화(닳아 무뎌진다) / 단조(달구고 두드린다 — 좋아지기도 나빠지기도).

---

## ⑥ 세부 규칙

### 전황과 전술의 상호작용

전황은 전장 조건, 전술은 부대 행동. 별개 레이어로 동시 적용.

| 케이스 | 처리 |
|--------|------|
| [기습] + [봉쇄] | R1은 기습(일방적 굴림)이 우선 — 선제 개념 불필요. R2부터 봉쇄의 "아군만 선제" 적용 |
| [기습] + [결투] | 결투 판정 먼저 → 결과 반영 → R1 기습 일방적 굴림 |
| [기습] + [난전] | R1 기습 일방적 굴림. R2부터 난전 적용 — 패시브 전부 무력화 |
| [결전] + [난전] | 결사 R3부터 + 패시브 무력화. 동시 적용. 충돌 없음 |
| [결전] + [결투] | 결투 판정 → 결과 반영 → 7스텝(결사 R3부터) |

### 태그 효과와 병종 패시브의 구분

태그 효과 ≠ 병종 패시브. [난전]은 병종 패시브(방진/반격/선제공격/쇄도)를 무력화하지만, 태그 효과([봉쇄]의 "아군만 선제")는 무력화하지 않는다. [봉쇄]의 선제는 궁병 패시브 '선제 공격'과 달리 태그가 부여하는 별도 효과.

### 전투 후 태그 발동 조건

| 조건 | 발동 |
|------|------|
| 전투 승리 | 발동 |
| 전투 패배 | 불발 |

패배 시 발동 태그는 현재 없음. 추후 확장 가능.

### 우연 3분위

| 분위 | 성격 | 덱 설계 용도 |
|------|------|-------------|
| 행운 | 아군에게 좋은 일 | 스테이지별 긍정 우연 비율 조절 |
| 불운 | 아군에게 나쁜 일 | 스테이지별 부정 우연 비율 조절 |
| 전투 | 강제 전투 발동 | 우연 전투 빈도 조절. 적 테이블 포함 |

우연 전투는 하위 유형. [복병] 외 추가 가능 (예: 조우 등).

## ⑦ 예시

### 전투 카드

```
「강변의 보초」 [기습]
  "다리 이쪽 끝에 적 보초 둘이 서 있다."

  A. 숨어서 친다 [봉쇄]-[약탈]
     "풀숲에 엎드려 기다린다. 적이 등을 보이면 움직인다."
     적: 보초 2기

  B. 정면에서 간다 [결투]-[귀순]
     "정면으로 나선다. 적장이 칼을 뽑았다."
     적: 보초 2기 + Named
```

### 비전투 카드

```
「버려진 야영지」
  "불 꺼진 야영지. 아직 온기가 남아 있다."

  A. 수색한다 [훈련]
     "장비를 뒤진다. 쓸 만한 것이 있다."

  B. 부상자를 돌본다 [치료]
     "약초가 있다. 충분하지는 않다."
```

### 우연 카드 — 불운

```
「밤의 그림자」 [탈영]
  "아침에 세어보니 한 명이 없다. 아무도 보지 못했다."
```

### 우연 카드 — 전투

```
「매복이다!」 [복병]
  "숲에서 적이 튀어나왔다."
  적: 복병 테이블
```

### 운명 카드

```
「도하 저지」 [결전]-[수습]
  "적 본대가 강을 건너온다. 이것이 끝이다."
  운명 조건: 적 병력 전멸
  적: 본대 테이블
```

## ⑧ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 분기 효과 enum을 폐기했나? | 태그로 통합하면 카드 = 서술 + 태그 배열로 단일화. 스키마가 극단적으로 단순해지고 AI 파이프라인(스토아 팩토리)에서 "이 소재에 어떤 태그를 붙일 것인가"만 판단하면 됨 |
| 왜 2레이어(카드/분기)인가? | 전황(세계가 정한 것)과 전술(내가 고른 것)의 분리. 소규모 부대가 전황을 바꿀 수 없지만 전술은 선택할 수 있다 — Chronicle의 서사와 일치 |
| 왜 전황은 최대 1개인가? | 조합 충돌 규칙이 필요 없어짐. 1개면 충돌 자체가 불가능 |
| 왜 전술-전투 후가 강제 쌍이 아닌가? | 전술 없는 순수 전투, 보상 없는 전투도 존재해야 카드 다양성이 나옴 |
| 왜 비용을 서술로 표현하나? | 비용 태그를 두면 슬롯이 복잡해짐. 서술로 표현하면 스키마 단순 + 서사 자유도 확보 |
| 왜 전리품을 업적 카드로 이관했나? | 런 중 영구 효과 축적이 통제 불가. 업적 카드(런당 2회, Chapter 전환)로 제한하면 영구 효과 총량이 설계자 손에 있음 |
| 왜 우연을 3분위로 나눴나? | 행운/불운/전투로 분류하면 덱 설계 시 스테이지별 우연 기대값을 조절 가능 |
| 왜 [난전]이 전술인가? | "뒤엉켜 싸운다"는 선택 가능한 전투 방식. "이 전장이 난전이다"(전황)가 아니라 "난전으로 간다"(전술) |
| 왜 [복병]이 우연인가? | 매복을 당하는 건 선택이 아니라 통제 밖의 사건. 고르는 게 어색함 |

## ⑨ 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| **전술 태그 확장** | 3개. 30개 목표 대비 최우선 보강 대상 | 7스텝 불변 범위 내 전투 다양성 아이디어 |
| **[봉쇄] 범위** | "아군만 선제"가 궁병 선제만인지 기병 쇄도 포함인지 미정 | 전투구조와 정합성 확인 |
| **[결투] 상세** | 판정 절차, 라운드 상한, 무승부 처리 미정 | 별도 미니게임 설계 |
| **[수습] 대상 선택** | 부상 Named 여러 명일 때 플레이어 선택인지 랜덤인지 | 밸런스 판단 |
| **[훈련] 대상 선택** | 아군 1기를 플레이어가 고르는지 랜덤인지 | 밸런스 판단 |
| **태그 총량 목표** | 19개 → 30개. 11개 부족 | 카테고리별 확장 설계 |
| **우연 전투 확장** | [복병] 외 추가 우연 전투 태그 가능 | 덱 다양성 필요 시 |
