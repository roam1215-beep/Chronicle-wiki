## ① 한 줄 요약

이야기카드를 대량 생산하기 위한 필드 정의. 이 스키마를 채우면 카드 1장이 완성된다. 전투/사건/우연-전투/우연-이벤트/운명 5종 공통 구조. **분기 없음. 뒤집으면 즉발.**

## ② 카드 유형 요약

| 유형 | 분기 | 태그 구성 | 전투 진입 | 정찰 정보 |
|------|------|----------|----------|----------|
| **전투** | 없음 | 전략 0~1 + 전술 1 + 전투후이벤트 1 | ✅ | 완전 공개 |
| **사건** | 없음 | 이벤트 1~2 | ❌ | 완전 공개 |
| **우연-전투** | 없음 | 포츈-배틀 1 + 전투후이벤트 1 | ✅ (강제) | "우연 카드"만 |
| **우연-이벤트** | 없음 | 포츈-이벤트 1~2 | ❌ | "우연 카드"만 |
| **운명** | 없음 | 전략 1 + 전술 1 + [이끌림] | ✅ | — (마지막 고정) |

## ④ 적 테이블 구조

적 테이블은 챕터 난이도 레벨(Lv1/2/3)별 엔트리를 가진다. 같은 카드가 챕터 위치에 따라 다른 적을 제공.

```
ENE-BRIDGE-SCOUT:
  Lv1 (Chapter 1): 민병×2
  Lv2 (Chapter 2): 민병×2 + 궁병×1
  Lv3 (Chapter 3): 민병×2 + 궁병×1 + Named보병
```

| 항목 | 내용 |
|------|------|
| **레벨 수** | 3 (Chapter 1/2/3) |
| **배정** | 런 시작 시 팩 배정 순서 = 챕터 레벨 |
| **효과** | 같은 팩이 Chapter 1이면 Lv1, Chapter 3이면 Lv3 |

## ⑤ ID 규칙

### 팩 카드 (전투/사건/우연)

```
{인물}-V{권}-{팩}-{번호}

인물: THEODORA 등
권: V1, V2
팩: PACK_A ~ PACK_I (구체 지명 확정 시 변경)
번호: 001~081 (일반 카드)

예시:
  THEODORA-V1-PACK_A-001  = 팩 A, 카드 001
  THEODORA-V1-PACK_C-042  = 팩 C, 카드 042
```

### 운명 카드

```
{인물}-V{권}-{팩}-FATE{번호}

예시:
  THEODORA-V1-PACK_A-FATE01  = 팩 A, 운명 01
  THEODORA-V1-PACK_A-FATE09  = 팩 A, 운명 09
```

## ⑥ 검증 규칙

| 규칙 | 조건 |
|------|------|
| **전투 카드 전술 필수** | `card_type == combat` → `tactic_tag` 필수 |
| **전투 카드 이벤트 필수** | `card_type == combat` → `post_event_tag` 필수 |
| **사건 카드 배틀 불가** | `card_type == event` → `event_tags`에 배틀 태그 포함 불가 |
| **사건 이벤트 수** | `card_type == event` → `event_tags` 1~2개 |
| **우연-전투 택1** | `card_type == fortune_combat` → `fortune_battle_tag` 정확히 1개 |
| **우연-이벤트 수** | `card_type == fortune_event` → `fortune_event_tags` 1~2개 |
| **이끌림+결별 동시 불가** | `fortune_event_tags`에 `운명적 이끌림`+`결별` 동시 불가 |
| **전략 태그 동시 불가** | `기습`+`역습` 동시 불가. `우세`+`열세` 동시 불가 |
| **운명 전략/전술 필수** | `card_type == fate` → `strategy_tag`+`tactic_tag` 각 1개 필수 |
| **팩 귀속** | 모든 카드 `pack_id` 필수 |
| **적 테이블 Lv 완전** | `enemy_table_ref`가 있으면 Lv1/2/3 엔트리 전부 존재 |
| **팩당 운명 9장** | `card_type == fate` && 같은 `pack_id` → 정확히 9장 |

## ⑦ 카드 1장의 삶 — 유형별 흐름

### 전투 카드

```
[팩 뒷면] → 페이즈 제시 (뒷면 3장 중 1장)
  → 정찰 대상이면: 공개 (태그+적+보상 전부 보임)
  → 판단에서 버려지면: 전해지지 않은 이야기
  → 감내에서 뒤집히면: 즉발
     ├─ 전략 태그 자동 적용
     └─ 전술 태그 자동 적용
  → 전투 진입 (적 테이블 Lv 참조, 대형 선택)
  → 7스텝 전투
  → 전투 종료
  → 전투 후 이벤트 태그 자동 적용
  → 겪은 카드로 기록
```

### 사건 카드

```
[팩 뒷면] → 페이즈 제시
  → 정찰 대상이면: 공개 (효과 태그 보임)
  → 감내에서 뒤집히면: 즉발
  → 이벤트 태그 적용
     ├─ [모병] 등 선택형: 유저 선택 UI
     └─ [사기 진작] 등 자동형: 자동 적용
  → 겪은 카드로 기록
```

### 우연-전투

```
[팩 뒷면] → 페이즈 제시
  → 정찰 대상이면: "우연 카드" 표시만
  → 감내에서 뒤집히면: 즉발
  → 포츈-배틀 태그 적용 → 강제 전투 진입
  → 7스텝 전투
  → 전투 후 이벤트 태그 적용
  → 겪은 카드로 기록
```

### 우연-이벤트

```
[팩 뒷면] → 페이즈 제시
  → 정찰 대상이면: "우연 카드" 표시만
  → 감내에서 뒤집히면: 즉발
  → 포츈-이벤트 태그 적용
  → 겪은 카드로 기록
```

### 운명 카드

```
[운명 뒷면] → 마지막 위치 고정. 모든 페이즈 종료 후 자동 뒤집기
  → 전략+전술 태그 적용
  → 운명 전투 진입 (적 테이블 Lv 참조)
  → 7스텝 전투
  → 승리: [이끌림] → 추종자 2명 제시, 1명 선택
  → 패배: 게임 오버
  → 겪은 카드로 기록
```

## ⑧ 서술 작성 원칙

| 규칙 | 내용 |
|------|------|
| **태그 미노출** | 카드 앞면에 태그명 표시 안 함. 서술이 효과를 암시 |
| **팩 귀속** | 서술이 팩(장소)에 귀속. "아비뇽 다리 위의 보초" |
| **카드 독립** | 모든 카드는 다른 카드의 존재/결과를 전제하지 않음 |
| **적 힌트 = 서술** | "보초 둘", "대규모 부대". 구체 수치는 전투 시작 후 공개 |
