## ① 한 줄 요약

이야기카드를 대량 생산하기 위한 필드 정의. 이 스키마를 채우면 카드 1장이 완성된다. 전투/사건/우연-전투/우연-이벤트/운명 5종 공통 구조.

## ② 카드 유형 요약

| 유형 | 분기 | 카드 레벨 태그 | 분기 레벨 태그 | 전투 진입 |
|------|------|--------------|--------------|----------|
| **전투** | 2개 | 전략 0~1 | 전술 1(필수) + 전투 후 이벤트 1(필수) | ✅ (분기 양쪽 다 전투) |
| **사건** | 2개 | — | 이벤트 1~2 (배틀 불가) | ❌ |
| **우연-전투** | 없음 | 포츈-배틀 택1 | 전투 후 이벤트 1 | ✅ (강제 전투) |
| **우연-이벤트** | 없음 | 포츈-이벤트 1~2 | — | ❌ |
| **운명** | 없음 | 전략 1(필수) + 전술 1(필수) + [이끌림] | — | ✅ (운명 전투) |

> 태그 상세 → [TAG-RULE-001 태그규칙](./태그규칙.md) 참조

| 필드명 | 타입 | 필수 | 설명 | 예시 |
|--------|------|------|------|------|

## ④ 위장 규칙

우연 카드(전투/이벤트)는 자기 뒷면이 없다. 전투 뒷면 또는 사건 뒷면 중 하나로 위장한다.

| 필드 | 설명 |
|------|------|
| `back_type` | 우연-전투: `combat_back` 또는 `event_back`. 우연-이벤트: `combat_back` 또는 `event_back` |

> 위장 유형은 카드마다 사전 결정. 홀드 탭으로는 진짜와 위장을 구분할 수 없음.
> 우연 빈도(장소 뽑기 비율의 우연 열) 높을수록 위장 카드가 많아져 홀드 탭 신뢰도 하락.

## ⑤ ID 규칙

### 장소 카드 (전투/사건/우연)

```
{인물}-V{권}-{장소}-{일러스트}-{유형}

인물: THEODORA 등
권: V1, V2
장소: LOC_A, LOC_B, LOC_C (구체 지명 확정 시 변경)
일러스트: IL001~IL020 (장소당 20개)
유형: C(전투) / E(사건) / CH(우연)

예시:
  THEODORA-V1-LOC_A-IL001-C   = 장소 A, 일러스트 001, 전투 카드
  THEODORA-V1-LOC_A-IL001-E   = 장소 A, 일러스트 001, 사건 카드
  THEODORA-V1-LOC_A-IL001-CH  = 장소 A, 일러스트 001, 우연 카드
```

### 운명 카드

```
{인물}-V{권}-F{번호}-{변형}

번호: 01~20 (운명 일러스트 20개)
변형: 1/2/3 (같은 일러스트, 다른 태그 조합)

예시:
  THEODORA-V1-F01-1  = 운명 일러스트 01, 변형 1
  THEODORA-V1-F01-2  = 운명 일러스트 01, 변형 2
```

### 일러스트 = 카드 세트

일러스트 1개에서 카드 3장이 나온다. 같은 그림, 다른 카드.

```
일러스트 IL001 (장소 A)
 ├─ THEODORA-V1-LOC_A-IL001-C   전투 카드
 ├─ THEODORA-V1-LOC_A-IL001-E   사건 카드
 └─ THEODORA-V1-LOC_A-IL001-CH  우연 카드
```

## ⑥ 검증 규칙

| 규칙 | 조건 |
|------|------|
| 면 합산 불필요 | 이야기카드는 주사위 면이 없음. 인물카드와 별개 |
| **전투 카드 전술 필수** | `card_type == combat` → `branch_a.tactic_tag` + `branch_b.tactic_tag` 필수 |
| **전투 카드 이벤트 필수** | `card_type == combat` → `branch_a.post_event_tag` + `branch_b.post_event_tag` 필수 |
| **양 분기 차별화** | `branch_a.tactic_tag != branch_b.tactic_tag` AND `branch_a.post_event_tag != branch_b.post_event_tag` |
| **사건 카드 배틀 불가** | `card_type == event` → `event_tags`에 배틀 태그 포함 불가 |
| **사건 이벤트 수** | `card_type == event` → 분기당 `event_tags` 1~2개 |
| **우연-전투 택1** | `card_type == fortune_combat` → `fortune_battle_tag` 정확히 1개 |
| **우연-전투 전술 없음** | `card_type == fortune_combat` → 전술 태그 슬롯 없음 |
| **우연-이벤트 수** | `card_type == fortune_event` → `fortune_event_tags` 1~2개 |
| **이끌림+결별 동시 불가** | `fortune_event_tags`에 `운명적 이끌림` + `결별` 동시 불가 |
| **전략 태그 동시 불가** | `기습`+`역습` 동시 불가. `우세`+`열세` 동시 불가 |
| **운명 전략/전술 필수** | `card_type == fate` → `strategy_tag` + `tactic_tag` 각 1개 필수 |
| **뒷면 유형 정합** | 전투 카드: `combat_back` 고정. 사건 카드: `event_back` 고정. 운명: `fate_back` 고정. 우연: `combat_back` 또는 `event_back` |
| **장소 귀속** | 전투/사건/우연: `location_id` = 장소 ID. 운명: `location_id` = `shared` |
| **일러스트 3종** | 같은 `illust_id`에 C/E/CH 3종 존재해야 함 (운명 제외) |
| **운명 일러스트 3종** | 같은 운명 `illust_id`에 변형 1/2/3 존재. 전략 또는 전술이 달라야 함 |

## ⑦ 카드 1장의 삶 — 유형별 흐름

### 전투 카드

```
[뒷면: 전투 표식] → 페이즈 제시 (뒷면 3장 중 1장)
  → 홀드 탭: "전투 카드" (우연 위장 가능)
  → 블라인드 선택 (2장 중 1장으로 선택될 수 있음)
  → 뒤집기: 앞면 공개
     ├─ 일러스트 + 제목 + 상황 서술
     └─ 분기 A / B 서술 + 적 힌트
  → 분기 선택 (유저 수동)
  → [카드 레벨: 전략 태그 자동 적용 — 유저 미인지]
  → [분기 레벨: 전술 태그 자동 적용 — 유저 미인지]
  → 전투 진입 (적 테이블 공개, 대형 선택)
  → 7스텝 전투
  → 전투 종료
  → [분기 레벨: 전투 후 이벤트 태그 자동 적용 — 유저 미인지]
  → 부대 상태 변경 (면 변환/합류/이탈 등)
  → 겪은 카드로 기록
```

### 사건 카드

```
[뒷면: 사건 표식] → 페이즈 제시
  → 홀드 탭: "사건 카드" (우연 위장 가능)
  → 블라인드 선택
  → 뒤집기: 앞면 공개
     ├─ 일러스트 + 제목 + 상황 서술
     └─ 분기 A / B 서술
  → 분기 선택 (유저 수동)
  → [이벤트 태그 자동 적용 — 유저 미인지]
  → 부대 상태 변경
     ├─ [모병] 등 선택형: 유저 선택 UI 팝업
     └─ [사기 진작] 등 자동형: 자동 적용
  → 겪은 카드로 기록
```

### 우연-전투

```
[뒷면: 전투 or 사건 표식 (위장)] → 페이즈 제시
  → 홀드 탭: "전투 카드" 또는 "사건 카드" (위장)
  → 블라인드 선택
  → 뒤집기: 앞면 = 우연 카드 → 즉시 발동
     ├─ 일러스트 + 제목 + 상황 서술
     └─ 분기 없음
  → [포츈-배틀 태그 자동 적용]
  → 강제 전투 진입 (적 테이블 공개)
  → 7스텝 전투
  → 전투 종료
  → [전투 후 이벤트 태그 자동 적용]
  → 부대 상태 변경
  → 겪은 카드로 기록
```

### 우연-이벤트

```
[뒷면: 전투 or 사건 표식 (위장)] → 페이즈 제시
  → 홀드 탭: "전투 카드" 또는 "사건 카드" (위장)
  → 블라인드 선택
  → 뒤집기: 앞면 = 우연 카드 → 즉시 발동
     ├─ 일러스트 + 제목 + 상황 서술
     └─ 분기 없음
  → [포츈-이벤트 태그 즉시 적용]
  → 부대 상태 변경
     ├─ [보강]/[보급]: 유저 선택 UI
     └─ [와해]/[결별]: 자동 적용
  → 겪은 카드로 기록
```

### 운명 카드

```
[뒷면: 금색 테두리] → 마지막 위치 고정. 모든 페이즈 종료 후 자동 뒤집기
  → 앞면: 장 제목 + 일러스트 + 상황 서술
  → 분기 없음
  → [전략 + 전술 태그 자동 적용]
  → 운명 전투 진입 (적 테이블 공개)
  → 7스텝 전투
  → 승리: [이끌림] → 추종자 2명 제시, 1명 선택
  → 패배: 게임 오버
  → 겪은 카드로 기록
```

## ⑧ 서술 작성 원칙

| 규칙 | 내용 |
|------|------|
| **태그 미노출** | 카드 앞면에 태그명 표시 안 함. 서술이 효과를 암시 |
| **장소 귀속** | L3 장소별 풀이므로 서술이 장소에 귀속. "아비뇽 다리 위의 보초", "파리 성문의 위병" |
| **카드 독립** | 모든 카드는 다른 카드의 존재/결과를 전제하지 않음 |
| **같은 일러스트 3종 차별화** | 같은 그림에서 전투/사건/우연 서술이 각각 다른 상황 |
| **적 힌트 = 서술** | "보초 둘", "대규모 부대". 구체 수치(민병×3 등)는 전투 시작 후 공개 |
| **분기 서술 = 행동** | "숨어서 기습한다" / "정면에서 나선다". 결과가 아니라 선택 |

## ⑨ 스프레드시트 연동

**위키 = 스키마 정의 (이 문서). 스프레드시트 = 데이터 입력.**

| 시트명 | 내용 |
|--------|------|
| `Combat` | 전투 카드 전량. 장소별 |
| `Event` | 사건 카드 전량. 장소별 |
| `Fortune_Combat` | 우연-전투 카드 전량. 장소별 |
| `Fortune_Event` | 우연-이벤트 카드 전량. 장소별 |
| `Fate` | 운명 카드 전량. 장소 무관 |
