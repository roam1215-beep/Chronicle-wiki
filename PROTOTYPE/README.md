# PROTOTYPE — Chronicle 디지털 프로토

> 상태: 진행중 (5-9 박음 시작) · 의존: 위키 본문

## 정의

UI 목업 + 동선 박는 자리. 마디마다 한 자리씩 박음. HTML 결 (반응성). 살아남 + 클로드 코드 레퍼런스.

## 결

```yaml
도구:        Visualizer 결 (Claude 본 채팅에서 박음)
형식:        HTML + CSS + JS (인라인 SVG 가능)
저장:        git 결로 영구 (이 자리)
반응성:      클릭/터치 = 자리 → 자리 전환

진행 결:
  C 결 (자리 단위, 마디마다)
  반응성 a 결 (마디마다 박을 때 반응성 같이)
  위키 박음 a 결 (마디마다 즉시 + 커밋)

자리 단위:
  index.html      = 통합 결 (모든 자리 묶음, 반응성)
  자리1_*.html    = 개별 자리 (자기 결로 살아남)
  자리2_*.html    = 다음 자리
  ...

본인 자리:
  플레이어 결 (클릭/터치)
  결 짚는 결 (이 자리 어떤지)
  본인 결 짚어주면 다음 자리

클로드씨 자리:
  결 박는 결 (HTML/CSS/JS)
  본인 결 살리는 결
  위키 박음 + 커밋
```

## 박힌 자리

| 자리 | 결 | 박힘 |
|------|------|------|
| 1 | 도서관 단계 0 (첫 진입) | ✓ 5-9 |
| 2 | 인물 목록 ([이야기] 클릭 후) | 펜딩 |
| 3 | 책 펼침 (인물 페이지) | 펜딩 |
| 4 | Order 선택 / 인격 선택 | 펜딩 |
| 5 | 편성 (틀만) | 펜딩 |
| 6 | Stage 페이즈 진입 | 펜딩 |
| 7 | Phase 카드 결 | 펜딩 |
| 8 | Battle 전투 | 펜딩 |
| 9 | Order 클리어 → 도서관 단계 1 | 펜딩 |

## 결 짚을 자리

```yaml
정적 결 vs 시뮬 결:
  지금 자리 = 정적 목업 (UI 동선 박음)
  다음 자리 = 시뮬 결 (실제 게임 결 굴러감)
  본인 결: 디지털 프로토 = UI 동선 + 시뮬 둘 다 박음
  순서: UI 먼저 → 시뮬 나중

반응성 결:
  HTML + JS 박힘
  본 채팅에서 = 클릭/터치 굴러감
  클로드 코드 = 결 그대로 읽음 (레퍼런스)

위키 결:
  마디마다 자리 박음 + 즉시 커밋
  자리별 .html = 살아남
  index.html = 묶음 결

폐기:
  종이 프로토 결 (5-5부터 1순위, 5-9까지 진입 X)
  → 디지털 프로토 결로 흡수 (5-9 박음)
```
