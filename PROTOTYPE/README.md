# PROTOTYPE — Chronicle 디지털 프로토

> 상태: 진행중 (5-9 시작) · 의존: 위키 본문

## 정의

UI 목업 + 동선 정리. 마디마다 한 단계씩. HTML (반응성). 보관 + Claude Code 레퍼런스.

## 구조

```yaml
도구:        Visualizer (Claude 본 채팅에서 작성)
형식:        HTML + CSS + JS (인라인 SVG 가능)
저장:        git으로 영구 (이 폴더)
반응성:      클릭/터치 = 단계 → 단계 전환

진행:
  C (단계 단위, 마디마다)
  반응성 a (마디마다 작성하면서 반응성도)
  위키 작성 a (마디마다 즉시 + 커밋)

단계 단위:
  index.html      = 통합 (모든 단계 묶음, 반응성)
  자리1_*.html    = 개별 단계 (자기 단위로 살아남)
  자리2_*.html    = 다음 단계
  ...

본인 역할:
  플레이어 (클릭/터치)
  피드백 (이 단계 어떤지)
  본인 피드백 주면 다음 단계로

클로드씨 역할:
  작성 (HTML/CSS/JS)
  본인 의도 살리기
  위키 작성 + 커밋
```

## 진행 단계

| 단계 | 내용 | 상태 |
|------|------|------|
| 1 | 도서관 단계 0 (첫 진입) | ✓ 5-9 |
| 2 | 인물 목록 ([이야기] 클릭 후) | 펜딩 |
| 3 | 책 펼침 (인물 페이지) | 펜딩 |
| 4 | Order 선택 / 인격 선택 | 펜딩 |
| 5 | 편성 (틀만) | 펜딩 |
| 6 | Stage 페이즈 진입 | 펜딩 |
| 7 | Phase 카드 | 펜딩 |
| 8 | Battle 전투 | 펜딩 |
| 9 | Order 클리어 → 도서관 단계 1 | 펜딩 |

## 짚을 부분

```yaml
정적 vs 시뮬:
  지금 = 정적 목업 (UI 동선)
  다음 = 시뮬 (실제 게임 굴러감)
  본인 의도: 디지털 프로토 = UI 동선 + 시뮬 둘 다
  순서: UI 먼저 → 시뮬 나중

반응성:
  HTML + JS
  본 채팅에서 = 클릭/터치 굴러감
  Claude Code = 그대로 읽음 (레퍼런스)

위키 작업:
  마디마다 단계 추가 + 즉시 커밋
  단계별 .html = 살아남
  index.html = 묶음

폐기:
  종이 프로토 (5-5부터 1순위, 5-9까지 진입 X)
  → 디지털 프로토로 흡수 (5-9)
```
