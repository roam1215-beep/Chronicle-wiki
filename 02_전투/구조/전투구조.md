# 전투 구조

## 5층

```yaml
Order > Chapter > Stage > Phase > Battle (Round)

Phase:  카드 시스템 (선택-거부-감내 3장). 최대 2 Battle.
Battle: 전투 카드 1장 = 1 전투 인스턴스
Round:  Battle 최소 단위. 명령 → 굴림 → 결산.
```

## 배틀

```yaml
R1 시간대:
  첫 배틀:     페이즈 시작 시간대
  두 번째 배틀: 이전 배틀 마지막 라운드 시간대

라운드 상한: 5 (자연 결판 우선)
배틀 종료: 양 진영 중 한쪽 전멸
새 배틀 진입 시: hp 재계산 (회복)
```

## 라운드 흐름

```yaml
1. 명령 (라운드 시작 전, 유저 결단):
   모든 인물 배치 자유 변경 (전열·후열·좌·우)
   라운드 안 결단 X

2. 굴림: 의지 주사위 (등급 수만큼)

3. 결산 (3 페이즈 순서):
   페이즈 1: 보호·축복·저주 — 진영별 (우리 → 적)
   페이즈 2: 사격 — 동시
   페이즈 3: 격돌 — 동시 (좌→우는 자기 진영 안)
```

## 페이즈 1 — 보호·축복·저주

```yaml
순서: 진영별 (우리 → 적)

행동:
  지상 사제 / 축복:
    우리 진영 전열 좌측에 임시 방어도
    대성공: 축성 (방어도량 증가)
  
  미궁 사제 / 저주:
    적 진영 전열 좌측에 피해 또는 스탯 감소
    대성공: [펜딩]
  
  수호자 / 수호 (대성공만):
    자신에게 임시 방어도

도발 효과 X (격돌이 아니라)
대상이 좌측 X면 다음 좌측 (전열 다 죽으면 후열 좌측)
```

## 페이즈 2 — 사격

```yaml
순서: 동시 결산 (양쪽 다 사망 가능)

행동:
  사냥꾼 / 사격:
    자기 위치에서 가장 먼 적 (열 기준)
    자기 피해 X
    공격력만큼 피해
    도발 효과 받지 X
    대성공: 저격 (추가 피해)

거리감 (열 기준):
  사냥꾼 자기 좌측 → 가장 먼 = 적 우측 (전열·후열 중 같은 열)
  사냥꾼 자기 우측 → 가장 먼 = 적 좌측

후열 사냥꾼 = 적 전열 가장 좌측 공격
```

## 페이즈 3 — 격돌

```yaml
순서: 동시 결산 (양 진영)
     좌→우는 자기 진영 안에서만

행동:
  전사 / 돌격:
    적 전열 가장 좌측 또는 도발 대상
    자기도 격돌 받음 (동시)
    대성공: 격파 (양 옆 광역, 옆 X면 광역 X)
            격돌 피해는 첫 전투 대상에게만
  
  수호자 / 방어:
    도발 (격돌 첫 피격)
    대성공: 수호 (페이즈 1에서 발동)

격돌 결산:
  공격력 = 상대 hp 직격 (하스스톤 전장식)
  모든 우리 전사 = 적 좌측만 공격
  적 좌측 사망 시 → 다음 좌측

피해 흐름: 보호막 (1번 무효) → 방어도 (감산) → hp
```

## 도발

```yaml
전열에서만 작동
후열 가면 도발 X 취급
다음 라운드 명령 시 전열로 옮기면 살아남

도발 ×N명: 전열 가장 좌측부터 좌→우 순서로 피격
축복·저주·사격: 도발 효과 받지 X
```

## 자리 변동

```yaml
조건: 전열 모두 다 사망
시점: 다음 라운드 시작

방식:
  후열 인물 = 자기 위치의 전열로 이동
  자기 위치 자리 X면 가장 가까운 빈 자리 메움

전열 부분 사망 = 자리 변동 X
전열 비우는 결 X (전열 배치 필수)
```

## 격돌 예시

```yaml
사례 (테오도라 [공 2 / hp 3] ↔ 도적 [공 1 / hp 2]):
  테오도라 → 도적: 공 2 직격, 도적 hp 0 = 사망
  동시에 도적 → 테오도라: 공 1, 테오도라 hp 2

대성공 격파 (테오도라 [공 2] / 적 좌측·우측 모두 hp 2):
  테오도라 → 적 좌측: 공 2 직격, 사망
  격파 광역 → 적 좌측의 양 옆: 공 2 직격, 양 옆도 피해
  테오도라 격돌 피해는 첫 전투 대상 (적 좌측)에게만
```
