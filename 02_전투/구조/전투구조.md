# 전투 구조 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 순서 점수 결, 라운드 안 결단, 편성 자리
> 정정: 페이즈 결산, 격돌 결, 자리 변동

---

## 5층 구조

```yaml
Order > Chapter > Stage > Phase > Battle (Round)

Order:    확장팩 결 (Order 1 = 미궁의 테오도라)
Chapter:  큰 마디 (Order 1 안에서 3 챕터)
Stage:    중간 마디 (Chapter 안에서)
Phase:    카드 시스템 결 (선택-거부-감내 3장)
Battle:   전투 카드 1장 = 1 전투 인스턴스
Round:    Battle의 최소 단위
```

---

## 페이즈 ↔ 배틀 ↔ 라운드

```yaml
페이즈:
  카드 시스템 (선택-거부-감내 3장)
  최대 2 배틀 (1·2번 카드 둘 다 전투면)

배틀:
  전투 카드 1장 = 1 전투 인스턴스
  R1 시간대:
    첫 배틀:     페이즈 시작 시간대
    두 번째 배틀: 이전 배틀의 마지막 라운드 시간대 이어짐

라운드:
  Battle의 최소 단위
  명령 → 굴림 → 결산
  라운드 상한: 임시 5 (자연 결판 우선)
```

---

## 라운드 흐름

```yaml
1. 명령 (라운드 시작 전, 유저 결단):
   - 모든 인물 배치 자유 변경 (전열·후열·좌·우)
   - 라운드 안 결단 X (개입 X, 결과만 봄)

2. 굴림: 의지 주사위 (등급 수만큼)
   각 주사위 독립 결과 (대성공/통상/실패)

3. 결산 (3 페이즈 순서):
   페이즈 1 (보호·축복·저주): 진영별 결산 (우리 → 적)
   페이즈 2 (사격):              동시 결산 (양쪽 다 사망 가능)
   페이즈 3 (격돌):              동시 결산 (좌→우는 자기 진영 안)
```

---

## 페이즈 1 — 보호·축복·저주

```yaml
순서: 진영별 결산 (우리 → 적)

행동 자리:
  지상 사제 / 축복:
    우리 진영 전열 좌측에 임시 방어도
    대성공: 축성 (방어도량 증가)
  
  미궁 사제 / 저주:
    적 진영 전열 좌측에 피해 또는 스탯 감소
    대성공: 펜딩
  
  수호자 / 수호 (대성공만):
    격돌 전 임시 방어도 (자신에게)
    통상은 방어 (페이즈 3에서)

도발 효과 X (격돌이 아니라)

결산 자리:
  우리 페이즈 1 → 우리 사제·수호자 행동
  적 페이즈 1 → 적 사제·수호자 행동
  대상 인물이 사망해도 동시 결산 X (진영별이라)
```

---

## 페이즈 2 — 사격

```yaml
순서: 동시 결산 (양 진영)

행동 자리:
  사냥꾼 / 사격:
    자기 위치에서 가장 먼 적 (열 기준)
    자기 피해 X
    공격력만큼 피해
    대성공: 저격 (추가 피해)
  
  도발 효과 받지 X (격돌이 아니라)

동시 결산 결:
  양쪽 사냥꾼이 동시 사격
  둘 다 사망 가능 (카운터 결)
  → 자기 굴림 ×N → 같은 자리 ×N 피해 (자기 피해 X)

거리감 (열 기준):
  사례: 적 전열 가 나 / 후열 다 라
  사냥꾼 자기 좌측 → 가장 먼 = 라 (자기 좌측 ↔ 적 우측)
  사냥꾼 자기 우측 → 가장 먼 = 다(자기 좌측 ↔ 적 우측 후열)
```

---

## 페이즈 3 — 격돌

```yaml
순서: 동시 결산 (양 진영)
     좌→우는 자기 진영 안에서만

행동 자리:
  전사 / 돌격:
    적 전열 가장 좌측 또는 도발 대상
    자기도 적 공격 받음 (격돌 동시)
    대성공: 격파 (양 옆 광역, 옆 X면 광역 X)
  
  수호자 / 방어:
    도발 (격돌 첫 피격)
    대성공: 수호 (페이즈 1에서 발동)

격돌 결산:
  공격력 = 상대 hp 직격 (하스스톤 전장식)
  방어도·보호막은 피해 흐름에 박힘

좌→우 순서:
  자기 진영 안에서만 좌→우 결산
  양 진영은 동시 (페이즈 1처럼 진영별 X)
  적 좌측 사망 시 = 다음 좌측으로 자연 이동

피해 흐름:
  적 공격 → 보호막 (1번 무효) → 방어도 (감산) → hp
```

---

## 도발 결

```yaml
전열에서만 작동:
  후열 가면 도발 X 취급
  후열 도발 유닛 = 일반 유닛처럼 결산

다음 라운드 명령 시:
  전열로 옮기면 도발 살아남 (유저 결단)

도발 ×N명:
  전열 가장 좌측 도발 유닛부터 좌→우 순서로 피격
  도발 다 사망 후 = 일반 유닛 박힘

축복·저주·사격:
  도발 효과 받지 X (격돌만 도발 결 박힘)
```

## 자리 변동 (자리 ㅁ)

```yaml
조건:
  전열 모두 다 사망 (전열 인물 다 죽음)
  전열 부분 사망 = 자리 변동 X

시점:
  다음 라운드 시작

방식 (자리 ㅁ):
  후열 인물 = 자기 위치의 전열로 이동
  자기 위치 자리 X면 가장 가까운 빈 자리 메움

전열 배치 결:
  전열 비우는 결 X (전열 배치 필수)

사례 1 (후열 1명):
  현재:    전열: [죽] [죽] / 후열: [__] [사냥꾼]
  변동 후: 전열: [__] [사냥꾼] / 후열: [__] [__]
  (자기 위치 그대로 = 우측)

사례 2 (후열 2명):
  현재:    전열: [죽] [죽] / 후열: [사냥꾼] [사제]
  변동 후: 전열: [사냥꾼] [사제] / 후열: [__] [__]
  (모든 자기 위치 그대로)
```

## 격돌 결산 결

```yaml
공격 대상:
  모든 우리 전사 = 적 좌측만 공격 (자기 위치 결)
  적 좌측 = 1) 도발 자리 2) 일반 자리 좌→우
  적 좌측 사망 시 = 다음 좌측

격돌식 (하스스톤 전장):
  공격력 = 상대 hp 직격
  자기도 적 공격 받음 (동시)
  
  사례 (테오도라 [공 2 / hp 3] ↔ 도적 [공 1 / hp 2]):
    테오도라 → 도적: 공격력 2 직격, 도적 hp 0 = 사망
    동시에 도적 → 테오도라: 공격력 1, 테오도라 hp 2

수동 격돌 (실패 면 박힌 인물):
  격돌 직업 (전사·수호자) = 자기 스탯대로 자동 반응
  원거리·사제 = 행동 X (수동도 X)

대성공 효과 (격파):
  돌격 대상 + 양 옆 광역 (옆 X면 광역 X)
  격돌 피해는 첫 전투 대상에게만 받음
  지속: 그 라운드만
```

## 폐기 자리 (5-12 후속)

```yaml
✗ 순서 점수 결 (시간대 보정 + 속도)
  → 좌→우 자리 결로 흡수 (자기 진영 안)
  → 양 진영 동시 결산

✗ 라운드 안 결단 (영웅·반신 1회)
  → 모든 인물 자동 매커니즘

✗ 편성 자리 (Recruit Phase)
  → 파티 한 번 정해지면 쭉 (1 스테이지 기준)

✗ 사거리 = 모든 직업 1열만
  → 사냥꾼·사제 = 자기 위치 가장 먼 적

✗ 방어력 능력치
  → 방어도(감산) / 보호막(이진) 분리

✗ 다이시 테일즈식 결산
  → 하스스톤 전장식 (공격력 직격)

✗ 격돌 양쪽 살아남 결산식 (박힌 면 × 능력치)
  → 단순 공격력 직격
```

---

## 정정 자리

```yaml
- 격돌 결산 = 하스스톤 전장식
- 페이즈 결산 = 1 진영별 / 2·3 동시
- 좌→우 = 자기 진영 안에서만
- 사냥꾼 거리 = 열 기준 가장 먼
- 도발 = 전열만 (조건 결)
- 자리 변동 = 전열 다 사망 시 (자리 ㅁ)
- 매 라운드 배치 자유 변경 (유저 결단)
```
