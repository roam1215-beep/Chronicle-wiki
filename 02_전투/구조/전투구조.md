# COMBAT-STRUCT-001: 전투 구조

> 상태: 설계중 · 의존: @COMBAT-DICE-001, @COMBAT-UNIT-CARD, @COMBAT-JUDGE-001

## 정의

전투 = 라운드 반복. 매 라운드 7스텝 실행. 4종 면 주사위(⚔🛡✕★)와 카드별 공/방 스칼라가 합산되어 피해를 결정한다. 카드 1장 = 주사위 1개 = 유닛 1기.

## 규칙

### 라운드 흐름

```yaml
round:
  steps:
    1: 선제      # 궁병 패시브 등 선제 효과 발동
    2: 전체굴림  # 아군·적 모든 유닛 동시 굴림
    3: 리롤      # 1회 무료 (TODO: 부활 여부)
    4: 쇄도      # 기병 ★ 파생 등
    5: 패시브    # 방진/반격/선제 등 (TODO: 시스템 정합)
    6: 합산      # 피해 = 아군 ⚔합 × 공격력 - 적 🛡합 × 방어력
    7: 전과      # 피해 적용. 사상자 처리
  termination:
    - 적 전멸: 승리
    - 아군 전멸: 패배
    - 테오도라 사망: 게임 오버
    - 라운드 상한: TODO(엔진): 8라운드 / 결사 부활 여부 결정 후
```

### 공격력 / 방어력 스칼라

```yaml
power_scalar:
  purpose: 같은 ⚔/🛡 면이 카드마다 다른 가중치를 가진다
  calculation:
    incoming_damage: ⚔합 × 공격력
    incoming_block: 🛡합 × 방어력
    final: max(0, 공격_총 - 방어_총)
  range:
    nameless: { atk: 1, def: 1 }            # 기준값
    named: TODO(밸런스): 프로토 후
  examples:
    - { card: PLY-NL-INFANTRY, atk_power: 1, def_power: 1, note: 표준 보병 }
    - { card: PLY-ND-THEODORA, atk_power: 3, def_power: 1, note: 공격 특화 Named }
```
