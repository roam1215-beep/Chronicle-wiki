# COMBAT-COLOR-KEEP: 색 매칭 · 킵 시스템 (Color Matching & Keep System)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** COMBAT-COLOR-KEEP · **수정일:** 2026-04-08

---

## ① 한 줄 요약

인물에게 색(빨강/파랑/검정)이 있다. 전투 중 색과 결과면이 일치하면 매칭. 매칭 2개마다 킵(확정 면)을 벌고, 킵은 이번 전투에 쓰거나 다음 전투로 가져간다. 아르멜로 다이스 배틀 위에 크로니클만의 전투 간 연결과 편성 깊이를 얹는 시스템.

---

## ② 색상 체계

### 색상 정의

| 색 | 대응 면 | 킵 보상 | 비고 |
|-----|---------|---------|------|
| **빨강** | ⚔ | 킵 칼 (확정 ⚔) | 공격 계열 |
| **파랑** | 🛡 | 킵 방패 (확정 🛡) | 방어 계열 |
| **검정** | ✕ | 킵 리롤 (추가 리롤 1회) | 실패→자원 전환 |
| **무색** | — | 매칭 불가 | 킵 생산 없음 |

> **DLC 예정:** 금색 (★ 대응). 기본판 미등장.
> **비전투:** 초록 (사건/정찰 대응). 전투 색 매칭에 참여하지 않음. 별도 체계 예정.

### 색상 부여 규칙

| 대상 | 색상 | 비고 |
|------|------|------|
| 아군 Named | 유색 가능 | 인물카드에 명시 |
| 아군 Nameless | 유색 가능 | 인물카드에 명시 |
| 적 일반 | **대부분 무색** | 레벨 디자인으로 통제 |
| 적 보스/운명급 | 유색 가능 | 위협 신호 |

> **색 배분이 곧 난이도 설계.** 적의 무색 비중을 높여 아군 킵 시스템의 우위를 구조적으로 보장.

## ③ 색 매칭 규칙

### 매칭 조건

**색과 결과면이 일치해야만 매칭.**

| 색 | 매칭 성립 | 매칭 불성립 |
|----|----------|-----------|
| 빨강 인물 | 결과면 ⚔ | 🛡, ★, ✕ |
| 파랑 인물 | 결과면 🛡 | ⚔, ★, ✕ |
| 검정 인물 | 결과면 ✕ | ⚔, 🛡, ★ |
| 무색 인물 | — (매칭 불가) | 모든 면 |

> **색이 있어도 면이 안 맞으면 매칭 0.** 빨강 궁병이 ⚔를 내야 빨강 매칭. 빨강 창병(⚔ 0%)은 반격(🛡→⚔) 후에만 빨강 매칭 가능. 색×병종 궁합이 편성 판단을 만든다.

### 매칭 타이밍

**스텝5(방진/반격) 후, 스텝7(전과) 전 = 스텝6(색 매칭 판정).**

방진/반격 전환 결과가 반영된 최종 면으로 매칭 판정. 쇄도(스텝4)로 ✕화된 면도 반영.

### 매칭 카운트

| 규칙 | 내용 |
|------|------|
| **카운트 단위** | 라운드 |
| **라운드 간** | **리셋.** 매 라운드 0부터 카운트 |
| **산개** | 유닛별 개별 카운트 |
| **밀집** | **유닛 수만큼 카운트.** 빨강 보병 3기 밀집 → 결과면 ⚔ → 빨강 매칭 3 |
| **적 매칭** | 유색 적이 있으면 적도 매칭 판정. 단, 적은 킵하지 않음 (즉시 사용만) |

### 킵 생산

**매칭 2개마다 킵 1개 생산.**

| 매칭 수 | 킵 생산 |
|---------|--------|
| 0~1 | 0개 |
| 2~3 | 1개 |
| 4~5 | 2개 |
| 6~7 | 3개 |

## ④ 킵 시스템

### 킵이란

**이전 전투의 성과를 다음 전투에 가져가는 확정 면.** 주사위가 아니다.

### 킵 종류

| 킵 | 효과 (즉시 사용) | 효과 (다음 전투 배치) |
|----|-----------------|---------------------|
| **킵 칼** | 이번 스텝7 전과에 ⚔+1 합산 | 전투 전 배치 → 스텝7 전과에 ⚔+1 합산 |
| **킵 방패** | 이번 스텝7 전과에 🛡+1 합산 | 전투 전 배치 → 스텝7 전과에 🛡+1 합산 |
| **킵 리롤** | 이번 라운드 스텝3(리롤)에 사용 불가 (이미 지남). **다음 라운드 또는 다음 전투에서 사용** | 스텝3에서 기존 리롤과 합산 사용. 기존 리롤 규칙 동일 |

### 킵 상한

| 필드 | 내용 |
|------|------|
| **상한** | **챕터 수와 동일** |
| **Ch1** | 1개 |
| **Ch2** | 2개 |
| **Ch3** | 3개 |
| **기준** | **총합.** 색별 아님. 칼 1 + 방패 1 = 2개 |
| **상한 초과** | 초과분은 **즉시 사용.** 킵 불가 |

### 스텝6: 킵 사용/저장 판단 (수동)

| 순서 | 처리 |
|------|------|
| 1 | 색 매칭 카운트 (자동) |
| 2 | 킵 생산량 확정 (자동) |
| 3 | 생산된 킵 각각에 대해: **즉시 사용 or 킵(저장)** 선택 (수동) |
| 4 | 상한 초과분 즉시 사용 (자동) |
| 5 | 스텝7(전과) 진행 |

> **즉시 사용 = 이번 라운드 스텝7 전과에 합산.** 킵 칼 즉시 사용 → ⚔+1. 킵 방패 즉시 사용 → 🛡+1.
> **킵 리롤 즉시 사용:** 이미 스텝3을 지났으므로 이번 라운드 사용 불가. **다음 라운드 스텝3 또는 다음 전투에서 사용.**

### 킵 배치 (다음 전투)

| 필드 | 내용 |
|------|------|
| **배치 타이밍** | **7스텝 진입 전.** ⓪ 대형 선택 시점 |
| **킵 칼/방패** | 전투판에 확정 면으로 배치. 어떤 유닛에 붙이는 것이 아님. 전체 합산에 추가 |
| **킵 리롤** | 배치 아님. 스텝3에서 기존 리롤과 합산 사용 |
| **선택** | 보유 킵 중 어떤 것을 이번 전투에 쓸지, 얼마나 쓸지 플레이어 선택 |

### 킵 속성

| 속성 | 내용 |
|------|------|
| **색상** | **무색.** 색 매칭에 기여하지 않음 |
| **주사위 여부** | **아님.** 킵은 주사위가 아닌 확정 면 |
| **쇄도 대상** | **아님** |
| **리롤 대상** | **아님** |
| **방진/반격 대상** | **아님** |
| **결사(R5~) 영향** | **없음.** 킵 방패는 결사에서도 🛡 유지 |
| **색 매칭 기여** | **없음.** 무색이므로 |
| **전투 간 유지** | **유지.** 다음 전투로 이월 |
| **라운드 간 유지** | **유지.** R1에서 생산한 킵을 R3에서 사용 가능 |
| **런 간 유지** | **미확정** |

> **킵이 킵을 낳지 않는다.** 킵은 무색이라 색 매칭에 기여 불가 → 킵 사용이 추가 킵 생산으로 이어지지 않음. 자기 제한적 시스템.

## ⑥ 시각 자료

### 색 매칭 흐름

```
스텝2(전체 굴림) → 스텝3(리롤) → 스텝4(쇄도) → 스텝5(방진/반격)
                                                         ↓
                                               스텝6: 색 매칭 판정
                                               ├─ 자동: 매칭 카운트
                                               ├─ 자동: 킵 생산
                                               └─ 수동: 즉시 사용 or 킵?
                                                         ↓
                                               스텝7: 전과 (킵 합산)
```

### 킵 라이프사이클

```
전투 A                              전투 B
├─ R1: 색 매칭 → 킵 1개 생산        ├─ 전투 전: 킵 배치 (칼/방패 확정)
│       └─ 킵 저장                  ├─ 스텝3: 킵 리롤 사용
├─ R2: 색 매칭 → 킵 1개 생산        ├─ 스텝7: 킵 칼/방패 합산
│       └─ 즉시 사용 (스텝7 합산)    └─ ...
├─ R3: 색 매칭 → 상한 초과
│       └─ 강제 즉시 사용
└─ 전투 종료: 킵 잔여분 유지 ────→
```

### 편성 예시: 색×병종 궁합

```
빨강 궁병:  ⚔60% → 빨강 매칭 확률 높음. 안정적 킵 칼 생산
빨강 창병:  ⚔ 0% → 반격(🛡→⚔) 후에만 빨강 매칭. 조건부
파랑 보병:  🛡30% → 방진(⚔→🛡) 후 파랑 매칭 추가 가능
파랑 궁병:  🛡 0% → 파랑 매칭 불가. 킵 상한만 제공
검정 민병:  ✕50% → 검정 매칭 최고 확률. 안정적 킵 리롤 생산
검정 기병:  ✕40% → 준안정적. 검정+쇄도 조합
```

## ⑦ 설계 근거

**Q. 왜 색×면 일치 조건인가?**
색만으로 카운트하면 편성 시 최적해가 바로 보인다. 주사위를 굴려야 매칭이 결정되므로 편성이 확률 조절이지 정답 맞추기가 아니다.

**Q. 왜 2개마다 1킵인가?**
1개마다면 킵 생산이 너무 빠르고, 3개마다면 매칭이 성립할 일이 드물다. d10에서 병종별 유효면 비율(0~60%)을 감안하면 2가 적정.

**Q. 왜 킵이 무색인가?**
킵이 색을 가지면 킵이 킵을 생산하는 눈덩이가 된다. 무색으로 자기 제한.

**Q. 왜 킵이 주사위가 아닌가?**
주사위면 쇄도/리롤/방진/결사의 대상이 되어 기존 엔진 전체에 엣지 케이스가 폭증한다. 확정 면으로 두면 스텝7 합산에만 관여하여 충돌 0.

**Q. 왜 적은 킵 안 하는가?**
소수 정예 테오도라 부대가 자원을 비축하며 운명 전투까지 버텨야 하는 서사. 적은 물량이 있으니 킵이 필요 없다.

**Q. 왜 라운드 간 매칭 리셋인가?**
라운드 누적이면 후반 라운드에 킵 폭발. 리셋이면 매 라운드 "이번에 터지나"의 긴장 유지.

**Q. 왜 상한이 챕터 수인가?**
런 진행에 따라 킵 상한이 자연스럽게 증가. Ch1=1(보험 1개), Ch3=3(전략적 비축). 최대 3이라 밸런스 표면적이 극소.

**Q. 왜 상한 초과분은 즉시 사용인가?**
버리는 선택지를 주면 "안 쓰는 게 최적"인 상황이 생긴다. 강제 사용이면 과잉 생산도 낭비가 아니라 보상이 된다.

**Q. 왜 검정이 ✕ 매칭인가?**
✕는 실패. 실패가 쌓여서 리롤(역전 기회)이 되는 구조는 크로니클의 "감내" 철학과 정확히 일치한다. 실패를 감내한 대가.

**Q. 왜 밀집이 유닛 수만큼 카운트인가?**
밀집은 일제 굴림(전원 동일 결과). 빨강 3기 밀집 → ⚔ → 매칭 3. 밀집의 올인 리스크에 킵 생산 리워드를 연동. ✕ 나오면 매칭 0.

**Q. 색과 병종이 어긋나면?**
편성 깊이가 생긴다. "빨강 궁병은 쉬운 빨강, 빨강 창병은 어려운 빨강." 반격으로 면을 바꿔야 매칭이 되는 조건부 카드는 운용 난이도가 높지만 전술 폭이 넓다.

**Q. 아르멜로와의 차별점은?**
아르멜로: 굴리고 → 결과 수용. 크로니클: 굴리고 → 조정(리롤/쇄도/방진) → 색 읽고 → 킵 판단 → 결과. 같은 다이스 배틀이지만 전투 후 자원이 남고, 전투 간 연결이 생긴다.
