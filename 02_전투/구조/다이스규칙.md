# COMBAT-DICE-001: 다이스 규칙

> 상태: 결정정합 (5-11 마디 박힘) · 의존: @COMBAT-STRUCT-001, @COMBAT-UNIT-CARD, @COMBAT-UNIT-HERO

> 5-11 마디 큰 정정:
> - 주사위 2종 (행동 + 인도) → 의지 1종으로 합침
> - 신성력 패러미터 폐기 (인도 결산 곱셈치 폐기)
> - 면 결 = 의지·신성·경계·실패 4종 (옛 결: 칼/방/실 + 인도 6면 → 통합)
> - 박힘 면 = 시간대 종속 (자기 시간대 라운드만 4면 박힘)
> - 직업 5종 → 3종 (전사/사냥꾼/신관, 면 비율은 직업 결 X — 모든 인물 같음)
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - "주사위가 곧 신성력이 포함된 의지 덩어리" — 한 굴림에 의지 + 신성 결 합주
> - 별 면 재굴림 무한 폐기 (재굴림 결 펜딩)
> - 시간대 2종 → 3종 (낮/경계/밤)

## 정의

전투 판정의 기반. d6 의지 주사위 1종. 의지 면 + 신성 면 + 경계 면 + 실패 면 (4종). 자기 시간대 라운드 = 박힘 면 큼 / 반대 시간대 = 별 면만 박힘. 박힘 면 × 공·방 (선언 1택). 인간의 결 + 신의 결이 한 주사위에 합주.

## 규칙

### 의지 주사위 (1종, 모든 인물)

```yaml
type:        d6 (모든 인물 보유)
faces:       의지 / 신성 / 경계 / 실패 (4종)
주사위 수:   등급 결로 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)

면 결:
  의지 면 (별):    완전 성공 — 어느 시간대든 박힘
  신성 면 (낮·밤): 조건 성공 — 자기 시간대 라운드만 박힘 (반대 시간대 = 실패)
  경계 면:          조건 성공 — 경계 인물만 자기 시간대 (경계 시간대) 박힘
  실패 면:          무 — 결 X

결의 결:
  "주사위가 곧 신성력이 포함된 의지 덩어리"
  → 인간의 결 (의지 면) + 신의 결 (신성·경계 면) 합주
  → 등급 = 신성 결의 그릇 (주사위 수)
  → 별도 신성력 패러미터 X (등급 자체가 신성 깊이)

N대N 전체 (적+아군 합산):
  최소: 2
  최대: 60 (잠정. 시뮬 후 트윅)
```

### 면 비율 (팩션별)

```yaml
지상:  별 2 / 경계 2 / 낮 2     → 별 3 / 경계 2 / 낮 1
미궁:  별 2 / 경계 2 / 밤 2     → 별 3 / 경계 2 / 밤 1
경계:  별 2 / 경계 2 / 낮 1 / 밤 1 → 별 3 / 낮 1 / 밤 1 / 경계 1

성공·실패:
  지상: 별·낮 = 성공 / 경계·밤 = 실패
  미궁: 별·밤 = 성공 / 경계·낮 = 실패
  경계: 별·경계 = 성공 / 낮·밤 = 실패

자기 시간대:
  지상 = 낮 시간대 (낮 면 박힘)
  미궁 = 밤 시간대 (밤 면 박힘)
  경계 = 경계 시간대 (경계 면 박힘)

→ 면 비율은 직업 결 X (모든 직업 같음)
→ 직업 결 = 행동 양식 + 분배 비율로만 박힘 (@COMBAT-CLASS-001)
```

### 박힘 면 (시간대 종속)

```yaml
박힘 면 = 자기 시간대 라운드 + 반대 시간대 라운드 다름

자기 시간대 라운드 (지상 = 낮 / 미궁 = 밤 / 경계 = 경계):
  별 3 + 자기 시간대 면 1 = 박힘 4면 (67%)
  반대 시간대 면 = 실패
  실패 면 = 실패

반대 시간대 라운드 (자기 시간대 X 모든 시간대):
  별 3 = 박힘 3면 (50%)
  다른 면 = 실패

의존도 결:
  자기 시간대 4면 vs 반대 3면 = 1.33배 차이
  → 5-11 결: 의존도 *완화* (옛 5-10 결: 4면 vs 2면 = 2배)
  → 결산 결 변동 작음. 시뮬 결 안정.
```

### 시간대 흐름 (5-11 박힘)

```yaml
시간대 3종: 낮 / 경계 / 밤

흐름 (라운드별 변동):
  낮 → 경계 → 밤 → 경계 → 낮 → 경계 → 밤 → ...
  → 1 라운드마다 시간대 1회 변동

페이즈 시작 시간대 (R1):
  지상: 1=낮 / 2=밤 / 3=낮 / 4=밤
  미궁: 1=밤 / 2=낮 / 3=밤 / 4=낮
  경계: 시작 랜덤

자기 시간대 라운드 비율:
  지상 (낮 페이즈): R1 낮 (자기) / R2 경계 / R3 밤 (반대) / R4 경계
                    → 자기 시간대 1/4 라운드
  지상 (밤 페이즈): R1 밤 (반대) / R2 경계 / R3 낮 (자기) / R4 경계
                    → 자기 시간대 1/4 라운드

  경계: 어느 페이즈든 R2·R4 경계 (자기 시간대) → 자기 시간대 2/4 라운드
       R1·R3 = 반대 시간대 (낮 또는 밤)
       → 경계 = 자기 시간대 자주 박힘. 단 반대 시간대 (R1) = 결 작음.
```

### 의지 결산 (5-11 박힘)

```yaml
선언 결 (단계 0, 굴림 전):
  공격 / 방어 1택
  → 박힘 면 = 선언 결산 자리

굴림 결 (단계 1):
  의지 주사위 굴림 (등급 수만큼)
  자기 시간대 라운드 = 별 + 자기 시간대 면 박힘
  반대 시간대 라운드 = 별만 박힘

결산 결 (단계 2):
  공격 선언: 박힘 면 × 공격력 = 공격 점수
  방어 선언: 박힘 면 × 방어력 = 방어 점수
  순서 점수 = 시간대 보정 + 인물 속도 (별도 결, 의지 결산 X)

피해 = max(0, 자기 공격 - 상대 방어)

영 허용:
  공격력 0 = 비공격 인물 (펜딩 — 신관 결 자리)
  방어력 0 = 글래스 캐논 (사냥꾼 = 방어 X 결산)
  → 사냥꾼은 공격력만 결산. 방어 선언 = 0 점수.
```

### 결산 예시

```yaml
예 1: 반신 인간 전사 (공 2 방 1, 행동 주사위 2개), 자기 시간대 라운드:
  굴림: [별·낮, 별·낮]  →  의지 주사위 2개 = 4면 박힐 자리
  실제 굴림: [별, 낮]
  박힘 면 = 2 (의지 + 신성)
  
  공격 선언: 박힘 면 2 × 공격력 2 = 공격 점수 4
  방어 선언: 박힘 면 2 × 방어력 1 = 방어 점수 2

예 2: 같은 인물, 반대 시간대 라운드:
  굴림: [별, 낮]
  박힘 면 = 1 (별만, 낮 = 실패)
  
  공격 선언: 1 × 2 = 2
  방어 선언: 1 × 1 = 1
  → 자기 시간대 결의 절반 자리

예 3: 신성 영웅 (공 2 방 1, 의지 주사위 3개), 자기 시간대:
  굴림: [별, 낮, 별]
  박힘 면 = 3
  
  공격 선언: 3 × 2 = 6
```
