> 상태: **재설계 진행중 (5-8)** · 의존: @COMBAT-STRUCT-001, @COMBAT-UNIT-NAMELESS, @COMBAT-UNIT-HERO

> ⚠️ 5-8 큰 정정 예정:
> - 면 종류 (⚔/🛡/★/✕) → 시간대 (낮/황혼/밤) 6면
> - 면 = 행동 표현 → 면 = 계산기 (점수)
> - 출신·신앙별 면 비율 (미궁: 밤3/황혼2/낮1, 도시: 낮3/황혼2/밤1, 경계: 균등 222)
> - 매칭 점수: 미궁/도시 자기 시간대 = 2점 / 그 외 0점. 경계 = 모든 면 1점 균일
> - ★ = 추가 굴림 (체이닝 부활). 단 덕목 주사위에만 (영웅 등급)
> - 본문은 5-5 결 그대로. 다음 세션에서 전면 재작성 예정.

## 정의

전투 판정의 기반. 6면 주사위. 4종 면(⚔🛡✕★) + 카드별 공/방 스칼라가 합산되어 피해를 결정한다.

## 규칙

### 주사위 형식

```yaml
type: d6 (모든 카드 동일)
faces:
  ⚔: 공격면
  🛡: 방어면
  ★: 대성공 (Named 전용 보유)
  ✕: 무효 (합산 제외)
면_합: 6
```

### 면 비율

```yaml
Nameless: @COMBAT-UNIT-NAMELESS 참조
Named:    @COMBAT-UNIT-HERO 참조
원칙:     모든 카드 d6 동일. 차별화 = 면 비율 + 공/방 + 병종 패시브
```

### ★ 정의

```yaml
효과: 그 카드 ⚔합 +1 (정수 보정)
체이닝: 폐기 (단순화)
적용: ⚔합에 보정 후 × 공격력
예: ⚔면 2개 + ★면 1개 → ⚔합 = 3 (= 2 + ★보정 1) → 3 × atk_power
```

### 공/방 적용

```yaml
모드: 감산
계산:
  아군_공격_총: sum(⚔) × atk_power      # ★ 보정 후 ⚔합
  적_방어_총:   sum(🛡) × def_power
  피해:        max(0, 아군_공격_총 - 적_방어_총)
영_허용:
  - atk_power = 0: 비공격 카드
  - def_power = 0: 글래스 캐논 (예: 궁병)
```

### 면 처리 순서 (스텝 6 합산)

```yaml
1: ★ 보정 (⚔합 += ★개수)
2: ⚔합 × atk_power = 공격_총
3: 🛡합 × def_power = 방어_총
4: max(0, 공격_총 - 방어_총) = 피해
5: ✕ 무시
```

### 환경 표현

```yaml
모델: 외부 모디파이어
공/방_고유값: 환경(낮/밤·날씨·장소)에 따라 변하지 않음
환경_효과: 카드 효과 / 장소 특수 규칙 / 날씨로 적용 (@META-BACKDROP)
```

### 폐기 항목

```yaml
- 색 매칭: 4-08 시도, 4-26 폐기
- 일제 굴림: 산개/밀집 폐기 연쇄
- ★ 체이닝: 5-5 폐기 (정수 보정으로 단순화)
- 시너지: 5-5 폐기 (현 단계). v3.5+ 검토
- 태그 / 챕터 팩 금형 환경 효과: 5-7 폐기 (장소·날씨로 흡수)
```
