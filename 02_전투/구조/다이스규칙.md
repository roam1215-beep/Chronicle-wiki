## ① 한 줄 요약

모든 전투 판정의 기반. 4종 면으로 구성된 주사위를 굴려 칼-방패 상쇄로 피해를 결정하며, ★ 체이닝이 폭발적 전과를 만든다.

## ② 규칙 정의

### 2-1. 주사위 면 종류

| 면 | 기호 | 효과 | 비고 |
|---|------|------|------|
| 칼 (Sword) | ⚔ | 피해 1 | 상대 🛡 1개와 상쇄 |
| 방패 (Shield) | 🛡 | 방어 1 | 상대 ⚔ 1개와 상쇄. 초과 방패는 소멸 (이월 없음) |
| 대성공 (Critical) | ★ | 칼 1 확정 + 해당 주사위 즉시 재굴림 | 체이닝 참조 |
| 실패 (Blank) | ✕ | 효과 없음 | 지형/정예화로 전환 가능 |

|--------|-----|-----|-----|-----|-----|-----|------|

| 날씨 주사위 | 맑음 | 맑음 | 맑음 | 안개 | 비 | 눈 | 매일(2턴) 시작 시 굴림. 맵 조건만 변경 |

#### 철수 주사위 (별도 주사위 아님 — 기존 전투 주사위 활용)

| 필드 | 내용 |
|------|------|
| **도주 측 (테오도라)** | 보유 전투 주사위 중 **플레이어가 선택** 1개 굴림 |
| **추격 측 (적)** | 보유 전투 주사위 중 **랜덤** 1개 굴림 |
| **도주 측 유효면** | 🛡만 유효. ⚔/★/✕ = 효과 없음 |
| **추격 측 유효면** | ⚔, ★ 유효. 🛡/✕ = 효과 없음 |
| **★ 체이닝** | 철수 판정에서도 유효. 추격 측 ★ → ⚔ 확정 + 재굴림 |
| **판정** | 추격 측 유효 ⚔ 합계 - 도주 측 유효 🛡 = 뚫린 만큼 피해 |
| **전략적 의미** | 도주 측이 선택이므로 병종 구성이 철수 안전도에 직접 영향. 창병(🛡67%)은 안전, 궁병(🛡0%)은 방어 불가 |

### 2-3. ★ 재굴림 (Critical Chaining)

| 필드 | 내용 |
|------|------|
| **조건** | 굴림 결과가 ★ |
| **대상** | ★이 나온 해당 주사위 1개 |
| **행동** | ⚔ 1을 확정 → 해당 주사위 즉시 재굴림 |
| **결과** | 재굴림이 ★ → ⚔ 1 추가 확정 + 또 재굴림. ⚔ → ⚔ 1 추가. 🛡 → 🛡 1 추가. ✕ → 없음 |
| **제한** | 체이닝 횟수 제한 없음 (무한) |
| **비용** | 없음 |
| **오버킬** | 적 전멸 후에도 체이닝은 계속 굴린다. 초과 피해는 흘려보냄 |

### 2-4. 전투 판정

| 필드 | 내용 |
|------|------|
| **조건** | 양측 주사위가 모두 굴려지고, 리롤/전환/지형 등 모든 수정이 끝난 후 |
| **행동** | 양쪽 동시 판정 |
| **피해 공식** | `피해 = 상대 ⚔ 합계 - 내 🛡 합계` |
| **피해 < 0** | 0으로 처리. 초과 방패는 소멸 (저장/이월 없음) |
| **피해 > 0** | 뚫린 수만큼 주사위(=병사) 제거 |
| **사상자 선택** | 랜덤. 플레이어 선택 불가. 영웅도 동일 풀에 포함 |
| **양쪽 동시 전멸** | 양쪽 모두 전멸 처리. 해당 타일 교전 종료 |
| **피해 0 vs 0** | 사상자 없음. 다음 라운드 속행 |

### 2-5. 예외 및 엣지 케이스

| 상황 | 처리 |
|------|------|
| 양쪽 모두 ⚔ 0 | 피해 0 vs 0. 사상자 없음 |
| 🛡이 상대 ⚔보다 많음 | 초과 🛡 소멸. 피해 0 |
| ★ 체이닝 중 적이 전멸 | 체이닝은 계속 굴림. 오버킬은 흘려보냄 |
| ★ 재굴림 결과가 🛡 | 🛡 1 추가. 체이닝 종료 |
| 사상자 수 > 잔여 주사위 수 | 잔여 전부 제거 (전멸). 초과분 흘려보냄 |
| 영웅만 남은 상태에서 피해 | 영웅이 사상자 대상. 부상 규칙 적용 (COMBAT-JUDGE-001 참조) |
| 체이닝으로 발생한 🛡 | 해당 라운드 방어에 즉시 합산 |
| 동시 전멸 시 승패 | 양쪽 전멸 = 해당 교전 무승부. 타일에서 양쪽 소멸 |
| 철수 시 양쪽 유효면 0 | 피해 0. 안전 철수 |
| 철수 시 도주 측에 🛡 보유 유닛 없음 | 최선이 ✕(무효). 방어 0. 추격 측 유효면만큼 피해 |
| 철수 시 추격 측 ★ 발생 | 체이닝 유효. ⚔ 확정 + 재굴림으로 피해 증가 가능 |

### 전투 판정 예시

```
[예시 1: 기본 상쇄]
아군 4주사위: ⚔⚔🛡✕  →  ⚔×2  🛡×1
적군 4주사위: ⚔🛡🛡✕  →  ⚔×1  🛡×2

아군 피해 = 적⚔(1) - 아군🛡(1) = 0  →  사상자 0
적군 피해 = 아군⚔(2) - 적🛡(2) = 0  →  사상자 0

[예시 2: ★ 체이닝]
아군 4주사위: ⚔⚔★✕
  → ★ 발동: ⚔ 1 확정 + 재굴림
  → 재굴림 결과: ⚔
  → 최종: ⚔×3  🛡×0
적군 4주사위: ⚔🛡🛡✕  →  ⚔×1  🛡×2

아군 피해 = 적⚔(1) - 아군🛡(0) = 1  →  아군 1명 랜덤 제거
적군 피해 = 아군⚔(3) - 적🛡(2) = 1  →  적군 1명 랜덤 제거

[예시 3: 오버킬]
아군 2주사위: ★★
  → ★₁: ⚔ 확정 + 재굴림 → ⚔  →  칼 2
  → ★₂: ⚔ 확정 + 재굴림 → ★ → ⚔ 확정 + 재굴림 → ✕  →  칼 2
  → 최종: ⚔×4  🛡×0
적군 1주사위: ⚔  →  ⚔×1  🛡×0

아군 피해 = 적⚔(1) - 아군🛡(0) = 1  →  아군 1명 제거
적군 피해 = 아군⚔(4) - 적🛡(0) = 4  →  적 1명 제거 (잔여 1). 초과 3 흘려보냄

[예시 4: 🛡 초과]
아군: 🛡🛡🛡🛡  →  ⚔×0  🛡×4
적군: ⚔✕✕✕    →  ⚔×1  🛡×0

아군 피해 = 적⚔(1) - 아군🛡(4) = -3 → 0 처리. 사상자 없음. 초과 🛡 소멸.
적군 피해 = 아군⚔(0) - 적🛡(0) = 0  →  사상자 없음

[예시 5: 철수 — 선택 vs 랜덤]
테오도라 대 (보병3 + 테오도라 + 앰버) vs 적 궁병2
테오도라 측 철수 선택.

도주 측 선택 1개: 보병 주사위 선택 → 🛡 면 (확정 방어)
추격 측 랜덤 1개: 궁병 주사위 → ⚔ (유효)

추격 ⚔(1) - 도주 🛡(1) = 0  →  안전 철수

[예시 6: 철수 — 궁병만 남은 경우]
앰버 + 궁병2만 남은 상태에서 철수.

도주 측 선택 1개: 궁병 주사위 → ⚔⚔⚔⚔✕✕ 중 🛡 없음.
  → 최선이 ✕(무효). 방어 0 확정.
추격 측 랜덤 1개: 적 보병 → ⚔ (유효)

추격 ⚔(1) - 도주 🛡(0) = 1  →  테오도라 대 1명 피해

[예시 7: 철수 — 추격 측 ★ 체이닝]
도주 측 선택 1개: 창병 주사위 → 🛡 (확정 방어)
추격 측 랜덤 1개: 적 T2 기병 → ★ 발동
  → ⚔ 확정 + 재굴림 → ⚔ → 칼 2

추격 ⚔(2) - 도주 🛡(1) = 1  →  테오도라 대 1명 피해
→ ★ 체이닝은 철수에서도 위험하다
```

## ④ 플레이어 피드백 (UI/UX)

| 상황 | 피드백 |
|------|--------|
| **굴림** | 모든 주사위 동시 굴림 연출 |
| **★ 발생** | 해당 주사위 강조 + 체이닝 재굴림 애니메이션 반복. 연쇄 횟수 표시 |
| **판정** | ⚔와 🛡 1:1 상쇄 시각화 (짝지어 소멸) → 잔여 ⚔ = 피해 |
| **사상자** | 제거 대상 주사위(=병사) 랜덤 선택 하이라이트 → 제거 연출 |
| **피해 0** | "BLOCK" 또는 "NO DAMAGE" 표시 |
