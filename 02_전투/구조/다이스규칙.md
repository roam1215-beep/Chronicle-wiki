# COMBAT-DICE-001: 다이스 규칙 (Dice Rules)

> **상태:** 🔄 설계중 · **버전:** 0.8 · **ID:** COMBAT-DICE-001 · **수정일:** 2026-03-01

## ① 한 줄 요약

모든 전투 판정의 기반. 4종 면으로 구성된 d10 주사위를 굴려 칼-방패 상쇄로 피해를 결정하며, ★ 체이닝이 폭발적 전과를 만든다.

## ② 규칙 정의

### 2-1. 주사위 면 종류

| 면 | 기호 | 효과 | 비고 |
|---|------|------|------|
| 칼 (Sword) | ⚔ | 피해 1 | 상대 🛡 1개와 상쇄 |
| 방패 (Shield) | 🛡 | 방어 1 | 상대 ⚔ 1개와 상쇄. 초과 방패는 소멸 (이월 없음) |
| 대성공 (Critical) | ★ | 칼 1 확정 + 해당 주사위 즉시 재굴림 | 체이닝 참조 |
| 실패 (Blank) | ✕ | 효과 없음 | — |

#### 전투 주사위 — 영웅

| 유닛 | 면 구성 | 취급 |
|------|---------|------|

> ⚠️ **테오도라 d10 면 구성 미확정.** Named 창병(🛡6 ★1 ✕3)을 그대로 적용하면 ⚔ 0으로 d6 시절(⚔🛡🛡★✕✕)과 성격이 크게 달라진다. 영웅 고유 면을 별도 설계할지 결정 필요.

### 2-3. ★ 재굴림 (Critical Chaining)

| 필드 | 내용 |
|------|------|
| **조건** | 굴림 결과가 ★ |
| **대상** | ★이 나온 해당 주사위 1개 |
| **행동** | ⚔ 1을 확정 → 해당 주사위 즉시 재굴림 |
| **결과** | 재굴림이 ★ → ⚔ 1 추가 확정 + 또 재굴림. ⚔ → ⚔ 1 추가. 🛡 → 🛡 1 추가. ✕ → 없음 |
| **제한** | 체이닝 횟수 제한 없음 (무한) |
| **비용** | 없음 |
| **오버킬** | 적 전멸 후에도 체이닝은 계속 굴린다. 초과 피해는 흘려보냄 |

### 2-4. 전투 판정

| 필드 | 내용 |
|------|------|
| **조건** | 양측 주사위가 모두 굴려지고, 리롤/쇄도/전환 등 모든 수정이 끝난 후 |
| **행동** | 양쪽 동시 판정 |
| **피해 공식** | `피해 = 상대 ⚔ 합계 - 내 🛡 합계` |
| **피해 < 0** | 0으로 처리. 초과 방패는 소멸 (저장/이월 없음) |
| **피해 > 0** | 뚫린 수만큼 주사위(=병사) 제거 |
| **사상자 선택** | 랜덤. 플레이어 선택 불가. 영웅도 동일 풀에 포함 |
| **양쪽 동시 전멸** | 양쪽 모두 전멸 처리. 패배 (테오도라 대 소멸) |
| **피해 0 vs 0** | 사상자 없음. 다음 라운드 속행 |

### 2-5. 예외 및 엣지 케이스

| 상황 | 처리 |
|------|------|
| 양쪽 모두 ⚔ 0 | 피해 0 vs 0. 사상자 없음 |
| 🛡이 상대 ⚔보다 많음 | 초과 🛡 소멸. 피해 0 |
| ★ 체이닝 중 적이 전멸 | 체이닝은 계속 굴림. 오버킬은 흘려보냄 |
| ★ 재굴림 결과가 🛡 | 🛡 1 추가. 체이닝 종료 |
| 사상자 수 > 잔여 주사위 수 | 잔여 전부 제거 (전멸). 초과분 흘려보냄 |
| 영웅만 남은 상태에서 피해 | 영웅이 사상자 대상. 부상 규칙 적용 (COMBAT-JUDGE-001 참조) |
| 체이닝으로 발생한 🛡 | 해당 라운드 방어에 즉시 합산 |
| 동시 전멸 시 승패 | 패배 처리 (테오도라 대 소멸) |

### 전투 판정 예시 (d10)

```
[예시 1: 기본 상쇄]
아군 보병 4명: ⚔⚔🛡✕ ⚔🛡🛡✕ 🛡⚔✕✕ ⚔🛡🛡✕  →  ⚔×5  🛡×6
적군 궁병 4명: ⚔⚔⚔✕ ⚔⚔✕✕ ✕⚔✕✕ ⚔⚔⚔✕    →  ⚔×9  🛡×0

아군 피해 = 적⚔(9) - 아군🛡(6) = 3  →  아군 3명 랜덤 제거
적군 피해 = 아군⚔(5) - 적🛡(0) = 5  →  적군 4명 전멸 (초과 1 흘려보냄)

[예시 2: ★ 체이닝]
아군 Named 보병 1명: ⚔⚔★ → ★ 발동: ⚔ 1 확정 + 재굴림 → 🛡
  최종: ⚔×3  🛡×1
적군 민병 2명: ⚔🛡✕✕ ✕✕⚔✕  →  ⚔×2  🛡×1

아군 피해 = 적⚔(2) - 아군🛡(1) = 1  →  아군 1명 제거
적군 피해 = 아군⚔(3) - 적🛡(1) = 2  →  적군 2명 전멸

[예시 3: 오버킬]
아군 Named 궁병 1명: ★ → ⚔ 확정 + 재굴림 → ★ → ⚔ 확정 + 재굴림 → ⚔
  최종: ⚔×3  🛡×0
적군 민병 1명: ✕  →  ⚔×0  🛡×0

아군 피해 = 적⚔(0) - 아군🛡(0) = 0  →  사상자 없음
적군 피해 = 아군⚔(3) - 적🛡(0) = 3  →  적 1명 전멸. 초과 2 흘려보냄
```

## ④ 플레이어 피드백 (UI/UX)

| 상황 | 피드백 |
|------|--------|
| **굴림** | 모든 주사위 동시 굴림 연출 |
| **★ 발생** | 해당 주사위 강조 + 체이닝 재굴림 애니메이션 반복. 연쇄 횟수 표시 |
| **판정** | ⚔와 🛡 1:1 상쇄 시각화 (짝지어 소멸) → 잔여 ⚔ = 피해 |

| **피해 0** | "BLOCK" 또는 "NO DAMAGE" 표시 |
| **오버킬** | 전멸 표시 후 초과분 흘러가는 연출 |
| **밤** | 적 주사위 개별 결과 "?" 처리. 최종 피해 수치만 공개 |
| **날씨** | 턴 시작 시 날씨 주사위 굴림 연출. 결과에 따른 오버레이 전환 (재설계 후) |

## ⑥ 설계 근거

| 질문 | 답변 | 근거 |
|------|------|------|
| 왜 d6에서 d10으로 전환했나? | 면 배분 차별화 폭 확대. d6은 17% 단위로만 조절 가능했으나 d10은 10% 단위. 병종 간 미세 차별화와 패시브 설계 자유도 확보. | 병종 확장 |
| 왜 4종 면인가? | 공격-방어-행운-빈손의 최소 전술 공간. 병종별 면 비율만 달라도 역할 분리 성립. | 전투 문법 통일 원칙 |
| 왜 ★ 체이닝이 무한인가? | "대박" 감정. Named ★ 10% 기준 2연속 ≈ 1%, 3연속 ≈ 0.1%. 제한 시 이 감정 소멸. | 주사위 게임 핵심 |
| 왜 사상자가 랜덤인가? | 선택제 → 최하 유닛 우선 제거로 최적해 수렴. 랜덤 → 영웅 사망 가능 → 긴장 유지. | v4 시뮬 검증 |
| 왜 초과 🛡이 소멸하는가? | 방패 저장 허용 시 창병이 방어→축적→무적 루프 발생. | 밸런스 |
| 왜 오버킬을 흘려보내는가? | 초과 데미지가 파급되면 체이닝 가치가 과도. 전투 단위 격리 원칙. | 설계 원칙 |
| 왜 Named가 ✕→★ 단일 규칙인가? | 구 체계(용병/기병/기사/석궁병 별도 면)는 병종 확장 시 Named 면도 별도 설계 필요. ✕→★ 규칙이면 어떤 병종이든 Named화 가능. | Named 체계 단순화 |
| 왜 지형 전환(✕ 활용)을 삭제했나? | 기병 쇄도(스텝5) 도입으로 스텝5 역할 교체. 지형 전환은 전투 판단에 기여하는 무게감이 낮았음. | 복잡도 교환 |
