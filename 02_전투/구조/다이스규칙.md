# 다이스 규칙 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 다이시 테일즈식 결산, 졸전 결, 변형 결 ×1.5 어휘
> 정정: 하스스톤 전장식 격돌, 우선순위 결산

---

## 의지 주사위 (1종, 모든 인물)

```yaml
type:        d6 (모든 인물 보유)
faces:       의지 / 신성 / 경계 (3종, 6면 구성)
주사위 수:   등급 결 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)

면 결:
  의지 면 (별):    완전 성공 — 어느 시간대든 통상 박힘
  신성 면 (낮·밤): 조건부 — 자기 시간대 라운드만 대성공
                  반대 라운드 박히면 통상 (case 2 = 깡)
  경계 면:         조건부 — 경계 인물만 자기 시간대 (경계 시간대) 대성공

작품 결:
  "주사위가 곧 신성력이 포함된 의지 덩어리"
  → 인간의 결 (의지 면) + 신의 결 (신성·경계 면) 합주
  → 등급 = 신성 결의 그릇 (주사위 수)
  → 별도 신성력 패러미터 X (등급 자체가 신성 깊이)

N대N 전체 (적+아군 합산):
  최소: 2
  최대: 60 (잠정. 시뮬 후 조정)
```

---

## 면 비율 (팩션별)

```yaml
지상:  별 3 / 경계 2 / 낮 1
미궁:  별 3 / 경계 2 / 밤 1
경계:  별 3 / 낮 1 / 밤 1 / 경계 1

자기 시간대:
  지상 = 낮 시간대 (낮 면)
  미궁 = 밤 시간대 (밤 면)
  경계 = 경계 시간대 (경계 면)

→ 면 비율은 직업·태생 무관 (모든 직업 같음)
→ 팩션 결로만 다름
```

---

## 박힘 면 (시간대 결산)

```yaml
면 종류 × 라운드 시간대 = 결과:

별 면 (어느 라운드든):
  → 통상 행동 1번 (스탯대로)

자기 시간대 면 + 자기 시간대 라운드:
  → 대성공 1번 (행동 변형, 직업별 매커니즘)

자기 시간대 면 + 반대 시간대 라운드 (case 2):
  → 통상 행동 1번 (깡, 스탯대로)

반대 시간대 면 (어느 라운드든):
  → 실패
  - 격돌 직업 (전사·수호자): 수동 격돌 (자기 스탯 자동 반응)
  - 원거리·사제 (사냥꾼·사제): 행동 X

우선순위 (개별 주사위 결과):
  대성공 > 통상 > 실패
```

## 주사위 수의 결

```yaml
등급 = 의지 주사위 수:
  필멸:  1개
  반신:  2개
  신성:  3개
  번외:  4+개

주사위 ×N개의 결:
  - 행동 ×N번 (각 주사위 독립 행동, 발더스 결: 공격 횟수 늘어남)
  - 가호 수와 정합 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
  - 대성공 확률에 영향

각 주사위 = 독립 결과:
  하나가 실패     → 그 행동 = 대기 (격돌 직업은 수동 격돌)
  하나가 대성공   → 그 행동 = 대성공 (변형)
  하나가 통상     → 그 행동 = 통상

같은 행동 ×N번 반복:
  대상은 같은 자리 (자기 위치 결로 정해짐)
  자기 굴림이 자기 피해 ×N되는 자리 X
  본인 행동 횟수 = 자기 능동 결
  본인 피격 횟수 = 적의 능동 결 (적의 굴림)
```

## 확률 결 (자기 라운드)

```yaml
필멸 (1개):
  대성공: 1/6 ≈ 17%
  통상:   3/6 = 50% (별)
  실패:   2/6 ≈ 33%

반신 (2개):
  대성공 (적어도 1개): 1 - (5/6)² ≈ 31%
  통상 (적어도 1개 별): 1 - (3/6)² = 75%
  실패 (둘 다 반대): (2/6)² ≈ 11%

신성 (3개):
  대성공: 1 - (5/6)³ ≈ 42%
  통상:   1 - (3/6)³ ≈ 87.5%
  실패:   (2/6)³ ≈ 3.7%

번외 (4개):
  대성공: 1 - (5/6)⁴ ≈ 52%
  통상:   1 - (3/6)⁴ ≈ 94%
  실패:   (2/6)⁴ ≈ 1.2%

→ 등급 결로 운 결의 그릇 자연 박힘
→ 결의 결의 결 살아남
```

## 시간대 흐름

```yaml
시간대 3종 (낮 / 경계 / 밤) 유지
태생과 별도 (태생은 인물 결 어휘만)

라운드별 시간대 변동:
  R1 = 페이즈 시작 시간대 (첫 배틀) 또는 이전 배틀 마지막 시간대 (두 번째 배틀)
  R2~ = 흐름 결로

흐름 결:
  지상 페이즈 1 (R1 낮) → R2 경계 → R3 밤 → R4 경계 → R5 낮 → ...
  미궁 페이즈 1 (R1 밤) → R2 경계 → R3 낮 → R4 경계 → R5 밤 → ...
```

## 폐기 자리 (5-12 후속)

```yaml
✗ 다이시 테일즈식 결산 (박힌 면 × 공격력)
✗ 졸전 결 (×0.5)
✗ 변형 결 ×1.5 어휘 (행동 종류 변형으로 정정)
✗ 실패 면 어휘 (5-11에서 정정됨)

정정:
  - 격돌 결산 = 하스스톤 전장식 (공격력 = 상대 hp 직격)
  - 능력치 = 공격력 + 체력만 (방어력 폐기 → 방어도/보호막 분리)
  - 면 결과 = 통상/대성공/실패 3종으로
```
