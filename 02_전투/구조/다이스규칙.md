## 정의

전투 판정의 기반. d6 주사위 2종 분리. 행동 주사위 = 인간의 결 (역량/그릇). 인도 주사위 = 신의 응답 결. 두 결 합주로 결산. 5 패러미터 (공·방·hp·속도·신성력)가 결산 곱셈치 + 순서 결정.

## 규칙

### 주사위 2종

```yaml
행동 주사위:
  type:        d6 (모두 보유)
  faces:       칼 / 방패 / 실패 3종
  비율:        직업/종족별 분화 (실패 2 고정 + 칼·방 4면 분배)
  결의 결:     신과 무관한 개인 존재의 역량/그릇
  
인도 주사위:
  type:        d6 (영웅·재앙만)
  faces:       자기 시간대 / 별 / 반대 시간대 3종
  비율:        자기 시간대3 / 별1 / 반대 시간대2 (대칭)
              지상: 낮3 / 별1 / 밤2
              미궁: 밤3 / 별1 / 낮2
              경계: 낮2 / 별2 / 밤2 (균등)
  결의 결:     신의 응답 결 (지상 = 인격신 / 미궁 = 자연신, 어휘만 분리)
              
주사위 수 (5-10 박힘):
  행동 주사위 수 = 인물별 (등급 결 X — 인물 결로 박힘)
                무리도 행동 결 많을 수 있음 (등급 결 X)
  인도 주사위 수 = 인물별 (영웅·재앙만)
                  보유 자체 = 등급 결 / 수치 = 인물별
  
N대N 전체 (적+아군 합산):
  최소: 2
  최대: 60 (잠정. 시뮬 후 트윅)
```

### 행동 주사위 분화 (5종)

```yaml
실패 면 = 2 고정 (운빨 보장)
칼·방 = 4면 안에서 분배

A. 칼4 / 방0 / 실2    — 사냥꾼
B. 칼3 / 방1 / 실2    — 용병
C. 칼2 / 방2 / 실2    — 전사
D. 칼1 / 방3 / 실2    — 수호자
E. 칼0 / 방4 / 실2    — 사제

지상·경계 = 직업 결. 미궁 = 종족 결 (어휘 펜딩, 직업 어휘 일단 사용).
같은 풀 공유 결 (5-10 박힘).
```

### 인도 주사위 6면 (대칭)

```yaml
지상 (인격신):
  낮3: 자기 시간대 (자기 신앙 일치)
  별1: 인도 박힘 + 인도 주사위 재굴림 (무한)
  밤2: 반대 시간대

미궁 (자연신):
  밤3: 자기 시간대
  별1: 인도 박힘 + 재굴림
  낮2: 반대 시간대

경계 (신앙 무관):
  낮2 / 별2 / 밤2 (균등)
  결의 결: 시간대 결 약함 (보정 +1) + 자기 결로 빛나는 자리 = 별 결 큼

신 결 어휘 분리 (5-10 박힘):
  지상 신 = 인격신 (그리스 올림포스 결, 영웅과 대화 가능)
  미궁 신 = 자연신 (자연 결, 인격 X — 결 자체가 신)
  → 결산 결 같음 (어휘만 분리)
```

### 인도 박힘 조건

```yaml
조건: 자기 시간대 면이 *현재 페이즈 시간대 일치 + 자기 신앙 일치* 둘 다 충족
박힘:
  지상 영웅 + 낮 페이즈 + 인도 낮 면     = 인도 박힘
  지상 영웅 + 낮 페이즈 + 인도 밤 면     = 실패 (자기 신앙 X)
  지상 영웅 + 밤 페이즈 + 인도 낮 면     = 실패 (페이즈 X)
  지상 영웅 + 밤 페이즈 + 인도 밤 면     = 인도 박힘 (페이즈 + 자기 신앙 일치)
  
별 면:
  무조건 인도 박힘
  + 인도 주사위 1회 재굴림 (별 또 나오면 재굴림 — 무한)
  
실패:
  반대 시간대 = 그저 무. 호메로스 결 (적 해코지 X).
```

### 인도 결산 (5-10 박힘)

```yaml
선언 결 (단계 0, 굴림 전):
  영웅·재앙 = 공·방·속도 3축 1택 (분배 X)
  굴림 결과 = 결 따라옴 (결정 X)
  굴림 결과 인도 0 = 그저 무 (호메로스 결 — 신은 답 안 할 수도)

점수:
  인도 1개당 = 인물 *신성력*만큼
  공으로 끌었을 시: 인도 수 × 신성력 = 공격 점수에 추가
  방으로 끌었을 시: 인도 수 × 신성력 = 방어 점수에 추가
  속도로 끌었을 시: 인도 수 × 신성력 = 순서 점수에 추가 (*같은 라운드*)
  
예: 영웅 신성력 1 / 인도 굴림 = 별·별·밤 (별 → 재굴림 → 별 → 재굴림 → 밤)
    유효면 = 2 (별 2 / 밤 = 낮 페이즈에 굴려서 실패)
    선언 = "속도"
    인도 점수 = 2 × 1 = 2
    이번 라운드 속도 = 시간대 +2 + 인물 속도 2 + 인도 2 = 6

결의 결:
  공·방·속도 = 인간의 결 (행동 결산 + 5 패러미터)
  신성력 = 신의 결 (인도 결산 곱셈치)
  → 두 결산이 *완전 분리*. 본인 박은 신화 결 깊이 정합.
```

### 행동 결산

```yaml
행동 면 × 인물 공·방 수치:
  칼 면 × 공격력 = 공격 점수
  방패 면 × 방어력 = 방어 점수
  실패 = 무

예:
  공격력 3 / 행동 주사위 3개 굴림 [칼/칼/실패]
  공격 점수 = 칼 2 × 공 3 = 6
  방어 점수 = 0 (방패 면 X)
```

### 결산 합산

```yaml
공격 점수 = (행동 칼 합 × 공격력) + (인도를 공으로 끌었을 시: 인도 수 × 신성력)
방어 점수 = (행동 방패 합 × 방어력) + (인도를 방으로 끌었을 시: 인도 수 × 신성력)
순서 점수 = 시간대 보정 + 인물 속도 + (인도를 속도로 끌었을 시: 인도 수 × 신성력)
피해 = max(0, 자기 공격 - 상대 방어)

영 허용:
  공격력 0 = 비공격 인물 (사제 = 칼 0)
  방어력 0 = 글래스 캐논 (사냥꾼 = 방 0)
  신성력 0 = 무리·인간 (인도 점수 = 0)
```

### 순서 점수 결산

```yaml
순서 점수 = 시간대 보정 + 인물 속도 + 인도(속도) 결산

시간대 보정:
  지상 인물 + 낮 페이즈 = +2
  지상 인물 + 밤 페이즈 = 0
  미궁 인물 + 낮 페이즈 = 0
  미궁 인물 + 밤 페이즈 = +2
  경계 인물 = +1 (낮·밤 무관)

행동 무관 / 인도 = 보정 자리 (속도 끌었을 시만)
순서 = 라운드 시작 시 정해짐 + 인도 보정 (해당 라운드)

상세: @COMBAT-STRUCT-001
```
