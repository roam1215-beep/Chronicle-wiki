# COMBAT-DICE-001: 다이스 규칙

> 상태: 결정정합 (5-9 코어 + 5 패러미터 박힘) · 의존: @COMBAT-STRUCT-001, @COMBAT-UNIT-CARD, @COMBAT-UNIT-HERO

> 5-9 5 패러미터 박힘 (이번 마디):
> - 가호 결산 정정: 가호 1개 = 인물 공·방 수치 (옛 결) → *신성력*만큼 (새 결)
> - 인물 카드 = 5 패러미터 (공·방·hp·속도·신성력) + 행동/신성 주사위 수
> - 순서 시스템 = 시간대 보정 + 인물 속도 (행동·신성 무관)
> - 주사위 수 잠정 시드 = N대N 전체 (적+아군) 최소 2 / 최대 60
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_5패러미터_박힘.md`

## 정의

전투 판정의 기반. d6 주사위 2종 분리. 행동 주사위 = 인간의 결. 신성 주사위 = 신의 가호 결. 두 결 합주로 결산. 5 패러미터 (공·방·hp·속도·신성력)가 결산 곱셈치 + 순서 결정.

## 규칙

### 주사위 2종

```yaml
행동 주사위:
  type:        d6 (모두 보유)
  faces:       칼 / 방패 / 실패 3종
  비율:        직업/종족별 분화 (실패 2 고정 + 칼·방 4면 분배)
  
신성 주사위:
  type:        d6 (영웅·재앙만)
  faces:       자기 시간대 / 별 / 반대 시간대 3종
  비율:        자기 시간대3 / 별1 / 반대 시간대2 (대칭)
              지상: 낮3 / 별1 / 밤2
              미궁: 밤3 / 별1 / 낮2
              경계: 펜딩
              
주사위 수:
  행동 주사위 수 = 인간 역량 (등급/인물 종속. 별도 속성)
  신성 주사위 수 = 신성 깊이 (등급/덕목 종속. 별도 속성)
  무리·인간 = 신성 0
  
N대N 전체 (적+아군 합산):
  최소: 2
  최대: 60 (잠정. 시뮬 후 트윅)
```

### 행동 주사위 분화 (5종)

```yaml
실패 면 = 2 고정 (운빨 보장)
칼·방 = 4면 안에서 분배

A. 칼4 / 실2          — 사냥꾼
B. 칼3 / 방1 / 실2    — 펜딩 (콘텐츠 결)
C. 칼2 / 방2 / 실2    — 전사
D. 칼1 / 방3 / 실2    — 펜딩 (콘텐츠 결)
E. 방4 / 실2          — 사제

지상·경계 = 직업 결. 미궁 = 종족 결. 형식 동일.
출신별 공유 풀 vs 다른 풀 = 펜딩.
```

### 신성 주사위 6면 (대칭)

```yaml
지상:
  낮3: 자기 시간대 (자기 신앙 일치)
  별1: 가호 + 신성 주사위 재굴림 (무한)
  밤2: 반대 시간대

미궁:
  밤3: 자기 시간대
  별1: 가호 + 재굴림
  낮2: 반대 시간대

경계: 펜딩 (균등? 결 변동? — 다음 마디)
```

### 가호 박힘 조건

```yaml
조건: 신성 면이 *현재 페이즈 시간대 일치 + 자기 신앙 일치* 둘 다 충족
박힘:
  지상 영웅 + 낮 페이즈 + 신성 낮 면     = 가호 박힘
  지상 영웅 + 낮 페이즈 + 신성 밤 면     = 실패 (자기 신앙 X)
  지상 영웅 + 밤 페이즈 + 신성 낮 면     = 실패 (페이즈 X)
  지상 영웅 + 밤 페이즈 + 신성 밤 면     = 가호 박힘 (페이즈 + 자기 신앙 일치)
  
별 면:
  무조건 가호 박힘
  + 신성 주사위 1회 재굴림 (별 또 나오면 재굴림 — 무한)
  
실패:
  반대 시간대 = 그저 무. 호메로스 결 (적 해코지 X).
```

### 가호 결산 (5 패러미터 정정)

```yaml
플레이어 = 박힌 가호를 *공 또는 방* 1택. 동시 선언 (정보 비대칭 보존).

점수 (5-9 5패러미터 박힘):
  가호 1개당 = 인물 *신성력*만큼 (옛 결: 공·방 수치 → 정정)
  공으로 끌었을 시: 가호 수 × 신성력 = 공격 점수에 추가
  방으로 끌었을 시: 가호 수 × 신성력 = 방어 점수에 추가
  
예: 영웅 신성력 2 / 가호 3개 / 공으로 끌음
    가호 점수 = 3 × 2 = 6
    공격 결산에 +6

결의 결:
  공·방 수치 = 인간의 결 (행동 결산 곱셈치)
  신성력 = 신의 결 (가호 결산 곱셈치)
  → 두 결산이 *완전 분리*
  → 본인 박은 신화 결 깊이 정합
```

### 행동 결산

```yaml
행동 면 × 인물 공·방 수치:
  칼 면 × 공격력 = 공격 점수
  방패 면 × 방어력 = 방어 점수
  실패 = 무

예:
  공격력 3 / 행동 주사위 3개 굴림 [칼/칼/실패]
  공격 점수 = 칼 2 × 공 3 = 6
  방어 점수 = 0 (방패 면 X)
```

### 결산 합산

```yaml
공격 점수 = (행동 칼 합 × 공격력) + (가호를 공으로 끌었을 시: 가호 수 × 신성력)
방어 점수 = (행동 방패 합 × 방어력) + (가호를 방으로 끌었을 시: 가호 수 × 신성력)
피해 = max(0, 자기 공격 - 상대 방어)

영 허용:
  공격력 0 = 비공격 인물
  방어력 0 = 글래스 캐논
  신성력 0 = 무리·인간 (가호 점수 = 0)
```

### 순서 점수 결산

```yaml
순서 점수 = 시간대 보정 + 인물 속도

시간대 보정:
  지상 인물 + 낮 페이즈 = +2
  지상 인물 + 밤 페이즈 = 0
  미궁 인물 + 낮 페이즈 = 0
  미궁 인물 + 밤 페이즈 = +2
  경계 인물 = +1 (낮·밤 무관)

행동·신성 무관: 순서 = 라운드 시작 시 정해짐 (굴림 결과 X)

상세: @COMBAT-STRUCT-001
```
