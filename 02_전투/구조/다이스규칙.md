# 다이스 규칙

## 의지 주사위 d6

```yaml
면 종류: 의지(별) / 신성(낮·밤) / 경계 (3종, 6면 구성)
주사위 수 = 등급:
  필멸 1 / 반신 2 / 신성 3 / 번외 4+
```

## 면 비율 (팩션별)

```yaml
지상: 별 3 / 경계 2 / 낮 1
미궁: 별 3 / 경계 2 / 밤 1
경계: 별 3 / 낮 1 / 밤 1 / 경계 1

자기 시간대:
  지상 = 낮
  미궁 = 밤
  경계 = 경계
```

## 굴림 결산 (개별 주사위마다)

```yaml
별 면:
  → 통상 행동 1번 (스탯대로)

자기 시간대 면 + 자기 시간대 라운드:
  → 대성공 1번 (행동 변형)

자기 시간대 면 + 반대 시간대 라운드 (case 2):
  → 통상 행동 1번 (깡, 스탯대로)

반대 시간대 면:
  → 실패
  - 격돌 직업 (전사·수호자): 수동 격돌 (자기 스탯 자동 반응)
  - 원거리·사제 (사냥꾼·사제): 행동 X

우선순위: 대성공 > 통상 > 실패
```

## 주사위 ×N개

```yaml
각 주사위 = 독립 행동
같은 행동 ×N번 반복 (대상은 같은 자리)

가호 수와 정합 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
```

## 예시

```yaml
테오도라 (반신, 지상, 자기 시간대 = 낮):
  주사위 2개 굴림
  
  라운드 시간대 = 낮:
    [낮, 별] → 대성공 + 통상 = 행동 변형 ×1 + 통상 ×1
    [별, 별] → 통상 ×2
    [낮, 낮] → 대성공 ×2
    [경계, 별] → 실패 + 통상 = 통상 ×1 (격돌 직업이면 + 수동 격돌)

  라운드 시간대 = 경계:
    [낮, 별] → case 2 통상 + 통상 = 통상 ×2 (깡)
    [경계, 별] → 실패 + 통상 = 통상 ×1
```

## 확률 (자기 라운드)

```yaml
필멸 (1개):   대성공 17% / 통상 50% / 실패 33%
반신 (2개):   대성공 31% / 통상 75% / 실패 11%
신성 (3개):   대성공 42% / 통상 87% / 실패 4%
번외 (4개):   대성공 52% / 통상 94% / 실패 1%
```

## 시간대 흐름

```yaml
시간대 3종: 낮 / 경계 / 밤
태생과 별도 (태생 = 인물 어휘만, 굴림 영향 X)

R1 시간대:
  첫 배틀:     페이즈 시작 시간대
  두 번째 배틀: 이전 배틀 마지막 라운드 시간대

라운드별 흐름:
  지상 페이즈 R1 낮 → R2 경계 → R3 밤 → R4 경계 → R5 낮 ...
  미궁 페이즈 R1 밤 → R2 경계 → R3 낮 → R4 경계 → R5 밤 ...
```
