# 다이스 규칙

> 상태: 결정정합 (5-11+ 마디 박힘)

> 5-11+ 마디 큰 정정 (전투 4.0 → 5.0):
> - 실패 면 어휘 폐기 (실제 면 비율엔 본디 없음. "실패"는 결산 상태)
> - 면 결 = 의지·신성·경계 3종 (어휘 정정)
> - 공·방 1택 선언 → 다이시 테일즈식 (면 종류 → 행동 풀)
> - 행동 5종 (격돌·사격·보호·축복·저주) + 상태 이상 결
> - 반대 시간대 면 = 졸전 (작게 박힘, 결산 X 아님)
> - 변형 결 (강타 ×1.5, 졸전 ×0.5 잠정)
> - 매 라운드 행동 선택 → 작은 AI + 영웅·반신 라운드 1회 결단
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-11 마디 큰 정정:
> - 주사위 2종 (행동 + 인도) → 의지 1종으로 합침
> - 신성력 패러미터 폐기 (인도 결산 곱셈치 폐기)
> - 면 결 = 의지·신성·경계·실패 4종 (옛 결: 칼/방/실 + 인도 6면 → 통합) [5-11+ 정정: 실패 어휘 폐기]
> - 박힘 면 = 시간대 종속 (자기 시간대 라운드만 4면 박힘)
> - 직업 5종 → 3종 (전사/사냥꾼/신관, 면 비율은 직업 결 X — 모든 인물 같음) [5-11+ 정정: 4종]
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - "주사위가 곧 신성력이 포함된 의지 덩어리" — 한 굴림에 의지 + 신성 결 합주
> - 별 면 재굴림 무한 폐기 (재굴림 결 펜딩)
> - 시간대 2종 → 3종 (낮/경계/밤)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

전투 판정의 기반. d6 의지 주사위 1종. 의지(별) 면 + 신성(낮·밤) 면 + 경계 면 (3종, 5-11+ 정정 — 실패 면 어휘 폐기). 자기 시간대 라운드 = 박힘 면 큼 / 반대 시간대 = 별 면만 박힘 (시간대 면은 졸전). 면 종류 → 행동 풀 (다이시 테일즈식, 5-11+ 정정). 박힘 면 × 결산치 (행동별 다름). 인간의 결 + 신의 결이 한 주사위에 합주.

## 규칙

### 의지 주사위 (1종, 모든 인물)

```yaml
type:        d6 (모든 인물 보유)
faces:       의지 / 신성 / 경계 (3종, 5-11+ 정정 — 실패 어휘 폐기)
주사위 수:   등급 결로 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)

면 결:
  의지 면 (별):    완전 성공 — 어느 시간대든 박힘
  신성 면 (낮·밤): 조건부 — 자기 시간대 라운드만 박힘 (반대 시간대 = 졸전)
  경계 면:          조건부 — 경계 인물만 자기 시간대 (경계 시간대) 박힘

5-11+ 정정 자리:
  옛 결 (5-11): 면 4종 (의지·신성·경계·실패) — 실패 면 어휘 박힘
  새 결 (5-11+): 면 3종. "실패"는 면 종류가 아니라 *결산 상태*
  근거 (본인 짚은 결): "실패 면이 사실 없잖아 자기 시간대 아니면 실패니까"
                    실제 면 비율엔 본디 없음 (4종으로 6면 구성)

졸전 결 (5-11+ 박힘):
  반대 시간대 라운드에서 시간대 면 박힘 = 졸전 (결산 X 아님, 작게 박힘)
  본인 박은 결: "안 싸우는 건 아니지만 퍼포먼스 낮음"
  결산 결: 변형 ×0.5 (잠정, 반올림)

결의 결:
  "주사위가 곧 신성력이 포함된 의지 덩어리"
  → 인간의 결 (의지 면) + 신의 결 (신성·경계 면) 합주
  → 등급 = 신성 결의 그릇 (주사위 수)
  → 별도 신성력 패러미터 X (등급 자체가 신성 깊이)

N대N 전체 (적+아군 합산):
  최소: 2
  최대: 60 (잠정. 시뮬 후 트윅)
```

### 면 비율 (팩션별)

```yaml
지상:  별 2 / 경계 2 / 낮 2     → 별 3 / 경계 2 / 낮 1
미궁:  별 2 / 경계 2 / 밤 2     → 별 3 / 경계 2 / 밤 1
경계:  별 2 / 경계 2 / 낮 1 / 밤 1 → 별 3 / 낮 1 / 밤 1 / 경계 1

성공·실패:
  지상: 별·낮 = 성공 / 경계·밤 = 실패
  미궁: 별·밤 = 성공 / 경계·낮 = 실패
  경계: 별·경계 = 성공 / 낮·밤 = 실패

자기 시간대:
  지상 = 낮 시간대 (낮 면 박힘)
  미궁 = 밤 시간대 (밤 면 박힘)
  경계 = 경계 시간대 (경계 면 박힘)

→ 면 비율은 직업 결 X (모든 직업 같음)
→ 직업 결 = 행동 양식 + 분배 비율로만 박힘
```

### 박힘 면 (시간대 종속, 5-11+ 정정)

```yaml
박힘 면 = 자기 시간대 라운드 + 반대 시간대 라운드 다름

자기 시간대 라운드 (지상 = 낮 / 미궁 = 밤 / 경계 = 경계):
  별 3 + 자기 시간대 면 1 = 박힘 4면 (67%)
  반대 시간대 면 = 결산 X (졸전 결 — 자기 시간대 라운드에선 졸전도 X)

반대 시간대 라운드 (자기 시간대 X 모든 시간대):
  별 3 = 박힘 3면 (50%)
  자기 시간대 면 = 졸전 (5-11+ 박힘 — 작게 박힘, 결산 X 아님)
  반대 시간대 면 = 결산 X

5-11+ 정정 자리:
  옛 결 (5-11): 자기 시간대 면 = 실패 (반대 시간대 라운드에서)
  새 결 (5-11+): 자기 시간대 면 = 졸전 (작게 박힘 ×0.5 잠정)
  근거 (본인 박은 결): "안 싸우는 건 아니지만 퍼포먼스 낮음"
                    실패 면 어휘 폐기로 결산 결의 결 자연 박힘.

의존도 결:
  자기 시간대 4면 vs 반대 3면 + 졸전 = 1.33~1.5배 차이
  → 5-11 결: 의존도 *완화* (옛 5-10 결: 4면 vs 2면 = 2배)
  → 5-11+ 결: 졸전으로 한 박자 더 완화
  → 결산 결 변동 작음. 시뮬 결 안정.
```

### 시간대 흐름 (5-11 박힘)

```yaml
시간대 3종: 낮 / 경계 / 밤

흐름 (라운드별 변동):
  낮 → 경계 → 밤 → 경계 → 낮 → 경계 → 밤 → ...
  → 1 라운드마다 시간대 1회 변동

페이즈 시작 시간대 (R1):
  지상: 1=낮 / 2=밤 / 3=낮 / 4=밤
  미궁: 1=밤 / 2=낮 / 3=밤 / 4=낮
  경계: 시작 랜덤

자기 시간대 라운드 비율:
  지상 (낮 페이즈): R1 낮 (자기) / R2 경계 / R3 밤 (반대) / R4 경계
                    → 자기 시간대 1/4 라운드
  지상 (밤 페이즈): R1 밤 (반대) / R2 경계 / R3 낮 (자기) / R4 경계
                    → 자기 시간대 1/4 라운드

  경계: 어느 페이즈든 R2·R4 경계 (자기 시간대) → 자기 시간대 2/4 라운드
       R1·R3 = 반대 시간대 (낮 또는 밤)
       → 경계 = 자기 시간대 자주 박힘. 단 반대 시간대 (R1) = 결 작음.
```

### 의지 결산 (5-11+ 박힘)

```yaml
선언 결 (단계 0, 굴림 전) — 다이시 테일즈식 (5-11+ 정정):
  필멸: 결단 X. 인물 카드 우선순위로 자동.
  영웅·반신: 라운드당 1회 결단 (행동 1택 + 대상 1택)
  → 굴림 → 박힌 면 보고 자동 발동 (호메로스 결: 인간이 결 박고 신이 응답)

옛 결 (5-11): 공/방 1택 (단계 0 선언)
새 결 (5-11+): 행동 풀 + 면 → 행동 (단순 1택 X)
근거 (본인 박은 결):
  - "공·방 고르게 하기가 무의식적으로 별로 의미 없다는 걸 눈치챔"
  - "다이시 테일즈가 마지막으로 한 인디 게임, 가져가고 싶은 결"
  - "굴려서 나온 면으로 뭔가를 한다는 게 좋아 보임"

굴림 결 (단계 1):
  의지 주사위 굴림 (등급 수만큼)
  자기 시간대 라운드 = 별 + 자기 시간대 면 박힘
  반대 시간대 라운드 = 별 박힘 + 자기 시간대 면 졸전

행동 풀 결 (5-11+ 박힘):
  면 종류가 행동 결정:
    별 면 → 직업 기본 행동 (격돌·사격·보호 등)
    자기 시간대 면 → 변형 행동 (강타·계통 특수)
    반대 시간대 라운드의 자기 시간대 면 → 졸전 (작게 박힘)

결산 결 (단계 2):
  격돌: 박힘 면 × 공격력 = 공격 점수 + 박힘 면 × 방어력 = 방어 점수 (양쪽)
  사격: 박힘 면 × 공격력 = 공격 점수
  수비: 박힘 면 × 방어력 = 방어 점수
  보호: 박힘 면 × 방어력 = 대상 보호 점수
  변형 결 (잠정): 강타 ×1.5 / 졸전 ×0.5 (반올림)
  
  순서 점수 = 시간대 보정 + 인물 속도 (별도 결, 의지 결산 X)

피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp
  보호막은 깎이지 않음 (감산식에 박히지만 영구)

영 허용:
  공격력 0 = 비공격 인물 (펜딩 — 사제 결 자리)
  방어력 0 = 글래스 캐논 (사냥꾼 = 방어 X 결산)
  → 사냥꾼은 공격 결만 결산. 방어 X.
```

### 결산 예시 (5-11+ 박힘)

```yaml
예 1: 필멸 인간 전사 (공1/방1, 의지 주사위 1개), 자기 시간대 라운드:
  굴림: 별 면 박힘
  행동: 격돌 (별 면 = 직업 기본)
  공격 점수 = 1 × 1 = 1 / 방어 점수 = 1 × 1 = 1 (격돌은 양쪽)

예 2: 같은 인물, 굴림 = 자기 시간대 면 (낮):
  행동: 강타 (변형)
  공격 점수 = 1 × 1 × 1.5 = 1.5 (반올림 2) / 방어 점수 = 0 (강타는 공만? 펜딩)

예 3: 같은 인물, 반대 시간대 라운드, 굴림 = 자기 시간대 면 (낮):
  행동: 졸전 (작게 박힘)
  공격 점수 = 1 × 1 × 0.5 = 0.5 (반올림 1) / 방어 점수 = 0.5 (반올림 1)

예 4: 반신 영웅 전사 (공2/방1, 의지 주사위 2개), 자기 시간대 라운드:
  굴림 [별, 별]:    격돌, 공=2×2=4, 방=2×1=2
  굴림 [별, 낮]:    강타 (변형), 공=2×2×1.5=6 (필살 결)
  굴림 [별, 밤]:    격돌 1면 + 졸전 1면, 공=1×2+1×2×0.5=3

예 5: 신성 영웅 (공2/방1, 의지 주사위 3개), 자기 시간대:
  굴림 [별, 낮, 별]: 면 종류 2종 박힘 → 작가 결로 행동 풀 결정 (펜딩)
                    잠정: 격돌 2면 + 강타 1면, 공=2×2 + 1×2×1.5 = 7
                    → 영웅·반신 결단 결에서 본인 결로 박힘

→ 결산 결 풍부 + 자원 경영 결 살아남 (본인 박은 결)
```

### 순서 점수 결산

```yaml
순서 점수 = 시간대 보정 + 인물 속도
  → 라운드 시작 시 정해짐 (의지 결산 X)

시간대 보정 (R1 시간대 결로):
  지상 인물 + 낮 시간대 = +2
  지상 인물 + 경계 시간대 = +1
  지상 인물 + 밤 시간대 = 0
  미궁 인물 + 낮 시간대 = 0
  미궁 인물 + 경계 시간대 = +1
  미궁 인물 + 밤 시간대 = +2
  경계 인물 + 어느 시간대 = +1

```
