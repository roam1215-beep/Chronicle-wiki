> 상태: 결정정합 (5-9 코어 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-9 정정:
> - 파일명 변경: 병종.md → 직업종족.md
> - ID 변경: COMBAT-UNIT-NAMELESS → COMBAT-UNIT-JOBRACE
> - 어휘: 병종 5종 + 용병 (5-7 결) → 직업·종족 5종 (5-9 행동 주사위 분화)
> - 면 = 행동 표현 (칼/방패/실패) 부활. 시간대 결은 신성 주사위로 분리.
> - 패시브 시스템 (굳건/반격/선제/쇄도) 폐기. 흡수 X.
> - 공/방 = 인물별 속성 (해석 1). 카드별 X.
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의

직업·종족 = 인물의 행동 주사위 면 비율 결. 5종 분화 (실패 면 2 고정 + 칼·방 4면 분배). 지상·경계 = 직업 결. 미궁 = 종족 결. 형식 동일.

## 규칙

### 행동 주사위 분화 5종

```yaml
공통:
  주사위:    d6
  면:        칼 / 방패 / 실패 3종
  실패 면:   2 고정 (운빨 보장)
  칼·방:    4면 안에서 분배

5종:
  A. 칼4 / 실2          — 사냥꾼 (공격 극단)
  B. 칼3 / 방1 / 실2    — 펜딩 (콘텐츠 결. 공격 치우침)
  C. 칼2 / 방2 / 실2    — 전사 (균형)
  D. 칼1 / 방3 / 실2    — 펜딩 (콘텐츠 결. 방어 치우침)
  E. 방4 / 실2          — 사제 (방어 극단)

대칭:
  A ↔ E (양극)
  B ↔ D (치우침)
  C (균형)

결의 결:
  사냥꾼: 터지면 큼. 막을 결 X.
  전사:   균형. 견딤. 신화 결로 가장 풍부 (헥토르·테세우스·이아손).
  사제:   방어 극단. 그리스 신화로는 드문 결 (펜딩).
```

### 직업 vs 종족

```yaml
지상·경계:    직업 결 (사냥꾼 / 전사 / 사제 등)
미궁:          종족 결 (어휘 펜딩)
형식:          동일 (행동 주사위 면 비율 5종)

출신별 공유 풀 vs 다른 풀: 펜딩 (다음 마디)
```

### 행동 결산

```yaml
행동 면 × 인물 공·방 수치:
  칼 면 × 공격력 = 공격 점수
  방패 면 × 방어력 = 방어 점수
  실패 = 무

상세: @COMBAT-DICE-001
```

### 공·방 수치

```yaml
배치: 인물별 속성 (해석 1)
카드별 X: 5-5 결 부활하지 않음. 카드 시스템과 분리.
잠정 시드: 펜딩 (시뮬 후 확정)
등급별 차이: 영웅·재앙 = 큼 / 인간 = 보통 / 무리 = 작음 (잠정)
상세: @COMBAT-UNIT-CARD
```

### 주사위 수

```yaml
행동 주사위 수 = 인간 역량 (등급/인물 종속)
신성 주사위 수 = 신성 깊이 (영웅·재앙만. 등급/덕목 종속)

잠정 시드:
  무리:    행동 1 / 신성 0
  인간:    행동 N / 신성 0
  영웅:    행동 N / 신성 N
  재앙:    행동 N / 신성 N

상세: @COMBAT-UNIT-HERO
```

### 폐기 항목

```yaml
- 병종 5종 + 용병 (5-7 어휘):  5-9 어휘 정정 (직업·종족 결)
- 면 비율 = 시간대 (5-8):       5-9 정정 (행동 면과 신성 면 분리)
- 패시브 시스템 (5-7):          5-7 폐기. 5-9 흡수 X.
                                옛 결: 굳건/반격/선제/쇄도 — 행동 풀 흡수 시도 → 5-9 자동 결로 폐기
- 8 특성 시스템:                5-7 폐기 (전투 효과 — 다른 세션)
- 편성 시스템:                  5-7 폐기 (다른 세션)
- 태그 ([회유]/[징집]/[모집]):  5-7 폐기 (태그 시스템)
- 추종자 합류 결:                5-7 폐기 (추종자 재설계 대기)
- color 필드:                    색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:          대형 폐기 (4-26)
- 방진 패시브:                   5-5 폐기
- 행동 카드 / 모드 선언:        5-9 폐기 (sRPG·격투 결로 가지 않음)
- 다이몬 결:                     5-9 폐기 (시너지·공유 효과 — 영영 안 박힐 수도)
- 1격사 결 (Nameless):           5-7 폐기. 5-9 모든 등급 hp 보유 그대로.
```
