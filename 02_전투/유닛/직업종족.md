# 직업·종족 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 위치 고정, 사거리 결, 사제 위치 제한
> 정정: 4축 결, 자동 매커니즘, 자유 배치

---

## 직업 4종

```yaml
전사 / 수호자 / 사냥꾼 / 사제

배치: 자유 (전열·후열 다, 4축 무관)
유저 결단: 매 라운드 명령 시 자리 자유 변경
직업 자동 매커니즘 (인물별 결단 X)
```

---

## 전사

```yaml
통상 / 돌격:
  페이즈 3 (격돌 페이즈)
  공격 대상: 적 전열 가장 좌측 또는 도발 대상
  공격력 = 상대 hp 직격
  자기도 적 공격 받음 (격돌 동시 결산)

대성공 / 격파:
  돌격 + 양 옆 대상 광역 피해
  옆 자리 X면 광역 X (단일 격돌)
  격돌 피해는 첫 전투 대상에게만
  지속: 그 라운드만

팩션 결 (펜딩, 작가 결):
  지상 전사: 정통 결
  미궁 전사: 야성 결
  경계 전사: 떠돌이 결
```

---

## 수호자

```yaml
통상 / 방어:
  페이즈 3 (격돌 페이즈)
  도발 (격돌 시 가장 먼저 피격)
  도발 = 전열에서만 작동 (후열 가면 X)

대성공 / 수호:
  방어 + 격돌 전 임시 방어도 (자신에게)
  지속: 그 라운드만

팩션 결:
  지상 수호자: 수비 강함 (방어도 결)
  미궁 수호자: 공격 강함 (격돌 결)
  경계 수호자: 떠돌이
```

---

## 사냥꾼

```yaml
통상 / 사격:
  페이즈 2 (사격 페이즈)
  공격 대상: 자기 위치에서 가장 먼 적 (열 기준)
  자기 피해 X (격돌 X)
  공격력만큼 피해
  도발 효과 받지 X (격돌이 아니라)

대성공 / 저격:
  사격 + 추가 피해 (치명타 결)
  지속: 그 라운드만

거리감:
  같은 열에서 가장 먼 적
  사례: 적 전열 가 나 / 후열 다 라
        사냥꾼 자기 좌측 → 가장 먼 = 라
        사냥꾼 자기 우측 → 가장 먼 = 다(자기 좌측 ↔ 적 우측)
```

---

## 사제

```yaml
계통 분리: 지상 / 미궁 (경계 사제 X)

지상 사제:
  통상 / 축복:
    페이즈 1 (보호·축복·저주 페이즈)
    우리 진영 전열 좌측에 임시 방어도
    도발 효과 받지 X
  
  대성공 / 축성:
    축복 + 방어도량 증가
    지속: 그 라운드만

미궁 사제:
  통상 / 저주:
    페이즈 1
    적 진영 전열 좌측에 피해 또는 스탯 감소
    도발 효과 받지 X
    적 좌측 사망 시 → 다음 좌측 또는 후열 좌측 (전열 다 죽으면)
  
  대성공:
    펜딩 (작가 결)

경계 사제 X (희미함이 개성)
```

## 4축 결 통째

```yaml
진영 (3종): 지상 / 미궁 / 경계
종족 (2종): 인간 / 무리
태생 (4종): 한낮 / 여명 / 황혼 / 심야
위계 (4종): 인간 / 영웅 / 무리 / 재앙
등급 (4종): 필멸 / 반신 / 신성 / 번외 (내부, 노출 X)

진영-종족-태생 조합 (4 자리):
  지상 + 인간 + 한낮 태생
  경계 + 인간 + 여명 태생
  경계 + 무리 + 황혼 태생
  미궁 + 무리 + 심야 태생

직업: 자유 (4축 무관, 모든 조합 가능)

종족 ↔ 위계 정합:
  인간 종족: 인간 ↔ 영웅
  무리 종족: 무리 ↔ 재앙
```

---

## 종족 결

```yaml
인간:
  진영: 지상 또는 경계
  태생: 한낮 (지상) 또는 여명 (경계)
  위계: 인간 ↔ 영웅 (Order 클리어 시 등극)

무리:
  진영: 미궁 또는 경계
  태생: 심야 (미궁) 또는 황혼 (경계)
  위계: 무리 ↔ 재앙 (Order 클리어 시 등극)

경계의 결:
  인간 = 지상에 속하지 못한 자 (여명 태생)
  무리 = 미궁에 속하지 못한 자 (황혼 태생)
  → 시간 속성의 비유 그 자체
  → 본인 결: "여명과 황혼 둘다 낮도 밤도 섞여있는거잖아"
```

---

## 진영 결

```yaml
지상 (낮):
  종족: 인간만
  태생: 한낮
  신앙: 인격신 (그리스 올림포스 결)
  자기 시간대: 낮

미궁 (밤):
  종족: 무리만
  태생: 심야
  신앙: 자연신
  자기 시간대: 밤

경계:
  종족: 인간 + 무리 둘 다
  태생: 여명(인간) + 황혼(무리)
  자기 시간대: 경계
  본인 결: "신앙 X 결" 결정 펜딩 (옛 결 폐기 자리)
```

---

## 위계 변동 (Order 클리어 시)

```yaml
인간 → 영웅:
  카타스테리스모스 결
  신성 X → 신적 결로 승천
  가호 폭 큼 (저위계 → 고위계)
  태생 = 변동 X

무리 → 재앙:
  같은 결로 적 진영 자리
  가호 폭 큼
```

---

## 등급 변동 (챕터 클리어 시)

```yaml
필멸 → 반신 → 신성 → 번외

챕터 클리어:
  의지 +1 (주사위 수 +1)
  가호 +1 (가호 수 +1)
  한 박자에 둘 다

내부 결 (게임 노출 X):
  가호 결로 체감 (가호 수가 늘어남)
```

## 폐기 자리 (5-12 후속)

```yaml
✗ 위치 고정 (전사·수호자 = 1열 / 사냥꾼·사제 = 2열)
  → 모든 직업 자유 배치

✗ 사거리 결 (모든 직업 1열만)
  → 사냥꾼·사제 = 자기 위치 가장 먼 적

✗ 분배 비율 결 (직업별 면 비율 분배)
  → 면 비율 = 팩션 결만

✗ 변형 결 ×1.5 어휘
  → 대성공 = 행동 종류 변형 (격파·수호·저격·축성)

✗ 사거리 = "모든 직업 1열만 공격" 결
  → 사냥꾼·사제 = 다른 결
```
