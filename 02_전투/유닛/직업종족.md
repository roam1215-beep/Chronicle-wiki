# COMBAT-UNIT-JOBRACE: 직업·종족

> 상태: 결정정합 (5-10 마디 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-10 마디 박힘:
> - 직업 5종 어휘 박힘: 사냥꾼 / 용병 / 전사 / 수호자 / 사제
> - D 결 (칼1/방3/실2) 부활 = 수호자 자리
> - 직업 ↔ 진형 결 (배치 위치)
> - 직업 ↔ 사거리 결 (기본 사거리)
> - 사제 = 특수 결 (방패 결산 부여)
> - 미궁 종족 = 같은 풀 공유 (어휘 일단 직업 어휘 사용)
> 상세: `DOCS/DESIGN/LOG/2026-05-10_사거리·진형·사제·인도·덕목.md`

## 정의

직업·종족 = 인물의 행동 주사위 면 비율 결 + 진형 위치 + 기본 사거리. 5종 분화 (실패 면 2 고정 + 칼·방 4면 분배). 지상·경계 = 직업 결. 미궁 = 종족 결 (어휘 펜딩, 같은 풀 공유). *속도와 무관* — 속도는 인물별 5 패러미터.

## 규칙

### 직업 5종 (5-10 박힘)

```yaml
공통:
  주사위:    d6
  면:        칼 / 방패 / 실패 3종
  실패 면:   2 고정 (운빨 보장)
  칼·방:    4면 안에서 분배

5종:
  사냥꾼:   칼4 / 방0 / 실2  + 2열 고정    + 원거리              + 특수 X
  용병:     칼3 / 방1 / 실2  + 1·2열 선택  + 위치 종속           + 특수 X
  전사:     칼2 / 방2 / 실2  + 1열 고정    + 근접                + 특수 X
  수호자:   칼1 / 방3 / 실2  + 1열 고정    + 근접                + 특수 X
  사제:     칼0 / 방4 / 실2  + 2열 고정    + 공격 X              + 방패 결산 부여 결

대칭:
  사냥꾼 ↔ 사제 (양극 — 공격 극단 ↔ 방어 극단)
  용병 ↔ 수호자 (치우침)
  전사 (균형)

결의 결:
  사냥꾼: 터지면 큼. 막을 결 X.
  용병:   유동적 결. 위치 종속 사거리 = 결의 결 풍부.
  전사:   균형. 견딤. 신화 결로 가장 풍부 (헥토르·테세우스·이아손).
  수호자: 방어 위주의 전투 결. 1열에서 견디는 자리.
  사제:   공격 X + 보호 결. 그리스 신화 결의 사제·신녀.
```

### 진형 결 (5-10 박힘)

```yaml
2단 진형:
  1열 (전위) / 2열 (후위)

배치 (편성 단위, 전투 시작 시 1번):
  사냥꾼:   2열 고정
  용병:     1·2열 선택
  전사:     1열 고정
  수호자:   1열 고정
  사제:     2열 고정

자동 진열:
  1열 전멸 = 근접 공격이 2열도 닿음 (자연 결)
  앞 인물 hp 0 = 뒤 인물 노출

상세: @COMBAT-STRUCT-001
```

### 사거리 결 (5-10 박힘)

```yaml
사거리 5종:
  근접:           1열 → 적 1열만 (1열 전멸 시 적 2열까지)
  원거리:         적 1·2열 선택 (1명만)
  광역-세로:      1열 적 모두 타격
  광역-가로:      1·2열 적 1명씩 (2명 타격)
  광역-전체:      1·2열 적 모두 타격

직업 ↔ 사거리 (기본):
  사냥꾼:   원거리
  용병:     위치 종속 (1열 = 근접 / 2열 = 원거리)
  전사:     근접
  수호자:   근접
  사제:     공격 X (방어 결만)

광역 결:
  인물 카드에 박힘 (영웅·재앙 자리)
  결의 결: 필살기·패턴 결 (펜딩 — 다음 마디)
  무리·인간 = 기본 광역 X
```

### 사제 특수 결 (5-10 박힘)

```yaml
보호 결 (방패 결산 부여):
  굴림 전 선언 단계 = 보호 대상 박음 (자기 / 다른 인물)
  방패 결산 통째로 부여 = 방패 면 N × 사제 방어력 → 대상 방어 점수에 추가
  
결의 결:
  사제 방어력 (5 패러미터) = 보호 결의 깊이
  굴림 결과 어그러질 수도 (방패 0면 = 그저 무)
  호메로스 결 정합 (사제의 결이 영웅에게 임함)

선언 시점:
  단계 0 (굴림 전) = 인도 선언과 같은 자리
  결의 결 = 결을 *먼저* 박고 굴림이 결 따라옴
```

### 직업·종족이 결정하는 자리 / 결정하지 않는 자리

```yaml
결정 (직업·종족 종속):
  행동 주사위 면 비율 (5종 중 1)
  진형 배치 위치 (1열 / 2열 / 선택)
  기본 사거리 (근접 / 원거리 / 위치 종속 / 공격 X)
  특수 결 (사제만)

결정 X (인물별 속성. 5 패러미터로):
  공격력 — 같은 사냥꾼이라도 인물별 다름
  방어력 — 같은 사제라도 인물별 다름
  생명력 — 인물별
  속도 — 인물별 (직업·종족 무관)
  신성력 — 인물별 (영웅·재앙만 의미)
  
결정 X (인물별):
  행동 주사위 수 — 인물별 (등급 결 X)
  인도 주사위 수 — 인물별 (영웅·재앙만)
  광역 사거리 — 인물 카드에 박힘 (영웅·재앙 자리, 펜딩)

→ 직업·종족 = *결의 결*만 결정 (행동 비율 + 배치 + 기본 사거리)
→ 인물 차별화 = 5 패러미터 + 인물별 결로 (자유 조합)
→ "느린 사냥꾼" / "빠른 사제" 같은 결도 표현 가능 ★
```

### 직업 vs 종족

```yaml
지상·경계:    직업 결 (사냥꾼 / 용병 / 전사 / 수호자 / 사제)
미궁:          종족 결 (어휘 펜딩, 직업 어휘 일단 사용)
형식:          동일 (5종, 같은 풀 공유)

5-10 박힘: 같은 풀 공유 결. 어휘만 다를 자리 (CON 결, 본인 자리).
```

### 행동 결산

```yaml
행동 면 × 인물 공·방 수치:
  칼 면 × 공격력 = 공격 점수
  방패 면 × 방어력 = 방어 점수
  실패 = 무

상세: @COMBAT-DICE-001
```

```yaml
배치: 인물별 속성 (5 패러미터 결로 5축 분리)
잠정 시드: 펜딩 (시뮬 후 확정)
영 허용:
  공 0 / 방 0 / 신성력 0 모두 가능
  
상세: @COMBAT-UNIT-CARD
```

### 주사위 수 (인물별 — 5-10 박힘)

```yaml
행동 주사위 수 = 인물별 (신과 무관한 개인 존재의 역량/그릇)
인도 주사위 수 = 인물별 (영웅·재앙만, 보유 자체는 등급 결)

잠정 시드:
  무리·인간:  행동 1~N (인물별, 신성 0)
  영웅·재앙:  행동 N / 인도 N (인물별)

5-10 정정:
  옛 결: 등급 결로 행동/신성 주사위 수 박힘
  새 결: 인물 카드에 박혀서 나옴 (등급 결 X)
  무리도 행동 결 많을 수 있음

상세: @COMBAT-UNIT-HERO
```

### 폐기 항목

```yaml
- 병종 5종 + 용병 (5-7 어휘):  5-9 어휘 정정
- 면 비율 = 시간대 (5-8):       5-9 정정
- 패시브 시스템 (5-7):          5-7 폐기. 5-9 흡수 X.
- 8 특성 시스템:                5-7 폐기
- 편성 시스템:                  5-7 폐기 (다른 세션)
- 태그 ([회유]/[징집]/[모집]):  5-7 폐기
- 추종자 합류 결:                5-7 폐기
- color 필드:                    색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:          대형 폐기 (4-26)
- 방진 패시브:                   5-5 폐기
- 행동 카드 / 모드 선언:        5-9 폐기
- 다이몬 결:                     5-9 폐기
- 1격사 결 (Nameless):           5-7 폐기. 5-9 모든 등급 hp 보유.
- 직업 종속 속도 (5-9 시도):     5-9 5패러미터 정정 (속도 별도 패러미터)
- 직업 4종 + B·D 펜딩 (5-9):     5-10 정정 (5종 어휘 박힘)
- 등급 종속 주사위 수 (5-9):     5-10 정정 (인물별)
- 무리 행동 = 1개 고정 (5-9 잠정): 5-10 정정 (인물별)
```
