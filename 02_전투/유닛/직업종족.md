# 직업·종족

> 상태: 결정정합 (5-11+ 마디 박힘)

> 5-11+ 마디 큰 정정 (전투 4.0 → 5.0):
> - 직업 3종 → 4종 (신관 폐기, 수호자·사제 부활)
> - 행동 양식 = 다이시 테일즈식 (면 종류 → 행동 풀)
> - 행동 5종 어휘 (격돌·사격·보호·축복·저주) + 상태 이상 결
> - 사거리 정정 (사냥꾼·사제 = 1열만)
> - 직업 = 분배 비율 결 폐기 (행동 양식만, 분배는 팩션 결로)
> - 사제 계통 결 (지상 = 보호·축복 / 미궁 = 저주·사격 / 경계 = 사제 X)
> - 경계 = 전사·사냥꾼만 (희미한 결 = 개성)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-11 마디 큰 정정:
> - 직업 5종 → 3종 (전사/사냥꾼/신관, 용병/사제/수호자 폐기) [5-11+ 정정으로 4종 부활]
> - 직업 결 = 면 비율 분화 폐기 (모든 인물 같음)
> - 직업 결 = 행동 양식 + 분배 비율로 박힘 [5-11+ 정정: 행동 양식만]
> - 사제 특수 결 (방패 결산 부여) 폐기 [5-11+ 정정: 사제 부활, 결산 결 정정]
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - 인도 주사위 / 신성력 패러미터 폐기
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

직업·종족 = 인물의 행동 양식 결 + 진형 위치. 4종 분화 (5-11+ 정정). 지상·경계 = 직업 결. 미궁 = 종족 결 (어휘 펜딩, 같은 풀 공유). *면 비율과 무관* — 면 비율은 팩션 결 (지상/미궁/경계). 능력치(공·방·hp·속) 는 인물별. 분배 결은 팩션 결의 결로 흡수 (5-11+ 정정 — 작가 결).

## 규칙

### 직업 4종 (5-11+ 박힘)

```yaml
공통:
  의지 주사위 (1종, 모든 인물)
  면 비율 = 팩션 결 (지상/미궁/경계, 같음)
  → 직업 결로 면 비율 분화 X (5-11 정정 살림)

4종 행동 양식:
  전사:
    배치:    1열 고정
    행동 결: 격돌 (1열 적 — 받기·주기 양방향)
    공·방:   양쪽 살아남 (한쪽 1택 X — 5-11+ 정정)
    
  수호자:
    배치:    1열 고정
    행동 결: 격돌 + 보호 (1열 격돌 + 아군 보호 부여)
    팩션 결: 지상 수호자 = 수비 결 강함 / 미궁 수호자 = 공격 결 강함
    
  사냥꾼:
    배치:    2열 고정
    행동 결: 사격 (1열 적 — 후열에서 일방적, 본인 피해 X)
    방어:    X (방어력 0 — 글래스 캐논 결 살림)
    
  사제:
    배치:    2열 고정
    행동 결: 계통별 다름 (팩션 결)
      지상 사제: 보호 + 축복 중심 (인격신, 보호의 결)
      미궁 사제: 저주 + 사격 중심 (자연신, 저주의 결)
    경계 사제: X (경계엔 사제 없음, 5-11+ 박힘)

5-11+ 정정 자리:
  옛 결 (5-11): 직업 3종, 신관 = 위치 자유
  새 결 (5-11+): 직업 4종, 모두 위치 고정. 신관 폐기.
                "신관을 신관 전사와 사제로 나누고 열 배치 곤란함을 풀어버리면 어떨까" (본인 박은 결)
                결의 결: 약화 X로 4개로 갈리는 결. 트레이드 오프 = 위치 + 행동 풀.

상태 이상 결 (5-11+ 박힘):
  모든 직업이 잠재적으로 보유.
  예: 측면 강타 (별 1, 데미지 X, 기절 부여)
  "단순히 막는다 때린다가 아니게 될 수 있어" (본인 박은 결)
  
결의 결:
  전사:    균형. 견딤. 신화 결로 가장 풍부 (헥토르·테세우스·이아손).
  수호자:  방패의 결. 팩션 결로 자기 색 (지상 = 수비 / 미궁 = 공격).
  사냥꾼:  터지면 큼. 막을 결 X. 글래스 캐논. 후열에서 1열 직격.
  사제:    신적 결의 결 (변신·축복·저주 결). 계통별 다양.
```

### 행동 5종 (편의상 분류, 5-11+ 박힘)

```yaml
1. 격돌:    전열에서 직접 전투. 받기·주기 양방향. (전사·수호자)
2. 사격:    원거리, 일방적 피해. (사냥꾼·미궁 사제)
3. 보호:    방어 능력 지원 (본인·아군). (수호자·지상 사제)
4. 축복:    아군 버프. (지상 사제)
5. 저주:    적 디버프 (그리스 신화 결: 변신 포함). (미궁 사제)

근거 (본인 박은 결):
  - "지상은 축복, 보호의 결이고 미궁은 저주, 사격의 결"
  - "그리스 신화 보면 갑자기 사람을 사슴으로 만들거나 죽인다거나"
  - 그리스 결: 신마다 다른 능력 (인격신 응답 / 자연신 변신 결)
```

### 진형 결 (5-11+ 박힘)

```yaml
2단 진형:
  1열 (전위) / 2열 (후위)

배치 (편성 단위, 전투 시작 시 1번):
  전사:    1열 고정
  수호자:  1열 고정
  사냥꾼:  2열 고정
  사제:    2열 고정

자동 진열:
  1열 전멸 = 근접 공격이 2열도 닿음 (자연 결)
  앞 인물 hp 0 = 뒤 인물 노출

5-11+ 정정 자리:
  옛 결 (5-11): 신관 = 1·2열 선택
  새 결 (5-11+): 모두 위치 고정. 결정 부담 X.

```

### 행동 양식 (직업별, 5-11+ 박힘)

```yaml
다이시 테일즈식 (5-11+ 박힘):
  매 라운드 굴림 → 박힌 면 종류 보고 → 행동 풀에서 자동 발동
  면 종류가 행동 결정:
    별 면:        직업 기본 행동
    자기 시간대 면: 변형 행동 (강화·계통 특수)
    반대 시간대 면: 졸전 (작게 박힘)

전사 (1열):
  기본 (별 면):       돌진 (1열 1명 공격, 격돌)
  기본 (별 면):       수비 (자기 방어, 격돌)
  기본 (별 면):       측면 강타 (1열 1명, 데미지 X, 기절 — 상태 이상)
  변형 (자기 시간대): 강타 (지상 = 큰 공격) / 야습 (미궁 = 데미지 + 디버프)
  
수호자 (1열):
  기본 (별 면):       돌진 (1열 1명 공격)
  기본 (별 면):       수호 (아군 1명 방어 부여, 보호)
  변형 (자기 시간대): 지상 수호자 = 수호 강화 / 미궁 수호자 = 돌진 강화
  
사냥꾼 (2열):
  기본 (별 면):       사격 (1열 1명 원거리)
  방어:                X (방어력 0)
  변형 (자기 시간대): 강화 사격 / 미궁 사냥꾼 = 저주 사격
  
사제 (2열, 계통별):
  지상 사제:
    기본:    보호 (아군 보호막 부여) / 축복 (아군 버프)
    변형:    축복 강화 또는 영구 보호막
  미궁 사제:
    기본:    사격 (1열 적) / 저주 (적 디버프)
    변형:    저주 강화 / 변신 결 (그리스 결, 큰 결 — 펜딩)

사거리 결 (5-11+ 정정):
  모든 직업 = 1열만 공격 (사냥꾼·사제도 후열에서 1열 직격)
  옛 결 (5-11): 사냥꾼 = 1·2열 적 선택
  새 결: "궁수가 뭘 막는 것도 웃기잖아" (본인 박은 결)
        원거리 = "후열에서 1열 박는 결"

영웅·반신 결단 결 (5-11+ 박힘):
  영웅·반신만 라운드당 1회 결단 (행동 + 대상 1택)
  필멸: 결단 X. 인물 카드 우선순위로 자동.
  결단 후 굴림 → 박힌 면 보고 자동 발동 (호메로스 결)

광역 결:
  행동 풀의 변형 결 안에 흡수 (5-11+ — 별도 결 X)
  예: 전사 강타 = 광역 가능 / 사제 축복 = 아군 전체
  결의 결: 필살기·패턴 결 (펜딩 — 다음 마디)
```

### 능력치 결 (5-11+ 정정 — 분배 비율 폐기)

```yaml
직업 분배 비율 = 폐기 (5-11+ 정정):
  옛 결 (5-11): 전사 5:3:2 / 사냥꾼 5:5 등 시스템 결로 박힘
  새 결 (5-11+): 시스템 강제 X. 작가 결로 박힘.
  근거 (본인 박은 결):
    - "경직하고 엄격한 규칙이 아니라 뭔가 아 이 진영은 이런 식이구나 하는 공통된 느낌"
    - 시스템 결 작음. 작품 결의 톤만 살림.

능력치 결의 결 (잠정 — 작가 결로):
  지상:    낮 시간대 강함 + 균형
  미궁:    공방 살림 (느리지만 큼)
  경계:    균형 결 (희미함이 개성)

직업·팩션 합주 (잠정):
  지상 수호자:  방어 결 강함 ("수비적인 전위")
  미궁 수호자:  공격 결 강함 ("공격적인 전위")
  지상 사제:    보호·축복 (인격신)
  미궁 사제:    저주·사격 (자연신)
  사냥꾼:       방 0 (모든 팩션 공통, 글래스 캐논)
  
능력치 합 (잠정 시드):
  필멸 공방 합 2 (사냥꾼은 공 2 / 방 0)
  반신 공방 합 3
  신성 공방 합 4
  속도: 별도 결 (인물 시드 또는 팩션 결, 펜딩)
  
→ 정확한 수치는 인물 박을 때 작가 결.
→ 본인 박은 결: "직업 비율이 팩션에 따라 극단적으로 달라지지는 않을 거야"
```

### 직업·종족이 결정하는 자리 / 결정하지 않는 자리 (5-11+ 정정)

```yaml
결정 (직업 결):
  진형 배치 위치 (1열 / 2열, 고정)
  행동 양식 (보유 행동 풀 — 5-11+ 정정)
  행동 결산 결 (격돌 = 공·방 양쪽 / 사격 = 공만 / 수비 = 방만 등)

결정 X (인물별 속성. 능력치로):
  공격력 — 같은 사냥꾼이라도 인물별 다름 (팩션 결의 결 따름)
  방어력 — 같은 전사라도 인물별 다름 (팩션 결의 결 따름)
  생명력 — 인물별 (등급 참고표 + 인물별 변동)
  속도 — 인물별 (별도 결, 팩션 또는 시드 — 펜딩)
  보호막 — 시작 0, 누적 결 (사건·장비·사제 부여)
  → 분배 = 작가 결. 시스템 강제 X (5-11+ 정정).

결정 X (등급 결):
  의지 주사위 수 — 등급 결 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
  hp — 등급 참고표 (1/3/5/10)

결정 X (인물별):
  특수 행동 결 — 인물 카드에 박힘 (영웅·재앙 자리, 변신 결 등, 펜딩)

→ 직업 = *행동의 결*만 결정 (배치 + 행동 풀)
→ 인물 차별화 = 등급 + 능력치 (자유 조합, 작가 결)
```

### 직업 vs 종족 (5-11+ 정정)

```yaml
지상·경계:    직업 결 (전사 / 수호자 / 사냥꾼 / 사제 — 단 경계는 전사·사냥꾼만)
미궁:          종족 결 (어휘 펜딩, 직업 어휘 일단 사용)
형식:          동일 (같은 행동 양식 풀 공유, 단 팩션 결로 계통 다름)

경계 특수 자리 (5-11+ 박힘):
  경계 = 전사 + 사냥꾼만 (사제·수호자 X)
  근거 (본인 박은 결): "희미한 거 자체가 팩션의 개성"
                    "본디 숫자가 적어 양쪽에 속하지 않은 인물"
                    "균형 잡힌 쪽에 가까운 사냥꾼과 전사가 많음"

5-10 박힘 살림: 같은 풀 공유 결.
5-11+ 정정: 4종으로 확장 + 경계 제한 + 사제 계통 결.
```

### 결산 결 (의지 1종, 5-11+ 정정)

```yaml
의지 주사위 굴림 (등급 수만큼):
  자기 시간대 라운드: 박힘 면 4면 (별 + 자기 시간대 면)
  반대 시간대 라운드: 박힘 면 3면 (별만)
  자기 시간대 면이 박혔는데 반대 시간대 라운드 = 졸전 (작게 박힘)

선언 결 (단계 0) — 다이시 테일즈식 (5-11+ 정정):
  필멸: 결단 X. 인물 카드 우선순위로 자동.
  영웅·반신: 라운드당 1회 결단 (행동 + 대상 1택)
  → 굴림 → 박힌 면 보고 자동 발동

결산 결 (단계 2):
  격돌: 박힘 면 × 공격력 = 공격 점수 + 박힘 면 × 방어력 = 방어 점수 (양쪽)
  사격: 박힘 면 × 공격력 = 공격 점수
  수비: 박힘 면 × 방어력 = 방어 점수
  보호: 박힘 면 × 방어력 = 대상 보호 점수 (그 라운드 또는 영구 — 펜딩)
  변형 결: 강타 ×1.5 / 졸전 ×0.5 (반올림, 잠정)
  
  순서 점수 = 시간대 보정 + 인물 속도

피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp
  보호막은 깎이지 않음 (감산식에 박히지만 영구)

```

### 능력치 (인물별, 5-11+ 정정)

```yaml
배치: 인물별 속성 (공·방·hp·속·보호막 분리)
잠정 시드: 펜딩 (시뮬 후 확정)

5-11+ 정정 자리:
  옛 결 (5-11): 5 패러미터 (공·방·속·hp·신성력 또는 변동)
  새 결 (5-11+): 능력치 어휘로 정정 + 보호막 추가

영 허용:
  공 0 = 비공격 인물 (펜딩, 사제 결 자리?)
  방 0 = 글래스 캐논 (사냥꾼 = 방 X 결산 — 5-11+ 박힘 살림)
  속 ≥ 1 (모든 인물)
  보호막 = 시작 0 (누적 결, 영구)
  
```

### 등급 결 (5-11 박힘)

```yaml
등급 = 의지 주사위 수:
  필멸:    1개
  반신:    2개
  신성:    3개
  번외:    4+개 (보스급)

위계 ↔ 등급 자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)

  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)
  보통 영웅 = 반신·신성 영웅
  운명 보스 = 신성·번외 재앙

```
