# 직업·종족

## 직업 4종

```yaml
전사 / 수호자 / 사냥꾼 / 사제

배치: 자유 (전열·후열, 4축 무관)
유저 결단: 매 라운드 명령 시 자리 자유 변경
직업 자동 매커니즘 (인물별 결단 X)
```

## 전사

```yaml
통상 / 돌격:
  페이즈 3 (격돌)
  적 전열 가장 좌측 또는 도발 대상
  공격력 = 상대 hp 직격
  자기도 격돌 받음 (동시)

대성공 / 격파:
  돌격 + 양 옆 광역 (옆 X면 광역 X)
  격돌 피해는 첫 전투 대상에게만
  지속: 그 라운드만
```

## 수호자

```yaml
통상 / 방어:
  페이즈 3 (격돌)
  도발 (격돌 첫 피격)
  도발 = 전열에서만 작동

대성공 / 수호:
  방어 + 자신에게 임시 방어도 (페이즈 1에서 발동)
  지속: 그 라운드만
```

## 사냥꾼

```yaml
통상 / 사격:
  페이즈 2 (사격)
  자기 위치에서 가장 먼 적 (열 기준)
  자기 피해 X (격돌 X)
  공격력만큼 피해
  도발 효과 받지 X

대성공 / 저격:
  사격 + 추가 피해 (치명타)
  지속: 그 라운드만

거리감 (열 기준):
  자기 좌측 → 가장 먼 = 적 우측
  자기 우측 → 가장 먼 = 적 좌측
  
후열 사냥꾼 = 적 전열 가장 좌측 공격
```

## 사제

```yaml
계통 분리: 지상 / 미궁 (경계 사제 X)

지상 사제:
  통상 / 축복:
    페이즈 1
    우리 진영 전열 좌측에 임시 방어도
    도발 효과 받지 X
  대성공 / 축성:
    축복 + 방어도량 증가
    지속: 그 라운드만

미궁 사제:
  통상 / 저주:
    페이즈 1
    적 진영 전열 좌측에 피해 또는 스탯 감소
    도발 효과 받지 X
    적 좌측 사망 시 → 다음 좌측 또는 후열 좌측
  대성공: [펜딩]
```

## 4축

```yaml
진영 (3): 지상 / 미궁 / 경계
종족 (2): 인간 / 무리
태생 (4): 한낮 / 여명 / 황혼 / 심야
위계 (4): 인간 / 영웅 / 무리 / 재앙

조합 (4 가능):
  지상 + 인간 + 한낮
  경계 + 인간 + 여명
  경계 + 무리 + 황혼
  미궁 + 무리 + 심야

직업: 자유 (4축 무관)

종족 ↔ 위계 정합:
  인간: 인간 ↔ 영웅 (Order 클리어 시 등극)
  무리: 무리 ↔ 재앙
```

## 진영 결

```yaml
지상 (낮):
  종족: 인간만
  태생: 한낮
  신앙: 인격신 (그리스 올림포스)
  자기 시간대: 낮

미궁 (밤):
  종족: 무리만
  태생: 심야
  신앙: 자연신
  자기 시간대: 밤

경계:
  종족: 인간 + 무리 둘 다
  태생: 여명(인간) + 황혼(무리)
  자기 시간대: 경계
```

## 태생 결

```yaml
한낮 = 지상 정통 (낮)
여명 = 경계 인간 (낮으로 가는 결, 밤이 가시는 자리)
황혼 = 경계 무리 (밤으로 가는 결, 낮이 지는 자리)
심야 = 미궁 정통 (밤)

경계 = 시간의 사이 (낮·밤 섞임)
```

## 등극

```yaml
위계 변동 (Order 클리어 시):
  인간 → 영웅 / 무리 → 재앙
  카타스테리스모스 결 (별이 됨)
  태생 = 변동 X
  미리 정한 인물 1명 (작가 결)

등급 변동 (챕터 클리어 시):
  필멸 → 반신 → 신성 → 번외
  의지 +1 (주사위 수) + 가호 +1
  내부 결 (게임 노출 X)
```
