# COMBAT-UNIT-JOBRACE: 직업·종족

> 상태: 결정정합 (5-11 마디 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-11 마디 큰 정정:
> - 직업 5종 → 3종 (전사/사냥꾼/신관, 용병/사제/수호자 폐기)
> - 직업 결 = 면 비율 분화 폐기 (모든 인물 같음, @COMBAT-DICE-001)
> - 직업 결 = 행동 양식 + 분배 비율로 박힘
> - 사제 특수 결 (방패 결산 부여) 폐기
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - 인도 주사위 / 신성력 패러미터 폐기
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

직업·종족 = 인물의 행동 양식 결 + 진형 위치 + 분배 비율. 3종 분화. 지상·경계 = 직업 결. 미궁 = 종족 결 (어휘 펜딩, 같은 풀 공유). *면 비율과 무관* — 면 비율은 팩션 결 (지상/미궁/경계). *공·방·속 무관* — 인물별 5 패러미터.

## 규칙

### 직업 3종 (5-11 박힘)

```yaml
공통:
  의지 주사위 (1종, 모든 인물)
  면 비율 = 팩션 결 (지상/미궁/경계, 같음)
  → 직업 결로 면 비율 분화 X (5-11 정정)

3종 행동 양식:
  전사:
    배치:    1열 고정
    공격:    1열 적 선택 (근접)
    방어:    자기 방어
    분배 비율: 공/방/속 = 5:3:2
    
  사냥꾼:
    배치:    2열 고정
    공격:    1·2열 적 선택 (원거리, 1명만)
    방어:    X (선언 결산 자리 X — 방어력 0)
    분배 비율: 공/속 = 5:5 (방 X)
    
  신관:
    배치:    1·2열 선택
    행동 양식: 1열 박힘 = 전사처럼 / 2열 박힘 = 사냥꾼처럼
    분배 비율: 펜딩 (1열·2열 결로?)

결의 결:
  전사:    균형. 견딤. 신화 결로 가장 풍부 (헥토르·테세우스·이아손).
  사냥꾼:  터지면 큼. 막을 결 X. 글래스 캐논.
  신관:    유동적 결. 위치 종속 행동 양식 = 결의 결 풍부.
           사제 + 수호자 + 용병 합주 결 (5-11 정정).
```

### 진형 결 (5-11 박힘)

```yaml
2단 진형:
  1열 (전위) / 2열 (후위)

배치 (편성 단위, 전투 시작 시 1번):
  전사:    1열 고정
  사냥꾼:  2열 고정
  신관:    1·2열 선택

자동 진열:
  1열 전멸 = 근접 공격이 2열도 닿음 (자연 결)
  앞 인물 hp 0 = 뒤 인물 노출

상세: @COMBAT-STRUCT-001
```

### 행동 양식 (직업별)

```yaml
전사 (1열):
  공격 선언: 1열 적 1명 선택 → 의지 결산 → 피해 박힘
  방어 선언: 자기 방어 → 의지 결산 = 자기 방어 점수 추가
  
사냥꾼 (2열):
  공격 선언: 1·2열 적 1명 선택 (원거리 결) → 의지 결산 → 피해 박힘
  방어 선언: 의미 X (방어력 0 결산)
  
신관:
  1열 박힘 = 전사 행동 양식
  2열 박힘 = 사냥꾼 행동 양식
  → 같은 신관이라도 배치 결로 행동 다름.

광역 결:
  인물 카드에 박힘 (영웅·재앙 자리)
  결의 결: 필살기·패턴 결 (펜딩 — 다음 마디)
  무리·인간 = 기본 광역 X
```

### 분배 비율 (5 패러미터)

```yaml
직업 결 = 분배 비율 결로 박힘 (수치 자체는 인물별):
  전사:    공/방/속 = 5:3:2
  사냥꾼:  공/속 = 5:5 (방 X)
  신관:    펜딩 (1열·2열 결로?)

비율 결산:
  공방속 합 (등급별 참고표): 필멸 3 / 반신 4 / 신성 5 / 번외 7
  → 합 안에서 직업 비율로 분배

예 (반신 등급, 합 4):
  전사:    공 2 / 방 1 / 속 1 (5:3:2 정합)
  사냥꾼:  공 2 / 속 2 (5:5 정합)
  신관:    펜딩

→ 분배 = 인물별 약간 변동 가능 (직업 비율 ±1)
→ 작가 결로 박힘. 자유 결.
```

### 직업·종족이 결정하는 자리 / 결정하지 않는 자리

```yaml
결정 (직업 결):
  진형 배치 위치 (1열 / 2열 / 선택)
  행동 양식 (공격 사거리 / 방어 결의 자리)
  분배 비율 (공·방·속 결로)

결정 X (인물별 속성. 5 패러미터로):
  공격력 — 같은 사냥꾼이라도 인물별 다름 (단 분배 비율 결 따름)
  방어력 — 같은 전사라도 인물별 다름
  생명력 — 인물별 (등급 참고표 + 인물별 변동)
  속도 — 인물별 (직업 결 종속 X 자리?)
  → 분배 비율 = 자리. 인물별 약간 변동.

결정 X (등급 결):
  의지 주사위 수 — 등급 결 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
  hp — 등급 참고표 (1/3/5/10)

결정 X (인물별):
  광역 사거리 — 인물 카드에 박힘 (영웅·재앙 자리, 펜딩)

→ 직업 = *행동의 결*만 결정 (배치 + 행동 양식 + 분배 비율)
→ 인물 차별화 = 등급 + 5 패러미터 (자유 조합)
```

### 직업 vs 종족

```yaml
지상·경계:    직업 결 (전사 / 사냥꾼 / 신관)
미궁:          종족 결 (어휘 펜딩, 직업 어휘 일단 사용)
형식:          동일 (3종, 같은 행동 양식 풀 공유)

5-11 정정: 같은 풀 공유 결 (이전 5-10 결 살림). 어휘만 다를 자리 (CON 결, 본인 자리).
```

### 결산 결 (의지 1종)

```yaml
의지 주사위 굴림 (등급 수만큼):
  자기 시간대 라운드: 박힘 면 4면 (별 + 자기 시간대 면)
  반대 시간대 라운드: 박힘 면 3면 (별만)

선언 결 (단계 0):
  공격 / 방어 1택

결산:
  공격 선언: 박힘 면 × 공격력 = 공격 점수
  방어 선언: 박힘 면 × 방어력 = 방어 점수
  순서 점수 = 시간대 보정 + 인물 속도

피해 = max(0, 자기 공격 - 상대 방어)

상세: @COMBAT-DICE-001
```

### 5 패러미터 (인물별)

```yaml
배치: 인물별 속성 (공·방·속·hp 4축 분리)
잠정 시드: 펜딩 (시뮬 후 확정)
영 허용:
  공 0 = 비공격 인물 (펜딩, 신관 결 자리?)
  방 0 = 글래스 캐논 (사냥꾼 = 방 X 결산)
  속 ≥ 1 (모든 인물)
  
상세: @COMBAT-UNIT-CARD
```

### 등급 결 (5-11 박힘)

```yaml
등급 = 의지 주사위 수:
  필멸:    1개
  반신:    2개
  신성:    3개
  번외:    4+개 (보스급)

위계 ↔ 등급 자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)
  아킬레우스 (영웅, 신과 관련) = 번외 영웅 (4)
  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)
  보통 영웅 = 반신·신성 영웅
  운명 보스 = 신성·번외 재앙

상세: @COMBAT-UNIT-HERO
```

### 폐기 항목

```yaml
- 병종 5종 + 용병 (5-7 어휘):  5-9 어휘 정정
- 면 비율 = 시간대 (5-8):       5-9 정정
- 패시브 시스템 (5-7):          5-7 폐기. 5-9 흡수 X.
- 8 특성 시스템:                5-7 폐기
- 편성 시스템:                  5-7 폐기 (다른 세션)
- 태그 ([회유]/[징집]/[모집]):  5-7 폐기
- 추종자 합류 결:                5-7 폐기
- color 필드:                    색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:          대형 폐기 (4-26)
- 방진 패시브:                   5-5 폐기
- 행동 카드 / 모드 선언:        5-9 폐기
- 다이몬 결:                     5-9 폐기
- 1격사 결 (Nameless):           5-7 폐기. 5-9 모든 등급 hp 보유.
- 직업 종속 속도 (5-9 시도):     5-9 5패러미터 정정 (속도 별도 패러미터)
- 직업 4종 + B·D 펜딩 (5-9):     5-10 정정 (5종 어휘 박힘)
- 등급 종속 주사위 수 (5-9):     5-10 정정 (인물별)
- 무리 행동 = 1개 고정 (5-9 잠정): 5-10 정정 (인물별)
- 직업 5종 (5-10):                5-11 정정 (3종)
- 사제·수호자·용병 (5-10):        5-11 폐기 (신관으로 통합)
- 사제 방패 결산 부여 (5-10):    5-11 폐기 (사제 직업 폐기)
- 직업 = 면 비율 분화 (5-10):    5-11 폐기 (모든 인물 같음, 행동 양식+분배 결로)
- 사거리 5종 (5-10):              5-11 정정 (직업 결로 단순화)
- 인도 주사위 / 신성력 (5-10):   5-11 폐기 (의지 1종으로)
- 등급 = 인물별 (5-10):           5-11 정정 (등급 = 의지 주사위 수)
```
