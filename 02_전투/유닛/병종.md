# COMBAT-UNIT-NAMELESS: Nameless 병종

> 상태: **재설계 진행중 (5-8)** · 의존: @COMBAT-DICE-001, @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> ⚠️ 5-8 큰 정정 예정:
> - 어휘 "Nameless 병종" → "인간(Humans) 직업" + "무리(Horde) 종족" 이원화
> - 지상·경계 팩션 = 직업 (떠돌이/전사/궁수/도적/5종째 펜딩)
> - 미궁 팩션 = 종족 (어휘 + 종족 수 펜딩)
> - 면 비율 = 직업/종족 무관. 출신(미궁/지상/경계)별 시간대 비율로 정함
> - 패시브 (굳건/반격/선제/쇄도) → 직업/종족 행동 풀로 흡수
> - hp 도입 (1격사 폐기). 잠정 시드 펜딩
> - 본문은 5-5 결 그대로. 다음 세션에서 전면 재작성 예정.
> 상세: `DOCS/DESIGN/LOG/2026-05-08_전투4.0_재설계_시작.md`

## 정의

Nameless = 이름 없는 병종 단위. 같은 d6 + 4면 위에서 면 비율·공/방·패시브로 역할 분리. 차별화 3축: 면 비율, 공/방 스칼라, 병종 패시브.

## 규칙

### 병종 5종 + 용병

```yaml
민병:
  role: 통제 불능 소모품
  formation: editable_pool 제외
  appearance: 스테이지 합류 / [징집] 태그 등
  faces: { ⚔: 1, 🛡: 1, ✕: 4 }   # 의도된 신뢰성 부족
  atk_power: 1
  def_power: 1
  passive: 없음
  note: ✕ 비율 최고

보병:
  role: 전열의 안정
  formation: editable_pool 포함
  faces: { ⚔: 2, 🛡: 1, ✕: 3 }
  atk_power: 1
  def_power: 2
  passive: 굳건 — 라운드 시작 시 🛡합 +1

창병:
  role: 반격 특화
  formation: editable_pool 포함
  faces: { ⚔: 2, 🛡: 1, ✕: 3 }
  atk_power: 2
  def_power: 1
  passive: 반격 — 피해 받으면 ⚔ 1발 추가 굴림 (라운드당 1회)

궁병:
  role: 글래스 캐논 + 선제
  formation: editable_pool 포함
  faces: { ⚔: 3, 🛡: 0, ✕: 3 }
  atk_power: 2
  def_power: 0                    # 글래스 캐논
  passive: 선제 — 라운드 시작 전 ⚔ 1발 사전 굴림

기병:
  role: 쇄도 (★ 체이닝 강화)
  formation: editable_pool 제외 (스테이지 합류만)
  faces: { ⚔: 2, 🛡: 1, ✕: 3 }
  atk_power: 2
  def_power: 1
  passive: 쇄도 — ★ 발생 시 추가 ⚔ +1
  note: Nameless 기병은 ★ 면 없음 → 쇄도 자체 발동은 동급 Named와의 결로 (특성 시스템 펜딩)

용병:
  grade: DLC
  role: 유격
  formation: editable_pool (DLC 활성화 시)
  faces: { ⚔: 2, 🛡: 1, ✕: 3 }
  atk_power: 1
  def_power: 1
  passive: 자유선택 — 굳건/반격/선제/쇄도 중 1개 (전투 시작 시 선언)
```

### 편성 풀 규칙

```yaml
default: [보병, 창병, 궁병]
excluded: [민병, 기병]
exception:
  - 민병: 카드 시스템 합류 자리 (구체 결 펜딩 — 옛 [회유]/[징집]/추종자 등 모두 폐기)
  - 기병: 카드 시스템 합류 자리 (구체 결 펜딩)
note: 옛 편성 시스템 (@META-FORMATION-001) 폐기. 편성 결 다른 세션
```

### 폐기 항목

```yaml
- 방패병 병종:           보병 🛡으로 흡수 (4-26)
- color 필드:            색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:   대형 폐기 (4-26)
- 방진 패시브:           5-5 폐기. 보병 신규 패시브 = 굳건으로 대체
- 편성 시스템:           5-7 폐기 (다른 세션)
- 태그 ([회유]/[징집]/[모집]): 5-7 폐기 (태그 시스템 의존)
- 추종자 합류 결 (지원병/떠돌이/패잔병/기마병): 5-7 폐기 (추종자 재설계 대기)
```
