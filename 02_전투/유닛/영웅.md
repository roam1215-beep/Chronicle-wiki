# COMBAT-UNIT-HERO: Named 인물 (Named Figures)

> **상태:** 🔄 설계중 · **버전:** 1.6 · **ID:** COMBAT-UNIT-HERO · **수정일:** 2026-03-09

---

## ① 한 줄 요약

Named = 같은 병종 + 고유명 + ★. 기사는 Named 전용 병종으로 ⚔2🛡3★2✕3의 고유 면(유효면 7개)을 가진다. 기사는 O2에서 테오도라 전직 + 적/아군 NPC로 등장. O1 테오도라는 Named 보병/창병/궁병 선택제. 패시브는 병종별 기본 보유. 특성 8종 = Named 고유 성격 (용맹한/굳건한/신중한/예리한/현명한/고결한/은밀한/대담한). Named 1기당 1개 보유, "형용사 + 이름" 플레이버.

## ② 규칙 정의

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **Named 정의** | 같은 병종 + 고유명 + 유효면2→★2 |
| **★ 면** | Nameless의 유효면(⚔ 또는 🛡) 2개가 ★로 교체. ✕ 수는 동일. Named만 보유 |
| **부상 생존** | 피격 1회 시 유효면(⚔/🛡/★) 중 랜덤 1개→✕ 전환(부상). 2회 피격 시 사망 |
| **패시브** | 병종 패시브 기본 보유. 슬롯 최대 1개. 기사는 방진/반격/쇄도 중 랜덤 1 |
| **사망** | 테오도라 사망 = 게임오버 |
| **대형 선택** | **항상 산개(개별 굴림).** 밀집 불가. "이름 있는 자는 홀로 싸운다." → [COMBAT-STRUCT-001 전투 구조](../구조/전투구조.md) 대형 선택 참조 |

### Named 범용 d10 면 구성 (유효면2→★2)

| Named 유닛 | d10 면 구성 | 기반 병종 |
|-----------|------------|----------|
| Named 민병 | ⚔⚔🛡★★✕✕✕✕✕ | 민병 (⚔-1🛡-1→★2) |
| Named 보병 | ⚔🛡🛡🛡★★✕✕✕✕ | 보병 (⚔-2→★2) |
| Named 창병 | 🛡🛡🛡🛡★★✕✕✕✕ | 창병 (🛡-2→★2) |
| Named 궁병 | ⚔⚔⚔⚔★★✕✕✕✕ | 궁병 (⚔-2→★2) |
| Named 기병 | ⚔⚔🛡🛡★★✕✕✕✕ | 기병 (⚔-2→★2) |

> **범용 규칙:** 유효면(⚔ 또는 🛡) 2개 → ★2 교체. ✕ 수는 동일. 안정성을 폭발력으로 교환. 기사는 이 규칙의 예외 (아래 참조).

### 기사 — Named 전용 병종

| 필드 | 내용 |
|------|------|
| **정의** | Named 전용 병종. Nameless 기사는 존재하지 않음. O1에서는 적/동료 NPC만 기사로 등장. O2에서 테오도라 기사 전직 |
| **정체성** | "이름이 있는 자만이 기사다." 이름의 유무가 등급인 Chronicle에서, 기사는 이름을 가진 자의 병종 |
| **유효면 7개** | 기사는 유효면 7개(✕3)를 갖는다. 다른 Named의 유효면 6개(✕4)와 구별되는 기사의 특권 |
| **면 구성** | ⚔2 🛡3 ★2 ✕3 — 고유 면. Named 범용 규칙(유효면→★)과 별도 |
| **★ 2개** | 체이닝 특화. d6 시절 테오도라(★17%)보다 높은 ★20% |
| **패시브** | 기존 패시브 중 랜덤 1 기본 보유: **방진 / 반격 / 쇄도**. 선제 공격 제외 (기사가 활을 쏘지 않음 — 적 기사 포함) |
| **쇄도 시** | 쇄도 보유자 수에 포함. 기병과 함께 카운트 |

> **기사 패시브별 성격:**
> - **방진:** 수비형 기사. ⚔2를 🛡로 전환 → 🛡5까지. 결사 전까지 버틴다.
> - **반격:** 공격형 기사. 🛡3을 ⚔로 전환 → ⚔5 + ★2. 폭발력.
> - **쇄도:** 돌격 기사. 적 유효면 1개 확정 파괴. 기병과 시너지.

### 테오도라 [플레이어 Named]

| 필드 | 내용 |
|------|------|
| **O1** | Named 보병/창병/궁병 중 택 1. **첫 런은 Named 보병 고정.** Ch1 클리어=창병 해금, Ch2 클리어=궁병 해금 |
| **O2** | 기사로 전직. ⚔2🛡3★2✕3 고유면. 패시브 4종(방진/반격/쇄도/유격) 2택 1택 |
| **O1 면 구성** | 선택 병종의 Named 면. Named 보병=⚔1🛡3★2✕4, Named 창병=🛡4★2✕4, Named 궁병=⚔4★2✕4 |
| **O1 패시브** | 병종 따라감. 보병=방진, 창병=반격, 궁병=선제 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 유효면(⚔/🛡/★) 중 랜덤 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |
| **플레이버 (기록)** | 서자 출신의 지휘관. |
| **플레이버 (개인)** | (비움 — 특성이 채운다) |

> **기사 클래스는 O2에서 해금.** O1에서는 NPC 적/동료만 기사로 등장 가능. 기사 면/패시브 상세는 아래 기사 섹션 참조.

### Named 특성 시스템

Named에게는 특성이 1개 부여된다. "형용사 + 이름" 플레이버. 매 라운드 적용. 동일 특성 복수 Named 합산.

#### 특성 8종

| # | 이름 | 효과 | 구간/스텝 | 제한 |
|---|------|------|----------|------|
| 1 | 용맹한 | 격돌 ⚔+1 | 스텝7 합산 | 없음 |
| 2 | 굳건한 | 격돌 🛡+1 | 스텝7 합산 | 없음 |
| 3 | 신중한 | 선제 🛡+1 (방패병 추종자 동일 규칙: 선제 전용, 이월 안 됨, ★ 체이닝 첫 ⚔만 차단) | 스텝1 | 밤 불발 |
| 4 | 예리한 | 선제 ⚔+1 | 스텝1 | 궁병 전용, 밤 불발 |
| 5 | 현명한 | 리롤+1 (기본 1 + 추가 1 = 2회) | 스텝4 | 테오도라 부대 전용 |
| 6 | 고결한 | 본인의 해당 라운드 굴림 결과 ✕ 중 랜덤 1개 → ⚔/🛡 50:50 (★ 변환 불가). ✕ 0이면 불발 | 스텝5 (쇄도와 동시, 독립) | 없음 |
| 7 | 은밀한 | 격돌 ⚔+2 | 스텝7 합산 | **밤 전용, 낮 불발** |
| 8 | 대담한 | 격돌 ⚔+2 | 스텝7 합산 | **낮 전용, 밤 불발** |

> **플레이버 예시:** "용맹한 테오도라", "굳건한 롬", "은밀한 마르쿠스", "대담한 기욤" 등.

#### 공통 규칙

| 규칙 | 내용 |
|------|------|
| **적용 주기** | 매 라운드 (1회성 아님) |
| **합산** | 동일 특성 복수 Named → 합산 |
| **보정값 성격** | **확정 보정값.** 리롤 불가. 쇄도 불가. 방진/반격 전환 불가 |
| **보유 수** | Named 1기당 1개. 배정 후 런 내 변경/추가/제거 불가 |
| **부상 시** | 특성 유지. 면만 변경 |
| **사망 시** | 해당 라운드는 정상 적용, 다음 라운드부터 소멸 |
| **[난전]** | **선제 포함 전부 무력화.** 기본 리롤 1회만 잔존 |
| **[결투]** | **특성 불발동** |
| **결사(R5~)** | 🛡 보정값도 ⚔ 판정 (굳건한 🛡+1 → 실질 ⚔+1) |

#### 배정 규칙

| 대상 | 배정 시점 | 풀 | 제외 |
|------|----------|-----|------|
| 테오도라 (O1) | 런 시작 | **해금제.** 첫 런=용맹한 고정. Stage 클리어마다 순차 해금(신중한→예리한→현명한→고결한→은밀한→대담한→굳건한). 해금 후 자유 선택 | 예리한=궁병 선택 시에만 |
| 테오도라 부대 Named | 합류 시 | 8종 전체 | 병종 제약만 (예리한=궁병) |
| 동료 Named | Chapter 시작 | 7종 | 현명한 (테오도라 부대 전용) |
| 적 Named | 테이블 사전 포함 | 7종 | 현명한 (테오도라 부대 전용) |
| 방랑기사 합류 Named | 획득 시 | 8종 전체 | 병종 제약 후 배정 |
| [우세]/[열세] 임시 유닛 | — | — | **Nameless만 추가. 특성 해당 없음** |

#### 합산 방식

| 규칙 | 내용 |
|------|------|
| **합산 위치** | 진영 총합에 단순 합산 |
| **스텝7 판정** | 피해 = (상대 ⚔ 총합 + 상대 ⚔ 보정) - (내 🛡 총합 + 내 🛡 보정). 최소값 0 |
| **장창병(추종자) 관계** | 보정 ⚔는 뚫린 수 계산에 포함되나, 장창병 타겟 선택 수에는 불포함 |

#### 🛡 소모 순서

**보정값 🛡 가장 먼저 → 원래 🛡 → 방진 🛡 가장 나중.** 중보병(추종자) 이월 극대화.

> 선제 🛡 보정값(신중한/방패병) 소모: 적 선제 ⚔에 먼저 소모. 미소모 시 소멸 (이월 안 됨). 선제 보정값끼리는 순서 무관.

#### 엣지 케이스

| 상황 | 처리 |
|------|------|
| 결사 + 용맹한 | 정상 적용. 결사 ⚔ 판정과 별도로 ⚔+1 추가 |
| 결사 + 굳건한 | 🛡+1도 ⚔ 판정. 실질 ⚔+1 |
| 결사 + 고결한 | ✕→🛡도 ⚔ 판정. 실질 ✕→⚔ 확정. 가치 상승 |
| 밤 + 은밀한 | 발동. 밤 전용 |
| 낮 + 대담한 | 발동. 낮 전용 |
| 밤 + 대담한 | 불발. 낮 전용 |
| 낮 + 은밀한 | 불발. 밤 전용 |
| 은밀한 + 대담한(별개 Named) | 동시 보유 가능. 낮에는 대담한만, 밤에는 은밀한만 발동. 동시 발동 불가 |
| 밤 + 신중한/예리한 | 불발. 선제 스킵 |
| 밤 + 은밀한 + 용맹한(별개 Named) | 진영 합산 ⚔+3. 정상 |
| [난전] + 현명한 | 현명한 무력화. 기본 리롤 1회만 잔존 |
| [난전] + 결사 + 밤 | 극한 상황. 기본 리롤 1회뿐. 의도된 설계 |
| 예리한 + 장궁병(추종자) | 보너스 ⚔+1은 아군 선사격에 랜덤 타겟으로 적용. 타겟 선택 수에 불포함 |
| 신중한 + 방패병(추종자) | 합산 🛡+2. 보정값끼리 순서 무관. 자동 |
| 현명한 + 정찰병(추종자) + 밤 | 리롤 2~3회 + 적 정보 공개. 밤 페널티 대폭 감소. 의도된 빌드 보상 |
| 고결한 + 종자/사제 | 레이어 다름 (전투 결과면 vs 구성면). 간섭 없음. ✕ 풀 축소로 약한 안티시너지 |
| 고결한 + 부상 Named | 부상으로 ✕ 증가 → 고결한 발동 확률 상승. 부상 약화 부분 보상 |
| 선제에서 Named 사망 | 해당 라운드 선제 보정 유효 (화살은 날아감). 격돌부터 소멸 |
| 동료 Named 사망 | 특성 다음 라운드 소멸. 진영 합산값 변동 |

  Named 창병:  🛡 🛡 🛡 🛡 ★ ★ ✕ ✕ ✕ ✕   ★20%
  Named 궁병:  ⚔ ⚔ ⚔ ⚔ ★ ★ ✕ ✕ ✕ ✕   ★20%

좌상단에 d10 배지 + 이름 + 병종 + 플레이버. 중앙에 일러스트(최소 160px). 하단에 패시브(이름+설명) → 다이스 면(5+5). 패시브는 민병 외 항상 표시. 특성은 "형용사 + 이름"으로 이름 영역에 표시.

## ④ 설계 근거

**Q. 왜 기사가 Named 전용인가?**
"이름 없는 기사"는 그냥 병사다. Chronicle의 핵심 문법 "이름의 유무가 곧 등급"에서, 기사는 이름을 가진 자만의 병종. Nameless 기사는 모순.

**Q. 왜 기사 면이 범용 규칙(유효면→★)과 다른가?**
⚔2🛡3★2✕3은 기존 5병종 어디에도 대응이 안 됨. "유효면→★"이 아니라 독립 면을 가진 6번째 병종. 예외가 아니라 독립 규칙.

**Q. 왜 Named 전원 ★2인가?**
Named = 유효면 2개를 ★로 교환. 안정성을 폭발력으로 바꾼다. ✕ 수는 동일하므로 실패율은 같되 체이닝으로 기대값 상승. "이름의 무게"가 곧 체이닝.
**Q. 왜 기사 패시브가 기존 풀(방진/반격/쇄도)에서 랜덤인가?**
새 패시브를 만들면 밸런스 비용 추가. 기존 패시브를 재활용하되 "어떤 것이 걸릴지 모른다"가 로그라이크의 빌드 다양성. 같은 기사인데 방진 기사 / 반격 기사 / 쇄도 기사로 성격이 달라짐.

**Q. 왜 선제 공격이 기사 패시브 풀에서 제외되나?**
기사가 활을 쏘는 건 서사에 안 맞음. 또한 선제 참여 시 격돌에서 빠지므로 ★2 체이닝이라는 기사의 핵심 강점을 격돌에서 쓸 수 없게 됨.

**Q. 왜 O1 테오도라가 기사가 아닌가?**
O1은 입문. 보병/창병/궁병 선택제가 3병종의 패시브(방진/반격/선제)를 체험하게 한다. 기사의 고유 면(⚔2🛡3★2✕3)과 랜덤 패시브는 3병종을 모두 이해한 후에야 의미가 있다. O2 전직이 "서자가 기사가 되는" 서사 보상.

**Q. 왜 기사 클래스가 존재하는가?**
⚔2🛡3★2✕3은 기존 5병종 어디에도 대응이 안 됨. "유효면→★"이 아니라 독립 면을 가진 6번째 병종. 예외가 아니라 독립 규칙.
