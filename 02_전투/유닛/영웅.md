# COMBAT-UNIT-HERO: Named 인물

> 상태: 결정정합 · 의존: @COMBAT-UNIT-CARD, @COMBAT-DICE-001, @COMBAT-STRUCT-001, @META-FOLLOWER

## 정의

Named = 같은 병종 + 고유명 + ★ 면 보유 + 특성 1개. 이름 유무가 등급. Named 사망 = 영구 손실. 테오도라 사망 = 게임 오버.

## 규칙

### Named 공통

```yaml
grade: named | knight
unique_name: 고유명 (예: 테오도라)
base_class: 병종 (보병/창병/궁병/기사 등)
star_face: 보유
faces: { ⚔: 1, 🛡: 1, ★: 1, ✕: 3 }   # Named 공통 잠정 시드
injury: 2단계 (정상 → 부상 → 사망) (@COMBAT-JUDGE-001)
trait: 1개 (8종 중)
atk_power: 카드별
def_power: 카드별
passive: 병종 따라감 (@COMBAT-STRUCT-001 패시브 시스템)
loss: 영구 (퍼마데스)
```

### 8 특성

```yaml
용맹한: 라운드 시작 시 ⚔합 +1
굳건한: 라운드 시작 시 🛡합 +1
신중한: 1라운드차에 ⚔ +1, 🛡 +1
예리한: ⚔ +1 추가 (랜덤 타겟). 궁병 전용
현명한: 리롤 1회 추가 (라운드당). 플레이어 진영 전용 (@COMBAT-ACT-002)
고결한: 부상 → 사망 진행 1회 무효 (런당 1회 사용)
은밀한: ⚔ +2 (랜덤 타겟)
대담한: ★ +1 추가 (★ 정의에 의해 ⚔합 +1)

unlock:
  base: 용맹한 (첫 런 고정)
  per_stage_clear: [신중한, 예리한, 현명한, 고결한, 은밀한, 대담한, 굳건한]
```

### 테오도라

  first_run: 보병 고정
  unlock:
    chapter_1_clear: 창병
    chapter_2_clear: 궁병
trait:
  first_run: 용맹한
  subsequent: 해금된 풀에서 자유 선택

```

```

### 폐기 항목

```yaml
- color 필드:                       색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:              대형 폐기 (4-26)
- '고결한' 산개/밀집 의존 효과:     5-5 재정의 (생존 보강)
- '신중한' 선제 페이즈 의존:        5-5 재정의 (1라운드차 ⚔🛡 +1)
- ★ 체이닝:                         5-5 폐기 (다이스규칙 참조)
```
