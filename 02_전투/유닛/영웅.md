# 영웅·재앙 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 라운드 안 결단, 다이시 테일즈식, 광역 사거리, 등극 결 펜딩
> 정정: 4축 결, 자동 매커니즘, Order 클리어 시 등극

---

## 정의

```yaml
영웅·재앙 = 신적 결의 자리 (위계 4종 중 고위계)
  영웅 = 인간 등극 자리 (지상·경계 인간 종족)
  재앙 = 무리 등극 자리 (미궁·경계 무리 종족)

위계와 등급 분리:
  위계 = 작품 결 (인간/영웅/무리/재앙, Order 클리어 시 변동)
  등급 = 내부 결 (필멸/반신/신성/번외, 챕터 클리어 시 변동)
  
  → 등급 = 의지 주사위 수 (1/2/3/4+) + 가호 수 (0/1/2/3)
  → 위계 = 가호 폭만 (저 폭 / 고 폭)

태생 ↔ 종족 ↔ 위계 정합:
  인간 종족: 한낮 또는 여명 태생 → 인간 ↔ 영웅
  무리 종족: 심야 또는 황혼 태생 → 무리 ↔ 재앙
  교차 X (인간 → 재앙 X / 무리 → 영웅 X)

사망: 영구 손실 (퍼마데스, 모든 위계·등급)
```

---

## 위계 4종

### 영웅 (Heroes)

```yaml
출신:        지상·경계 인간 종족
태생:        한낮 (지상) 또는 여명 (경계)
가호 폭:     고 폭 (저위계 인간 → 등극 시 폭 큼)
의지 주사위: 등급 결 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
가호 수:     등급 결 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
사망:        게임 오버 (테오도라 결 — 작품 주연인 경우)
            또는 영구 손실 (작품 조연 영웅)
결의 결:     카타스테리스모스 (별이 됨)
```

### 재앙 (Calamity)

```yaml
출신:        미궁·경계 무리 종족
태생:        심야 (미궁) 또는 황혼 (경계)
가호 폭:     고 폭
의지 주사위: 등급 결
가호 수:     등급 결
사망:        멸절 (적 진영이라 영구 손실)
결의 결:     신적 적대 자리 (라키아의 사자 결)
```

### 인간 (Humans, 저위계)

```yaml
출신:        지상·경계 인간 종족
태생:        한낮 또는 여명
가호 폭:     저 폭
등극 자리:   Order 클리어 시 → 영웅
            (단 모든 인간이 등극 X, 작가 결로 미리 정해진 인물만)
사망:        영구 손실
```

### 무리 (Beasts, 저위계)

```yaml
출신:        미궁·경계 무리 종족
태생:        심야 또는 황혼
가호 폭:     저 폭
등극 자리:   Order 클리어 시 → 재앙
            (작가 결로 미리 정한 인물만)
사망:        영구 손실
```

## 등극 결 (Order 클리어 시)

```yaml
시점:        Order 클리어 시 (카타스테리스모스 결)
자리:        미리 정한 인물 1명에 등극 박힘
             (작가 결로 Order 시작 시 박혀 있음)

변동:
  인간 → 영웅 (가호 폭 큼)
  무리 → 재앙 (가호 폭 큼)
  
태생 = 변동 X (한낮 인간 → 한낮 영웅)
등급 = 별도 결 (챕터 클리어 시 변동)

결의 결:
  "신성 X → 신적 결로 승천"
  본인 결: "위계는 인간이, 무리가 신성 없는 존재에서
          신적인 존재로 승천하는 것을 의미"
  
작품 결:
  카타스테리스모스 = 별이 됨 (그리스 결)
  Order 클리어 = 작품의 큰 마디 끝
  영웅 등극 = 그 자리의 결정적 결
```

---

## 등급 결 (챕터 클리어 시)

```yaml
변동:        필멸 → 반신 → 신성 → 번외
시점:        챕터 클리어 시

박는 결:
  의지 주사위 수 +1 (1 → 2 → 3 → 4)
  가호 수 +1 (0 → 1 → 2 → 3)
  → 한 박자에 둘 다

내부 결 (게임 노출 X):
  등급 자체는 안 보임
  가호 결로 체감 (가호 수 늘어남)
```

---

## 가호 결 (5-12 후속 마감)

```yaml
가호 수 = 등급:
  필멸 0 (가호 X)
  반신 1
  신성 2
  번외 3

가호 폭 = 위계:
  저위계 (인간·무리) = 작은 폭
  고위계 (영웅·재앙) = 큰 폭

가호 유형 = 태생 직접 정합:
  한낮 태생 = 한낮 가호 (지상 인간)
  여명 태생 = 여명 가호 (경계 인간)
  황혼 태생 = 황혼 가호 (경계 무리)
  심야 태생 = 심야 가호 (미궁 무리)

가호 영역 (광역):
  - 기본 스탯 +N (시작 시)
  - 대성공 시 스탯 +N
  - 라운드 기반 조건부
  - 열 기반 조건부
  - 공격·피격 기반 조건부

지속:
  가호 = 영구
  대성공 행동 효과 = 1 라운드만

상세: 02_전투/유닛/인물카드규칙.md 참조
```

## 행동 결

```yaml
유저 결단:
  매 라운드 명령 시 = 배치 자유 변경
  편성 = 폐기 (파티 한 번 정해지면 쭉)
  라운드 안 결단 X

영웅·반신·필멸 차별:
  시스템 결로는 가호 결만 (수 + 폭)
  라운드 안 결단 X (모든 인물 자동 매커니즘)
  
  본인 결: "영웅이고 반신이고 필멸이고 그냥 다 역할군에 따른 배치만 신경쓰면 되게 바뀐거"

직업 자동 매커니즘:
  전사 / 돌격 / 격파
  수호자 / 방어 / 수호
  사냥꾼 / 사격 / 저격
  사제 (지상) / 축복 / 축성
  사제 (미궁) / 저주 / 펜딩
  
상세: 02_전투/유닛/직업종족.md 참조
```

## 폐기 자리 (5-12 후속)

```yaml
✗ "영웅·반신 라운드 1회 결단" (호메로스 결의 내부 자리)
  → 모든 인물 자동 매커니즘

✗ "다이시 테일즈식 (면 종류 → 행동 풀)"
  → 하스스톤 전장식 결산 (공격력 = 상대 hp 직격)

✗ "광역 사거리 인물 카드 결"
  → 사냥꾼 = 자기 위치 가장 먼 적 (열 기준)

✗ 등극 결 펜딩
  → Order 클리어 시 = 미리 정한 인물 등극 (작가 결)

✗ "운명 전투 클리어 = 미리 정한 인물에 신성 박힘"
  → 정정: 운명 전투 ≠ 등극 결.
          등극 = Order 클리어 시.
          등급 변동 = 챕터 클리어 시.

✗ "1챕터 1스테이지 테오도라 = 인간 분류" 결
  → 정정: 위계 = Order 클리어 시 변동.
          첫 챕터 시작 = 인간 위계 / 필멸 등급.
          첫 챕터 클리어 = 인간 위계 / 반신 등급.
          ...
          Order 1 클리어 = 영웅 위계 (선정된 경우)

✗ 광역 사거리 = 인물 카드 결로 박힘
  → 광역 = 행동 대성공의 결과물만 (격파 결)
```

## 펜딩

```yaml
- 등극 인물 선정 결의 자리 (작가 결, 다음 마디)
- 영웅 주연 결 (테오도라 = 게임 오버 결)
  → 작품 결로만, 시스템 결로는 hp 결만
- Order 1의 등극 인물 = 테오도라 (운명 정합)
```
