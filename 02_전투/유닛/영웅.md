# COMBAT-UNIT-HERO: Named 인물 (Named Figures)

> **상태:** 🔄 설계중 · **버전:** 1.0 · **ID:** COMBAT-UNIT-HERO · **수정일:** 2026-03-02

---

## ① 한 줄 요약

Named = 같은 병종 + 고유명 + ★. Nameless의 ✕ 1개가 ★로 바뀌며, 2단계 부상 체계를 가진다. 테오도라(창병 계열)가 유일한 플레이어 Named. 패시브는 스테이지 보상으로, 업적 카드는 Chapter 전환 시 획득.

## ② 규칙 정의

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **Named 정의** | 같은 병종 + 고유명 + ✕→★ |
| **★ 면** | Nameless의 ✕ 1개가 ★로 교체. Named만 보유 |
| **병종명** | 변환 없음. Named 보병은 "보병"이고 고유명이 따로 있다 |
| **구 명칭** | 용병/기병(보병 Named)/기사/석궁병 등은 폐기 |
| **부상 생존** | 피격 1회 시 면 1개→✕로 전환(부상). 2회 피격 시 사망 |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개. 전부 스테이지 보상으로 획득 |
| **패시브 슬롯** | 최대 1개 (병종 고정) |
| **사망** | 테오도라 사망 = 게임오버 |

### Named d10 면 구성

| Named 유닛 | d10 면 구성 | 기반 병종 |
|-----------|------------|----------|
| Named 민병 | ⚔⚔⚔🛡🛡★✕✕✕✕ | 민병 (✕→★) |
| Named 보병 | ⚔⚔⚔🛡🛡🛡★✕✕✕ | 보병 (✕→★) |
| Named 창병 | 🛡🛡🛡🛡🛡🛡★✕✕✕ | 창병 (✕→★) |
| Named 궁병 | ⚔⚔⚔⚔⚔⚔★✕✕✕ | 궁병 (✕→★) |
| Named 기병 | ⚔⚔⚔⚔🛡🛡★✕✕✕ | 기병 (✕→★) |

> **단일 규칙:** 어떤 병종이든 ✕ 1개→★ 교체로 Named화. 병종별 별도 면 설계 불필요.

### 테오도라 — 창병 계열 [유일한 플레이어 Named]

| 필드 | 내용 |
|------|------|
| **명칭** | 테오도라 (고유명) / 창병 계열 |
| **면 구성** | ⚠️ d10 면 미확정 — Named 창병(🛡6★1✕3) 기반, 영웅 고유 면 검토 필요 |
| **참여** | 본 라운드에 굴림 |
| **패시브 (초기)** | 없음. 미획득 |
| **병종 패시브** | 반격 — 🛡 결과를 ⚔로 전환할 수 있다 (스텝6). 스테이지 보상으로 획득 |
| **전환** | 🛡→⚔ 일방향 (창병 계열). 반격 패시브 획득 시 사용 가능 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 🛡 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |

### 업적 카드 시스템

| 필드 | 내용 |
|------|------|
| **정체** | 테오도라 전용 성장 시스템. 패시브와 별도 영역 |
| **획득 시점** | Chapter 전환 시 (런당 2회: Chapter 1→2, Chapter 2→3) |
| **선택 방식** | 3종 업적 카드 제시 → 플레이어 택 1 |
| **정보 비대칭** | 다음 Chapter 내용을 모르는 상태에서 선택 |
| **카드 영역** | 기존 패시브 슬롯과 분리된 별도 영역 |
| **런당 최대** | 2장 (Chapter 1→2 전환, Chapter 2→3 전환) |

> **업적 카드 풀 구체 내용은 미정.** 패시브 계열이지만 기존 병종 패시브(반격/방진/선제공격/쇄도)와는 별도 체계.

## ⑥ 설계 근거

**Q. 왜 Named가 테오도라 1기뿐인가?**
승급(Nameless→Named) 시스템 폐기. 1인 개발 데모에서 승급 처리 비용이 과대. 테오도라만 패시브/업적으로 성장하는 구조가 깔끔.

**Q. 왜 Named = 같은 병종 + 고유명인가?**
구 체계(보병→기병, 창병→기사 등)는 병종 확장 시 Named 명칭도 별도 설계 필요. ✕→★ 단일 규칙이면 어떤 병종이든 Named화 가능. 기병 추가 시에도 "Named 기병"으로 바로 적용.

**Q. 왜 테오도라가 창병 계열인가?**
보병 계열(⚔→🛡)이면 테오도라가 수비적. 서자 기사라는 서사와 맞지 않음. 창병 계열(🛡→⚔)은 기본 방어가 탄탄하되 필요 시 공격 전환 가능 — "증명해야 하는 기사"에 적합.

**Q. 왜 패시브가 초기 비어있나?**
"겪은 것이 능력이 된다." 테오도라도 런 시작 시에는 아무 능력 없이 ★ + 부상 생존만 가진다.

**Q. 왜 업적 카드가 패시브와 분리되나?**
패시브는 병종 기반(반격 등)이고 스테이지 보상으로 획득. 업적은 Chapter 전환 보상이며 다른 계열. 두 성장 축이 분리되어야 빌드 다양성 확보.

**Q. 왜 업적 카드를 다음 Chapter 내용 모르고 고르나?**
의도된 정보 비대칭. "닥친 상황에 적응"하는 핵심 경험과 일치.
