# COMBAT-UNIT-HERO: Named 인물 (Named Figures)

> **상태:** 🔄 설계중 · **버전:** 0.6 · **ID:** COMBAT-UNIT-HERO · **수정일:** 2026-02-28

---

## ① 한 줄 요약

테오도라(기사, 창병 계열)는 유일한 시작 Named. 추가 Named는 Nameless 승급으로만 등장한다. Named는 ★ 면과 2단계 부상 체계를 가지며, 패시브는 스테이지 보상으로 획득한다.

---

## ② 규칙 정의

### 테오도라 — 기사 (창병 계열) [시작 Named]

| 필드 | 내용 |
|------|------|
| **명칭** | 테오도라 / 기사 |
| **면 구성** | ★ ⚔ 🛡 🛡 ✕ ✕ |
| **참여** | 본 라운드에 굴림 |
| **패시브 (초기)** | 없음. 빈 슬롯 3개 |
| **병종 패시브** | 반격 — 🛡 결과를 ⚔로 전환할 수 있다 (스텝6). 스테이지 보상으로 획득 |
| **전환** | 🛡→⚔ 일방향 (창병 계열). 반격 패시브 획득 시 사용 가능 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 🛡 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |

### Named 승급 — Nameless → Named 전환

| 필드 | 내용 |
|------|------|
| **조건** | 스테이지 운명 달성 보상 |
| **변경** | ✕ 1개 → ★ 교체 + 부상 생존 획득 + 고유 이름 부여 |
| **병종 유지** | 원래 Nameless의 병종을 유지 (궁병→석궁병, 창병→기사, 보병→기병, 민병→용병) |
| **이름 풀** | 병종별 Named 이름 풀에서 배정 |
| **사망** | 영구 손실 (퍼마데스). 게임오버 아님 (테오도라만 게임오버) |

### Named 승급 면 구성

| 원본 (Nameless) | 승급 후 (Named) | 병종명 |
|-----------------|-----------------|--------|
| 보병 ⚔⚔🛡🛡✕✕ | ⚔⚔🛡🛡✕★ | 기병 |
| 창병 🛡🛡🛡🛡✕✕ | 🛡🛡🛡🛡✕★ | 기사 |
| 궁병 ⚔⚔⚔⚔✕✕ | ⚔⚔⚔★✕✕ | 석궁병 |
| 민병 ⚔⚔🛡✕✕✕ | ⚔⚔🛡✕✕★ | 용병 |

> **궁병 승급 이름 풀에 앰버 포함.** 앰버는 편성 시 시작 Named가 아니라 궁병 승급 시 등장하는 이름/일러스트로 존재.

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | Named만 보유. Nameless는 ★ 없음 |
| **부상 생존** | 피격 1회 시 면 1개→✕로 전환(부상). 2회 피격 시 사망 |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개. 전부 스테이지 보상으로 획득 |
| **패시브 슬롯** | 최대 3개 |
| **사망 차등** | 테오도라 사망 = 게임오버. 그 외 Named 사망 = 영구 손실 (런 계속) |

### Named 부상 체계

```
테오도라 (시작 Named):
  정상:  ★ ⚔ 🛡 🛡 ✕ ✕
           ↓ 피해 뚫림
  부상:  ★ ⚔ 🛡  ✕  ✕ ✕   (🛡→✕)
           ↓ 피해 뚫림
  사망:  게임오버

승급 Named 궁병 (석궁병):
  정상:  ⚔ ⚔ ⚔ ★ ✕ ✕
           ↓ 피해 뚫림
  부상:  ⚔ ⚔  ✕  ★ ✕ ✕   (⚔→✕)
           ↓ 피해 뚫림
  사망:  영구 손실
```

### Named vs Nameless 비교

```
테오도라 (Named 기사):  ★ ⚔ 🛡 🛡 ✕ ✕   부상 생존, 패시브 슬롯 3
창병대 (Nameless):      🛡 🛡 🛡 🛡 ✕ ✕   즉사, 패시브 슬롯 3

석궁병 (Named 궁병):    ⚔ ⚔ ⚔ ★ ✕ ✕   부상 생존, 패시브 슬롯 3
궁병대 (Nameless):      ⚔ ⚔ ⚔ ⚔ ✕ ✕   즉사, 패시브 슬롯 3
```

## ⑥ 설계 근거

**Q. 왜 시작 Named가 테오도라 1기뿐인가?**
편성 비용 최소화. 사이드킥(앰버)을 시작 Named에 넣으면 사망 시 Order 간 처리 비용이 크다. 1인 개발 데모에서 감당 불가. 앰버는 궁병 승급 이름 풀로 이동 — 서사적 존재감 유지, 편성 비용 제거.

**Q. 왜 테오도라가 보병에서 기사(창병 계열)로 변경되었나?**
보병 계열(⚔→🛡)이면 테오도라가 수비적. 서자 기사라는 서사와 맞지 않음. 창병 계열(🛡→⚔)은 기본 방어가 탄탄하되 필요 시 공격 전환 가능 — "증명해야 하는 기사"에 적합.

**Q. T2 병종과 Named는 무슨 관계인가?**
Named 승급 시 T2 병종명을 획득한다. Nameless 보병 → Named 기병, Nameless 창병 → Named 기사, Nameless 궁병 → Named 석궁병, Nameless 민병 → Named 용병. T2는 별도 티어가 아니라 Named의 병종명이다.

**Q. 왜 패시브가 초기 비어있나?**
"겪은 것이 능력이 된다." 테오도라도 런 시작 시에는 아무 능력 없이 ★ + 부상 생존만 가진다. 패시브는 스테이지를 겪으며 채운다.
