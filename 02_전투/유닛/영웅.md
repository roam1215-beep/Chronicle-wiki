# COMBAT-UNIT-HERO: 영웅·재앙

> 상태: 결정정합 (5-9 코어 박힘) · 의존: @COMBAT-UNIT-CARD, @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE

> 5-9 정정:
> - 어휘 정정: Named 인물 (5-7) → 영웅·재앙 4등급 (5-8) → 5-9 두 축 박힘
> - 등급 = 행동 주사위 수 + 신성 주사위 수 두 축
> - 신성 = 영웅·재앙만 보유. 무리·인간 = 신성 0.
> - 8 특성 폐기 (5-7) → 행동 주사위 분화 5종으로 흡수 (@COMBAT-UNIT-JOBRACE)
> - 패시브 시스템 (5-7) 폐기 → 5-9 자동 결로 폐기
> - hp 도입 (1격사 폐기). 잠정 시드 펜딩.
> - 영웅 사망 = 게임 오버 / 재앙 사망 = 운명 클리어 (5-8 결 살아남)
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의

영웅·재앙 = 신성 받는 등급. 행동 주사위 + 신성 주사위 둘 다 굴림. 가호 1택으로 응대 자리 박힘. 영웅 = 인간 상위 (지상·경계). 재앙 = 무리 상위 (미궁). 사망 = 영구 손실.

## 규칙

### 등급 = 두 축

```yaml
행동 주사위 수 = 인간 역량
신성 주사위 수 = 신성 깊이

영웅 (Heroes):
  팩션:        지상·경계
  행동:        N개 (잠정. 시드 펜딩)
  신성:        N개 (시작 시드 펜딩 + 덕목 누적)
  hp:          큼
  사망:        게임 오버 (테오도라 결)
  결:          카타스테리스모스 (별이 됨)

재앙 (Calamity):
  팩션:        미궁
  행동:        N개
  신성:        N개
  hp:          큼
  사망:        운명 전투 클리어 + 영웅에 덕목 박힘
  결:          멸절

인간 (Humans):
  팩션:        지상·경계
  행동:        N개 (영웅보다 적음)
  신성:        0 (신성 X)
  hp:          보통
  사망:        영구 손실 (퍼마데스)
  결:          정예. 수 적음.

무리 (Horde):
  팩션:        미궁
  행동:        1개
  신성:        0
  hp:          작음
  사망:        영구 손실
  결:          떼. 수 많음.
```

### 신성 주사위 풀

```yaml
영웅 (지상):    낮3 / 별1 / 밤2 (자기 시간대 = 낮)
재앙 (미궁):    밤3 / 별1 / 낮2 (자기 시간대 = 밤)
영웅 (경계):    펜딩 (균등? 결 변동? — 다음 마디)

별 면:          무조건 가호 + 신성 주사위 재굴림 (무한)
가호 박힘:      신성 면 = 페이즈 시간대 일치 + 자기 신앙 일치 시
실패:           반대 시간대 = 그저 무 (호메로스 결, 적 해코지 X)

상세: @COMBAT-DICE-001
```

### 가호 결산

```yaml
플레이어 = 박힌 가호를 *공 또는 방* 1택. 동시 선언 (정보 비대칭 보존).
점수 = 가호 1개당 인물 공·방 수치만큼 (공으로 끌었을 시 공격력, 방으로 끌었을 시 방어력)

결의 결:
  영웅이 강할수록 가호 결도 강함
  카타스테리스모스 정합 (영웅 = 자기 결로 별이 됨)
  
플레이어 시점:
  신적 (아테나 결)
  영웅 = 자기 결로 행동 (자동)
  플레이어 = 가호의 결을 *어디로 끌지* 정함

상세: @COMBAT-STRUCT-001
```

### 폐기 항목

```yaml
- color 필드:                    색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:           대형 폐기 (4-26)
- '고결한' 산개/밀집 의존 효과:  5-5 재정의 시도 (특성 풀)
- '신중한' 선제 페이즈 의존:     5-5 재정의 시도
- ★ 체이닝 (5-5 결):             5-5 폐기 → 5-9 별 면 재굴림 결로 부활
- 8 특성 시스템:                 5-7 폐기 (전면 재설계)
                                  옛 결: Named 1기당 1개. 매 라운드 적용.
                                  5-9 흡수 X. 행동 주사위 분화 5종으로 차별화.
- 특성 풀 unlock per_stage_clear: 5-7 폐기
- Named 어휘:                    5-8 정정 (영웅·재앙)
- 면 = ⚔/🛡/★/✕ (5-7):           5-9 정정 (행동 칼/방패/실패 + 신성 시간대/별)
- Named ★ 면 1개 (5-7):           5-9 정정 (영웅 = 신성 주사위 별 면 보유)
- 패시브 시스템 (5-7):            5-9 폐기 (자동 결로 흡수 X)
- 1격사 결 (Nameless):            5-7 폐기. 모든 등급 hp 보유.
- 카드별 atk_power/def_power:    5-9 정정 (인물별 속성으로)
- 다이몬 결:                      5-9 폐기 (시너지·공유 효과 — 영영 안 박힐 수도)
```
