# COMBAT-UNIT-HERO: Named 인물 (Named Figures)

> **상태:** 🔄 설계중 · **버전:** 0.3 · **ID:** COMBAT-UNIT-HERO · **수정일:** 2026-02-27

---

## ① 한 줄 요약

테오도라(기사, 창병 계열)와 앰버(궁병). Named 인물은 ★ 면과 2단계 부상 체계를 가지며, 패시브는 스테이지 보상으로 획득한다.

---

## ② 규칙 정의

### 테오도라 — 기사 (창병 계열)

| 필드 | 내용 |
|------|------|
| **명칭** | 테오도라 / 기사 |
| **면 구성** | ★ ⚔ 🛡 🛡 ✕ ✕ |
| **참여** | 본 라운드에 굴림 |
| **패시브 (초기)** | 없음. 빈 슬롯 3개 |
| **병종 패시브** | 반격 — 피격 시 ⚔ 1을 되돌린다. 스테이지 보상으로 획득 |
| **전환** | 🛡→⚔ 일방향 (창병 계열). "반격" 패시브 텍스트로 표현 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 🛡 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |

### 앰버 — 궁병

| 필드 | 내용 |
|------|------|
| **명칭** | 앰버 / 궁병 |
| **면 구성** | ⚔ ⚔ ⚔ ★ ✕ ✕ |
| **참여** | 선제 페이즈에서 사격 (낮). 밤에는 본 라운드 합류 |
| **패시브 (초기)** | 없음. 빈 슬롯 3개 |
| **병종 패시브** | 선제 공격 — 선제 페이즈에서 사격한다. 스테이지 보상으로 획득 |
| **전환** | 없음 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림 |
| **부상** | 피격 시 ⚔ 1개 → ✕. 부상 상태에서 재피격 = 사망 = 영구 손실 (퍼마데스) |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | Named만 보유. Nameless는 ★ 없음 |
| **부상 생존** | 피격 1회 시 면 1개→✕로 전환(부상). 2회 피격 시 사망 |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개. 전부 스테이지 보상으로 획득 |
| **패시브 슬롯** | 최대 3개 |

```
  부상:  ★ ⚔ 🛡  ✕  ✕ ✕   (🛡→✕)
           ↓ 피해 뚫림
  사망:  게임오버

앰버:
  정상:  ⚔ ⚔ ⚔ ★ ✕ ✕
           ↓ 피해 뚫림
  부상:  ⚔ ⚔  ✕  ★ ✕ ✕   (⚔→✕)
           ↓ 피해 뚫림
  사망:  영구 손실
```

### Named vs Nameless(T1) 비교

```
테오도라 (Named 기사):  ★ ⚔ 🛡 🛡 ✕ ✕   부상 생존, 패시브 슬롯 3
창병대 (Nameless):      🛡 🛡 🛡 🛡 ✕ ✕   즉사, 패시브 슬롯 3

앰버 (Named 궁병):      ⚔ ⚔ ⚔ ★ ✕ ✕   부상 생존, 패시브 슬롯 3
궁병대 (Nameless):      ⚔ ⚔ ⚔ ⚔ ✕ ✕   즉사, 패시브 슬롯 3
```

## ⑥ 설계 근거

**Q. 왜 테오도라가 보병에서 기사(창병 계열)로 변경되었나?**
보병 계열(⚔→🛡)이면 테오도라가 수비적. 서자 기사라는 서사와 맞지 않음. 창병 계열(🛡→⚔)은 기본 방어가 탄탄하되 필요 시 공격 전환 가능 — "증명해야 하는 기사"에 적합.

**Q. T2 병종과 Named는 무슨 관계인가?**
Named 승급 시 T2 병종명을 획득한다. Nameless 보병 → Named 기병, Nameless 창병 → Named 기사, Nameless 궁병 → Named 석궁병, Nameless 민병 → Named 용병. T2는 별도 티어가 아니라 Named의 병종명이다.

**Q. 왜 패시브가 초기 비어있나?**
"겪은 것이 능력이 된다." 테오도라와 앰버도 런 시작 시에는 아무 능력 없이 ★ + 부상 생존만 가진다. 패시브는 스테이지를 겪으며 채운다.

**Q. 앰버 면 구성(⚔⚔⚔★✕✕)이 석궁병(Named 궁병)과 같은데?**
의도적. Named는 Nameless보다 강해야 한다. 앰버는 ★ + 부상 생존 + 패시브 슬롯으로 차별화. 일반 Named 석궁병은 이름을 얻은 궁병.
