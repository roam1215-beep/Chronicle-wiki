# COMBAT-UNIT-HERO: Named 인물

> 상태: 설계중 · 의존: @COMBAT-UNIT-CARD, @COMBAT-DICE-001, @META-FOLLOWER

## 정의

Named = 같은 병종 + 고유명 + ★ 면 보유 + 특성 1개. 이름의 유무가 등급. Named 사망 = 영구 손실. 테오도라 사망 = 게임 오버.

## 규칙

### Named 공통

```yaml
named:
  grade: named | knight
  unique_name: 고유명 (예: 테오도라)
  base_class: 병종 (보병/창병/궁병/기사 등)
  star_face: 보유 (수량 TODO)
  injury: 2단계 (정상 → 부상 → 사망)  # @COMBAT-JUDGE-001
  trait: 1개 (8종 중)
  atk_power: TODO(밸런스)
  def_power: TODO(밸런스)
  passive: 병종 따라감 (TODO 시스템 정합)
  loss: 영구 (퍼마데스)
```

### 8 특성

```yaml
traits:
  - id: 용맹한
    effect: 라운드 시작 시 ⚔+1 (확정 보정값)
  - id: 굳건한
    effect: 라운드 시작 시 🛡+1
  - id: 신중한
    effect: 선제 페이즈 🛡+1
  - id: 예리한
    effect: ⚔+1 추가 (랜덤 타겟)
    constraint: 궁병 전용
  - id: 현명한
    effect: 리롤 1회 추가 (TODO: 리롤 부활 후)
    constraint: player 진영 전용
  - id: 고결한
    effect: TODO(엔진): 산개/밀집 폐기 후 재정의
  - id: 은밀한
    effect: ⚔+2 (랜덤 타겟)
  - id: 대담한
    effect: ★+1 추가 (체이닝 가속)
unlock:
  base: 용맹한 (첫 런 고정)
  per_stage_clear: [신중한, 예리한, 현명한, 고결한, 은밀한, 대담한, 굳건한]
```
