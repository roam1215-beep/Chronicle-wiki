# COMBAT-UNIT-HERO: Named 인물

> 상태: 결정정합 · 의존: @COMBAT-UNIT-CARD, @COMBAT-DICE-001, @COMBAT-STRUCT-001

## 정의

Named = 같은 병종 + 고유명 + ★ 면 보유 + 특성 1개 (특성 시스템은 다른 세션). 이름 유무가 등급. Named 사망 = 영구 손실. 테오도라 사망 = 게임 오버.

## 규칙

### Named 공통

```yaml
grade: named | knight
unique_name: 고유명 (예: 테오도라)
base_class: 병종 (보병/창병/궁병/기사 등)
star_face: 보유
faces: { ⚔: 1, 🛡: 1, ★: 1, ✕: 3 }   # Named 공통 잠정 시드
injury: 2단계 (정상 → 부상 → 사망) (@COMBAT-JUDGE-001)
trait: TODO(시스템) — 특성 시스템 재설계 대기
atk_power: 카드별
def_power: 카드별
passive: 병종 따라감 (@COMBAT-STRUCT-001 패시브 시스템)
loss: 영구 (퍼마데스)
```

### 테오도라

```yaml
order: 1
base_class:
  options: [보병, 창병, 궁병]
  first_run: 보병 고정
  unlock:
    chapter_1_clear: 창병
    chapter_2_clear: 궁병
인격:
  first_run: 용맹 고정 (튜토리얼 결)
  unlock:
    order_1_clear: 지혜
    chapter_2_clear (지혜): 광명 (1·2 인격 클리어 시)
  상세: @ORDER-001-CH 변주 시스템
trait: TODO(시스템) — 특성 결 다른 세션
atk_power: 3   # 잠정 — TODO(밸런스)
def_power: 1
death: 게임 오버
order_2: 기사 전직 (TODO(서사): O2 설계 시)
```

### 기사 (Order 2+)

```yaml
grade: knight (별도)
class: 기사
base_class: 기사 (병종 자체)
faces: TODO(밸런스): Order 2 설계 시
atk_power: TODO(밸런스)
def_power: TODO(밸런스)
passive_pool:
  options: [굳건, 반격, 쇄도]   # 선제 제외 (궁병 전용)
  selection: 3종 중 2택 1택 (Order 2 시)
note: Order 2+ 영역. Order 1에선 손대지 않음.
```

### 폐기 항목

```yaml
- color 필드:                       색 시스템 폐기 (4-26)
- 산개/밀집별 면 차이:              대형 폐기 (4-26)
- '고결한' 산개/밀집 의존 효과:     5-5 재정의 시도 (특성 풀 안에 있던 자리)
- '신중한' 선제 페이즈 의존:        5-5 재정의 시도
- ★ 체이닝:                         5-5 폐기 (다이스규칙 참조)
- 8 특성 시스템 (용맹한·굳건한·신중한·예리한·현명한·고결한·은밀한·대담한):
                                    5-7 폐기 (전면 재설계 — 다른 세션)
                                    이전 결: Named 1기당 1개. 매 라운드 적용. 스테이지 클리어 해금
                                    폐기 사유: 카드 시스템·인격 변주 결과 정합 재검토 필요
- 특성 풀 unlock per_stage_clear:   5-7 폐기 (특성 시스템과 한 묶음)
```
