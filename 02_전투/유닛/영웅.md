# COMBAT-UNIT-HERO: 영웅·재앙

> 상태: 결정정합 (5-9 코어 + 5 패러미터 박힘) · 의존: @COMBAT-UNIT-CARD, @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE

> 5-9 5 패러미터 박힘 (이번 마디):
> - 인물 5 패러미터 (공·방·hp·속도·신성력) + 별도 행동/신성 주사위 수
> - 가호 결산 정정: 가호 1개 = *신성력*만큼 (옛 결 = 인물 공·방 수치 정정)
> - 신성력 = 영웅·재앙의 *신성 깊이*가 수치로 박힘
> - 카타스테리스모스 = 신성력 깊이로도 박힘
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_5패러미터_박힘.md`

> 5-9 코어:
> - 어휘 정정: Named 인물 (5-7) → 영웅·재앙 4등급 (5-8) → 5-9 두 축 박힘
> - 등급 = 행동 주사위 수 + 신성 주사위 수 두 축
> - 신성 = 영웅·재앙만 보유. 무리·인간 = 신성 0.
> - 8 특성 폐기 (5-7) → 행동 주사위 분화 5종으로 흡수 (@COMBAT-UNIT-JOBRACE)
> - 패시브 시스템 (5-7) 폐기 → 5-9 자동 결로 폐기
> - hp 도입 (1격사 폐기). 잠정 시드 펜딩.

## 정의

영웅·재앙 = 신성 받는 등급. 행동 주사위 + 신성 주사위 둘 다 굴림. 가호 1택으로 응대 자리 박힘. 영웅 = 인간 상위 (지상·경계). 재앙 = 무리 상위 (미궁). 사망 = 영구 손실.

## 규칙

### 등급 = 두 축 + 5 패러미터

```yaml

영웅 (Heroes):

  사망:        게임 오버 (테오도라 결)
  결:          카타스테리스모스 (별이 됨)

  공격력:      잠정 (큼)

  팩션:        지상·경계
```

### 신성 주사위 풀

```yaml
영웅 (지상):    낮3 / 별1 / 밤2 (자기 시간대 = 낮)
재앙 (미궁):    밤3 / 별1 / 낮2 (자기 시간대 = 밤)
영웅 (경계):    펜딩 (균등? 결 변동? — 다음 마디)

별 면:          무조건 가호 + 신성 주사위 재굴림 (무한)
가호 박힘:      신성 면 = 페이즈 시간대 일치 + 자기 신앙 일치 시
실패:           반대 시간대 = 그저 무 (호메로스 결, 적 해코지 X)

상세: @COMBAT-DICE-001
```

### 가호 결산 (5 패러미터 정정)

```yaml
플레이어 = 박힌 가호를 *공 또는 방* 1택. 동시 선언 (정보 비대칭 보존).

점수 (5-9 5패러미터 박힘):
  가호 1개당 = *신성력*만큼 (옛 결 = 인물 공·방 정정)
  공으로 끌었을 시: 가호 수 × 신성력 = 공격 점수에 추가
  방으로 끌었을 시: 가호 수 × 신성력 = 방어 점수에 추가

결의 결:
  공·방 수치 = 인간의 결 (행동 결산)
  신성력 = 신의 결 (가호 결산)
  → 두 결산이 *완전 분리*
  
플레이어 시점:
  신적 (아테나 결)
  영웅 = 자기 결로 행동 (자동)
  플레이어 = 가호의 결을 *어디로 끌지* 정함

상세: @COMBAT-STRUCT-001
```

### 명성·덕목 (큰 그림 — 디테일 펜딩)

```yaml
명성:        업 쌓이면 인간 → 영웅 등극
표현:        신성 주사위 +1 (5-9 정정. 옛 결: ★ 추가 굴림)
메커니즘:    운명 전투 (재앙 처치) 클리어 시 덕목 1개 보장. 사건/우연도 가능 (R 결)
변주 ≠ 덕목: 분리. 변주 = 카드 풀 결, 덕목 = 신성 깊이 결.
덕목 풀:     그리스 4주덕 결 가능 (펜딩)
보유:        회차 누적, 다음 회차 초기화 (D 결)
덕목 효과:   신성 주사위 +1 → 별 면 / 자기 시간대 면 결로 박힘
체이닝:      별 면 = 신성 주사위 재굴림 (무한). 5-9 박힘.
덕목별 결:   덕목별 다른 결 X 같은 결 — 펜딩
신성력 정합: 덕목 누적 = 신성 주사위 수 +1. 신성력 자체 변동 펜딩.
             → 덕목이 신성력도 키울지 / 주사위 수만 늘릴지 펜딩
```

```yaml

- Named 어휘:                    5-8 정정 (영웅·재앙)
- 면 = ⚔/🛡/★/✕ (5-7):           5-9 정정 (행동 칼/방패/실패 + 신성 시간대/별)
- Named ★ 면 1개 (5-7):           5-9 정정 (영웅 = 신성 주사위 별 면 보유)

- 1격사 결 (Nameless):            5-7 폐기. 모든 등급 hp 보유.

- 가호 = 인물 공·방 수치 (5-9 코어): 5-9 5패러미터 마디 정정 (신성력으로)
```
