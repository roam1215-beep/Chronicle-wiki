# 영웅·재앙

## 위계 4종

```yaml
영웅 (Heroes):
  출신:    지상·경계 인간 종족
  태생:    한낮 (지상) 또는 여명 (경계)
  가호 폭: 고 폭

재앙 (Calamity):
  출신:    미궁·경계 무리 종족
  태생:    심야 (미궁) 또는 황혼 (경계)
  가호 폭: 고 폭

인간 (Humans, 저위계):
  출신:    지상·경계 인간 종족
  가호 폭: 저 폭
  등극:    Order 클리어 시 → 영웅 (작가 결 인물만)

무리 (Beasts, 저위계):
  출신:    미궁·경계 무리 종족
  가호 폭: 저 폭
  등극:    Order 클리어 시 → 재앙
```

## 종족 ↔ 위계 정합

```yaml
인간 종족: 인간 ↔ 영웅
무리 종족: 무리 ↔ 재앙
교차 X (인간 → 재앙 X / 무리 → 영웅 X)
```

## 등극 (위계 변동)

```yaml
시점: Order 클리어 시
방식: 미리 정한 인물 1명 등극 (작가 결, Order 시작 시 결정)
결:   인간 → 영웅 / 무리 → 재앙
      카타스테리스모스 (별이 됨)
태생 = 변동 X
```

## 등급 (챕터 클리어 시)

```yaml
변동: 필멸 → 반신 → 신성 → 번외
결:
  의지 +1 (주사위 수)
  가호 +1 (가호 수)
  한 박자에 둘 다
내부 결 (게임 노출 X)
```

## 가호

```yaml
가호 수 = 등급:
  필멸 0 / 반신 1 / 신성 2 / 번외 3

가호 폭 = 위계:
  저위계 = 작은 폭
  고위계 = 큰 폭

가호 유형 = 태생:
  한낮 / 여명 / 황혼 / 심야

지속: 가호 = 영구 / 대성공 효과 = 1 라운드
영역: 기본 스탯 / 대성공 시 / 라운드·열·공격·피격 기반
콘텐츠: [펜딩]

상세: 인물카드규칙.md
```
