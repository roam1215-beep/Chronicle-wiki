## ① 한 줄 요약

Named = 같은 병종 + 고유명 + ★. 기사는 Named 전용 병종으로 ⚔2🛡3★2✕3의 고유 면(유효면 7개)을 가진다. 기사는 테오도라 전용이 아니며 적/아군 모두 등장 가능. 패시브는 병종별 기본 보유. 특성 A풀은 [지혜로운](리롤+1)만 잔존, 나머지 폐기. B풀(악덕 6종) = Named 특성(성격).

## ② 규칙 정의

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **Named 정의** | 같은 병종 + 고유명 + 유효면2→★2 |
| **★ 면** | Nameless의 유효면(⚔ 또는 🛡) 2개가 ★로 교체. ✕ 수는 동일. Named만 보유 |
| **부상 생존** | 피격 1회 시 유효면(⚔/🛡/★) 중 랜덤 1개→✕ 전환(부상). 2회 피격 시 사망 |
| **패시브** | 병종 패시브 기본 보유. 슬롯 최대 1개. 기사는 방진/반격/쇄도 중 랜덤 1 |
| **사망** | 테오도라 사망 = 게임오버 |

### Named 범용 d10 면 구성 (유효면2→★2)

| Named 유닛 | d10 면 구성 | 기반 병종 |
|-----------|------------|----------|
| Named 민병 | ⚔⚔🛡★★✕✕✕✕✕ | 민병 (⚔-1🛡-1→★2) |
| Named 보병 | ⚔🛡🛡🛡★★✕✕✕✕ | 보병 (⚔-2→★2) |
| Named 창병 | 🛡🛡🛡🛡★★✕✕✕✕ | 창병 (🛡-2→★2) |
| Named 궁병 | ⚔⚔⚔⚔★★✕✕✕✕ | 궁병 (⚔-2→★2) |
| Named 기병 | ⚔⚔🛡🛡★★✕✕✕✕ | 기병 (⚔-2→★2) |

> **범용 규칙:** 유효면(⚔ 또는 🛡) 2개 → ★2 교체. ✕ 수는 동일. 안정성을 폭발력으로 교환. 기사는 이 규칙의 예외 (아래 참조).

### 기사 — Named 전용 병종

| 필드 | 내용 |
|------|------|
| **정의** | Named 전용 병종. Nameless 기사는 존재하지 않음. 테오도라 전용이 아니며 적/아군 모두 등장 가능 |
| **정체성** | "이름이 있는 자만이 기사다." 이름의 유무가 등급인 Chronicle에서, 기사는 이름을 가진 자의 병종 |
| **유효면 7개** | 기사는 유효면 7개(✕3)를 갖는다. 다른 Named의 유효면 6개(✕4)와 구별되는 기사의 특권 |
| **면 구성** | ⚔2 🛡3 ★2 ✕3 — 고유 면. Named 범용 규칙(유효면→★)과 별도 |
| **★ 2개** | 체이닝 특화. d6 시절 테오도라(★17%)보다 높은 ★20% |
| **패시브** | 기존 패시브 중 랜덤 1 기본 보유: **방진 / 반격 / 쇄도**. 선제 공격 제외 (기사가 활을 쏘지 않음 — 적 기사 포함) |
| **쇄도 시** | 쇄도 보유자 수에 포함. 기병과 함께 카운트 |

> **기사 패시브별 성격:**
> - **방진:** 수비형 기사. ⚔2를 🛡로 전환 → 🛡5까지. 결사 전까지 버틴다.
> - **반격:** 공격형 기사. 🛡3을 ⚔로 전환 → ⚔5 + ★2. 폭발력.
> - **쇄도:** 돌격 기사. 적 유효면 1개 확정 파괴. 기병과 시너지.

### 테오도라 — 기사 [플레이어 Named]

| 필드 | 내용 |
|------|------|
| **명칭** | 테오도라 / 기사 |
| **면 구성** | ⚔⚔ 🛡🛡🛡 ★★ ✕✕✕ (⚔20% 🛡30% ★20% ✕30%) |
| **패시브** | 방진 / 반격 / 쇄도 중 랜덤 1 기본 보유 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 유효면(⚔/🛡/★) 중 랜덤 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |
| **플레이버 (기록)** | 서자 출신의 기사. |
| **플레이버 (개인)** | (비움 — 특성이 채운다) |

### 특성 시스템

특성은 A풀(미덕)과 B풀(악덕) 2풀 체계. 카드에 "형용사 + 이름"으로 표기된다.

#### A풀 — 미덕 (테오도라 전용)

> ⚠️ **용감한/충직한/고결한/자비로운 폐기 (2026-03-08).** 카드락 시스템 폐기. 추종자 패시브로 흡수. [지혜로운]만 잔존.

| 미덕 | 효과 | 비고 |
|------|------|------|
| ~~용감한~~ | ~~아군 주사위 1개 ⚔ 카드락~~ | **폐기.** 추종자로 이관 |
| ~~충직한~~ | ~~아군 주사위 1개 🛡 카드락~~ | **폐기.** 추종자로 이관 |
| ~~고결한~~ | ~~아군 주사위 1개 ★ 카드락~~ | **폐기.** 추종자로 이관 |
| 지혜로운 | 리롤+1 | 기본 1 + 추가 1 = 2회. **잔존** |
| ~~자비로운~~ | ~~매 라운드 아군 전체 ✕ 결과 1개 → ⚔/🛡 랜덤(50:50)~~ | **폐기.** 추종자로 이관 |

> **플레이버:** "지혜로운 테오도라" 등.

#### B풀 — 악덕 (적/아군 Named 공통)

상시형 효과. 판단 불필요. 적/아군 Named는 처음부터 보유.

| 악덕 | 효과 | 비고 |
|------|------|------|
| 잔혹한 | 격돌 ⚔+1 확정 | 양측 총합 합산. 쇄도 대상 아님 |
| 고집센 | 격돌 🛡+1 확정 | 양측 총합 합산. 결사 시 ⚔ 전환 |
| 겁이 많은 | 선제 🛡+1 (피격 1발 방어) | 피격 흡수 시 영구 소멸. 밤엔 보존 |
| 교활한 | 선제 ⚔+1 | 궁병 Named만. 밤엔 효과 없음 |
| 집요한 | 부상 1회 완전 무효 | 면 전환 없음. 선제 포함. 1회 소모 영구 소멸 |
| 위선적인 | 매 라운드 해당 진영 전체 ✕ 결과 1개 → ⚔/🛡 랜덤(50:50) | 자동. 스텝4 후 스텝5 전. ✕ 없으면 불발 |

> **B풀 상호작용:** 쇄도 대상 아님. 결사 🛡→⚔ 전환 적용. 부상 무관. 전황 적용 (기습/역습 시 R2부터).
> **플레이버:** "잔혹한 마르쿠스", "집요한 발레리안" 등.

#### 풀 운영 규칙

| 필드 | 내용 |
|------|------|
| **A↔B** | 풀 침범 불가 |
| **분리 근거** | 미덕/악덕 서사 기반 |
| **테오도라** | A풀 [지혜로운]만 잔존. 획득 시점 미정 (업적 시스템 폐기) |
| **적/아군 Named** | B풀 처음부터 보유. 최대 3개 |
| **보유 상한** | Named 1기당 1개 (추후 복수 확장, 최대 3개) |

## ④ 설계 근거

**Q. 왜 기사가 Named 전용인가?**
"이름 없는 기사"는 그냥 병사다. Chronicle의 핵심 문법 "이름의 유무가 곧 등급"에서, 기사는 이름을 가진 자만의 병종. Nameless 기사는 모순.

**Q. 왜 기사 면이 범용 규칙(유효면→★)과 다른가?**
⚔2🛡3★2✕3은 기존 5병종 어디에도 대응이 안 됨. "유효면→★"이 아니라 독립 면을 가진 6번째 병종. 예외가 아니라 독립 규칙.

**Q. 왜 Named 전원 ★2인가?**
Named = 유효면 2개를 ★로 교환. 안정성을 폭발력으로 바꾼다. ✕ 수는 동일하므로 실패율은 같되 체이닝으로 기대값 상승. "이름의 무게"가 곧 체이닝.
**Q. 왜 기사 패시브가 기존 풀(방진/반격/쇄도)에서 랜덤인가?**
새 패시브를 만들면 밸런스 비용 추가. 기존 패시브를 재활용하되 "어떤 것이 걸릴지 모른다"가 로그라이크의 빌드 다양성. 같은 기사인데 방진 기사 / 반격 기사 / 쇄도 기사로 성격이 달라짐.

**Q. 왜 선제 공격이 기사 패시브 풀에서 제외되나?**
기사가 활을 쏘는 건 서사에 안 맞음. 또한 선제 참여 시 격돌에서 빠지므로 ★2 체이닝이라는 기사의 핵심 강점을 격돌에서 쓸 수 없게 됨.

**Q. 왜 테오도라가 기사인가?**
⚔2🛡3★2✕3은 어떤 기존 병종과도 안 맞음. 보병보다 방어가 높고 공격이 낮으면서 ★2. "증명해야 하는 서자 기사"에 적합. 방패 뒤에서 칼을 뽑거나(반격), 칼을 거두고 방패를 세우거나(방진), 돌격하거나(쇄도).
