# COMBAT-UNIT-HERO: Named 인물 (Named Figures)

> **상태:** 🔄 설계중 · **버전:** 0.8 · **ID:** COMBAT-UNIT-HERO · **수정일:** 2026-02-28

---

## ① 한 줄 요약

테오도라(기사, 창병 계열)는 유일한 Named. 추가 Named 승급은 폐기. Named는 ★ 면과 2단계 부상 체계를 가지며, 패시브는 스테이지 보상으로, 업적 카드는 Chapter 전환 시 획득한다.

---

## ② 규칙 정의

### 테오도라 — 기사 (창병 계열) [유일한 Named]

| 필드 | 내용 |
|------|------|
| **명칭** | 테오도라 / 기사 |
| **면 구성** | ★ ⚔ 🛡 🛡 ✕ ✕ |
| **참여** | 본 라운드에 굴림 |
| **패시브 (초기)** | 없음. 빈 슬롯 3개 |
| **병종 패시브** | 반격 — 🛡 결과를 ⚔로 전환할 수 있다 (스텝6). 스테이지 보상으로 획득 |
| **전환** | 🛡→⚔ 일방향 (창병 계열). 반격 패시브 획득 시 사용 가능 |
| **★ 체이닝** | ★ = ⚔ 1 확정 + 재굴림. 재굴림 결과도 유효 |
| **부상** | 피격 시 🛡 1개 → ✕. 부상 상태에서 재피격 = 사망 = **게임오버** |
| **사상자 풀** | 랜덤 풀에 포함. 보호 없음 |

### 업적 카드 시스템

| 필드 | 내용 |
|------|------|
| **정체** | 테오도라 전용 성장 시스템. 패시브와 별도 영역 |
| **획득 시점** | Chapter 전환 시 (런당 2회: Chapter 1→2, Chapter 2→3) |
| **선택 방식** | 3종 업적 카드 제시 → 플레이어 택 1 |
| **정보 비대칭** | 다음 Chapter 내용을 모르는 상태에서 선택 |
| **카드 영역** | 기존 패시브 슬롯과 분리된 별도 영역 |
| **런당 최대** | 2장 (Chapter 1→2 전환, Chapter 2→3 전환) |

> **업적 카드 풀 구체 내용은 미정.** 패시브 계열이지만 기존 병종 패시브(반격/전열교대/선제공격)와는 별도 체계.

### Named 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | Named만 보유. Nameless는 ★ 없음 |
| **부상 생존** | 피격 1회 시 면 1개→✕로 전환(부상). 2회 피격 시 사망 |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개. 전부 스테이지 보상으로 획득 |
| **패시브 슬롯** | 최대 3개 |
| **업적 카드** | Chapter 전환 시 획득. 패시브와 별도 영역 |
| **사망** | 테오도라 사망 = 게임오버 |

## ⑥ 설계 근거

**Q. 왜 Named가 테오도라 1기뿐인가?**
승급(Nameless→Named) 시스템 폐기. 1인 개발 데모에서 승급 처리 비용이 과대. 프로모션 대신 테오도라만 패시브/업적으로 성장하는 구조가 깔끔.

**Q. 왜 테오도라가 보병에서 기사(창병 계열)로 변경되었나?**
보병 계열(⚔→🛡)이면 테오도라가 수비적. 서자 기사라는 서사와 맞지 않음. 창병 계열(🛡→⚔)은 기본 방어가 탄탄하되 필요 시 공격 전환 가능 — "증명해야 하는 기사"에 적합.

**Q. 왜 패시브가 초기 비어있나?**
"겪은 것이 능력이 된다." 테오도라도 런 시작 시에는 아무 능력 없이 ★ + 부상 생존만 가진다. 패시브는 스테이지를 겪으며 채운다.

**Q. 왜 업적 카드가 패시브와 분리되나?**
패시브는 병종 기반(반격 등)이고 스테이지 보상으로 획득. 업적은 Chapter 전환 보상이며 다른 계열. 두 성장 축이 분리되어야 빌드 다양성 확보.

**Q. 왜 업적 카드를 다음 Chapter 내용 모르고 고르나?**
의도된 정보 비대칭. 규칙은 플레이하면 알게 되는 것. "닥친 상황에 적응"하는 핵심 경험과 일치.
