# 영웅·재앙

> 상태: 결정정합 (5-11+ 마디 박힘)

> 5-11+ 마디 큰 정정 (전투 4.0 → 5.0):
> - 직업 3종 → 4종 (신관 폐기, 수호자·사제 부활)
> - 공·방 1택 → 다이시 테일즈식 (면 종류 → 행동 풀)
> - 매 라운드 행동 선택 → 작은 AI + 영웅·반신 라운드 1회 결단
> - 행동 5종 (격돌·사격·보호·축복·저주) + 상태 이상 결 (잠재)
> - 사거리 정정 (사냥꾼 1·2열 → 1열만)
> - 보호막 결 (영구, 모든 인물)
> - 챕터 클리어 = 의지 +1 (등급 변동) — 펜딩 풀림
> - 실패 면 어휘 폐기 (실제 면 비율엔 없음)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-11 마디 큰 정정:
> - 인도 주사위 폐기 (의지 1종으로 합침)
> - 신성력 패러미터 폐기 (등급 자체가 신성 결의 그릇)
> - 위계 ↔ 등급 자유 조합 (헥토르 = 신성 인간 / 아킬레우스 = 번외 영웅)
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - 영웅 등극 결 = 펜딩 (등급 변동? 위계만? 둘 다?)
> - 챕터 클리어 = 신성 주사위 획득 계기 → 의지 주사위 수 결 박을 자리 (5-11+ 박힘)
> - "주사위가 곧 신성력이 포함된 의지 덩어리" — 등급 = 신성 결 자체
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

영웅·재앙 = 신성 결의 깊이 박힌 자리 (위계 결). 등급 = 의지 주사위 수 (필멸/반신/신성/번외). 별도 인도 주사위 X — 한 굴림에 의지 + 신성 결 합주. 영웅 = 인간 상위 (지상·경계). 재앙 = 무리 상위 (미궁). 사망 = 영구 손실.

## 규칙

### 등급 결 (위계 ↔ 등급 자유 조합)

```yaml
등급 4단:
  필멸:    의지 주사위 1개
  반신:    2개
  신성:    3개
  번외:    4+개 (보스급)

위계 ↔ 등급 자유 조합:
  보통:
    인간:    필멸 (평민) / 반신 (정예)
    무리:    필멸 (잡몹) / 반신 (강한 무리)
    영웅:    반신 (보통) / 신성 (강한)
    재앙:    반신 (보통) / 신성 (강한) / 번외 (보스)
  
  예외:
    헥토르 (인간 무용 큼) = 신성 인간 (3)
    아킬레우스 (영웅 + 신과 관련) = 번외 영웅 (4)

→ 등급 = 결의 깊이.
→ 위계 = 게임 노출 어휘 + 신성 결 보유 자리.
→ 자유 조합 가능. 작가 결로 박힘.

```

### 의지 결산 (5-11+ 박힘)

```yaml
"주사위가 곧 신성력이 포함된 의지 덩어리":
  의지 주사위 1종만 굴림 (별도 인도 주사위 X).
  면 결: 의지(별) / 신성(낮·밤) / 경계 (3종, 실패 면 어휘 폐기)
  
  자기 시간대 라운드:
    별 + 자기 시간대 면 = 박힘 4면 (67%)
    
  반대 시간대 라운드:
    별 = 박힘 3면 (50%)
    자기 시간대 면 = 졸전 (작게 박힘, 결산 X 아님)

선언 결 (단계 0) — 다이시 테일즈식 (5-11+ 정정):
  필멸: 결단 X. 인물 카드 우선순위로 자동.
  영웅·반신: 라운드당 1회 결단 (행동 1택 + 대상 1택)
  → 굴림 → 박힌 면 보고 자동 발동 (호메로스 결: 선언→굴림→응답)
  
행동 풀 결 (면 종류 → 행동):
  별 면:        직업 기본 행동 (격돌·사격·보호·축복·저주 중)
  자기 시간대 면: 변형 행동 (강타·관통·계통 특수 등)
  반대 시간대 면: 졸전 (작게 박힘)

결산 결 (단계 2):
  격돌: 박힌 면 × 공격력 = 공격 점수 + 박힌 면 × 방어력 = 방어 점수 (양쪽)
  사격: 박힌 면 × 공격력 = 공격 점수
  수비: 박힌 면 × 방어력 = 방어 점수
  변형 결: 강타 ×1.5 / 졸전 ×0.5 (반올림, 잠정)

→ 영웅·재앙 = *주사위 수 큼* 결로 결의 깊이 박힘.
→ 인간·무리 (필멸 1) vs 영웅·재앙 (반신 2+) = 결의 결 차이.
→ 별도 신성력 X. 별도 인도 결산 X.

```

### 직업·종족 (5-11+ 박힘)

```yaml

  전사:     1열 / 격돌 결
  수호자:   1열 / 격돌 + 보호 결
  사냥꾼:   2열 / 사격 결 (방 0)
  사제:     2열 / 계통별 행동 풀 (팩션 결)

직업 결 = 행동 양식만 (5-11+ 정정)
  옛 결 (5-11): 행동 양식 + 분배 비율 (5:3:2 등)
  새 결: 행동 양식만. 분배 결 = 팩션 결의 결로 흡수 (작가 결).

```

```yaml
  first_run:   용맹 고정 (튜토리얼 결)
  unlock:
    order_1_clear:               지혜
    chapter_2_clear (지혜 결):   광명 (1·2 인격 클리어 시)
  표기 유지: "용맹한" / "지혜로운" / "빛나는" (5-10 결정)

능력치 시드 (잠정 펜딩):
  공격력:        잠정 펜딩 (직업·등급 결로)
  방어력:        잠정 펜딩 (직업·등급 결로)
  속도:          잠정 펜딩 (별도 결, 인물 시드 또는 팩션 결)
  hp:           잠정 펜딩 (필멸 1 / 반신 3 결로 박힐 자리)
  보호막:        시작 0 (사건·장비·사제 부여로 누적)

별도 속성:
  의지 주사위 수: 등급 결 (필멸 1 또는 반신 2)
  행동 풀:       직업 결로 박힘 (5-11+ — 별 면 기본 + 시간대 면 변형)
  
death:         게임 오버
```

### 명성·덕목 (5-10 박힘 살림 + 5-11+ 정정)

```yaml
큰 정정 (5-10 박힘 살림):
  덕목 = *살아내는 결* (시작한 덕목대로)
        덕목 = 인격에 박힌 결 (변주 = 인격 = 덕목 결)
        획득 X
        본인 박은 결: "인간이 신성에 가까워지는 *과정*"

5-11+ 정정 자리 (5-11 펜딩 부분 풀림):
  등급 변동 결 (박힘):
    챕터 클리어 = 의지 주사위 +1 (등급 변동)
    Order 1 (3 챕터):
      챕터 1 클리어: 필멸 1 → 반신 2
      챕터 2 클리어: 반신 2 → 신성 3
      챕터 3 클리어: 신성 3 → ? (Order 결로 박힘, 펜딩)
    근거 (본인 박은 결): 챕터 클리어가 *과정*이라 등급 변동의 결이 챕터 단위와 정합 깊음.

  위계 변동 결 (인간 → 영웅): 여전히 펜딩
    후보 시점:
      ㄱ. 운명 전투 첫 클리어 시 (=챕터 1 스테이지 1 운명 = 발드 클리어)
      ㄴ. Order 클리어 시 (=별이 박히는 결, 카타스테리스모스)
      ㄷ. 다른 결

→ 두 결 분리:
  덕목 (변동 X) = 살아내는 결
  의지 주사위 수 (누적 결) = 챕터 클리어로 박힘 (5-11+ 박힘)
  위계 (인간/영웅 등) = 시나리오 단위 변동 (펜딩)

명성:        업 쌓이면 인간 → 영웅 등극 (시나리오 단위 박힘, 시점 펜딩)
표현:        등급 변동 = 의지 주사위 +1 / 위계 변동 = 펜딩
메커니즘:    운명 전투 (재앙 처치) 클리어 시 미리 정한 인물에 신성 박힘
변주 = 덕목: 변주 = 인격 = 덕목 결 (분리 X)
덕목 풀:     그리스 4주덕 (지혜 / 용기 / 절제 / 정의)
```

```yaml
- 광역 사거리 = 별도 결:            5-11+ 흡수 (행동 풀의 변형 결 안에)
- 챕터 클리어 = 의지 +1 펜딩 (5-11): 5-11+ 박힘 (등급 변동 결)
```
