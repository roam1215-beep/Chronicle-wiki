# 인물 카드 규칙

## 카드 5축

```yaml
진영:  지상 / 미궁 / 경계 (3종)
종족:  인간 / 무리 (2종)
태생:  한낮 / 여명 / 황혼 / 심야 (4종)
위계:  인간 / 영웅 / 무리 / 재앙 (4종)
등급:  필멸 / 반신 / 신성 / 번외 (4종, 내부, 노출 X)

+ 직업: 전사 / 수호자 / 사냥꾼 / 사제 (자유)
```

## 능력치

```yaml
공격력:
  상대 hp 직격 (하스스톤 전장식)
  시간대·가호로 출력 변동

체력 (hp):
  인물 고유 (변동 X)
  배틀 단위 회복 (새 배틀 진입 시 풀)
  
  잠정 시드:
    필멸: 1~2
    반신: 3~4
    신성: 5~7
    번외: 10+
  [실제 시드 = 작가 결, 펜딩]

방어도 (감산):
  부여: 시작 시 (직업·가호) / 행동 (수호·축복) / 가호
  결산: 숫자만큼 막음
  지속: 행동 = 1 라운드 / 가호 = 영구

보호막 (이진, 희소):
  결: 어떤 피해든 1번 무효, 1번 사용 시 1개 소멸
  부여: 사제 행동? 가호? [펜딩, 희소]

피해 흐름: 보호막 → 방어도 → hp
```

## 의지 주사위 수 = 등급

```yaml
필멸:  1개
반신:  2개
신성:  3개
번외:  4+개

주사위 ×N개:
  각 주사위 = 독립 행동
  같은 행동 ×N번 (대상 같은 자리)
  가호 수와 정합 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
```

## 가호

```yaml
가호 수 = 등급:
  필멸 0 (가호 X)
  반신 1
  신성 2
  번외 3

가호 폭 = 위계:
  저위계 (인간·무리) = 작은 폭
  고위계 (영웅·재앙) = 큰 폭

가호 유형 = 태생 정합:
  한낮 태생 = 한낮 가호 (지상 인간)
  여명 태생 = 여명 가호 (경계 인간)
  황혼 태생 = 황혼 가호 (경계 무리)
  심야 태생 = 심야 가호 (미궁 무리)

영역:
  - 기본 스탯 +N (시작 시)
  - 대성공 시 스탯 +N
  - 라운드 기반 조건부
  - 열 기반 조건부
  - 공격·피격 기반 조건부

지속:
  가호 = 영구 (배틀·라운드 무관)
  대성공 행동 효과 = 1 라운드만

콘텐츠: [펜딩, 작가 결]
```

## 행동

```yaml
유저 결단:
  매 라운드 명령 시 = 배치 자유 변경
  편성 = 폐기 (파티 한 번 정해지면 쭉)
  라운드 안 결단 X

직업 자동 매커니즘:
  영웅·반신·필멸 차별 = 가호 결만 (수 + 폭)
  → 직업종족.md 참조
```

## 결산식

```yaml
격돌:
  공격력 = 상대 hp 직격
  동시 결산 (양 진영)
  자기도 격돌 받음

굴림 결산 (개별 주사위):
  별 → 통상 행동 1번
  자기 시간대 면 + 자기 라운드 → 대성공 1번 (행동 변형)
  자기 시간대 면 + 반대 라운드 → 통상 1번 (case 2)
  반대 시간대 면 → 실패 (격돌 직업만 수동)

우선순위: 대성공 > 통상 > 실패
```

## 등극·등급

```yaml
위계 (Order 클리어 시):
  인간 → 영웅 / 무리 → 재앙
  카타스테리스모스 결 (별이 됨)
  태생 = 변동 X

등급 (챕터 클리어 시):
  필멸 → 반신 → 신성 → 번외
  의지 +1 + 가호 +1 (한 박자)
  내부 결 (게임 노출 X)
```
