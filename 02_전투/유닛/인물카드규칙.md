# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: **재설계 진행중 (5-8)** · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001

> ⚠️ 5-8 큰 정정 예정:
> - 등급 체계: Named/Nameless 2종 → 영웅/인간/재앙/무리 4종
> - 차별 = 주사위 수 (인간·무리 1개, 영웅·재앙 N개) + hp + 출신 신앙
> - 카드 데이터: faces (⚔/🛡/★/✕) → 시간대 면 (낮/황혼/밤) + 매칭 점수
> - hp 신규 (1격사 폐기). 모든 등급 hp 보유
> - 면 영구 변환 자리 펜딩 (옛 교관/종자/사제 폐기 — 5-7)
> - 본문은 5-7 결 그대로. 다음 세션에서 전면 재작성 예정.
> 상세: `DOCS/DESIGN/LOG/2026-05-08_전투4.0_재설계_시작.md`

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.**

## 규칙

### 등급 체계

```yaml
nameless:
  star_face: 0
  injury: 없음 (피격 = 즉사) (@COMBAT-JUDGE-001)
  trait: 없음
  atk_power: 병종별 (@COMBAT-UNIT-NAMELESS)
  def_power: 병종별

named:
  star_face: 1
  injury: 2단계 (정상 → 부상 → 사망)
  trait: TODO(시스템) — 특성 시스템 재설계 대기 (@COMBAT-UNIT-HERO)
  atk_power: 카드별 (@COMBAT-UNIT-HERO)
  def_power: 카드별

knight:
  star_face: 1+ (Order 2 결정)
  injury: 2단계
  trait: TODO(시스템)
  note: Named 변형. 병종 자체가 "기사"
```

### 카드 자체 정보

```yaml
card_data:
  faces: { ⚔: int, 🛡: int, ★: int, ✕: int }   # 합 = 6 (d6)
  power: { atk_power: int, def_power: int }      # 0 허용
  passive: enum [없음, 굳건, 반격, 선제, 쇄도, 자유선택]
  trait: TODO(시스템) — 특성 시스템 재설계 대기
```

### 면 정의 (구성면 vs 결과면)

```yaml
initial: 병종/Named 기본값 (병종.md / 영웅.md)
current: initial + 영구 변환
  영구 변환 자리: TODO(시스템) — 옛 결(교관/종자/사제/[연마]/[단조])은 5-7 폐기
  새 결: 인격 변주 + 카드 시스템 재설계 후 박을 자리 (다른 세션)
result:  매 라운드 굴림 결과 (라운드마다 리셋)
injury:  current의 유효면(⚔/🛡/★) 1개 → ✕. 전투 종료 시 current 복원
```

### 폐기 항목

```yaml
- 앞면 = 산개 / 뒷면 = 밀집:    대형 폐기 (4-26)
- 뒷면 시 일제 굴림:            대형 폐기 (4-26)
- color 필드:                   색 시스템 폐기 (4-26)
- 밀집 시 구성면 변환 무시:     대형 폐기 (4-26)
- 8 특성 시스템:                5-7 폐기 (전면 재설계 대기)
- 태그 시스템 (전황/전술/우연 등): 5-7 폐기 (전면 재설계 대기)
- 영구 변환 자리 (교관/종자/사제 등): 5-7 폐기 (전면 재설계 대기)
- [연마] / [단조] / [열화] 서브 메카닉: 5-7 폐기 (태그 시스템 의존)
```
