# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 결정정합 · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. 이름 유무가 곧 등급. **카드 1장 = 주사위 1개 = 유닛 1기.**

## 규칙

### 카드 = 유닛 = 주사위

```yaml
mapping:
  card_count: 유닛 수와 1:1
  dice_per_card: 1
  examples:
    - 보병 3기 = 보병 카드 3장 = 주사위 3개
    - 테오도라 1기 = Named 카드 1장 = 주사위 1개
```

### 등급 체계

```yaml
nameless:
  star_face: 0
  injury: 없음 (피격 = 즉사) (@COMBAT-JUDGE-001)
  trait: 없음
  atk_power: 병종별 (@COMBAT-UNIT-NAMELESS)
  def_power: 병종별

named:
  star_face: 1
  injury: 2단계 (정상 → 부상 → 사망)
  trait: 1개 (8종 중)
  atk_power: 카드별 (@COMBAT-UNIT-HERO)
  def_power: 카드별

knight:
  star_face: 1+ (Order 2 결정)
  injury: 2단계
  trait: 1개
  note: Named 변형. 병종 자체가 "기사"
```

### 카드 자체 정보

```yaml
card_data:
  faces: { ⚔: int, 🛡: int, ★: int, ✕: int }   # 합 = 6 (d6)
  power: { atk_power: int, def_power: int }      # 0 허용
  passive: enum [없음, 굳건, 반격, 선제, 쇄도, 자유선택]
  trait: enum (Named 전용. @COMBAT-UNIT-HERO 8종)
```

### 면 정의 (구성면 vs 결과면)

```yaml
initial: 병종/Named 기본값 (병종.md / 영웅.md)
current: initial + 영구 변환 (교관/종자/사제/[연마]/[단조] 등)
result:  매 라운드 굴림 결과 (라운드마다 리셋)
injury:  current의 유효면(⚔/🛡/★) 1개 → ✕. 전투 종료 시 current 복원
```

### 폐기 항목

```yaml
- 앞면 = 산개 / 뒷면 = 밀집:    대형 폐기 (4-26)
- 뒷면 시 일제 굴림:            대형 폐기 (4-26)
- color 필드:                   색 시스템 폐기 (4-26)
- 밀집 시 구성면 변환 무시:     대형 폐기 (4-26)
```
