# COMBAT-UNIT-CARD: 인물 카드 규칙 (Figure Card Rules)

> **상태:** 🔄 설계중 · **버전:** 1.0 · **ID:** COMBAT-UNIT-CARD · **수정일:** 2026-03-08

---

## ① 한 줄 요약

전투에서 주사위를 굴리는 모든 존재는 인물 카드다. 이름이 있으면 Named, 없으면 Nameless. 이름의 유무가 곧 등급이다.

---

## ② 카드 타입 체계

| 타입 | 역할 | 예시 |
|------|------|------|
| **인물 (Figure)** | 전투에서 주사위를 굴리는 존재 | 테오도라, 보병대, 궁병대, 기병대 |
| **이야기 카드** | 전투 카드, 사건 카드, 우연 카드, 운명 카드 | → [TAG-RULE-001 태그규칙](../../08_스키마/태그규칙.md) |
| **기록 (Record)** | 압축 산물. 스테이지/챕터/오더 카드 | 미정 |

> 이 문서는 **인물 카드만** 다룬다. 사건/기록 카드는 별도 문서에서 정의.
> 카드 시각 표현(진영 3색, 레이아웃 상세)은 [UI-CARD-001](../../05_UI/컴포넌트/카드.md) 참조.

## ③ 등급 체계: Nameless / Named / Hero

### 세 단계

| 등급 | 표면 표기 | 의미 |
|------|-----------|------|
| **Nameless (무명)** | 병종+대 (예: 보병대) | 이름 없는 부대. 피격 시 즉사 |
| **Named (유명)** | 고유명 / 병종 (예: 테오도라 / 기사) | 이름을 가진 인물. 피격 시 부상→사망 2단계 |
| **Hero (영웅)** | 게임플레이 중 표기 없음 | 런 완료 시 오더 카드에 기록. 메타 등급 |

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **이름이 곧 등급** | 카드 표면에 "Nameless", "Named" 태그를 쓰지 않는다. 이름 유무로 판별 |
| **영웅은 되는 것** | "기록되지 않은 자들의 영웅전" — 영웅으로 시작하지 않고 영웅이 된다 |
| **★이 Named의 증표** | Named만 ★ 면을 가진다. Nameless는 ★ 없음 |
| **Named = 같은 병종** | Named는 병종이 바뀌지 않는다. 고유명이 붙을 뿐. 기사는 Named 전용 병종 (Nameless 없음). 기사는 테오도라 전용이 아니며, 적/아군 모두 등장 가능 |

### Nameless 규칙

| 필드 | 내용 |
|------|------|
| **명칭** | 병종+대 (민병대, 보병대, 창병대, 궁병대, 기병대) |
| **★ 면** | 없음 |
| **피격** | 즉사. 퍼마데스 |
| **카드 뒷면** | 크로스해치 거친 종이, "CHRONICLE" 각인 |
| **플레이버** | 병종 공통 문구 (예: "전선의 이름 없는 방패들") |

### Named 규칙

| 필드 | 내용 |
|------|------|
| **명칭** | 고유명 / 병종 (예: 테오도라 / 기사) |
| **★ 면** | 있음. Nameless의 유효면(⚔/🛡) 2개가 ★으로 교체. ✕ 수 동일 |
| **피격** | 1회 부상(유효면 중 랜덤→✕), 2회 사망. 테오도라 사망 = 게임오버 |
| **카드 뒷면** | 양피지 노이즈, "CHRONICLE" 각인, ✦ 봉인 |
| **플레이버** | 고유 서사 문구 (예: "내 이름은 아직 아무것도 아니다. 그래서 나아간다") |

### ~~승급: Nameless → Named~~ (폐기)

> **Nameless → Named 승급 시스템은 폐기되었다.** Named = 테오도라 1기(편성 시). 테오도라의 성장은 추종자 시스템 + Named 특성으로 표현한다.

## ④ 카드 레이아웃

> **상세 레이아웃은 [UI-CARD-001 카드 컴포넌트](../../05_UI/컴포넌트/카드.md) 참조.** 아래는 규칙 수준 요약.

### 앞면 구조

| 영역 | 위치 | Named | Nameless |
|------|------|-------|----------|
| 주사위 배지 + 이름 + 병종 | 좌측 상단 | d10 SVG ×1, 고유명 / 병종 | 🎲 ×N, 병종+대 |
| 플레이버 | 이름 아래 | 고유 서사 | 병종 공통 문구 |
| 일러스트 | 중앙 (최소 160px) | 고유 인물 초상 | 대표 병사 초상 |
| 특성 | 하단 (Named만) | ✦ + 이름 + 설명 인라인. 획득분만 표시 | 없음 |
| 패시브 | 하단 | 이름 + 설명 텍스트. 민병은 미표시 | 민병은 미표시 |
| 다이스 면 | 최하단 | 5+5 배치 + 비율 바. ★ 포함 | ★ 없음 |

> **빈 슬롯 미표시:** 특성은 획득된 것만 카드에 표시. 패시브는 민병 외 항상 표시.
> **일러스트 규칙:** 모든 인물 카드는 1인 초상화. Named = 고유 인물, Nameless = 대표 병사.

### 뒷면

| 요소 | Nameless | Named |
|------|----------|-------|
| 질감 | 크로스해치 거친 종이 | 양피지 노이즈 |
| 텍스트 | "CHRONICLE" 각인 | "CHRONICLE" 각인 |
| 봉인 | 없음 | 원형 ✦ 봉인 + 내부 프레임 |
| 테두리 | 진영 기본색 | 진영 Named 색 |

## ⑥ 카드 상태 표현

### 건강 → 부상 → 사망

| 상태 | 시각 표현 | 적용 대상 |
|------|-----------|-----------|
| **건강** | 카드 온전 | 모든 인물 |
| **부상** | 카드 반파 + 손실 면 취소선 (예: ~~🛡~~→✕ 또는 ~~★~~→✕). 유효면 중 랜덤 | Named만 |
| **사망** | 카드 찢어짐 퇴장 애니메이션 | 모든 인물 |

> Nameless는 부상 단계 없이 즉사.

## ⑦ 스케일 해소

| 문제 | 해법 |
|------|------|
| 카드 = 개인 초상인데 다이스 = 부대 전투력 | 카드는 개인 초상, 내부적으로 다이스는 부대 규모 전투력 |
| 테오도라 다이스 1개 = ? | 테오도라 + 친위대. 카드에 명시하지 않음 |
| 보병대 다이스 1개 = ? | 보병 분대. "대" 접미사가 부대 규모 암시 |

> **규칙:** 모든 카드는 1인 초상화를 보여준다. 스케일은 세계관이 처리하고, 카드 표면에서 명시적으로 설명하지 않는다.

## ⑧ 설계 근거

**Q. 왜 Nameless/Named/Hero 3단계인가?**
이름이 없으면 기록도 없다. 이름을 얻으면 기록될 수 있다. 영웅은 기록이 완성된 자. 등급 시스템이 곧 서사 구조.

**Q. 왜 카드 표면에 등급 태그를 쓰지 않는가?**
"Nameless", "Named"는 메타 분류. 카드 표면에는 이름이 있거나 없을 뿐. 이름 유무가 등급 — 설명 불필요.

**Q. 왜 Named = 같은 병종 + 고유명인가?**
구 체계(보병→기병, 창병→기사 등)는 병종 확장 시 Named 명칭도 별도 설계 필요. 유효면→★ 규칙이면 어떤 병종이든 Named화 가능. 기사는 Named 전용 병종으로 독립 면.

**Q. 왜 패시브가 기본 보유인가?**
"병종 선택이 곧 패시브 선택." 같은 인물이 런마다 다른 빌드는 추종자가 담당한다.
