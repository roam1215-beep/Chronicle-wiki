# COMBAT-UNIT-CARD: 인물 카드 규칙 (Figure Card Rules)

> **상태:** 🧪 TC작성 · **버전:** 0.5 · **ID:** COMBAT-UNIT-CARD · **수정일:** 2026-02-28

---

## ① 한 줄 요약

전투에서 주사위를 굴리는 모든 존재는 인물 카드다. 이름이 있으면 Named, 없으면 Nameless. 이름의 유무가 곧 등급이다.

---

## ② 카드 타입 체계

| 타입 | 역할 | 예시 |
|------|------|------|
| **인물 (Figure)** | 전투에서 주사위를 굴리는 존재 | 테오도라, 앰버, 보병대, 궁병대 |
| **사건 (Event)** | 스테이지 덱 카드. 전투/비전투 사건, 우연 | 미정 |
| **기록 (Record)** | 압축 산물. 스테이지/챕터/오더 카드 | 미정 |

> 이 문서는 **인물 카드만** 다룬다. 사건/기록 카드는 별도 문서에서 정의.

---

## ③ 등급 체계: Nameless / Named / Hero

### 세 단계

| 등급 | 표면 표기 | 의미 |
|------|-----------|------|
| **Nameless (무명)** | 병종+대 (예: 보병대) | 이름 없는 부대. 피격 시 즉사 |
| **Named (유명)** | 이름/역할 (예: 테오도라 / 기사) | 이름을 가진 인물. 피격 시 부상→사망 2단계 |
| **Hero (영웅)** | 게임플레이 중 표기 없음 | 런 완료 시 오더 카드에 기록. 메타 등급 |

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **이름이 곧 등급** | 카드 표면에 "Nameless", "Named" 태그를 쓰지 않는다. 이름 유무로 판별 |
| **영웅은 되는 것** | "기록되지 않은 자들의 영웅전" — 영웅으로 시작하지 않고 영웅이 된다 |
| **★이 Named의 증표** | Named만 ★ 면을 가진다. Nameless는 ★ 없음 |

### Nameless 규칙

| 필드 | 내용 |
|------|------|
| **명칭** | 병종+대 (보병대, 궁병대, 창병대, 민병대) |
| **★ 면** | 없음 |
| **피격** | 즉사. 퍼마데스 |
| **카드 뒷면** | 거친 종이 질감, 어두운 단색, 빈 뒷면 |
| **플레이버** | 병종 공통 문구 (예: "전선의 이름 없는 방패들") |

### Named 규칙

| 필드 | 내용 |
|------|------|
| **명칭** | 이름 / 역할 (테오도라 / 기사, 앰버 / 궁병) |
| **★ 면** | 있음. 유효면(⚔ 또는 🛡) 1개가 ★으로 교체 |
| **피격** | 1회 부상(면→✕), 2회 사망. 테오도라 사망 = 게임오버 |
| **카드 뒷면** | 양피지 질감, "CHRONICLE" 각인 |
| **플레이버** | 고유 서사 문구 (예: "서자의 칼은 아직 증명되지 않았다") |

### 승급: Nameless → Named

| 필드 | 내용 |
|------|------|
| **조건** | 스테이지 운명 보상 (한정적, 귀하게) |
| **변화** | 같은 카드가 변환됨 (교체가 아님) |
| **구체적 변화** | ① "보병대" → "쟝 / 기병" ② 유효면 1개→★ (✕ 수 불변) ③ 부상 생존 획득 ④ 뒷면 변경 |

## ④ 카드 레이아웃

### 앞면

```
┌──────────────────────────┐
│                          │
│       [일러스트]          │  ① 일러스트 (상단까지 확장)
│                          │
├──────────────────────────┤
│  테오도라 / 기사           │  ② 이름/역할 또는 병종+대
│  서자의 칼은               │  ③ 플레이버 (1~2줄)
│  아직 증명되지 않았다       │
├──────────────────────────┤
│  반격                     │  ④ 패시브 슬롯 (최대 3칸)
│  🛡→⚔ 전환 (스텝6)        │     초기에는 비어있음
│                          │     스테이지 보상으로 획득
│  (빈 슬롯)                │
│  (빈 슬롯)                │
├──────────────────────────┤
│  ★ ⚔ 🛡 🛡 ✕ ✕           │  ⑤ 다이스 면 (한 줄)
└──────────────────────────┘
```

### 레이아웃 규칙

| 영역 | Named | Nameless |
|------|-------|----------|
| ① 일러스트 | 고유 인물 초상 | 대표 병사 초상 |
| ② 명칭 | 이름 / 역할 | 병종+대 |
| ③ 플레이버 | 고유 서사 | 병종 공통 문구 |
| ④ 패시브 | 스테이지 보상으로 획득 | 스테이지 보상으로 획득 |
| ⑤ 다이스 면 | ★ 포함 | ★ 없음 |

> **일러스트 규칙:** 모든 인물 카드는 1인 초상화. Named = 고유 인물, Nameless = 대표 병사.

### 뒷면

| 요소 | Nameless | Named |
|------|----------|-------|
| 질감 | 거친 종이, 어두운 단색 | 양피지 질감 |
| 텍스트 | 없음 | "CHRONICLE" 각인 |

## ⑤ 패시브 시스템

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **겪은 것이 능력이 된다** | 패시브는 캐릭터 고유가 아니라 스테이지 경험의 산물 |
| **모든 인물에 적용** | Named와 Nameless 모두 패시브 획득 가능 |
| **초기 상태 = 빈 슬롯** | 테오도라, 앰버 포함 모든 카드가 패시브 없이 시작 |

### 획득 경로

| 필드 | 내용 |
|------|------|
| **획득** | 스테이지 클리어 → 운명 달성 → 보상으로 패시브 획득 |
| **슬롯** | 카드당 최대 3개 |
| **중복** | 같은 패시브 중복 불가 |

### 병종 기본 패시브 (획득 시)

| 병종 | 패시브 | 효과 |
|------|--------|------|
| 궁병 | 선제 공격 | 선제 페이즈에서 사격한다 |
| 창병 | 반격 | 🛡 결과를 ⚔로 전환할 수 있다 (스텝6) |
| 보병 | 전열 교대 | ⚔ 결과를 🛡로 전환할 수 있다 (스텝6) |
| 민병 | (없음) | — |

> **전환 메카닉의 패시브 흡수:** 기존 보병/창병의 면 전환 규칙은 패시브로 표현된다. 패시브 미획득 상태에서는 전환 불가.

### 추가 패시브

> 미정. 스테이지 사건 설계 후 구체화.

## ⑥ 카드 상태 표현

### 건강 → 부상 → 사망

| 상태 | 시각 표현 | 적용 대상 |
|------|-----------|-----------|
| **건강** | 카드 온전 | 모든 인물 |
| **부상** | 카드 반파 + 손실 면 취소선 (예: ~~🛡~~→✕) | Named만 |
| **사망** | 카드 찢어짐 퇴장 애니메이션 | 모든 인물 |

> Nameless는 부상 단계 없이 즉사.

### 승급 연출 (Nameless → Named)

| 단계 | 연출 |
|------|------|
| 1 | 카드가 빛나며 변환 시작 |
| 2 | "보병대" → "쟝 / 기병" 명칭 변경 |
| 3 | 유효면(⚔ 또는 🛡) 하나가 ★으로 변환 |
| 4 | 카드 뒷면 거친 종이 → 양피지 + "CHRONICLE" |

## ⑦ 스케일 해소

| 문제 | 해법 |
|------|------|
| 카드 = 개인 초상인데 다이스 = 부대 전투력 | 카드는 개인 초상, 내부적으로 다이스는 부대 규모 전투력 |
| 테오도라 다이스 1개 = ? | 테오도라 + 친위대. 카드에 명시하지 않음 |
| 보병대 다이스 1개 = ? | 보병 분대. "대" 접미사가 부대 규모 암시 |

> **규칙:** 모든 카드는 1인 초상화를 보여준다. 스케일은 세계관이 처리하고, 카드 표면에서 명시적으로 설명하지 않는다.

## ⑩ 설계 근거

**Q. 왜 Nameless/Named/Hero 3단계인가?**
이름이 없으면 기록도 없다. 이름을 얻으면 기록될 수 있다. 영웅은 기록이 완성된 자. 등급 시스템이 곧 서사 구조.

**Q. 왜 카드 표면에 등급 태그를 쓰지 않는가?**
"Nameless", "Named"는 메타 분류. 카드 표면에는 이름이 있거나 없을 뿐. 이름 유무가 등급 — 설명 불필요.

**Q. 왜 패시브가 캐릭터 고유가 아니라 스테이지 보상인가?**
"겪은 것이 능력이 된다." 테오도라도 런 시작 시 빈 슬롯. 같은 인물이 런마다 다른 빌드.
