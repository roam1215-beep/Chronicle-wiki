# 인물 카드 규칙 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 능력치 5종, 다이시 테일즈식 결산, 라운드 안 결단
> 정정: 4축 결, 능력치 2종(+방어도·보호막), 자동 매커니즘

---

## 카드 속성 (5축)

```yaml
인물 카드 5축:
  진영:  지상 / 미궁 / 경계 (3종)
  종족:  인간 / 무리 (2종)
  태생:  한낮 / 여명 / 황혼 / 심야 (4종)
  위계:  인간 / 영웅 / 무리 / 재앙 (4종)
  등급:  필멸 / 반신 / 신성 / 번외 (4종, 내부 결, 노출 X)

+ 직업: 전사 / 수호자 / 사냥꾼 / 사제 (자유, 4축 무관)
```

---

## 진영-종족-태생 조합

```yaml
가능 조합 (4 자리):
  지상 + 인간 + 한낮 태생
  경계 + 인간 + 여명 태생
  경계 + 무리 + 황혼 태생
  미궁 + 무리 + 심야 태생

종족 ↔ 위계 정합:
  인간 종족: 인간 ↔ 영웅 (등극)
  무리 종족: 무리 ↔ 재앙 (등극)
  교차 X (인간 → 재앙 X)

태생의 결:
  한낮 = 지상 정통 (낮의 자리)
  여명 = 경계 인간 (낮으로 가는 결, 밤이 가시는 자리)
  황혼 = 경계 무리 (밤으로 가는 결, 낮이 지는 자리)
  심야 = 미궁 정통 (밤의 자리)

  → 경계 = 시간의 사이 (낮·밤 섞임)
  → 본인 결: "여명과 황혼 둘다 낮도 밤도 섞여있는거잖아"
```

## 능력치

```yaml
공격력:
  결: 상대 hp 직격 (하스스톤 전장식)
  변동: 시간대·가호로 출력 변동
  본인 결: "체력은 정해져 있어. 날씨대에 따라 출력이 달라짐"

체력 (hp):
  결: 인물 고유 (변동 X)
  잠정 시드 (등급 결 참고):
    필멸: 1~2
    반신: 3~4
    신성: 5~7
    번외: 10+

방어도:
  결: 감산 (숫자만큼 막음)
  부여:
    - 시작 시 (직업·가호 결로)
    - 행동 (수호자 수호 / 사제 축복)
    - 가호
  지속: 행동 = 1 라운드만 / 가호 = 영구

보호막:
  결: 이진 (어떤 피해든 1번 무효)
  희소: 쉽게 부여 X
  부여 자리: 사제 행동? 가호? (펜딩)
  지속: 1번 사용 시 1개 소멸

피해 흐름:
  적 공격 → 보호막 → 방어도 → hp
```

## 의지 주사위 수 (등급 결)

```yaml
필멸:   1개
반신:   2개
신성:   3개
번외:   4+개

주사위 ×N개:
  - 행동 ×N번 (각 주사위 독립)
  - 가호 수와 정합 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
```

---

## 가호 (5-12 후속)

```yaml
가호 수 = 등급:
  필멸 0 (가호 X)
  반신 1
  신성 2
  번외 3

가호 폭 = 위계:
  저위계 (인간·무리) = 작은 폭
  고위계 (영웅·재앙) = 큰 폭

가호 유형 = 태생 정합:
  한낮 태생 = 한낮 가호 (지상 인간)
  여명 태생 = 여명 가호 (경계 인간)
  황혼 태생 = 황혼 가호 (경계 무리)
  심야 태생 = 심야 가호 (미궁 무리)

가호 영역 (광역):
  - 기본 스탯 +N (시작 시)
  - 대성공 시 스탯 +N
  - 라운드 기반 조건부 (첫 라운드 / 라운드 진행마다)
  - 열 기반 조건부 (소속 열에 따라)
  - 공격·피격 기반 조건부 (맞을 때마다 / 때릴 때마다)

지속:
  가호 = 영구 (배틀·라운드 무관)
  대성공 행동 효과 = 1 라운드만

가호 어휘 (잠정 임시):
  한낮:   생명력 +N (방어 결)
  심야:   공격력 +N (공세 결)
  여명:   공격력 더 + 생명력 조금
  황혼:   생명력 더 + 공격력 조금
  → 실제 가호 콘텐츠 = 작가 결 (펜딩)
```

## 행동 결 (라운드 안 자동)

```yaml
유저 결단:
  매 라운드 명령 시 = 인물 배치 자유 변경 (모든 인물)
  편성 = 폐기 (파티 한 번 정해지면 쭉)

라운드 안 결단 X:
  영웅·반신·필멸 구분 = 시스템 결로 의미 X
  → 차별은 가호 결로만 (필멸 0 / 반신 1 / 신성 2 / 번외 3)
  → 호메로스 결의 라운드 안 자리 = 폐기 (작품 결로만 살아남)

직업별 자동 매커니즘 (직업종족.md 참조):
  전사: 돌격 / 격파
  수호자: 방어 / 수호
  사냥꾼: 사격 / 저격
  사제: 축복(지상) / 저주(미궁) → 축성 / 펜딩
```

## 결산식 (5-12 후속 마감)

```yaml
폐기:
  ✗ 박힌 면 × 공격력 = 공격 점수 (다이시 테일즈식)
  ✗ 박힌 면 × 방어력 = 방어 점수
  ✗ 졸전 결 ×0.5
  ✗ 변형 결 ×1.5 어휘

새 결 (하스스톤 전장식):
  공격력 = 상대 hp 직격
  격돌 = 양 진영 동시 결산 (좌→우는 자기 진영 안)
  
  굴림 결산 (개별 주사위):
    별 면 → 통상 행동 1번 (스탯대로)
    자기 시간대 면 + 자기 라운드 → 대성공 1번 (행동 변형)
    자기 시간대 면 + 반대 라운드 → 통상 행동 1번 (case 2, 깡)
    반대 시간대 면 → 실패
      격돌 직업: 수동 격돌
      원거리·사제: 행동 X
  
  우선순위: 대성공 > 통상 > 실패

피해 결:
  적 공격 → 보호막 (1번 무효) → 방어도 (감산) → hp
```

## 등극·등급 변동

```yaml
위계 (Order 클리어 시):
  인간 → 영웅 / 무리 → 재앙
  카타스테리스모스 결 (신성 X → 신적 결로 승천)
  게임 노출: 인물 카드 위계 어휘만
  태생 = 변동 X

등급 (챕터 클리어 시):
  필멸 → 반신 → 신성 → 번외
  의지 +1 + 가호 +1 (한 박자에)
  게임 노출 X (가호 결로 체감)
```

## 폐기 자리 (5-12 후속)

```yaml
✗ 능력치 5종 (공·방·속·hp·보호막)
  → 능력치 2종 (공격력·체력) + 방어도·보호막 두 자리로

✗ 방어력 능력치
  → 방어도(감산) / 보호막(이진) 분리

✗ 속도 결 (순서 점수 = 시간대 보정 + 인물 속도)
  → 좌→우 자리 결로 흡수 (자기 진영 안)
  → 양 진영 동시 결산

✗ 사거리 결 (모든 직업 1열만)
  → 사냥꾼·사제 = 후열 가능 / 자기 위치에서 가장 먼 적

✗ 라운드 안 결단 (영웅·반신 1회)
  → 모든 인물 자동 매커니즘

✗ 다이시 테일즈식 결산
  → 하스스톤 전장식

✗ 졸전 결 / 변형 결 어휘
  → 통상/대성공/실패 3단계
```

## 잠정 시드 (펜딩)

```yaml
인물 능력치 시드 = 작가 결 (다음 마디):

테오도라 (Order 1 효시):
  진영: 지상 / 종족: 인간 / 태생: 한낮
  위계: 인간 → 영웅 (Order 클리어 시)
  등급: 필멸 → 반신 → 신성 → 번외 (챕터별)
  직업: 펜딩
  공·hp: 펜딩 (시뮬 후)

발드 (라키아의 사자, Order 1 챕터 1 운명):
  진영: 미궁 / 종족: 무리 / 태생: 심야
  위계: 재앙 / 등급: 신성 또는 번외
  직업: 펜딩
  공·hp: 펜딩

도적단·토벌대 NPC: 펜딩
```
