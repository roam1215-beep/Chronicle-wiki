# 인물 카드 규칙

> 상태: 결정정합 (5-11+ 마디 박힘)

> 5-11+ 마디 정정 (전투 4.0 → 5.0):
> - 직업 3종 → 4종 (전사·수호자·사냥꾼·사제. 신관 폐기)
> - 패러미터 어휘 → 능력치 (공·방·속·hp·보호막 5종)
> - 보호막 결 박힘 (영구, 모든 인물, 시작 0)
> - 다이시 테일즈식 (면 → 행동 풀). 공·방 1택 선언 폐기.
> - 행동 5종 (격돌·사격·보호·축복·저주) + 상태 이상 결 (잠재)
> - 매 라운드 행동 선택 → 작은 AI + 영웅·반신 라운드 1회 결단
> - 실패 면 어휘 폐기 (면 비율엔 본디 없음. "실패"는 결산 상태)
> - 사거리 정정 (모든 직업 1열만 공격)
> - 직업 = 분배 비율 결 폐기 (행동 양식만, 분배는 팩션 결로)
> - 챕터 클리어 = 의지 주사위 +1 (등급 변동, 펜딩 풀림)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-11 마디 박힘 (살림):
> - 신성력 패러미터 폐기 (등급 자체가 신성 결의 그릇)
> - 인도 주사위 폐기 (의지 1종으로 합침)
> - 등급 어휘: 영웅/인간/재앙/무리 (위계) + 필멸/반신/신성/번외 (등급)
> - 위계 ↔ 등급 자유 조합 (헥토르 = 신성 인간 / 아킬레우스 = 번외 영웅)
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - 면 비율 = 팩션 결 (모든 인물 같음, 직업 결 X)

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.** 위계 + 등급 + 능력치 (공·방·속·hp·보호막) + 직업/종족 결 + 행동 풀로 차별화 박힘. 의지 주사위 1종만 굴림 — 한 굴림에 인간 결 + 신 결 합주.

## 규칙

### 능력치 5종 (5-11+ 박힘)

```yaml
공격력:
  결: 박힌 면 × 공격력 = 공격 점수 (격돌·사격 행동 시)
  0 허용: 비공격 인물 (펜딩, 사제 결 자리?)

방어력:
  결: 박힌 면 × 방어력 = 방어 점수 (격돌·수비·보호 행동 시)
  0 허용: 글래스 캐논 결 (사냥꾼 = 방어 0, 모든 팩션 공통)

속도:
  결: 순서 점수 (시간대 보정 + 인물 속도)
  결의 결: "느린 거인 / 빠른 자객" 결 표현 가능
  최소: 1

생명력 (hp):
  결: 인물 hp (별도 자원)
  등급 참고표 (잠정 시드):
    필멸: 1
    반신: 3
    신성: 5
    번외: 10
  사망: hp 0 도달. 영구 손실 (퍼마데스).

보호막 (5-11+ 박힘):
  층위:   hp 위 별도 그릇
  영구:   깎이지 않음 (감산식에 박히지만 누적만)
  시작:   0 (누적 결로 박힘)
  출처:   사건 카드 / 장비(가호) / 사제 부여
  결산:   피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp 직격
```

### 의지 주사위 수 (등급 결)

```yaml
등급 = 의지 주사위 수:
  필멸:    1개
  반신:    2개
  신성:    3개
  번외:    4+개 (보스급)

결의 결:
  "주사위가 곧 신성력이 포함된 의지 덩어리"
  → 등급 = 신성 결의 그릇 (주사위 수 = 신과 가까운 깊이)
  → 인도 주사위 별도 X. 신성력 패러미터 별도 X.
  → 한 굴림에 의지 + 신성 결 합주.

챕터 클리어 = 의지 +1 (5-11+ 박힘):
  Order 1 (3 챕터):
    챕터 1 클리어: 필멸 1 → 반신 2
    챕터 2 클리어: 반신 2 → 신성 3
    챕터 3 클리어: 신성 3 → ? (Order 결로, 펜딩)
  근거 (본인 박은 결): 챕터 클리어가 *과정*이라 등급 변동의 결이 챕터 단위와 정합 깊음.
```

### 위계 ↔ 등급 자유 조합

```yaml
위계 (게임 노출, 분류 결):
  영웅 (Heroes)
  인간 (Humans)
  재앙 (Calamity)
  무리 (Horde)

등급 (내부 결, 결의 깊이):
  필멸 / 반신 / 신성 / 번외

자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)
  아킬레우스 (영웅, 신과 관련) = 번외 영웅 (4)
  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)
  보통 영웅 = 반신·신성 영웅
  운명 보스 = 신성·번외 재앙

→ 등급 = 모든 인물에 박힘 (위계 무관)
→ 위계 = 신성 보유 결 + 시점 결 + 게임 노출 어휘
```

### 카드 자체 정보

```yaml
card_data:
  위계:           [영웅 | 인간 | 재앙 | 무리]
  등급:           [필멸 | 반신 | 신성 | 번외]
  팩션:           [지상 | 미궁 | 경계]
  직업·종족:      [전사 | 수호자 | 사냥꾼 | 사제]
  
  공격력:         int (인물별 속성, 작가 결로)
  방어력:         int (인물별 속성. 사냥꾼 = 0)
  속도:           int (인물별 속성, 최소 1)
  생명력:         int (인물별, 등급 참고표 정합)
  보호막:         int (시작 0, 누적 결로 박힘)
  
  의지 주사위 수: int (등급 결로 자동 — 필멸 1 / 반신 2 / 신성 3 / 번외 4+)

영웅·재앙만:
  덕목:           list (살아내는 결. 변주 = 인격 = 덕목 결)
  인격 변주:      enum (오더 단위)
  특수 행동 결:   인물 카드에 박힘 (변신 결 등, 펜딩)
```

### 면 비율 (팩션 결, 모든 직업 같음)

```yaml
지상:  별 3 / 경계 2 / 낮 1
미궁:  별 3 / 경계 2 / 밤 1
경계:  별 3 / 낮 1 / 밤 1 / 경계 1

→ 팩션 결만. 직업 결 X.
→ 모든 직업 = 같은 면 비율.
→ 직업 결 = 행동 양식 (행동 풀)로만 박힘.
```

### 직업 결 (4종, 5-11+ 박힘)

```yaml
전사 (1열 고정):
  행동 풀:
    별 면:        돌진 / 수비 / 측면 강타 (상태 이상)
    자기 시간대:  강타 (지상) / 야습 (미궁)
  격돌: 공·방 양쪽 살아남

수호자 (1열 고정):
  행동 풀:
    별 면:        돌진 / 수호 (아군 보호 부여)
    자기 시간대:  지상 = 수호 강화 / 미궁 = 돌진 강화
  팩션 결: 지상 = 수비 강함 / 미궁 = 공격 강함

사냥꾼 (2열 고정):
  행동 풀:
    별 면:        사격 (1열 적 직격)
    자기 시간대:  강화 사격 / 미궁 = 저주 사격
  방어 0: 글래스 캐논 (모든 팩션 공통)

사제 (2열 고정, 계통별):
  지상 사제 (인격신 결):
    별 면:        보호 / 축복
    자기 시간대:  축복 강화 / 영구 보호막
  미궁 사제 (자연신 결):
    별 면:        사격 / 저주
    자기 시간대:  저주 강화 / 변신 결 (그리스 결, 펜딩)
  경계 사제 X (희미함이 개성)

사거리 (5-11+ 정정):
  모든 직업 = 1열만 공격
  "원거리" = 후열에서 1열 박는 결
```

### 결산 결 (다이시 테일즈식, 5-11+ 박힘)

```yaml
선언 결 (단계 0, 굴림 전):
  필멸: 결단 X. 인물 카드 우선순위로 자동 (작은 AI).
  영웅·반신: 라운드당 1회 결단 (행동 1택 + 대상 1택)
  → 굴림 → 박힌 면 보고 자동 발동 (호메로스 결: 인간이 결 박고 신이 응답)

굴림 결 (단계 1):
  의지 주사위 굴림 (등급 수만큼)
  자기 시간대 라운드: 별 + 자기 시간대 면 = 박힘 4면 (67%)
  반대 시간대 라운드: 별 = 박힘 3면 (50%) + 자기 시간대 면 졸전 (×0.5 잠정)

행동 풀 결 (단계 2 — 면 종류 → 행동):
  별 면 →         직업 기본 행동 (격돌·사격·보호 등)
  자기 시간대 →  변형 행동 (강타·계통 특수)
  반대 시간대의 자기 시간대 면 → 졸전 (작게 박힘)

결산식:
  격돌: 박힌 면 × 공격력 = 공격 점수 + 박힌 면 × 방어력 = 방어 점수 (양쪽)
  사격: 박힌 면 × 공격력 = 공격 점수
  수비: 박힌 면 × 방어력 = 방어 점수
  보호: 박힌 면 × 방어력 = 대상 보호 점수
  변형 결: 강타 ×1.5 / 졸전 ×0.5 (반올림, 잠정)
  순서 점수 = 시간대 보정 + 인물 속도 (별도 결)

피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp 직격
  보호막은 깎이지 않음 (감산식에 박히지만 영구)
```

### 면 처리 (구성면 vs 결과면)

```yaml
initial:    팩션 + 직업 기본값 (면 비율 = 팩션 결)
current:    initial = current (영구 변환 자리 X, 5-7 폐기 살림)
result:     매 라운드 굴림 결과 (라운드마다 리셋)
```

### 영웅 등극 결 (펜딩)

```yaml
인간 → 영웅 등극:
  ㄱ. 위계만 변동 (인간 → 영웅)
  ㄴ. 등급 + 위계 둘 다 변동
  ㄷ. 다른 결

후보 시점 (5-11+ 펜딩):
  운명 전투 첫 클리어 시 (=발드 클리어)
  Order 클리어 시 (=별이 박히는 결, 카타스테리스모스)
  다른 결

분리된 결 (5-11+ 박힘):
  덕목 = 살아내는 결 (변동 X)
  의지 주사위 수 = 챕터 클리어로 +1 (등급 변동)
  위계 = 시나리오 단위 변동 (펜딩)
```
