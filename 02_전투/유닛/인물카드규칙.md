# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 결정정합 (5-11 마디 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE, @COMBAT-UNIT-HERO

> 5-11 마디 큰 정정:
> - 5 패러미터 → 3 패러미터 (공·방·속) + hp 별도
> - 신성력 패러미터 폐기 (등급 자체가 신성 결의 그릇)
> - 인도 주사위 폐기 (의지 1종으로 합침)
> - 등급 어휘: 영웅/인간/재앙/무리 (위계) + 필멸/반신/신성/번외 (등급)
> - 위계 ↔ 등급 자유 조합 (헥토르 = 신성 인간 / 아킬레우스 = 번외 영웅)
> - 등급 = 의지 주사위 수 (필멸 1 / 반신 2 / 신성 3 / 번외 4+)
> - 직업 5종 → 3종 (전사/사냥꾼/신관)
> - 사제 결 (방패 결산 부여) 폐기
> - 면 비율 = 팩션 결 (모든 인물 같음, 직업 결 X)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.** 위계 + 등급 + 패러미터(공·방·속) + hp + 직업/종족 결 + (영웅·재앙) 광역 사거리 결로 차별화 박힘.

## 규칙

### 패러미터 (3종 + hp 별도)

```yaml
공격력:
  결: 의지 면 박힘 시 곱셈치
  계산: 박힌 면 × 공격력 (공 선언 시) = 공격 점수
  0 허용: 비공격 인물 (펜딩, 신관 결 자리?)

방어력:
  결: 의지 면 박힘 시 곱셈치
  계산: 박힌 면 × 방어력 (방 선언 시) = 방어 점수
  0 허용: 글래스 캐논 결 (사냥꾼 = 방 0)

속도:
  결: 순서 점수 (시간대 보정 + 인물 속도)
  결의 결: "느린 거인 / 빠른 자객" 결 표현 가능
  최소: 1

생명력 (hp):
  결: 인물 hp (별도 자원, 패러미터 X)
  잠정 수치 (등급 참고표):
    필멸: 1
    반신: 3
    신성: 5
    번외: 10
  사망: hp 0 도달. 영구 손실.

신성력 폐기 (5-11):
  옛 결: 인도 결산 곱셈치
  새 결: 폐기. 등급 자체 (의지 주사위 수)가 신성 결의 그릇.
  → "주사위가 곧 신성력이 포함된 의지 덩어리"
```

### 공방속 합 (등급별 참고표)

```yaml
필멸: 합 3
반신: 합 4
신성: 합 5
번외: 합 7

→ 분배는 직업 비율로 박힘 (전사 5:3:2 / 사냥꾼 5:5)
→ 인물별 약간 변동 가능
→ 참고표일 뿐 — 작가 결로 박힘
```

### 의지 주사위 수 (등급 결, 5-11 박힘)

```yaml
등급 = 의지 주사위 수:
  필멸:    1개
  반신:    2개
  신성:    3개
  번외:    4+개 (보스급)

결의 결:
  "주사위가 곧 신성력이 포함된 의지 덩어리"
  → 등급 = 신성 결의 그릇 (주사위 수 = 신과 가까운 깊이)
  → 인도 주사위 별도 X. 신성력 패러미터 별도 X.
  → 한 굴림에 의지 + 신성 결 합주.

상세: @COMBAT-DICE-001
```

### 위계 ↔ 등급 자유 조합 (5-11 박힘)

```yaml
위계 (게임 노출, 분류 결):
  영웅 (Heroes)
  인간 (Humans)
  재앙 (Calamity)
  무리 (Horde)

등급 (내부 결, 결의 깊이):
  필멸 / 반신 / 신성 / 번외

자유 조합:
  헥토르 (인간 무용 큼) = 신성 인간 (3)
  아킬레우스 (영웅, 신과 관련) = 번외 영웅 (4)
  평민 = 필멸 인간 (1)
  잡몹 = 필멸 무리 (1)
  보통 영웅 = 반신·신성 영웅
  운명 보스 = 신성·번외 재앙

→ 등급 = 모든 인물에 박힘 (위계 무관)
→ 위계 = 신성 보유 결 + 시점 결로만
→ 인도 주사위 폐기로 위계 결의 메카닉 자리 작아짐
→ 위계 = 작품 결로 박힘 (게임 노출 어휘)

상세: @COMBAT-UNIT-HERO
```

### 카드 자체 정보

```yaml
card_data:
  위계:           [영웅 | 인간 | 재앙 | 무리]
  등급:           [필멸 | 반신 | 신성 | 번외]
  팩션:           [지상 | 미궁 | 경계]
  직업·종족:      [전사 | 사냥꾼 | 신관]
  
  공격력:         int (인물별 속성, 분배 비율 결 정합)
  방어력:         int (인물별 속성)
  속도:           int (인물별 속성, 최소 1)
  생명력:         int (인물별, 등급 참고표 정합)
  
  의지 주사위 수: int (등급 결로 자동 — 필멸 1 / 반신 2 / 신성 3 / 번외 4+)

영웅·재앙만:
  광역 사거리:    enum (펜딩 — 인물별 필살기·패턴 결)
  덕목:           list (살아내는 결. 변주 = 인격 = 덕목 결)
  인격 변주:      enum (오더 단위. @ORDER-001-CH)
```

### 면 비율 (팩션 결)

```yaml
지상:  별 3 / 경계 2 / 낮 1
미궁:  별 3 / 경계 2 / 밤 1
경계:  별 3 / 낮 1 / 밤 1 / 경계 1

→ 팩션 결만. 직업 결 X.
→ 모든 직업 = 같은 면 비율.
→ 직업 결 = 행동 양식 + 분배 비율로만 박힘.

상세: @COMBAT-DICE-001
```

### 직업 결 (3종)

```yaml
전사:    1열, 공격(1열 적), 방어(자기), 분배 5:3:2
사냥꾼:  2열, 공격(1·2열 적), 방어 X, 분배 5:5 (공·속)
신관:    1·2열 선택, 1열=전사 / 2열=사냥꾼, 분배 펜딩

상세: @COMBAT-UNIT-JOBRACE
```

### 결산 결

```yaml
선언 결 (단계 0): 공격 / 방어 1택
굴림 결 (단계 1): 의지 주사위 굴림 (등급 수만큼)
결산 결 (단계 2):
  공격 점수 = 박힌 면 × 공격력 (공 선언)
  방어 점수 = 박힌 면 × 방어력 (방 선언)
  순서 점수 = 시간대 보정 + 인물 속도

피해 = max(0, 자기 공격 - 상대 방어)
hp 깎임 = 박은 피격 순서 1번부터 (@COMBAT-STRUCT-001)

상세: @COMBAT-DICE-001
```
