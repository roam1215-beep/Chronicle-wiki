# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 결정정합 (5-9 5 패러미터 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE, @COMBAT-UNIT-HERO

> 5-9 5 패러미터 박힘:
> - 인물 카드 = 5 패러미터 (어휘 임시): 공격력 / 방어력 / 생명력 / 속도 / 신성력
> - 별도 속성: 행동 주사위 수 / 신성 주사위 수 (등급 종속)
> - 가호 결산 정정: 가호 1개 = 인물 공·방 수치 (옛 결) → *신성력*만큼 (새 결)
> - 5축 분리: 결의 결 풍부 (빠른 거인 / 느린 자객 / 강한 영웅 / 약한 무리 / 견디는 사제)
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_5패러미터_박힘.md`

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.** 5-9 5 패러미터 결로 인물별 차별화 박힘. 등급 결 (행동/신성 주사위 수) + 직업·종족 결 (행동 면 비율) + 인물 결 (5 패러미터)이 합주.

## 규칙

### 5 패러미터 (어휘 임시)

```yaml
공격력:
  결: 행동 칼 면 / 가호 공 결산 곱셈치
  계산: 칼 면 × 공격력 + 가호(공) × 신성력 = 공격 점수
  0 허용: 비공격 인물

방어력:
  결: 행동 방패 면 / 가호 방 결산 곱셈치
  계산: 방패 면 × 방어력 + 가호(방) × 신성력 = 방어 점수
  0 허용: 글래스 캐논 결

생명력 (hp):
  결: 인물 hp
  잠정 시드: 펜딩 (시뮬 후 확정)
  사망: hp 0 도달. 영구 손실.

속도:
  결: 순서 점수 (행동·신성 무관)
  계산: 순서 점수 = 시간대 보정 + 인물 속도
  결의 결: "느린 거인 / 빠른 자객" 결 표현 가능
  
신성력:
  결: 가호 결산 곱셈치
  의미: 영웅·재앙만 (무리·인간 = 0)
  계산: 가호 수 × 신성력 = 가호 점수 (공/방 1택)
  결의 결: "신성 깊은 영웅" 결 (자기 신과의 결)
```

### 별도 속성

```yaml
행동 주사위 수:
  의미: 인간 역량
  무리: 1
  인간: N (잠정 시드 펜딩)
  영웅·재앙: N (잠정 시드 펜딩)

신성 주사위 수:
  의미: 신성 깊이
  무리·인간: 0
  영웅·재앙: N (시작 시드 + 덕목 누적)
  
덕목 효과: 신성 주사위 +1 (5-9 박힘. 옛 결: ★ 추가 굴림 정정)
```

### 등급 체계 (두 축 + 5 패러미터)

```yaml
영웅 (Heroes):
  팩션:        지상·경계
  5 패러미터:  공·방·hp·속도·신성력 모두 큼 (잠정)
  행동 주사위: N (잠정)
  신성 주사위: N (시작 + 덕목 누적)
  사망:        게임 오버 (테오도라 결)

인간 (Humans):
  팩션:        지상·경계
  5 패러미터:  공·방·hp·속도 보통. 신성력 0.
  행동 주사위: N
  신성 주사위: 0
  사망:        영구 손실

재앙 (Calamity):
  팩션:        미궁
  5 패러미터:  공·방·hp·속도·신성력 모두 큼
  행동 주사위: N
  신성 주사위: N
  사망:        멸절. 운명 전투 클리어 + 영웅에 덕목 박힘.

무리 (Horde):
  팩션:        미궁
  5 패러미터:  공·방·hp 작음. 속도 작음. 신성력 0.
  행동 주사위: 1
  신성 주사위: 0
  사망:        영구 손실

상세: @COMBAT-UNIT-HERO
```

### 카드 자체 정보

```yaml
card_data:
  등급:           [영웅 | 인간 | 재앙 | 무리]
  팩션:           [지상 | 미궁 | 경계]
  직업·종족:      [A | B | C | D | E] (행동 주사위 분화 5종)
  
  공격력:         int (인물별 속성)
  방어력:         int (인물별 속성)
  생명력:         int (인물별 속성)
  속도:           int (인물별 속성)
  신성력:         int (인물별 속성. 영웅·재앙만 의미)
  
  행동 주사위 수: int (등급 종속)
  신성 주사위 수: int (영웅·재앙만)
  
영웅·재앙만:
  덕목:           list (회차 누적. 다음 회차 초기화. 신성 주사위 +1 결)
  인격 변주:      enum (오더 단위. @ORDER-001-CH)
```

```

### 신성 주사위 면 비율 (출신 종속, 영웅·재앙만)

미궁 (재앙):    밤3 / 별1 / 낮2
경계 (영웅):    펜딩

상세: @COMBAT-DICE-001
```

### 결산 결

```yaml
공격 점수 = 칼 면 × 공격력 + (가호를 공으로 끌었을 시: 가호 수 × 신성력)
방어 점수 = 방패 면 × 방어력 + (가호를 방으로 끌었을 시: 가호 수 × 신성력)
실패 면 = 무

피해 = max(0, 자기 공격 - 상대 방어)
hp 깎임 = 선언 1번 인물부터 (피해 받는 순서. @COMBAT-STRUCT-001)
```

### 순서 결산

```yaml
순서 점수 = 시간대 보정 + 인물 속도 (행동·신성 무관)

시간대 보정:
  지상 인물 + 낮 페이즈 = +2
  지상 인물 + 밤 페이즈 = 0
  미궁 인물 + 낮 페이즈 = 0
  미궁 인물 + 밤 페이즈 = +2
  경계 인물 = +1 (낮·밤 무관)

순서 = 점수 큰 쪽 먼저
동점: 같은 진영 자연 결로 동시 행동
적 사망 시: 적 결산 무화 (트로이 결)

상세: @COMBAT-STRUCT-001
```

### 폐기 항목

```yaml
- 앞면 = 산개 / 뒷면 = 밀집:    대형 폐기 (4-26)
- 뒷면 시 일제 굴림:            대형 폐기 (4-26)
- color 필드:                   색 시스템 폐기 (4-26)
- 밀집 시 구성면 변환 무시:     대형 폐기 (4-26)
- 8 특성 시스템:                5-7 폐기 → 5-9 행동 주사위 분화 5종으로 흡수
- 태그 시스템:                  5-7 폐기 (전면 재설계 대기)
- 영구 변환 자리 (교관/종자/사제 등): 5-7 폐기. 5-9 부활 X.
- [연마] / [단조] / [열화] 서브 메카닉: 5-7 폐기 (태그 시스템 의존)
- faces (⚔/🛡/★/✕):              5-7 폐기. 5-9 행동(칼/방패/실패) + 신성(시간대/별) 분리.
- atk_power / def_power 카드별 (5-5): 5-9 정정. 인물별 속성으로.
- 가호 결산 = 인물 공·방 수치 (5-9 코어): 5-9 5패러미터 마디 정정. 신성력으로.
- 패시브 시스템 (5-7):           5-9 폐기 (자동 결로 흡수 X)
- 1격사 결 (Nameless):           5-7 폐기. 모든 등급 hp 보유.
- 다이몬 결:                     5-9 폐기 (시너지·공유 효과 — 영영 안 박힐 수도)
```
