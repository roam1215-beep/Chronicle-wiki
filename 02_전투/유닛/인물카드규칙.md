# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 결정정합 (5-10 마디 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE, @COMBAT-UNIT-HERO

> 5-10 마디 박힘:
> - 어휘 정정: "가호" → "인도" (신성 결산)
> - 인도 결산 = 공·방·속도 3축 (선언 시점 = 굴림 전)
> - 행동/인도 주사위 수 = 인물별 (등급 결 X — 인물 카드에 박힘)
> - 광역 사거리 = 인물 카드에 박힘 (영웅·재앙 자리, 펜딩)
> - 직업 5종 어휘 박힘
> 상세: `DOCS/DESIGN/LOG/2026-05-10_사거리·진형·사제·인도·덕목.md`

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.** 5 패러미터 + 인물별 주사위 수 + 직업/종족 결 + (영웅·재앙) 광역 사거리 결로 차별화 박힘.

## 규칙

### 5 패러미터 (어휘 임시)

```yaml
공격력:
  결: 행동 칼 면 / 인도(공) 결산 곱셈치
  계산: 칼 면 × 공격력 + 인도(공) × 신성력 = 공격 점수
  0 허용: 비공격 인물 (사제 = 칼 0)

방어력:
  결: 행동 방패 면 / 인도(방) 결산 곱셈치
  계산: 방패 면 × 방어력 + 인도(방) × 신성력 = 방어 점수
  0 허용: 글래스 캐논 결 (사냥꾼 = 방 0)

생명력 (hp):
  결: 인물 hp
  잠정 시드: 펜딩 (시뮬 후 확정)
  사망: hp 0 도달. 영구 손실.

속도:
  결: 순서 점수 (시간대 보정 + 인물 속도 + 인도(속도) 결산)
  결의 결: "느린 거인 / 빠른 자객" 결 표현 가능
  
신성력:
  결: 인도 결산 곱셈치
  의미: 영웅·재앙만 (무리·인간 = 0)
  계산: 인도 수 × 신성력 = 인도 점수 (공·방·속도 1택)
  결의 결: "신성 깊은 영웅" 결 (자기 신과의 결)
```

### 별도 속성 (인물별 — 5-10 박힘)

```yaml
행동 주사위 수:
  결: 신과 무관한 개인 존재의 역량/그릇
  배치: 인물별 (등급 결 X)
  무리도 결 많을 수 있음 (등급 결 X)
  잠정 시드: 펜딩 (시뮬 후 확정)

인도 주사위 수:
  결: 신성 깊이
  배치: 인물별 (영웅·재앙만)
  보유 자체 = 등급 결
  덕목 ↔ 주사위 결: 펜딩 (덕목 = 살아내는 결, 챕터 클리어 = 신성 주사위 획득 계기)

광역 사거리:
  결: 인물 카드에 박힘 (영웅·재앙 자리)
  결의 결: 필살기·패턴 결 (펜딩 — 다음 마디)
  무리·인간 = 기본 광역 X
```

### 등급 체계 (5-10 정정)

```yaml
등급 결 = 신성 보유 여부 + 변동 결:
  영웅 (Heroes):    인도 보유 / 인간 → 영웅 등극 가능 (시나리오 단위)
  인간 (Humans):    인도 0 / 영웅 등극 가능
  재앙 (Calamity):  인도 보유 / 시작부터 재앙 (변동 X — 5-10 박힘)
  무리 (Horde):     인도 0 / 변동 X

5 패러미터 + 주사위 수: 모두 *인물별*
  → 등급 결로는 보통 결만 (영웅·재앙은 큰 결 / 인간·무리는 보통 결)
  → 단 결 자유 조합 가능 (행동 큰 무리 / 약한 영웅 등)

상세: @COMBAT-UNIT-HERO
```

### 카드 자체 정보

```yaml
card_data:
  등급:           [영웅 | 인간 | 재앙 | 무리]
  팩션:           [지상 | 미궁 | 경계]
  직업·종족:      [사냥꾼 | 용병 | 전사 | 수호자 | 사제]
  
  공격력:         int (인물별 속성)
  방어력:         int (인물별 속성)
  생명력:         int (인물별 속성)
  속도:           int (인물별 속성)
  신성력:         int (인물별 속성. 영웅·재앙만 의미)
  
  행동 주사위 수: int (인물별)
  인도 주사위 수: int (인물별. 영웅·재앙만)
  
영웅·재앙만:
  광역 사거리:    enum (펜딩 — 인물별 필살기·패턴 결)
  덕목:           list (살아내는 결. 변주 = 인격 = 덕목 결)
  인격 변주:      enum (오더 단위. @ORDER-001-CH)
```

### 행동 주사위 면 비율 (직업·종족 종속)

```yaml
사냥꾼:   칼4 / 방0 / 실2  + 2열 고정    + 원거리
용병:     칼3 / 방1 / 실2  + 1·2열 선택  + 위치 종속
전사:     칼2 / 방2 / 실2  + 1열 고정    + 근접
수호자:   칼1 / 방3 / 실2  + 1열 고정    + 근접
사제:     칼0 / 방4 / 실2  + 2열 고정    + 공격 X + 방패 결산 부여 결

상세: @COMBAT-UNIT-JOBRACE
```

### 인도 주사위 면 비율 (출신 종속, 영웅·재앙만)

```yaml
지상 (영웅, 인격신):    낮3 / 별1 / 밤2
미궁 (재앙, 자연신):    밤3 / 별1 / 낮2
경계 (영웅, 신앙 무관):  낮2 / 별2 / 밤2 (균등)

상세: @COMBAT-DICE-001
```

### 결산 결

```yaml
공격 점수 = 칼 면 × 공격력 + (인도를 공으로 끌었을 시: 인도 수 × 신성력)
방어 점수 = 방패 면 × 방어력 + (인도를 방으로 끌었을 시: 인도 수 × 신성력)
순서 점수 = 시간대 보정 + 인물 속도 + (인도를 속도로 끌었을 시: 인도 수 × 신성력)
실패 면 = 무

피해 = max(0, 자기 공격 - 상대 방어)
hp 깎임 = 박은 피격 순서 1번부터 (@COMBAT-STRUCT-001)
```

### 사제 결 (특수)

```yaml
방패 결산 부여:
  굴림 전 선언 단계 = 보호 대상 박음 (자기 / 다른 인물)
  방패 결산 통째로 부여 = 방패 면 × 사제 방어력 → 대상 방어 점수에 추가

상세: @COMBAT-UNIT-JOBRACE
```

### 폐기 항목

```yaml
- 앞면 = 산개 / 뒷면 = 밀집:    대형 폐기 (4-26)
- 뒷면 시 일제 굴림:            대형 폐기 (4-26)
- color 필드:                   색 시스템 폐기 (4-26)
- 밀집 시 구성면 변환 무시:     대형 폐기 (4-26)
- 8 특성 시스템:                5-7 폐기
- 태그 시스템:                  5-7 폐기
- 영구 변환 자리 (교관/종자/사제 등): 5-7 폐기. 5-9 부활 X.
- [연마] / [단조] / [열화] 서브 메카닉: 5-7 폐기
- faces (⚔/🛡/★/✕):              5-7 폐기. 5-9 행동·인도 분리.
- atk_power / def_power 카드별 (5-5): 5-9 정정 (인물별 속성)
- 가호 결산 = 인물 공·방 수치 (5-9 코어): 5-9 5패러미터 정정 (신성력으로)
- 패시브 시스템 (5-7):           5-9 폐기
- 1격사 결 (Nameless):           5-7 폐기
- 다이몬 결:                     5-9 폐기
- 가호 어휘 (신성 결산):          5-10 정정 ("인도"로)
- 가호 1택 = 공/방 (5-9):         5-10 정정 (공·방·속도 3축)
- 가호 굴림 후 선언 (5-9):        5-10 정정 (굴림 전 선언)
- 등급 종속 주사위 수 (5-9):      5-10 정정 (인물별)
```
