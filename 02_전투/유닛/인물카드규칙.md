# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 결정정합 (5-9 코어 박힘) · 의존: @COMBAT-DICE-001, @COMBAT-STRUCT-001, @COMBAT-UNIT-JOBRACE, @COMBAT-UNIT-HERO

> 5-9 정정:
> - 등급 = 두 축 (행동 주사위 수 + 신성 주사위 수)
> - 카드 데이터: faces (⚔/🛡/★/✕) → 행동 주사위 분화 5종 (직업·종족) + 신성 주사위 (영웅·재앙)
> - 공·방 = 인물별 속성 (해석 1). 카드별 X. 5-5 결 부활하지 않음.
> - hp 신규 (1격사 폐기). 모든 등급 hp 보유. 잠정 시드 펜딩.
> - 패시브 시스템 폐기 (5-7 → 5-9 흡수 X).
> - 면 영구 변환 자리 폐기 (옛 교관/종자/사제 결).
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. **각각은 인격체.** 5-9 결로 등급(두 축) + 직업·종족(행동 주사위) + 인물 속성(공·방·hp) 세 결로 박힘.

## 규칙

### 등급 체계 (두 축)

```yaml
영웅 (Heroes):
  팩션:        지상·경계
  행동 주사위: N개 (잠정. 시드 펜딩)
  신성 주사위: N개
  hp:          큼
  사망:        게임 오버 (테오도라 결)

인간 (Humans):
  팩션:        지상·경계
  행동 주사위: N개
  신성 주사위: 0
  hp:          보통
  사망:        영구 손실

재앙 (Calamity):
  팩션:        미궁
  행동 주사위: N개
  신성 주사위: N개
  hp:          큼
  사망:        운명 전투 클리어 + 영웅에 덕목 박힘

무리 (Horde):
  팩션:        미궁
  행동 주사위: 1개
  신성 주사위: 0
  hp:          작음
  사망:        영구 손실

상세: @COMBAT-UNIT-HERO
```

### 카드 자체 정보

```yaml
card_data:
  등급:           [영웅 | 인간 | 재앙 | 무리]
  팩션:           [지상 | 미궁 | 경계]
  직업·종족:      [A | B | C | D | E] (행동 주사위 분화 5종)
  행동 주사위 수: int (등급/인물 종속)
  신성 주사위 수: int (영웅·재앙만. 0 가능)
  공격력:         int (인물별 속성. 0 허용)
  방어력:         int (인물별 속성. 0 허용)
  hp:             int (잠정 펜딩)
  
영웅·재앙만:
  덕목:           list (회차 누적. 다음 회차 초기화. 신성 주사위 +1 결)
  인격 변주:      enum (오더 단위. @ORDER-001-CH)
```

### 행동 주사위 면 비율 (직업·종족 종속)

```yaml
A. 칼4 / 실2          — 사냥꾼
B. 칼3 / 방1 / 실2    — 펜딩 (콘텐츠)
C. 칼2 / 방2 / 실2    — 전사
D. 칼1 / 방3 / 실2    — 펜딩 (콘텐츠)
E. 방4 / 실2          — 사제

상세: @COMBAT-UNIT-JOBRACE
```

### 신성 주사위 면 비율 (출신 종속, 영웅·재앙만)

```yaml
지상 (영웅):    낮3 / 별1 / 밤2
미궁 (재앙):    밤3 / 별1 / 낮2
경계 (영웅):    펜딩

상세: @COMBAT-DICE-001
```

### 공·방 수치

```yaml
배치:        인물별 속성 (해석 1). 카드별 X.
잠정 시드:   펜딩 (시뮬 후 확정)
0 허용:      공격력 0 = 비전투 인물 / 방어력 0 = 글래스 캐논 결

결산:
  공격 점수 = (행동 칼 면 × 공격력) + (가호를 공으로 끌었을 시: 가호 수 × 공격력)
  방어 점수 = (행동 방패 면 × 방어력) + (가호를 방으로 끌었을 시: 가호 수 × 방어력)
  
상세: @COMBAT-DICE-001
```

### 폐기 항목

```yaml
- 앞면 = 산개 / 뒷면 = 밀집:    대형 폐기 (4-26)
- 뒷면 시 일제 굴림:            대형 폐기 (4-26)
- color 필드:                   색 시스템 폐기 (4-26)
- 밀집 시 구성면 변환 무시:     대형 폐기 (4-26)
- 8 특성 시스템:                5-7 폐기 → 5-9 행동 주사위 분화 5종으로 흡수
- 태그 시스템:                  5-7 폐기 (전면 재설계 대기)
- 영구 변환 자리 (교관/종자/사제 등): 5-7 폐기. 5-9 부활 X.
- [연마] / [단조] / [열화] 서브 메카닉: 5-7 폐기 (태그 시스템 의존)
- faces (⚔/🛡/★/✕):              5-7 폐기. 5-9 행동(칼/방패/실패) + 신성(시간대/별) 분리.
- atk_power / def_power 카드별: 5-9 정정 (인물별 속성으로)
- 패시브 시스템 (5-7):           5-9 폐기 (자동 결로 흡수 X)
- 1격사 결 (Nameless):           5-7 폐기. 모든 등급 hp 보유.
- 다이몬 결:                     5-9 폐기 (시너지·공유 효과 — 영영 안 박힐 수도)
```
