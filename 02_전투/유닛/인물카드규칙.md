# COMBAT-UNIT-CARD: 인물 카드 규칙

> 상태: 설계중 · 의존: @COMBAT-DICE-001, @SCHEMA-FIGURE

## 정의

전투에서 주사위를 굴리는 모든 존재는 인물 카드. 이름 유무가 곧 등급. **카드 1장 = 주사위 1개 = 유닛 1기.**

## 규칙

### 카드 = 유닛 = 주사위

```yaml
mapping:
  card_count: 유닛 수와 1:1
  dice_per_card: 1
  examples:
    - 보병 3기 = 보병 카드 3장 = 주사위 3개
    - 테오도라 1기 = Named 카드 1장 = 주사위 1개
```

### 등급 체계

```yaml
grades:
  nameless:
    star_face: false
    injury: 없음 (피격 = 즉사)  # @COMBAT-JUDGE-001
    trait: 없음
    atk_power: 1 (기준)
    def_power: 1 (기준)
  named:
    star_face: true
    injury: 2단계 (정상 → 부상 → 사망)
    trait: 1개 (8종 중)
    atk_power: 카드별 (TODO 분포)
    def_power: 카드별 (TODO 분포)
  knight:
    star_face: true
    injury: 2단계
    trait: 1개
    note: Named의 변형. 병종 자체가 "기사"
```

### 카드 자체 정보

```yaml
card_data:
  faces: { atk: int, def: int, star: int, null: int }   # 합 = 면 수
  power: { atk_power: int, def_power: int }              # 공/방 스칼라
  passive: enum (TODO 정합)
  trait: enum (Named 전용)
  schema: @SCHEMA-FIGURE
```

### 폐기 항목 (4-26)

```yaml
deprecated:
  - 앞면 = 산개 / 뒷면 = 밀집 # 대형 폐기
  - 뒷면 시 일제 굴림         # 대형 폐기
  - color 필드               # 색 시스템 폐기
  - 밀집 시 구성면 변환 무시  # 대형 폐기
```

### 면 정의 (구성면 vs 결과면)

```yaml
face_layers:
  initial: 병종/Named 기본값 (스키마 정의)
  current: initial + 영구 변환 (교관/종자/사제/[연마]/[단조] 등)
  result: 매 라운드 굴림 결과 (라운드마다 리셋)
  injury: current의 유효면 1개 → ✕ (전투 종료 시 current 복원)
```
