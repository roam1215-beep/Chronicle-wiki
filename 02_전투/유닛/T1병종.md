# COMBAT-UNIT-T1: Nameless 병종 (Nameless Units)

> **상태:** 🔄 설계중 · **버전:** 0.8 · **ID:** COMBAT-UNIT-T1 · **수정일:** 2026-03-01

---

## ① 한 줄 요약

5개 기본 Nameless 병종. 같은 d10 주사위 문법 위에 면 비율과 패시브로 역할이 분리된다. 패시브는 스테이지 보상으로 획득.

---

## ② 규칙 정의

### 병종별 면 구성 + 패시브

| 유닛 | d10 면 구성 | ⚔% | 🛡% | ✕% | 병종 패시브 | 패시브 효과 |
|------|------------|-----|-----|-----|-------------|-------------|
| 민병 | ⚔⚔⚔🛡🛡✕✕✕✕✕ | 30% | 20% | 50% | (없음) | — |
| 보병 | ⚔⚔⚔🛡🛡🛡✕✕✕✕ | 30% | 30% | 40% | 전열 교대 | ⚔→🛡 전환 (스텝6) |
| 창병 | 🛡🛡🛡🛡🛡🛡✕✕✕✕ | 0% | 60% | 40% | 반격 | 🛡→⚔ 전환 (스텝6) |
| 궁병 | ⚔⚔⚔⚔⚔⚔✕✕✕✕ | 60% | 0% | 40% | 선제 공격 | 선제 페이즈 사격 (스텝1) |
| 기병 | ⚔⚔⚔⚔🛡🛡✕✕✕✕ | 40% | 20% | 40% | 교란 | 적 주사위 무작위 ✕화 (스텝5) |

> **패시브 미획득 시:** 전환/반격/선제/교란 불가. 순수 주사위 굴림만.
> **패시브 획득:** 스테이지 운명 달성 보상. 슬롯 최대 3개.

### Nameless 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | 없음. Nameless는 ★을 가지지 않는다 |
| **피격** | 즉사. 퍼마데스 (부상 단계 없음) |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개 |
| **패시브 슬롯** | 최대 3개. Named와 동일 |
| **승급** | 폐기. Nameless는 Named로 승급하지 않는다 |

### 민병

| 필드 | 내용 |
|------|------|
| **역할** | 가장 약한 기본 유닛. 전선 소모품 |
| **패시브** | 없음. 순수 주사위 굴림 |
| **특징** | ✕ 5개로 빈 손 확률 50%. 유효면 50%로 최하 |

### 보병

| 필드 | 내용 |
|------|------|
| **역할** | 공방 균형. 패시브 획득 시 수비 강화 |
| **패시브: 전열 교대** | 스텝 6(대응 페이즈)에서 ⚔→🛡 일방향 전환 |
| **패시브 미획득 시** | 전환 불가. 굴린 결과 그대로 |
| **제한** | 🛡→⚔ 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(⚔)는 전환 가능 |

### 창병

| 필드 | 내용 |
|------|------|
| **역할** | 방어 특화. 패시브 획득 시 공격 전환 가능 |
| **패시브: 반격** | 스텝 6(대응 페이즈)에서 🛡→⚔ 일방향 전환 |
| **패시브 미획득 시** | 전환 불가. 🛡 6개 방어만 |
| **설계 의도** | 🛡 6개(60%)로 방어가 본업. "반격" 패시브로 필요 시 공격 전환 |
| **제한** | ⚔→🛡 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(🛡)는 전환 가능 |

### 궁병

| 필드 | 내용 |
|------|------|
| **역할** | 선제 공격. 본 전투 전에 적 전력 깎기 |
| **패시브: 선제 공격** | 낮: 선제 페이즈에서 양측 동시 사격. 본 라운드 불참 |
| **패시브 미획득 시** | 선제 사격 불가. 본 라운드에 합류 (일반 유닛처럼 굴림) |
| **밤** | 선제 없음. 본 라운드 합류 |
| **선제 사격** | 양측 동시 사격. 죽은 궁병도 사격 (화살은 날아감). 사상자 동시 적용 |

### 기병

| 필드 | 내용 |
|------|------|
| **역할** | 교란 특화. 적 주사위 결과를 무력화하여 아군 전환 판단을 지원 |
| **패시브: 교란** | 스텝 5(대응 페이즈)에서 아군 기병 생존 수만큼 적 주사위를 무작위 ✕화 |
| **패시브 미획득 시** | 교란 불가. 본 라운드에 일반 유닛처럼 굴림만 |
| **대상** | 적 주사위 전부 — ⚔, 🛡, ★ 체이닝 결과, 카드락 다이스 포함 |
| **헛발** | 이미 ✕인 주사위가 선택되면 효과 없음 |
| **밤** | 자동 처리. 무작위라 적 정보 불필요 |
| **설계 의도** | 기병 돌격이 적 진형을 흐트러뜨리는 판타지. 교란 후 보병/창병 전환 판단이 달라지는 연쇄 효과 |
| **희소성** | 기병은 고위 병종. 편성 수량 자체가 적어 밸런스 조절 |

## ⑥ 설계 근거

**Q. 왜 5병종인가?**
4병종(민/보/창/궁)이 전투 내 메카닉을 완전히 커버. 기병은 "적 면 파괴"라는 새로운 축으로 편성 다양성을 추가. 보창 쌍(면 전환) + 궁병(타이밍) + 기병(교란) + 민병(없음)으로 패시브가 전부 다른 문법.

**Q. 왜 d6에서 d10으로 바꿨나?**
d6은 면 배분 차별화 폭이 17% 단위. d10은 10% 단위로 병종 간 미세 차별화 가능. 기병(⚔4🛡2)처럼 공격 치우침+약간의 방어 같은 포지션이 d6에서는 불가능.

**Q. 왜 기병 교란이 자동인가?**
무작위 ✕화라 플레이어 판단이 필요 없음. 대신 교란 결과가 보병/창병의 스텝6 전환 판단을 바꿔주는 간접적 판단 기여.

**Q. 왜 기병 교란이 카드락을 관통하나?**
적의 카드 확정을 기병 돌격이 무력화하는 판타지. 아군 카드락은 보호(전환/리롤 불가), 적 카드락만 교란에 뚫림.

**Q. 왜 패시브가 초기 없는가?**
"겪은 것이 능력이 된다." 스테이지 1에서는 모든 유닛이 순수 주사위만 굴린다. 패시브를 얻어가며 전술 옵션이 열리는 성장 구조.

**Q. 왜 기병이 희소한가?**
교란이 기병 수만큼 발동하므로 다수 기병은 적 유효면을 과도하게 파괴. 편성 수량을 제한하여 밸런스 유지.
