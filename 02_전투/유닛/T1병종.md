# COMBAT-UNIT-T1: Nameless 병종 (Nameless Units)

> **상태:** 🔄 설계중 · **버전:** 0.7 · **ID:** COMBAT-UNIT-T1 · **수정일:** 2026-02-28

---

## ① 한 줄 요약

4개 기본 Nameless 병종. 같은 6면 주사위 문법 위에 면 비율과 패시브로 역할이 분리된다. 패시브는 스테이지 보상으로 획득.

---

## ② 규칙 정의

### 병종별 면 구성 + 패시브

| 유닛 | 면 구성 | 병종 패시브 | 패시브 효과 |
|------|---------|-------------|-------------|
| 민병대 | ⚔ ⚔ 🛡 ✕ ✕ ✕ | (없음) | — |
| 보병대 | ⚔ ⚔ 🛡 🛡 ✕ ✕ | 전열 교대 | ⚔ 결과를 🛡로 전환할 수 있다 (스텝6) |
| 창병대 | 🛡 🛡 🛡 🛡 ✕ ✕ | 반격 | 🛡 결과를 ⚔로 전환할 수 있다 (스텝6) |
| 궁병대 | ⚔ ⚔ ⚔ ⚔ ✕ ✕ | 선제 공격 | 선제 페이즈에서 사격한다 |

> **패시브 미획득 시:** 전환/반격/선제 사격 불가. 순수 주사위 굴림만.
> **패시브 획득:** 스테이지 운명 달성 보상. 슬롯 최대 3개.

### Nameless 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | 없음. Nameless는 ★을 가지지 않는다 |
| **피격** | 즉사. 퍼마데스 (부상 단계 없음) |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개 |
| **패시브 슬롯** | 최대 3개. Named와 동일 |
| **승급** | 폐기. Nameless는 Named로 승급하지 않는다 |

### 민병대

| 필드 | 내용 |
|------|------|
| **역할** | 가장 약한 기본 유닛. 전선 소모품 |
| **패시브** | 없음. 순수 주사위 굴림 |
| **특징** | ✕ 3개로 빈 손 확률 50%. 양적 열세에서 더 불리 |

### 보병대

| 필드 | 내용 |
|------|------|
| **역할** | 공방 균형. 패시브 획득 시 수비 강화 |
| **패시브: 전열 교대** | 스텝 6(대응 페이즈)에서 ⚔→🛡 일방향 전환 |
| **패시브 미획득 시** | 전환 불가. 굴린 결과 그대로 |
| **제한** | 🛡→⚔ 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(⚔)는 전환 가능 |

### 창병대

| 필드 | 내용 |
|------|------|
| **역할** | 방어 특화. 패시브 획득 시 공격 전환 가능 |
| **패시브: 반격** | 스텝 6(대응 페이즈)에서 🛡→⚔ 일방향 전환 |
| **패시브 미획득 시** | 전환 불가. 🛡 4면 방어만 |
| **설계 의도** | 🛡 4면으로 방어가 본업. "반격" 패시브로 필요 시 공격 전환 |
| **제한** | ⚔→🛡 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(🛡)는 전환 가능 |

### 궁병대

| 필드 | 내용 |
|------|------|
| **역할** | 선제 공격. 본 전투 전에 적 전력 깎기 |
| **패시브: 선제 공격** | 낮: 선제 페이즈에서 양측 동시 사격. 본 라운드 불참 |
| **패시브 미획득 시** | 선제 사격 불가. 본 라운드에 합류 (일반 유닛처럼 굴림) |
| **밤** | 선제 없음. 본 라운드 합류 |
| **선제 사격** | 양측 동시 사격. 죽은 궁병도 사격 (화살은 날아감). 사상자 동시 적용 |

## ③ 시각 자료

### 병종 타이밍 분리 (패시브 획득 후)

```
7스텝:  [1.선제사격] → [2.카드] → [3.전체굴림] → [4.리롤] → [5.지형] → [6.유닛전환] → [7.사상자]

궁병:    ████                                                                          (선제만)
보병:                   ██████████████████████████████████████   ████                   (본전투+전환⚔→🛡)
창병:                   ██████████████████████████████████████   ████                   (본전투+전환🛡→⚔)
민병:                   ██████████████████████████████████████                          (본전투만)
```

> **패시브 미획득 시:** 궁병은 본 라운드 합류, 보병은 전환 없음, 창병은 전환 없음.

### 면 비율 비교

```
민병: ⚔⚔🛡✕✕✕     공격 33% | 방어 17% | 빈손 50%
보병: ⚔⚔🛡🛡✕✕     공격 33% | 방어 33% | 빈손 33%
창병: 🛡🛡🛡🛡✕✕     공격  0% | 방어 67% | 빈손 33%  (+🛡→⚔ 전환 패시브)
궁병: ⚔⚔⚔⚔✕✕     공격 67% | 방어  0% | 빈손 33%  (+선제 패시브)
```

## ⑥ 설계 근거

**Q. 왜 4병종인가?**
최소 병종 수로 전술 공간을 최대화. 궁=선제, 보=⚔→🛡전환, 창=🛡→⚔전환, 민=없음. 하나의 문법(패시브)으로 모든 차이를 만든다.

**Q. 왜 패시브가 초기 없는가?**
"겪은 것이 능력이 된다." 스테이지 1에서는 모든 유닛이 순수 주사위만 굴린다. 패시브를 얻어가며 전술 옵션이 열리는 성장 구조.

**Q. 시뮬 데이터는?**
v6 시뮬 기준 테오도라 부대 손모율: 보병 7%, 창병 5%, 궁병 16%, 민병 19%. 창병이 가장 안전하고 궁병이 가장 위험.

**Q. T2 병종은?**
T2 병종 / Named 승급 시스템은 폐기됨. Named는 테오도라 1기만 존재. Nameless는 Named로 승급하지 않는다.
