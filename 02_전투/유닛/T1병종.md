# COMBAT-UNIT-T1: Nameless 병종 (Nameless Units)

> **상태:** 🔄 설계중 · **버전:** 0.9 · **ID:** COMBAT-UNIT-T1 · **수정일:** 2026-03-02

---

## ① 한 줄 요약

5개 기본 Nameless 병종. 같은 d10 주사위 문법 위에 면 비율과 패시브로 역할이 분리된다. 패시브는 병종당 1개 고정.

---

## ② 규칙 정의

### 병종별 면 구성 + 패시브

| 유닛 | d10 면 구성 | ⚔% | 🛡% | ✕% | 병종 패시브 | 카드 텍스트 |
|------|------------|-----|-----|-----|-------------|------------|
| 민병 | ⚔⚔⚔🛡🛡✕✕✕✕✕ | 30% | 20% | 50% | (없음) | — |
| 보병 | ⚔⚔⚔🛡🛡🛡✕✕✕✕ | 30% | 30% | 40% | 방진 | 격돌 후, 칼을 거두고 방패를 세운다. 자신의 ⚔를 🛡로 바꿀 수 있다. |
| 창병 | 🛡🛡🛡🛡🛡🛡✕✕✕✕ | 0% | 60% | 40% | 반격 | 격돌 후, 방패 뒤에서 창을 내민다. 자신의 🛡를 ⚔로 바꿀 수 있다. |
| 궁병 | ⚔⚔⚔⚔⚔⚔✕✕✕✕ | 60% | 0% | 40% | 선제 공격 | 격돌 전, 양측 궁병이 동시에 사격한다. 밤에는 발동하지 않는다. |
| 기병 | ⚔⚔⚔⚔🛡🛡✕✕✕✕ | 40% | 20% | 40% | 쇄도 | 격돌 후, 적 진형에 돌입한다. 적의 ⚔, 🛡, ★ 중 하나를 ✕로 바꾼다. |

> **패시브는 병종당 1개 고정.** 대체 패시브 없음. 민병은 영구적으로 패시브 없음.
> **패시브 미획득 시:** 전환/반격/선제/쇄도 불가. 순수 주사위 굴림만.
> **패시브 획득:** 스테이지 운명 달성 보상.

### Nameless 공통 규칙

| 필드 | 내용 |
|------|------|
| **★ 면** | 없음. Nameless는 ★을 가지지 않는다 |
| **피격** | 즉사. 퍼마데스 (부상 단계 없음) |
| **패시브 시작** | 스테이지 1 시작 시 패시브 0개 |
| **패시브** | 병종당 1개 고정. 대체 없음 |
| **승급** | 폐기. Nameless는 Named로 승급하지 않는다 |

### 편성 풀

| 필드 | 내용 |
|------|------|
| **편성 가능** | 보병, 창병, 궁병 (3종) |
| **편성 불가** | 민병 — 스테이지 중 병종 합류로만 등장 |
| **편성 불가** | 기병 — 스테이지 중 병종 합류로만 등장. 고위 병종 |

### 민병

| 필드 | 내용 |
|------|------|
| **명칭** | 민병대 |
| **역할** | 가장 약한 기본 유닛. 전선 소모품 |
| **패시브** | 없음. 영구적으로 없음 |
| **특징** | ✕ 5개로 실패 확률 50%. 편성 불가, 스테이지 합류로만 등장 |
| **플레이버** | 비정규 징집 병력. 훈련 기록 없음. / 고향으로 돌아간 자는 아직 없다. |

### 보병

| 필드 | 내용 |
|------|------|
| **명칭** | 보병대 |
| **역할** | 공방 균형. 패시브 획득 시 방어 강화 |
| **패시브: 방진** | 격돌 후, 자신이 굴린 ⚔를 🛡로 전환. 일방향 |
| **패시브 미획득 시** | 전환 불가. 굴린 결과 그대로 |
| **제한** | 🛡→⚔ 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(⚔)는 전환 가능 |
| **플레이버** | 검과 방패를 갖춘 근접 전투 병과. 전열의 중심을 맡는다. / 그저 나아갈 뿐, 물러서는 법은 배우지 못했다. |

### 창병

| 필드 | 내용 |
|------|------|
| **명칭** | 창병대 |
| **역할** | 방어 특화. 패시브 획득 시 공격 전환 가능 |
| **패시브: 반격** | 격돌 후, 자신이 굴린 🛡를 ⚔로 전환. 일방향 |
| **패시브 미획득 시** | 전환 불가. 🛡 6개 방어만 |
| **설계 의도** | 🛡 6개(60%)로 방어가 본업. "반격" 패시브로 필요 시 공격 전환 |
| **제한** | ⚔→🛡 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(🛡)는 전환 가능 |
| **플레이버** | 장창과 방패를 갖춘 대열 방어 병과. 전선 유지를 맡는다. / 창끝은 흔들려도 눈빛은 흔들리지 않는다. |

### 궁병

| 필드 | 내용 |
|------|------|
| **명칭** | 궁병대 |
| **역할** | 선제 타이밍 분리. 격돌 전에 적 전력 깎기 |
| **패시브: 선제 공격** | 격돌 전, 양측 궁병이 동시에 사격. 전원 랜덤 타겟 |
| **패시브 미획득 시** | 선제 사격 불가. 격돌에 합류 (일반 유닛처럼 굴림) |
| **밤** | 선제 없음. 격돌 합류 |
| **선제 사격** | 양측 동시 사격. 죽은 궁병도 사격 (화살은 날아감). 사상자 동시 적용 |
| **플레이버** | 활을 주무장으로 하는 사격 병과. 격돌 전 제압 사격을 맡는다. / 떨리는 손이 가리키는 것은 시위뿐이다. |

| 필드 | 내용 |
|------|------|
| **명칭** | 기병대 |
| **역할** | 쇄도 특화. 적 유효면 파괴로 아군 전환 판단을 지원 |
| **패시브: 쇄도** | 격돌 후, 적 주사위 중 ⚔/🛡/★에서만 기병 수만큼 랜덤 선택 → ✕로 변경 |
| **패시브 미획득 시** | 쇄도 불가. 격돌에서 일반 유닛처럼 굴림만 |
| **대상** | 적 주사위 중 ⚔, 🛡, ★에서만 선택. ✕는 선택 대상이 아님 (헛발 없음) |
| **카드락** | 관통. 적 카드락 주사위도 ✕화 가능 |
| **체이닝 산물** | ★ 체이닝으로 이미 확정된 ⚔/🛡는 유지. 체이닝 완료 후 남은 최종 면만 ✕화 대상 |
| **밤** | 자동 처리. 무작위라 적 정보 불필요 |
| **설계 의도** | 기병 돌격이 적 진형을 붕괴시키는 판타지. 쇄도 후 보병/창병 전환 판단이 달라지는 연쇄 효과 |
| **희소성** | 고위 병종. 편성 풀 제외, 스테이지 합류로만 등장. 물량 자체가 적어 밸런스 유지 |
| **플레이버** | 기마 돌격 병과. 적 전열 붕괴를 맡는다. / 들판에 풀린 화마와 같이, 전장을 불태운다. |

## ⑥ 설계 근거

**Q. 왜 5병종인가?**
4병종(민/보/창/궁)이 전투 내 메카닉을 완전히 커버. 기병은 "적 면 파괴"라는 새로운 축으로 편성 다양성을 추가. 보창 쌍(면 전환) + 궁병(타이밍) + 기병(쇄도) + 민병(없음)으로 패시브가 전부 다른 문법.

**Q. 왜 패시브가 병종당 1개 고정인가?**
대체 패시브를 도입하면 밸런스 복잡도가 병종 수 × 패시브 수로 폭증. 1인 개발에서 감당 불가. 병종 선택 자체가 패시브 선택이 되는 구조가 깔끔하다.

**Q. 왜 d6에서 d10으로 바꿨나?**
d6은 면 배분 차별화 폭이 17% 단위. d10은 10% 단위로 병종 간 미세 차별화 가능. 기병(⚔4🛡2)처럼 공격 치우침+약간의 방어 같은 포지션이 d6에서는 불가능.

**Q. 왜 기병 쇄도가 자동인가?**
✕를 제외한 유효면에서 무작위 선택이라 플레이어 판단이 필요 없음. 대신 쇄도 결과가 보병/창병의 방진/반격 판단을 바꿔주는 간접적 판단 기여.

**Q. 왜 기병 쇄도가 카드락을 관통하나?**
적의 카드 확정을 기병 돌격이 무력화하는 판타지. 아군 카드락은 보호(전환/리롤 불가), 적 카드락만 쇄도에 뚫림.

**Q. 왜 쇄도가 ✕를 제외하나?**
기병 돌격이 빗나가는 건 판타지에 안 맞음. 적 진형의 유효 전력을 확정적으로 붕괴시키는 것이 쇄도의 본질.

**Q. 왜 패시브가 초기 없는가?**
"겪은 것이 능력이 된다." 스테이지 1에서는 모든 유닛이 순수 주사위만 굴린다. 패시브를 얻어가며 전술 옵션이 열리는 성장 구조.

**Q. 왜 기병이 편성 풀에서 제외되나?**
쇄도가 헛발 없는 확정 면 파괴라 다수 기병은 적 전력을 과도하게 무력화. 스테이지 합류로만 등장하여 희소성 유지.
