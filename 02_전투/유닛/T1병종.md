# COMBAT-UNIT-T1: T1 병종 (Tier 1 Units)

> **상태:** 🔄 설계중 · **버전:** 0.2 · **ID:** COMBAT-UNIT-T1 · **수정일:** 2026-02-25

---

## ① 한 줄 요약

4개 기본 병종. 같은 4면 주사위 문법 위에 면 비율과 고유 메카닉으로 역할이 분리된다.

---

## ② 규칙 정의

### 병종별 면 구성 + 메카닉

| 유닛 | 면 구성 | 메카닉 |
|------|---------|--------|
| 민병대 | ⚔ ⚔ 🛡 ✕ ✕ ✕ | 없음 |
| 보병대 | ⚔ ⚔ 🛡 🛡 ✕ ✕ | ⚔→🛡 일방향 전환 |
| 창병대 | 🛡 🛡 🛡 🛡 ✕ ✕ | 🛡→⚔ 일방향 전환 (필요 시 펀치) |
| 궁병대 | ⚔ ⚔ ⚔ ⚔ ✕ ✕ | 선제 페이즈 사격, 본 라운드 불참 (밤에는 본 라운드 합류) |

### 민병대

| 필드 | 내용 |
|------|------|
| **역할** | 가장 약한 기본 유닛. 전선 소모품 |
| **메카닉** | 없음. 순수 주사위 굴림 |
| **특징** | ✕ 3개로 빈 손 확률 50%. 양적 열세에서 더 불리 |

### 보병대

| 필드 | 내용 |
|------|------|
| **역할** | 공방 균형. 전환으로 수비 강화 |
| **메카닉** | 스텝 6(유닛 전환)에서 ⚔→🛡 일방향 전환 |
| **제한** | 🛡→⚔ 역전환 불가. 카드락 다이스 전환 불가. ★ 체이닝 결과(⚔)는 전환 가능 |
| **밤** | 상대 결과 안 보이므로 감으로 전환 |

### 창병대

| 필드 | 내용 |
|------|------|
| **역할** | 방어 특화. 필요 시 공격으로 전환 |
| **메카닉** | 스텝 6(유닛 전환)에서 🛡→⚔ 일방향 전환 |
| **제한** | ⚔→🛡 역전환 불가. 카드락 다이스 전환 불가 |
| **설계 의도** | 🛡 4면으로 방어가 본업이되, 전선에 칼이 급할 때 방패를 깨서 공격력으로 전환. "필요하면 펀치" |

### 궁병대

| 필드 | 내용 |
|------|------|
| **역할** | 선제 공격. 본 전투 전에 적 전력 깎기 |
| **메카닉** | 낮: ① 선제 페이즈에서 사격. 본 라운드 불참. 밤: 선제 없음, 본 라운드 합류 (주사위 하나 더) |
| **선제 우선** | 궁병 많은 쪽 먼저 사격. 같으면 동시. 선제에서 적 궁병 사망 시 상대 선제 소멸 |

## ⑥ 설계 근거

**Q. 왜 4병종인가?**
최소 병종 수로 전술 공간을 최대화. 궁=선제, 보=⚔→🛡전환, 창=🛡→⚔전환, 민=없음. 하나의 문법(면 전환)으로 모든 차이를 만든다.

**Q. 시뮬 데이터는?**
v6 시뮬 기준 테오도라 부대 손모율: 보병 7%, 창병 5%, 궁병 16%, 민병 19%. 창병이 가장 안전하고 궁병이 가장 위험. 병종 차이가 데이터로 입증됨.
