# 사망

> 상태: 결정정합 (5-11+ 마디 박힘)

> 5-11+ 마디 정정 (전투 4.0 → 5.0):
> - 부상 단계 결 통째 폐기 (hp 단일 결로, 보호막 추가)
> - 파일명 정정: 부상사망.md → 사망.md
> - 피해 결산 정정: max(0, 공-방) → max(0, 공-(방+보호막)) → hp
> - 보호막 = 영구, 모든 인물 보유 (사건·장비·사제 부여)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-11 마디 정정:
> - hp = 별도 자원 (옛 결: 5 패러미터 생명력 → 새 결: 패러미터 X, 별도 자원)
> - hp 등급 참고표: 필멸 1 / 반신 3 / 신성 5 / 번외 10
> - 어휘 정정: "신성 주사위" → "의지 주사위 수" (인도 폐기)
> - 결산 결 정합: 의지 주사위 (1종) + 박힌 면 × 공·방 [5-11+ 정정: 행동 풀로]
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

> 5-10 마디 박힘 (살림):
> - 피격 결: 매 라운드 *변경 시에만* 선언 (디폴트 = 마지막 박은 결)
> - 1열 전멸 = 근접 공격이 2열도 닿음 (자동 진열)
> - 결 a (트로이 결) = 적 사망 시 적 결산 무화

## 정의

피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp 깎임 (5-11+ 정정). 보호막은 영구 (깎이지 X). hp 0 도달 = 사망. 모든 등급 영구 손실. 철수 없음 (퍼마데스). 피격 받는 순서 = 본인 결로 박음 (변경 시에만, 매 라운드 가능).

## 규칙

### 피해 입력 (5-11+ 정정)

```yaml
계산:        결산 결로 산출 (다이스 규칙 참고)
적용:        피해 = max(0, 자기 공격 - (상대 방어 + 보호막)) → hp 깎임
             보호막은 깎이지 않음 (감산식에 박히지만 영구)
발생 시점:   라운드 결산 단계 2
순서:        박은 피격 순서 1번부터 (5-10 정정)

결산 결 (5-11+ 박힘):
  격돌: 박힘 면 × 공격력 = 공격 점수 + 박힘 면 × 방어력 = 방어 점수 (양쪽)
  사격: 박힘 면 × 공격력 = 공격 점수
  수비: 박힘 면 × 방어력 = 방어 점수
  보호: 박힘 면 × 방어력 = 대상 보호 점수
  변형 결: 강타 ×1.5 / 졸전 ×0.5 (잠정)
  → 의지 주사위 1종 결산 (5-11 박힘) + 다이시 테일즈식 행동 풀 (5-11+ 박힘)
```

### 피격 받는 순서 (5-10 박힘 살림)

```yaml
선언:    매 라운드 변경 가능 (변경 시에만 박음)
디폴트:  마지막 박은 결 (자동)
시작:    라운드 1 = 본인 박음 (시작 자리)
적용:    적 공격 시 = 박은 순서 1번부터 hp 깎임
노출:    앞 인물 hp 0 = 다음 인물 노출

판단 자리:
  변경 결: "이번 라운드 누구를 앞에 둘지" (본인 결로)
  강한 영웅 앞 = 트로이 결 (헥토르가 앞에 섬)
  약한 인물 앞 = 희생 결
  부담 결: 매 라운드 *X*. 변경 시에만 = 부담 작음.
  
근거:
  순서 = 행동 순서 (시간대 보정 + 인물 속도)
  피격 순서 = 별개 결 (본인 결로 박음)
  → 두 결 분리. 행동 빠른 자가 반드시 앞은 아님.
```

### 1열 전멸 = 자동 진열 (5-10 박힘 살림)

```yaml
1열 전멸 시:
  근접 공격이 2열도 닿음 (자연 결)
  앞 인물 hp 0 = 뒤 인물 노출
  
근거:
  1열 = 전위 / 2열 = 후위 (진형 결)
  전위 사망 = 후위가 노출 = 자연 결
```

### 결 a (트로이 결)

```yaml
적 사망 시: 적 결산 무화
  먼저 행동한 쪽이 적 hp 0 도달시킴 → 적 굴림 결과 *적용 X*
  
결의 결:
  "내가 먼저 휘둘러 적이 *말을 못하고* 죽음" 결
  트로이 헥토르 결 (자기 자리 떠난 영웅)

호메로스 결 절충:
  적 결을 *해코지*하지는 않음 (능력으로 무력화 X)
  단 *시간이 안 닿음* = 적이 굴렸어도 휘두를 수 없음
  → 본인 박은 호메로스 결과 정합
```

### hp + 보호막 (5-11+ 정정)

```yaml
배치: 인물별 속성 (별도 자원, 능력치와 별개)

hp 등급 참고표 (5-11 박힘):
  필멸:    1
  반신:    3
  신성:    5
  번외:    10

→ 작가 결로 인물별 ±1 변동 가능
→ 위계 ↔ 등급 자유 조합 결로 박힘

보호막 (5-11+ 박힘):
  층위:    hp 위 별도 그릇
  최대치:  X / 회복: X / 영구
  결산:    피해 - (방어 + 보호막) → hp 직격. 보호막은 깎이지 X.
  출처:    사건 카드 / 장비(가호) / 사제 부여
  시작:    0 (누적 결로 박힘)

회복:
  hp:
    한 스테이지 내:    유지 (라운드 간 누적)
    스테이지 종료 후:  펜딩 (다음 스테이지 진입 시 회복? 운명 전투 후 풀 회복?)
    운명 전투 후:      풀 회복? — 펜딩
  보호막:
    회복 X (영구)
    누적만
```

### 사망 처리

```yaml
조건:        hp 0 도달
영구:        모든 등급 (퍼마데스)
카드 제거:   즉시 (런 내 영구)

위계별:
  영웅:        게임 오버 (테오도라 결)
  인간:        영구 손실
  재앙:        멸절. 운명 전투 클리어 + 미리 정한 인물에 신성 박힘.
  무리:        영구 손실
```

### 종료 조건

```yaml
victory:    적 전멸
defeat:     아군 전멸
game_over:  영웅 사망 (테오도라 사망 결)
시간 소진:  라운드 상한 도달 시 양측 생존 → 아군 패배
round_cap:  8 (잠정)
철수/도주:  X (전투 진입 시 끝까지 싸운다, 퍼마데스 전제)
```
