# 사망 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 다이시 테일즈식 결산식, 보호막 = 영구 결, 변형 결 ×1.5/×0.5, 라운드 상한 8
> 정정: 하스스톤 전장식 격돌, 보호막(이진)/방어도(감산) 분리

---

## 정의

```yaml
hp 0 도달 = 사망 (영구 손실, 퍼마데스)
철수 X (전투 진입 시 끝까지)

피해 흐름 (5-12 마감):
  적 공격 → 보호막 (1번 무효) → 방어도 (감산) → hp 직격
  
공격력 = 상대 hp 직격 (하스스톤 전장식)
방어력 능력치 = 폐기 (방어도/보호막 두 자리로 분리)
```

---

## 능력치 (5-12 정정)

```yaml
공격력:
  결: 상대 hp 직격 (하스스톤 전장식)
  변동: 시간대·가호로 출력 변동
  본인 결: "체력은 정해져 있어. 날씨대에 따라 출력이 달라지는 것 같아"

체력 (hp):
  결: 인물 고유 (변동 X)
  잠정 시드:
    필멸: 1~2
    반신: 3~4
    신성: 5~7
    번외: 10+

방어도 (감산):
  결: 숫자만큼 막음
  부여 자리:
    - 시작 시 (직업·가호 결로)
    - 행동 (수호자 수호 / 사제 축복)
    - 가호
  지속:
    행동 = 1 라운드만
    가호 = 영구

보호막 (이진, 희소):
  결: 어떤 피해든 1번 무효, 1번 사용 시 1개 소멸
  희소: 쉽게 부여 X
  부여 자리: 사제 행동? 가호? (펜딩)
  본인 결: "보호막은 희소 자원이니까 그렇게 쉽게 주지않을거야"
```

---

## 피해 결산

```yaml
피해 흐름:
  1. 적의 공격력 박힘
  2. 보호막 결산:
     보호막 ≥ 1 → 1개 소멸 + 피해 무효 (어떤 피해든)
     보호막 = 0 → 다음 단계로
  3. 방어도 결산:
     방어도 ≥ 1 → 방어도 - 피해 (감산, 0 미만 시 0)
     남은 피해 → 다음 단계
  4. hp 결산:
     hp - 남은 피해 → 0 도달 시 사망

본인 결:
  보호막 = 1번 어떤 피해든 무효 (천상의 보호막 결)
  방어도 = 숫자만큼 막음 (영웅 갑옷 결)
  우선순위: 보호막 → 방어도 → hp
```

---

## 격돌 결 (5-12 마감)

```yaml
하스스톤 전장식:
  공격력 = 상대 hp 직격
  격돌 = 양 진영 동시 결산 (페이즈 3)
  자기도 적 공격 받음 (동시)
  
사례 (테오도라 [공 2 / hp 3] ↔ 도적 [공 1 / hp 2]):
  테오도라 → 도적: 공격력 2 직격, 도적 hp 0 = 사망
  동시에 도적 → 테오도라: 공격력 1, 테오도라 hp 2
```

---

## 피격 자리

```yaml
공격 대상:
  격돌 = 적 좌측만 (모든 우리 전사가 같은 자리)
  사격 = 자기 위치에서 가장 먼 적 (열 기준)
  축복 = 우리 진영 전열 좌측
  저주 = 적 진영 전열 좌측

좌→우 순서 (격돌):
  자기 진영 안에서만
  양 진영은 동시 (페이즈 3)
  적 좌측 사망 시 = 다음 좌측

도발 자리:
  전열에서만 작동 (후열 가면 X)
  도발 ×N명 = 전열 좌측부터 좌→우 순서

배치 변경:
  매 라운드 명령 시 자유 (유저 결단)
  → 옛 결 "피격 받는 순서 = 변경 시에만" 정정
```

## 자리 변동 (전열 다 사망 시)

```yaml
조건: 전열 모두 다 사망
시점: 다음 라운드 시작
방식 (자리 ㅁ):
  후열 인물 = 자기 위치의 전열로 이동
  자기 위치 자리 X면 가장 가까운 빈 자리

전열 부분 사망 = 자리 변동 X
전열 비우는 결 X (전열 배치 필수)
```

## 회복

```yaml
hp:
  한 배틀 내:        라운드 간 누적 (회복 X)
  배틀 종료 후:      펜딩 (배틀 간 회복? 챕터 종료 시?)
  
방어도:
  행동 = 그 라운드만 (라운드 종료 시 사라짐)
  가호 = 영구
  
보호막:
  1번 사용 시 1개 소멸
  영구 누적 (소멸 X — 사용 외에는)
```

## 사망 처리

```yaml
조건:        hp 0 도달
영구:        모든 위계·등급 (퍼마데스)
카드 제거:   즉시 (런 내 영구)

위계별:
  영웅 (주연):  게임 오버 (테오도라 결)
  영웅 (조연):  영구 손실
  인간:         영구 손실
  재앙:         멸절 (적 진영, 운명 전투 클리어 시)
  무리:         영구 손실

자리 변동 결:
  전열 사망 → 후열이 다음 라운드에 전열로 (자리 ㅁ)
  전열 전체 사망 X면 변동 X
```

## 종료 조건

```yaml
victory:    적 전멸
defeat:     아군 전멸
game_over:  영웅 사망 (테오도라 결, 작품 주연)
시간 소진:  라운드 상한 도달 시 양측 생존 → 아군 패배
round_cap:  임시 5 (자연 결판 우선)
철수/도주:  X (전투 진입 시 끝까지)
```

## 폐기 자리 (5-12 후속)

```yaml
✗ 다이시 테일즈식 결산식 (박힌 면 × 공·방)
  → 하스스톤 전장식 (공격력 = 상대 hp 직격)

✗ 보호막 = 영구 결 (5-11+)
  → 보호막 = 이진 (1번 무효, 1번 사용 시 소멸)
  → 영구 결은 누적 가능 자리에만 (사용 외에는 소멸 X)

✗ 변형 결 ×1.5 / 졸전 ×0.5
  → 대성공 = 행동 종류 변형 (격파·수호·저격·축성)

✗ 방어력 능력치
  → 방어도(감산) / 보호막(이진) 두 자리로

✗ 라운드 상한 8 (잠정 5로 정정)
  → 임시 5 (자연 결판 우선)

✗ "피격 받는 순서 = 변경 시에만"
  → 매 라운드 배치 자유 변경 (유저 결단)
```
