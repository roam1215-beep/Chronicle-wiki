# 사망

## 정의

```yaml
hp 0 도달 = 영구 사망 (퍼마데스)
철수 X (전투 진입 시 끝까지)
```

## 능력치

```yaml
공격력:
  상대 hp 직격 (하스스톤 전장식)
  시간대·가호로 출력 변동

체력 (hp):
  인물 고유 (변동 X)
  배틀 단위 회복 (새 배틀 진입 = hp 풀)
  
  잠정 시드:
    필멸: 1~2 / 반신: 3~4 / 신성: 5~7 / 번외: 10+

방어도 (감산):
  부여: 시작 시 (직업·가호) / 행동 (수호·축복) / 가호
  결산: 숫자만큼 막음
  지속: 행동 = 1 라운드 / 가호 = 영구

보호막 (이진, 희소):
  결: 어떤 피해든 1번 무효, 1번 사용 시 1개 소멸
  부여: [펜딩, 희소]
```

## 피해 흐름

```yaml
적 공격 → 보호막 → 방어도 → hp

1. 보호막 ≥ 1 → 1개 소멸 + 피해 무효
2. 방어도 ≥ 1 → 감산 (방어도 - 피해, 0 미만 시 0)
3. 남은 피해 → hp 깎임

예시 (방어도 2 + 피해 5):
  방어도 2 → 0 (감산)
  남은 피해 3 → hp 3 깎임
```

## 격돌 결산

```yaml
공격력 = 상대 hp 직격
공격 대상 = 적 좌측만 (모든 우리 전사)
좌→우 순서 = 자기 진영 안에서만
양 진영 동시 (페이즈 3)

수동 격돌 (실패 면 박힌 인물):
  격돌 직업 (전사·수호자) = 자기 스탯대로 자동 반응
  원거리·사제 = 행동 X (수동도 X)

대성공 격파:
  돌격 + 양 옆 광역 (옆 X면 광역 X)
  격돌 피해는 첫 전투 대상에게만
  지속: 그 라운드만
```

## 피격 자리

```yaml
격돌:  적 전열 가장 좌측 또는 도발 대상
사격:  자기 위치 가장 먼 적 (열 기준), 후열 = 적 전열 좌측
축복:  우리 진영 전열 좌측
저주:  적 진영 전열 좌측

좌→우 순서 (격돌): 자기 진영 안에서만
대상 사망 시: 다음 좌측 또는 후열 좌측
```

## 자리 변동

```yaml
조건: 전열 모두 사망
시점: 다음 라운드 시작
방식:
  후열 인물 = 자기 위치의 전열로 이동
  자기 위치 자리 X면 가장 가까운 빈 자리

전열 부분 사망 = 자리 변동 X
전열 비우는 결 X
```

## 회복

```yaml
hp:
  한 배틀 안 = 누적 (회복 X)
  배틀 종료 → 새 배틀 진입 시 = 풀 회복

방어도:
  행동 = 그 라운드만 (라운드 종료 시 사라짐)
  가호 = 영구

보호막:
  1번 사용 시 1개 소멸
  영구 누적 (사용 외에는 소멸 X)
```

## 사망 처리

```yaml
조건:        hp 0
영구:        모든 위계·등급
카드 제거:   즉시 (런 내 영구)

위계별:
  영웅 (주연, 테오도라):  게임 오버
  영웅 (조연):             영구 손실
  인간:                    영구 손실
  재앙:                    멸절
  무리:                    영구 손실
```

## 종료

```yaml
승리:     적 전멸
패배:     아군 전멸
게임오버: 영웅 사망 (테오도라 등)
시간초과: 라운드 5 도달 시 양측 생존 → 패배
철수 X
```
