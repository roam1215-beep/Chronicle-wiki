# COMBAT-JUDGE-001: 부상 / 사망

> 상태: 결정정합 (5-9 코어 박힘) · 의존: @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-9 정정:
> - 부상 시스템 5-7 결 폐기 → hp 시스템으로 대체 (모든 등급 hp 보유)
> - 1격사 결 폐기 (5-7 결 → 5-9 모든 등급 hp 보유)
> - 사망 = 모든 등급 영구 손실
>   영웅 사망 = 게임 오버 (테오도라 사망 결)
>   인간 사망 = 영구 손실
>   재앙 사망 = 멸절 + 운명 전투 클리어 + 영웅에 덕목 박힘
>   무리 사망 = 영구 손실
> - 부상 단계 결 (정상 → 부상 → 사망 2단계) = 펜딩
>   영웅·재앙 부상 단계 vs hp 단일 결 — 다음 마디
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의

피해 = max(0, 자기 공격 - 상대 방어). hp 깎임. hp 0 도달 = 사망. 모든 등급 영구 손실. 철수 없음 (퍼마데스).


### hp

```yaml
배치:        인물별 속성 (등급별 잠정 시드)

회복:
  한 스테이지 내:    유지 (라운드 간 누적)
  스테이지 종료 후:  펜딩 (다음 스테이지 진입 시 회복? 운명 전투 후 풀 회복?)
  운명 전투 후:      풀 회복? — 펜딩

상세: @COMBAT-UNIT-CARD
```

### 사망 처리

```yaml
조건:        hp 0 도달
영구:        모든 등급 (퍼마데스)
카드 제거:   즉시 (런 내 영구)

등급별:
  영웅:        게임 오버 (테오도라 결)
  인간:        영구 손실
  재앙:        멸절. 운명 전투 클리어 + 영웅에 덕목 박힘.
  무리:        영구 손실
```
