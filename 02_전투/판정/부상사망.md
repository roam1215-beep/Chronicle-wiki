# COMBAT-JUDGE-001: 부상 / 사망

> 상태: 설계중 · 의존: @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

## 정의

Nameless 피격 = 즉사. Named 2단계 부상. 모든 손실은 영구 (퍼마데스). 철수 없음.

## 규칙

### Nameless 사상자

```yaml
nameless_casualty:
  on_hit: 즉사
  injury_state: 없음
  death: 영구 (런 내 복귀 없음)
  card_removal: 즉시 (전투 종료 후 부대에서 영구 제거)
  exception: 없음
```

### Named 2단계 부상

```yaml
named_injury:
  states: [정상, 부상, 사망]
  transition:
    정상 → 부상: 1회 피격
    부상 → 사망: 1회 피격
  injury_effect:
    target: current_face의 유효면(⚔/🛡/★) 1개
    operation: → ✕
    selection: 랜덤
  on_battle_end:
    state_restore: 부상 → 정상 (current_face 복원)
    survival: 정상 상태로 다음 전투 진입
  death:
    permanent: true
    theodora_special: 게임 오버
```

### 사망 처리

```yaml
death_processing:
  card_removal: 즉시 (런 내 영구)
  follower_effect: TODO(엔진): 추종자 슬롯에 영향이 있는지
```

### 철수 / 도주

```yaml
retreat:
  available: false
  rationale: 전투 진입 시 끝까지 싸운다 (퍼마데스 전제)
```

### 종료 조건

```yaml
battle_end:
  victory: 적 전멸
  defeat: 아군 전멸
  game_over: 테오도라 사망
  round_cap: TODO(엔진): 8라운드 / 결사 부활 후 결정
```
