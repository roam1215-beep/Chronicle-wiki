# COMBAT-JUDGE-001: 부상 / 사망

> 상태: 결정정합 (5-9 코어 + 5 패러미터 박힘) · 의존: @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-9 5 패러미터 박힘 (이번 마디):
> - hp = 5 패러미터 (생명력)로 박힘
> - 피해 받는 순서 = 매 라운드 시작 선언 (전열 → 후열)
> - 결 a (트로이 결) = 적 사망 시 적 결산 무화
> - 본인이 짚으신 "유저 선언이 의미 있어야"의 자연 자리
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_5패러미터_박힘.md`

> 5-9 코어:
> - 부상 시스템 5-7 결 폐기 → hp 시스템으로 대체 (모든 등급 hp 보유)
> - 1격사 결 폐기 (5-7 결 → 5-9 모든 등급 hp 보유)
> - 사망 = 모든 등급 영구 손실
>   영웅 사망 = 게임 오버 (테오도라 사망 결)
>   인간 사망 = 영구 손실
>   재앙 사망 = 멸절 + 운명 전투 클리어 + 영웅에 덕목 박힘
>   무리 사망 = 영구 손실
> - 부상 단계 결 (정상 → 부상 → 사망 2단계) = 펜딩

## 정의

피해 = max(0, 자기 공격 - 상대 방어). hp 깎임. hp 0 도달 = 사망. 모든 등급 영구 손실. 철수 없음 (퍼마데스). 피해 받는 순서 = 매 라운드 선언.

## 규칙

### 피해 입력

```yaml
계산:        @COMBAT-DICE-001 결산 결로 산출
적용:        피해 = max(0, 자기 공격 - 상대 방어). hp 깎임.
발생 시점:   라운드 결산 7단계 (@COMBAT-STRUCT-001)
순서:        선언 1번부터 (피해 받는 순서, 5-9 박힘)
```

### 피해 받는 순서 (5-9 박힘)

```yaml
선언:    매 라운드 시작 (전열 → 후열)
적용:    적 공격 시 = 선언 1번부터 hp 깎임
노출:    앞 인물 hp 0 = 다음 인물 노출

판단 자리:
  매 라운드 = "이번 라운드 누구를 앞에 둘지"
  강한 영웅 앞 = 트로이 결 (헥토르가 앞에 섬)
  약한 인물 앞 = 희생 결
  
근거:
  순서 = 행동 순서 (시간대 + 속도)
  선언 = 피해 받는 순서 (별개 결)
  → 두 결 분리. 행동 빠른 자가 반드시 앞은 아님.
```

### 결 a (트로이 결)

```yaml
적 사망 시: 적 결산 무화
  먼저 행동한 쪽이 적 hp 0 도달시킴 → 적 굴림 결과 *적용 X*
  
결의 결:
  "내가 먼저 휘둘러 적이 *말을 못하고* 죽음" 결
  트로이 헥토르 결 (자기 자리 떠난 영웅)

호메로스 결 절충:
  적 결을 *해코지*하지는 않음 (능력으로 무력화 X)
  단 *시간이 안 닿음* = 적이 굴렸어도 휘두를 수 없음
  → 본인 박은 호메로스 결과 정합
```

### hp

```yaml
배치: 인물별 속성 (5 패러미터: 생명력)
잠정 시드: 펜딩 (시뮬 후 확정)
영웅·재앙: 큼
인간: 보통
무리: 작음

회복:
  한 스테이지 내:    유지 (라운드 간 누적)
  스테이지 종료 후:  펜딩 (다음 스테이지 진입 시 회복? 운명 전투 후 풀 회복?)
  운명 전투 후:      풀 회복? — 펜딩

상세: @COMBAT-UNIT-CARD
```

### 사망 처리

```yaml
조건:        hp 0 도달
영구:        모든 등급 (퍼마데스)
카드 제거:   즉시 (런 내 영구)

등급별:
  영웅:        게임 오버 (테오도라 결)
  인간:        영구 손실
  재앙:        멸절. 운명 전투 클리어 + 영웅에 덕목 박힘.
  무리:        영구 손실
```

### 부상 단계 (펜딩)

```yaml
펜딩 자리:
  영웅·재앙 = 정상/부상/사망 단계 결?
  또는 hp 단일 결 (단계 X)?
  
짚어둘 자리:
  5-7 결: Named 2단계 (정상 → 부상 → 사망. 부상 = 면 1개 ✕로)
  5-9 결: hp 단일 결로 갈지 / 부상 단계 결 살릴지 펜딩
  
시뮬 후 결정.
```

### 폐기 항목

```yaml
- Named 2단계 부상 (5-7):       5-9 정정 (hp 시스템으로 대체. 단계 결 펜딩)
- Nameless 1격사 (5-7):          5-9 정정 (모든 등급 hp 보유)
- 면 1개 ✕ 변환 부상 (5-5):     5-9 폐기 (hp 결로)
- '고결한' 특성 (부상→사망 무효): 5-7 폐기 (특성 시스템 재설계)
```
