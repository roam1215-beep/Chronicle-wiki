# COMBAT-JUDGE-001: 부상 / 사망

> 상태: 결정정합 (5-11 마디 박힘) · 의존: @COMBAT-UNIT-CARD, @COMBAT-STRUCT-001

> 5-11 마디 정정:
> - hp = 별도 자원 (옛 결: 5 패러미터 생명력 → 새 결: 패러미터 X, 별도 자원)
> - hp 등급 참고표: 필멸 1 / 반신 3 / 신성 5 / 번외 10
> - 어휘 정정: "신성 주사위" → "의지 주사위 수" (인도 폐기)
> - 결산 결 정합: 의지 주사위 (1종) + 박힌 면 × 공·방
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

> 5-10 마디 박힘 (살림):
> - 피격 결: 매 라운드 *변경 시에만* 선언 (디폴트 = 마지막 박은 결)
> - 1열 전멸 = 근접 공격이 2열도 닿음 (자동 진열)
> - 결 a (트로이 결) = 적 사망 시 적 결산 무화

## 정의

피해 = max(0, 자기 공격 - 상대 방어). hp 깎임. hp 0 도달 = 사망. 모든 등급 영구 손실. 철수 없음 (퍼마데스). 피격 받는 순서 = 본인 결로 박음 (변경 시에만, 매 라운드 가능).

## 규칙

### 피해 입력

```yaml
계산:        @COMBAT-DICE-001 결산 결로 산출
적용:        피해 = max(0, 자기 공격 - 상대 방어). hp 깎임.
발생 시점:   라운드 결산 단계 2 (@COMBAT-STRUCT-001)
순서:        박은 피격 순서 1번부터 (5-10 정정)

결산 결:
  공격 점수 = 박힌 면 × 공격력 (공 선언 시)
  방어 점수 = 박힌 면 × 방어력 (방 선언 시)
  → 의지 주사위 1종 결산 (5-11 박힘)
```

### 피격 받는 순서 (5-10 박힘 살림)

```yaml
선언:    매 라운드 변경 가능 (변경 시에만 박음)
디폴트:  마지막 박은 결 (자동)
시작:    라운드 1 = 본인 박음 (시작 자리)
적용:    적 공격 시 = 박은 순서 1번부터 hp 깎임
노출:    앞 인물 hp 0 = 다음 인물 노출

판단 자리:
  변경 결: "이번 라운드 누구를 앞에 둘지" (본인 결로)
  강한 영웅 앞 = 트로이 결 (헥토르가 앞에 섬)
  약한 인물 앞 = 희생 결
  부담 결: 매 라운드 *X*. 변경 시에만 = 부담 작음.
  
근거:
  순서 = 행동 순서 (시간대 보정 + 인물 속도)
  피격 순서 = 별개 결 (본인 결로 박음)
  → 두 결 분리. 행동 빠른 자가 반드시 앞은 아님.
```

### 1열 전멸 = 자동 진열 (5-10 박힘 살림)

```yaml
1열 전멸 시:
  근접 공격이 2열도 닿음 (자연 결)
  앞 인물 hp 0 = 뒤 인물 노출
  
근거:
  1열 = 전위 / 2열 = 후위 (진형 결)
  전위 사망 = 후위가 노출 = 자연 결
  
상세: @COMBAT-STRUCT-001
```

### 결 a (트로이 결)

```yaml
적 사망 시: 적 결산 무화
  먼저 행동한 쪽이 적 hp 0 도달시킴 → 적 굴림 결과 *적용 X*
  
결의 결:
  "내가 먼저 휘둘러 적이 *말을 못하고* 죽음" 결
  트로이 헥토르 결 (자기 자리 떠난 영웅)

호메로스 결 절충:
  적 결을 *해코지*하지는 않음 (능력으로 무력화 X)
  단 *시간이 안 닿음* = 적이 굴렸어도 휘두를 수 없음
  → 본인 박은 호메로스 결과 정합
```

