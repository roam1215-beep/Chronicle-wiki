## 정의

Nameless 피격 = 즉사. Named 2단계 부상. 모든 손실은 영구 (퍼마데스). 철수 없음.

## 규칙

### Nameless 사상자

```yaml
on_hit: 즉사
injury_state: 없음
death: 영구 (런 내 복귀 없음)
card_removal: 즉시 (전투 종료 후 부대에서 영구 제거)
exception: 없음
```

### Named 2단계 부상

```yaml
states: [정상, 부상, 사망]
transition:
  정상 → 부상: 1회 피격
  부상 → 사망: 1회 피격
특성_효과: TODO(시스템) — 옛 '고결한' 특성 (부상→사망 1회 무효) 폐기. 새 결 다른 세션

injury_effect:
  target: current_face의 유효면(⚔/🛡/★) 1개
  operation: → ✕
  selection: 랜덤

발생_시점: 스텝 7 전과 (피해 적용 직후)

on_battle_end:
  state_restore: 부상 → 정상 (current_face 복원)
  survival: 정상 상태로 다음 전투 진입

death:
  permanent: true
  theodora_special: 게임 오버
```

### 사망 처리

```yaml
card_removal: 즉시 (런 내 영구)
note: 옛 추종자 슬롯 영향 자리 = 5-7 폐기 (추종자 재설계 대기)
```

### 철수 / 도주

```yaml
available: false
근거: 전투 진입 시 끝까지 싸운다 (퍼마데스 전제)
```
