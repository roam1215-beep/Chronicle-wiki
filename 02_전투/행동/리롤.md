# COMBAT-ACT-002: 지휘 / 리롤

> 상태: 완료 · 의존: @COMBAT-STRUCT-001

## 정의

지휘 = 플레이어 대면 명칭. 7스텝의 스텝 3에서 자기 주사위 1개를 다시 굴리는 개입.

## 규칙

### 스펙

```yaml
실행_스텝: 3 (전체굴림 후)
횟수: 라운드당 1회 무료
대상: 자기 주사위 1개만 (적 주사위 리롤 불가)
재리롤: 불가 (1회만)
결과: 받아들임 (좋든 나쁘든)
```

### 정합

```yaml
특성_효과:        TODO(시스템) — 옛 '현명한' 특성 폐기. 새 결 다른 세션
추종자_효과:      TODO(시스템) — 옛 추종자 시스템 폐기. 다른 세션
```

```yaml

- 8 특성 ('현명한' 추가 리롤): 5-7 폐기 (특성 재설계 대기)
```
