# COMBAT-ACT-002: 지휘 / 리롤

> 상태: 결정정합 (5-9 정합) · 의존: @COMBAT-STRUCT-001, @COMBAT-DICE-001

> 5-9 정정:
> - 7스텝 라운드 (5-5/5-8 결) 폐기. 5-9 라운드 결산 6단계 (@COMBAT-STRUCT-001)
> - 별 면 결 = 신성 주사위 재굴림 (무한). 체이닝 부활.
> - 리롤 (라운드당 1회 무료) = 5-5 결 살아남. 단 *어떤 주사위*에 적용할지 펜딩.
>   행동 주사위만 / 신성 주사위만 / 둘 다 — 결 펜딩
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의

지휘 = 플레이어 대면 명칭. 라운드 결산 1단계 (굴림) 후 자기 주사위 1개를 다시 굴리는 개입. 별 면 = 신성 주사위 재굴림 (무한). 두 결 분리.

## 규칙

### 리롤 스펙

```yaml
실행 시점:    라운드 결산 1단계 (굴림) 후
횟수:         라운드당 1회 무료
대상:         자기 주사위 1개만 (적 주사위 리롤 불가)
재리롤:       불가 (1회만)
결과:         받아들임 (좋든 나쁘든)

적용 자리 (펜딩):
  결 a. 행동 주사위만:    인간의 결 응대
  결 b. 신성 주사위만:    "신께 다시 빌어봄"
  결 c. 둘 다 가능:        가벼움. 본인 결로 결정 자리 1개 추가.
  결 d. 등급별 다름:       무리·인간 = 행동만 / 영웅·재앙 = 둘 다
```

### 별 면 재굴림 (5-9 박힘)

```yaml
조건:        신성 주사위 별 면 굴려짐
효과:        가호 박힘 (조건 무시) + 신성 주사위 1회 재굴림
연쇄:        재굴림에서 별 또 나오면 또 재굴림 (무한)
적용:        영웅·재앙만 (신성 주사위 보유 등급)

결의 결:
  별 = 영웅의 결정적 결
  재굴림 = 신이 *다시 손 얹는* 자리
  카타스테리스모스 정합 (별이 영웅을 이끄는 결)

상세: @COMBAT-DICE-001
```

### 정합

```yaml
특성 효과:        5-7 결 폐기 ('현명한' 특성 = 5-9 흡수 X)
추종자 효과:      5-7 결 폐기 (추종자 재설계 대기)
```

### 폐기

```yaml
- 일괄 리롤 (밀집 시):           산개/밀집 폐기 연쇄
- 적 주사위 리롤:                5-5 폐기 (컴팩트 단순화)
- 8 특성 ('현명한' 추가 리롤):   5-7 폐기 (특성 재설계 대기)
- 추종자 정찰병:                  5-7 폐기 (추종자 재설계 대기)
- 7스텝 라운드 (5-5/5-8):        5-9 폐기 (라운드 결산 6단계로 정정)
- ★ 정수 보정 (5-5):              5-5 폐기 → 5-9 별 면 재굴림 결로 부활
- ★ 체이닝 폐기 (5-5):            5-5 폐기 → 5-9 별 면 재굴림 결로 부활
```
