# 리롤 — 폐기 (5-12 후속 마감)

> 마감 결: 5-12 후속 마디
> 폐기: 별 면 재굴림 결, 리롤 결 통째
> 정정: 별 면 = 통상 행동의 자리로 박힘 (재굴림 X)

---

## 폐기 자리

```yaml
리롤 결 = 통째 폐기:
  ✗ 5-5: 리롤 = 라운드당 1회 무료
  ✗ 5-9: 별 면 재굴림 무한 (인도 주사위)
  ✗ 5-11 펜딩: 별 면 재굴림 자리 펜딩
  ✗ 5-12 정정: 별 면 = 통상 행동 결로 박힘 (재굴림 자리 X)

폐기 근거:
  호메로스 결 정합: 인간이 신을 다시 굴리지 X
  두 결 분리: 인간의 결단 (외부 결단) ↔ 신의 응답 (굴림)
  본인 결: "별은 통상 행동을 하긴 하는거야"
  → 별 면 = 그 자체로 행동 결 박힘 (재굴림의 결 자리 X)
```

---

## 별 면 결 (5-12 마감)

```yaml
의지 주사위 면 결:
  의지 (별):     통상 행동 1번 (스탯대로) — 어느 라운드든
  신성 (낮·밤):  자기 라운드면 대성공 / 반대 라운드면 통상
  경계:           경계 인물만 자기 시간대 (경계 라운드)에서 대성공

별 면 = 통상 행동:
  격돌·사격·축복·저주 = 직업 결로 자동 발동 (스탯대로)
  추가 효과 X (대성공의 결과만)
  재굴림 X
  
대성공의 자리:
  자기 시간대 면 + 자기 라운드 = 대성공 (행동 변형)
  격파·수호·저격·축성 결 발동
```

---

## 호메로스 결 절충

```yaml
호메로스 결 (살아남):
  인간이 결 박고 신이 응답
  외부 결단: 배치 (매 라운드 자유 변경)
  내부 응답: 굴림 결로 결과 박힘

리롤 결 X 박힌 자리:
  굴림 = 신의 결로 한 번만
  재굴림 = 신을 강제 X (호메로스 결 정합)
  
별 면의 자리:
  옛 결 (5-9): 별 = 영웅의 결정적 결로 *재굴림*
  새 결 (5-12): 별 = 통상 성공 결 박힌 자리
  → 영웅의 결정적 결 = *대성공* 자리에 박힘 (자기 시간대 면 + 자기 라운드)
  → 재굴림 결 자리 X
```

---

## 폐기 자리 통째

```yaml
- 일괄 리롤 (밀집 시):           5-5 폐기
- 적 주사위 리롤:                5-5 폐기
- 8 특성 ('현명한' 추가 리롤):   5-7 폐기
- 추종자 정찰병:                  5-7 폐기
- ★ 정수 보정 (5-5):              5-5 폐기 → 5-9 부활 → 5-12 폐기
- ★ 체이닝 폐기 (5-5):            5-5 폐기 → 5-9 부활 → 5-12 폐기
- 리롤 (라운드당 1회 무료):       5-10 폐기
- 인도 주사위 (5-10):              5-11 폐기 (의지 1종으로)
- 별 면 재굴림 무한 (5-9):        5-11 펜딩 → 5-12 폐기
- 7스텝 라운드 (5-5/5-8):        5-9 폐기
- 체이닝 (대성공 추가 굴림, 5-12 잠정):  5-12 폐기 (한 번만 굴림)
```

---

## 새 결 (5-12 후속)

```yaml
주사위 한 번만 굴림:
  매 라운드 시작 시 1회
  체이닝 X (대성공 박혀도 추가 굴림 X)
  
별 면 = 통상 행동:
  재굴림 X
  스탯대로 행동 발동 (직업 결로)

대성공 = 행동 변형:
  자기 시간대 면 + 자기 라운드 시
  격파 / 수호 / 저격 / 축성 (직업별)
  지속: 그 라운드만

본인 결:
  "한 번만 굴릴게"
  "별은 통상 행동을 하긴 하는거야"
```
