# COMBAT-ACT-002: 지휘 / 리롤

> 상태: 완료 · 의존: @COMBAT-STRUCT-001

## 정의

지휘 = 플레이어 대면 명칭. 7스텝의 스텝 3에서 자기 주사위 1개를 다시 굴리는 개입.

## 규칙

### 스펙

```yaml
실행_스텝: 3 (전체굴림 후)
횟수: 라운드당 1회 무료
대상: 자기 주사위 1개만 (적 주사위 리롤 불가)
재리롤: 불가 (1회만)
결과: 받아들임 (좋든 나쁘든)
```

### 정합

```yaml
'현명한' 특성:    리롤 1회 추가 (라운드당 총 2회). 플레이어 진영 전용 (@COMBAT-UNIT-HERO)
추종자_정찰병:    적 ★ 체이닝 리롤 효과 별도 카운트 (@META-FOLLOWER)
```

### 폐기

```yaml
- 일괄 리롤 (밀집 시):  산개/밀집 폐기 연쇄
- 적 주사위 리롤:       5-5 폐기 (컴팩트 단순화)
```
