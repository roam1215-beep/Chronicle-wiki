> - 다른 결로 부활 펜딩

## 폐기 결

```yaml
폐기 자리:
  리롤 = 라운드당 1회 무료 (5-5 결, 5-9까지 살아남)
  
폐기 근거 (5-10 박힘):
  본인 결: "리롤은 폐기하고 만들어도 나중에 다시 만들거나 할거야"
  호메로스 결 정합: 인간이 신을 다시 굴리지 X
  두 결 분리: 인간의 결산(의지) ↔ 신의 결산(별·신성 면)
  → 행동 리롤 폐기

5-11 정정:
  옛 결: 별 면 = 인도 주사위 재굴림 (무한) → 5-9 결로 살아남
  새 결: 의지 주사위 1종으로 합침. 재굴림 결 펜딩.
        → 별 면이 의지 주사위 결로 박힌 자리 = 재굴림 결 자리 X 또는 다른 결.
```

## 별 면 재굴림 (5-11 펜딩)

```yaml
옛 결 (5-9 박힘):
  조건:        인도 주사위 별 면 굴려짐
  효과:        인도 박힘 (조건 무시) + 인도 주사위 1회 재굴림
  연쇄:        재굴림에서 별 또 나오면 또 재굴림 (무한)
  적용:        영웅·재앙만 (인도 주사위 보유 등급)

5-11 정정:
  인도 주사위 폐기 → 의지 주사위 1종.
  의지 주사위 면: 의지(별) / 신성(낮·밤) / 경계 / 실패 (4종)
  
  별 면 = 의지 면 = 완전 성공 (어느 시간대든 박힘)
  → 옛 결의 "재굴림" 결 = 자리 X (의지 면 자체가 박힘 결)
  
펜딩 자리:
  ㄱ. 별 면 재굴림 결 자리 X (옛 결 폐기)
  ㄴ. 별 면 = 별도 결 (재굴림 부활)
  ㄷ. 다른 결 (예: 별 면 박히면 다음 라운드 +1 결)
  
  → 시뮬 자리에서 결 박힐 자리.
  → 본인 결로 박을 자리.

결의 결 (옛 결 살림):
  별 = 영웅의 결정적 결
  재굴림 = 신이 *다시 손 얹는* 자리
  카타스테리스모스 정합 (별이 영웅을 이끄는 결)
  → 단 의지 1종 결로는 결 자체 정정 박힐 자리.
```
