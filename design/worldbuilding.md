## 이원 구조

```yaml
이오니아:
  성격: 패권국 + 세력권
  지형: 세력권에 섬나라가 많음 (단 지상 국가도 있음)
  활동: 섬과 바다로 넓은 지역을 오감
  이념: 외인·타종족에게도 일정 권리 부여 (보편주의 패권)
  결: 아테네

도리아:
  지형: 분지 (도리아인에겐 신성한 대지)
  이념: 강자의 약자 지배는 당연. 외인·타종족 권리 반대.
        이오니아식 패권 구조에 반발.
  결: 스파르타
```

## 서로의 멸칭 — 대지의 미궁 ↔ 바다 위 새장

각 진영이 상대의 땅에 붙인 멸칭이자 인식. 실체가 아니라 시선이다.

```yaml
도리아 = "대지의 미궁" (이오니아·피지배민이 부름):
  도리아 자칭: 신성한 대지의 궁전 (분지)
  이오니아의 시선: 섬·바다로 트인 그들에겐, 분지에 갇혀 못 빠져나오는 땅의 감옥
  피지배민의 시선: 스파르타에 탄압받던 페리오이코이처럼, 못 벗어나는 땅의 미궁
  결: 갇힌 줄 알면서 못 나옴 (타르타로스 결)

이오니아 = "바다 위 새장" (도리아가 부름):
  이오니아 자칭: 황금의 도시
  도리아의 시선: 갇힌 줄도 모르고 황금 창살 속에서 노래하는 새.
    실은 도리아보다 더 막힌 내륙이면서 그걸 바다로 칠한 위선.
  결: 갇힌 줄 모르고 곱게 노래함

핵심: 둘 다 서로의 땅에 대한 멸칭일 뿐. 보는 자의 위치가 이름을 정한다.
  대지의 미궁(갇힌 줄 아는 고통) ↔ 바다 위 새장(갇힌 줄 모르는 허영)
```

(STATE·카드의 "밤 = 미궁" 표현은 이 결로 유지)

## 신앙 — 같은 4분기, 두 얼굴

같은 신·같은 질서를 인간과 무리가 다르게 본다. 4분기 구조와 타입은 공통.

```yaml
4분기 (공통 구조):
  낮:   하늘과 태양
  여명: 달과 사냥
  황혼: 화로와 그림자
  밤:   땅과 밤

인간의 신 = 인격신:
  형상·성별 있음. 하늘과 태양의 신, 화로와 그림자의 여신 …
  단 아폴론·아르테미스 같은 고유명이 아니라 직능으로 부름.
  결: 자연을 인간 형상으로 길들임 = 정복자의 신학

무리의 신 = 자연신:
  형상 없음. 화로의 여신이 아니라 화로 그 자체, 불 그 자체.
  인간에게 무관심한 자연.
  결: 길들지 않은 세계 = 선주민의 신학
```

종교적 가해: 인간의 인격신이 무리의 자연신을 덮음.
  같은 화로를 두고 한쪽은 여신을, 한쪽은 불 자체를 봄.
  영토 정복의 신학판. (미궁·가해와 같은 관점주의가 신에서 반복)

* 본질은 같은 신·같은 질서 → 무리도 같은 4분기·같은 타입 사용 (시스템 공유).
  타자화가 거짓인 이유: 완전히 다른 신이 아니라 같은 신을 다르게 볼 뿐.

## 태생 = 정치 · 종교 좌표

```yaml
낮   = 이오니아
여명 = 친이오니아 (경계)
황혼 = 친도리아 (경계)
밤   = 도리아
```

## 경계 — 양쪽 다 괴로운 주변국

```yaml
친이오니아 (여명):
  강요: 막대한 지원금·보조금 납부
  대가: 자치는 보장
  결: 델로스 동맹 공납

친도리아 (황혼):
  강요: 전쟁마다 물자 징발 + 징집·군대 차출
  결: 펠로폰네소스 동맹

요지: 어느 쪽에 붙어도 수탈. 경계 소국은 양쪽 다 고됨.
      (라키아가 바로 이 자리 — 아래)
```

## 세계사 — 불변 국면 (영웅·오더와 독립)

```yaml
# 세계사는 고정 배경. 영웅들은 이 위에서 살고 교차한다(이아손=아르고호 결).
# 국면 = 시대(불변). 어느 영웅의 어느 오더가 어느 국면에 놓이는지는 아래 '영웅과 오더'에서 배치.
# 크로니클이 오더 1은 국면2 이후 3 시작 전의 시기이다

국면 1: 이오니아 위주 패권 질서 (페리클레스 느낌)
국면 2: 이오니아 ↔ 도리아 전쟁 → 도리아 위주 패권 형성 (펠로폰네소스 느낌)  ← 테오도라 오더1 무대
국면 3: 도리아 패권 종식 (테베 에파미논다스·펠로피다스, 레우크트라 전투 느낌)
국면 4: 도리아·이오니아 쇠퇴기 틈에 외부 세력 재침공
국면 5+: [펜딩 — 미확정]
```

## 영웅과 오더 (세계사 위에서)

```yaml
# 영웅 = 세계사를 사는 인물. 한 인물 = 여러 오더(개인 순번, 같은 편으로 관통). 영웅들이 국면 위에서 교차.

테오도라:
  오더1 "미궁의 테오도라" (국면2 — 도리아 패권기):
    라키아 = 도리아권 속국 (라코니아 분지로 가는 길목). 종족·문화는 이오니아도 도리아도 아닌 경계인.
    이오니아에겐 적국 취급, 도리아에겐 만만한 속국·억압받는 백성.
    모레아 골짜기를 휩쓴 도적단·무리의 잇단 습격과 그 뒤의 흑막(발드)에 맞섬 → 미궁 반격의 효시.
    ※ 오더1은 모레아 골짜기 안에서 완결.
  오더2·3 = 펜딩 (테오도라 개인 오더, 놓일 국면 미정)

다른 영웅 = 펜딩 (각자 오더1부터, 다른 국면에 놓일 수 있음)
```

## 라키아 — 테오도라의 고향

```yaml
지명: 라키아 (국가명 자체)
위치: 라코니아 분지(도리아 내륙)로 가는 길목의 경계 소국
정치: 도리아권 속국 — 지형·역사상 도리아에 속해옴 (분지 관문이라 도리아가 안 놓음). 전시 물자 징발 + 병력 차출
처지: 이오니아엔 적국 취급(도리아권 입구라 치려면 먼저 밟힘), 도리아엔 만만한 속국
      → 양쪽에서 수탈당하나 어느 편도 라키아 편이 아닌 이중 피해자
      + 흑막 발드가 도적단·무리를 부려 교란하는 무대 (서사 = narrative_ssot §4)
종족: 경계인 (이오니아인도 도리아인도 아닌 별개 인간)
지역:
  모레아 — 라키아인이 사는 골짜기(산악) 지형. 테오도라의 동네. 험준해 군인·사냥꾼을 배출.
    역설: 칼리돈의 도적·짐승 탓에 치안이 나빠 도리아 지배가 덜 닿았음 (방치 = 착취 덜함).
          그 위협이 다 걷히면 오히려 도리아 압제가 들어오는 역설 → 이후 세계사 국면(도리아 변동기)으로. (오더1은 모레아 안에서 완결)
  칼리돈 — 모레아 인근의 숲. 라키아 영토 경계 안이나 누구의 관할도 아닌 미개발 야생.
            무리(선주민) 서식. 사냥꾼·약초꾼·도망자가 깃듦. 위험해 사람들이 잘 다니지 않음.
패잔병 유입 경로: 칼리돈 숲 (발드 일당이 토착 도적단과 합류해 은거)
```

## 발드 — 오더1 흑막 [B]

> 서사 결·역할·보스 배치 = narrative_ssot.md §4 (정본). 여기선 세계 토대와의 접점만.

```yaml
원형: 오노다 히로오 (종전 30년 뒤까지 게릴라).
정체: 종전 모르는 이오니아 낙오병 (이오니아-도리아 전쟁 도리아 승리 후 탈주).
세계 접점: 만만한 라키아(경계 약자)만 노림 = 경계 소국 수탈 구조의 또 한 겹.
※ 발드 = 낱개 단일 흑막. 도적단·무리 양쪽을 뒤에서 부린 원흉, 정의 챕터3 전용.
   옛 '무모/교활/위선 3가면·거울상'·'챕터1 보스'·'선견대 프리키온' 폐기 → narrative_ssot §4.
```

## 종족 — 무리(선주민)와 인간(정복자)

```yaml
무리: 이 세계 땅의 선주민. 원래 주인.
  결: 스파르타 이전 라코니아·메세니아 정주민 (헤일로타이)
  ※ 외부에서 온 이민족이 아님. 정반대 — 애초에 이 땅에 살던 자들, 인간이 아니라 비인간(정령,마물 등).

인간: 나중에 들어온 정복자 · 정착민.
  이오니아인 · 도리아인 · 경계인(라키아 포함) — 모두 인간.
```

### 정복의 두 방식 — 억압(도리아) vs 기만(이오니아)

```yaml
도리아 (억압적):
  무리 땅에 들어와 그들을 노예로 부리고 혹사
  무리의 처지: 노예 · 농민 · 수탈 대상 · 군인(최하층)
  방식: 노골적 예속

이오니아 (기만적):
  수도 이명: 황금의 도시
  무리가 당연히 주인이던 땅에서, 그들에게 거주·생활 명목 세금을 물림
  → 못 내면 추방 또는 노예 전락
  방식: 원주민을 외지인 취급하며 권리를 주는 척 돈으로 옥죔.
        도리아보다 음습하고 기만적.
```

### 진실과 인식 — 가려진 가해

```yaml
사실: 무리에게 인간은 땅을 빼앗고 짓밟은 침략자. 이는 진실이다.
인식: 그러나 도리아 · 이오니아를 포함한 세계의 인간들은
      그렇게 알고 있지 않다.
      (자기를 정당한 주인으로 믿거나, 가해를 모르거나 왜곡함)

→ 가해자가 가해를 인지하지 못하는 구조 (정착민 식민주의 결).
→ 테오도라(라키아 · 인간)조차 인간 측 시점 안에서 출발하는 한계가 깔림.
   양쪽 패권을 거부하더라도 이 맹점에서 자유롭지 않음.
```


## 인격 = 가능세계 (메타 구조)

```yaml
인격: 각 인물은 용기 · 지혜 · 정의 세 갈래. 각 인격 = 닫힌 가능세계 하나.
  같은 사건도 인격에 따라 다르게 풀림 (사건은 인격의 함수).
  예: 용감한 테오도라 = 옳다 믿는 길을 정면돌파 /
      지혜로운 테오도라 = 자신에게 유리한 쪽으로

기계적 실체: 인격이 바뀌면 직업이 바뀌고 카드풀도 다름.
  → 인격이 은유가 아니라 실제 다른 메커닉의 세계.
  (직업 · 카드풀 정의는 시스템 정본 — STATE / cards.md)

정사: 세 갈래 중 가장 이상적 흐름이 '정사처럼' 느껴짐 (테오도라 = 정의).
  외적 정전 지정은 안 함 — 그럴듯한 가능성들을 보여줄 뿐.

캠페인: 각 플레이 = 독립된 한 판 (로그라이크 한 런 = 하나의 생애).
  끝나면 닫힘. 미련 누적 X. 무게는 정전이 아니라 '한 판의 완결성'에서.

오더 간 연속: 한 인물의 오더들은 같은 편으로 관통(용맹 오더1→용맹 오더2). 편끼리 안 섞임.
  편 3 × 오더로 엮인 실타래. (다른 인물·무리 주인공 오더도 예정 — 시점 전환)

장르: 판타지 플루타르크 영웅전.
  인격 중심(누구냐) + 병렬 비교(분기 대조). 단 영웅의 한계까지 그림
  (주인공도 가해 맹점에서 자유롭지 않음) — 단순 고전 재현과 가르는 칼.
```
