# 세계 — 미궁 세계

> 작품 측면. specs/ X. 미궁 세계의 정치·종교·역사 골격.

## 진영 3종

```yaml
지상 (낮):
  종족: 인간만
  태생: 낮
  신앙: 인격신 (그리스 올림포스)
  자기 시간대: 낮

미궁 (밤):
  종족: 무리만
  태생: 밤
  신앙: 자연신
  자기 시간대: 밤

경계:
  종족: 인간 + 무리 둘 다
  태생: 여명(인간) + 황혼(무리)
  자기 시간대: 경계
  신앙: 일정 X / 떠돌이
```

## 종족 ↔ 위계 정합

```yaml
인간 종족: 인간 ↔ 영웅 (Order 클리어 시 등극)
무리 종족: 무리 ↔ 재앙 (시작부터 또는 변동)
교차 X (인간 → 재앙 X / 무리 → 영웅 X)
```

## 태생

```yaml
낮 = 지상 정통
여명 = 경계 인간 (낮으로 가는 방향, 밤이 가시는 시점)
황혼 = 경계 무리 (밤으로 가는 방향, 낮이 지는 시점)
밤 = 미궁 정통

경계 = 시간의 사이 (낮·밤 섞임)
```

## Order 1 무대 — 섬 정치

```yaml
형태: 섬, 다수 도시국가
공통 조건: 모두 미궁의 속국
거짓 평형: 각 도시국가가 다른 도시국가에 "우리는 굴복 안 했다" 거짓
평형 작동: 능동 모의 X. 각자 거짓이 우연히 상호 지탱
```

### 이쪽 도시국가 — 표면

```yaml
공헌제:
  매년 1회, 남 5 + 여 5 = 10명
  선발: 추천제, 능력 우수 명목
  실제 경향: 사생아, 권력 다툼에서 밀려난 자
  의식 명목: 미궁 도전, 성스러운 영웅 행위

주신:
  거대한 소 대가리 = 미궁 우두머리 (가짜 이름)
  (테세우스 결: 미노타우로스 흡수)

미궁 입구 수비대:
  출입 통제, 퇴로 봉쇄, 도망자 살해·은폐

금은보화 행사:
  공헌 1달 후 미궁발 도착
  "용사 전리품"으로 위장
  실제 정체: 미궁의 분할통치 매수
```

### 이쪽 도시국가 — 심층 (100년 전)

```yaml
미궁 토착, 도시국가 후발

첫 멸망 위기:
  미궁에 의한
  위기 직전 도시국가 통치자 일부 배신, 지도자 암살·찬탈
  
휴전 체결: 굴욕적
  진짜 조항: 미궁 우두머리를 도시 주신으로 섬김
  부수 결과: 진짜 여신 신앙 말살

진짜 여신: 1 (이름 펜딩)
후예 정의: 신봉자 자손(인간) + 혈통 일부
후예 일부: 말살 시기 미궁으로 도주, 100년 경과
```

### 미궁 = 지하 도시 국가

```yaml
종족: 토착 무리
비대 요인: 100년간 위쪽 모든 도시국가에서 인적 자원 누적
정치 형태: 협상 가능한 정치 단위
외교 전략: 분할통치 (금은보화로 위쪽 각 도시국가 거짓 보강)
```

### 미궁 입구 도시 (경계 폴리스)

```yaml
위치: 미궁 진입부, 지하 첫 도시
행사: 도전자 환대 연회
수단: 음식·술에 수면제, 잠든 자 그대로 납치 → 노예
환대자: 미궁 시민 (도전자와 같은 종족)
도전자 인지: "전초 도시"로 오인, "괴물은 더 안쪽"으로 자기조립
```

### 미궁 안의 망명 공동체

```yaml

```
