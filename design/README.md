# design/ — 작품·설계 의도

> claude.ai 기획 보조용. 클로드 코드는 평소 안 읽음.

## 원칙

```yaml
- 결정의 의도·이유·맥락이 들어가는 곳
- 비결정론적 내용도 OK (시적 표현·서사·디자인 메모)
- specs/ 의 명세가 *왜 그런지*를 보존
- 어휘·작품 일관성 유지
```

## 파일

```yaml
narrative.md:     서사 (인물·어머니·검 동기 등)
worldbuilding.md: 세계 (진영·종족·태생·미궁의 정체)
ui_flow.md:       UI·UX (도서관·책 펼침 등)
```

## 작품 핵심

```yaml
사서 프레임:
  사서 = 플레이어
  책 = 영웅 이야기 (Order 단위)
  도서관 = Order 컬렉션
  Order 클리어 = 별이 됨 (카타스테리스모스)

인격:
  같은 인물, 다른 가능세계
  그리스 4주덕 (지혜·용기·절제·정의)
  인물 = 3 보유 + 1 빠짐. 빠진 것 = 정체성
  같은 장면도 인격마다 다른 결로 그려짐

시점 교차:
  Order = 같은 세계 다른 단면
  영감: 워크3 RoC + Frozen Throne, 플루타르크 영웅전
  여러 영웅 누적 = 시리즈 = 밤하늘

작품 윤리:
  공적 발화 = 진실 (객관 진실 X, 여러 시점의 합 + 발화)
```
