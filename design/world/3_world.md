# 크로니클 — 세계 (World)

> **`0_premise`·`1_powers`·`2_faith` 위에 선다(world/ 토대 3문서).** 토대가 "세계가 무엇을 믿고 어떻게 생겼나"를 잡았다면, 이 문서는 그 위에 선 **지리·시대·인물(Character) 구조의 무대 사전**이다. (회귀·코어루프 = 작품 구조 층, `design/` 직속)
> 세력의 성격 / 신앙·4분기 / 무리의 정체 = world 토대가 정본. 회귀 = `3_return`. 여기선 베끼지 않고 **포인터만** 건다(미러 금지).
> 고유명사는 `[작명 대기]`. 단 **모레아·테오도라·키레네아**는 확정 유지(첫 무대·주인공·자매).

---

## 1. 구획 — 토대 / 무대

이 문서는 두 층을 잇는 자리다.

```
[토대]  공용 (world/ 1~3)            — 세력·신앙·무리·회귀. 특정 영웅(Character) 없음.
[무대]  영웅별 (이 문서 §3~)          — 세계사 국면·지리·미궁의 테오도라 무대. 영웅(Character) 늘면 칸 추가.
```

시뮬·생성기가 읽는 무대 사전 = **이 문서 + world/ 1~3**.

---

## 2. 두 패권의 땅

세력의 이념·모델·관계 = `1_powers` §1·§2 (정본). 여기선 **지형**만.

```yaml
낮의 땅:
  지형: 바다에 면한 항구 도시. 섬과 해상로로 넓게 뻗는 해양 세력.
밤의 땅:
  지형: 산으로 둘러싸인 반도. 험준한 내륙 분지가 중심이다.

세계 통칭: [작명 대기]   # 세계 전체를 부르는 이름
바다:     [작명 대기]   # 별도 이름
```

---

## 3. 세계사 — 불변 국면

시대는 고정 배경이다. 영웅들은 이 위에서 살고 교차한다. 국면 = 불변, 어느 영웅(Character)이 어느 국면에 놓이는지만 배치된다.

```yaml
국면 1: 낮 위주 패권 질서            (페리클레스기)
국면 2: 낮↔밤 전쟁 → 밤 패권 형성    (펠로폰네소스 전쟁기)   ← 미궁의 테오도라
국면 3: 밤 패권 종식                 (레우크트라 전후)
국면 4: 양 패권 쇠퇴기, 외부 세력 재침공
국면 5+: [펜딩 — 미확정]

미궁의 테오도라 = 국면2 (밤 패권기), 국면3 시작 전.
```

> "절정이 곧 균열"(밤이 이긴 그 순간부터 곪음) = `1_powers` §2. 국면2→3 전환의 정체가 그 부패다.
> 더 깊은 바닥 — 국면 전환(추수 후 새 씨) = `2_faith` §1.

## 4. 영웅과 인물(Character) 구조

```yaml
영웅 = 세계사를 사는 인물. 한 영웅 = 하나의 Character (270 = 용기·지혜·정의 3 Book — structure §위계).
  세 편은 독립된 가능세계로 안 섞인다 (3_return §5). 여러 영웅(Character)이 국면 위에서 교차한다.

테오도라:
  Character "미궁의 테오도라" (국면2) — 모레아 골짜기 안에서 완결 (§5).
다른 영웅 = [펜딩] (각자 별개 Character, 다른 국면·다른 시점).
# 한 영웅 = 한 Character로 완결. 같은 인물이 다른 작품에 나와도 별개 Character로 다룬다 (시즌·연작 구조 아님).
```

> 세 인격(용기·지혜·정의) = 닫힌 가능세계 셋 = `3_return` §5 (정본). 인격이 바뀌면 직업·카드풀이 바뀐다 = `specs/cards.md`.
> 장르 = 판타지 플루타르크 영웅전 — 누구냐(인격) × 병렬 비교(분기 대조). 단 영웅의 가해 맹점까지 그린다.

> **가해 맹점:** 인간은 자기를 정당한 주인으로 믿거나 가해를 모른다. 테오도라(인간)조차 인간 측 시점에서 출발하는 한계를 깐다 — 양 패권을 거부해도 이 맹점에서 자유롭지 않다. (무리가 왜 피해자인가 = `2_faith` §4)

---

## 5. 모레아 — 미궁의 테오도라 무대

```yaml
모레아 (확정):
  위상: 밤(승자) 진영의 위성 (= 1_powers §3). 산악 골짜기 소국.
  지형: 험준한 산골. 그래서 군인·사냥꾼을 배출한다.
  처지: 밤에 물자·병력을 바치는 속국. 양 패권 어디도 모레아 편이 아닌 약자.
        (경계 위성의 수탈 구조 = 1_powers §3 + 2_faith §2)
  치안 역설:
    험준함과 인근 야생의 위협 탓에 밤의 지배가 깊이 닿지 못한다 (방치 = 착취 덜함).
    그 위협이 걷히면 도리어 밤의 압제가 들어온다 — 이후 국면(밤 변동기)의 씨앗.
    (미궁의 테오도라는 모레아 안에서 완결)

숲 [작명 대기]:
  모레아 인근의 야생 — 누구의 관할도 아닌 미개발 지대. 사냥꾼·약초꾼·도망자가 깃든다.
  무리의 서식지이자 위험한 자들이 은거하는 자리.
  ※ 무리의 정체·서식은 2_faith §4 소관(재구축 중).
```

> 옛 상위 속국(라키아)·옛 숲 이름(칼리돈) 폐기. 모레아를 **밤 위성 소국 단위로 단순화** — `1_powers` §3이 "모레아 골짜기 = 위성"이라 직접 잡으므로 그 정본을 따른다.
