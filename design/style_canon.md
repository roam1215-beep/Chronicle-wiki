# 스타일 캐논 — 양식 · 톤 · 화법 · 검증

> 모든 생성·집필이 따르는 통일 기준. tools/stoa-factory 시제품에서 검증된 규칙을 정본화(2026-06-03).
> 카드 스키마 = specs/cards.md / 인격 함수 = design/story_arc.md / 세계관 = design/worldbuilding.md.
> 이 문서는 "어떻게 쓰는가(양식·톤)"와 "통과 기준(검증)"을 정의한다.

## 1. 카드 텍스트 3조각의 의존성 (★핵심)

```yaml
desc   = 사실 (객관). 상황 서술만. 감상·1인칭·가치판단·미사여구 금지.
         좋음: "대지의 여신의 사당이 관리되지 않은 채 방치되어 있다."
         나쁨: "안타깝게도 신성한 사당이 슬프게 버려져 있다."
quote  = 주관. 사건 × 인물 × 오더 × 인격에 의존. 인격마다 반드시 다름.
         (드물게 대상 자체의 말일 수도.)
flavor = 톤 (Chronicle 공용). 전승 카드 필드.
         ※ 기록 카드(battle/event/chance/fate)엔 flavor 필드 없음 — desc·quote만. (cards.md 정본)

※ 같은 모티프라도 인격마다 다른 카드가 된다 (예: "버려진 여신상" → 용기=대지 신상 / 지혜=태양 신상).
  desc는 '어떤 사실을 만나는가'가 인격별로 달라도 어조는 항상 객관.
  quote는 '같은 사실을 어떻게 보는가'가 인격별로 갈림.
```

## 2. 톤 — 철(작가)이 손수 쓴 전승 카드 flavor 기준

```
실제 예시 (이 결을 따른다):
- "라키아의 희망, 미래, 골칫거리기도 한 친구들입니다"
- "단단하기로 유명한 라키아 중장 보병, 자존심만큼이나 방패도 단단하다"
- "칼리돈 숲의 주인이자 골칫거리"
- "라키아인 신병, 지금은 풋내기일 뿐이지만 미래는 알 수 없다"
- "통행자와 행상인의 걱정거리로, 다리 위의 악독한 협상가인 그들에게 타협은 없다"

규칙:
- 간결하게. 한 문장 위주. 만연체·장황함 금지.
- 과하게 비장·심각하지 마라. 가벼운 위트·여유·약간의 농담조 환영.
- 지명·고유명사 구체적으로(라키아·모레아·칼리돈). 추상 미사여구 금지.
- 한 대상의 양면을 같이 보는 시선("희망이자 골칫거리").
- 단 desc는 위 중 '간결·구체·객관' 면만 — 감상·위트는 quote로.
```

## 3. 인격 화법 (느낌만)

```yaml
용기: 마음이 먼저 정해진 사람의 목소리.
지혜: 한 발 떨어져 보는 목소리, 약간의 냉소.
정의: 곁(타인)을 향하는 목소리.

원칙: 성격·태도이지 문장 형식이 아니다. 길이·어미·구문을 지정하지 마라.
      억지 구별보다 자연스러움 우선. (상세 = story_arc.md 인격 함수)
```

## 4. 검증 rubric (독 게이트)

```yaml
# 품질은 '정의 불가'다 — 규칙 위반만 검사한다. "백지보다 나은가"가 효용 바닥선.

[기계]      스키마:     cost 0~7·kind 유효·등급 상한 (카드). 린터 100%, 사람 0.
[기계+판단]  desc 객관:   1인칭·감상어 1차 기계 플래그 / 진짜 객관인지 판단.
[기계+판단]  quote 분화:  인격별 quote 유사도 기계 플래그 / 인격 함수·화법 묻어나는지 판단.
[판단·agy]  캐논 정합:   세계관 사실과 모순 없음 (이오니아≠분지, 발드=위선 등).
[판단·agy]  톤:         §2 위반(과장·현대어·비장 과잉·이모지) 없음.
[취향·철]   효용:       "이 초안을 고쳐 쓰는 게 백지보다 빠른가." 표본만, 전수 X.

운영 원칙:
- 기계가 잡는 건 사람이 재검사하지 않는다.
- 통과율 미달 시 *출력*을 손보지 말고 *씨앗*(이 문서·story_arc·생성기 SYSTEM)을 고친다.
  출력은 버리는 것, 씨앗은 자산. 씨앗 한 줄 = 이후 전체 개선.
- agy = 읽기 전용 검수(캐논·톤 게이트 플래그). 쓰기 금지.
```
