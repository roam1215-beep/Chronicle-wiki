## 한 스테이지 = 하나의 운명 = 하나의 페이지

```yaml
스테이지 = 주인공 생애의 한 마디 = 하나의 운명을 향해 가는 한 판 = 완성하면 한 페이지.
  페이지(그림) = 그 새벽(그 마디)의 한 타임라인. 절반은 고정(운명), 절반은 매번 다름(선택).
  오더 = 챕터의 모음, 챕터 = 페이지(스테이지)의 모음 → 한 인물의 일대기.

판 구성:
  선택 페이즈: 운명에 닿기까지의 시간 슬롯들 (잠정 3). 각 슬롯에서 카드 3장 중 하나를 고른다.
  운명: 맨 끝, 반드시 마주하는 그 마디의 죽음. 무엇을 고르든 닿는다 (0_premise §5 "필연").

운명 = 그 마디의 정해진 죽음 (테마 안):
  스테이지 = 하나의 테마 (예: "산골짜기의 기습"). 무엇을 고르든 그 끝의 죽음에 닿는다 (0_premise §5 "필연").
  default 죽음 1장 = 회귀 전 주인공이 실제로 맞은 죽음 = 원형. 미리 쓴 원본이자 되돌릴 대상 (structure §죽음 모델).
  회귀 후 죽음 = 매번 다르게 흘러간다 — 구성 방식도 결론도 그때그때 다르다.
    게임오버 순간의 상태(운명전 갈래·부족 능력치·소진 지점)를 서사로 렌더한다 (미리 안 씀 — structure).
    → 같은 테마, 매번 다른 죽음. 단 옛 '미리 쓴 4종 뽑기'가 아니라 상태 기반 렌더 (다양성이 더 넓다).
  # 각 인격의 default 죽음 = 그 덕목의 과잉 (용기=만용 / 지혜=과한 회피 / 정의=과한 헌신 — 3_return).
```

## 카드 = 그 시각의 행동 (타임라인의 토막)

```yaml
카드는 유닛·자원이 아니라 '그 시점에 할 수 있는 행동'이다.
  한 페이즈 = 한 시간 슬롯 (예: 새벽 2시 반). 그 시각에 가능한 행동 여러 개가 뜬다.
  플레이어는 그중 하나를 골라 자기 타임라인을 한 칸 잇는다.
  (예: 새벽 2시 반 → "옆집 노인을 깨운다 / 광장으로 가 성화를 켠다 / 키레네아를 깨워 북문으로")

고른 행동들이 모여 = "그 새벽 주인공이 보낸 하나의 타임라인" = 한 페이지.
못 고른 행동 = 그 길로 가지 않은 것 (시간은 하나뿐 — 한 곳을 향하면 나머지를 등진다).

작가는 슬롯마다 행동 토막을 여러 개 준비해 둔다 (로그라이크 — 풀이 그림보다 크다).
  한 런은 그중 일부만 만난다. 다음 런은 다른 조합 → 같은 운명, 다른 새벽.

두 종류 (판정 규칙 = dice.md):
  확정형 — 굴리지 않음, 결과 정해짐 (안전·확실, 토대 쌓기).
  변동형 — 굴림, '요구면' 있음 (도박: 충족=상 / 미달=벌). 무엇으로 굴리는지(힘·민첩·지혜) 아이콘 표시.
  능력치는 풀·셔플 설계에서 고루 나오게 한다 (한 능력치만 파면 가린 운명전에서 독 — dice.md §운명전). 페이즈 조합은 고정 X: 기본 변동·변동·확정, 드물게 ordeal이 변동 한 자리.

## 선택 — 잘못된 선택은 없다

```yaml
모든 행동은 합리적이다. 정답·함정 구조가 아니다 (공략 외우기 = 비극이 퀴즈가 됨, 거부).
  어느 것도 틀리지 않았다 — 다만 다른 대가, 다른 밤으로 이어진다.
  (0_premise §1 "누구도 구원이 아니었다" — 옳은 답이 없어, 무엇을 포기할지만 고른다.)

인간이라 일관되게 고르지 못한다 — 한 슬롯은 가족을, 다음 슬롯은 마을을 향할 수 있다.
  그 흔들림이 곧 그 회차의 인물됨이다.

# 페이즈 수·슬롯당 행동 수 = 미정. Stage 그릇(9 결정 + 1 운명) = specs/structure.md.
#   TODO(프로토): 3선택+1운명이 맞는지 / 슬롯당 몇 개를 띄울지 = 한 판 돌려야 보임.
```

## 인과 — 고른 것이 운명전을 빚는다

```yaml
선택은 그 자리에서 끝나지 않는다 — 나비효과로 운명전까지 굴러온다.
  고른 것 = 운명을 맞이할 때 내가 쥔 것 / 등진 것 = 그때 내게 없는 것.
  (예: 키레네아를 깨워 북문 → 운명전에서 곁에 키레네아가 있다. 대신 마을의 조력은 없다.
       성화를 켬 → 마을은 깨어나지만 도적도 불빛을 본다 — 경보이자 표적, 양날.)

두 층 (전부 묶지 않는다 — 설계 폭발 경계):
  ① 즉시 정산 (대부분): 그 자리에서 무게가 보인다. 사람을 구하면 곁에 선다.
  ② 나비효과 (소수·핵심): 그 밤엔 결과를 모른다. 종을 안 울린 대가가 운명전에서 증원으로 온다.
     "죽어봐야 아는" 긴장의 핵 — 한 스테이지에 두셋이면 족하다.

핵심: 선택은 운명전의 전력을 ±하는 게 아니라, 운명전의 '판(성격)'을 바꾼다.
  → "다른 종류의 밤" (## 운명전).
인과 짝(고름→흔적)은 작가가 토막마다 미리 박는다.
  # 작성량 큼 — 토막마다 흔적을 설계해야 함. ①에 무게를 분산하고 ②를 아껴 쓴다.
```

## 운명전 — 내역을 가린 베팅

> 굴림의 규칙 = `dice.md §운명전`. 여기선 운명전의 성격만.

```yaml
이 운명을 무엇으로 감당할지 고른다 = 두 격:
  스테이지 운명: 3갈래(힘/민첩 · 민첩/지혜 · 힘/지혜) 중 택1 — 내 패에 맞는 길을 고른다.
  챕터 운명(3·6·9): 힘·민첩·지혜를 모두 — 피할 약점이 없는 무거운 시험.
  가림은 '내역'에만: 어느 능력치를·도합 몇인지는 보이되, 각 몇 개인지는 가린다.
  → 내역을 모른 채 들어선다 = "운명은 가늠할 수 없다" (일반 사건은 요구가 보이나, 운명 앞에선 흐릿하다 — 주제의 구현).
    한 능력치만 판 빌드는 챕터 운명에서 막힌다 (분산 압박).

고른 운명을, 주사위를 나눠 던지며 탐색해 채운다:
  앞 페이즈에서 쌓은 모든 것이 판돈 — 고른 ordeal이 운명 require를 빚고 내역을 깐다(포석·fate_pull), 동료가 주사위를 늘리고, 건강이 깎였으면 위태롭다.
  → 적은 밖에서 오지 않는다. 내 선택이 운명의 무게를 정한다 (앞 선택이 클라이맥스에서 회수됨).

종료:
  생존 → 능력치를 다 채움. 운명-죽음 카드가 운명-생존으로 뒤집힌다 (## 수집).
  사망 → 주사위 예산 소진 + 미충족 / 건강 0 → 회귀.

운 = 양념이지 주재료 아님. 합리적으로 골라도 모르고 헛걸면 무너질 수 있다(=운명) — 단 드물고 무겁게.
```

## 회귀 — 못 바꾸는 운명을 다르게 겪음

> 회귀의 서사·세계관 의미(여신의 되돌림·기원=죽음·시지프스·세 인격) = `3_return`. 여기선 게임 작동만.

```yaml
죽음 = 끝이 아니라 루프의 마디. 운명의 바대로 죽으면 그 새벽으로 되돌아와, 다시 타임라인을 짠다.
  (퍼마데스 아님 — 죽음이 종료가 아니라 회귀의 마디. 화로의 여신이 꺼진 불씨를 다시 지핀다 = 2_faith §3.)

무엇이 바뀌고 무엇이 안 바뀌나 (3_return §6·§7):
  바뀜   = 개인 불행. 다르게 골라 그 새벽을 넘긴다(운명전을 이긴다) — 미시 희극, 플레이가 헛수고 아님.
  안 바뀜 = 거대한 흐름. 한 운명을 넘겨도 또 다음 죽음으로, 시대는 같은 끝 — 거시 비극.
  넘긴 운명은 영구히 넘어간다 (리제로 결 — 세이브 포인트가 앞으로 이동). 다시는 그 새벽으로 안 돌아간다.

세 인격 = 세 회귀:
  용기·지혜·정의 = 같은 운명을, 다른 태도로 사는 세 번의 회귀.
  T-01 절정: 용기=학살 / 지혜=방관 / 정의=구원 (같은 운명, 다른 태도).
  이기려 돌아오는 게 아니라 '어떻게 살 것인가'를 다른 태도로 살아보려 돌아온다.
```

## 전 회차의 흔적 — 죽은 세계가 다음 판의 지도가 된다

```yaml
# 회귀의 한 갈래이자 이 게임의 정체성 못. 실패한 런이 휘발하지 않고 다음 런의 '읽을거리'로 남는다.

첫 회차: default — 정해진 죽음의 페이지를 본다 (이 세계 주인공이 원래 맞은 운명).
둘째 회차부터: 직전 회차에 '내가' 그린 타임라인이 "이 세계의 주인공이 죽은 길"로 박제되어,
              다음 판 시작 시 흔적으로 깔린다. 어느 행동을 거쳐 어디서 죽었는지가 비쳐 보인다.

플레이어는 그 흔적을 읽으며 이번엔 다른 길을 고른다 ("지난번엔 북문에서 죽었으니, 이번엔 광장으로").
  → 실패가 자산이 된다. 회차가 쌓일수록 "이 운명을 두고 시도한 모든 길"의 기록이 누적된다.

서사 정합: 이 흔적 = 화로의 여신이 지핀 불씨가 품은 '어렴풋한 전생의 기억'(3_return 데자뷰).
  메커니즘이 곧 서사다 — 되돌아온 자가 안고 오는 희미한 기억이 곧 전 회차 동선의 표시.

# TODO(프로토): 흔적을 얼마나 보여줄지 (전체 동선? 죽은 지점만? 일부만?) — 너무 다 보이면 긴장↓.
```

## 수집 — 도감에 갈래를 모은다

```yaml
# 회귀에 목적을 주는 메타 진행. 이 게임의 시각적 심장이자 영구 누적의 그릇.
#   능력치는 런마다 리셋(dice.md). 회차를 넘어 남는 건 이 도감뿐.

수집 단위 = 카드 그 자체. 그 스테이지의 카드 그릇(결정 9 + 운명 1 — structure §카드 그릇)을 한 칸씩 채운다.
  결정 카드 — 골라야 채워진다: 그 Phase에서 실제로 고른 카드가 도감에 남는다.
    안 고른 갈래는 빈칸 — 다음 회귀에 그 길을 골라야 채워진다.
    → 회귀 동기 = "지난번 안 가본 길을 살아보러". 도감을 채움 = 그 밤의 모든 갈래를 다 살아봄.
  운명 카드 — 넘겨야 채워진다: 운명전을 이기면 죽음이 생존으로 뒤집혀 채워진다 (아래 flip).

완성: 그 스테이지(밤)의 칸을 다 채우면 페이지 완성 → 상위 위계로 누적 (Book·Character = structure §위계).
  도감이 곧 일대기 — "이 사람이 산 모든 새벽의, 갈 수 있던 모든 갈래".

운명-생존 flip (도감의 특별한 한 칸):
  운명 카드는 default 죽음 1장 (structure §죽음 모델 — 미리 쓴 원본).
  운명전 생존 → 죽음 면이 생존 면으로 뒤집힌다. 정해진 죽음을 삶으로 고쳐 쓴다.
    카드 한 장이 죽음→생존으로 뒤집히는 그 순간이 회귀 전체의 의미를 압축한다.
  회귀하다 맞는 죽음(게임오버)은 흘러가는 연출일 뿐 — 도감엔 default 죽음 한 장만 박제된다.

# 짝: 전 회차 흔적(§전 회차의 흔적) = 아직 못 밟은 갈래의 자취 / 도감 = 이미 밟아 채운 갈래.
# 제목·'도감' 명칭 = 철님 명명 대기 (기능명으로 둠).
```
