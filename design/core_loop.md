## 한 스테이지 = 하나의 운명

```yaml
스테이지 = 테오도라 생애의 한 마디 = 하나의 운명을 향해 가는 한 판.
판 구성:
  운명 카드 1장: 맨 위, 처음부터 공개 (무슨 운명인지 보인다). 카운트다운을 단다.
                 → 결말을 알면서 그리로 끌려가는 구조 (0_premise §5 "필연").
  사건 카드 10장: 뒷면이 모두 동일 (무엇인지 모른다).
```

## 카드 = 일어난 일(사건)

```yaml
카드는 유닛·자원이 아니라 '사건'이다 — "불타는 오두막의 아이", "무너지는 성문".
각 사건 카드에는 두 결과가 박혀 있다 (글자 아님, 아이콘으로 표현):
  고르면(구하면): 무엇을 얻는가 (→ 전력)
  버리면(외면하면): 무엇이 인과로 돌아오는가 (→ 운명을 키움 / 내 결핍)
```

## 진행 — 선택은 곧 희생

```yaml
2장씩 뒤집어 → 1장 선택 · 1장 버림. 5번 반복 (10장 소진).
  선택한 5장 → 내 덱 (구한 사건 = 내 전력)
  버린 5장   → 운명의 것 (외면한 사건 = 인과로 돌아옴)
순서: 선택 → 남은 것. 버린 카드는 버림 더미로.
핵심: 버림은 회피가 아니다. 하나를 구하면 하나를 못 구한다 — 외면의 대가가 운명을 키운다.
      (0_premise §1 "누구도 구원이 아니었다" — 다 구할 수 없다.)

운명 카운트다운: 선택을 한 번 할 때마다 줄어든다 (= 남은 진행도).
  0이 되면(10장 다 소진) → 운명전.
  # TODO(펜딩): 시작값·감소 단위 (5번 선택 ↔ 카운트다운 5 잠정).
  # TODO(펜딩): '감내'(안 고른 것을 강제로 떠안음, structure 원안) — 산수 위해 현 모델(1택1버림)에선 빠짐. 재도입 여부.
```

## 인과 — 외면이 부르는 것

```yaml
버린 사건은 '적'이 되는 게 아니라 '인과'로 돌아온다 (적대 아님, 인과):
  성문을 안 닫음 → 후속 병력이 온다      (운명의 전력 추가)
  아이를 안 구함 → 그 아이가 패에 없다    (내 결핍)
즉 버림의 대가는 두 방향:
  ① 버린 것이 부르는 결과 → 운명의 전력
  ② 안 고른 것의 부재     → 내 약점
인과 연결은 카드에 미리 박혀 있다 (작가가 사건마다 고름/버림 두 결과를 짝지음 — 아이콘 표현).
  # 작성량 큼 — 사건마다 두 결과를 설계해야 함. 프로토 전 경계 (종이 설계 폭발 위험).
```

## 운명전 — 선택의 결산

```yaml
카운트다운 0 → 내 5장(구한 것) vs 운명(버린 5장의 인과)의 대결.
  내 강함·약함도, 운명의 강함도 — 전부 내 5번의 선택이 빚은 것.
  적은 밖에서 오지 않는다. 내 외면의 인과가 운명의 형상으로 닥친다.
  감당하면 → 살아 다음으로. 못 하면 → 운명의 바대로 죽음 → 회귀.

5장 = '운명에 맞서 내미는 패'다 (맵 위에서 조종하는 유닛 아님 — 공간 전투 접음, 카드 대결 방향).
```

## 회귀 — 못 바꾸는 운명을 다르게 겪음

> 회귀의 서사·세계관 의미(여신의 되돌림·기원=죽음·시지프스·세 인격) = `3_return`. 여기선 게임 작동만.

```yaml
죽음 = 끝이 아니라 루프의 마디. 운명의 바대로 죽으면 되돌아와, 10장을 다시 고르고 그 운명을 다시 겪는다.
  (퍼마데스 아님 — 죽음이 종료가 아니라 회귀의 마디라는 점이 이 게임의 정체. 닷새간 퍼마데스가 안 맞물린 근본 이유.)
무엇이 바뀌고 무엇이 안 바뀌나 (3_return §6·§7):
  바뀜   = 개인 불행. 잘 골라 그 스테이지·챕터를 성공으로 바꾼다(운명전을 이긴다) — 미시 희극, 플레이가 헛수고 아님.
  안 바뀜 = 거대한 흐름. 챕터를 성공시켜도 또 다음 죽음으로, 시대는 같은 끝 — 거시 비극.
  성공의 반복 자체가 형벌이다 (시지프스). (0_premise §3 "누가 이겨도 소용없다" / §5 "권선징악 아님")

세 인격 = 세 회귀 (narrative_ssot):
  용기·지혜·정의 = 같은 9스테이지·같은 운명을, 다른 태도로 사는 세 번의 회귀.
  T-01 절정: 용기=학살 / 지혜=방관 / 정의=구원 (같은 운명, 다른 태도).
  이기려 돌아오는 게 아니라 '어떻게 살 것인가'를 다른 태도로 살아보려 돌아온다.

# 회귀 시 무엇이 남나 = 3_return이 정함: 개인 불행은 바뀌고(성공으로), 본인은 되돌아왔음을 어렴풋이 자각(데자뷰).
#   힘이 쌓여 거시 흐름을 이기는 구조는 아님 (0_premise §3과 충돌). 화로의 여신의 되돌림 = 유예지 구원 아님.
```
