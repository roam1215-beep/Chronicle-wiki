# 스토리 아크 — 오더 1 (테오도라)

> design/ 작품 측면. 척추(서사 기능) + 인격 함수의 단일 지도.
> narrative.md(인물·기원·검 동기 = 정본) ↔ README(챕터·스테이지 명명) ↔ structure.md(5층) 사이의 중간층.
> **인격 함수·기원 분기·1스테이지 페이즈 국면은 tools/stoa-factory 시제품으로 출력 검증됨(2026-06-03).**
> 범위: 서사 흐름 + 인물(보스)의 서사적 자리. 기록 카드 슬롯 세부 = 스키마 확정 후(`[기록스키마後]`).

## 플래그

```
[확정]      git 정본(narrative·worldbuilding·README·adversaries) 또는 시제품 검증 완료
[제안]      이름+세계관 연결 추론 — 철님이 메우거나 엎음
[창작]      철님 고유 영역 (플레이버·대사·클라이맥스 내용)
[기록스키마後] 기록 카드 스키마 확정 후 채울 슬롯
[펜딩]      아직 안 정해진 것 (신규 보스·챕터2·3 내용 등)
```

## 0. 아크 프레임

```yaml
분기점 [확정]:
  기원 — 어머니의 선택(테오도라 5세). 세 가능세계로 갈림. (narrative.md 정본)
  갈리는 사실: 어머니 생사 / 키레네아 직업 / 입양 사실 인지 / 검 동기 범위

수렴점 [확정]:
  주요 보스 = 세 인격 공통 고정점. 모든 테오도라가 같은 적과 만남(다른 통과).
  S1 프리키온 / S3 발드(챕터1 보스) / 이후 [펜딩]
  발드 = 인격 거울상(무모↔용기·교활↔지혜·위선↔정의, birth=낮 이오니아). [확정, adversaries]

절제 클라이맥스 슬롯 [창작, T-01]:
  "절제 없는 자" 정체성이 터지는 지점. 챕터3(신탁) 어딘가 — 위치만 예약.

오더1 큰 줄기 [확정, worldbuilding]:
  라키아의 테오도라가 발드 약탈에 맞섬 → 도리아 패권 저항 → 미궁 반격의 효시.
  끝에 카타스테리스모스. '미궁'은 시선의 은유.
```

## 1. 인격 함수 (코어 — 동기범위 × 행동문법 × 화법)

```yaml
# 동기범위 = narrative.md 정본 [확정] / 행동문법·화법 = 신규, 시제품 검증 [확정(검증)]
# 이 블록이 ① 서사·카드 생성기 코어 ② quote 검증 기준 ③ 카드 quote 분화 근거.
# 기원 분기 상세(어머니 선택·키레네아 직업·입양 인지)는 narrative.md "인격 분기" 정본 참조.

용기 (courage):
  동기범위: 가족 (범위 2)                       # [확정]
  행동문법: 정면돌파 · 맞서 결단 · 물러서지 않음    # [확정(검증)]
  화법:    마음이 먼저 정해진 사람의 목소리.        # [확정(검증)] — 느낌만, 형식 아님
  직업: warrior

지혜 (wisdom):
  동기범위: 자기 (범위 1)                       # [확정]
  행동문법: 최단 · 최적 · 치명 · 손실 최소 · 분석적  # [확정(검증)]
  화법:    한 발 떨어져 보는 목소리, 약간의 냉소.    # [확정(검증)]
  직업: hunter

정의 (justice):
  동기범위: 마을 (범위 3)                       # [확정]
  행동문법: 동행 · 구원 · 함께                    # [확정(검증)]
  화법:    곁(타인)을 향하는 목소리.              # [확정(검증)]
  직업: priest

# 화법 원칙: 성격·태도이지 문장 형식이 아니다. 길이·어미·구문을 제한하지 마라.
#   같은 사건 앞 세 사람의 태도가 다른 것. 억지 구별보다 자연스러움 우선.
# 인격 = 세계를 보는 렌즈(무엇을 지각하나)이자 목소리(어떻게 말하나).
```

### 챕터 1 — 고향·발드 [척추 확정 / 제목은 인격별 분기 — 펜딩]

```yaml
# 챕터명·스테이지명은 인격(용기·지혜·정의)마다 다르게 쓴다 — 펜딩(철님과 확정 중).
# 아래는 인격 공통 서사 골격(척추). 같은 사건, 인격마다 다른 통과.

큰 줄기:
  고향(모레아 골짜기 마을, 이름 없음)이 칼리돈 숲의 도적단에게 습격당함 → 받아침
  → 칼리돈에서 왔음을 앎 → 칼리돈 숲 토벌(토착 도적단) → 발드 매듭.
  ★ 역설(챕터2 입구): 모레아는 칼리돈 위협(치안 공백) 덕에 도리아 지배가 덜 닿았음.
    그 골칫거리를 다 없애자 오히려 도리아 압제가 들어오기 시작 → "도리아의 부름"으로 챕터2.
  적 구성: 이오니아 낙오병(발드 일당) + 칼리돈에 먼저 와 있던 토착 도적단의 합류 (adversaries.md)

stage_1 (첫 검):
  서사기능: 모레아 마을 습격·받아침. 첫 검. 기원 회상(5세)→현재(17~18세) 접합. 튜토리얼.   # [제안]
  보스: 성급한 프리키온 (스테이지 보스, hp 20). 발드의 선견대·행동대장. 황금에 눈멂·성급. 누더기 밑 이오니아 군복(위선).  # [확정/검증]
  페이즈: 1 침공(마을 습격) / 2 격퇴·추격(칼리돈서 왔음을 앎) / 3 선견대의 윤곽 / 운명 프리키온
  제목: [인격별 펜딩]   기록: [기록스키마後]

stage_2 (칼리돈 진입):
  서사기능: 칼리돈 숲 진입. 먼저 와 있던 토착 도적단과 대면. 발드가 흡수한 무리의 실체.   # [제안]
  보스: 칼리돈의 쇄도하는 재앙 (토착 도적단 쪽 — "숲의 주인이자 골칫거리", neutral 카드)   # [제안]
  제목: [인격별 펜딩]   기록: [기록스키마後]

stage_3 (발드 매듭):
  서사기능: 칼리돈 깊은 곳. 발드 대면. 위선이 드러나는 수렴점(거울상과 맞섬). 챕터1 매듭.   # [제안]
  보스: 발드 (챕터 보스, hp 30, 인격 분기=거울상)   # [확정]
  제목: [인격별 펜딩]   기록: [기록스키마後]
```

### 챕터 2 — 도리아의 부름 [입구 방향 메모 / 제목·내용 펜딩]

```yaml
# 제목(챕터·스테이지)도 인격별 분기 예정 — 펜딩.
# 옛 단일 제목(참고, 인격 분기로 재작성 예정): 단말마와 메아리 / 도망치는 자들·다가오는 위협·헤매임의 끝
입구 (챕터1 역설에서 이어짐):
  테오도라가 칼리돈 위협(프리키온·재앙·발드)을 없앤 결과, 도리아의 골칫거리(라키아를 어지럽힌 이오니아 잔당)를 대신 처리한 셈.
  → 명성이 오르고 도리아의 부름을 받음. 고향을 지킨 행위가 자기를 억압하는 도리아에 봉사하는 역설.
  → worldbuilding 오더2 방향("도리아 패권이 무너지는 이야기")의 씨앗. 챕터2 = 도리아에 불려가 그 안에서 균열.
큰 줄기·스테이지·보스: [펜딩 — 챕터2 차례에 확정]
```

## 3. 생성기 연결 (스토아 팩토리)

```yaml
# 이 문서가 tools/stoa-factory 생성기의 코어다. 생성기는 git을 직접 읽지 않으므로,
# 이 캐논이 바뀌면 생성기 SYSTEM 프롬프트도 갱신해야 한다(스냅샷).

서사 생성기:   입력=스테이지+인격+키워드, 코어=1(인격함수)+2(척추) → 흐름 출력.
기록 생성기:   입력=페이즈 국면+인격(+키워드), 코어=1+2+style_canon → 기원/페이즈/운명 카드.
              [검증] 1스테이지 전 구간(기원→1→2→3→운명) 인격별 출력 확인.
인물 생성기:   입력=인물/모티프+인격, 코어=1+직업·능력치(adversaries·cards.md). [다음]
```
