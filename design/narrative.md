## 테오도라 — 기원 (공통)

```yaml
어머니:
  사랑으로 키운 분. 친모 X. 테오도라는 주워온 남의 자식. (친부모 펜딩)
  아버지 없음 (이유 미설명).

자매 키레네아:
  테오도라와 쌍둥이라 믿는 자매 (실은 아님). 모티브 = 키레네.
  원형 하나, 인격(가능세계)마다 다른 직업으로 갈림.

기원 사건 (테오도라 5세):
  도적단이 마을 침공. 마을 박살, 사람들 피신 → 이웃 마을 정착.
  이 첫 침공이 인격을 가르는 분기점.

현재 (17~18세, stage1):
  그 이웃 마을에 도적단이 다시 침공하며 시작.
  도적단 정체 = 이오니아 탈주병 무리 (stage1 진행 중 드러남).

검 익힘:
  결심 시점부터 자기 단련.
```

## 도입 — 회상 → 현재 (2층 구조)

```yaml
회상: 5세 기원 (도적단 첫 침공, 인격별 어머니의 선택)
현재: 17~18세 이웃 마을 재침공 (stage1 플레이)
사이 12년 = 시작 5장이 메움 (기원이 손에 든 카드로 남음)
```

## 인격 분기 — 어머니의 선택 (기원의 분기점)

### 용기

```yaml
어머니의 선택: 두 자매를 양쪽 품에 안고 불타는 마을을 주파, 가족과 함께 피신
정체 인식: 모름
따르는 것: 가족을 위해 불의에 맞서고 결단하는 용기 (어머니가 보여줌)
검 동기: 가족 (범위 2)
키레네아: 전사
```

### 지혜

```yaml
어머니의 선택: 키레네아만 데리고 도망 → 혼자 도망친 테오도라와 재회
정체 인식: 앎 (어머니 눈의 죄책감·절망·희미한 안도를 읽고 남의 자식임을 본능적으로 깨달음)
따르는 것: 남보다 자신을 위해 현명하게
검 동기: 자기 (범위 1)
키레네아: 궁수
```

### 정의

```yaml
어머니의 선택: 마을 사람들과 자매를 이끌고 피신, 후미에서 시간 벌다 죽음 (최소 전투력 설정). 자매는 마을 사람들 손에 큼
정체 인식: 모름
따르는 것: 혼자가 아니라 마을과 함께 — 가족보다 큰 선
검 동기: 마을 (범위 3)
키레네아: 사제
```

## 4주덕 ↔ 테오도라 정체성

```yaml
보유: 용기 / 지혜 / 정의
빠짐: 절제

"절제 없는 자" = 테오도라 정체성
  항상 최선을 다하고 신념대로 맹목적으로 나아가는 자.
  자제 못함이 아니라 행동이 앞선다.
```
