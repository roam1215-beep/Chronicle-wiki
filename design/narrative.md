# 서사 결

> 작품 결의 자리. 명세 X. 작가 결의 깊이가 박힌 자리.

## 테오도라 — 출생 결

```yaml
어머니:
  사랑으로 키운 분. 훌륭한 분. 친모 X.
  누군가의 사생아를 받아 키운 결. (친부모 펜딩)
  
극한의 상황:
  도적단 침입. 베렝의 다리에서 가족과 도망.
  손 둘 / 아이 셋.
  한 자식을 놓아야 살릴 수 있는 결 (Sophie's Choice 결).
  인격마다 어머니의 결이 다르게 박힘.
  어린 자기가 어머니 눈에서 그것을 봄.
  어머니는 자기 결 모름. 어린 자기만 본 결.

첫 기억:
  어머니가 모르는 결을 본 결.
  평생 짊어지는 자리.

받아 키워짐:
  마을 사람들이 받음.
  치안 어렸을 때부터 나빴음 (도적 위협 누적).

검 익힘:
  결심 시점부터 자기 단련.
```

## 진입 컷씬 결 (회상)

```yaml
첫 문장:
  "베렝의 다리 위, 찢어지는 고함 소리와 함께, 나는 혼자가 되었다."

둘째 문장:
  "상실의 냄새는 습한 비 냄새와 옅은 풀내음이 났다."

감각 결 전환 → 현재:
  회상 = 비 + 풀 (남겨진 자리, 조용한 상실)
  현재 = 탄내 + 불 (격렬한 상실 위기)
  같은 다리 두 번 박힘. 공간이 시간을 묶는 결 (카타스테리스모스 결).
```

## 인격 분기 — 어머니의 결 + 어린 자기

### 용기

```yaml
어머니: 무의식적으로 주저 없이 테오도라 버림
어머니 결의 정체:
  무의식이 의식을 거치지 않고 행동으로 박힌 결.
  자기 결을 모르는 결.

어린 자기가 본 것:
  어머니의 무의식. 어둠.

결의 결:
  용맹(과감)의 어두운 얼굴.
  주저 없이 던지는 결이 자기를 버린 자리에서 옴.

현재 결 — 도적 침입:
  가족을 보내고 후미에 남음
  검 동기: 가족을 지키기 위해
  어머니 결의 반응: 역전 (놓는 자가 아니라 지키는 자)
  결의 무게: 어머니의 비극을 자기가 안 반복하려는 결
```

### 지혜

```yaml
어머니: 의식적으로 생각해보고 테오도라 버림
어머니 결의 정체:
  자기 결을 보려 한 결. 무의식적 후련함을 알아챈 결.
  의식이 무의식과 부딪힌 결. 결국 놓음.

어린 자기가 본 것:
  어머니의 고민의 무게.
  의식과 무의식의 충돌과 패배.

결의 결:
  지혜의 어두운 얼굴.
  생각해보고도 같은 결로 갈 수 있는 자리.

현재 결 — 도적 침입:
  가족보다 먼저 다리를 건넘
  검 동기: 혼자서도 살아남기 위해
  어머니 결의 반응: 반복 (살기 위해 자기를 우선)
  결의 무게: 어머니의 무의식이 자기 안에도 있을까 두려운 결.
            의식적으로 자기를 박는 결.
```

### 정의

```yaml
어머니: 무의식적으로 주저 없이 테오도라와 두 아이를 모두 살림
어머니 결의 정체:
  아무것도 버리지 않는 결.
  가장 정의로운 선택.
  무의식이 사랑·정의로 박힌 결.

어린 자기가 받은 것:
  어머니의 무의식적 정의.
  몸으로 받은 결.

결의 결:
  정의의 밝은 얼굴.
  안 버려진 자기가, 놓일 수도 있었던 자기를 알기에
  정의를 살아내는 결.

현재 결 — 도적 침입:
  가족 보냈고, 같은 마을 사람들 구함
  검 동기: 마을을 지키기 위해
  어머니 결의 반응: 받아들임 + 다음 결
  결의 무게: 안 놓인 자가, 놓일 수도 있었던 자기를 알기에
            사람을 살리는 결
```

## 4주덕 ↔ 테오도라 정체성

```yaml
보유: 용기 / 지혜 / 정의
빠짐: 절제

"절제 없는 자" = 테오도라 정체성
  자기를 다스리지 못함. 끓는 결.
  공헌제 진실 알자 자기를 던짐 = 절제 X
  미궁 들어가서 폭로 = 끓어오르는 결
  
"절제했다면 폭로 안 했음" = 작품 동력
```

## 검 동기 — 반경의 결

```yaml
지혜 = 자기 (반경 1)
용기 = 가족 (반경 2)
정의 = 마을 (반경 3)
```

## 인격별 호 (弧)

```yaml
공통:
  다리 위의 아이 (출생) → 라키아의 들개 (마을 멸칭)
  → [용맹한 / 지혜로운 / 정의로운] 테오도라
  → 미궁의 테오도라 (Order 결, 별이 됨)

들개 = 평민 사생아 멸시 어휘.
멸칭이 인격으로 *지나가는 결* (벗겨지고 자기 이름 박히는 결).
```
