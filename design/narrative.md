## 테오도라 — 출생

```yaml
어머니:
  사랑으로 키운 분. 훌륭한 분. 친모 X.
  누군가의 사생아를 키움. (친부모 펜딩)
  
극한의 상황:
  도적단 침입. 베렝의 다리에서 가족과 도망.
  손 둘 / 아이 셋.
  한 자식을 놓아야 살릴 수 있는 상황 (Sophie's choice).
  인격마다 어머니의 선택이 다름.
  어머니 자신도 모르는 것을 어린 테오도라가 본능적으로 알게 됨.

첫 기억:
  어머니가 모르는 것을 본 것.
  테오도라의 기원.

받아 키워짐:
  마을 사람들이 받음.
  치안 어렸을 때부터 나빴음 (도적 위협 누적).

검 익힘:
  결심 시점부터 자기 단련.
```

## 진입 컷씬 (회상)

```yaml
첫 문장:
  "베렝의 다리 위, 찢어지는 고함 소리와 함께, 나는 혼자가 되었다."

둘째 문장:
  "상실의 냄새는 습한 비 냄새와 옅은 풀내음이 났다."

감각 전환 → 현재:
  회상 = 비 + 풀 (버려짐, 조용한 상실)
  현재 = 탄내 + 불 (격렬한 상실 위기)
  같은 다리 두 번 나옴. 공간과 시간이 연결됨 (카타스테리스모스).
```

## 인격 분기 — 어머니의 선택 + 어린 자기

### 용기

```yaml
어머니: 무의식적으로 주저 없이 테오도라 버림
어머니의 선택의 정체:
  무의식이 의식을 거치지 않고 행동으로 드러난 것.
  자기 마음을 모르는 것.

어린 자기가 본 것:
  어머니의 무의식. 어둠.

용기의 어두운 단면:
  주저없이 가식없이 자기 자식이 아닌 테오도라를 버림.

현재 — 도적 침입:
  가족을 보내고 후미에 남음
  검 동기: 가족을 지키기 위해
  어머니의 선택에 대한 반응: 역전 (놓는 자가 아니라 지키는 자)
  의미: 어머니의 비극을 자기가 안 반복하려는 다짐
```

### 지혜

```yaml
어머니: 의식적으로 생각해보고 테오도라 버림
어머니의 선택의 정체:
  자기 마음을 보려 한 것. 무의식적 후련함을 알아챈 것.
  의식이 무의식과 부딪힘. 결국 놓음.

어린 자기가 본 것:
  어머니의 고민의 무게.
  의식과 무의식의 충돌과 패배.

지혜의 어두운 단면:
  생각해보고도 같은 선택으로 갈 수 있음.

현재 — 도적 침입:
  가족보다 먼저 다리를 건넘
  검 동기: 혼자서도 살아남기 위해
  어머니의 선택에 대한 반응: 반복 (살기 위해 자기를 우선)
  의미: 어머니의 무의식이 자기 안에도 있을까 두려움.
       의식적으로 자기를 다잡음.
```

### 정의

```yaml
어머니: 무의식적으로 주저 없이 테오도라와 두 아이를 모두 살림
어머니의 선택의 정체:
  아무것도 버리지 않는 선택.
  가장 정의로운 선택.
  무의식이 사랑과 정의로 드러남.

어린 자기가 받은 것:
  어머니의 무의식적 정의.
  몸으로 받은 것.

진정한 정의:
  구원 받은 사람이 곤경에 처한 사람을 구하는 것.

현재 — 도적 침입:
  가족 보냈고, 같은 마을 사람들 구함
  검 동기: 마을을 지키기 위해
  어머니의 선택에 대한 반응: 받아들임 + 다음 단계
  의미: 구원 받은 사람이 곤경에 처한 사람을 구함.
```

## 4주덕 ↔ 테오도라 정체성

```yaml
보유: 용기 / 지혜 / 정의
빠짐: 절제

"절제 없는 자" = 테오도라 정체성
  항상 최선을 다하고 자신의 신념대로 맹목적으로 나아가는 자.
  자제를 못한다기보다는 행동이 앞선다.
  공헌제 진실 알자 자기를 던짐 = 절제 X
  미궁 들어가서 폭로 = 행동이 앞섬
  
"절제했다면 폭로 안 했음" = 작품 동력
```

## 검 동기 — 범위

```yaml
지혜 = 자기 (범위 1)
용기 = 가족 (범위 2)
정의 = 마을 (범위 3)
```

## 인격별 호 (弧)

```yaml
공통:
  다리 위의 아이 (출생) → 라키아의 들개 (마을 멸칭)
  → [용맹한 / 지혜로운 / 정의로운] 테오도라
  → 미궁의 테오도라 (Order 끝, 별이 됨)

들개 = 평민 사생아 멸시 어휘.
멸칭이 인격으로 바뀌는 흐름 (벗겨지고 자기 이름이 새겨짐).
```
