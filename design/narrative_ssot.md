## 0. 읽는 법 · 플래그


## 1. 공통 토대 (세 인격 공유)

### 1.1 기원 — 테오도라 5세 [확정]

```yaml
어머니:
  사랑으로 키운 분. 친모 X. 테오도라는 주워온 남의 자식. (친부모 펜딩)
  아버지 없음 (이유 미설명).

자매 키레네아:
  테오도라와 쌍둥이라 믿는 자매 (실은 아님). 모티브 = 키레네.
  원형 하나, 인격(가능세계)마다 다른 직업으로 갈림. (§3 인격별)

기원 사건 (5세):
  도적단이 마을 침공. 마을 박살, 사람들 피신 → 이웃 마을 정착.
  이 첫 침공이 인격을 가르는 분기점. (§3 어머니의 선택)

검 익힘:
  결심 시점부터 자기 단련.
```

### 1.2 도입 — 회상 → 현재 (2층 구조) [확정]

```yaml
회상: 5세 기원 (도적단 첫 침공, 인격별 어머니의 선택)
현재: 17~18세 이웃 마을 재침공 (stage1 플레이)
  도적단 정체 = 이오니아 탈주병 무리 (stage1 진행 중 드러남 — 발드 일당, §4)
사이 12년 = 시작 5장이 메움 (기원이 손에 든 카드로 남음)
```

도입 컷씬 = 오더 시작 origin 카드 1장 (페이즈 밖, structure.md 편성). TODO(컷씬): 회상 컷씬 구체 문장 — 철님 창작.

### 1.3 4주덕 ↔ 정체성 [확정]

## 2. 공통 척추 (9스테이지 서사 기능 — 같은 사건, 다른 통과)

> 세 인격이 같은 적·같은 마디를 지난다. 통과 방식만 인격별로 갈림(§3).
> 서사기능 = [제안]. 플레이버·대사 = [창작]. 기록 슬롯 = [기록스키마後].

### 2.1 아크 프레임 [확정]

```yaml
분기점:
  기원 — 어머니의 선택(5세). 세 가능세계로 갈림. (§3)
  갈리는 사실: 어머니 생사 / 자매 키레네아 직업 / 입양 사실 인지 / 동기 범위

수렴점:
  주요 보스 = 세 인격 공통 고정점. 모든 테오도라가 같은 적과 만남(다른 통과).
  S1 프리키온 / S3 발드(챕터1 보스) / 이후 [펜딩]
  발드 = 인격 거울상(무모↔용기·교활↔지혜·위선↔정의, birth=낮 이오니아). [확정, §4]

절제 클라이맥스 슬롯 [창작, T-01]:
  "절제 없는 자" 정체성이 터지는 지점. 챕터3(신탁) 어딘가 — 위치만 예약.
  (옛 "공헌제·미궁 폭로" 폐기 → 새 세계관 라키아·발드·무리로 재정립 대기)
```

### 2.2 챕터 1 — 고향·발드 [척추 확정]

```yaml
큰 줄기:
  고향(모레아 골짜기 마을, 이름 없음)이 칼리돈 숲의 도적단에게 습격당함 → 받아침
  → 칼리돈에서 왔음을 앎 → 칼리돈 숲 토벌(토착 도적단) → 발드 매듭.
  적 구성: 이오니아 낙오병(발드 일당) + 칼리돈에 먼저 와 있던 토착 도적단의 합류 (§4)

★ 역설 (챕터2 입구):
  모레아는 칼리돈 위협(치안 공백) 덕에 도리아 지배가 덜 닿았음.
  그 골칫거리를 다 없애자 오히려 도리아 압제가 들어오기 시작 → "도리아의 부름"으로 챕터2.

stage_1 (첫 검):
  서사기능: 모레아 마을 습격·받아침. 첫 검. 기원 회상(5세)→현재(17~18세) 접합. 튜토리얼.
  보스: 성급한 프리키온 (스테이지 보스, hp 20). 발드의 선견대·행동대장. (§4)

stage_2 (칼리돈 진입):
  서사기능: 칼리돈 숲 진입. 먼저 와 있던 토착 도적단과 대면. 발드가 흡수한 무리의 실체.
  보스: 칼리돈의 쇄도하는 재앙 (토착 도적단 쪽 — "숲의 주인이자 골칫거리", neutral 카드)  [제안]

stage_3 (발드 매듭):
  서사기능: 칼리돈 깊은 곳. 발드 대면. 위선이 드러나는 수렴점(거울상과 맞섬). 챕터1 매듭.
  보스: 발드 (챕터 보스, hp 30, 인격 분기=거울상) [확정]
```

### 2.3 챕터 2 — 도리아의 부름 [입구 메모]

```yaml
입구 (챕터1 역설에서 이어짐):
  테오도라가 칼리돈 위협(프리키온·재앙·발드)을 없앤 결과, 도리아의 골칫거리(라키아를 어지럽힌

  → 챕터2 = 도리아에 불려가 그 안에서 균열. (worldbuilding 오더2 "도리아 패권이 무너지는 이야기"의 씨앗)

큰 줄기·스테이지·보스: [펜딩 — 챕터2 차례에 확정]
```

> 각 인격 = 닫힌 가능세계 하나. 동기범위 = narrative 정본 [확정] / 행동문법·화법 = 시제품 검증 [확정(검증)].
> 이 블록이 ① 서사·카드 생성기 코어 ② quote 검증 기준.
> 화법 원칙: 성격·태도이지 문장 형식이 아니다. 길이·어미·구문을 제한하지 마라. 억지 구별보다 자연스러움 우선.

## 4. 보스 — 서사 결 (능력치·스키마 = `characters/adversaries.md`)

```yaml
프리키온 (성급한 프리키온, 스테이지1 보스 hp20, attack 1):
  발드의 선견대·행동대장. 황금에 눈멂·성급. 누더기 밑 이오니아 군복(위선).
  탐욕스럽고 성급한 무법자. 황금과 욕망의 포로이나 감옥을 벗어날 생각이 없음.

발드 (챕터1 보스 hp30, 인격별 거울상):
  원형 = 오노다 히로오 (종전 모르는 낙오병).
  정체: 이오니아 백인대장. 이오니아-도리아 전쟁 도리아 승리 → 휘하 부대와 탈주, 종전 인정 못 함.
  자칭 "라키아 해방군" (명분=도리아 압제서 라키아 해방 / 실제=그럴 뜻 없음 — 위선의 핵심).
  거점: 칼리돈 숲. 먼저 와 있던 토착 도적단을 흡수해 세를 키움.
  비겁: 자기 이긴 도리아 정규군과는 못 싸움 → 만만한 라키아(경계 약자)만 약탈.
  3인격 가면 (같은 발드):
    무모(↔용기): 노골적 약탈, 그냥 도적에 가까움
    교활(↔지혜): 마을 사람 회유·도적단 포섭 시도
    위선(↔정의): 흡수한 옛 칼리돈 도적단을 악으로 몰며 진짜 해방군인 척 수작

이오니아 탈주병 (stage1 일반전 잡졸, hp10):
  이오니아 탈주병이 라키아 토착 도적 무리와 합류해 치안을 어지럽힘.
  전사 / 사수 / 헤매이는 떠돌이.
```
