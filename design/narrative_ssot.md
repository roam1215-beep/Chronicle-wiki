```

[제안]       이름+세계관 연결 추론 — 철님이 메우거나 엎음
```

## 1. 공통 토대 (세 인격 공유)

### 1.1 기원 — 테오도라 5세 [확정]

```yaml
어머니:
  사랑으로 키운 분. 친모 X. 테오도라는 주워온 남의 자식. (친부모 펜딩)
  아버지 없음 (이유 미설명).

자매 키레네아:
  테오도라와 쌍둥이라 믿는 자매 (실은 아님). 모티브 = 키레네.
  원형 하나, 인격(가능세계)마다 다른 직업으로 갈림. (§3 인격별)

기원 사건 (5세):
  도적단이 마을 침공. 마을 박살, 사람들 피신 → 이웃 마을 정착.
  이 첫 침공이 인격을 가르는 분기점. (§3 어머니의 선택)

검 익힘:
  결심 시점부터 자기 단련.
```

### 1.2 도입 — 회상 → 현재 (2층 구조) [확정]

```yaml
회상: 5세 기원 (도적단 첫 침공, 인격별 어머니의 선택)
현재: 17~18세 이웃 마을 재침공 (stage1 플레이)
  도적단 정체 = 이오니아 탈주병 무리 (stage1 진행 중 드러남 — 발드 일당, §4)
사이 12년 = 시작 5장이 메움 (기원이 손에 든 카드로 남음)
```

도입 컷씬 = 오더 시작 프롤로그 1장 (페이즈 밖, structure.md 편성. 줄거리 카드). TODO(컷씬): 회상 컷씬 구체 문장 — 철님 창작.

### 1.3 인격 · 기질 [확정]

```yaml
편(구 '인격') = 용기 / 지혜 / 정의 (가능세계 3개 = 직업 3개). 위계: 전기(인물) ⊃ 오더 ⊃ 편 — 같은 편이 오더를 넘어 이어짐(편끼리 안 섞임)
  용기 = 전사 / 지혜 = 사냥꾼 / 정의 = 사제 (테오도라 매핑)
  ※ '4주덕 중 절제 빠짐 = 정체성' 도식 폐기. 인격은 결핍이 아니라 통과 렌즈다.

기질 (세 인격 공통 바닥) — "물러설 줄 모르는 자":
  항상 최선을 다하고 신념대로 끝까지 가는 자. 한번 정하면 물러섬·중도포기가 없다.
  자제 못함이 아니라 행동이 앞선다.
  → 이 기질이 인격별로 다르게 터지는 곳이 T-01 (§2.1).
```

### 1.4 동기 — 범위 [확정]

```yaml
지혜 = 자기 (범위 1)
용기 = 가족 (범위 2)
정의 = 마을 (범위 3)
```

### 1.5 오더1 큰 줄기 [확정, worldbuilding]

```yaml
모레아 골짜기가 도적단·무리의 잇단 습격에 휩쓸림 → 테오도라가 맞서며 그 뒤의 흑막(발드)에 다가감 → 미궁 반격의 효시.
오더1은 모레아 골짜기 안에서 완결 (도리아 패권 종식 = 세계사 국면3, 별도. 발드 종말 서사 = 후속 — §4).
끝에 별이 됨. '미궁'은 시선의 은유 (worldbuilding "멸칭").
배경 세계·정치·종족 = `design/world/` 정본 (단 아래 옛 고유명사 라키아 등은 재설계 대기).
```

## 2. 공통 척추 (9스테이지 — 같은 무대·같은 골격, 인격마다 다른 통과)

> 오더1 = 모레아 골짜기 전투, 9스테이지 안에서 완결. 세 인격이 같은 챕터 골격(마을→숲→재습격)을 지나되,
> 만나는 보스·전말 도달이 인격마다 다르다(§3). 같은 사건을 누구냐에 따라 다르게 사는 구조.
> 보스·전말 = [확정, 철님]. 서사기능 슬롯 = [확정]. 장면·대사·이유·단서 = [시뮬](서사/기록 시뮬레이터 생성·검수).

### 2.1 아크 프레임 [확정]

```yaml
분기점 (5세 기원):
  어머니의 선택으로 세 가능세계가 갈림 (§3). 갈리는 사실: 어머니 생사 / 자매 키레네아 직업 / 입양 인지 / 동기 범위.

수렴 폐기 (옛 "프리키온·발드 공통 고정점·거울상" 폐기):
  세 인격은 같은 보스로 모이지 않는다. 같은 인물 풀(프리키온·도적 대장·네임드 무리·무리 대장·발드)을
  인격마다 다른 순서·다른 결말로 만난다. (보스 분배 = §3 표)

전말 (셋을 겹쳐야 드러남):
  흑막 = 발드. 모레아에서 시작해 라키아 전체를 박살내려 암약.
  진짜 피해자 = 마을 사람들. 도적단과 무리는 둘 다 발드에게 이용당한 도구.
  → 무리는 침입자가 아니라 또 다른 피해자 (+ worldbuilding "무리=선주민·원래 주인").
  발드 도달: 용맹=모름 / 지혜=의심 / 정의=직면. 정의 회차만 흑막에 닿는다.

절제 클라이맥스 (T-01) — "물러설 줄 모르는 자"의 인격별 발현:
  같은 기질(신념대로 끝까지, 물러섬 없음)이 보는 범위에 따라 갈림.
  용맹 = 학살 (피해자 무리를 원흉으로 오인해 벤다 — 맹목이 가해)
  지혜 = 방관 (흑막 윤곽을 보고도 자기 밖이라 칼 거두고 떠남 — 알면서 외면)
  정의 = 구원 (적이 아니었음을 받아들이고 끝까지 함께 — 맹목이 연대)
```

### 2.2 챕터 1 — 마을 [척추 확정]

```yaml
무대: 모레아 산골짜기. 마을을 공격하는 세력과 마을 안에서 싸운다.
stage_1 (마을 침공): 마을을 공격하는 대상과 마을에서 전투. 첫 검. 기원 회상(5세)→현재 접합. 튜토리얼.
stage_2 (밀어냄):    마을 사람들을 구해가며 적을 마을에서 물리치기 시작.
stage_3 (우두머리):  마을을 공격한 부대의 우두머리와 전투. (챕터 보스)
※ 침공자·우두머리 = 인격별 (용맹·정의=도적단 / 지혜=무리 — §3)
```

### 2.3 챕터 2 — 숲 (칼리돈) [척추 확정]

```yaml
무대: 칼리돈 숲. 마을을 위협한 세력을 쫓아 들어간다.
stage_1 (추격 개시): 마을 사람들(토벌대)과 함께 숲으로 추격.
stage_2 (본거지):    위협 세력의 본거지로 접근.
stage_3 (원흉):      위협 세력의 원흉 처단. (챕터 보스)
※ 정의는 도적 잔당을 쫓다 숲에서 무리와 우발적으로 마주침 → 무리 대장을 죽이지 않고 화해 (§3)
```

### 2.4 챕터 3 — 재습격 / 진실 [척추 확정]

```yaml
무대: 모레아. "위협은 하나가 아니었다."
stage_1 (재습격):  마을을 위협한 대상이 하나가 아니었음을 알게 됨 (마을 재습격).
stage_2 (뒷수습):  마을을 다시 막아내고 뒷수습.
stage_3 (재대결):  마을을 다시 공격한 존재와 재대결. (챕터 보스)
※ 재대결 상대 = 인격별. 정의만 그 끝에서 흑막(발드)에 직면 (§3). 용맹·지혜는 흑막을 못 본 채 닫힘.
```

### 2.5 페이즈 원칙 (★ 기록 카드 작성의 핵심 — structure.md 정본)

```yaml
# 위 척추의 stage별 "서사기능"은 스테이지 전체의 서사 호(arc)다.
# 페이즈(1·2·3)에 서사 단계를 박지 마라 — structure.md가 인과 사슬을 금지한다.
스테이지당 일반 9장 = 순서 셔플 (매 런 다른 순서). 고정점 = 오더 시작 기원 1장 + 각 스테이지 끝 운명 1장.
일반 카드 = 인과 사슬(A→B) 금지. 같은 무대의 병렬 사건 단위.
  → 어떤 순서로 와도 그 스테이지 이야기가 되도록 쓴다.
  (예: 챕터1 stage1 = "마을 침공"이라는 한 무대의 병렬 단편 9장)
```

## 3. 인격 변주 (분기 · 함수 · 보스 · 명명)

> 각 인격 = 닫힌 가능세계 하나. 동기범위 = 정본 [확정] / 행동문법·화법 = 시제품 검증.
> 화법 원칙: 성격·태도이지 문장 형식이 아니다. 길이·어미·구문을 제한하지 마라.

### 보스 분배 [확정, 철님]

```
            챕터1(마을)      챕터2(숲)             챕터3(재습격/진실)   흑막   T-01
  용맹      프리키온         도적 대장             무리 대장 (죽임)      모름   학살
  지혜      네임드 무리      무리 대장 (죽임)      도적 대장 (죽임)      의심   방관
  정의      도적 대장        무리 대장 (살림→화해) 발드                 직면   구원

침공자: 용맹·정의 = 도적단 / 지혜 = 무리.
같은 인물 풀을 인격마다 다른 순서·결말로 (수렴 폐기).
이름(도적 대장·무리 대장·네임드 무리) = 자리표, 실명은 다음 단위.
```

### 3.1 용기 (courage)

```yaml
어머니의 선택: 두 자매를 양쪽 품에 안고 불타는 마을을 주파, 가족과 함께 피신
정체 인식: 모름 / 따르는 것: 가족 위해 불의에 맞서는 용기 / 동기: 가족(범위 2) / 자매 키레네아: 전사
인격함수: 정면돌파·맞서 결단·물러서지 않음 / 화법: 마음이 먼저 정해진 사람의 목소리 / 직업: warrior

통과: 도적단 침공 → 마을서 격퇴(프리키온) → 숲 추격(도적 대장 처단) → 재습격은 무리 →
      무리를 원흉으로 오인해 다 쓸어버림(무리 대장, ch3).
T-01 = 학살: 피해자(무리)를 베는 맹목. 흑막(발드)은 끝내 모름 — 가장 좁게 봐 가장 무겁게 가해.

명명: 챕터·스테이지 제목 [창작 — 다음 단위]
사건: [시뮬]. stage 카드 = courage/record.md (펜딩)
```

### 3.2 지혜 (wisdom)

```yaml
어머니의 선택: 자매 키레네아만 데리고 도망 → 혼자 도망친 테오도라와 재회
정체 인식: 앎 / 따르는 것: 남보다 자신을 위해 현명하게 / 동기: 자기(범위 1) / 자매 키레네아: 궁수
인격함수: 최단·최적·치명·손실 최소·분석적 / 화법: 한 발 떨어져 보는 목소리, 약간의 냉소 / 직업: hunter

통과: 무리 침공 → 마을서 격퇴(네임드 무리) → 숲 추격(무리 대장 죽임) → 재습격은 도적 →
      도적 대장도 죽임(ch3). 둘 다 베고 나서 그 뒤 흑막의 존재를 추론·의심하며 종결.
T-01 = 방관: 흑막 윤곽을 보고도 자기 밖이라 외면. 발드 = 의심만, 못 봄.

명명: [창작 — 다음 단위]
사건: [시뮬]. stage 카드 = wisdom/record.md (펜딩)
```

### 3.3 정의 (justice)

```yaml
어머니의 선택: 마을 사람들과 자매를 이끌고 피신, 후미에서 시간 벌다 죽음. 자매는 마을 사람들 손에 큼
정체 인식: 모름 / 따르는 것: 마을과 함께 — 가족보다 큰 선 / 동기: 마을(범위 3) / 자매 키레네아: 사제
인격함수: 동행·구원·함께 / 화법: 곁(타인)을 향하는 목소리 / 직업: priest

통과: 도적단 침공 → 마을서 격퇴(도적 대장) → 도적 잔당 쫓다 숲에서 무리와 우발적 조우 →
      무리 대장을 죽이지 않음(살림) → 무리가 사연·흑막을 알려줌 → 화해 →
      재습격의 끝에서 흑막(발드)에 직면(ch3).
```
