# 이야기 레퍼런스 카탈로그

> **상태: RESEARCH WORKING DOC. 정본 아님.**
> Chronicle의 제작 전에 참고할 “케이크 카탈로그”.
> 게임 메커니즘을 베끼기 위한 목록이 아니라, 공유 무대·인물망·인과·시점·수렴이 강한 이야기에서 구조를 채굴하기 위한 작업장이다.

## 선정 기준

Chronicle에 특히 유용한 이야기:

~~~yaml
- 같은 시간·공간에 여러 인물이 함께 존재한다.
- 한 사건이 인물마다 다른 의미를 가진다.
- 인물별 이야기 길이가 다르다.
- 한 인물의 종착점이 다른 인물에게는 중간 사건 또는 출발 조건이 된다.
- 앞선 작은 행위들이 뒤의 큰 귀결로 이어진다.
- 한 인물 시점만으로는 객관적 전체를 알 수 없다.
- 사건이 이후 세대·지역·정치 질서에 여파를 남긴다.
~~~

## 세션에서 나온 후보

아래는 후보일 뿐 Pilot 원전으로 확정하지 않았다.

### 테베 신화군

채굴 포인트:
- 여러 세대에 걸친 인과
- 한 세대의 선택이 다음 세대의 정치·가족 갈등으로 전이
- 같은 도시와 가문을 여러 인물이 다른 위치에서 경험
- 한 사람의 종착점이 다음 사람 이야기의 출발점이 됨

### 아트레우스 가문 / 오레스테이아 계열

채굴 포인트:
- 하나의 사건이 왕·부모·자식·복수자에게 서로 다른 의무와 의미를 가짐
- 가족 인과와 정치 인과가 겹침
- 세대 간 결과 전달

### 트로이 전쟁권

채굴 포인트:
- 매우 큰 공유 무대
- 수많은 인물의 길이가 서로 다름
- 같은 죽음·전투·정치 사건이 누구에게는 Fate, 누구에게는 배경
- 여러 제한 시점을 합쳤을 때 큰 전쟁의 전체가 드러남

주의:
- 표면 플롯과 유명 고유명사를 그대로 옮기면 원전 복제에 가까워진다.
- 구조 채굴용으로 쓰고 강하게 분해해야 한다.

### 펠로폰네소스 전쟁

채굴 포인트:
- 장기간의 정치·군사·시민 생활이 같은 역사 안에 공존
- 도시·동맹·개인 수준의 시점 차이
- 작은 정치·군사 판단이 후대의 큰 상태 변화로 연결

세부 후보:
- 시칠리아 원정
- 코르키라 내전

### 보이오티아의 부상 / 레우크트라 / 에파미논다스

이번 Structure 사고에서 특히 많이 사용한 역사적 예시.

채굴 포인트:
- 지역의 작은 갈등이 패권 변화로 확대되는 과정
- 한 인물의 생사와 정치적 영향력이 이후 역사에 미치는 반향
- “그가 죽지 않았다면?”처럼 소수의 의미 있는 역사적 가정을 Book Outcome으로 변형하기 좋음
- 같은 출발점에서 Series가 서로 다른 역사적 계통으로 갈라지는 사고 실험에 적합

주의:
- 「레우크트라의 신의 복수」, 「에파미논다스의 죽음」 등은 현재 사고용 Book 제목 예시다. Chronicle 세계의 확정 콘텐츠가 아니다.

## 분석 템플릿

원전 하나를 고르면 먼저 이 표만 채운다.

| 항목 | 질문 |
|---|---|
| 공유 무대 | 어느 시간·공간을 하나의 케이크로 볼 수 있는가? |
| 객관 사건 | 인물 시점과 무관하게 실제로 무엇이 일어났는가? |
| 인물망 | 누가 언제 어디에 있고 서로 어떤 관계인가? |
| 길이 차이 | 누가 전체를 관통하고 누가 짧게 스치는가? |
| 인과 사슬 | 작은 사건이 어떤 큰 결과로 이어지는가? |
| 시점 차이 | 같은 사건을 서로 어떻게 다르게 접하는가? |
| 수렴점 | 어떤 사건이 특정 인물의 Fate가 되는가? |
| 거시 귀결 | 어떤 사실이 이후 역사 전체를 바꿀 수 있는가? |
| Chronicle이 채굴할 것 | 기능·관계·구조 중 무엇을 가져올 가치가 있는가? |
| 버릴 것 | 고유명사·표면 플롯·유명 장면 중 무엇을 제거할 것인가? |
| 변형 후보 | 분할·병합·반전·삭제·추가할 구조는 무엇인가? |
