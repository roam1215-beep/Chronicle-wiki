# STAGE-WEATHER: 날씨 (Weather)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** STAGE-WEATHER · **수정일:** 2026-02-25

---

## ① 한 줄 요약

6면 날씨 주사위. 하루(2턴) 지속. 날씨는 맵 조건만 바꾸고 전투 규칙은 건드리지 않는다. 낮밤과 조합되어 8가지 상황을 만든다.

---

## ② 규칙 정의

### 날씨 주사위

| 면 | 확률 | 효과 |
|---|------|------|
| 맑음 (×3) | 50% | 효과 없음 |
| 안개 (×1) | 17% | 아군 시야 공유 해제. 각 유닛 자기 시야만 |
| 비 (×1) | 17% | 시야가 좌우만. 상하 안 보임 |
| 눈 (×1) | 17% | 전체 이동력 -1. 징집병/적 모두 정지. 테오도라만 이동 가능 |

### 적용 규칙

| 필드 | 내용 |
|------|------|
| **지속** | 하루 = 2턴 |
| **굴림** | 매일 시작 시 |
| **원칙** | 날씨는 맵 조건만 바꾼다. 전투 규칙을 건드리지 않는다 |

### 낮밤 × 날씨 조합

| 조합 | 맵 시야 | 전투 |
|------|---------|------|
| 낮+맑음 | 정상 | 선제O, 결과 보임 |
| 낮+안개 | 공유 해제 | 선제O, 결과 보임 |
| 낮+비 | 좌우만 | 선제O, 결과 보임 |
| 낮+눈 | 정상, 이동-1 | 선제O, 결과 보임 |
| 밤+맑음 | 정상 | 선제X, 결과 안 보임 |
| 밤+안개 | 공유 해제 | 선제X, 결과 안 보임 |
| 밤+비 | 좌우만 | 선제X, 결과 안 보임 |
| 밤+눈 | 정상, 이동-1 | 선제X, 결과 안 보임 |

## ⑥ 설계 근거

**Q. 왜 맑음이 50%인가?**
특수 날씨가 너무 자주 나오면 "정상"이 없어져서 기준선이 사라진다. 절반은 맑음이어야 특수 날씨가 이벤트로 느껴진다.

**Q. 눈에서 왜 테오도라만 이동 가능한가?**
눈은 유일하게 테오도라가 자유롭게 위치를 잡을 수 있는 날씨. 전선이 멈추는 동안 재배치할 기회. 위기이자 기회.
