## ① 한 줄 요약

낮/밤 교대가 전투 정보와 선제 페이즈를 지배한다. 날씨 주사위는 추가 변수를 만들되, 전투 규칙은 건드리지 않는다.

## ② 규칙 정의

### 낮/밤 교대 (확정)

| 필드 | 내용 |
|------|------|
| **주기** | 홀수 턴 = 낮, 짝수 턴 = 밤. 매 턴 교대 |
| **낮** | ① 선제 페이즈 정상 진행. 상대 주사위 결과 보임 |
| **밤** | ① 선제 페이즈 통째로 스킵 (궁병 본전투 합류). 상대 주사위 결과 "?" 처리 |

| 항목 | 낮 (홀수 턴) | 밤 (짝수 턴) |
|------|-------------|-------------|
| **① 선제 페이즈** | 정상 진행 | 통째로 스킵 |
| **상대 주사위 결과** | 보임 | "?" 처리 |
| **유닛 전환 ③** | 결과 보고 대응 | 감으로 판단 |
| **리롤 (스텝 4)** | 내/적 자유 선택 | 내 주사위만 안전 (적은 도박) |
| **앰버 타겟 지정** | 발동 (선제에서 사살 대상 지정) | 발동 안 함 (선제 스킵) |
| **영웅 선제 피격** | 랜덤 히트에 포함 | 리스크 없음 |

### 날씨 주사위 (재설계 필요)

> ⚠️ **재설계 필요.** v0.1의 날씨 효과(안개=시야 공유 해제, 비=좌우만, 눈=이동-1)는 그리드 이동+시야 체계 전제. 이동 시스템 삭제 및 카드 덱 기반 진행 확정으로 날씨 효과 재정의 필요.
>
> **결정에 필요한 것:** 카드 덱 구조 확정 후, 날씨가 카드 덱 진행에 어떤 변수를 만드는지 정의.

| 면 | 확률 | v0.1 효과 (무효) | v0.2 효과 |
|---|------|------------------|-----------|
| 맑음 (×3) | 50% | 효과 없음 | 유지 |
| 안개 (×1) | 17% | 시야 공유 해제 | 미정 |
| 비 (×1) | 17% | 좌우 시야만 | 미정 |
| 눈 (×1) | 17% | 전체 이동력 -1 | 미정 |

| 필드 | 내용 |
|------|------|
| **지속** | 하루 = 2턴 |
| **굴림** | 매일 시작 시 |
| **원칙** | 날씨는 맵 조건만 바꾼다. 전투 규칙을 건드리지 않는다 — 이 원칙은 유지 |

## ⑥ 설계 근거

**Q. 왜 맑음이 50%인가?**
특수 날씨가 너무 자주 나오면 "정상"이 없어져서 기준선이 사라진다. 절반은 맑음이어야 특수 날씨가 이벤트로 느껴진다.

**Q. 낮/밤과 날씨는 왜 분리되는가?**
낮/밤은 전투 규칙을 바꾼다 (선제 스킵, 정보 은닉). 날씨는 전투 규칙을 안 건드린다. 층위가 다르다.

**Q. v0.1 날씨 효과는 왜 무효화됐는가?**
안개(시야 공유 해제), 비(좌우 시야), 눈(이동-1)이 전부 그리드 이동+타일 시야 기반. 이동 시스템 삭제로 전제가 사라짐.
