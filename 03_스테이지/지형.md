## ① 한 줄 요약

타일(바닥)과 지물(배치물)의 2층 구조. 타일 3종이 전투 스텝5 지형전환에만 영향하고, 지물은 기존 7스텝의 숫자만 변경한다. 새 규칙 없음.

## ② 규칙 정의

### 타일 (바닥) — 3종

| 타일 | 효과 | 7스텝 위치 |
|------|------|-----------|
| 고지 | ✕→⚔ 전환 | 스텝5 지형전환 |
| 엄폐 | ✕→🛡 전환 | 스텝5 지형전환 |
| 평지 | 전환 불가 | — |

| 필드 | 내용 |
|------|------|
| **전환 수** | 1개 주사위만 전환 가능. 양쪽 각각 |
| **적용 대상** | 양쪽 모두 적용 |
| **타이밍** | 스텝5 (리롤 후, 유닛 전환 전) |
| **평지** | 전환 불가. 스텝5 자동 스킵 |

### 지물 (타일 위 배치물)

| 지물 | 효과 | 7스텝 위치 |
|------|------|-----------|
| 고지 지물 (망루, 성벽 위) | 궁병 선제 +1기 | 스텝1 선제 |
| 엄폐 지물 (숲, 바리케이드) | ✕→🛡 전환 추가 | 스텝5 지형전환 |
| 좁은 길목 | 동시 교전 주사위 상한 제한 | 스텝3 전체 굴림 |
| 함정 | 전투 시작 전 적 1기 제거 | 스텝1 이전 |

| 필드 | 내용 |
|------|------|
| **원칙** | 기존 7스텝에 숫자를 더하거나 빼기만. 새 규칙 없음 |
| **복합 배치** | 하나의 타일에 복수 지물 가능 (성벽 위 + 망루 등) |
| **스테이지별** | 지물 배치는 스테이지 모듈에서 정의 |

### 이전 버전과의 차이

| v0.1 (폐기) | v0.2 (현행) |
|-------------|-------------|
| 4종 단일 구조 (평원/산/숲/언덕) | 타일 3종 + 지물 분리 |
| 산 = 이동 불가 | 이동 시스템 삭제로 불필요 |
| 숲 = ✕→⚔, 언덕 = ✕→🛡 | 고지 = ✕→⚔, 엄폐 = ✕→🛡 (동일 문법, 이름 변경) |
| 지물 개념 없음 | 망루/바리케이드/함정/길목 등 배치물 |

### 2층 구조

```
┌─────────────────────────────┐
│  지물 (배치물)                │  ← 망루, 바리케이드, 함정 등
│  기존 7스텝 숫자만 변경        │
├─────────────────────────────┤
│  타일 (바닥)                  │  ← 고지, 엄폐, 평지
│  스텝5 지형전환에만 영향       │
└─────────────────────────────┘
```

### 지물이 7스텝에 끼는 위치

```
[함정]  [1.선제(+망루)]  [2.카드]  [3.굴림(길목)]  [4.리롤]  [5.지형(타일+엄폐)]  [6.전환]  [7.사상자]
  ↑         ↑                        ↑                          ↑
스텝1전   스텝1                     스텝3                      스텝5
```

### 복합 배치 예시: 공성전

```
성벽 위 타일 (고지) + 망루 (지물) + 바리케이드 (지물)
→ 스텝1: 궁병 선제 +1기 (망루)
→ 스텝5: ✕→⚔ (고지 타일) + ✕→🛡 (바리케이드)
→ 새 규칙 없음. 숫자만 합산.
```

## ⑥ 설계 근거

**Q. 왜 타일과 지물을 분리했는가?**
v0.1의 단일 구조(타일 1개 = 지형 1개)로는 성벽+사다리+성문+망루 공존이 불가능했다. 태그 방식은 예외처리 지옥. 바닥(타일)과 배치물(지물)을 분리하면 조합이 자유롭고 규칙 추가 없이 숫자만 변경.

**Q. 왜 타일이 3종인가?**
전투 스텝5 지형전환의 결과가 ⚔ 또는 🛡 둘 뿐이므로, 고지(→⚔)와 엄폐(→🛡)와 평지(전환 없음)가 최소 완전 집합.

**Q. 양쪽 적용은 유지되는가?**
유지. v0.1과 동일한 이유 — 일방 적용이면 "유리한 지형으로 가라"가 최적해. 양쪽 적용이면 소규모 부대에서 비율 이득이 더 크다.

**Q. 지물이 새 규칙을 추가하지 않는다는 게 어떤 의미인가?**
망루 = 스텝1에 숫자 +1. 함정 = 스텝1 이전에 숫자 -1. 바리케이드 = 스텝5에 전환 +1. 전부 기존 스텝의 숫자 조작. 플레이어가 새 규칙을 학습할 필요 없음.
