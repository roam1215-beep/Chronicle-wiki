# STAGE-TERRAIN: 지형 (Terrain)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** STAGE-TERRAIN · **수정일:** 2026-02-25

---

## ① 한 줄 요약

4종 지형. 평원은 중립, 산은 벽, 숲은 공격 보너스, 언덕은 방어 보너스. 소규모 부대일수록 지형 효과의 상대적 가치가 크다.

---

## ② 규칙 정의

| 지형 | 효과 |
|------|------|
| 평원 | 효과 없음 |
| 산 | 이동 불가 |
| 숲 | ✕ 1개를 ⚔로 전환 (양쪽 적용) |
| 언덕 | ✕ 1개를 🛡로 전환 (양쪽 적용) |

### 적용 규칙

| 필드 | 내용 |
|------|------|
| **전환 수** | 1개 주사위만 전환 가능. 양쪽 각각 |
| **적용 대상** | 양쪽 모두 적용 |
| **타이밍** | ⑤ 지형 전환 페이즈 (전투 카드 사용 후, 보병 전환 전) |
| **순서** | 전투 카드 → 지형 전환 → 보병 전환 → 최종 확정 |

---

## ③ 시각 자료

```
적용 순서:
④ 전투 카드  →  ⑤ 지형 전환  →  ⑧ 보병 전환  →  최종 확정

숲 예시: 보병 ⚔⚔🛡🛡[✕]✕  →  ⚔⚔🛡🛡[⚔]✕  (빈손 → 칼)
언덕 예시: 보병 ⚔⚔🛡🛡[✕]✕  →  ⚔⚔🛡🛡[🛡]✕  (빈손 → 방패)
```

## ⑥ 설계 근거

**Q. 왜 양쪽에 다 적용되는가?**
일방 적용이면 지형이 항상 유리해서 "숲으로 가라"가 최적해. 양쪽 적용이면 소규모 부대에서 비율 이득이 더 크므로 테오도라 대에게 상대적으로 유리한 구조. 시뮬 검증됨.
