# STAGE-CONSCRIPT: 징집병 (Conscripts)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** STAGE-CONSCRIPT · **수정일:** 2026-02-25

---

## ① 한 줄 요약

양쪽 자동 스폰, 자동 전진하는 배경 전선. 아군 징집병은 기본적으로 약해서 자연스럽게 밀리며, 테오도라 대의 개입 필요성을 만든다.

---

## ② 규칙 정의

| 필드 | 내용 |
|------|------|
| **스폰** | 양쪽 주기적으로 일정 턴마다 자동 스폰 |
| **이동** | 매 턴 1칸. 아군은 우측, 적은 좌측 |
| **전투** | 같은 주사위 전투 시스템 사용 |
| **면 구성** | 밸런싱 영역 (기본적으로 민병 수준) |
| **아군 징집병** | 기본적으로 약함. 자연스럽게 밀리는 구조 |
| **적 추가** | 적도 징집병 외 별도 부대 보유 |
| **합류** | 테오도라 대와 같은 타일이면 합산 전투 |

---

## ③ 시각 자료

```
좌(아군)                              우(적)
  [아군 징집병] →→→  충돌  ←←← [적 징집병]
                      ↑
              테오도라 대 개입 가능

아군 징집병 ≈ 민병 수준 (약함)
적 징집병 + 적 별도 부대 = 점진적 우세
→ 개입 없으면 밀림
```

## ⑥ 설계 근거

**Q. 왜 징집병이 자동인가?**
플레이어가 모든 유닛을 직접 통제하면 RTS가 된다. 징집병이 자동이어야 테오도라 대의 "어디에 개입할 것인가"라는 판단이 핵심이 된다.

**Q. 왜 아군이 약한가?**
아군이 강하면 개입할 필요가 없다. 약해서 밀리니까 테오도라가 가야 하고, 어디를 먼저 갈지가 판단.
