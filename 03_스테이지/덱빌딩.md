# STAGE-DECK-001: 덱빌딩 — "겪은 것이 덱이 된다"

> **상태:** 🔄 설계중 · **버전:** 0.8 · **ID:** STAGE-DECK-001 · **수정일:** 2026-03-04

---

## ① 한 줄 요약

Stage마다 이벤트 5장 + 운명 1장 = 6장 덱. 분기 효과가 유일한 보상. 테오도라는 업적 카드로 성장하고, 패시브는 키워드 형태로 카드에 붙는다.

---

## ② 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **서사-메카닉 일치** | 겪은 것이 나를 만든다. 플레이 이력이 곧 빌드. |
| **전투는 주사위** | 카드는 전투 조건을 세팅한다. 전투 안에서 주역은 주사위. |
| **분기 효과가 유일한 보상** | 추상 자원(토큰) 없음. 분기를 고르면 그 효과가 곧 보상. |

---

## ③ 카드의 세 얼굴

| 얼굴 | 역할 | 예시 |
|------|------|------|
| **이야기** | 사건 서술 + 분기 선택 | "강변의 보초를 기습했다" |
| **재료** | 분기 선택이 부대 상태와 전투 조건을 변화 | 전투 버프 획득, 병종 합류 등 |
| **기록** | 사서 로그에 기록. 겪은 카드로 보존 | 📜 "테오도라 대, 다리 위의 보초를 기습하다." |

## ⑤ 테오도라 성장 시스템

### 업적

> ⚠️ **업적 시스템 폐기 (카드풀구조 v3, 2026-03-08).** A풀(미덕) → 추종자 패시브로 흡수. B풀(악덕) → Named 특성으로 재정의. 성장 시스템은 추종자로 통합.

| 필드 | 내용 |
|------|------|
| **Named 특성 (구 B풀)** | 적/아군 Named 공통. 처음부터 보유. 잔혹한/고집센/겁이많은/교활한/집요한/위선적인 → 영웅.md 참조 |
| **추종자** | 운명 승리 시 2명 제시 1명 선택. 패시브 + 조언. A풀 역할 흡수 → 추종자.md 참조 |
| **플레이버** | "형용사 + 이름" (예: 용감한 테오도라, 잔혹한 마르쿠스) |
| **보유 상한** | 테오도라 실질 2개. 적 Named 최대 3개 |

### 패시브

| 필드 | 내용 |
|------|------|
| **정체** | 병종 기반 능력. 민병 제외 기본 보유 |
| **슬롯** | 최대 1개 (병종당 고정) |
| **초기 상태** | 민병 제외 전 병종 기본 보유 |

> **성장과 패시브는 별개 시스템.** 패시브 = 병종 기반(방진/반격/선제공격/쇄도), 기본 보유. 성장 = 추종자(패시브 수정자) + Named 특성(고유 성격).

## ⑥ 운명 달성 = 결산

| 항목 | 내용 |
|------|------|
| **부상 회복** | 전투 종료 즉시 자동 회복. Named만 부상, Nameless 피격 = 즉사 |
| **업적 (A풀)** | Chapter 전환 시 A풀 랜덤 부여. 테오도라 전용 성장 |
| **서사** | 군공을 세웠다. 기록할 가치가 있는 사건 |

> 별도 야영 페이즈 없음. Stage 간 결산도 없음 (책장 넘기기만). Chapter 전환 시 업적 카드.

## ⑦ 런 전체 카드 물량

| 항목 | 값 |
|------|-----|
| 막 / 런 | 6 (1장=2막, 2·3장=3막) |
| **총 카드 소모 / 런** | **48~60장** |
| 전투 / 런 | 18장 (막당 3장) |
| 사건 / 런 | 18장 (막당 3장) |
| 우연 / 런 | 6~18장 (상황 의존) |
| 운명 / 런 | 6장 (막당 1장) |

> 팩/시리즈 구조 폐기. 권 = 풀. 상세 → [카드풀구조_초안_v3](../DOCS/DESIGN/카드풀구조_초안_v3.md)

| 규칙 | 내용 |
|------|------|
| **풀 구조** | 권 전체 단일 풀. 범용/전용 구분 없음. 런 내 비중복 뽑기 |
| **운명 카드 풀** | 권 풀 소속. 런 시작 시 6장 비중복 뽑기 |
| **셔플 제약** | 같은 유형 3장 불가. 우연 페이즈당 최대 1장 |

## ⑧ 폐기된 시스템

| 시스템 | 대체 | 사유 |
|--------|------|------|
| **토큰 3종** | 분기 효과 | 전략 토큰이 로그라이크 리플레이 파괴 |
| **보급** (붕대/방패/검/깃발) | 분기 효과 | 겪은 카드의 분기가 전투 조건 역할 |
| **야영** | Chapter 전환 시 회복 | 별도 야영 불필요 |
| **유물 시스템** (겪은 카드 → 성향별 테이블 → 패시브) | 업적 카드 | 성향 집계 복잡. 업적 카드(3종 택1)가 더 깔끔 |
| **Nameless→Named 승급** | 폐기 (대체 없음) | Named = 테오도라 1기만. 승급 비용 과대 |
| **스테이지 카드/챕터 카드 압축** | 업적 카드로 단순화 | 압축 구조 제거. 성장은 업적 카드로 표현 |

## ⑩ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 토큰을 폐기했나? | 전략 토큰이 로그라이크 리플레이를 파괴. 분기 효과가 더 강한 보상 |
| 왜 유물 시스템을 업적 카드로 대체했나? | 겪은 카드 성향 집계는 복잡하고 1인 개발 부담. 3종 택1이 깔끔하고 플레이어 선택이 명확 |
| 왜 승급을 폐기했나? | "누굴 골라서 네임드로 올려준다" 자체가 경험과 안 맞음. 테오도라만 업적으로 성장하는 게 깔끔 |
| 왜 업적 카드를 다음 Chapter 모르고 고르나? | 의도된 정보 비대칭. 하다 보면 알게 되는 규칙. 핵심 경험 "닥친 상황에 적응"과 일치 |
