# STAGE-DECK-001: 덱빌딩 — "겪은 것이 덱이 된다"

> **상태:** 🔄 설계중 · **버전:** 0.3 · **ID:** STAGE-DECK-001 · **수정일:** 2026-02-28

---

## ① 한 줄 요약

스테이지에서 겪은 카드와 선택이 유물 재료가 된다. 카드 한 장이 이야기이고, 재료이고, 기록이다.

---

## ② 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **서사-메카닉 일치** | 겪은 것이 나를 만든다. 플레이 이력이 곧 빌드. |
| **전투는 주사위** | 카드는 전투 조건을 세팅한다. 전투 안에서 주역은 주사위. |
| **분기 효과가 유일한 보상** | 추상 자원(토큰) 없음. 분기를 고르면 그 효과가 곧 보상. |

---

## ③ 카드의 세 얼굴

| 얼굴 | 역할 | 예시 |
|------|------|------|
| **이야기** | 사건 서술 + 분기 선택 | "강변의 보초를 기습했다" |
| **재료** | 스테이지 끝 유물 생성의 인풋 | 전투 카드 다수 겪음 → 공격 계열 유물 풀 |
| **기록** | 사서 로그에 기록. 스테이지 카드 안에 묶여 보존 | 📜 "테오도라 대, 다리 위의 보초를 기습하다." |

> v0.1에서 "토큰" 얼굴 제거. 토큰 체계 전면 폐기 (v0.2).

## ④ 분기 효과 → 전투 연결

> 상세 규칙은 → [STAGE-CARD-002 스테이지카드규칙](./스테이지카드규칙.md) 참조

| 항목 | 내용 |
|------|------|
| **전투 버프** | 비전투 카드 분기에서 획득. 면 확정, 리롤 추가, 적 정보 공개, 선제 등 |
| **버프 슬롯** | 1개. 새 버프 받으면 기존 덮어쓰기 |
| **지속** | 다음 전투 한정. 사용하면 소멸 |
| **부대 변화** | 병종 합류, 부상, 사망 등은 영구 |
| **전투 카드** | 분기 양쪽 다 전투. 적 편성/조건이 다름 |

## ⑤ 유물 시스템 (스테이지 카드)

### 유물 생성

| 필드 | 내용 |
|------|------|
| **생성 시점** | 운명 달성 (스테이지 클리어) 시 |
| **인풋** | 겪은 카드 내역 (전투/비전투 비율) + 선택한 분기 성향 + 전투 결과 |
| **방식** | 시스템이 인풋 기반으로 해당 성향 테이블에서 효과 결정 |
| **결과물** | 유물 1장 = 스테이지 카드. 칭호 + 영구 패시브 |
| **예시** | 전투 카드 다수 + 공격적 분기 → 공격 테이블 → "다리 위의 테오도라 — [피의 진격]" |

### 유물 재료 집계 (v0.2 변경)

| 인풋 | 설명 |
|------|------|
| **겪은 카드 구성** | 전투 카드 vs 비전투 카드 비율 |
| **선택한 분기 성향** | 공격적 분기 vs 신중한 분기. 분기마다 성향 태그 가능 |
| **전투 결과** | 승리 방식 (압승/신승/피로스), 부상/사망 수 |
| **우연 경험** | 우연 카드 전투/비전투 여부 |

> v0.1의 "토큰 잔여 집계" 폐기. 겪은 경험 자체가 재료.

### 유물 규칙

| 필드 | 내용 |
|------|------|
| **영구** | 획득 이후 모든 전투에 적용 |
| **패시브** | 플레이어가 능동 사용하지 않음. 조건 충족 시 자동 발동 |
| **묶임** | 스테이지 카드 안에 겪은 사건 카드들이 보존됨. 희생 아님 |
| **열기** | 유물을 열면 겪은 사건들이 다 보임 (사서 기록) |

### 칭호 — 헤라클레스 방식

| 필드 | 내용 |
|------|------|
| **명명** | 추상 덕목이 아니라 겪은 사건/장소가 이름이 됨 |
| **예시** | "부서진 다리의 테오도라", "검은 숲의 테오도라" |
| **서사** | 네메아의 사자 → 헤라클레스의 용맹. 군공이 곧 이름 |

## ⑥ 압축 구조 — 5층 카드 대응

| 게임 층위 | 카드 층위 | 내용 |
|----------|----------|------|
| Battle | 겪은 사건 카드 (낱장) | 이야기 + 재료 + 기록 |
| Stage | 스테이지 카드 (유물) | 사건들 묶음 → 칭호 + 영구 패시브 |
| Chapter | 챕터 카드 | 스테이지 카드들 묶음 → 더 강한 패시브 |
| Order | 오더 카드 (성적표) | 챕터 카드들 묶음 → 런 전체 기록. 게임 효과 없음 |

### 압축 흐름

```
겪은 사건들 ──묶임──→ [스테이지 카드]
                      "다리 위의 테오도라"
                       칭호 + 패시브

스테이지 카드들 ──묶임──→ [챕터 카드]
                         "오를레앙의 테오도라"
                          더 강한 패시브

챕터 카드들 ──묶임──→ [오더 카드]
                      "강철의 성녀 테오도라"
                       성적표 (효과 없음)
```

> 묶임이지 희생이 아니다. 상위 카드를 열면 하위 카드가 전부 보인다. 종이가 쌓여 역사가 된다.

## ⑦ 운명 달성 = 결산 (야영 대체)

| 항목 | 내용 |
|------|------|
| **부상 회복** | 기본. 달성하면 전원 자동 회복 |
| **유물 생성** | 겪은 내역 기반 스테이지 카드 탄생 |
| **면 교체** | ✕ 1개 → ⚔/🛡/✕ 랜덤 교체. 매 스테이지 클리어 시 1회 |
| **프로모션** | Nameless→Named 승급. 운명 보상 한정. 매우 귀함 |
| **서사** | 군공을 세웠다. 기록할 가치가 있는 사건 |

> 별도 야영 페이즈 없음. 운명 달성의 결산 과정이 야영.

## ⑨ 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| **유물 테이블 구조** | 성향별 테이블 방향. 구체 인풋/아웃풋 미정 | 카드 9장 실물 설계 + 효과 풀 |
| **분기 성향 태그** | 방향만 있음. 공격/신중 같은 태그를 분기에 붙일지 | 카드 설계 시 확정 |
| **챕터 카드 합치기 규칙** | 스테이지 카드들이 묶이는 것만 확정 | Order 1 챕터 구조 확정 후 |
| **브리핑 준비 요소** | 미정. 현재 운명 공개 + 위업 수락만 존재. 추가 준비 메카닉 필요 여부 미정 | 전투 밸런스 설계 시 |

## ⑩ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 토큰을 폐기했나? | 전략 토큰이 로그라이크 리플레이를 파괴. 토큰 축적이 운명 전투를 왜곡. 분기 효과가 "창병이 합류했다"처럼 토큰 +1보다 강한 보상 |
| 왜 유물 재료가 겪은 카드+선택 기반인가? | 토큰 잔여 집계는 추상적. "전투 카드를 많이 겪고 공격적으로 플레이했다"가 더 서사적 |
| 왜 유물이 랜덤 테이블인가? | 확정 조합표 → 최적해 도출. 테이블 → 방향은 내 선택, 결과는 확정 아님. 주사위 게임 철학과 일치 |
| 왜 헤라클레스 방식 칭호인가? | 추상 덕목(용맹 Lv3)보다 구체 사건(다리 위의 테오도라)이 기억에 남고 사서 프레임과 정합 |
| 왜 압축이 희생이 아니라 묶임인가? | 카드 = 시간 = 기록. 역사는 사라지지 않고 쌓인다 |
