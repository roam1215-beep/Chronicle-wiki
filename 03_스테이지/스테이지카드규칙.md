# 카드 시스템

## 구조

```yaml
Stage = 4 Phase
Phase = 3장 (선택 + 거부 + 감내) 또는 운명 Phase (운명 카드 1장)

7장면 = Stage 단위
인격 = Order 단위 (같은 자리의 다른 가능세계)
```

## 페이즈 진행

```yaml
어휘: 선택 - 거부 - 감내

선택: 1번 카드 박음 (효과 발동)
거부: 1번 카드 거부 (효과 X)
감내: 2번 카드 박음 (자동, 거부 X)

발화 순서: 1번 → 2번 → 거부 카드
비가역 결정

뒷면 2상태:
  Dark:  미공개 (정보 X)
  Type:  분류만 공개 (전투/사건/우연/운명)
```

## 카드 종류

```yaml
스토리 카드 (270장 = Order 1 작품 그릇):
  전투 카드:  적 부대 등장. Battle 1개 = 전투 카드 1장. 페이즈당 최대 2 Battle
  사건 카드:  결과형 단일 (분기 X). 즉발
  우연 카드:  5 자리 (위기/기회/축복/저주/예언). 분기 = 축복·저주만
  운명 카드:  운명 Phase 1장. Stage 팩 공용 뒷면

인물 카드 (별도 영구 컬렉션):
  영구 컬렉션 결 (작품 결, DLC 입자)
  같은 인물 = 여러 카드 가능 (붕어빵 풀 — 다른 자리·시점·인격의 기본형)
  명시적 해금 (가챠 X)
  Order 진행으로 풀에 누적

참조 결:
  전투·운명 카드 = 인물 카드 ID 참조
  적 부대 = 인물 카드 풀에서 호출
  예: 전투 카드 "마을 침공" → 인물 카드 풀에서 "도적 졸병" × 3 호출

대적자:
  운명 카드의 적 인물 = 그 스테이지의 대적자
  대적자 본체 동일, 인격별 표현 분기 (가능세계)
  예: 라키아의 사자 = 발드 (Order 1 챕터 1 스테이지 1의 대적자)
```

## 정보 공개

```yaml
적 유닛 모형 위:
  노출:    위계 (인간/영웅/무리/재앙) + 자기 시간대 + hp 바 + 보호막 개수 + 방어도 수치 + 직업 아이콘
  비노출:  등급 (가호 수로 드러남), 공격력

정보 비대칭:
  아군: hp + 보호막 + 방어도 (정확한 숫자)
  적:   hp 바 + 보호막 개수 + 방어도 수치 (유추)
```

## 인격 (Order 단위)

```yaml
시스템: 그리스 4주덕 (지혜·용기·절제·정의)
인물 = 4주덕 중 3 인격 보유. 빠진 1개 = 정체성
Order 단위 — 한 회차 = 1 인격 팩 (90장)

같은 인물, 다른 인격 = 다른 가능세계
같은 자리(챕터·스테이지)도 인격마다 다른 명명 가능

해금:
  Order 클리어 시 다른 인격 해금
  같은 Order 다른 인격 = 다른 결의 자리 박힘
  [구체 결 = 펜딩, 작가 결]

예: 테오도라 — 용기 / 지혜 / 정의 (빠진 절제 = 정체성)
    표기 = 용맹한 / 지혜로운 / 정의로운 테오도라
```

## 카드 단위

```yaml
Order = 작품 그릇 = 확장팩 단위 = 270 스토리 카드
  예: "미궁의 테오도라 팩"

인격 팩 = 90장 = 한 회차 = 9 스테이지
  = 81 일반 + 9 운명

스테이지 = 10장 = 9 일반 + 1 운명

페이즈 카드 = 3장 (일반 페이즈) 또는 1장 (운명 페이즈)

챕터 단위 그릇 X (챕터는 진행 단위로만 작동)
인물 카드는 카드 단위 그릇 밖 (영구 컬렉션)
```
