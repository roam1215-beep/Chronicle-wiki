## ① 한 줄 요약

뒷면 3장이 제시된다. 홀드 탭으로 유추한다. 2장을 블라인드로 고른다. 1장은 전해지지 않은 이야기로 사라진다. 고른 카드를 뒤집고 분기를 선택한다. 모든 페이즈가 끝나면 운명 전투.

## ② 막 시작 — 풀에서 뽑기

각 막 시작 시 권 풀에서 카드를 뽑아 막 덱을 구성한다.

| 단계 | 처리 |
|------|------|
| 1 | 전투 풀에서 3장 뽑기 (런 내 비중복) |
| 2 | 사건 풀에서 3장 뽑기 (런 내 비중복) |
| 3 | 우연 풀에서 N장 뽑기 (배경 장소가 결정. 런 내 비중복) |
| 4 | 전투+사건+우연 셔플 |
| 5 | 운명 카드 1장 배치 (런 시작 시 배정됨. 마지막 위치 고정) |

> **풀 상세:** → [카드풀구조_초안_v3](../DOCS/DESIGN/카드풀구조_초안_v3.md) 참조

### 셔플 제약

| 규칙 | 내용 |
|------|------|
| 같은 유형 3장 불가 | 한 페이즈에 전투-전투-전투, 사건-사건-사건 불가 |
| 우연 페이즈당 최대 1장 | 한 페이즈에 우연 2장 이상 불가 |

### 페이즈 수 (장별)

| 장 위치 | 페이즈 수 | 성격 |
|---------|----------|------|
| 1장 | 3페이즈 | 도입 |
| 2장 | 3페이즈 | 전개 |

### 페이즈 흐름

| 순서 | 처리 | 수동/자동 |
|------|------|----------|
| 1 | 셔플된 막 덱에서 **뒷면 3장 제시** | 자동 |
| 2 | **홀드 탭** — 카드를 길게 누르면 뒷면 유형(전투/사건) 확인. 우연 위장으로 확신 불가 | **수동** |
| 3 | **블라인드 2장 선택** — 우연 위장이 있어 확신 없이 고름 | **수동** |
| 4 | 안 뽑힌 1장 → **전해지지 않은 이야기** (뒷면 채 퇴장. 내용 미공개) | 자동 |
| 5 | 선택한 2장 뒤집기 → **플레이 순서 결정** (플레이어) → 순차 플레이 | **수동** |

> **핵심 판단:** "뭘 가져갈 것인가"(붙잡기) + "어떤 순서로 볼 것인가"(뒤집기). → [CORE-001 핵심경험목표](../01_코어/핵심경험목표.md) 참조

## ④ 홀드 탭 + 우연 위장

### 뒷면 유형 — 2종

이야기 카드 뒷면은 **전투 뒷면**과 **사건 뒷면** 2종이 존재한다. 홀드 탭(길게 누르기)하면 뒷면 유형이 보인다.

| 뒷면 유형 | 홀드 탭 시 | 실제 카드 |
|-----------|----------|----------|
| **전투 뒷면** | "전투 카드" | 전투 카드 **또는** 전투로 위장한 우연 카드 |
| **사건 뒷면** | "사건 카드" | 사건 카드 **또는** 사건으로 위장한 우연 카드 |
| **운명 뒷면** | 금색 테두리 | 운명 카드 (항상 진짜) |

### 우연 위장

우연 카드는 자기 뒷면이 없다. 전투 뒷면 또는 사건 뒷면 중 하나로 위장한다.

| 항목 | 내용 |
|------|------|
| **위장 규칙** | 우연 카드마다 위장 유형이 사전 결정 (전투 or 사건) |
| **뒤집기 전** | 홀드 탭으로는 진짜 전투/사건과 우연 위장을 구분할 수 없음 |
| **뒤집은 후** | 앞면이 우연 카드 → 즉시 발동. 분기 없음 |
| **우연 빈도** | **배경의 장소가 결정.** 우연이 많은 장소 = 위장이 많아 홀드 탭 신뢰도 하락 |

### 정보 신뢰도

| 신뢰도 | 조건 |
|--------|------|
| **확실** | 운명 카드 (금색 테두리. 위장 없음) |
| **높음** | 우연 빈도 낮은 장소. 홀드 탭이 대체로 맞음 |
| **낮음** | 우연 빈도 높은 장소. 홀드 탭해도 위장이 섞여 있음 |

> **핵심:** 정보가 있는데 믿을 수 없다. "이건 전투겠지" → 뒤집으면 우연. 완전 블라인드도 완전 공개도 아닌 **불완전한 정보.**
> → [META-BACKDROP 배경](../04_메타/배경.md) 장소별 우연 빈도 참조

## ⑤ 카드 종류

### 이야기 카드 뒷면 — 2종 (전투/사건)

| 필드 | 전투 뒷면 | 사건 뒷면 |
|------|----------|----------|
| **디자인** | 권 공통. 전투 표식 | 권 공통. 사건 표식 |
| **정보량** | "전투 카드" — 다만 우연 위장 가능 | "사건 카드" — 다만 우연 위장 가능 |
| **홀드 탭** | 길게 누르면 뒷면 유형(전투) 확인 | 길게 누르면 뒷면 유형(사건) 확인 |

### 운명 카드 뒷면 — 별도

| 필드 | 내용 |
|------|------|
| **디자인** | 금색 테두리. 이야기 카드와 다른 뒷면 |
| **식별** | 마지막 카드가 운명이라는 것을 알 수 있음 |
| **위치** | 항상 마지막. 모든 페이즈 종료 후 자동 뒤집기 |

### 전투 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 전투 진입. 분기 양쪽 다 전투 |
| **분기** | 최대 2개. "어떻게 싸울지" 선택 |
| **적 정보** | 서술로 힌트만. "보초 둘", "대규모 부대" 등. 적 상세는 전투 시작 후 공개 |
| **태그** | **유저 미노출.** 서술이 태그 효과를 암시 |

### 사건 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 준비 카드. 정보, 합류, 장비, 정찰 등 |
| **분기** | 최대 2개. 각 분기마다 다른 이득+비용 |
| **태그** | **유저 미노출.** 서술로만 유추 |

### 우연 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 통제 밖의 사건. 뒤집는 순간 즉시 발동 |
| **선택** | 없음. 분기 없음 |
| **종류** | 우연-전투 (강제 전투 진입) / 우연-이벤트 (즉발 효과) |
| **태그** | **유저 미노출** |

### 운명 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 장 제목 + 최종 전투 + 추종자 획득 |
| **구성** | 전략 태그 1(필수) + 전술 태그 1(필수) + 적 테이블 |
| **승리** | 추종자 2명 제시, 1명 선택 |
| **패배** | 게임 오버 |

## ⑥ 카드 앞면 레이아웃

### 전투/사건 카드

```
┌──────────────────────┐
│                      │
│   [배경 일러스트]      │
│                      │
├──────────────────────┤
│  「강변의 보초」        │  ← 카드 제목 (태그명 미노출)
│                      │
│  다리 이쪽 끝에 적    │  ← 상황 서술
│  보초 둘이 서 있다.   │
├──────────────────────┤
│  A. 숨어서 기습한다   │  ← 분기 선택지
│     효과 서술 텍스트   │     (태그 미노출. 서술로 효과 암시)
│     적 힌트: 보초 2기  │
│                      │
│  B. 정면에서 나선다   │
│     효과 서술 텍스트   │
│     적 힌트: 보초+지휘관│
└──────────────────────┘
```

> **태그 미노출 원칙:** 카드 앞면에 [기습], [봉쇄] 등 태그명을 표시하지 않는다. 서술이 효과를 암시할 뿐. 유저는 서술을 읽고 어떤 효과가 있을지 유추한다.

### 우연 카드

```
┌──────────────────────┐
│                      │
│   [배경 일러스트]      │
│                      │
├──────────────────────┤
│  「뜻밖의 조우」        │  ← 카드 제목
│                      │
│  풀숲에서 낯선 병사   │  ← 상황 서술 + 즉발 효과 서술
│  셋이 나타났다.       │
│  싸울 수밖에 없다.    │     (분기 없음. 즉시 발동)
└──────────────────────┘
```

| 항목 | 내용 |
|------|------|

## ⑩ 설계 근거

**Q. 왜 블라인드 선택인가?**
"정보는 부족하고 현장은 이미 달라져 있다" — 핵심경험목표의 구조적 구현. 뒤집기 전에 선택해야 하므로 홀드 탭으로 뒷면 유형을 확인하되, 우연 위장으로 불확실성은 남는다.

**Q. 왜 순차 뒤집기가 아닌가?**
순차 뒤집기는 플레이어 에이전시가 분기 선택뿐. 블라인드 선택은 "뭘 가져갈지"와 "뭘 버릴지"가 추가됨. 전해지지 않은 이야기가 만들어짐.

**Q. 왜 3장 중 2장인가?**
3장 전부 가져가면 블라인드 의미 없음. 1장만 가져가면 콘텐츠 소모가 너무 적음. 2장 선택 + 1장 버림이 "가져갈 것과 버릴 것의 판단"을 만드는 최소 구조.

**Q. 왜 태그를 미노출하는가?**
태그는 내부 메카닉. 유저에게 [기습]이라고 보여주면 "기습 = ⚔ 유리" 같은 메타 지식이 형성. 서술로만 암시하면 "숨어서 기습한다 → 유리할 것 같다"는 유추만 가능. 불확실성 유지.

**Q. 왜 뒷면이 전투/사건 2종인가?**
완전 블라인드(유형 정보 0)도, 완전 공개(유형 확정)도 아닌 불완전한 정보 구조. 홀드 탭으로 유형이 보이지만 우연이 위장하고 있어서 확신할 수 없다. "정보가 있는데 믿을 수 없다"가 핵심경험목표의 "정보는 부족하고 현장은 이미 달라져 있다"를 구현.

**Q. 왜 우연이 위장하는가?**
우연 = 통제 밖의 사건. 뒷면에 "우연"이라고 써 있으면 플레이어가 회피 가능. 위장하면 회피 불가. "전투인 줄 알고 골랐더니 우연"이라는 경험이 불확실성을 만든다. 우연 빈도는 배경(장소)이 결정하므로 장소를 아는 순간 "이번 런은 얼마나 믿을 수 있는가"를 직감할 수 있다.

**Q. 왜 운명이 마지막인가?**
준비→결전 구조. 페이즈에서 겪은 이야기 카드가 운명 전투를 위한 준비. 마지막인 걸 아니까 역산 전략이 생긴다.

**Q. 왜 스텝2(버프)가 비어있는가?**
이야기 카드 분기 효과(태그)가 직접 부대 상태를 변화시키는 구조. 별도 버프를 부여해서 전투 중 소모하는 구조가 아님. 전투 중 에이전시는 대형 선택(산개/밀집) + 리롤 + 방진/반격으로 충분.
