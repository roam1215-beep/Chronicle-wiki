# STAGE-CARD-002: 카드 시스템

> 상태: 결정정합 · 의존: @META-BOOK-001, @META-BACKDROP, @ORDER-001-CH

## 정의

카드 시스템 v4.0. 스테이지 = 4 페이즈 = 10장. 일반 페이즈 3개 (각 3장: 1정찰 + 1버림 + 1자동) + 운명 페이즈 1개 (운명 카드 1장). 변주 = 오더 단위 인격 (같은 자리의 다른 가능세계).

## 규칙

### 페이즈 진행 (정찰-판단-감내)

```yaml
일반_페이즈:
  1: 카드 3장 뒷면 제시
     뒷면 종류별 식별:
       전투 ⚔ / 사건 ✦ / 우연 ?
  2: 정찰 — 1장 골라 뒤집음 (내용 공개)
     전투/사건은 내용 노출. 우연은 "우연" 표시만
  3: 판단 — 1장 버림 (전해지지 않은 이야기. 영구 미공개)
  4: 감내 — 남은 1장 자동 공개 → 즉발

운명_페이즈:
  1: 일반 페이즈 3개 종료 후 자동 진입
  2: 운명 카드 1장 뒤집기 → 운명 전투
  3: 승리 → 다음 스테이지. 패배 → 게임 오버 (모든 운명 패배 시)
```

### 카드 종류

```yaml
스토리_카드: 전투 / 사건 / 우연 (한 풀 안에 섞임)
운명_카드:    스테이지당 1장 고정. 별도 풀
```

### 전투 카드

```yaml
표시: [텍스트] - 적 - 낮/밤
분기: 없음. 뒤집으면 즉시 전투
정찰 시: 적 정보 + 낮/밤 공개

낮/밤:
  낮: 적 정보 완전 공개 (예: "보병 2 + 궁병 1")
  밤: 적 정보 부분 공개 (예: "보병 2 + ?")

지형: 폐기 (스테이지 단위 = 장소가 흡수)
```

### 사건 카드 — 2 분류

```yaml
선택형:
  표시: [텍스트] - 분기 a/b/c (3 선택)
  결과: 각 분기마다 다름 (합류 / 아무일 / 전투 전환 등)
  정찰 시: 텍스트 + 분기 라벨 공개. 단 전투 전환 시 적·낮밤은 비공개
  
결과형:
  표시: [텍스트] - 결과 1
  결과: 즉발. 분기 없음
  정찰 시: 텍스트 + 결과 공개

내부 라벨: 카드 데이터에 "선택/결과" 박힘. 유저는 식별표시 없음
비율 (잠정): 선택형 30 / 결과형 30 — 종이 프로토 후 확정
```

### 우연 카드 — 5 자리

```yaml
정찰 시: "우연 카드"만 표시 (5 자리 어느 것인지 모름). 가장 강한 ?
닫힘: 카드 안 엄격 (예언 정보만 유저 기억으로 살음)

5 자리:
  위기:  강제 전투. 적이 더 많거나 불리한 상태. 분기 없음
  기회:  강제 전투. 아군이 유리한 상태. 분기 없음
  축복:  선택형 이득. 분기 (a/b/c 등 — 무엇을 가져갈지)
  저주:  선택형 손해. 분기 (a/b/c 등 — 무엇으로 손해볼지)
  예언:  운명 카드에 대한 힌트 (발드 / 부대 구성 등). 카드 넘어가면 표시 사라짐 (유저 기억만)

불운/행운 라벨: 폐기 (5 자리 자체가 결을 결정)
비율 (잠정): 5 자리 균등 ± 작가 결. 종이 프로토 후 확정
```

### 운명 카드

```yaml
역할: 스테이지의 닻. 페이즈 4
구성: 텍스트 + 적 + 낮/밤 + 변주별 표현 (부대·지형·배경 변주)
변주: 본체 동일 (같은 인물). 표현은 변주별 다름 = "가능세계의 같은 인물"
정찰: 정찰 단계 없음. 운명 페이즈 진입 시 자동 공개
패배: 게임 오버 (모든 운명 패배 시)
```

### 카드 비율 — 변주(인격) 단위 금형

```yaml
원칙:
  - 변주 = 작가가 짠 한 인격 결의 카드 묶음 (오더 팩 = 90장)
  - 페이즈 단위 종류 강제 X
  - 통제 자리 = 변주 단위 (작가가 인격 결로 비율 짬)
  - 0 금지: 어떤 종류든 최소 1장 (전투·사건·우연 다 만남 보장)

잠정 시드 (스테이지 = 10장 기준):
  편중형 변주: 한 종류 4~5장 + 다른 종류 2~3장
  균형형 변주: 전 3 / 사 3 / 우 3 / 운 1
  → 종이 프로토 후 확정

자연_산출:
  변주(인격)가 짜이면 비율은 자연 산출
  강제 비율 X. 작가 결의 결과
```

### 변주 시스템 (오더 단위 인격)

```yaml
변주 = 가능세계 = 같은 자리의 다른 인격
단위: 오더 팩 (90장)
한 오더 = 인격 풀 (Order 1 = 용맹 / 지혜 / 광명. 광명은 1·2 클리어 시 해금)

선택_시점: 오더 시작 시 1번 (9 스테이지 통째)
첫_회차:   작가 표준 인격 고정 (Order 1 = 용맹)
재플레이: 해금된 인격 풀에서 선택

명명:
  오더 팩:   "서자, 테오도라 — 용맹"
  스테이지: "라키아의 서자" (변주 라벨 안 붙음)
  
미답파 시각화:
  본 인격 = 안 빛남. 안 본 인격 = 빛남 (사서 프레임 = 미답파 페이지)

상세: @ORDER-001-CH
```

### 환경 영향 — 정찰

```yaml
날씨 (@META-BACKDROP):
  맑음:   영향 없음
  흐림:   정찰 시 1장만 노출 (3장 중 1장)
  안개:   뒷면이 모두 ?로 처리 (종류 식별 불가)
  악천후: 정찰 스킵 + 시스템 임의 1장 집고 1장 버림

장소 (@META-BACKDROP):
  라키아: 특수 규칙 없음
  미궁:   우연 카드 ? 해제 (정찰 시 전투/사건 중 무엇으로 노출)
  기타:   장소별 특수 규칙. 펜딩
```

### 전해지지 않은 이야기

```yaml
정의: 페이즈에서 버린 카드
공개: 없음. 영구 미공개로 버림 패에 들어감
서사: "모든 이야기가 겪어지는 것은 아니다"
기록 상태: 정사 / 야사 / 미기록 / 전해지지 않은 이야기 (4번째 상태)
```

### 카드 총량 (오더 1 기준)

```yaml
한 오더 (광명 해금 전):
  용맹 팩: 90장 (81 일반 + 9 운명)
  지혜 팩: 90장 (81 일반 + 9 운명)
  합계:    180장

광명 해금 시:
  광명 팩: 90장 (81 일반 + 9 운명)
  합계:    270장

운명 카드: 18장 (스테이지 9 × 변주 2). 광명 해금 시 27장
일반 카드: 162장 (스테이지 9 × 변주 2 × 9). 광명 해금 시 243장
```

### 폐기 항목

```yaml
- 챕터 팩 30장 (일반 27 + 운명 3):       5-7 폐기 (오더 팩 단위 90장으로 변경)
- 페이즈 = 정찰-판단-감내 (3장):          v3.0 골격 살림. 형식만 v4.0 정정
- 사건 카드 분기 폐기:                     v3.0 폐기 → 5-7 부활 (선택형/결과형 분리)
- 뒷면 1종 (팩 뒷면):                       5-7 폐기 (종류별 뒷면. 우연만 ?)
- 우연 카드 = 전투/사건 중 하나:           5-7 폐기 (5 자리 = 위기/기회/축복/저주/예언)
- 추종자 시스템:                            5-7 폐기 (다른 세션)
- 태그 시스템:                              5-7 폐기 (다른 세션)
- 적 테이블 Lv (챕터 난이도):              5-7 펜딩
- 변주 시스템 = 스테이지 단위:             5-7 폐기 (오더 단위 인격으로 변경)
- 변주 = 통계 분포 (전투형/우연형):        5-7 폐기 (가능세계 = 인격 결로 변경)
```
