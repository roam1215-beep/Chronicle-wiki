# STAGE-CARD-002: 이야기 카드 규칙 (Story Card Rules)

> **상태:** 🔄 설계중 · **버전:** 3.0 · **ID:** STAGE-CARD-002 · **수정일:** 2026-03-10

---

## ① 한 줄 요약

뒷면 3장이 제시된다. 1장을 정찰해서 정체를 확인한다. 1장을 버린다. 남은 2장을 순차로 겪는다. 뒤집으면 즉발. 분기 없음. 모든 페이즈가 끝나면 운명 전투.

---

## ② Stage 시작 — 팩에서 뽑기

각 Stage 시작 시 해당 챕터 팩에서 뽑아 막 덱을 구성한다.

| 단계 | 처리 |
|------|------|
| 1 | 챕터 팩(일반 27장)에서 9장 비중복 뽑기. 유형 지정 없음 |
| 2 | 9장 셔플 |
| 3 | 3장씩 3페이즈에 배분 |
| 4 | 운명 카드 1장 배치 (팩 운명 3장 중 비중복 뽑기. 마지막 위치 고정) |

> **유형 보장 없음.** 뽑기에 전투/사건/우연 비율 제약이 없다. 팩 내 유형 비율(금형 개성)에 의존한 확률적 분포.

## ③ 페이즈 진행 — 정찰-판단-감내

### 페이즈 수

| Stage | 페이즈 수 |
|-------|----------|
| 전 Stage 공통 | 3페이즈 |

### 페이즈 흐름

| 순서 | 처리 | 수동/자동 |
|------|------|----------|
| 1 | **뒷면 3장 제시.** 전부 같은 뒷면(팩 뒷면). 유형 불명 | 자동 |
| 2 | **정찰** — 1장을 골라 뒤집는다. 정체 확인 | **수동** |
| 3 | **판단** — 3장 중 1장 버림. 공개 카드 포함 어디든 가능 | **수동** |
| 4 | 버린 1장 → **전해지지 않은 이야기** (뒷면 채 퇴장. 내용 미공개) | 자동 |
| 5 | **감내** — 남은 2장 순차 뒤집기 → 즉발 | 자동 |

> **핵심 판단:** "뭘 열어볼 것인가"(정찰) + "뭘 버릴 것인가"(판단). → [CORE-001 핵심경험목표](../01_코어/핵심경험목표.md) 참조

### 정찰 정보 비대칭

| 카드 유형 | 정찰 시 공개 정보 |
|-----------|-----------------|
| **전투 카드** | 완전 공개 — 태그, 적 구성(챕터 레벨), 보상(전투 후 이벤트) |
| **사건 카드** | 완전 공개 — 효과 태그 |
| **우연 카드** | **"우연 카드"만 표시.** 우연-전투/우연-이벤트 구분 불가. 효과 미공개 |

### 모든 페이즈 종료 후

| 처리 | 내용 |
|------|------|
| 운명 카드 뒤집기 | 자동. 운명 전투 강제 발동 |
| 승리 | 추종자 2명 제시, 1명 선택 → [META-FOLLOWER 추종자](../04_메타/추종자.md) |
| 패배 | **게임 오버** (모든 운명 전투 패배 = 게임 오버) |

## ④ 카드 종류 (3종 + 운명)

### 전투 카드

| 필드 | 내용 |
|------|------|
| **역할** | 전투 진입. 뒤집으면 즉시 전투 |
| **분기** | 없음 |
| **태그** | 전략 0~1 + 전술 1 + 전투 후 이벤트 1 (1세트 고정) |
| **적** | 적 테이블 참조. 챕터 레벨(Lv1/2/3)에 따라 난이도 변동 |
| **정찰 시** | 태그 + 적 구성 + 보상 전부 공개 |

### 사건 카드

| 필드 | 내용 |
|------|------|
| **역할** | 비전투 효과. 뒤집으면 즉발 |
| **분기** | 없음 |
| **태그** | 이벤트 태그 1~2개 (1세트 고정) |
| **정찰 시** | 효과 태그 전부 공개 |

### 우연 카드

| 필드 | 내용 |
|------|------|
| **역할** | 통제 밖의 사건. 뒤집으면 즉발 |
| **종류** | 우연-전투 (강제 전투 진입) / 우연-이벤트 (즉발 효과) |
| **분기** | 없음 |
| **정찰 시** | **"우연 카드"만 표시.** 세부 미공개 |

### 운명 카드

| 필드 | 내용 |
|------|------|
| **역할** | 장 제목 + 최종 전투 + 추종자 획득 |
| **구성** | 전략 태그 1(필수) + 전술 태그 1(필수) + 적 테이블 |
| **위치** | 항상 마지막. 모든 페이즈 종료 후 자동 뒤집기 |
| **승리** | 추종자 2명 제시, 1명 선택 |
| **패배** | 게임 오버 |
| **소속** | 팩 내장. 팩당 9장 |

## ⑤ 뒷면 체계

| 뒷면 종류 | 적용 | 식별 |
|-----------|------|------|
| **팩 뒷면** | 해당 챕터 팩의 일반 카드 전부 | 팩당 고유 디자인. 9팩 = 9종 |
| **운명 뒷면** | 운명 카드 | 운명 전용 디자인 1종. 팩 무관 공통 |

> 팩 뒷면은 일반 카드(전투/사건/우연) 전부 동일. 정찰 전까지 유형 불명.

## ⑥ 전해지지 않은 이야기

| 항목 | 내용 |
|------|------|
| 정의 | 페이즈에서 버린 카드 |
| 공개 | **없음.** 미공개로 버린 카드는 뒷면 채 퇴장. 정찰 후 버린 카드만 정체를 안다 |
| 기록 상태 | 정사/야사/미기록에 이은 **4번째 기록 상태** |
| 런당 수량 | 27장 (27페이즈 × 1장) |

> **서사:** "모든 이야기가 겪어지는 것은 아니다. 전해지지 않은 이야기는 영원히 뒤집히지 않는다."

## ⑧ 설계 근거

**Q. 왜 정찰-판단-감내인가?**
→ [CORE-001 핵심경험목표](../01_코어/핵심경험목표.md) 참조. 간략한데 심오하다.

**Q. 왜 분기가 없는가?**
카드 3장 중 2장을 고르는 것 자체가 이미 선택이다. 그 위에 분기까지 있으면 판단이 분산된다. 카드 레벨 판단(정찰-판단)과 전투 레벨 판단(대형/리롤/방진)을 완전 분리.

**Q. 왜 유형 보장이 없는가?**
보장이 없어야 정찰이 진짜 의미가 있다. "전투가 있을 수도 있고 없을 수도 있다"는 불확실성이 정찰의 가치를 만든다. 팩 내 유형 비율(금형)이 확률적으로 조절.

**Q. 왜 뒷면이 1종(팩 뒷면)인가?**
정찰이 유일한 정보 수단이려면 정찰 전 정보가 0이어야 한다. 뒷면이 유형별로 다르면 정찰 전에 이미 정보가 있다. 전부 같은 뒷면 = 정찰 전 정보 0 = 야바위의 긴장.

**Q. 우연 정찰 시 왜 "우연 카드"만 보여주는가?**
우연 = 통제 밖. 정체를 알면 통제 가능해진다. "우연이라는 것만 안다"가 우연의 본질. 버릴지 남길지는 도박.

**Q. 전투 회피가 가능한가?**
가능하다. 정찰로 전투를 찾아 버리면 된다. 하지만: ① 전투 후 보상 포기 ② 팩 전투 비율 ~50%이므로 미지 2장에도 전투 확률 높음 ③ 우연-전투는 정찰해도 전투인지 모름. 적극적 플레이가 안정적이고 회피 플레이가 불안정.

**Q. 운명이 마지막인 이유는?**
준비→결전 구조. 페이즈에서 겪은 카드가 운명 전투를 위한 준비. 마지막인 걸 아니까 역산 전략이 생긴다.
