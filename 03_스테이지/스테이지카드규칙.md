# 카드 시스템

> 상태: 결정정합 (5-12 후속 마디 박힘)

> 5-12 후속 마디 정정:
> - 적 카드 결 = 하스스톤 전장식 격돌 (공격력 = 상대 hp 직격)
> - 다이시 테일즈식 결산 폐기
> - 보호막 ↔ 방어도 분리:
>     보호막 = 이진 (어떤 피해든 1번 무효, 희소 자원)
>     방어도 = 감산 (숫자만큼 막음)
> - 적 정보 노출 결 정정 (적 유닛 모형 위):
>     노출:   위계 + 자기 시간대 + hp 바 + 보호막 개수 + 방어도 수치 + 직업 아이콘
>     비노출: 등급 (가호 수로 드러남), 공격력
> - 4축 결 박힘 (진영·종족·태생·위계·등급)
> 상세: `DOCS/DESIGN/LOG/2026-05-12_전투시스템마감·4축결·가호광역·격돌결산.md`

> 5-11+ 마디 정정 (전투 5.0):
> - 직업 4종 (전사·수호자·사냥꾼·사제) + 행동 5종 (격돌·사격·보호·축복·저주)
> - 적 카드 결 = 다이시 테일즈식 (면 → 행동 풀), 보호막 결 포함 [5-12에 폐기]
> - 사건 카드 분기 폐기 (선택형 → 결과형으로 통합. 분기 a/b/c 자리 X)
> - 우연 카드 분기 살림 (축복·저주만 분기. 5 자리 = 위기/기회/축복/저주/예언 유지)
> - 전투 카드 정보 공개 결: 시간대 차등 X. Type 노출 시 다 공개. 페이즈가 이미 정보 차단.
> - 적 정보 노출 결 (적 유닛 모형 위):
>     노출:   위계 (인간/영웅/무리/재앙) + 자기 시간대 + hp 바 + 보호막 바(있을 때만) + 직업 아이콘
>     비노출: 등급 (굴림 시 드러남), 능력치 (공·방·속)
> - 정보 비대칭 결 (5-11+ 박힘):
>     아군: hp 바 + 숫자 / 보호막 바 + 숫자
>     적:   hp 바만 / 보호막 바만 (수치 X, 유추만)
> - 시간대 3종 (낮/경계/밤), 페이즈 R1 + 라운드별 변동
> 상세: `DOCS/DESIGN/LOG/2026-05-11_전투5.0_다이시테일즈식·행동풀_큰정리.md`

> 5-8 페이즈 정의 박음 (살림):
> - 페이즈 진행 어휘: 선택-거부-감내
> - 뒷면 2상태 (Dark / Type)
> - 7장면 결 (Stage = 4 Phase = 7장면)
> - 발화 순서 (1번 → 2번 → 거부 카드)
> - 비가역 결정
> - 운명 Phase 정합 (Stage 팩 공용 뒷면)

## 정의

카드 시스템 v4.0. Stage = 4 Phase = 10장 = 7장면. 일반 Phase 3개 (각 3장: 선택 + 거부 + 감내) + 운명 Phase 1개 (운명 카드 1장). 변주 = 오더 단위 인격 (같은 자리의 다른 가능세계).

## 규칙

### 구조

```yaml
Stage = 4 Phase = 7장면:
  Phase 1~3 (3장씩) = 각 2장면 (1번 + 2번)
  Phase 4 (1장)     = 1장면 (운명)

카드 총량 (Stage 단위):
  Stage = 10장 (Phase 1~3 = 9장 + Phase 4 = 1장)
  겪는 카드 = 7장 (1번 3 + 2번 3 + 운명 1)
  거부 카드 = 3장 (Phase 1~3 각 1장. 영구 미공개)
```

### 뒷면 2상태

```yaml
Dark = Stage 팩 공용 뒷면
  종류 안 보임 (선택 전 자리)
  Stage 팩 단위 공용 = 한 Stage의 10장 모두 동일한 Dark
  운명 카드도 동일 공용 뒷면

Type = 종류 노출
  전투 ⚔ / 사건 ✦ / 우연 ?
  카드 터치 후 노출
```

### Phase 진행 (선택-거부-감내)

```yaml
일반_Phase:
  초기:
    카드 3장 Dark 상태 제시. 종류 식별 X
    [Dark][Dark][Dark]

  1차 [선택] (비가역):
    1장 터치 → Type 노출
    자동 1번 자리 결정 (이야기 진행)
    [선택됨:Type 봄][Dark][Dark]

  2차 [거부] (비가역):
    남은 2장 중 1장 터치 → Type 노출
    버림 결정. 발화 X (마지막에)
    [선택됨:Type 봄][거부됨:Type 봄][Dark]

  자동 [감내]:
    마지막 1장. Dark 그대로 발화 = 2번 자리
    Type 모르고 받음

  발화 순서:
    1번 발화 → 2번 발화 → 거부 카드 (뒷면 상태로 버림 패. 영구 미공개)

운명_Phase:
  카드: 1장. 가운데 자리
  뒷면: Stage 팩 공용 뒷면 (Dark)
  진행: 뒤집어서 봄 → 즉시 운명 전투
  선택·거부: 없음 (1장이라 분기 X)

승패:
  승리: 다음 Stage
  패배: 게임 오버 (모든 운명 패배 시)
```

### 비가역 결정

```yaml
1차 [선택]: 카드를 정하면 취소 X
2차 [거부]: 카드를 정하면 취소 X
"취소하고 3장 다 보기": 불가
한 번 정하면 그대로 굴러감

대가 구조:
  1번 (선택) = Type 알고 겪음
  거부 카드  = Type 알고 버림 (영구 미공개)
  2번 (감내) = Type 모르고 받음 ← 선택·거부의 대가
```

### 카드 종류

```yaml
스토리_카드: 전투 / 사건 / 우연 (한 풀 안에 섞임)
운명_카드:    Stage당 1장 고정. 별도 풀
```

### 전투 카드 (5-11+ 정정)

```yaml
표시: [텍스트] - 적 부대
분기: 없음. Type 노출 시 = 발화 = 전투 시작

정보 공개 결 (5-11+ 박힘):
  시간대 차등 X (페이즈가 이미 정보 차단)
  Type 노출 시: 적 부대 다 공개 (정찰 결과)
  옛 5-7 결 (낮 = 완전 공개 / 밤 = 부분 공개) 폐기

적 유닛 모형 위 노출 결 (5-11+ 박힘):
  노출:
    위계 (인간 / 영웅 / 무리 / 재앙)
    자기 시간대 (낮 / 경계 / 밤 — 그 적이 유리 받는 시간대)
    hp 바 (수치 X)
    보호막 바 (있을 때만)
    직업 아이콘 (전사 / 수호자 / 사냥꾼 / 사제)
  비노출:
    등급 (필멸/반신/신성/번외 — 굴림 시 주사위 수로 자연 드러남)
    능력치 (공·방·속 수치)
  
  예: "무리, 밤, hp 바, 직업(사냥꾼 아이콘) / 고블린 척후대"

정보 비대칭 결 (5-11+ 박힘):
  아군 인물:
    hp 바 + 숫자 (정확한 결)
    보호막 바 + 숫자 (정확한 결)
  적 인물:
    hp 바만 (유추 결)
    보호막 바만 (있을 때, 유추 결)
  근거 (본인 박은 결): "포인트야" — 진영 차별 결.

지형: 폐기 (Stage 단위 = 장소가 흡수)
```

### 사건 카드 (5-11+ 정정 — 분기 폐기)

```yaml
표시: [텍스트] - 결과 1
결과: 즉발. 분기 없음 (5-11+ 박힘)
Type 노출 시: 텍스트 + 결과 공개
발화 시: 자동 즉발 (개입 X)

5-11+ 정정 자리:
  옛 결: 선택형 (분기 a/b/c) + 결과형 (즉발) 두 분류
  새 결: 결과형 단일 (선택형 폐기)
  근거 (본인 박은 결): "분기라는걸 제외할거야 전투 카드도 사건카드에서도 마찬가지야"

내부 분류: 폐기 (단일 결로 통합)
```

### 우연 카드 — 5 자리 (분기 살림, 5-11+ 확인)

```yaml
Type 노출 시: "우연 카드"만 표시 (5 자리 어느 것인지 모름). 가장 강한 ?
닫힘: 카드 안 엄격 (예언 정보만 유저 기억으로 살음)
발화 시:
  위기/기회/예언: 자동 즉발 (개입 X)
  축복/저주:      분기 살림 (a/b/c — 무엇을 가져갈지·무엇으로 손해볼지)

5 자리:
  위기:  강제 전투. 적이 더 많거나 불리한 상태. 분기 없음
  기회:  강제 전투. 아군이 유리한 상태. 분기 없음
  축복:  선택형 이득. 분기 (a/b/c — 무엇을 가져갈지)
  저주:  선택형 손해. 분기 (a/b/c — 무엇으로 손해볼지)
  예언:  운명 카드에 대한 힌트 (발드 / 부대 구성 등). 카드 넘어가면 표시 사라짐 (유저 기억만)

5-11+ 확인:
  사건 카드 분기는 폐기됐지만 우연 축복·저주 분기는 살림.
  근거 (본인 박은 결): "우연은 분기 살리고 사건에서 폐기야"
  결의 결: 작품 결 = 우연 = 외부 결 (신의 결로 박힘) → 작은 결단만 살림.
           사건 = 일어나는 일 (내부 결) → 분기 X.

불운/행운 라벨: 폐기 (5 자리 자체가 결을 결정)
비율 (잠정): 5 자리 균등 ± 작가 결. 디지털 프로토 후 확정.
```

### 운명 카드

```yaml
역할: Stage의 닻. Phase 4
구성: 텍스트 + 적 부대 + 변주별 표현 (부대·지형·배경 변주)
변주: 본체 동일 (같은 인물). 표현은 변주별 다름 = "가능세계의 같은 인물"
Type 노출: 운명 Phase 진입 시 자동
정보 공개: 전투 카드 결 따름 (위계 + 자기 시간대 + hp 바 + 보호막 + 직업 아이콘. 정보 비대칭)
패배: 게임 오버 (모든 운명 패배 시)
```

### 연출 + 플레이어 개입 (5-11+ 정정)

```yaml
연출:
  몽환적. Phase = 꿈에서 미리 본 자리. 선택·거부로 현실로 나타남
  결: "어렴풋이 뭐겠구나 알고 들어간다" — Type만 봄, 내용은 모름

플레이어 개입:
  1번 → 2번 사이 = 자동 (개입 X)
  카드 종류별 발화 안 분기:
    사건       = 자동 즉발 (5-11+ 박힘 — 분기 폐기)
    전투       = 전투 진입 (별도 시스템)
    우연 위기/기회/예언 = 자동 즉발
    우연 축복/저주      = 분기 선택 (a/b/c)

→ Phase의 *외부* 결단 = 선택-거부만 (사건 발화 시 X)
→ Phase의 *내부* 결단 = 우연 축복/저주 (작은 결)
→ 사건 분기 폐기로 발화 시 결단 자리 작아짐 (5-11+ 결)
```

### 카드 비율 — 변주(인격) 단위 금형

```yaml
원칙:
  - 변주 = 작가가 짠 한 인격 결의 카드 묶음 (오더 팩 = 90장)
  - Phase 단위 종류 강제 X
  - 통제 자리 = 변주 단위 (작가가 인격 결로 비율 짬)
  - 0 금지: 어떤 종류든 최소 1장 (전투·사건·우연 다 만남 보장)

잠정 시드 (Stage = 10장 기준):
  편중형 변주: 한 종류 4~5장 + 다른 종류 2~3장
  균형형 변주: 전 3 / 사 3 / 우 3 / 운 1
  → 디지털 프로토 후 확정

자연_산출:
  변주(인격)가 짜이면 비율은 자연 산출
  강제 비율 X. 작가 결의 결과
```

### 변주 시스템 (오더 단위 인격)

```yaml
변주 = 가능세계 = 같은 자리의 다른 인격
단위: 오더 팩 (90장)
한 오더 = 인격 풀 (Order 1 = 용맹 / 지혜 / 광명. 광명은 1·2 클리어 시 해금)

선택_시점: 오더 시작 시 1번 (9 Stage 통째)
첫_회차:   작가 표준 인격 고정 (Order 1 = 용맹)
재플레이: 해금된 인격 풀에서 선택

명명:
  오더 팩:   "사생아, 테오도라 — 용맹"
  Stage:    "라키아의 들개" (변주 라벨 안 붙음)

미답파 시각화:
  본 인격 = 안 빛남. 안 본 인격 = 빛남 (사서 프레임 = 미답파 페이지)
```

### 환경 영향 — 선택·거부·감내

### 폐기 항목

```yaml
- 챕터 팩 30장 (일반 27 + 운명 3):       5-7 폐기 (오더 팩 단위 90장으로 변경)
```
