# STAGE-CARD-002: 스테이지 카드 규칙 (Stage Card Rules)

> **상태:** 🔄 설계중 · **버전:** 0.9 · **ID:** STAGE-CARD-002 · **수정일:** 2026-03-01

---

## ① 한 줄 요약

이벤트 카드 5장을 순차 뒤집는다. 분기를 고른다. 6번째 카드는 운명 — 마지막 전투가 자동 발동한다.

---

## ② 카드 흐름

```
카드 1 (이벤트)  →  뒤집기 → 분기 선택 → 효과 적용 [전투 시 7스텝]
카드 2 (이벤트)  →  뒤집기 → 분기 선택 → 효과 적용 [전투 시 7스텝]
카드 3 (이벤트)  →  뒤집기 → 분기 선택 → 효과 적용 [전투 시 7스텝]
카드 4 (이벤트)  →  뒤집기 → 분기 선택 → 효과 적용 [전투 시 7스텝]
카드 5 (이벤트)  →  뒤집기 → 분기 선택 → 효과 적용 [전투 시 7스텝]
카드 6 (★ 운명)  →  뒤집기 → 운명 전투 → 운명 판정
```

- 이벤트 5장: 셔플 순서대로 뒤집힘. 순서 선택 불가
- 운명 1장: 항상 마지막 (6번째). 뒤집으면 운명 전투 자동 발동
- 전투 발생 빈도: 이벤트 카드 중 약 30~40% (우연 카드 포함)

## ③ 카드 구조

### 이벤트 카드 — 뒷면

| 필드 | 내용 |
|------|------|
| **공통 프레임** | 스테이지별 공통 디자인. 스테이지 문양 + CHRONICLE 표기 |
| **정보량** | 없음. 완전 블라인드. 뒤집어야 전투인지 비전투인지 알 수 있음 |
| **모든 이벤트 동일** | 사건/우연 구분 불가. 전투/비전투 구분 불가 |

### 운명 카드 — 뒷면

| 필드 | 내용 |
|------|------|
| **별도 디자인** | 이벤트 카드와 다른 뒷면. 금색 테두리 |
| **식별 가능** | 마지막 카드가 운명이라는 것을 알 수 있음 |
| **사전 정보** | 화면 상단에 운명 조건 상시 표시 |

### 앞면 (뒤집은 후)

| 필드 | 내용 |
|------|------|
| **일러스트** | 배경 일러스트 1장 |
| **상황 서술** | 중앙 최상단. 무슨 일이 벌어졌는가. 1~2문장 |
| **분기** | 서술 아래. 2~3개 선택지. 각 분기에 효과가 직접 명시 |
| **우연 표시** | 우연 카드일 경우 분기 없이 즉시 발동 효과 표시 |

### 조작법

| 조작 | 효과 |
|------|------|
| **길게 누르기** | 카드 아래쪽이 살짝 들림. 누르는 동안 천천히 앞면 드러남. 손 떼면 다시 덮임 |
| **70% 이상 들추기** | 완전히 뒤집힘 (되돌릴 수 없음) |
| **스페이스바** | 즉시 뒤집기 |

## ④ 카드 종류

### 사건 카드 — 전투

| 필드 | 내용 |
|------|------|
| **역할** | 전투 진입 카드. 분기 양쪽 다 전투 |
| **분기** | "누구랑 싸울지" 선택. 적 정보는 서술과 힌트로 부분 공개 |
| **적 정보 수준** | "보초 2기", "대규모 부대" 등 힌트만. 적 상세 스탯은 전투 시작 후 공개 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |

### 사건 카드 — 비전투

| 필드 | 내용 |
|------|------|
| **역할** | 준비 카드. 정보, 합류, 장비, 정찰 등 |
| **분기** | 2~3개. 각 분기마다 다른 이득+비용 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |

### 우연 카드

| 필드 | 내용 |
|------|------|
| **뒷면** | 이벤트 카드와 동일. 구분 불가 |
| **선택** | 없음. 뒤집는 순간 즉시 발동 |
| **내용** | 런마다 다름. 전투일 수도, 비전투(부상/병력 손실 등)일 수도 |
| **보상** | 없음. 통제 밖의 사건 |

### 운명 카드

| 필드 | 내용 |
|------|------|
| **위치** | 항상 마지막 (6번째 카드) |
| **뒷면** | 이벤트와 다른 디자인. 금색 테두리 |
| **표시** | 화면 상단에 운명 조건 상시 표시 (예: "적 병력 전멸") |
| **발동** | 뒤집으면 강제 전투 |
| **판정** | 운명 전투 승패가 Stage 결과 결정 |
| **미달성** | 홀수 Stage = 패널티, 짝수 Stage = 패배 |

## ⑤ 분기 효과 시스템

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **분기 효과가 유일한 보상** | 추상 자원 없음. 분기를 고르면 그 효과가 곧 보상 |
| **버프 슬롯 1개** | 전투 버프는 동시에 1개만 보유 가능. 새 버프를 받으면 기존 버프 덮어쓰기 |
| **전투 버프는 다음 전투 한정** | 사용하면 소멸. 전투 없이 스테이지가 끝나면 그대로 소멸 |
| **부대 변화는 영구** | 병종 합류, 부상, 사망 등은 스테이지 끝까지 유지 |

### 분기 효과 풀 — 전투 버프 (슬롯 1개, 다음 전투 한정)

| 효과 | 내용 | 대응 스텝 |
|------|------|----------|
| **면 확정** | 아군 주사위 1개를 ⚔ 또는 🛡로 확정 | 스텝 2 |
| **리롤 추가** | 리롤 +1 (기본 1회 → 총 2회) | 스텝 4 |
| **적 정보 공개** | 적 주사위 결과 1개를 미리 봄 | 스텝 1 |
| **선제** | 아군이 먼저 행동 | 스텝 1 |

### 분기 효과 풀 — 부대 변화 (영구)

| 효과 | 내용 |
|------|------|
| **병종 추가** | Nameless 유닛 1기 합류. 주사위 풀 증가 |
| **면 교체** | 유닛 1기의 ✕ 1개를 ⚔ 또는 🛡로 교체 |
| **부상** | Named 인물 1기 부상. 유효 면 1개 → ✕. Nameless는 부상 없이 즉사이므로 대상 아님 |
| **병력 손실** | Nameless 유닛 1기 제거 (퍼마데스) |

### 덱 구성

| **운명 카드** | 항상 마지막 (6번째). 뒤집으면 운명 전투 |
| **셔플** | 이벤트 5장만 셔플. 운명은 고정 위치 |

### 카드 풀 규칙

| 필드 | 내용 |
|------|------|
| **범용 카드** | 시리즈간 공유. 전체 카드 중 약 70% |
| **전용 카드** | 특정 시리즈/Stage에 묶임. 약 30% |
| **챕터 간 범용 중복 불가** | 같은 범용 카드가 다른 Chapter에서 다시 나올 수 없음 |
| **운명 카드 풀** | 시리즈간 공유. Stage 결정 시 운명 풀에서 셔플 뽑기 |

### 전투 횟수 정리

| 전투 | 출처 | 보장 |
|------|------|------|
| **운명 전투** | 6번째 카드 자동 발동 | 100% 보장 |
| **사건/우연 전투** | 이벤트 5장 중 전투 카드 뒤집힘 | 확률적 (30~40%) |
| **최소** | 1회 (운명) | 구조적 보장 |
| **최대** | 6회 (전투 이벤트 5장 + 운명) | 이론적 최대 |

## ⑪ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 6장인가? | 이벤트 5장 + 운명 1장. 스테이지 하나가 가볍되 운명 전투는 보장. 9장은 너무 많고 선택 피로 |
| 왜 운명이 마지막인가? | 준비→결전 구조. 이벤트 5장은 운명 전투를 위한 준비. 마지막인 걸 아니까 역산 전략이 생긴다 |
| 왜 운명 뒷면이 다른가? | 운명이 다가오는 걸 의식하게. 이벤트와 같으면 "몇 번째인지 세기" 게임이 되고, 다르면 "이제 운명이다" 느낌 |
| 왜 범용/전용 나누나? | 범용으로 제작 물량 줄이고, 전용으로 시리즈별 서사 차별화. 범용 70% 전용 30% 비율 |
| 왜 챕터 간 범용 중복 불가? | 같은 이벤트가 반복되면 신선함 소멸. 36장/런에서 30장 이벤트가 다 다르면 매 Stage가 새 경험 |
| 왜 전투 빈도 30~40%? | 매 카드가 전투면 피로. 비전투 카드로 준비하고 전투에서 결산하는 리듬 |
| 왜 패스가 없는가? | 서자 부대는 골라야 산다 |
