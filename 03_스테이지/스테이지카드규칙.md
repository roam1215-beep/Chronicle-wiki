# STAGE-CARD-002: 스테이지 카드 규칙 (Stage Card Rules)

> **상태:** 🔄 설계중 · **버전:** 0.1 · **ID:** STAGE-CARD-002 · **수정일:** 2026-02-28

---

## ① 한 줄 요약

매 턴 카드 1장을 뒤집는다. 뒤집으면 토큰을 받고, 분기를 고른다. 패스는 없다.

---

## ② 카드 구조

### 뒷면 (뒤집기 전)

| 필드 | 내용 |
|------|------|
| **토큰 아이콘** | 전술(⚔) / 지휘(🔍) / 전략(↻) 중 하나 |
| **우연 카드** | 셋 중 하나를 랜덤으로 위장. 뒤집기 전까지 사건과 구분 불가 |
| **정보량** | 토큰 종류만 알 수 있음. 상황, 분기, 효과는 모름 |

### 앞면 (뒤집은 후)

| 필드 | 내용 |
|------|------|
| **상황 서술** | 무슨 일이 벌어졌는가. 1~2문장 |
| **토큰 보상** | 카드에 고정. 뒤집으면 무조건 받음. 분기 선택과 무관 |
| **분기** | 사건 카드: 2~3개 선택지. 반드시 하나를 골라야 함 |
| **즉시 발동** | 우연 카드: 선택 없음. 효과 즉시 적용 |

---

## ③ 카드 종류

### 사건 카드

| 필드 | 내용 |
|------|------|
| **비율** | 덱의 대다수 |
| **분기 수** | 2~3개. 카드마다 다름 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |
| **토큰** | 뒤집는 순간 고정 토큰 +1 |
| **분기 효과** | 토큰과 별개. 선택지마다 다른 효과 |

### 우연 카드

| 필드 | 내용 |
|------|------|
| **비율** | 덱의 소수 (Stage 1 기준 10장 중 1장) |
| **뒷면** | 전술/지휘/전략 중 하나를 랜덤 위장 |
| **선택** | 없음. 뒤집는 순간 즉시 발동 |
| **토큰** | 없음 |
| **효과** | 강제 전투, 부상, 병력 손실 등 통제 밖의 사건 |

### 운명 카드

| 필드 | 내용 |
|------|------|
| **정체** | 사건 카드의 특수 변종. 분기 없이 강제 전투 |
| **보장** | 반드시 5장 안에 포함됨 (셔플 규칙으로 보장) |
| **토큰** | 카드에 명시된 고정 토큰 +1 |
| **역할** | 운명 달성(스테이지 클리어) 조건과 직결되는 핵심 전투 |

## ④ 토큰 3종

| 토큰 | 아이콘 | 소모 타이밍 | 효과 |
|------|--------|------------|------|
| **전술** | ⚔ | 전투 스텝 2 | 아군 주사위 1개를 ⚔ 또는 🛡로 확정 + 카드락 |
| **지휘** | 🔍 | 전투 스텝 4 | 추가 리롤 +1 (기본 1회 → 총 2회) |
| **전략** | ↻ | 카드 페이즈 | 다음 카드를 버리고 새 카드를 뽑음 (카드 교체) |

### 토큰 규칙

| 필드 | 내용 |
|------|------|
| **획득** | 카드 뒤집기 시 고정 +1. 분기 선택과 무관 |
| **이월** | 가능. 스테이지 내 전투 간 이월 |
| **소멸** | 스테이지 종료 시 잔여 토큰 소멸. 유물 재료 집계에 반영 |
| **우연** | 우연 카드는 토큰을 주지 않음 |

---

## ⑤ 분기 효과 풀

분기 선택지가 줄 수 있는 효과의 종류. 모든 분기는 이 풀 안에서 조합된다.

### 얻는 것 (이득)

| 효과 | 내용 |
|------|------|
| **전투 진입** | 전투 시작. 운명 달성에 필요 |
| **병종 추가** | T1 유닛 1기 합류. 주사위 풀 증가 |
| **면 교체** | 유닛 1기의 ✕ 1개를 ⚔ 또는 🛡로 교체 |
| **승급** | T1 → T2 승급 기회 |
| **전투 조건 유리** | 지형 세팅, 선제 보너스, 적 정보 공개 등 |

### 잃는 것 (비용)

| 효과 | 내용 |
|------|------|
| **부상** | 유닛 1기 부상. 면 1개 → ✕ |
| **면 손상** | 유닛 1기의 유효면 1개 → ✕ |
| **병력 손실** | T1 유닛 1기 제거 (퍼마데스) |
| **전투 조건 불리** | 적 증원, 밤 전투 강제, 지형 불리 등 |

### 설계 원칙

| 원칙 | 내용 |
|------|------|
| **양쪽 다 무언가** | 모든 분기는 이득과 비용이 있다. "한다/안 한다"가 아니라 "이걸 얻고 저걸 잃는다 vs 저걸 얻고 이걸 잃는다" |
| **패스 없음** | 반드시 골라야 한다. 닥친 상황에 대응하는 것이 핵심 경험 |
| **토큰은 공짜** | 어떤 분기를 골라도 토큰은 받는다. 분기 판단에 토큰은 변수가 아님 |

## ⑥ 덱 운영 규칙

### Stage 1 기준

| 필드 | 내용 |
|------|------|
| **덱 크기** | 10장 |
| **뒤집기** | 매 턴 1장. 5턴 = 5장 |
| **잔여** | 5장은 안 뒤집힘. 매 런 다른 경험 |
| **셔플** | 스테이지 시작 시 셔플 |
| **운명 보장** | 운명 카드는 반드시 5장 안에 포함 (셔플 시 상위 5장에 삽입) |

### 토큰 배분 (Stage 1)

| 토큰 | 장수 |
|------|------|
| 전술 ⚔ | 3장 (운명 카드 1장 포함) |
| 지휘 🔍 | 3장 |
| 전략 ↻ | 3장 |
| 우연 | 1장 (토큰 없음, 뒷면 위장) |
| **합계** | **10장** |

## ⑦ 시각 자료

### 카드 1장의 생애

```
[뒷면]                    [뒤집기]                 [분기 선택]
┌──────────┐             ┌──────────────┐         ┌──────────────┐
│          │             │ 상황 서술     │         │              │
│   ⚔      │  ──뒤집기→  │              │  ──선택→ │ 효과 적용     │
│ (토큰    │             │ 토큰: ⚔ +1   │         │ + 토큰 획득   │
│  아이콘)  │             │              │         │              │
│          │             │ A: ────────  │         │ 겪은 카드로   │
│          │             │ B: ────────  │         │ 패에 축적     │
│          │             │ C: ────────  │         │              │
└──────────┘             └──────────────┘         └──────────────┘
```

### 우연 카드

```
[뒷면]                    [뒤집기]
┌──────────┐             ┌──────────────┐
│          │             │              │
│   🔍      │  ──뒤집기→  │ ⚡ 우연!      │  ──즉시→  효과 발동
│ (가짜    │             │              │          선택 없음

```

```
턴 1(낮)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용
턴 2(밤)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용
턴 3(낮)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  [전투 진입 시 7스텝]
턴 4(밤)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  [전투 진입 시 7스텝]
턴 5(낮)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  운명 판정 → 기록
```

## ⑧ 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| **전략 토큰 카드 교체 세부** | "다음 카드를 버리고 새 카드를 뽑음" 방향. 덱에서? 버린 카드 더미에서? | 덱 운영 프로토타입 |
| **우연 카드 토큰** | 현재 "없음". 주는 것도 가능 | 밸런스 테스트 |
| **운명 카드 보장 메커니즘** | "상위 5장에 삽입" 방향. 구체 셔플 알고리즘 미정 | 구현 시 확정 |
| **분기 효과 밸런스** | 풀만 정의. 구체 수치/조합 미정 | 카드 10장 개별 설계 시 |

## ⑨ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 토큰이 분기와 무관한가? | 토큰을 분기에 걸면 "토큰 최적화"가 판단의 전부가 됨. 토큰은 공짜로 주고, 분기에서는 전투/병력/상태 같은 서사적 판단에 집중시키기 위함 |
| 왜 패스가 없는가? | 핵심경험목표 — "닥친 상황에 대응한다". 회피 불가. 서자 부대는 골라야 산다 |
| 왜 우연 뒷면이 위장인가? | 뒤집기 전 계획 수립 후 "당했다" 경험. 우연이 진짜 우연이 됨 |
| 왜 운명 카드가 강제 전투인가? | 운명 달성(적 전멸)에 전투가 필수. 최소 1회 전투를 구조적으로 보장 |
| 왜 분기 양쪽 다 이득+비용인가? | "한다/안 한다"는 선택이 아니라 함정 회피. 양쪽 다 무언가를 얻고 잃어야 진짜 판단 |
