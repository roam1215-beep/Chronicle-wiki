# STAGE-CARD-002: 스테이지 카드 규칙 (Stage Card Rules)

> **상태:** 🔄 설계중 · **버전:** 0.3 · **ID:** STAGE-CARD-002 · **수정일:** 2026-02-28

---

## ① 한 줄 요약

턴 1~4에 카드 1장씩 뒤집는다. 분기를 고른다. 분기 효과가 유일한 보상이다. 턴 5에 운명 전투가 자동 발동한다.

---

## ② 턴 구조

```
턴 1(낮)  →  카드 뒤집기  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 2(밤)  →  카드 뒤집기  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 3(낮)  →  카드 뒤집기  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 4(밤)  →  카드 뒤집기  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 5(낮)  →  ★ 운명 전투 자동 발동  →  운명 판정  →  기록
```

- 턴 1~4: 덱에서 카드 4장 뒤집힘
- 턴 5: 카드 뒤집기 없음. 운명 전투 자동 발동
- 전투 최소 1회(운명) 보장. 덱에서 추가 전투 가능

## ③ 카드 구조

### 뒷면 (뒤집기 전)

| 필드 | 내용 |
|------|------|
| **공통 프레임** | 스테이지별 공통 디자인. 스테이지 문양 + CHRONICLE 표기 |
| **전투/비전투 표시** | ⚔(전투) 또는 🛡(비전투). 이 카드를 뒤집으면 싸우게 되는지 여부 |
| **우연 카드** | ⚔/🛡 중 랜덤 위장. 뒤집기 전까지 사건과 절대 구분 불가 |
| **정보량** | 전투 여부만 알 수 있음. 상황, 분기, 효과, 사건/우연 여부 모름 |

### 앞면 (뒤집은 후)

| 필드 | 내용 |
|------|------|
| **일러스트** | 배경 일러스트 1장 |
| **상황 서술** | 중앙 최상단. 무슨 일이 벌어졌는가. 1~2문장 |
| **분기** | 서술 아래. 2~3개 선택지. 각 분기에 효과가 직접 명시 |

### 조작법

| 조작 | 효과 |
|------|------|
| **클릭/터치** | 카드 정보 확인 (전투/비전투, 현재 보유 버프 등) |
| **길게 누르기** | 카드 아래쪽이 살짝 들림. 누르는 동안 천천히 앞면 드러남. 손 떼면 다시 덮임 |
| **70% 이상 들추기** | 완전히 뒤집힘 (되돌릴 수 없음) |
| **스페이스바** | 즉시 뒤집기 |

## ④ 카드 종류

### 사건 카드 — 전투

| 필드 | 내용 |
|------|------|
| **뒷면** | ⚔ 표시 |
| **역할** | 전투 진입 카드. 분기 양쪽 다 전투 |
| **분기** | "누구랑 싸울지" 선택. 엘리트 vs 일반, 기습 vs 정면 등 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |
| **보상** | 분기 효과 자체가 보상. 전투 승리 시 추가 효과 가능 |

### 사건 카드 — 비전투

| 필드 | 내용 |
|------|------|
| **뒷면** | 🛡 표시 |
| **역할** | 준비 카드. 정보, 합류, 장비, 정찰 등 |
| **분기** | 2~3개. 각 분기마다 다른 이득+비용 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |
| **보상** | 분기 효과 자체가 보상 |

### 우연 카드

| 필드 | 내용 |
|------|------|
| **뒷면** | ⚔/🛡 중 랜덤 위장. 사건 카드와 완전히 동일 외관 |
| **선택** | 없음. 뒤집는 순간 즉시 발동 |
| **내용** | 런마다 다름. 전투일 수도, 비전투(부상/병력 손실/재앙 등)일 수도 |
| **보상** | 없음. 통제 밖의 사건 |

### 운명

| 필드 | 내용 |
|------|------|
| **정체** | 카드가 아님. 스테이지의 목적 그 자체 |
| **표시** | 화면 상단에 운명 조건 상시 표시 (예: "적 병력 전멸") |
| **발동** | 턴 5에 자동 발동. 강제 전투 |
| **역할** | 스테이지 클리어 조건 직결. 이 전투의 승패가 스테이지 결과 |

## ⑤ 분기 효과 시스템

### 핵심 원칙

| 원칙 | 내용 |
|------|------|
| **분기 효과가 유일한 보상** | 토큰 없음. 추상 자원 없음. 분기를 고르면 그 효과가 곧 보상 |
| **전투 버프는 다음 전투 한정** | 비전투 카드에서 얻은 전투 관련 효과는 다음 전투 1회에만 적용. 사용하면 소멸 |
| **축적 불가** | 전투 버프는 중첩되지 않음. 이전 버프를 쓰기 전에 새 버프를 얻으면 선택 또는 덮어쓰기 |
| **부대 변화는 영구** | 병종 합류, 부상, 사망 등 부대 상태 변화는 스테이지 끝까지 유지 |

### 분기 효과 풀 — 전투 버프 (다음 전투 한정, 소멸)

| 효과 | 내용 | 대응 스텝 |
|------|------|----------|
| **면 확정** | 아군 주사위 1개를 ⚔ 또는 🛡로 확정 | 스텝 2 |
| **리롤 추가** | 리롤 +1 (기본 1회 → 총 2회) | 스텝 4 |
| **적 정보 공개** | 적 주사위 결과 1개를 미리 봄 | 스텝 1 |
| **선제** | 아군이 먼저 행동 | 스텝 1 |
| **지형 유리** | 특정 지형 효과 적용 | 스텝 5 |

### 분기 효과 풀 — 부대 변화 (영구)

| 효과 | 내용 |
|------|------|
| **병종 추가** | T1 유닛 1기 합류. 주사위 풀 증가 |
| **면 교체** | 유닛 1기의 ✕ 1개를 ⚔ 또는 🛡로 교체 |
| **승급** | T1 → T2 승급 기회 |
| **부상** | 유닛 1기 부상. 면 1개 → ✕ |
| **병력 손실** | T1 유닛 1기 제거 (퍼마데스) |

### 전투 카드 분기 설계 원칙

| 원칙 | 내용 |
|------|------|
| **양쪽 다 전투** | "싸울까 말까"가 아니라 "누구랑 싸울까" |
| **적 구성이 다름** | 엘리트 vs 일반, 소수정예 vs 다수, 기습 vs 정면 등 |
| **전투 조건이 다름** | 지형, 선제 여부, 밤/낮 보너스 등 |

### 비전투 카드 분기 설계 원칙

| 원칙 | 내용 |
|------|------|
| **양쪽 다 무언가** | 이득과 비용이 모두 있다. "한다/안 한다"가 아님 |
| **패스 없음** | 반드시 골라야 한다 |
| **선택의 결과가 보인다** | 부대 상태 변화는 즉시 화면에 반영 |

## ⑥ 덱 운영 규칙

### Stage 1 기준

| 필드 | 내용 |
|------|------|
| **덱 크기** | 9장 (운명은 덱 밖) |
| **구성** | 전투 사건 4장 + 비전투 사건 4장 + 우연 1장 |
| **뒤집기** | 턴 1~4에 1장씩. 총 4장 |
| **잔여** | 5장은 안 뒤집힘. 매 런 다른 경험 |
| **셔플** | 스테이지 시작 시 셔플 |
| **전투 빈도** | 전투 카드 4장/9장 = 4장 뒤집을 때 전투 0장 확률 약 4% |

### 전투 횟수 정리

| 전투 | 출처 | 보장 |
|------|------|------|
| **운명 전투** | 턴 5 자동 발동 | 100% 보장 |
| **사건/우연 전투** | 덱에서 전투 카드 or 전투형 우연 뒤집힘 | 확률적 (~96%) |
| **최소** | 1회 (운명) | 구조적 보장 |
| **최대** | 5회 (전투 카드 4장 + 운명) | 이론적 최대 |

## ⑧ 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| **전투 버프 중첩 규칙** | "축적 불가" 방향. 구체 처리(덮어쓰기? 선택?) 미정 | 카드 9장 설계 시 실제 사례로 확정 |
| **우연 카드 풀** | 런마다 랜덤. 풀 구성 미정 | Stage 1 우연 카드 후보 설계 |
| **운명 전투 상세** | 턴 5 자동 발동 확정. 연출/적 편성 미정 | Stage 1 전투 밸런스 설계 |
| **적 편성 시스템** | 전투 카드 분기에서 적이 결정됨. 적 데이터 구조 미정 | 전투 엔진과 연동 설계 |
| **낮/밤 전투 차이** | 낮/밤 교대 확정. 전투 시 구체 메카닉 차이 미정 | 전투 구조 문서와 연동 |
| **유물 재료 집계** | 토큰 제거로 기존 방식 폐기. 겪은 카드+선택 기반 방향 | 유물 시스템 설계 시 |

## ⑨ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 토큰을 제거했는가? | 토큰은 추상 자원. "숫자 +1"보다 "창병이 합류했다"가 강한 보상. 또한 전략 토큰이 로그라이크 리플레이를 깨뜨리고, 토큰 축적이 운명 전투 난이도를 왜곡함 |
| 왜 전투 버프가 다음 전투 한정인가? | 축적 허용 시 비전투 카드 연속 → 버프 쌓임 → 운명 전투 무력화. 1회 한정으로 "준비는 다음 전투에만 쓸 수 있다"는 긴장감 유지 |
| 왜 뒷면이 전투/비전투 표시인가? | 토큰 종류보다 "이 카드를 뒤집으면 싸우게 되는가"가 플레이어에게 훨씬 유의미한 정보. "다음이 전투면 각잡자, 비전투면 준비하자"라는 판단이 생김 |
| 왜 운명이 턴 5 자동 발동인가? | 운명 = 스테이지의 목적. 반드시 마주해야 하며, 턴 1~4는 준비, 턴 5는 결전 |
| 왜 전투 카드 분기가 양쪽 다 전투인가? | 서자 부대는 다리를 확보하러 왔음. "누구랑 어떻게 싸울지"가 진짜 판단 |
| 왜 패스가 없는가? | 핵심경험목표 — "닥친 상황에 대응한다". 서자 부대는 골라야 산다 |
| 왜 우연 뒷면이 사건과 동일한가? | 구분 가능하면 우연이 아님. 완전 위장이 핵심 |
