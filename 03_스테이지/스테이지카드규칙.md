## ① 한 줄 요약

뒷면 3장이 제시된다. 홀드 탭으로 유추한다. 2장을 블라인드로 고른다. 1장은 전해지지 않은 이야기로 사라진다. 고른 카드를 뒤집고 분기를 선택한다. 모든 페이즈가 끝나면 운명 전투.

---

## ② 막 시작 — 풀에서 뽑기

각 막 시작 시 권 풀에서 카드를 뽑아 막 덱을 구성한다.

| 단계 | 처리 |
|------|------|
| 1 | 전투 풀에서 3장 뽑기 (런 내 비중복) |
| 2 | 사건 풀에서 3장 뽑기 (런 내 비중복) |
| 3 | 우연 풀에서 N장 뽑기 (배경 상황이 결정. 런 내 비중복) |
| 4 | 전투+사건+우연 셔플 |
| 5 | 운명 카드 1장 배치 (런 시작 시 배정됨. 마지막 위치 고정) |

> **풀 상세:** → [카드풀구조_초안_v3](../DOCS/DESIGN/카드풀구조_초안_v3.md) 참조

### 셔플 제약

| 규칙 | 내용 |
|------|------|
| 같은 유형 3장 불가 | 한 페이즈에 전투-전투-전투, 사건-사건-사건 불가 |
| 우연 페이즈당 최대 1장 | 한 페이즈에 우연 2장 이상 불가 |

## ③ 페이즈 진행 — 블라인드 선택

### 페이즈 수 (장별)

| 장 위치 | 페이즈 수 | 성격 |
|---------|----------|------|
| 1장 | 2페이즈 | 도입 |
| 2장 | 3페이즈 | 전개 |
| 3장 | 3페이즈 | 절정 |

### 페이즈 흐름

| 순서 | 처리 | 수동/자동 |
|------|------|----------|
| 1 | 셔플된 막 덱에서 **뒷면 3장 제시** | 자동 |
| 2 | **홀드 탭** — 카드를 길게 누르면 일러스트가 일렁임. 희미하게 유추 가능. 확신 불가 | **수동** |
| 3 | **추종자 조언** (보유 시) | 자동 |
| 4 | **블라인드 2장 선택** — 유형(전투/사건/우연)을 모른 채 고름 | **수동** |
| 5 | 안 뽑힌 1장 → **전해지지 않은 이야기** (뒷면 채 퇴장. 내용 미공개) | 자동 |
| 6 | 선택한 2장 뒤집기 → **플레이 순서 결정** (플레이어) → 순차 플레이 | **수동** |

> **핵심 판단:** "뭘 가져갈 것인가"(붙잡기) + "어떤 순서로 볼 것인가"(뒤집기). → [CORE-001 핵심경험목표](../01_코어/핵심경험목표.md) 참조

### 모든 페이즈 종료 후

| 처리 | 내용 |
|------|------|
| 운명 카드 뒤집기 | 자동. 운명 전투 강제 발동 |
| 승리 | 추종자 2명 제시, 1명 선택 → [META-FOLLOWER 추종자](../04_메타/추종자.md) |
| 패배 | **게임 오버** |

## ④ 홀드 탭 + 일러스트 기만

### 정보 신뢰도

| 신뢰도 | 상태 | 예시 |
|--------|------|------|
| **확실** | 운명 카드 뒷면 (금색 테두리) | "이건 운명이다" |
| **높음** | 일러스트가 명확한 카드 | 칼 든 병사 → 전투 가능성 높음 |
| **중간** | 일러스트가 모호한 카드 | 길 위의 사람들 → 전투? 사건? 우연? |
| **낮음** | 일러스트가 기만하는 카드 | 평화로운 마을 → 실은 우연 [배신] |

### 기만 구조

- 같은 일러스트 = 반드시 전투/사건/우연 3종 존재 (일러스트 1장 = 카드 세트 3장)
- 이전 런에서 사건이었던 그림이 이번에는 전투가 될 수 있음
- 리플레이할수록 "이 그림이면 1/3" 학습. 확신은 불가
- 일부 카드는 의도적으로 다른 유형처럼 보이는 일러스트 사용

### 추종자 조언

| 추종자 등급 | 조언 형태 |
|-----------|----------|
| Nameless | 현상 서술만. "마을에서 불길이 치솟고 있습니다" |
| Named | 현상 + 해석 + 의견 (편향 있음). "매복이 있을 수도 있습니다, 테오도라님" |

> 추종자 조언은 **틀릴 수 있음.** Named 추종자는 성격 기반 편향(신중/호전/비관/낙관). 유저는 추종자의 편향을 학습해서 보정해야 함.

## ⑤ 카드 종류

### 이야기 카드 뒷면 — 전 유형 동일

| 필드 | 내용 |
|------|------|
| **디자인** | 권 공통. "CHRONICLE" 각인. 크로스해치 질감 |
| **정보량** | 없음. 전투/사건/우연 구분 불가 |
| **홀드 탭** | 길게 누르면 일러스트 일렁임 — 유추만 가능 |

### 운명 카드 뒷면 — 별도

| 필드 | 내용 |
|------|------|
| **디자인** | 금색 테두리. 이벤트 카드와 다른 뒷면 |
| **식별** | 마지막 카드가 운명이라는 것을 알 수 있음 |
| **위치** | 항상 마지막. 모든 페이즈 종료 후 자동 뒤집기 |

### 전투 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 전투 진입. 분기 양쪽 다 전투 |
| **분기** | 최대 2개. "어떻게 싸울지" 선택 |
| **적 정보** | 서술로 힌트만. "보초 둘", "대규모 부대" 등. 적 상세는 전투 시작 후 공개 |
| **태그** | **유저 미노출.** 서술이 태그 효과를 암시 |

### 사건 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 준비 카드. 정보, 합류, 장비, 정찰 등 |
| **분기** | 최대 2개. 각 분기마다 다른 이득+비용 |
| **태그** | **유저 미노출.** 서술로만 유추 |

### 우연 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 통제 밖의 사건. 뒤집는 순간 즉시 발동 |
| **선택** | 없음. 분기 없음 |
| **종류** | 우연-전투 (강제 전투 진입) / 우연-이벤트 (즉발 효과) |
| **태그** | **유저 미노출** |

### 운명 카드 (앞면)

| 필드 | 내용 |
|------|------|
| **역할** | 장 제목 + 최종 전투 + 추종자 획득 |
| **구성** | 전략 태그 1(필수) + 전술 태그 1(필수) + 적 테이블 |
| **승리** | 추종자 2명 제시, 1명 선택 |
| **패배** | 게임 오버 |

## ⑥ 카드 앞면 레이아웃

### 전투/사건 카드

```
┌──────────────────────┐
│                      │
│   [배경 일러스트]      │
│                      │
├──────────────────────┤
│  「강변의 보초」        │  ← 카드 제목 (태그명 미노출)
│                      │
│  다리 이쪽 끝에 적    │  ← 상황 서술
│  보초 둘이 서 있다.   │
├──────────────────────┤
│  A. 숨어서 기습한다   │  ← 분기 선택지
│     효과 서술 텍스트   │     (태그 미노출. 서술로 효과 암시)
│     적 힌트: 보초 2기  │
│                      │
│  B. 정면에서 나선다   │
│     효과 서술 텍스트   │
│     적 힌트: 보초+지휘관│
└──────────────────────┘
```

> **태그 미노출 원칙:** 카드 앞면에 [기습], [봉쇄] 등 태그명을 표시하지 않는다. 서술이 효과를 암시할 뿐. 유저는 서술을 읽고 어떤 효과가 있을지 유추한다.

### 우연 카드

```
┌──────────────────────┐
│                      │
│   [배경 일러스트]      │
│                      │
├──────────────────────┤
│  「뜻밖의 조우」        │  ← 카드 제목
│                      │
│  풀숲에서 낯선 병사   │  ← 상황 서술 + 즉발 효과 서술
│  셋이 나타났다.       │
│  싸울 수밖에 없다.    │     (분기 없음. 즉시 발동)
└──────────────────────┘
```

## ⑦ 전해지지 않은 이야기

| 항목 | 내용 |
|------|------|
| 정의 | 페이즈에서 유저가 선택하지 않은 카드 |
| 공개 | **없음.** 뒷면 채 퇴장. 내용 미공개 |
| 연출 | 모든 버림 카드 동일 연출 |
| 기록 상태 | 정사/야사/미기록에 이은 **4번째 기록 상태** |

> **서사:** "모든 이야기가 겪어지는 것은 아니다. 전해지지 않은 이야기는 영원히 뒤집히지 않는다."

## ⑧ 덱 운영 규칙

### 풀 구조 (권 = 풀)

| 풀 | 크기 | 뽑기 기준 |
|----|------|----------|
| 전투 풀 | 60장 (기본 일러스트 60 × 전투 1종) | 막당 3장, 런 내 비중복 |
| 사건 풀 | 60장 (기본 일러스트 60 × 사건 1종) | 막당 3장, 런 내 비중복 |
| 우연 풀 | 60장 (기본 일러스트 60 × 우연 1종) | 배경 상황이 주입 수 결정 |
| 운명 풀 | 60장 (운명 일러스트 20 × 3종) | 런 시작 시 6장 비중복 |
| **1권 합계** | **240장** | |

### 런당 소모량

| 항목 | 값 |
|------|-----|
| 막 / 런 | 6 |
| 페이즈 / 런 | 16 (2+2+3+3+3+3) |
| 제시 카드 / 페이즈 | 3장 |
| 선택 / 페이즈 | 2장 |
| 버림 / 페이즈 | 1장 (전해지지 않은 이야기) |
| 운명 / 런 | 6장 |
| **런당 소모** | **48~60장** |

### 전투 횟수

| 전투 | 출처 | 보장 |
|------|------|------|
| 운명 전투 | 막 종료 시 자동 | 100% (런당 6회) |
| 전투 카드 | 블라인드 선택으로 뒤집힘 | 확률적 |
| 우연-전투 | 블라인드 선택으로 뒤집힘 | 확률적 |
| **최소** | 6회 (운명만) | 구조적 보장 |

## ⑨ 겪은 카드 표시

| 요소 | 내용 |
|------|------|
| **겪은 카드** | 앞면이 보이는 상태로 표시. 탭하면 다시 볼 수 있음 |
| **남은 카드** | 뒷면 아이콘 + 숫자. 운명 카드 뒷면이 별도로 보임 |
| **전해지지 않은 이야기** | 뒷면 채 퇴장. 도감에 기록되지 않음 |

## ⑩ 설계 근거

**Q. 왜 블라인드 선택인가?**
"정보는 부족하고 현장은 이미 달라져 있다" — 핵심경험목표의 구조적 구현. 뒤집기 전에 선택해야 하므로 홀드 탭으로 유추하고, 추종자 조언을 참고하되 불확실성은 남는다.

**Q. 왜 순차 뒤집기가 아닌가?**
순차 뒤집기는 플레이어 에이전시가 분기 선택뿐. 블라인드 선택은 "뭘 가져갈지"와 "뭘 버릴지"가 추가됨. 전해지지 않은 이야기가 만들어짐.

**Q. 왜 3장 중 2장인가?**
3장 전부 가져가면 블라인드 의미 없음. 1장만 가져가면 콘텐츠 소모가 너무 적음. 2장 선택 + 1장 버림이 "가져갈 것과 버릴 것의 판단"을 만드는 최소 구조.

**Q. 왜 태그를 미노출하는가?**
태그는 내부 메카닉. 유저에게 [기습]이라고 보여주면 "기습 = ⚔ 유리" 같은 메타 지식이 형성. 서술로만 암시하면 "숨어서 기습한다 → 유리할 것 같다"는 유추만 가능. 불확실성 유지.

**Q. 왜 일러스트 1장 = 3종인가?**
기만 구조 + 아트 효율 + 도감 단위 + 스토아 팩토리 생산 단위. 같은 그림이 전투/사건/우연으로 나뉘어 블라인드 기만을 구조적으로 보장.

**Q. 왜 운명이 마지막인가?**
준비→결전 구조. 페이즈에서 겪은 이야기 카드가 운명 전투를 위한 준비. 마지막인 걸 아니까 역산 전략이 생긴다.

**Q. 왜 스텝2(버프)가 비어있는가?**
이야기 카드 분기 효과(태그)가 직접 부대 상태를 변화시키는 구조. 별도 버프를 부여해서 전투 중 소모하는 구조가 아님. 전투 중 에이전시는 대형 선택(산개/밀집) + 리롤 + 방진/반격으로 충분.
