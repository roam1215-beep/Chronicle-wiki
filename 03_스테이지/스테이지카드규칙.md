# 카드 시스템

## 구조

```yaml
Stage = 4 Phase
Phase = 3장 (선택 + 거부 + 감내) 또는 운명 Phase (운명 카드 1장)

7장면 = Stage 단위
변주 = Order 단위 인격 (같은 자리의 다른 가능세계)
```

## 페이즈 진행

```yaml
어휘: 선택 - 거부 - 감내

선택: 1번 카드 박음 (효과 발동)
거부: 1번 카드 거부 (효과 X)
감내: 2번 카드 박음 (자동, 거부 X)

발화 순서: 1번 → 2번 → 거부 카드
비가역 결정

뒷면 2상태:
  Dark:  미공개 (정보 X)
  Type:  분류만 공개 (전투/사건/우연/운명)
```

## 카드 종류

```yaml
전투 카드:
  Type 노출 시 다 공개 (페이즈 결로 정보 차단됨)
  Battle 1개 = 전투 카드 1장
  최대 2 Battle (1·2번 다 전투면)

사건 카드:
  결과형 단일 (분기 X)
  즉발 (선택 시 결과 박힘)

우연 카드:
  분기 (축복·저주)
  5 자리: 위기/기회/축복/저주/예언

운명 카드:
  운명 Phase 1장
  Stage 팩 공용 뒷면
```

## 정보 공개

```yaml
적 유닛 모형 위:
  노출:    위계 (인간/영웅/무리/재앙) + 자기 시간대 + hp 바 + 보호막 개수 + 방어도 수치 + 직업 아이콘
  비노출:  등급 (가호 수로 드러남), 공격력

정보 비대칭:
  아군: hp + 보호막 + 방어도 (정확한 숫자)
  적:   hp 바 + 보호막 개수 + 방어도 수치 (유추)
```

## 인격 변주

```yaml
Order 단위
같은 인물, 다른 인격 = 다른 가능세계
예: 용맹한·지혜로운·빛나는 테오도라

해금:
  Order 클리어 시 다른 인격 해금
  같은 Order 다른 인격 = 다른 결의 자리 박힘
  [구체 결 = 펜딩, 작가 결]
```
