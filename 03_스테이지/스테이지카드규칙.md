# STAGE-CARD-002: 스테이지 카드 규칙 (Stage Card Rules)

> **상태:** 🔄 설계중 · **버전:** 0.2 · **ID:** STAGE-CARD-002 · **수정일:** 2026-02-28

---

## ① 한 줄 요약

턴 1~4에 카드 1장씩 뒤집는다. 뒤집으면 토큰을 받고, 분기를 고른다. 턴 5에 운명 전투가 자동 발동한다.

---

## ② 턴 구조

```
턴 1(낮)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 2(밤)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 3(낮)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 4(밤)  →  카드 뒤집기  →  토큰 획득  →  분기 선택  →  효과 적용 [전투 시 7스텝]
턴 5(낮)  →  ★ 운명 전투 자동 발동  →  운명 판정  →  기록
```

- 턴 1~4: 덱에서 카드 4장 뒤집힘
- 턴 5: 카드 뒤집기 없음. 운명 전투가 자동으로 발동
- 전투 최소 1회(운명) 보장. 덱에서 추가 전투 가능

## ③ 카드 구조

### 뒷면 (뒤집기 전)

| 필드 | 내용 |
|------|------|
| **공통 프레임** | 스테이지별 공통 디자인. 스테이지 문양 + CHRONICLE 표기 |
| **토큰 아이콘** | 전술(⚔) / 지휘(🔍) / 전략(↻) 중 하나. 공통 프레임 위에 표시 |
| **우연 카드** | 뒷면이 사건 카드와 완전히 동일. 뒤집기 전까지 절대 구분 불가 |
| **정보량** | 토큰 종류만 알 수 있음. 상황, 분기, 효과, 사건/우연 여부 모름 |

### 앞면 (뒤집은 후)

| 필드 | 내용 |
|------|------|
| **일러스트** | 배경 일러스트 1장 |
| **상황 서술** | 중앙 최상단. 무슨 일이 벌어졌는가. 1~2문장 |
| **분기** | 서술 아래. 사건 카드: 2~3개 선택지 |
| **토큰 보상** | 카드에 고정. 뒤집으면 무조건 받음. 분기 선택과 무관 |
| **즉시 발동** | 우연 카드: 선택 없음. 효과 즉시 적용 |

### 조작법

| 조작 | 효과 |
|------|------|
| **클릭/터치** | 토큰 정보 팝업 (자원 설명) |
| **길게 누르기** | 카드 아래쪽이 살짝 들림. 누르는 동안 천천히 앞면 드러남. 손 떼면 다시 덮임 |
| **70% 이상 들추기** | 완전히 뒤집힘 (되돌릴 수 없음) |
| **스페이스바** | 즉시 뒤집기 |

## ④ 카드 종류

### 사건 카드 — 전투

| 필드 | 내용 |
|------|------|
| **역할** | 전투 진입 카드. 분기 양쪽 다 전투 |
| **분기** | "누구랑 싸울지" 선택. 엘리트 vs 일반, 기습 vs 정면 등 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |
| **토큰** | 뒤집는 순간 고정 토큰 +1 |

### 사건 카드 — 비전투

| 필드 | 내용 |
|------|------|
| **역할** | 준비 카드. 정보, 합류, 장비, 정찰 등 |
| **분기** | 2~3개. 각 분기마다 다른 이득+비용 |
| **선택** | 반드시 하나를 골라야 함. 패스 없음 |
| **토큰** | 뒤집는 순간 고정 토큰 +1 |

### 우연 카드

| 필드 | 내용 |
|------|------|
| **뒷면** | 사건 카드와 완전히 동일. 토큰 아이콘도 위장 (랜덤) |
| **선택** | 없음. 뒤집는 순간 즉시 발동 |
| **내용** | 런마다 다름. 전투일 수도, 비전투(부상/병력 손실/재앙 등)일 수도 있음 |
| **토큰** | 없음 |
| **핵심** | 통제 밖의 사건. 뒤집기 전까지 알 수 없고, 뒤집으면 선택권 없음 |

### 운명

| 필드 | 내용 |
|------|------|
| **정체** | 카드가 아님. 스테이지의 목적 그 자체 |
| **표시** | 화면 상단에 운명 조건 상시 표시 (예: "적 병력 전멸") |
| **발동** | 턴 5에 자동 발동. 강제 전투 |
| **역할** | 스테이지 클리어 조건 직결. 이 전투의 승패가 스테이지 결과 |

## ⑤ 토큰 3종

| 토큰 | 아이콘 | 소모 타이밍 | 효과 |
|------|--------|------------|------|
| **전술** | ⚔ | 전투 스텝 2 | 아군 주사위 1개를 ⚔ 또는 🛡로 확정 + 카드락 |
| **지휘** | 🔍 | 전투 스텝 4 | 추가 리롤 +1 (기본 1회 → 총 2회) |
| **전략** | ↻ | 카드 페이즈 | 다음 카드를 버리고 새 카드를 뽑음 (카드 교체) |

### 토큰 규칙

| 필드 | 내용 |
|------|------|
| **획득** | 사건 카드 뒤집기 시 고정 +1. 분기 선택과 무관 |
| **이월** | 가능. 스테이지 내 전투 간 이월 |
| **소멸** | 스테이지 종료 시 잔여 토큰 소멸. 유물 재료 집계에 반영 |
| **우연** | 우연 카드는 토큰을 주지 않음 |

## ⑥ 분기 효과 풀

분기 선택지가 줄 수 있는 효과의 종류. 모든 분기는 이 풀 안에서 조합된다.

### 얻는 것 (이득)

| 효과 | 내용 |
|------|------|
| **전투 진입** | 전투 시작 (전투 카드 전용) |
| **병종 추가** | T1 유닛 1기 합류. 주사위 풀 증가 |
| **면 교체** | 유닛 1기의 ✕ 1개를 ⚔ 또는 🛡로 교체 |
| **승급** | T1 → T2 승급 기회 |
| **전투 조건 유리** | 지형 세팅, 선제 보너스, 적 정보 공개 등 |

### 잃는 것 (비용)

| 효과 | 내용 |
|------|------|
| **부상** | 유닛 1기 부상. 면 1개 → ✕ |
| **면 손상** | 유닛 1기의 유효면 1개 → ✕ |
| **병력 손실** | T1 유닛 1기 제거 (퍼마데스) |
| **전투 조건 불리** | 적 증원, 밤 전투 강제, 지형 불리 등 |

### 전투 카드 분기 설계 원칙

| 원칙 | 내용 |
|------|------|
| **양쪽 다 전투** | 전투 카드의 분기는 모두 전투로 연결. "싸울까 말까"가 아니라 "누구랑 싸울까" |
| **적 구성이 다름** | 분기에 따라 엘리트 vs 일반, 소수정예 vs 다수, 기습 vs 정면 등 |
| **전투 조건이 다름** | 분기에 따라 지형, 선제 여부, 밤/낮 보너스 등이 달라짐 |

### 비전투 카드 분기 설계 원칙

| 원칙 | 내용 |
|------|------|
| **양쪽 다 무언가** | 모든 분기는 이득과 비용이 있다. "한다/안 한다"가 아님 |
| **패스 없음** | 반드시 골라야 한다. 닥친 상황에 대응하는 것이 핵심 경험 |
| **토큰은 공짜** | 어떤 분기를 골라도 토큰은 받는다. 분기 판단에 토큰은 변수가 아님 |

## ⑦ 덱 운영 규칙

### Stage 1 기준

| 필드 | 내용 |
|------|------|
| **덱 크기** | 9장 (운명은 덱 밖) |
| **구성** | 전투 사건 4장 + 비전투 사건 4장 + 우연 1장 |
| **뒤집기** | 턴 1~4에 1장씩. 총 4장 |
| **잔여** | 5장은 안 뒤집힘. 매 런 다른 경험 |
| **셔플** | 스테이지 시작 시 셔플 |
| **전투 빈도** | 전투 카드 4장/9장 = 4장 뒤집을 때 전투 0장 확률 약 4% |

### 토큰 배분 (Stage 1)

| 토큰 | 장수 |
|------|------|
| 전술 ⚔ | 3장 |
| 지휘 🔍 | 3장 |
| 전략 ↻ | 3장 |
| 우연 | 1장 (토큰 없음, 뒷면 완전 위장) |
| **합계** | **9장** (운명은 덱 밖) |

### 전투 횟수 정리

| 전투 | 출처 | 보장 |
|------|------|------|
| **운명 전투** | 턴 5 자동 발동 | 100% 보장 |
| **사건/우연 전투** | 덱에서 전투 카드 or 전투형 우연 뒤집힘 | 확률적 (~96%) |
| **최소 전투** | 1회 (운명) | 구조적 보장 |
| **최대 전투** | 5회 (전투 카드 4장 + 운명) | 이론적 최대 |

## ⑨ 미확정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| **전략 토큰 카드 교체 세부** | "다음 카드를 버리고 새 카드를 뽑음" 방향. 덱에서? 버린 카드 더미에서? | 덱 운영 프로토타입 |
| **우연 카드 전투/비전투 결정** | 런마다 랜덤. 어떤 풀에서 뽑는지 미정 | 우연 카드 풀 설계 |
| **운명 전투 상세** | 턴 5 자동 발동 확정. 연출/적 편성 미정 | Stage 1 전투 밸런스 설계 |
| **분기 효과 밸런스** | 풀만 정의. 구체 수치/조합 미정 | 카드 9장 개별 설계 시 |
| **낮/밤 전투 차이** | 낮/밤 교대 확정. 전투 시 구체 차이 미정 | 전투 구조 문서와 연동 |

## ⑩ 설계 근거

| 질문 | 답변 |
|------|------|
| 왜 운명이 턴 5 자동 발동인가? | 운명 = 스테이지의 목적. 반드시 마주해야 하며, 카드처럼 운에 맡기면 안 됨. 턴 1~4는 준비, 턴 5는 결전 |
| 왜 전투 카드 분기가 양쪽 다 전투인가? | "싸울까 말까"는 다리목 전초전 맥락에서 말이 안 됨. 서자 부대는 다리를 확보하러 왔음. "누구랑 어떻게 싸울지"가 진짜 판단 |
| 왜 우연이 런마다 다른가? | 우연의 정체성 — 통제 밖. 같은 스테이지에서 매번 다른 우연이 일어나야 "이번 런"의 고유성이 생김 |
| 왜 토큰이 분기와 무관한가? | 토큰을 분기에 걸면 "토큰 최적화"가 판단의 전부가 됨. 분기에서는 전투/병력/상태 같은 서사적 판단에 집중시키기 위함 |
| 왜 패스가 없는가? | 핵심경험목표 — "닥친 상황에 대응한다". 회피 불가. 서자 부대는 골라야 산다 |
| 왜 우연 뒷면이 사건과 완전히 동일한가? | 뒤집기 전 계획 수립 후 "당했다" 경험. 조금이라도 구분 가능하면 우연이 아님 |
| 왜 덱이 9장인데 4장만 뒤집는가? | 5장은 못 봄 = 매 런 다른 경험. 로그라이크 리플레이 핵심 |
