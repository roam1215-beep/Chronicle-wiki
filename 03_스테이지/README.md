## 현행 설계 방향

- **스테이지 진행:** 매 페이즈 뒷면 3장 중 2장 블라인드 선택 → 뒤집기 → 분기 선택. 모든 페이즈 종료 후 운명 전투. 홀드 탭으로 일러스트 유추. 태그 유저 미노출
- **뒷면:** 전 유형 동일 블라인드. 전투/사건/우연 구분 불가. 운명 카드만 별도 뒷면(금색 테두리)
- **보상:** 분기 효과가 유일한 보상. 토큰/보급/버프 없음
- **성장:** 추종자(운명 승리 시 획득) + Named 특성 7종. 부상은 전투 종료 시 자동 회복
- **구조:** 권(Order) → Chapter(3개/런) → Stage(2개/Chapter, 6개/런). 시리즈 계층 폐기
- **운명:** 운명 패배 = 게임 오버. 홀짝 이원화(패널티/패배) 폐기
