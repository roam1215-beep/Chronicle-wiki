## 현행 설계 방향 (STAGE-CARD-002 v0.8 기준)

- **스테이지 진행:** 이벤트 카드 5장 순차 뒤집기 + 6번째 운명 카드 자동 발동. 덱 6장/Stage
- **뒷면:** 완전 블라인드. 전투/비전투 구분 불가. 운명 카드만 별도 뒷면(금색 테두리)
- **보상:** 분기 효과가 유일한 보상. 토큰/보급 없음
- **버프:** 슬롯 1개, 다음 전투 한정, 덮어쓰기
- **성장:** 추종자(운명 승리 시 획득) + Named 특성. 부상은 전투 종료 시 자동 회복
- **구조:** 시리즈(Chapter 조합 묶음, Order당 3세트) → Chapter(3개/런) → Stage(2개/Chapter, 6개/런)
- **운명:** 홀수 Stage 미달성 = 패널티, 짝수 Stage 미달성 = Order 패배
