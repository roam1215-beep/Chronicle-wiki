## 설계 방향 (2026-02-26 세션 확정)

- **스테이지 진행:** 중앙 카드 덱 기반. 매 턴 3장 → 1장 선택. 이동·사건·전투 전부 여기서 나옴
- **구조:** 런(내전 종식) → 챕터(군사 작전) → 스테이지(작전 국면)
- **챕터 트위스트:** 챕터 전체에 규칙 1개 (예: "겨울 — 첫 턴 밤 강제")
- **스테이지 특수규칙:** SC2식, 스테이지당 고유 규칙 1개
- **미선택 구역 자동 판정:** 소비턴 × 1d6 → 승/교착/패
- **적 이월:** Ardennes식. 도주적 + 미선택 구역 패배분 → 다음 스테이지 합류
