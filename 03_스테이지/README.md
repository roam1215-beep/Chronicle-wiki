## 현행 설계 방향 (STAGE-CARD-002 v0.6 기준)

- **스테이지 진행:** 덱 9장 + 운명. 턴 1~4에 카드 1장씩 뒤집기 → 분기 선택. 턴 5에 운명 전투 자동 발동
- **뒷면:** 완전 블라인드. 전투/비전투 구분 불가
- **보상:** 분기 효과가 유일한 보상. 토큰/보급 없음
- **버프:** 슬롯 1개, 다음 전투 한정, 덮어쓰기
- **결산:** 운명 달성 시 유물 생성 + 부상 회복 + 면 교체 + 승급 (야영 대체)
- **구조:** 런(내전 종식) → 챕터(군사 작전) → 스테이지(작전 국면)
