# ORDER-001-CH: 미궁의 테오도라 — 챕터 + 인격 변주

> 상태: 결정정합 (5-9 정합) · 의존: @ORDER-001-WORLD, @ORDER-001-FIGURE, @STAGE-CARD-002, @COMBAT-UNIT-HERO

> 5-9 정합:
> - 변주 시스템 = 그대로 유지 (용맹/지혜/광명, 가능세계 결)
> - 챕터·스테이지 골격 = 그대로 유지
> - 운명 전투 = 재앙 처치 (5-8 신규 어휘)
>   발드 (라키아의 사자) = 재앙
>   재앙 처치 = 영웅(테오도라)에 신성 주사위 +1 = 카타스테리스모스 작동 (5-9 정정)
> - 도적단 = 무리 (미궁 출신? 또는 다른 결?). 펜딩
> - 도시국가군 = 인간 + 영웅 (지상·경계 출신)
> - 챕터 1 시뮬 시 = 라키아의 들개 스테이지 = 시뮬·시드 박힌 후 가능
> - 5-9 어휘 정정: 도시 → 지상 (팩션 결). 도시국가 = 작품 결 어휘 (그대로).
> 상세: `DOCS/DESIGN/LOG/2026-05-09_전투4.0_코어_박힘.md`

## 정의
Order 1 = 테오도라. 한 인물 한 호(弧)의 한 런. 3 챕터 = 다리 위의 아이 → 경계의 테오도라 → 해방의 테오도라. 변주 = 오더 단위 인격 (용맹한 / 지혜로운 / 빛나는).

## 규칙

### 작품 종결 조건
- 결: 공헌제가 거짓된 명예이자 인신공양임을 폭로
- 청자: 다음 공헌제 후보 아이들
- 시점: 챕터 3 마지막
- 시리즈 내 위치: 미궁 거짓 지배 종결의 효시

### 챕터 골격

#### 챕터 1: 다리 위의 아이
- 무대: 지상
- 결: 튜토리얼이자 테오도라가 누구인지 보여주는 자리. 위업 → 공헌제 자격
- 중의: "다리 위" = ① 출생 (사생아) ② 라키아 다리 위 포부 발화 ③ 장소 = 다리
- 스테이지:
  - 1: 라키아의 들개
  - 2: 라키아의 사자
  - 3: 골짜기는 더 이상 울지 않는다

#### 챕터 2: 경계의 테오도라
- 무대: 경계
- 결: 경계의 기만, 경계에서 겪는 이야기, 반격 다짐
- 스테이지:
  - 1: 연회 그리고 면회 (참조: @ORDER-001-SCENE 환대 연회)
  - 2: 도망치는 자들
  - 3: 길이 없다면 누구의 잘못인가

#### 챕터 3: 해방의 테오도라
- 무대: 지상 (경계에서 물리적 귀환)
- 결: 미궁에서 벗어나, 공헌제가 거짓된 명예이자 인신공양임을 폭로
- 스테이지:
  - 1: 반격 그리고 반란
  - 2: 테오도라, 그녀는 누구인가
  - 3: 미궁에 헤매임이 빠진다면 뭐라고 불러야 하는가

용맹:

  자리: 펜딩 (구체 결 다른 세션)

### 같은 자리, 다른 인격 — 결의 차이 예시

```yaml
스테이지: 라키아의 들개
운명: 발드 (도적단 두목 별명 = "사자")

용맹 결:
  P1 도적 침공: 테오도라가 앞장서서 막음. 정면 충돌
  P2 토벌대 합류: 테오도라가 토벌대 주도
  P3 지부 들이침: 정면 진군
  운명 발드: 정면 결투

지혜 결:
  P1 도적 침공: 마을 사람 보호 + 후퇴 위주. 회피·수비
  P2 토벌대 합류: 토벌대 뒤따름. 후방 지원
  P3 지부 들이침: 우회·정찰 후 진입
  운명 발드: 꾐에 빠진 발드 (계략으로 처치)

→ 큰 결과는 같음 (사자 처치). 가는 길이 다름
→ "용맹의 발드"와 "지혜의 발드"는 본체 같은 발드, 표현 다름
```

### 챕터 1 스테이지 1: 라키아의 들개 — 페이즈 골격

```yaml
상황:
  지명: 라키아 (장소)
  사건: 도적단 발호. 두목 별명 = "사자". 본명 = 발드 (잠정)
  토벌대: 나라 모집. 전력 약함. NPC = 환경 모디파이어
  우호 NPC: 1명 (다음 챕터까지 이어짐). 토벌대 NPC는 안 이어짐. (참조: @META-NPC)
  테오도라: 토벌대 자원
    내적 동기: 명성 → 공헌제 자격 → 미궁 입성 → 형제자매 보호
    외적 표현: 의협심, 라키아 수호

페이즈 (변주 무관 골격):
  P1: 도적이 마을에 침공
  P2: 도적을 마을에서 몰아냄 + 토벌대 합류
  P3: 도적단 지부 들이침
  운명: 도적단 지부 대장 (발드)과의 전투

장소 특수 규칙: 없음 (튜토리얼 결)
```
