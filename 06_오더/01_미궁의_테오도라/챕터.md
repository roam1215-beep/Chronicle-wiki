# 미궁의 테오도라 — 챕터 + 인격

## 정의
Order 1 = 미궁의 테오도라 팩 (확장팩 단위 작품 그릇). 테세우스 결 차용 (완전 대응 X, 속성). 크레타 섬 결 — 공물로 바쳐지고 미궁에서 탈출하는 호. 3 인격 팩 × 90장 = 270장 스토리 카드. 각 인격마다 챕터·스테이지 명명 다름 (같은 자리, 다른 가능세계).

## 규칙

### 인격 시스템 (그리스 4주덕)

```yaml
4주덕 풀: 지혜 / 용기 / 절제 / 정의
인물 = 4주덕 중 3 인격 보유
빠진 1개 = 그 인물의 정체성 결

테오도라:
  보유: 용기 / 지혜 / 정의
  빠짐: 절제 → "절제 없는 자" = 테오도라 정체성
  표기: 용맹한 / 지혜로운 / 정의로운 테오도라
```

### 작품 종결 조건
- 결: 공헌제가 거짓된 명예이자 인신공양임을 폭로
- 청자: 다음 공헌제 후보 아이들
- 시점: 챕터 3 마지막
- 시리즈 내 위치: 미궁 거짓 지배 종결의 효시

### 인격별 챕터·스테이지

```yaml
같은 오더, 같은 큰 흐름, 인격마다 다른 결 박힘
```

#### 용맹한 테오도라

```yaml
챕터 1: 버려진 아이
  결: 출생 결 + 튜토리얼 + 위업 → 공헌제 자격
  스테이지:
    1-1: 라키아의 들개
    1-2: 라키아의 사자
    1-3: 골짜기는 더 이상 울지 않는다

챕터 2: 단말마와 메아리
  결: 미궁의 거짓을 몸으로 겪는 결 + 반격 다짐
  스테이지:
    2-1: 도망치는 자들
    2-2: 다가오는 위협
    2-3: 헤매임의 끝

챕터 3: 신탁
  결: 폭로의 결 + 진실의 공적 발화
  스테이지:
    3-1: 귀환
    3-2: 기만과 체념 사이
    3-3: 변하지 않는 것들
```

#### 지혜로운 테오도라
```yaml
명명: [펜딩, 작가 결]
```

#### 정의로운 테오도라
```yaml
명명: [펜딩, 작가 결]
```

### 같은 자리, 다른 인격 — 결의 차이 예시

```yaml
자리: 챕터 1 스테이지 1 (용맹 = 라키아의 들개)
대적자: 발드 (도적단 두목 별명 = "사자")

용맹 결:
  P1 도적 침공: 테오도라가 앞장서서 막음. 정면 충돌
  P2 토벌대 합류: 테오도라가 토벌대 주도
  P3 지부 들이침: 정면 진군
  운명 발드: 정면 결투

지혜 결:
  P1 도적 침공: 마을 사람 보호 + 후퇴 위주. 회피·수비
  P2 토벌대 합류: 토벌대 뒤따름. 후방 지원
  P3 지부 들이침: 우회·정찰 후 진입
  운명 발드: 꾐에 빠진 발드 (계략으로 처치)

→ 큰 결과는 같음 (사자 처치). 가는 길이 다름
→ 본체 같은 발드, 표현 다름 (대적자 본체 동일, 인격별 표현 분기)
```

### 챕터 1 스테이지 1: 라키아의 들개 — 페이즈 골격 (용맹)

```yaml
상황:
  지명: 라키아 (장소)
  사건: 도적단 발호. 두목 별명 = "사자". 본명 = 발드 (잠정)
  토벌대: 나라 모집. 전력 약함. NPC = 환경 모디파이어
  우호 NPC: 1명 (다음 챕터까지 이어짐). 토벌대 NPC는 안 이어짐.
  테오도라: 토벌대 자원
    내적 동기: 명성 → 공헌제 자격 → 미궁 입성 → 형제자매 보호
    외적 표현: 의협심, 라키아 수호

페이즈 (용맹 결 골격):
  P1: 도적이 마을에 침공
  P2: 도적을 마을에서 몰아냄 + 토벌대 합류
  P3: 도적단 지부 들이침
  운명: 발드 (대적자) 와의 전투

장소 특수 규칙: 없음 (튜토리얼 결)
```

### 카드 단위 — 270장 (작품 그릇)

```yaml
미궁의 테오도라 팩 (= Order 1 확장팩 단위) = 270 스토리 카드
  ├─ 용기 인격 팩  = 90장 (81 일반 + 9 운명) = 한 회차
  ├─ 지혜 인격 팩  = 90장 (81 일반 + 9 운명) = 한 회차
  └─ 정의 인격 팩  = 90장 (81 일반 + 9 운명) = 한 회차

한 회차 = 1 인격 팩 (90장) = 3 챕터 × 3 스테이지 × 10장
스테이지 = 10장 (9 일반 + 1 운명)

인물 카드 = 별도 영구 컬렉션 (작품 결, DLC 입자)
참조 결: 전투·운명 카드 = 인물 카드 ID 참조
```
