# 미궁의 테오도라 — 인물

## 정의
Order 1의 인물 등록 인덱스. 테오도라 + 챕터 진행 시 누적되는 동료·대적자 자리.

## 규칙

### 등록 인물
- 테오도라 (효시, 작품 주인공)
- 발드 (라키아의 사자, 챕터 1 스테이지 1 대적자)
- 우호 NPC × 1 (챕터 1~2 이어짐. 자리 펜딩)
- 도적단 졸병 (잡몹 풀)

### 테오도라

```yaml
4축:
  진영: 지상
  종족: 인간
  태생: 한낮
  위계: 인간 → 영웅 (Order 클리어 시 등극)
  등급: 필멸 → 반신 → 신성 → 번외 (챕터 클리어 시 변동)

인격 (4주덕):
  보유: 용기 / 지혜 / 정의
  빠짐: 절제 → "절제 없는 자" = 정체성
  표기: 용맹한 / 지혜로운 / 정의로운 테오도라

신분: 사생아
동기 발화 시점: 어린 시절, 공헌제 진실 우연히 알게 됨
결심: 미궁에 잡아먹히지 않고 미궁을 잡아먹고 나옴
단련: 결심 시점부터 자기 단련
공헌 사유: 형제자매 보호 위해 본인 지원

작품 내 위치: 미궁 반격의 효시
시리즈 내 위치: 다른 Order에서 NPC로 등장 가능 (도시국가 1개 점령 + 선언 후 시점)
```

### 발드 (라키아의 사자)

```yaml
자리: Order 1 챕터 1 스테이지 1 대적자
별명: 사자 (도적단 두목)
본명: 발드 (잠정)

4축:
  진영: 미궁
  종족: 무리
  태생: 심야
  위계: 재앙
  등급: 신성 또는 번외 (펜딩)

직업: 펜딩
공·hp: 펜딩 (잠정 시드)
```

### 인물 카드 결 (영구 컬렉션)

```yaml
인물 카드 = 영구 컬렉션 (작품 결, DLC 입자)
같은 인물 = 여러 카드 가능 (붕어빵 풀)
  - 다른 자리·시점·인격의 기본형
  - 예: "라키아의 들개 테오도라 (필멸/한낮/전사)"
       "미궁의 사슬 테오도라 (인격별 다른 자리)"
  - 시점 교차 시 그 시점의 카드 호출

해금: 명시적 (가챠 X)
누적: Order 진행에 따라 풀 누적
```

### 잠정 능력치 결 (시뮬 전)

```yaml
스탯: 공격력 + 체력 (2종)
합 결 (등급별, 잠정 시드):
  필멸: 합 4
  반신: 합 9
  신성: 합 16
  번외: 합 25
  → 죽창 결 (1라운드 결판) 기준

태생 분배 비율 (잠정 시드):
  한낮:  공 30% / hp 70%  (수비)
  여명:  공 40% / hp 60%  (균형, hp ↑)
  황혼:  공 60% / hp 40%  (균형, 공 ↑)
  심야:  공 70% / hp 30%  (공격)

방어도·축복·도발 = 직업 자동 매커니즘 (스탯 밖)
가호 = 등급+위계+태생 결 (합 밖, 영구)
```
