# 06_오더 — 인덱스

> 상태: **결정정합 (5-7) · 5-8 갱신 (시점 교차 풀이 + 등급 4종 + 카타스테리스모스)**

## 정의
Order = 한 영웅의 한 호. 한 별이 별자리가 되는 자리. N개 누적 = 시리즈 = 밤하늘.

## 규칙

### 5층 구조 내 위치
- 인물 → 오더 → 챕터 → 스테이지 → 전투
- 오더 = 한 인물의 한 호 (캠페인 전체)
- 인물별 무대 누적 = 세계 전체 (단일 세계관 강제 X)

### 카타스테리스모스 결 (5-8)

```yaml
영웅: 무명에서 시작 (Order 시작 시점)
운명 전투: 재앙 처치 = 덕목 박힘 = 별 자리 생김
Order 클리어: 영웅이 별자리로 박힘 (카타스테리스모스 작동)
시리즈: 여러 별자리 = 밤하늘
시리즈 종결: 별자리들이 함께 보임 = 미궁 세계 전체 그림
```

### 시리즈 단위 결정
- 효시: Order 1 (미궁의 테오도라) = 첫 별
- 1층 폭로 (5-6): 공헌제 = 거짓된 명예 + 인신공양
- 2층 폭로 (5-8 신규): 경계의 인간 = 미궁 끄나풀 (시점 펜딩)
- 종결: 여러 영웅 Order 모음 = 미궁 세계 거짓 지배 전체 종결
- 작품 단위 ≠ 시리즈 단위 (한 오더는 도시국가 1개 단위)

### Order 간 시점 교차 (5-8 풀이)

영감 결: 워크래프트 III *Reign of Chaos* 4 캠페인 (인간/언데드/오크/나이트엘프) + *Frozen Throne* 3 캠페인 (Sentinels/Alliance/Scourge). 같은 시기·세계의 영웅들이 다른 단면에서 자기 결로 풀림. 그리고 만남.

플루타르크 영웅전 결도 같이: 영웅들의 *비교 전기*. 같은 결의 두 자리 또는 다른 결의 두 자리.

```yaml
교차 메카닉 4종 (5-8 비전, 디테일 펜딩):

1. NPC 등장:
   다른 Order의 효시 인물이 NPC로 등장
   예: Order 1 클리어 후 → Order N에서 테오도라가 NPC로 등장
   조건: Order 1의 도시국가 1개 점령 + 진실 발화 시점 이후
   
2. 같은 사건 두 시점:
   하나의 사건이 여러 Order에서 *다른 결로* 다시 보임
   예: 공헌제 폭로 = Order 1에서는 *발화의 자리*
                   Order N에서는 *듣는 자리* (사건 카드)
   사서 프레임 정합: "그날, 다리 위에서 한 여인이 외쳤다"
   
3. 세계 상태 변화 누적:
   Order 클리어 = 세계 영구 변화
   다음 Order에서 그 자리는 *다른 결*
   예: Order 1 클리어 = 라키아 도적단 정리 → Order N에서 라키아는 다른 결

4. 시간선 동시 진행:
   여러 Order가 *같은 시간선*에서 동시 진행
   어느 Order 먼저 플레이하느냐에 따라 *교차 자리* 다름
```

### 사서 프레임 + 시점 교차

```yaml
전해진 이야기 (자동 공개 카드): Order에서 박힌 결
전해지지 않은 이야기 (버린 카드): Order에서 박히지 않은 결

다른 Order에서 같은 사건:
  Order A에서 전해진 자리 = Order B에서 전해지지 않을 수도
  Order A에서 전해지지 않은 자리 = Order B에서 전해질 수도
  
진실 = 객관 X
진실 = 여러 시점의 합
단 *공적 발화*는 그래도 진실 (작품 윤리 결, 5-6)
```

### 등급 4종 (5-8)

```yaml
영웅 (Heroes):    Order 효시. 인간 상위. 카타스테리스모스 (별이 됨)
인간 (Humans):    Order 동행. 정예. 수 적음
재앙 (Calamity):  Order 운명 전투 대상. 무리 상위. 멸절. 처치 = 영웅에 덕목 박힘
무리 (Horde):     Order 적. 떼. 수 많음

영웅 ↔ 재앙 (이름 박힌 자, 큰 자리)
인간 ↔ 무리 (이름 없는 자, 작은 자리)
카타스테리스모스 ↔ 멸절
```
