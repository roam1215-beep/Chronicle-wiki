# 06_오더 — 인덱스

> 상태: 결정정합

## 정의
오더 = 인물 단위 캠페인. N개 합치면 미궁 도시 거짓 지배 종결.

## 규칙

### 5층 구조 내 위치
- 인물 → 오더 → 챕터 → 스테이지 → 전투
- 오더 = 한 인물의 캠페인 전체
- 인물별 무대 누적 = 세계 전체 (단일 세계관 강제 X)

### 시리즈 단위 결정
- 효시: Order 1 (미궁의 테오도라)
- 종결: 모든 오더 합 = 미궁 도시 거짓 지배 종결
- 작품 단위 ≠ 시리즈 단위 (한 오더는 도시 1개 단위)

### 오더 간 관계
- 각 오더는 자기 무대·인물·챕터 보유
- 다른 오더 효시 인물은 NPC로 교차 등장 가능
- 같은 사건도 오더에 따라 다른 카드로 기록 가능 (사서 프레임)

### 등록 오더
