# 기록 카드 공장 (Record Factory)

> 기록 카드 양산 공정의 정본. **어느 세션에서도 이 문서를 읽고 같은 결과를 재현한다.**
> 스키마(장면 레이어·필드) = `specs/structure.md`·`specs/cards.md`. 재료 = `design/narrative_ssot.md`.
> 이 문서 = "어떻게 찍나" (공정·페르소나·난수·검수). 옛 `tools/stoa-factory`(일괄 JSON 생성) 대체.

## 0. 부팅 (★ 재현 절차 — 새 세션은 이대로)

```yaml
1. 읽기 순서:
   CLAUDE.md → 이 README → specs/structure.md("페이즈 = 장면") → specs/cards.md(RecordCard 스키마)
   → design/narrative_ssot.md(재료: 척추·인격함수·보스) → design/style_canon.md(톤)
2. 작업할 스테이지·편 = 철님이 지시.
3. 페르소나 명세 로드 (§1) · 스테이지 풀 로드 (§6 해당 스테이지).
4. 난수 굴림 (§2 — bash 실제 난수. 임의 선택 금지) → 검수 (§3) → 정제 (§4).
5. 위키 커밋 전 철님 확인. 확인 없이 커밋 금지.
```

## 1. 페르소나 명세 (= 사람. 태도 아님)

```yaml
# 핵심: 라벨("용기")이 아니라 재현 가능한 구체(말버릇·시선·금지)를 박는다.
#       추상 한 줄("단호함")이면 매번 일반적 강단으로만 나온다 — 사람으로 두껍게.

테오도라 / 용기 / 전사:   # [확정]
  핵:     행동이 말보다 먼저. "용기 있다"고 말하는 사람이 아니라 이미 움직이는 사람.
  라코닉:  말수 적음. 짧게 끊어 말함. 설명·다짐·각오를 입에 안 담음 (그건 행동이 함).
  재치:   적은 말 안에 건조한 재치. 비장함을 농으로 눌러버림. 웃기려 들지 않고 툭 던짐.
  시선:   위협보다 지킬 것을 먼저 봄. 적을 보기 전에 등 뒤를 챙김.
  말투:   적에게도 말을 건다. 명령형보다 "~하자"에 가까운, 곁에 두고 말하는 결.
  금지:   자기 연민·후회·과거 곱씹기 X / 멋부린 명대사 X / "각오"·"결심" 어휘 X.

테오도라 / 지혜 / 사냥꾼:   # [펜딩 — 작가 박음]
테오도라 / 정의 / 사제:     # [펜딩 — 작가 박음]
# 화법 원칙: 성격·태도이지 문장 형식 아님. 길이·어미 강제 X (style_canon §3 / narrative_ssot §3).
```

## 2. 굴림 = 3층 (틀 / 판 / 맛) — 층마다 규칙이 다르다

```yaml
# 굴림은 3층. 틀·판 = "무슨 일이 일어나는가"(사건 표면) / 맛 = "어떻게 찍느냐"(베이스).
#   "틀 굴려" → 1층(골격) / "판 굴려" → 2층(살) / 맛은 판마다 베이스로 함께 굴림.
#   변주 = 틀 × 판 × 맛. 맛 레이어가 다양성을 곱으로 늘린다 (금지가 아니라 변주 확장).
# 공통: 얕은 라벨(적=d4) 금지 — 표면만 뽑히면 1차원 desc가 나온다. 극적 층위를 굴린다.
# 공통: 틀·판은 척추 제약 안 (스테이지1=침공의 밤 → 도입=들이닥침·횃불접근까지, '잠입' 류 X).

[1층] 틀 굴림 (스테이지 골격 = scene 시퀀스):
  규칙 = 인과 순서 (밤이 흐르는 단계). scene을 §6 도입/전개/절정 등급에서 각 1뽑아 배열.
         도입 → 전개 → 절정 → 운명(보스 고정). 구간 안 지키면 "반격→들이닥침" 거꾸로 남.
  운명 beat = 첫 장면(도입)과 호응 (수미상관 — structure.md "페이즈 = 장면").

[2층] 판 굴림 (틀 고정 → 살 입힘):
  규칙 = 병렬 자유 (같은 장면 스냅샷, 순서 없음 — 각도 막 뽑아도 됨, 중복 한도만 §3).
  scene(페이즈)마다:
    beat  = 그 scene의 beat 풀(§6)에서 1뽑기 (장면 핵).
    angle = 각도 풀(§6)에서 카드(battle·event·chance)마다 1뽑기 (라벨 아닌 극적 각도).
    보조  = event effect(bind|crossing|parting) · chance(행운|불운).
  ★ 변주는 angle이 가른다 (beat보다). 같은 beat라도 각도가 다르면 다른 장면 → 각도 풀을 두껍게.

[3층] 맛 (판의 베이스 — 같은 사건을 어떤 정서·시선으로 찍나):
  정서:     처절 · 분노 · 담담 · 쓸쓸 · 서늘 · 뜨겁게 들뜬 · 비장 …
  시선 거리:  한복판(휩쓸림) / 반보 물러서(관찰) / 멀리서(관조)  → desc 카메라 위치를 정함.
  무게중심:   상실 · 액션 · 사람 사이 관계 · 작은 유머가 숨통 · 공포·압박  → 무엇을 중심으로 찍나.
  ★ 맛은 사건을 안 바꾼다. 시선이 desc 카메라를, 정서·무게가 quote의 속을 바꿔
    같은 사건을 다른 밤으로 만든다 (같은 '대신 막아선 자' → 쓸쓸한 우려 / 서늘한 억누름).
  ★ 제품 정체성(페르소나 §1)은 유지 — 라코닉은 라코닉인 채로 쓸쓸·서늘·분노로 갈린다.
  ★ 함정: 맛 뽑아도 한 목소리로 수렴하면 같은 맛이 난다 → 검수(§3)가 "지난 판과 맛이 갈렸나"를 본다.
```

```python
# bash 템플릿 — §6 풀을 채워 실행. seed 없이(실제 난수).
import random
# ── 1층 틀 (인과 순서: 구간에서 각 1뽑기) ──
틀 = [random.choice(scene_도입), random.choice(scene_전개), random.choice(scene_절정)]  # → 운명 고정
# ── 2층 판 (틀 고정 후, 병렬 자유) ──
for scene in 틀:
    beat   = random.choice(beat_of[scene])
    angles = random.sample(angle_pool, 3)          # battle/event/chance — sample OK(병렬)
    eff    = random.choice(['bind','crossing','parting']); luck = random.choice(['행운','불운'])
# ── 3층 맛 (판 베이스. 연속 판은 sample로 다른 맛 — 맛 중복 방지) ──
정서 = random.sample(정서풀, 2)                     # 연속 두 판이 다른 정서
시선 = random.sample(시선풀, 2); 무게 = random.sample(무게풀, 2)
# 적용: 시선 → desc 카메라 / 정서·무게 → quote·초점 (§4 정제에서)
# 운명: beat = 도입 호응
```

## 3. 검수 게이트 (★ 스테이지 9장 단위 — 페이즈만 보면 못 잡음)

```yaml
- 틀 순서(1층):  도입→전개→절정 인과가 맞나 (절정이 앞·도입이 뒤 = 깨짐 → 재배열).
- 맛 변별(3층):  이 판, 지난 판과 맛(정서·시선·무게)이 갈렸나. 같으면 맛 재굴림(sample로 연속 중복 방지).
                 + 맛 뽑아도 한 목소리로 수렴 안 했나 — 라코닉이 쓸쓸/서늘/분노로 '실제로' 달라졌나.
- 클리셰 컷:    §5 금지 목록 위반 → 버림.
- 각도 중복:    같은 angle 스테이지 내 최대 1회. 2회 이상 = 비틀거나 재굴림.
- 행불 밸런스:  스테이지 성격 반영 — 당하는 밤=불운 우세 OK / 반격하는 밤=행운↑.
                + chance 불운=ordeal(전투). 전투 과부하 점검 (단 chance는 위장·버림 가능).
- scene 정합:   카드가 그 beat의 스냅샷인가.
- 2장 조합:     battle+event / battle+chance / event+chance — 어느 둘이 펼쳐져도 그 장면으로 이어지나.
- 캐논:        페르소나 금지(§1) 위반·`world/` 모순 없나 (메타지식 등).
# 통과 못 하면 버린다 = 정상 작동. 출력 말고 씨앗(이 문서·풀)을 고친다 (style_canon §4).
```

## 4. 정제 — desc / quote / art_hook 분업 (★ 그림과 한 쌍으로 나온다)

```yaml
art_hook: 그 스냅샷이 그릴 한 컷 = 시각 100% 전담. (일러스트 입력. 실제 그림은 작가 영역)
desc:     그림 밖 사실만 — 의미·시간·안 보이는 것. art_hook에 보이는 건 desc에서 뺀다.
          객관·무인칭. 동작 중계(캡션화) 금지.
quote:    페르소나 목소리(§1). 짧게(1~2문장). 상황 대사가 아니라 '그 사람이 하는 말/짓'.
# 길이: desc·quote 1~2문장 OK. 한 문장에 다 우겨넣어 빡빡하게 말고 2문장으로 풀어도 된다(장황은 X).
# 맛 적용(§2 3층): 시선 거리 → desc 카메라 위치(한복판/물러서/멀리). 정서·무게 → quote의 속·초점.
#   같은 사건도 맛이 desc·quote를 가른다. 페르소나(§1)는 유지 — 맛은 그 안에서 갈린다.
# 깊이 = 셋이 서로·그림과 공명하는 데서 나온다.
# 한 끗(좋은 비유·여백)은 여전히 손/판단의 몫 — 난수는 좋은 '재료'를 줄 뿐. 검수가 거기를 본다.
```
