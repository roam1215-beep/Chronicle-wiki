## ① 한 줄 요약

Stage 씬은 "카드를 뒤집고, 분기를 고르고, 전투에 들어가는" 화면. 턴 1~4 카드 뒤집기 + 턴 5 운명 전투까지 하나의 씬에서 진행.

### 메인 레이아웃

```
┌─────────────────────────────────────────┐
│ [A] 운명 바                              │
├─────────────────────────────────────────┤
│ [B] 상태 바                              │
├─────────────────────────────────────────┤
│                                         │
│                                         │

│                                         │
│                                         │
├─────────────────────────────────────────┤
│ [D] 부대 바                              │
├─────────────────────────────────────────┤
│ [E] 겪은 카드 / 남은 카드                 │
```

### [A] 운명 바 — 상단 고정

| 요소 | 내용 |
|------|------|
| **운명 텍스트** | "★ 운명: [조건]" 상시 표시. 예: "★ 운명: 다리를 확보하라" |
| **터치** | 터치 시 운명 상세 팝업 (적 구성 힌트, 조건 설명) |
| **비주얼** | 금색 테두리. 다른 UI와 시각적 분리 |

### [B] 상태 바

| 요소 | 내용 |
|------|------|
| **턴 표시** | "턴 1/5", "턴 2/5" … "턴 5/5" |
| **낮/밤** | ☀️ 낮 / 🌙 밤 아이콘 + 텍스트 |
| **버프 슬롯** | 현재 보유 버프 1개 표시. 없으면 빈 슬롯 |
| **날씨** | 날씨 아이콘 (맑음/안개/비/눈). 재설계 전까지 맑음 고정 |

### [C] 카드 영역 — 화면 중앙

| 상태 | 표시 |
|------|------|
| **뒤집기 전** | 카드 뒷면 1장. 화면 중앙. "터치하여 뒤집기" 안내 |
| **뒤집기 중** | 길게 누르면 카드가 아래에서 들림. 70% 넘으면 완전 뒤집힘 |
| **뒤집힌 후** | 카드 앞면 전체 표시. 상황 서술 + 분기 선택지 |
| **분기 선택 후** | 선택된 분기 강조 → 효과 적용 연출 → 카드가 겪은 카드로 이동 |
| **턴 5** | 카드 없음. 운명 바가 펼쳐지며 "운명 전투 시작" 연출 |

### [D] 부대 바 — 하단

| 요소 | 내용 |
|------|------|
| **유닛 표시** | 좌→우: 테오도라 / Nameless 1 / Nameless 2 |
| **표시 내용** | 미니 카드: 이름 + 면 구성 아이콘 (⚔🛡✕★) + 부상 상태 |
| **터치** | 유닛 터치 → 상세 팝업 (전체 면, 패시브, 부상 상태) |
| **실시간 반영** | 분기 효과(합류/부상/사망)가 즉시 부대 바에 반영 |

### [E] 겪은 카드 / 남은 카드 — 최하단

| 요소 | 내용 |
|------|------|
| **겪은 카드** | 왼쪽. 앞면 미니 썸네일 나열. 터치→다시 열람 |
| **남은 카드** | 오른쪽. 뒷면 아이콘 + "×5" 숫자. 터치 불가 |

## ③ 턴 흐름 (상세)

### 턴 시작

```
[낮/밤 전환 오버레이]
   ↓ 0.8초
[상태 바 갱신: 턴 N, ☀️/🌙]
   ↓
[카드 뒷면 등장 — 중앙에 슬라이드 인]
   ↓
[대기: 플레이어 입력]
```

### 카드 뒤집기

```
[플레이어: 카드 길게 누르기]
   ↓ 누르는 동안 카드 하단부터 들림 (0~70%)
[70% 초과 시]
   ↓ 자동 완전 뒤집기 (되돌릴 수 없음)
[카드 앞면 공개]
   ↓
[사건 카드] → 분기 선택 단계로
[우연 카드] → 즉시 발동 → 효과 적용
```

> **스페이스바 / 더블탭:** 즉시 뒤집기 (스킵)

### 분기 선택 (사건 카드)

```
[카드 앞면: 상황 서술 + 분기 A/B 표시]
   ↓
[플레이어: 분기 터치]
   ↓ 선택한 분기 하이라이트
[확인 팝업: "A. 기습한다 — 선제 1라운드"]
   ↓ [확인] / [취소]
[확인]
   ↓
[효과 적용 연출]
   ↓
[전투 카드?] → 전투 씬 전환
[비전투 카드?] → 효과 적용 → 카드 겪은 카드로 이동 → 다음 턴
```

### 우연 카드 (분기 없음)

```
[카드 앞면: 상황 서술 + "즉시 발동" 표시]
   ↓ 1.5초 후 자동 적용
[효과 적용 연출]
   ↓
[전투형 우연?] → 전투 씬 전환
[비전투형 우연?] → 효과 적용 → 카드 겪은 카드로 이동 → 다음 턴
```

```

   ↓
[전투 결과 요약 오버레이: 사상자, 부상, 생존]
   ↓ 터치로 닫기
[부대 바 갱신]
   ↓
[카드 겪은 카드로 이동]
   ↓
[다음 턴 시작]
```

### 턴 5 — 운명

```

   ↓
[운명 바 확대 연출: 화면 중앙으로 펼쳐짐]
   ↓
["운명 전투 시작" 텍스트]
   ↓ 1.5초 후 자동 전환
```

```
[운명 전투 종료]
   ↓

   ├─ 달성 → "운명 달성" 연출 → Stage 결산
```

## ⑧ 설계 근거

**Q. 왜 분기 선택에 확인 팝업이 있나?**
편성의 [확정]과 같은 원칙. 되돌릴 수 없는 선택이니까 실수 방지. "닥친 상황에 적응"이 핵심 경험이지만, 실수로 잘못 터치하는 건 "적응"이 아니라 "사고".

**Q. 왜 카드 들추기에 70% 임계값이 있나?**
들추다 마는 행위 = 망설임 표현. 70% 넘으면 자동으로 넘어감 = "보기 시작하면 되돌릴 수 없다". 긴장감과 몰입. 50%면 너무 빨리 잠기고, 90%면 조작감이 답답해짐. 프로토타입에서 조정.

**Q. 왜 Stage 간 결산 화면이 있나?**
쉬는 틈. Stage 3개를 연속으로 몰아치면 피로. 결산이 "이번 스테이지는 여기까지" 구두점 역할.

**Q. 턴 5가 항상 낮인 이유?**
턴 1=낮, 2=밤, 3=낮, 4=밤, 5=낮. 운명 전투(결전)가 항상 낮 = 선제 페이즈 있음 = 궁병 활용 가능 = 전력을 다 쓸 수 있는 마지막 전투. 밤에 결전하면 정보 없이 최종전 → 너무 가혹.

**Q. 게임오버 텍스트가 왜 "쓰여지지 않았다"인가?**
사서 프레임. 실패한 이야기는 역사에 기록되지 않는다. "Game Over" 대신 세계관 안에서의 실패 표현.

**Q. 운명 실패인데 테오도라가 살아있어도 Order 실패인 이유?**
운명 = 작전 목표. 목표 달성 못하면 기록할 이야기가 없다. 테오도라가 살았다고 성공이 아님. "다리를 확보하라"는 운명을 실패하면, 서자 기사가 살아 돌아왔을 뿐 역사에 남을 건 없다.
