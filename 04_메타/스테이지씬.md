## ① 한 줄 요약

Stage 씬은 "카드를 뒤집고, 분기를 고르고, 전투에 들어가는" 화면. 이벤트 카드 5장을 순차 뒤집고, 마지막 6번째 카드인 운명 카드로 Stage가 끝난다.

| 요소 | 내용 |

| **버프 슬롯** | 현재 보유 버프 1개 표시. 없으면 빈 슬롯 |

### [C] 카드 영역 — 화면 중앙

| 상태 | 표시 |
|------|------|
| **뒤집기 전** | 이벤트 카드 뒷면 1장 (공통 디자인). 또는 운명 카드 뒷면 (별도 디자인) |
| **뒤집기 중** | 길게 누르면 카드가 아래에서 들림. 70% 넘으면 완전 뒤집힘 |
| **뒤집힌 후** | 카드 앞면 전체 표시. 상황 서술 + 분기 선택지 |
| **분기 선택 후** | 선택된 분기 강조 → 효과 적용 연출 → 카드가 겪은 카드로 이동 |
| **6번째 카드 (운명)** | 운명 카드 뒷면 등장 (이벤트와 다른 디자인) → 뒤집기 → 운명 전투 시작 |

### [D] 부대 바 — 하단

| 요소 | 내용 |
|------|------|
| **유닛 표시** | 좌→우: 테오도라 / Nameless 1 / Nameless 2 |
| **표시 내용** | 풀 카드 표시 (미니 카드 폐기): 이름 + 면 구성 + 부상 상태 |
| **터치** | 유닛 터치 → 상세 팝업 (전체 면, 패시브, 부상 상태) |
| **실시간 반영** | 분기 효과(합류/부상/사망)가 즉시 부대 바에 반영 |

### [E] 겪은 카드 / 남은 카드 — 최하단

| 요소 | 내용 |
|------|------|
| **겪은 카드** | 왼쪽. 축소 썸네일 나열 (미니 카드 폐기). 터치→다시 열람 |
| **남은 카드** | 오른쪽. 뒷면 아이콘 + 숫자. 운명 카드가 남았으면 별도 표시 |

## ③ 카드 흐름 (상세)

### 카드 순서

```
카드 1 (이벤트) → 카드 2 (이벤트) → 카드 3 (이벤트)
  → 카드 4 (이벤트) → 카드 5 (이벤트) → 카드 6 (운명)
```

- 이벤트 5장은 셔플 순서대로 뒤집힘
- 운명 카드는 항상 마지막 (6번째)
- 전투 발생 빈도: 이벤트 카드 중 50% (전투 사건 2장 + 운명 1장). 우연 카드는 비전투 고정
- 전투 연속 방지: 셔플 결과에서 전투 사건이 연속 배치되면 리셔플. 전투 사이에 최소 1장 비전투/우연 보장

### 카드 뒤집기

```
[카드 뒷면 등장 — 중앙에 슬라이드 인]
   ↓
[대기: 플레이어 입력]
   ↓
[플레이어: 카드 길게 누르기]
   ↓ 누르는 동안 카드 하단부터 들림 (0~70%)
[70% 초과 시]
   ↓ 자동 완전 뒤집기 (되돌릴 수 없음)
[카드 앞면 공개]
   ↓
[사건 카드] → 분기 선택 단계로
[우연 카드] → 즉시 발동 → 효과 적용
```

> **스페이스바 / 더블탭:** 즉시 뒤집기 (스킵)

### 분기 선택 (사건 카드)

```
[카드 앞면: 상황 서술 + 분기 A/B 표시]
   ↓
[플레이어: 분기 터치]
   ↓ 선택한 분기 하이라이트
[확인 팝업: "A. 기습한다 — 선제 1라운드"]
   ↓ [확인] / [취소]
[확인]
   ↓
[효과 적용 연출]
   ↓
[전투 카드?] → 전투 씬 전환
[비전투 카드?] → 효과 적용 → 카드 겪은 카드로 이동 → 다음 카드
```

### 6번째 카드 — 운명

```
[운명 카드 뒷면 등장 (이벤트와 다른 디자인 — 금색 테두리)]
   ↓
[플레이어: 뒤집기]
   ↓
[운명 카드 앞면 공개 — 운명 전투 조건 표시]
   ↓
[운명 전투 자동 진입]
   ↓
[전투 종료 → 운명 판정]
```

### Stage 종료 — 운명 판정

```
[운명 전투 종료]
   ↓
[운명 판정]
   ├─ 달성 → 다음 Stage or Chapter 전환 or Order 완료
   └─ 미달성
       ├─ Stage 홀수(1,3,5): 패널티 부여 (Chapter 내 지속) → 다음 Stage 진행
       └─ Stage 짝수(2,4,6): Order 패배
           └─ "그 이야기는 쓰여지지 않았다." → 로비 복귀 (미기록)
```

## ⑨ 설계 근거

**Q. 왜 운명이 항상 마지막 카드인가?**
운명 = 이 Stage의 목적. 이벤트 5장은 운명 전투를 위한 준비. 마지막에 온다는 것을 알기에 역산해서 준비하는 전략이 생긴다.

**Q. 왜 운명 카드 뒷면이 이벤트와 다른가?**
플레이어가 "다음이 운명이다"를 알아야 한다. 뒷면이 같으면 운명이 언제 올지 모르고, 다르면 다가오는 운명을 의식하며 준비한다.

**Q. 왜 Stage 간 결산이 없는가?**
나이트 오브 풀문의 페이즈 시프트처럼. 책장만 넘어가면 충분. 결산 화면이 끼면 흐름이 끊긴다.

**Q. 왜 패널티/패배가 나뉘는가?**
매 Stage 운명 미달성이 즉시 패배면 너무 가혹. 홀수 Stage에서는 패널티만 주고 기회를 더 준다. 짝수 Stage(Chapter 마지막)에서 미달성하면 패배. 3번의 체크포인트에서 성공해야 Order를 완수한다.

**Q. 왜 Chapter 전환 시 부상이 회복되는가?**
Chapter = 새로운 작전의 시작. 부상이 Chapter를 넘어 누적되면 후반 Chapter가 너무 불리. 깨끗한 상태에서 새 작전을 시작하되, 사망한 유닛은 돌아오지 않는다.

**Q. 게임오버 텍스트가 왜 "쓰여지지 않았다"인가?**
사서 프레임. 실패한 이야기는 역사에 기록되지 않는다. "Game Over" 대신 세계관 안에서의 실패 표현.
