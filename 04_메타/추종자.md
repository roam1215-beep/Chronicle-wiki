# META-FOLLOWER: 추종자 시스템

> 상태: 설계중 · 의존: @COMBAT-STRUCT-001, @COMBAT-UNIT-CARD, @TAG-RULE-001

## 정의

추종자 = 비전투 인물. 주사위 없음. 전투 불참. 런 전체 지속. NL/ND 2등급, 25종. Slay the Spire 유물 격.

## 규칙

### 공통

```yaml
follower:
  type: 비전투 인물
  dice: 없음
  combat_participation: 없음
  grades: [NL, ND]
  total_count: 25  # NL 16 + ND 9
  capacity: 10
  scope: 런 전체
  acquisition:
    - 운명 전투 승리 → 2명 제시, 1명 선택
    - 우연-이벤트 [운명적 이끌림] → 특별 풀 (극히 드묾)
  loss:
    - [결별] 태그
    - 상한 초과 시 해고 (유저 선택)
  pool_removal: 획득 시 영구 제거
  pool_return: [결별]/해고 시 풀 복귀 (예외 없음)
  named_protection: 없음 (전투 긴장 유지 — 의도)
```

### 지속 유형

```yaml
duration_types:
  지속: 보유하는 한 매 전투/태그 발동마다 효과
  즉발: 획득 순간 1회 효과. 이후 슬롯만 차지
```

### 25종 (ND 9종)

```yaml
nd_followers:
  - id: 대장장이
    effect: 획득 즉시 [연마] 2회 발동
    duration: 즉발

  - id: 전령
    effect: 획득 즉시 [사기진작] 2회 발동
    duration: 즉발

  - id: 기마병
    effect: 획득 즉시 기병 1기 합류
    duration: 즉발

  - id: 방랑기사
    effect: 획득 즉시 방랑기사 풀(10명)에서 Named 1기 + 특성 풀에서 랜덤 배정
    duration: 즉발

  - id: 상인
    effect: 운명 전투 승리 시 Nameless(민/보/창/궁) 1기 플레이어 선택 획득
    duration: 지속

  - id: 장창병
    effect: 전과(스텝7)에서 보유 창병 수만큼 적 사상자 타겟 선택 (반격과 동시 선언)
    duration: 지속
    requires: 창병 보유
    flag: TODO(엔진) 반격 패시브 정합 후

  - id: 중보병
    effect: 방진으로 전환된 🛡 중 상쇄 후 잔여분 → 다음 라운드 이월
    duration: 지속
    requires: 보병 보유
    flag: TODO(엔진) "방진 패시브 + 결사 부활 정합 후. 옛 스펙은 산개/밀집/결사 의존이었음"

  - id: 사제
    effect: Named/기사 유닛 전원 ✕1 → ★ 영구 변환 (구성면 변경)
    duration: 지속

  - id: 음유시인
    effect: 아군 Named의 ★ 체이닝 발동 시마다 ⚔+1 추가
    duration: 지속
    flag: TODO(엔진) 옛 "수비 대형/[난전] 시 불발" 중 수비 대형은 폐기. [난전] 영향만 잔존
```

### 구성면 체계

```yaml
face_layers:
  initial: 병종/Named 기본 (스키마 정의)
  current: initial + 영구 변환 누적 (교관/종자/사제/[연마]/[사기진작] 등)
  injury: current 유효면(⚔/🛡/★) 1개 → ✕. 전투 종료 시 current 복원
  result: 매 라운드 굴림 결과 (라운드마다 리셋)
deprecated:
  - 밀집(뒷면) 시 구성면 변환 무시  # 대형 폐기
note: 모든 굴림은 current_face 기준. 산개/밀집 분기 없음
```

### 변환 대상 분리

```yaml
conversion_split:
  교관: Nameless 병종 대상
  종자: Named/기사 대상
  사제: Named/기사 대상
  교관 vs 종자/사제: 대상 분리. 경쟁 없음
  multi_conversion:
    on_same_unit: 순서대로 누적. 나중 변환이 덮어씀
  배신_target_inheritance: 강화된 면을 적이 사용 (의도)
  배신_follower_effect: 적에게 이전 안 됨 (장궁병/장창병/중보병 등)
  우세_addon: 테오도라 부대 아님 → 교관 적용 안 받음
  회유_addon: 아군 합류 NL → 교관 적용 받음
```

```yaml
  - { combo: 종자 + 사제 + 음유시인, effect: 'Named 특화 극대화 (3슬롯 시너지)' }
```

### [결별]/해고 처리

```yaml
on_loss:
  면_변환_계열: 이미 변환된 면 유지. 이후 합류분부터 미적용. 풀 복귀
  지속_효과_계열: 즉시 효과 꺼짐. 풀 복귀
  즉발_계열: 이미 발동 완료. 영향 없음. 풀 복귀
```
