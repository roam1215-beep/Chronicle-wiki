## ① 한 줄 요약

추종자 = 비전투 인물. 주사위 없음. 전투 불참. 런 전체 지속. NL/ND 2등급, 24종. 슬레이 더 스파이어의 유물 격.

## ⑤ 구성면 체계

| 용어 | 정의 |
|------|------|
| **초기면** | 주사위별 최초값. 병종에 의해 결정 |
| **현재면** | 초기면 + 교관/종자/사제/연마/단조 등 영구 변환 누적 |
| **부상** | 현재면의 유효면(⚔/🛡/★) 1개 → ✕. **전투 종료 시 현재면으로 복원** |
| **전투 결과면** | 매 라운드 굴림 결과. 라운드마다 리셋 |

> **교관/종자/사제/[연마]/[사기진작] 등은 전투 결과면이 아니라 구성면(현재면)을 영구 변경하는 것.** 전투 중 결과와 혼동 금지.

### 구성면 변환과 부상의 관계

- 종자가 Named의 ✕→⚔로 변환 → 현재면이 ⚔
- 전투 중 부상으로 해당 ⚔가 ✕로 변경
- 전투 종료 시 현재면(⚔)으로 복원

### 구성면 변환 대상 분리

- 교관 계통: **Nameless 병종 대상.** Named/기사 대상 아님
- 종자: **Named/기사 대상.** Nameless 대상 아님
- 사제: **Named/기사 대상.** Nameless 대상 아님
- 교관과 종자/사제는 대상이 분리되어 있어 **경쟁 없음**
- 같은 유닛에 복수 변환(교관 + [사기진작] 등) 적용 시: **순서대로 누적.** 나중 변환이 현재면을 덮어씀
- **밀집(뒷면) 시 구성면 변환 무시.** 교관/종자/사제/연마/사기진작 등 모든 변환이 미적용. 병종 초기면 기준으로 일제 굴림. → [COMBAT-STRUCT-001 전투 구조](../../02_전투/구조/전투구조.md) 대형 선택 참조

### 교관 효과 적용 원칙

- 교관 효과는 **유닛 개체가 아니라 교관 보유 여부에 따른 상시 효과**
- 교관 보유 중 해당 병종 전멸 → 교관 슬롯 유지. 이후 재획득 시 즉시 적용
- [우세]로 추가된 아군 유닛: **테오도라 부대가 아니므로 교관 적용 안 받음**
- [회유]로 전환된 적 NL: 아군 합류 시 교관 효과 적용
- [배신]으로 넘어간 NL: 강화된 면을 적이 사용 (의도된 리스크). 단, 장궁병/장창병/중보병 추종자 효과는 테오도라 부대 기반이므로 **적에게 이전되지 않음**

| **Named 특화** | 종자+사제+견습 대장장이 | ✕→⚔ + ✕→★ + 면 태그 리롤 | Named 항상 산개 |
| **생존 보험** | 감시자+방패병+정찰병 | 이탈/배신 차단 + 선제 방어 + 밤 정보 | 상황 의존 |
| **충원 극대화** | 상인+지원병+패잔병 | 매 막 병종 선택 충원 + 즉발 합류 | 병종 다양 → 밀집 기회 적음 |

> **교관 빌드 vs 밀집:** 교관으로 면을 강화하면 산개(현재면)가 유리. 교관이 없으면 밀집(초기면)과 차이 없음. 부상/약화 런에서는 밀집이 초기면으로 돌아가므로 오히려 유리. → [COMBAT-STRUCT-001 전투 구조](../../02_전투/구조/전투구조.md) 대형 선택 참조

## ⑪ 설계 근거

**Q. 왜 추종자인가?**
정찰, 보급, 훈련 등은 태그(카드 단위)로도 배경(챕터 단위)으로도 표현이 어렵다. 추종자는 기존 메카닉을 수정하는 레이어로, 새 메카닉 추가 없이 표현 폭을 넓힌다.

**Q. 왜 유물이 아닌 인물인가?**
Chronicle의 핵심 문법은 "이름의 유무". 유물은 물건이지만 추종자는 이름 있는 인물이다. Named의 확장이지 새로운 개념이 아니다.

**Q. 왜 교관 계통이 Nameless 전용, 종자/사제가 Named 전용인가?**
대상 분리로 경쟁 없이 병렬 적용. Nameless는 교관이 훈련하고, Named는 종자/사제가 보좌하는 서사적 분리.

**Q. 왜 장궁병이 선제 순서를 바꾸는가?**
궁병 빌드의 결정적 차별점. "누구를 쏘는가"에서 "먼저 쏘고 적 궁병을 제거한다"로. 궁병전에서 일방적 우위는 빌드 보상.

**Q. 왜 중보병이 방진 🛡만 이월하고 원래 🛡은 소멸인가?**
보병 패시브(방진)를 더 잘 쓰게 만드는 트윅이지, 보병 전체를 강화하는 게 아님. 패시브 직결.

**Q. 왜 장창병이 반격과 동시 선언인가?**
"창을 내밀면서 누구를 찌를지 정한다." 반격 = 🛡→⚔ 전환, 장창병 = 그 ⚔가 누구를 죽이는가. 하나의 행동.

**Q. 왜 Named 보호 수단이 없는가?**
전투의 핵심 긴장 = 테오도라 피격 가능성. 보호 수단이 있으면 긴장이 소멸. 추종자는 전투를 유리하게 만들지, 사망을 방지하지 않는다.
