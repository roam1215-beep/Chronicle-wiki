# META-FOLLOWER: 추종자 시스템 (Follower System)

> **상태:** 🔄 설계중 · **버전:** 0.4 · **ID:** META-FOLLOWER · **수정일:** 2026-03-08

---

## ① 한 줄 요약

추종자 = 비전투 인물. 주사위 없음. 전투 불참. 런 전체 지속. Nameless/Named 2등급, 14종. 슬레이 더 스파이어의 유물 격.

---

## ② 규칙 정의

| 항목 | 내용 |
|------|------|
| 정의 | 비전투 인물. 주사위 없음. 전투에 참여하지 않음 |
| 등급 | Nameless / Named. 같은 종 내에서 등급 차이 존재 |
| 등급 차이 | NL: 리롤/제한적 효과 / ND: 결과 선택/강한 효과 |
| 승급 | 없음. NL/ND는 별개 2종으로 존재 |
| 사상자 풀 | 미포함. 전투에서 죽지 않음 |
| 보유 상한 | 10명 |
| 지속 범위 | 런 전체 |
| 획득 경로 | 운명 전투 승리 → [이끌림] (2명 제시, 1명 선택) |
| 특별 획득 | 우연-이벤트 [운명적 이끌림] (특별 풀. 극히 드묾) |
| 상실 경로 | 우연-이벤트 [결별] (유일한 경로). 전투 중 피격 차단 후 제거(순교자) |
| 상한 초과 처리 | 상한 10명 초과 시 기존 1명 해고 + 신규 1명 영입. 획득 포기 불가 |

## ③ 등급별 공통 원칙

| 원칙 | 내용 |
|------|------|
| NL 추종자 | 역할명이 곧 이름. 효과 범위 넓되 통제 약함 (리롤) |
| ND 추종자 | 고유명 보유. 효과 좁되 통제 강함 (결과 선택) |
| 이름의 문법 | Chronicle 핵심 문법 "이름의 유무 = 등급" 추종자에도 적용 |

---

## ④ 보유 제한 규칙

| 유형 | 제한 | 풀 제거 |
|------|------|--------|
| NL 단일 종 (대장장이/교관/방패병/순교자/용병대장/민병대장) | 최대 1명 | 보유 시 풀에서 제거 |
| ND 전문화 종 (대장장이/교관/참모) | 전문화 종별 1명 | 보유 시 풀에서 제거 |
| ND 단일 종 (부관/사제/방패병/순교자/경비대장/석궁사수/중장보병/파이크병/종자) | 최대 1명 | 보유 시 풀에서 제거 |
| ND 용병대장 | 최대 1명 | 보유 시 풀에서 제거 |

> **NL+ND 동시 보유:** 같은 종의 NL/ND는 별개 계통. 동시 보유 가능 (방패병, 순교자, 용병대장).
> **병종 전문 추종자 풀 등장 조건:** 해당 병종 보유 시에만 풀 등장. 병종을 전부 잃어도 슬롯 유지.
> **병종 전문 추종자 [결별] 시:** [결별] 이전에 변환된 병종의 면은 유지. [결별] 이후 합류하는 병종부터 효과 미적용 (기본 면으로 합류).
> **종자 [결별] 시:** 이미 변환된 테오도라 ★ 면 유지. 종자는 즉발 효과이므로 결별 후에도 영구 적용 상태 유지.
> **종자:** 조건 없이 항상 풀 등장. 1회 획득 후 풀 제거.

## ⑤ 추종자 종류

### 대장장이

| 항목 | 내용 |
|------|------|
| 역할 | Named 유닛 면 변환 태그 개입 |
| NL 효과 | Named 면 태그([연마]/[열화]/[단조]) 발동 시 결과 1회 리롤 |
| ND 전문화 | 연마 / 열화 / 단조 3종 |
| ND 효과 | 해당 태그 발동 시 결과 선택 ([단조]: 열화/연마 양 단계 전부 선택 가능) |
| 보유 제한 | NL 최대 1명, ND 종별 1명 |

### 교관

| 항목 | 내용 |
|------|------|
| 역할 | Nameless 유닛 면 변환 태그 개입 |
| NL 효과 | Nameless 면 태그([사기진작]/[사기저하]/[단련]) 발동 시 결과 1회 리롤 |
| ND 전문화 | 사기진작 / 사기저하 / 단련 3종 |
| ND 효과 | 해당 태그 발동 시 결과 선택 ([단련]: 사기저하/사기진작 양 단계 전부 선택 가능) |
| 보유 제한 | NL 최대 1명, ND 종별 1명 |

### 참모

| 항목 | 내용 |
|------|------|
| 등급 | ND만. NL 없음 |
| 역할 | 전투 진입 시 카드락 자동 적용 / 라운드 중 면 변환 |
| 전문화 | 칼 / 방패 / 실패 3종 |
| 칼 참모 효과 | 전투 진입 시 아군 주사위 1개 ⚔ 자동 카드락 |
| 방패 참모 효과 | 전투 진입 시 아군 주사위 1개 🛡 자동 카드락 |
| 실패 참모 효과 | 매 라운드 아군 전체 ✕ 결과 1개 → ⚔/🛡 랜덤(50:50). 자동. ✕ 없으면 불발 |
| 보유 제한 | 종별 1명. 칼/방패/실패 동시 보유 가능 |

> **설계 의도:** 참모 3종 풀세팅이 의도된 강력한 빌드. 실패 참모는 부정적 이름과 달리 ✕ 변환이 핵심 가치로 매우 유용.

### 부관

| 항목 | 내용 |
|------|------|
| 등급 | ND만. NL 없음 |
| 역할 | 지휘(리롤) 횟수 증가 |
| 효과 | 지휘 횟수 +1 (기본 1회 → 2회) |
| 보유 제한 | 최대 1명 |

### 사제

| 항목 | 내용 |
|------|------|
| 등급 | ND만. NL 없음 |
| 역할 | ★ 카드락 |
| 효과 | 전투 진입 시 Named/기사 주사위 1개 ★ 자동 카드락 |
| 대상 제한 | Named/기사만. Nameless 대상 불가 |
| 보유 제한 | 최대 1명 |

> **설계 의도:** ★ 카드락 = 확정 ⚔ + 재굴림 보장. 추종자 중 최상위 효과.

### 방패병

| 항목 | 내용 |
|------|------|
| 역할 | 선제 페이즈 방어 보강 |
| NL 효과 | 선제 🛡 +1 |
| ND 효과 | 선제 🛡 +2 |
| 돌파 시 | 전투 중 선제 방어가 돌파되어도 재보충 없음 |
| 밤 전투 | 선제 페이즈 스킵으로 효과 없음 |
| NL+ND 동시 보유 | 가능. 합산 🛡 +3 |
| 보유 제한 | NL 최대 1명, ND 최대 1명 |

### 순교자

| 항목 | 내용 |
|------|------|
| 역할 | 전투 중 피격 차단 후 제거 |
| NL 효과 | 전투 중 Nameless 피격 1기 차단 → 순교자 제거. 동시 복수 피격 시 1기만 차단 |
| ND 효과 | 전투 중 Named 2회째 피격(사망) 차단 → 순교자 제거. 부상은 차단 불가 |
| 적용 범위 | 전투 중만. 전투 외 제거는 차단 불가 |
| 보유 제한 | NL 최대 1명, ND 최대 1명 |

### 용병대장

| 항목 | 내용 |
|------|------|
| 역할 | 획득 즉시 유닛 합류 |
| NL 효과 | 획득 즉시 민병 2기 합류 |
| ND 효과 | 획득 즉시 기병 1기 합류 |
| 지속 효과 | 없음. 획득 시 1회성 즉발 효과 |
| 보유 제한 | NL 최대 1명, ND 최대 1명. 보유 시 풀에서 제거 |

> **설계 의도:** 기병은 편성 불가 병종. 용병대장 ND가 사실상 안정적 기병 획득의 유일한 경로.

### 민병대장

| 항목 | 내용 |
|------|------|
| 등급 | NL만. ND 없음 |
| 역할 | 민병 전원 공격 면 강화 |
| 효과 | 민병 전원 ✕ 1개 → ⚔ 영구 변환. 이후 합류하는 민병도 즉시 적용 |
| 풀 등장 조건 | 민병 보유 시에만 풀 등장 |
| 보유 제한 | 최대 1명. 민병 전부 잃어도 슬롯 유지 |

### 경비대장

| 항목 | 내용 |
|------|------|
| 등급 | ND만. NL 없음 |
| 역할 | 민병 전원 방어 면 강화 |
| 효과 | 민병 전원 ✕ 1개 → 🛡 영구 변환. 이후 합류하는 민병도 즉시 적용 |
| 풀 등장 조건 | 민병 보유 시에만 풀 등장 |
| 보유 제한 | 최대 1명. 민병 전부 잃어도 슬롯 유지 |

> **민병 빌드:** 민병대장(NL)+경비대장(ND) 동시 보유 시 민병 전원 ✕ 2개 변환(⚔+🛡). 패시브 없는 약소 병종을 전문화로 끌어올리는 컨셉 빌드.

```
기본 민병:              ⚔⚔⚔🛡🛡✕✕✕✕✕  (⚔30% 🛡20% ✕50%)
민병대장 적용:          ⚔⚔⚔⚔🛡🛡✕✕✕✕  (⚔40% 🛡20% ✕40%)
경비대장 적용:          ⚔⚔⚔🛡🛡🛡✕✕✕✕  (⚔30% 🛡30% ✕40%)
민병대장+경비대장:      ⚔⚔⚔⚔🛡🛡🛡✕✕✕  (⚔40% 🛡30% ✕30%)
```

### 중장보병

| 항목 | 내용 |

| 효과 | 보병 전원 ✕ 1개 → 🛡 영구 변환. 이후 합류하는 보병도 즉시 적용 |
| 풀 등장 조건 | 보병 보유 시에만 풀 등장 |

|------|-----------|------|
| 테오도라 특화 | 종자 + 사제 + 참모(칼) | ★ 체이닝 극대화 |
| 민병 컨셉 | 용병대장(NL) + 민병대장 + 경비대장 | 민병 ✕ 2개 변환으로 약소 병종 끌어올리기 |
| 궁병 집중 | 석궁사수 + 방패병(NL/ND) | 선제 ⚔ 극대화 + 선제 방어 |
| 보병 방어 | 중장보병 + 참모(방패) + 순교자(NL) | 방진 강화 + 피격 차단 |
| 창병 공격 | 파이크병 + 참모(칼) | 반격 후 ⚔ 극대화 |
| 생존 보험 | 순교자(NL/ND) + 방패병(NL/ND) | 피격 차단 + 선제 방어 |

## ⑧ 설계 근거

**Q. 왜 추종자인가?**
정찰, 보급, 훈련 등은 태그(카드 단위)로도 배경(챕터 단위)으로도 표현이 어렵다. 추종자는 기존 메카닉을 수정하는 제3 레이어로, 새 메카닉 추가 없이 표현 폭을 넓힌다.

**Q. 왜 유물이 아닌 인물인가?**
Chronicle의 핵심 문법은 "이름의 유무". 유물은 물건이지만 추종자는 이름 있는 인물이다. Named의 확장이지 새로운 개념이 아니다.

**Q. 왜 NL/ND가 승급이 아닌 별개 2종인가?**
인물 카드와 동일한 원칙. 이름이 있으면 Named, 없으면 Nameless. 승급이 아니라 처음부터 다른 존재.

**Q. 왜 NL은 리롤, ND는 결과 선택인가?**
"이름의 무게" = 통제 가능성. 등급 차이를 수치가 아닌 통제력의 차이로 표현.

**Q. 왜 병종 전문 추종자가 ✕ 변환인가?**
새 메카닉 없이 면 구성 자체를 강화. 해당 병종 패시브를 더 잘 활용하게 만드는 방향. 병종 집중 빌드에 의미를 부여.

**Q. 왜 민병대장(NL)이 ⚔, 경비대장(ND)이 🛡인가?**
전투 손실 누적 구조에서 🛡가 장기적으로 더 귀하다. ND가 더 가치 있는 효과를 갖는 등급 체계와 일치.

**Q. 왜 병종 전문 추종자가 병종을 잃어도 슬롯에 남는가?**
[결별]만이 추종자 상실 경로. 전투 손실로 추종자를 잃으면 병종 재건 시 즉시 재적용되지 않아 설계가 복잡해진다.
