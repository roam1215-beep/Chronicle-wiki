# META-BATTLE-001: 전투 씬 (Battle Scene)

> **상태:** 🔄 설계중 · **버전:** 0.3 · **ID:** META-BATTLE-001 · **수정일:** 2026-03-02

## ① 한 줄 요약

전투 씬은 7스텝 엔진을 3페이즈로 보여주는 화면. 플레이어가 하는 일은 3가지뿐: 버프 사용, 리롤, 방진/반격. 나머지는 엔진이 연출한다.

## ② 화면 구성

### 메인 레이아웃

```
┌─────────────────────────────────────────┐
│ [A] 전투 헤더                            │
├─────────────────────────────────────────┤
│                                         │
│ [B] 적 영역                              │
│                                         │
├─────────────────────────────────────────┤
│ [C] 판정 영역 (칼-방패 상쇄)              │
├─────────────────────────────────────────┤
│                                         │
│ [D] 아군 영역                            │
│                                         │
├─────────────────────────────────────────┤
│ [E] 행동 바                              │
└─────────────────────────────────────────┘
```

### [A] 전투 헤더 — 상단 고정

| 요소 | 내용 |
|------|------|
| **페이즈 표시** | 현재 페이즈: "① 선제" / "② 격돌" / "③ 전과" |
| **라운드 표시** | "라운드 N / 8" (상한 8. R5부터 결사) |
| **낮/밤** | Stage에서 상속. ☀️ / 🌙 아이콘 |
| **버프 슬롯** | 보유 버프 1개 표시. 없으면 빈 슬롯 |
| **운명 전투** | 운명 전투일 경우 "★ 운명 전투" 금색 배지 |

### [B] 적 영역 — 상단

```
┌─────────────────────────────────────────┐
│  적 부대                                 │
│                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │보초 1 │  │보초 2 │  │      │          │
│  │ ⚔⚔🛡 │  │ ⚔⚔🛡 │  │      │          │
│  │ ✕✕✕  │  │ ✕✕✕  │  │      │          │
│  └──────┘  └──────┘  └──────┘          │
│                                         │
│  주사위 결과:                             │
│  [⚔] [🛡] [✕] [?] [?] [?]    ← 밤이면 ? │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **적 유닛 카드** | 풀 카드 표시 (미니 카드 폐기). 사망 시 찢어짐 연출 후 제거 |
| **적 주사위 결과** | 낮: 면 결과 공개. 밤: "?" 처리 (스텝 7 최종 피해만 공개) |
| **적 정보 수준** | 유닛 종류/수는 전투 시작 시 공개. 면 구성은 카드 터치로 확인 |

### [C] 판정 영역 — 중앙

```
┌─────────────────────────────────────────┐
│              ⚔⚔⚔ vs 🛡🛡              │
│                                         │
│           피해: 1  →  적에게 적용         │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **상쇄 연출** | 아군 ⚔ vs 적 🛡, 적 ⚔ vs 아군 🛡 — 쌍으로 소멸 |
| **잔여 피해** | 상쇄 후 남은 ⚔ = 피해. 숫자로 표시 |
| **표시 타이밍** | 스텝 7 전과 시에만 활성. 그 전에는 비어있음 |
| **밤** | 적 결과가 "?"이므로 상쇄 과정 생략 → 최종 피해만 표시 |

### [D] 아군 영역 — 하단

```
┌─────────────────────────────────────────┐
│  아군 부대                                │
│                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │테오도라│  │ 보병  │  │ 궁병  │          │
│  │⚔🛡🛡★│  │⚔⚔🛡🛡│  │⚔⚔⚔⚔│          │
│  │ ✕ ✕  │  │ ✕ ✕  │  │ ✕ ✕  │          │
│  └──────┘  └──────┘  └──────┘          │
│                                         │
│  주사위 결과:                             │
│  [⚔] [🛡] [🛡] [★→⚔→⚔] [✕] [✕]       │
│   ↑ 터치로 리롤/전환 대상 선택             │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **아군 유닛 카드** | 풀 카드 표시 (미니 카드 폐기). 부상 표시 (~~🛡~~→✕) |
| **아군 주사위 결과** | 항상 공개. 각 주사위는 소속 유닛 색상으로 구분 |

| **★ 체이닝** | ★ 결과 시 체이닝 연출: ⚔ 확정 → 재굴림 → 결과 (연쇄) |
| **유닛 터치** | 유닛 카드 터치 → 상세 팝업 (전체 면, 패시브, 부상) |

### [E] 행동 바 — 최하단

```
┌─────────────────────────────────────────┐
│  [버프 사용]   [리롤 1/1]   [전환]   [확정]            │
└─────────────────────────────────────────┘
```

| 버튼 | 스텝 | 조건 | 동작 |
|------|------|------|------|
| **[버프 사용]** | 2 | 버프 보유 시 활성 | 버프 효과 적용. 사용 후 소멸 |
| **[리롤 N/N]** | 4 | 리롤 잔여 횟수 > 0 | 주사위 1개 선택 → 재굴림 |
| **[전환]** | 6 | 전환 가능 유닛 존재 시 | 유닛 결과 일방향 전환 |
| **[확정]** | — | 항상 | 현재 스텝 완료 → 다음 스텝 진행 |

> **비활성 버튼:** 조건 미충족 시 회색 처리 + 터치 불가. 해당 스텝 자동 스킵.

#### 스텝 2: 버프 사용 (수동)

```
[전투 헤더: "② 격돌 — 버프"]
   ↓
[버프 보유?]

| 버프 | 연출 |

### ③ 전과 (스텝 6→7)

#### 스텝 6: 유닛 전환 (수동)

```
[전투 헤더: "③ 전과 — 전환"]
   ↓
[전환 가능 유닛 존재?]
   ├─ YES → [전환] 버튼 활성
   │         ├─ 터치 → 전환 가능 유닛 하이라이트
   │         │         ├─ 보병: ⚔ → 🛡 (방진 패시브)
   │         └─ 창병: 🛡 → ⚔ (반격 패시브)
   │         └─ 기사: 패시브 의존 (방진이면 ⚔→🛡, 반격이면 🛡→⚔)
   │         ├─ 유닛 터치 → 전환 미리보기 → [적용] / [취소]
   │         └─ [확정] → 전환 안 하고 넘기기
   └─ NO → 자동 스킵 → 스텝 7
```

**전환 미리보기:**

```
┌────────────────────────────────┐
│  보병: ⚔ → 🛡 전환             │
│                                │
│  변경 전: ⚔ ⚔ 🛡 🛡 ✕ ✕      │
│  변경 후: ⚔ 🛡 🛡 🛡 ✕ ✕      │  ← 변경 면 강조
│                                │
│    [취소]          [적용]       │
└────────────────────────────────┘
```

**전환 제외 대상:**
- ★ 면 자체: 전환 불가 (체이닝 결과물은 가능)
- 궁병: 전환 없음
- 민병: 전환 없음
- 기병: 전환 없음 (쇄도는 스텝5에서 별도 처리)
- 기사(쇄도): 전환 없음 (쇄도는 스텝5에서 별도 처리)
- 패시브 미보유 유닛: 전환 불가

#### 스텝 7: 전과 (자동)

```
[전투 헤더: "③ 전과 — 판정"]
   ↓
[판정 영역 [C] 활성]
   ↓
[상쇄 연출: ⚔ vs 🛡 쌍소멸]
   ↓
[잔여 피해 계산]
   ├─ 적에게 피해 → 적 유닛 랜덤 제거 (Nameless 즉사, Named 부상/사망)
   └─ 아군에게 피해 → 아군 유닛 랜덤 피격 (Nameless 즉사, Named 부상/사망)
   ↓

   ├─ Nameless 즉사: 카드 찢어짐 + 퇴장
   ├─ Named 부상: 카드 반파 + 유효면(⚔/🛡/★) 중 랜덤 1개 → ✕
   ├─ Named 사망: 카드 찢어짐 + 퇴장
   └─ 테오도라 사망: 게임오버 전환
   ↓
[전투 종료 확인]
   ├─ 적 전멸 → 승리
   ├─ 아군 전멸 → 패배
   ├─ 테오도라 사망 → 게임오버
   └─ 양측 생존 → 다음 라운드

## ④ 라운드 반복 / 전투 종료

### 라운드 흐름

```
낮/밤은 Stage 턴에서 상속. 전투 내 교대 없음.

R1: ①선제→②격돌→③전과 → [종료?]
R2: ①선제→②격돌→③전과 → [종료?]
R3: ①선제→②격돌→③전과 → [종료?]
R4: ①선제→②격돌→③전과 → [종료?] ← "다음 라운드부터 결사" 경고
R5: ①선제→②격돌→③전과 → [종료?] ← 결사 돌입. 🛡→⚔ 판정
R6: ①선제→②격돌→③전과 → [종료?] ← 결사 계속
R7: ①선제→②격돌→③전과 → [종료?] ← 결사 계속
R8: ①선제→②격돌→③전과 → 상한. 종료 안 되면 패배
```

> **라운드 상한 8.** 결사(R5~)로 대부분 R5~R6에서 끝남. R8은 안전장치.
> **결사 (R5~):** 양측 모든 🛡→⚔ 판정. 방진/반격 무력화. 리롤만 유일한 개입.
> **"턴"은 스테이지 전용 용어.** 전투에서는 "라운드"만 사용.

```
┌─────────────────────────────────────────┐
│                                         │
│              ⚔ 전투 종료 ⚔              │
│                                         │
│           결과: 승리 / 패배              │
│                                         │
│  ┌─ 아군 ──────────────────────┐        │
│  │ 테오도라    생존 (부상 1)     │        │
│  │ 보병        생존              │        │
│  │ 궁병        사망 ☠           │        │
│  └─────────────────────────────┘        │
│                                         │
│  ┌─ 적군 ──────────────────────┐        │
│  │ 보초 1      사망 ☠           │        │
│  │ 보초 2      사망 ☠           │        │
│  └─────────────────────────────┘        │
│                                         │
│           라운드: 3 / 8          │
│                                         │
│              [계속]                      │
└─────────────────────────────────────────┘

| 결과 | 후속 |
|------|------|
| **운명 전투 승리** | [계속] → 추종자 선택 → 장 전환 |
| **일반 전투 패배 (테오도라 생존)** | [계속] → 막 씬 복귀 (부대 손실 반영) |
| **운명 전투 패배** | 게임오버 확정 (v3 확정) |
| **테오도라 사망** | 게임오버 전환 ("그 이야기는 쓰여지지 않았다.") |

## ⑦ 설계 근거

**Q. 왜 행동 바에 모든 버튼이 있는가?**
7스텝이 순차 진행이라 한 번에 1~2개만 활성. 나머지는 회색. 전체 버튼을 보여주면 "다음에 뭘 할 수 있는지" 예측 가능. 버튼이 나타났다 사라지면 인지 부하가 더 높음.

**Q. 왜 전환에 미리보기가 있는가?**
유닛 전환은 일방향이라 되돌릴 수 없음. 편성의 [확정], Stage의 분기 확인과 같은 원칙: 되돌릴 수 없는 행동에는 미리보기 + 확인.

**Q. 왜 수동 스텝에 [확정] 스킵이 있는가?**
모든 수동 행동은 선택이지 의무가 아님. 버프 안 쓰기, 리롤 안 하기, 전환 안 하기 모두 유효한 전략. [확정]으로 "아무것도 안 하고 넘어간다"를 명시적으로 선택.

**Q. 밤 전투에서 상쇄 과정을 왜 안 보여주나?**
적 결과가 "?"이므로 어떤 ⚔가 어떤 🛡와 상쇄되는지 보여줄 수 없음. 최종 피해만 공개 = "맞고 나서야 안다." 밤의 불확실성.

**Q. 판정 영역이 왜 중앙에 있는가?**
적 영역(상단) ↔ 아군 영역(하단) 사이에서 충돌하는 장면. 공간적으로 "부딪히는 곳"이 중앙. 시선이 자연스럽게 모인다.

Named 궁병의 핵심 가치가 "원하는 적을 골라 죽이는 것". 자동 랜덤이면 Named와 Nameless 궁병 차이가 체감 안 됨. 이름이 있으니까 판단한다.
