# META-BATTLE-001: 전투 씬 (Battle Scene)

## ① 한 줄 요약

전투 씬은 7스텝 엔진을 3페이즈로 보여주는 화면. 플레이어가 하는 일은 3가지뿐: 버프 사용, 리롤, 유닛 전환. 나머지는 엔진이 연출한다.

## ② 화면 구성

### 메인 레이아웃

```
┌─────────────────────────────────────────┐
│ [A] 전투 헤더                            │
├─────────────────────────────────────────┤
│                                         │
│ [B] 적 영역                              │
│                                         │
├─────────────────────────────────────────┤
│ [C] 판정 영역 (칼-방패 상쇄)              │
├─────────────────────────────────────────┤
│                                         │
│ [D] 아군 영역                            │
│                                         │
├─────────────────────────────────────────┤
│ [E] 행동 바                              │
└─────────────────────────────────────────┘
```

### [A] 전투 헤더 — 상단 고정

| 요소 | 내용 |
|------|------|
| **페이즈 표시** | 현재 페이즈: "① 선제" / "② 격돌" / "③ 전과" |
| **라운드 표시** | "라운드 1/2" (1턴 = 2라운드) |
| **낮/밤** | Stage에서 상속. ☀️ / 🌙 아이콘 |
| **버프 슬롯** | 보유 버프 1개 표시. 없으면 빈 슬롯 |
| **운명 전투** | 운명 전투일 경우 "★ 운명 전투" 금색 배지 |

### [B] 적 영역 — 상단

```
┌─────────────────────────────────────────┐
│  적 부대                                 │
│                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │보초 1 │  │보초 2 │  │      │          │
│  │ ⚔⚔🛡 │  │ ⚔⚔🛡 │  │      │          │
│  │ ✕✕✕  │  │ ✕✕✕  │  │      │          │
│  └──────┘  └──────┘  └──────┘          │
│                                         │
│  주사위 결과:                             │
│  [⚔] [🛡] [✕] [?] [?] [?]    ← 밤이면 ? │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **적 유닛 카드** | 풀 카드 표시 (미니 카드 폐기). 사망 시 찢어짐 연출 후 제거 |
| **적 주사위 결과** | 낮: 면 결과 공개. 밤: "?" 처리 (스텝 7 최종 피해만 공개) |
| **적 정보 수준** | 유닛 종류/수는 전투 시작 시 공개. 면 구성은 카드 터치로 확인 |

### [C] 판정 영역 — 중앙

```
┌─────────────────────────────────────────┐
│              ⚔⚔⚔ vs 🛡🛡              │
│                                         │
│           피해: 1  →  적에게 적용         │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **상쇄 연출** | 아군 ⚔ vs 적 🛡, 적 ⚔ vs 아군 🛡 — 쌍으로 소멸 |
| **잔여 피해** | 상쇄 후 남은 ⚔ = 피해. 숫자로 표시 |
| **표시 타이밍** | 스텝 7 전과 시에만 활성. 그 전에는 비어있음 |
| **밤** | 적 결과가 "?"이므로 상쇄 과정 생략 → 최종 피해만 표시 |

### [D] 아군 영역 — 하단

```
┌─────────────────────────────────────────┐
│  아군 부대                                │
│                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │테오도라│  │ 보병  │  │ 궁병  │          │
│  │⚔🛡🛡★│  │⚔⚔🛡🛡│  │⚔⚔⚔⚔│          │
│  │ ✕ ✕  │  │ ✕ ✕  │  │ ✕ ✕  │          │
│  └──────┘  └──────┘  └──────┘          │
│                                         │
│  주사위 결과:                             │
│  [⚔] [🛡] [🛡] [★→⚔→⚔] [✕] [✕]       │
│   ↑ 터치로 리롤/전환 대상 선택             │
└─────────────────────────────────────────┘
```

| 요소 | 내용 |
|------|------|
| **아군 유닛 카드** | 풀 카드 표시 (미니 카드 폐기). 부상 표시 (~~🛡~~→✕) |
| **아군 주사위 결과** | 항상 공개. 각 주사위는 소속 유닛 색상으로 구분 |
| **카드락 표시** | 버프로 확정된 주사위 → 🔒 아이콘. 터치 불가 |
| **★ 체이닝** | ★ 결과 시 체이닝 연출: ⚔ 확정 → 재굴림 → 결과 (연쇄) |
| **유닛 터치** | 유닛 카드 터치 → 상세 팝업 (전체 면, 패시브, 부상) |

### [E] 행동 바 — 최하단

```
┌─────────────────────────────────────────┐
│  [버프 사용]   [리롤 1/1]   [전환]   [확정]            │
└─────────────────────────────────────────┘
```

| 버튼 | 스텝 | 조건 | 동작 |
|------|------|------|------|
| **[버프 사용]** | 2 | 버프 보유 시 활성 | 버프 효과 적용. 사용 후 소멸 |
| **[리롤 N/N]** | 4 | 리롤 잔여 횟수 > 0 | 주사위 1개 선택 → 재굴림 |
| **[전환]** | 6 | 전환 가능 유닛 존재 시 | 유닛 결과 일방향 전환 |
| **[확정]** | — | 항상 | 현재 스텝 완료 → 다음 스텝 진행 |

> **비활성 버튼:** 조건 미충족 시 회색 처리 + 터치 불가. 해당 스텝 자동 스킵.

## ③ 페이즈별 상세 흐름

### ① 선제 페이즈 (스텝 1) — 낮만

```
[전투 헤더: "① 선제"]
   ↓
[양측 궁병 하이라이트]
   ↓
[궁병 동시 사격 연출 — 화살 교차]
   ↓
[Named 궁병 타겟 지정]
   ┌─ Named 궁병 있음 → 적 유닛 중 사살 대상 터치 선택
   └─ Named 궁병 없음 → 스킵 (일반 궁병은 랜덤 타겟)
   ↓
[사격 결과 표시: 적/아군 사상자]
   ↓ 1초 대기
[사상자 적용 — 유닛 카드 제거/부상 연출]
   ↓
[적 전멸?] → YES: 전투 승리 종료
             NO: ② 격돌로 이동
```

**밤일 때:** 선제 페이즈 자체가 표시되지 않음. 헤더가 바로 "② 격돌"로 시작. 궁병 주사위가 격돌 굴림 풀에 합류.

**Named 궁병 타겟 지정 UI:**

```
┌─────────────────────────────────────────┐
│  타겟 지정: Named 궁병의 사살 대상을 선택   │
│                                         │
│  ┌──────┐  ┌──────┐  ┌──────┐          │
│  │적 보병│  │적 궁병│  │적 창병│          │
│  │  ◉   │  │  ◉   │  │  ◉   │          │
│  └──────┘  └──────┘  └──────┘          │
│                                         │
│            [확인]                        │
└─────────────────────────────────────────┘
```

### ② 격돌 페이즈 (스텝 2→3→4→5)

#### 스텝 2: 버프 사용 (수동)

```
[전투 헤더: "② 격돌 — 버프"]
   ↓
[버프 보유?]
   ├─ YES → [버프 사용] 버튼 활성
   │         ├─ 터치 → 버프 효과 적용 연출 → 소멸
   │         └─ [확정] → 버프 안 쓰고 넘기기
   └─ NO → 자동 스킵 → 스텝 3
```

**버프 종류별 연출:**

| 버프 | 연출 |
|------|------|
| **면 확정** | 아군 주사위 1개 선택 → ⚔ 또는 🛡로 잠금 + 🔒 표시 |
| **리롤 추가** | 리롤 카운터 1/1 → 2/2 갱신 |
| **적 정보 공개** | 적 주사위 1개 "?" → 결과 공개 (밤 전투 시) |
| **선제** | "선제 공격" 배지 표시 (아군 먼저 사상자 적용) |

#### 스텝 3: 전체 굴림 (자동)

```
[전투 헤더: "② 격돌 — 굴림"]
   ↓
[카드락 주사위: 잠금 상태 유지]
   ↓
[나머지 전체 주사위 동시 굴림 연출]
   ↓
[아군 결과: [D] 아군 영역에 표시]
[적 결과: [B] 적 영역에 표시 (밤이면 "?")]
   ↓
[★ 발생?] → YES: 체이닝 연출 (⚔ 확정 → 재굴림 → 결과...)
             NO: 스텝 4로
```

**★ 체이닝 연출:**

```
[★ 결과!]
   ↓ ⚔ 1 확정 (금색 이펙트)
[해당 주사위 재굴림]
   ↓ 결과에 따라:
   ├─ ★ → ⚔ 추가 확정 + 또 재굴림 (연쇄!)
   ├─ ⚔ → ⚔ 추가. 체이닝 종료
   ├─ 🛡 → 🛡 추가. 체이닝 종료
   └─ ✕ → 없음. 체이닝 종료
```

#### 스텝 4: 리롤 (수동)

```
[전투 헤더: "② 격돌 — 리롤"]
   ↓
[리롤 가능?]
   ├─ YES → [리롤 N/N] 버튼 활성
   │         ├─ 터치 → 주사위 선택 모드 진입
   │         │         ├─ 아군 주사위 터치 → 해당 주사위 재굴림
   │         │         └─ 적 주사위 터치 → 해당 주사위 재굴림 (밤: "?" 경고)
   │         └─ [확정] → 리롤 안 쓰고 넘기기
   └─ NO → 자동 스킵 → 스텝 5
```

**밤 적 주사위 리롤 경고:**

```
┌─────────────────────────┐
│  적 주사위 결과를 모릅니다. │
│  리롤하시겠습니까?         │
│                         │
│   [취소]      [리롤]     │
└─────────────────────────┘
```

**리롤 대상 제외:**
- 🔒 카드락 주사위: 선택 불가 (잠금 아이콘 + 회색)

#### 스텝 5: 기병 쇄도 (자동)

```
[전투 헤더: "② 격돌 — 쇄도"]
   ↓
[아군 기병 생존 + 쇄도 패시브 보유?]
   ├─ YES → 적 주사위 중 무작위 N개(기병 수) ✕화 연출
   │         ├─ 유효면(⚔/🛡) 선택됨 → ✕로 전환 + 깨짐 이펙트
   │         └─ ✕ 선택됨 → 헛발 (변화 없음)
   └─ NO → 자동 스킵 → ③ 대응
```

### ③ 전과 전 (방진/반격) (스텝 6→7)

#### 스텝 6: 유닛 전환 (수동)

```
[전투 헤더: "③ 대응 — 전환"]
   ↓
[전환 가능 유닛 존재?]
   ├─ YES → [전환] 버튼 활성
   │         ├─ 터치 → 전환 가능 유닛 하이라이트
   │         │         ├─ 보병: ⚔ → 🛡 (방진 패시브)
   │         └─ 창병/테오도라: 🛡 → ⚔ (반격 패시브)
   │         ├─ 유닛 터치 → 전환 미리보기 → [적용] / [취소]
   │         └─ [확정] → 전환 안 하고 넘기기
   └─ NO → 자동 스킵 → 스텝 7
```

**전환 미리보기:**

```
┌────────────────────────────────┐
│  보병: ⚔ → 🛡 전환             │
│                                │
│  변경 전: ⚔ ⚔ 🛡 🛡 ✕ ✕      │
│  변경 후: ⚔ 🛡 🛡 🛡 ✕ ✕      │  ← 변경 면 강조
│                                │
│    [취소]          [적용]       │
└────────────────────────────────┘
```

**전환 제외 대상:**
- 🔒 카드락 주사위: 전환 불가
- ★ 면 자체: 전환 불가 (체이닝 결과물은 가능)
- 궁병: 전환 없음
- 민병: 전환 없음
- 기병: 전환 없음 (쇄도은 스텝5에서 별도 처리)
- 패시브 미보유 유닛: 전환 불가

#### 스텝 7: 전과 (자동)

```
[전투 헤더: "③ 대응 — 판정"]
   ↓
[판정 영역 [C] 활성]
   ↓
[상쇄 연출: ⚔ vs 🛡 쌍소멸]
   ↓
[잔여 피해 계산]
   ├─ 적에게 피해 → 적 유닛 랜덤 제거 (Nameless 즉사, Named 부상/사망)
   └─ 아군에게 피해 → 아군 유닛 랜덤 피격 (Nameless 즉사, Named 부상/사망)
   ↓
[사상자 연출]
   ├─ Nameless 즉사: 카드 찢어짐 + 퇴장
   ├─ Named 부상: 카드 반파 + 면 1개 ~~취소선~~ → ✕
   ├─ Named 사망: 카드 찢어짐 + 퇴장
   └─ 테오도라 사망: 게임오버 전환
   ↓
[전투 종료 확인]
   ├─ 적 전멸 → 승리
   ├─ 아군 전멸 → 패배
   ├─ 테오도라 사망 → 게임오버
   └─ 양측 생존 → 다음 라운드
```

## ④ 라운드 반복 / 전투 종료

### 라운드 흐름

```
1턴 (낮/밤은 Stage에서 상속)
├── 라운드 1: ①→②→③
├── [전투 종료?] → YES: 종료 / NO: 계속
└── 라운드 2: ①→②→③
    └── [전투 종료?] → YES: 종료 / NO: 다음 턴

2턴
├── 라운드 3: ①→②→③
└── 라운드 4: ①→②→③
    └── ...반복...
```

> **턴 상한:** 미확정. 무한 교착 방지용 검토 중.

### 전투 종료 화면

```
┌─────────────────────────────────────────┐
│                                         │
│              ⚔ 전투 종료 ⚔              │
│                                         │
│           결과: 승리 / 패배              │
│                                         │
│  ┌─ 아군 ──────────────────────┐        │
│  │ 테오도라    생존 (부상 1)     │        │
│  │ 보병        생존              │        │
│  │ 궁병        사망 ☠           │        │
│  └─────────────────────────────┘        │
│                                         │
│  ┌─ 적군 ──────────────────────┐        │
│  │ 보초 1      사망 ☠           │        │
│  │ 보초 2      사망 ☠           │        │
│  └─────────────────────────────┘        │
│                                         │
│           라운드: 3 / 소요 턴: 2          │
│                                         │
│              [계속]                      │
└─────────────────────────────────────────┘
```

| 결과 | 후속 |
|------|------|
| **승리** | [계속] → Stage 씬 복귀 |
| **패배 (테오도라 생존)** | [계속] → Stage 씬 복귀 (부대 손실 반영) |
| **테오도라 사망** | 게임오버 전환 ("그 이야기는 쓰여지지 않았다.") |

### 게임오버 (테오도라 사망)

```
[테오도라 카드 찢어짐 연출]
   ↓ 2초
[화면 페이드 아웃 → 검은 화면]
   ↓
["그 이야기는 쓰여지지 않았다."]
   ↓ 3초 대기 또는 터치
[로비 복귀 — 비활성 상태]
```

## ⑨ 설계 근거

**Q. 왜 행동 바에 모든 버튼이 있는가?**
7스텝이 순차 진행이라 한 번에 1~2개만 활성. 나머지는 회색. 전체 버튼을 보여주면 "다음에 뭘 할 수 있는지" 예측 가능. 버튼이 나타났다 사라지면 인지 부하가 더 높음.

**Q. 왜 전환에 미리보기가 있는가?**
유닛 전환은 일방향이라 되돌릴 수 없음. 편성의 [확정], Stage의 분기 확인과 같은 원칙: 되돌릴 수 없는 행동에는 미리보기 + 확인.

**Q. 왜 수동 스텝에 [확정] 스킵이 있는가?**
모든 수동 행동은 선택이지 의무가 아님. 버프 안 쓰기, 리롤 안 하기, 전환 안 하기 모두 유효한 전략. [확정]으로 "아무것도 안 하고 넘어간다"를 명시적으로 선택.

**Q. 밤 전투에서 상쇄 과정을 왜 안 보여주나?**
적 결과가 "?"이므로 어떤 ⚔가 어떤 🛡와 상쇄되는지 보여줄 수 없음. 최종 피해만 공개 = "맞고 나서야 안다." 밤의 불확실성.

**Q. 판정 영역이 왜 중앙에 있는가?**
적 영역(상단) ↔ 아군 영역(하단) 사이에서 충돌하는 장면. 공간적으로 "부딪히는 곳"이 중앙. 시선이 자연스럽게 모인다.

**Q. Named 궁병 타겟 지정이 왜 수동인가?**
Named 궁병의 핵심 가치가 "원하는 적을 골라 죽이는 것". 자동 랜덤이면 Named와 Nameless 궁병 차이가 체감 안 됨. 이름이 있으니까 판단한다.
