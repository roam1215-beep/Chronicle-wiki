# 우호 NPC

> 상태: 결정정합 (골격)

## 정의

우호 NPC = 아군 진영이지만 플레이어 통제 불가. 같이 싸우거나 같이 진행하되, 조작 결정권은 시스템·서사에 있다. 옛 동료 시스템(5-7 폐기)에서 *통제 불가* 결만 살려 재정의한 자리.

## 규칙

### 정의

```yaml
진영:    아군
통제:    불가 (조작 X)
존재 기간: 시스템·서사가 정함
손실 처리: 서사 결로 박힘 (게임 룰로 강제 X)
```

### 발현 자리 (예시)

```yaml
스테이지 합류 NPC:    토벌대 / 마을 자원자 등. 그 스테이지·챕터 종료 시 이탈
챕터 우호 NPC:        다음 챕터까지 이어지는 자리 (예: Order 1 챕터 1 동료 = 챕터 2까지)
운명 우호 NPC:        운명 전투에 등장. 결과는 서사 결정
```

### 작동 결

```yaml
전투 등장: 가능. 단 카드 시스템 결 다름 (펜딩)
조작 시도: 불가 (UI 차단)
사망 처리: 서사 결 (게임 룰로 영구 손실 강제 X)
```

### 폐기 자리

```yaml
- 동료 시스템 (5-7 폐기): 통제 가능한 부대원 결 폐기. 통제 불가 결만 살림
- 추종자 시스템 (5-7 폐기): 다른 세션에서 재설계
```
