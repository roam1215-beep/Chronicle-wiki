# META-COMPANION: 동료 시스템

> 상태: 설계중 · 의존: @META-BOOK-001, @COMBAT-STRUCT-001

## 정의

동료 = Chapter 단위로 합류하는 조작 불가 아군. 사상자 풀은 내 부대와 공유하지만 리롤·버프·패시브 조작은 불가. AI 성향에 따라 자동 행동.

## 규칙

### 합류

```yaml
companion:
  unit: chapter
  reveal_order: 장소(팩 뒷면) → 계절 → 동료
  source: chapter 동료 테이블 (랜덤)
  carry_over:
    within_chapter: 이월 (부상/사망 포함)
    between_chapter: 교체 (새 챕터 = 새 동료)
  replenishment: 기본 없음. 사건 카드로 가능
  casualty_pool: 내 부대와 공유  # 사상자 풀 단일
```

### 조작 제한

```yaml
control:
  player_actions:
    - reroll: 불가         # @COMBAT-ACT-002 (단, 리롤 부활 여부 자체 TODO)
    - passive_choice: 불가
    - buff_apply: 불가
  auto:
    - 선제: 자동
    - 패시브: AI 성향 따름 (TODO 시스템 정합)
    - 굴림: 자동
  damage:
    - 사상자 풀에 포함됨 (피격/부상/사망 대상)
```

### AI 성향

```yaml
ai_disposition:
  options: [공격적, 수비적]
  visibility: 플레이어에게 비공개. 첫 전투에서 행동 관찰로 파악
  application: 부대 테이블에 고정
  rules:
    공격적:
      passive_priority: TODO(엔진): "산개/밀집 폐기 후 패시브 시스템 정합 시"
    수비적:
      passive_priority: TODO(엔진): 동일
  reroll: 동료 AI는 리롤 안 함
```

### 동료 구성

```yaml
composition:
  base: 민병 ×N + Named 1기
  named:
    passive: 병종 기본 (TODO 정합)
    trait: Named 공통 규칙
    injury: 2단계   # @COMBAT-JUDGE-001
  nameless: 민병 (즉사)
```
