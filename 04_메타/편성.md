# META-FORMATION-001: 편성 (Formation)

> **상태:** 🔄 설계중 · **버전:** 0.7 · **ID:** META-FORMATION-001 · **수정일:** 2026-03-10

---

## ① 한 줄 요약

편성은 Order 시작 시 1회 발생하는 부대 구성 화면. 플루타르크식 인물 소개 페이지로 표현되며, Named 1기(병종 선택) + Nameless 2기(선택 1 + 랜덤 1)로 3기 부대가 확정된다. **첫 런은 용맹한 테오도라 / Named 보병 고정.** 카드 1장 = 주사위 1개 = 유닛 1기.

---

## ② 규칙 정의

### 부대 구성

| 슬롯 | 유형 | 내용 |
|------|------|------|
| **슬롯 1** | Named (병종 선택) | 테오도라 — **O1: Named 보병/창병/궁병 중 택 1.** 첫 런은 Named 보병 고정. Ch1 클리어=창병 해금, Ch2 클리어=궁병 해금. 사망 = 게임오버. **O2: 기사로 전직** |
| **슬롯 2** | Nameless (선택) | 보병/창병/궁병 중 플레이어 택 1 |
| **슬롯 3** | Nameless (랜덤) | 보병/창병/궁병 중 랜덤 1기. 뒷면 상태로 배치 |

> **편성 풀 = 보병, 창병, 궁병 (3종).** 민병은 편성 풀에서 제외. 스테이지 중 병력 합류 등으로는 등장 가능.
>
> **선택과 랜덤은 중복 허용.** 보병을 골랐는데 랜덤도 보병일 수 있다.

### Nameless 선택 규칙

| 필드 | 내용 |
|------|------|
| **선택지** | 보병, 창병, 궁병 — 3장을 앞면으로 제시 |
| **선택 수** | 1기 |
| **타이밍** | 편성 화면 진입 직후. 랜덤 공개 전 |

### Nameless 랜덤 공개 규칙

| 필드 | 내용 |
|------|------|
| **초기 상태** | 뒷면 (병종 비공개) |
| **공개 방법** | 플레이어가 뒷면 카드를 터치/클릭 |
| **공개 결과** | 뒤집기 연출 → 병종 공개 (보병/창병/궁병) |
| **공개 강제** | 공개해야 진행 가능. 뒷면 상태로 시작 불가 |
| **랜덤 시점** | Order 진입 시 시스템이 결정. 공개 시점이 아님 |

### 진행 흐름

```
인물 페이지에서 [✒ 쓰기] / [다시 쓰기]
    ↓
편성 화면 진입
    ↓
테오도라 소개 표시 (Named 1기 고정)
    ↓
Nameless 선택지 3장 표시 (보병/창병/궁병)
    ↓
플레이어 택 1 → [확정] 버튼으로 확정
    ↓
Nameless 뒷면 카드 표시
    ↓
플레이어가 뒷면 터치 → 뒤집기 연출 → 병종 공개
    ↓
[시작] 활성화
    ↓
Chapter 1 공개 (책장 펼침 + Chapter 제목) → 진입
```

### O1 테오도라 — 병종 해금

| 시점 | 선택 가능 병종 | 패시브 |
|------|--------------|--------|
| **첫 런** | Named 보병 **고정** | 방진 (고정) |
| Ch1 클리어 후 | 보병 / **창병** | 병종 따라감 |
| Ch2 클리어 후 | 보병 / 창병 / **궁병** | 병종 따라감 |

> **O1 패시브 = 병종에 따라 자동 결정.** 보병=방진, 창병=반격, 궁병=선제.
> **O2 패시브 = 4종(방진/반격/쇄도/유격) 중 2택 제시 1택.** 기사 전직에 맞춰 풀 확장.

### O1 테오도라 — 특성 해금

| 해금 시점 | 특성 | 선택 제한 |
|----------|------|----------|
| **기본** | 용맹한 | 첫 런 고정 |
| Stage 1 클리어 | 신중한 | — |
| Stage 2 클리어 | 예리한 | **궁병 선택 시에만 표시** |
| Stage 3 클리어 | 현명한 | — |
| Stage 4 클리어 | 고결한 | — |
| Stage 5 클리어 | 은밀한 | — |
| Stage 6 클리어 | 대담한 | — |
| Stage 7 클리어 | 굳건한 | — |

> **첫 런 = 용맹한 고정.** 두 번째 런부터 해금된 특성 풀에서 자유 선택.
> **Stage 7까지 클리어하면 8종 전부 해금.**

### 카드 = 유닛

**카드 1장 = 주사위 1개 = 유닛 1기.** 보병 3기 = 보병 카드 3장. 밀집 대형 선택 시 전원 뒷면(초기면)으로 뒤집힘.

### 초기 상태

| 항목 | 값 |
|------|-----|
| **전원 패시브** | 병종별 기본 보유 (민병 제외) |
| **전원 부상** | 없음 (정상 상태) |
| **버프** | 없음 |
| **덱** | Stage별 9장(팩에서 뽑기) + 운명 1장 → [스테이지카드규칙](../03_스테이지/스테이지카드규칙.md) 참조 |

### 화면 구성 — 사서 프레임

| 요소 | 표현 |
|------|------|
| **화면 전체** | 인물 소개 페이지. 플루타르크 영웅전의 "인물 서두" |
| **Named 영역** | 테오도라의 간결한 소개. Order별로 내용이 축적됨 |
| **Nameless 선택 영역** | 3장 앞면. "부대를 고르시오" |
| **Nameless 랜덤 영역** | 뒷면 카드 1장. "우연한 만남" |
| **[시작] 버튼** | 선택 완료 + 랜덤 공개 후 활성화 |

### Order별 소개 축적

| Order | 소개 내용 |
|-------|----------|
| **Order 1 (첫 플레이)** | 테오도라 기본 소개. 짧음 |
| **Order 1 (재플레이)** | 동일. 이전 정사 기록은 인물 페이지에서 확인 |
| **Order 2** | Order 1 정사 내용이 소개에 반영 — "다리 위의 전투를 거친 테오도라는..." |
| **Order N** | 이전 정사들이 축적되어 소개가 두꺼워짐 |

> **Order 소개 축적은 정사 기준.** 야사는 소개에 반영되지 않음.

## ④ 설계 근거

**Q. 왜 Named가 테오도라 1기인가?**
편성 시 Named = 테오도라 1기. 런 중 방랑기사 추종자(ND)로 추가 Named를 획득할 수 있다. Named가 늘어나면 사망/부상 처리 비용이 증가하지만, 방랑기사 획득은 선택이므로 플레이어가 리스크를 감수한다. 테오도라만 추종자+특성/패시브로 성장하는 구조가 기본.

**Q. 왜 선택 1 + 랜덤 1인가?**
둘 다 랜덤 → 극단 조합 위험 (궁병+궁병, 전부 같은 병종). 둘 다 선택 → 매 런 최적 조합만 반복, 뒤집기 연출 의미 소멸. 하나는 전략(내가 고른 동료), 하나는 운명(보내진 동료) — 로그라이크의 "주어진 패로 최선을 찾는" 경험.

**Q. 왜 민병이 편성 풀에 없는가?**
민병은 패시브 없음 + ✕ 5개(실패 50%). 편성에서 뽑히면 "운이 나쁨"이 아니라 "벌을 받음"이 돼. 선택지에선 안 고르고, 랜덤에서 나오면 짜증만 남아. 민병은 게임 내 존재(스테이지 합류, 적 유닛 등)로 유지하되 편성 풀에서 제외.

**Q. 왜 3기인가?**
최소 규모로 전술 공간을 열면서 로그라이크의 "적은 것에서 키워나간다"를 살린다. 분기 효과 "병력 합류"로 스테이지 중 증원 가능. 3기 시작은 매 런 손실의 무게를 극대화 — 1기 잃으면 전력의 1/3이 증발.

**Q. 사서 프레임에서 편성은 뭔가?**
플루타르크 영웅전의 인물 서두. "알키비아데스는 아테네의 귀족으로..." 같은 소개가 Order를 거듭할수록 두꺼워진다. 편성 화면 = 이번 이야기의 등장인물 페이지. 선택 = "인연", 랜덤 = "우연한 만남".

**Q. 대형 선택(산개/밀집)은 편성에서 하는가?**
아니다. 대형 선택은 **전투 중 매 라운드** 결정. 편성은 "누구를 데려갈지", 대형은 "어떻게 싸울지." 다만 같은 병종 2기 이상이 밀집 조건이므로, 편성에서 병종을 집중할지 분산할지가 밀집 전술에 영향. → [COMBAT-STRUCT-001 전투 구조](../../02_전투/구조/전투구조.md) 대형 선택 참조
