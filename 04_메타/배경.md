# META-BACKDROP: 배경 시스템 (Backdrop System)

> **상태:** 🔄 설계중 · **버전:** 0.6 · **ID:** META-BACKDROP · **수정일:** 2026-03-09

---

## ① 한 줄 요약

배경 = 장소 + 계절. 챕터 단위로 적용. 이야기 카드가 벌어지는 무대. 메카닉 조건을 결정하되 서술은 바꾸지 않는다.

---

## ② 구조

```
챕터 시작
 └─ 배경 공개
     ├─ 장소  → 전투 조건 + 우연 빈도(홀드 탭 신뢰도)
     └─ 계절  → 막 내 낮/밤 패턴
```

| 항목 | 내용 |
|------|------|
| 단위 | 챕터 |
| 역할 | 메카닉 조건 결정. 이야기 카드의 서술은 안 바꿈 |
| 태그와의 관계 | 독립. 태그는 카드 단위, 배경은 챕터 단위 |
| 확장 원칙 | 7스텝으로 안 되는 것을 배경에서 품는다 |

| 축 | 조절 대상 | 영향 범위 |
|----|----------|----------|
| **장소** | 전투 조건 + **우연 빈도 → 홀드 탭 신뢰도** | 전투 + 카드 흐름 |
| **계절** | **막 내 낮/밤 패턴** | 전투 조건 (간접) |

---

## ③ 스토리 팩 연동

```
오더 1: 다리 위의 서자들

장소 3개 (구체 이름 미정) × 계절 4개 = 챕터당 4가지
챕터 3개: 각 챕터에 장소 1:1 배정

장소 순서 × 계절 조합:
 순서 고정 시: 1 × 4³ = 64 런
 순서 랜덤 시: 6 × 4³ = 384 런
 (순서 미정 — 서사 설계 후 결정)
```

장소가 카드풀을 결정하므로, 다른 장소 = 다른 이야기 카드. 계절이 같아도 장소가 다르면 겪는 카드가 다르다. 같은 장소라도 계절(낮/밤 패턴) + 셔플 + 블라인드 선택으로 체감이 바뀐다.

---

## ④ 계절

챕터 시작 시 4계절 중 랜덤 1개 결정. 해당 챕터 전체 적용. 계절 = 막 내 낮/밤 패턴. 추가 효과 없음.

### 패턴 정의

모든 막은 **3페이즈 고정.** 계절이 각 페이즈의 낮/밤을 결정한다. 매 막 동일 패턴 반복.

| 계절 | P1 | P2 | P3 + 운명 전투 | 낮:밤 | 주기 | 중세 근거 |
|------|----|----|---------------|-------|------|----------|
| **봄** | ☀ 낮 | 🌙 밤 | ☀ 낮 | 2:1 | 2 (낮→밤 교대) | 춘분 — 균등에 가까운 약간 긴 낮 |
| **여름** | ☀ 낮 | ☀ 낮 | 🌙 밤 | 2:1 | 3 (낮낮밤) | 하지 — 긴 낮, 마지막만 밤 |
| **가을** | 🌙 밤 | ☀ 낮 | 🌙 밤 | 1:2 | 2 (밤→낮 교대) | 추분 — 균등에 가까운 약간 긴 밤 |
| **겨울** | 🌙 밤 | 🌙 밤 | ☀ 낮 | 1:2 | 3 (밤밤낮) | 동지 — 긴 밤, 마지막만 낮 |

### 구조적 특성

| 항목 | 내용 |
|------|------|
| **대칭** | 봄 ↔ 가을 (비율 반전, 시작점만 뒤집힘). 여름 ↔ 겨울 (완벽한 거울 대칭) |
| **운명 전투** | P3의 낮/밤을 상속. 여름 운명=밤, 겨울 운명=낮 — 계절 유불리가 마지막에 뒤집힘 |
| **예측 가능** | 계절을 아는 순간 6막×3페이즈의 낮/밤 전부 확정. 빌드 판단의 근거 |
| **7스텝 불변** | 낮/밤의 규칙(선제 발동, 적 정보 공개 등)은 일절 변경 없음. 빈도만 조정 |

### 낮/밤 배정 규칙

| 항목 | 내용 |
|------|------|
| **배정 단위** | 페이즈. 페이즈마다 낮/밤이 고정 |
| **전투 상속** | 해당 페이즈에서 뒤집힌 전투 카드 / 우연-전투는 해당 페이즈의 낮/밤을 상속 |
| **운명 전투** | P3의 낮/밤 상속 |
| **비전투** | 사건 카드 / 우연-이벤트는 낮/밤 무관 |
| **전투 내** | 교대 없음. 끝까지 유지 (기존 확정 규칙) |

### 빌드 영향

| 계절 | 궁병/선제 | 정찰병 | 은밀한(특성) | 신중한/예리한(특성) | 운명 |
|------|----------|--------|------------|------------------|------|
| **봄** | P1·P3 발동 | P2 유용 | P2 발동 | P1·P3 발동 | 낮 |
| **여름** | P1·P2 발동 | P3 유용 | P3 발동 | P1·P2 발동 | **밤** |
| **가을** | P2 발동 | P1·P3 유용 | P1·P3 발동 | P2 발동 | **밤** |
| **겨울** | P3 발동 | P1·P2 유용 | P1·P2 발동 | P3 발동 | 낮 |

### 공개 방식

계절 카드 뒷면 → 자동 뒤집기 연출. 랜덤이므로 뒤집기. 플레이어 조작 불필요.

## ⑤ 장소

장소 = 장소별 카드풀(60장) + 뽑기 비율 세트. 챕터당 장소 1개, 오더당 장소 3개.

### 핵심 구조

| 항목 | 내용 |
|------|------|
| **형태** | 고유 지명. 오더당 3개 |
| **카드풀** | 장소별 60장 (전투 20 + 사건 20 + 우연 20). 장소 전용 서술 |
| **뽑기 비율** | 막 시작 시 장소가 전투/사건/우연 뽑기 수를 결정. 합계 9장 |
| **챕터 배정** | 챕터당 장소 1개 (1:1 매핑) |
| **총량** | 장소 3개 × 60장 = 180장 + 운명 60장 = **240장 (현행 동일)** |

### 풀 구조

```
오더 1 [다리 위의 서자들]
 ├─ 장소 A 풀: 60장 (전투20+사건20+우연20) — 장소 A 전용 서술
 ├─ 장소 B 풀: 60장 (전투20+사건20+우연20) — 장소 B 전용 서술
 ├─ 장소 C 풀: 60장 (전투20+사건20+우연20) — 장소 C 전용 서술
 └─ 운명 풀: 60장 (운명 일러스트 20 × 3종) — 장소 무관
```

### 뽑기 비율 (γ 세트)

| 장소 | 전투 | 사건 | 우연 | 합계 | 성격 | 홀드 탭 신뢰도 |
|------|------|------|------|------|------|--------------|
| **장소 A** | 4장 | 4장 | 1장 | 9장 | 균형 안정 | **높음** (우연 1장, 위장 최소) |
| **장소 B** | 4장 | 2장 | 3장 | 9장 | 전투+혼란 | **낮음** (우연 3장, 위장 많음) |
| **장소 C** | 2장 | 4장 | 3장 | 9장 | 사건+혼란 | **낮음** (우연 3장, 위장 많음) |

> **장소 A:** 전투와 사건이 균등하고 우연이 거의 없다. 홀드 탭이 대체로 맞는다. 가장 안정적.
> **장소 B:** 전투가 많지만 우연도 많다. "전투인 줄 알고 골랐더니 우연." 혼란스러운 전장.
> **장소 C:** 사건이 많지만 우연도 많다. 준비하려는데 우연이 끼어든다. 계획이 틀어지는 곳.

### 리플레이 구조

같은 장소 풀 60장이라도 매 런 경험이 다른 이유:
- 셔플 순서가 다르면 페이즈별 제시 3장 조합이 다르다
- 계절이 다르면 낮/밤 패턴이 다르다
- 블라인드 선택이 다르면 겪는 카드가 다르다
- 전해지지 않은 이야기가 달라진다

### 미정 사항

| 항목 | 현재 상태 | 결정에 필요한 것 |
|------|----------|----------------|
| 구체 장소 이름 | 미정 | 오더 1 서사 설계 |
| 장소 순서 (고정 vs 랜덤) | 미정 | 오더 1 서사 설계 |
| 장소별 카드 서술 | 미정 | 스토아 팩토리 + 서사 설계 |

## ⑥ 설계 근거

**Q. 왜 배경이 필요한가?**
태그는 7스텝 호환만 허용. 공성전 같은 전장 유형은 태그에 억지로 넣으면 7스텝 불변 원칙이 깨진다. 배경이 챕터 레벨에서 메카닉 조건을 깔면(장소=전투 조건+우연 빈도, 계절=낮/밤 패턴) 태그는 보수적으로 유지하면서도 표현 폭이 넓어진다. 공성전은 전투구조의 수비 대형으로 구현 — 장소/태그가 트리거.

**Q. 왜 배경 × 스토리 팩 분리인가?**
장소가 카드풀을 결정하고, 계절이 낮/밤 패턴을 결정한다. 같은 장소라도 계절이 다르면 메카닉 조건이 달라져 체감이 바뀐다. 다른 장소면 카드 자체가 다르다. 콘텐츠 비용을 장소×계절 조합으로 푸는 구조.

**Q. 왜 장소별 카드풀(L3)인가?**
"겪은 것이 덱이 된다"가 핵심 원칙이다. 아비뇽에서 겪은 이야기는 아비뇽의 이야기여야 한다. 단일 풀에서 범용 카드를 뽑으면 장소감이 없다. 장소별 풀이면 서술이 장소에 귀속되어 "이 장소의 이야기를 겪고 있다"는 체감이 자연스럽다. 총량은 240장으로 현행과 동일.

**Q. 장소별 풀이면 리플레이가 약해지지 않나?**
같은 장소 풀 60장이라도 셔플 순서, 계절(낮/밤 패턴), 블라인드 선택, 전해지지 않은 이야기가 매 런 다르다. 리플레이는 풀 크기가 아니라 풀 위의 레이어들이 보장한다.

**Q. 배경이 서술을 안 바꾸면 어색하지 않나?**
~~기존: 카드 서술이 장소에 의존하지 않음.~~ → **L3으로 전환: 장소별 카드풀이므로 카드 서술이 장소에 귀속.** "아비뇽 다리 위의 보초", "파리 성문의 위병" 등 장소 전용 서술.

**Q. 왜 4계절인가?**
중세 전쟁의 계절성을 반영. 여름의 긴 낮(원정 적기), 겨울의 짧은 낮(교전 가능 시간 제한)이 메카닉으로 직결. 서사와 메카닉이 한 몸.

**Q. 왜 계절 효과가 낮/밤 패턴 단일 축인가?**
낮/밤은 이미 전투에 가장 큰 영향을 미치는 확정 시스템(선제 발동, 적 정보, 리롤 판단, 궁병 가치). 계절이 낮/밤의 규칙을 건드리지 않고 빈도만 조정하면 7스텝 불변을 지키면서 챕터 체감이 바뀐다. 정찰병/특성 등 기존 시스템과 역할이 겹치지 않는다.

**Q. 왜 봄/가을이 같은 2:1 / 1:2 비율인데 분리되어 있나?**
시작점이 다르다. 봄은 첫 전투가 낮, 가을은 첫 전투가 밤. 첫 페이즈의 낮/밤이 초반 전략(편성 직후 첫 교전)을 가르므로 체감이 확연히 다르다.

**Q. 왜 여름 운명이 밤이고 겨울 운명이 낮인가?**
"좋은 계절이라고 안심할 수 없고, 나쁜 계절이라고 절망할 수 없다." 여름은 평소 밝지만 마지막이 어둡고, 겨울은 평소 어둡지만 마지막이 밝다. Chronicle의 불확실성 철학에 부합.

**Q. 왜 계절은 Chapter 단위인가?**
Stage 단위면 같은 작전 안에서 계절이 바뀌는 서사적 모순. Chapter = 새 작전이므로 계절 변경이 자연스럽다.
