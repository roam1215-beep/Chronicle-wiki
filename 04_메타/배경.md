# META-BACKDROP: 배경 시스템

> 상태: 결정정합 · 의존: @STAGE-CARD-002, @TAG-RULE-001

## 정의

배경 = 챕터 팩(공간 금형) + 계절. 챕터 팩이 카드풀과 전투 성격을 결정하고, 계절이 낮/밤 패턴을 결정한다. 공개 순서: 장소(팩) → 계절 → 동료.

## 규칙

### 구조

```yaml
단위: 챕터
공개_순서: 장소(팩 뒷면) → 계절 → 동료
태그_관계: 독립 (태그 = 카드 단위, 배경 = 챕터 단위)
확장_원칙: 7스텝으로 안 되는 것을 배경에서 품는다

축:
  장소_팩: 카드풀 + 태그 분포 + 적 성격 + 금형 특수 규칙 → 전투+카드 흐름 전체
  계절:    막 내 낮/밤 패턴 → 전투 조건 (간접)
```

### 챕터 팩

```yaml
정의: 장소 = 고유 지명 + 공간 금형. 팩이 카드풀 전체를 담는다
팩_크기: 30 (일반 27 + 운명 3)
1권_구성: 챕터 팩 9. 런마다 9개 중 3개 랜덤 배정
뒷면: 팩당 1종. 9팩 = 9종 뒷면 (팩 아이덴티티)
운명: 팩 내장. 팩당 3장. Stage당 1장 사용, 비중복

런_구성:
  팩_풀: 9
  런당_선택: 3 랜덤
  조합_수: C(9,3) = 84
```

### 공간 금형 6종

```yaml
다리: { 성격: "좁은 통로, 정면 수비", 카드: "[봉쇄][수비] 편향",     특수규칙: TODO }
협곡: { 성격: "폐쇄 지형, 매복",      카드: "[함정][역습][난전] 편향", 특수규칙: TODO }
평원: { 성격: "개활지, 기동전",       카드: "[기습][우세] 편향",      특수규칙: TODO }
숲:   { 성격: "시야 차단, 은밀",      카드: "사건 多, 전투 少",       특수규칙: TODO }
산지: { 성격: "고저차, 방어 유리",    카드: "전투 多, 거친 곳",       특수규칙: TODO }
분지: { 성격: "포위 가능, 전략적",    카드: "균형",                   특수규칙: TODO }
```

> 금형 특수 규칙: 7스텝 불변. 외부 조건만 변경.

### 적 테이블 — 챕터 난이도

```yaml
테이블_레벨: 3 (Chapter 1/2/3)
효과: 같은 팩이 Chapter 1=Lv1(쉬움), Chapter 3=Lv3(어려움)
팩_범용성: 9팩 어디든 아무 챕터 배정 가능
콘텐츠_효율: 카드 N장 × 3레벨 = 실질 3배 다양성
```

### 팩 소모

```yaml
뽑기_per_chapter: 30 (일반 27 + 운명 3)
겪기_per_chapter: 21 (일반 18 + 운명 3)
버림_per_chapter: 9 (전해지지 않은 이야기)
미사용_per_pack: 0
리플레이: 버림 9 + 9팩 중 3팩 (84조합) + 셔플 + 계절
```

### 계절

챕터 시작 시 4계절 중 랜덤 1개. 챕터 전체 적용. 같은 챕터 내 3 Stage 동일 패턴.

```yaml
봄:   { P1: 낮, P2: 밤, P3+운명: 낮, ratio: "2:1" }
여름: { P1: 낮, P2: 낮, P3+운명: 밤, ratio: "2:1" }
가을: { P1: 밤, P2: 낮, P3+운명: 밤, ratio: "1:2" }
겨울: { P1: 밤, P2: 밤, P3+운명: 낮, ratio: "1:2" }

배정_단위: 페이즈
전투_상속: 페이즈 낮/밤 상속
운명_상속: P3 상속
비전투: 무관
전투_내_교대: 없음
공개: 계절 카드 뒷면 → 자동 뒤집기 (팩 뒷면 공개 후)
```

### 1권 총량

```yaml
챕터_팩: 9 × 30 = 270장
운명: 팩 내장
```

### 12과업 구조

챕터 팩 = 하나의 이야기. 헤라클레스 12과업처럼, 지명이 팩을 호출한다.
