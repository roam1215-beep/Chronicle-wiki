# META-BACKDROP: 배경 시스템 (Backdrop System)

> **상태:** 🔄 설계중 · **버전:** 1.0 · **ID:** META-BACKDROP · **수정일:** 2026-03-10

---

## ① 한 줄 요약

배경 = 챕터 팩(공간 금형) + 계절. 챕터 팩이 카드풀과 전투 성격을 결정하고, 계절이 낮/밤 패턴을 결정한다. 공개 순서: 장소(팩) → 계절 → 동료.

---

## ② 구조

| 항목 | 내용 |
|------|------|
| 단위 | 챕터 |
| 공개 순서 | 장소(팩 뒷면) → 계절(카드 뒤집기) → 동료(카드 공개) |
| 태그와의 관계 | 독립. 태그는 카드 단위, 배경은 챕터 단위 |
| 확장 원칙 | 7스텝으로 안 되는 것을 배경에서 품는다 |

| 축 | 조절 대상 | 영향 범위 |
|----|----------|----------|
| **장소(팩)** | 카드풀 + 태그 분포 + 적 성격 + 금형 특수 규칙 | 전투 + 카드 흐름 전체 |
| **계절** | 막 내 낮/밤 패턴 | 전투 조건 (간접) |

## ③ 챕터 팩 (Chapter Pack)

### 핵심 구조

| 항목 | 내용 |
|------|------|
| **정의** | 장소 = 고유 지명 + 공간 금형. 팩이 카드풀 전체를 담는다 |
| **팩 크기** | 90장 (일반 81장 + 운명 9장) |
| **1권 구성** | 챕터 팩 9개. 런마다 9개 중 3개 랜덤 배정 |
| **뒷면** | 팩당 1종. 9팩 = 9종 뒷면 (팩 아이덴티티) |
| **운명** | 팩 내장. 팩당 9장. Stage당 1장 사용, 비중복 |

### 공간 금형 (6종)

금형이 팩의 뼈대를 결정한다.

| 금형 | 공간 성격 | 카드 개성 | 특수 규칙 |
|------|----------|----------|----------|
| **다리** | 좁은 통로. 정면 수비 | [봉쇄][수비] 편향 | 미정 |
| **협곡** | 폐쇄 지형. 매복 | [함정][역습][난전] 편향 | 미정 |
| **평원** | 개활지. 기동전 | [기습][우세] 편향 | 미정 |
| **숲** | 시야 차단. 은밀 | 사건 多. 전투 少 | 미정 |
| **산지** | 고저차. 방어 유리 | 전투 多. 거친 곳 | 미정 |
| **분지** | 포위 가능. 전략적 | 균형 | 미정 |

> **금형 특수 규칙:** 7스텝 불변. 외부 조건만 변경. 구체 내용은 후속 세션에서 설계.

### 금형 개성 = 유형 비율 + 태그 분포

전투 비율은 모든 금형에서 ~50% 공통. **사건과 우연의 배분이 금형의 개성.**

### 적 테이블 — 챕터 난이도 레벨

같은 카드라도 챕터 위치(1/2/3)에 따라 적이 달라진다.

| 항목 | 내용 |
|------|------|
| **테이블 레벨** | 3단계 (Chapter 1/2/3) |
| **효과** | 같은 팩이 Chapter 1이면 Lv1(쉬움), Chapter 3이면 Lv3(어려움) |
| **팩 범용성** | 9팩 어디든 아무 챕터에 배정 가능 |
| **콘텐츠 효율** | 카드 N장 × 테이블 3레벨 = 실질 3배 전투 다양성 |

### 팩 소모

| 항목 | 값 |
|------|-----|
| 뽑기 / Chapter | 27장 (일반) + 3장 (운명) = 30장 |
| 겪기 / Chapter | 18장 (일반) + 3장 (운명) = 21장 |
| 버림 / Chapter | 9장 (전해지지 않은 이야기) |
| 소모율 / 팩 | 30/90 = 33% |
| 미사용 / 팩 | 60장 (67%) |

### 12과업 구조

챕터 팩 = 하나의 이야기. 헤라클레스 12과업처럼, 지명이 팩을 호출한다.

### 런 구성 — 9팩 중 3팩 배정

| 항목 | 내용 |
|------|------|
| 팩 풀 | 9개 |
| 런당 선택 | 3팩 랜덤 배정 |
| 팩 조합 수 | C(9,3) = 84가지 |

## ④ 계절

챕터 시작 시 4계절 중 랜덤 1개 결정. 해당 챕터 전체 적용. 같은 챕터 내 3 Stage는 동일 패턴 반복.

### 패턴 정의

| 계절 | P1 | P2 | P3 + 운명 전투 | 낮:밤 |
|------|----|----|---------------|-------|
| **봄** | ☀ 낮 | 🌙 밤 | ☀ 낮 | 2:1 |
| **여름** | ☀ 낮 | ☀ 낮 | 🌙 밤 | 2:1 |
| **가을** | 🌙 밤 | ☀ 낮 | 🌙 밤 | 1:2 |
| **겨울** | 🌙 밤 | 🌙 밤 | ☀ 낮 | 1:2 |

### 낮/밤 배정 규칙

| 항목 | 내용 |
|------|------|
| **배정 단위** | 페이즈 |
| **전투 상속** | 해당 페이즈 낮/밤 상속 |
| **운명 전투** | P3 상속 |
| **비전투** | 낮/밤 무관 |
| **전투 내** | 교대 없음 |

### 공개 방식

계절 카드 뒷면 → 자동 뒤집기 연출. 장소(팩 뒷면) 공개 후.

## ⑥ 설계 근거

**Q. 왜 챕터 팩인가?**
장소가 이야기 단위. 챕터 = 하나의 장소 = 하나의 완결된 이야기.

**Q. 왜 공간 금형인가?**
지명보다 공간이 메카닉을 결정한다. "헬름 협곡"에서 핵심은 협곡. 금형 = 재사용 가능한 구조, 지명 = 1회성 서사.

**Q. 왜 적 테이블을 유지하나?**
같은 카드가 챕터 위치에 따라 다른 난이도. 팩 범용성과 콘텐츠 효율 극대화.

**Q. 왜 뒷면이 팩당 1종인가?**
정찰 전 정보 0. 팩 뒷면이 공간 정체성. 하스스톤 뒷면 장식과 같은 맥락.

**Q. 왜 운명이 팩 내장인가?**
운명도 그 장소의 이야기. 별도 풀 관리 불필요.
