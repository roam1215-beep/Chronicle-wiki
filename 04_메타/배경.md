# 환경 레이어

## 정의

```yaml
환경 = 장소 + 날씨 + 시간대

장소:    Stage 단위 고정. Stage 정체성 + 특수 규칙
날씨:    Stage 시작 시 결정. 정찰 조건
시간대:  Phase 시작 R1 + 라운드별 변동. 의지 주사위 굴림 조건
```

## 시간대

```yaml
3종: 낮 / 경계 / 밤

자기 시간대:
  지상 = 낮
  미궁 = 밤
  경계 = 경계

R1 시간대:
  첫 배틀:     Phase 시작 시간대
  두 번째 배틀: 이전 배틀 마지막 라운드 시간대

라운드별 흐름 (예시):
  지상 Phase R1 낮 → R2 경계 → R3 밤 → R4 경계 → R5 낮 ...
  미궁 Phase R1 밤 → R2 경계 → R3 낮 → R4 경계 → R5 밤 ...
```

## 진영 자기 시간대

```yaml
지상: 낮 — 인격신 (그리스 올림포스)
미궁: 밤 — 자연신
경계: 경계 — 신앙 X / 떠돌이
```

## 장소

```yaml
Stage 단위 고정 결
특수 규칙: [Stage별 펜딩]
```

## 날씨

```yaml
Stage 시작 시 결정
정찰 조건에 영향
[구체 결 = 펜딩]
```
