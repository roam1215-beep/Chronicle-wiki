# META-BACKDROP: 배경 시스템 (Backdrop System)

> **상태:** 🔄 설계중 · **버전:** 0.3 · **ID:** META-BACKDROP · **수정일:** 2026-03-09

---

## ① 한 줄 요약

배경 = 장소 + 계절 + 상황. 챕터 단위로 적용. 이야기 카드가 벌어지는 무대. 메카닉 조건을 결정하되 서술은 바꾸지 않는다.

---

## ② 구조

```
챕터 시작
 └─ 배경 공개
     ├─ 장소  → 전투 조건 + 우연 빈도(홀드 탭 신뢰도)
     ├─ 계절  → 환경 조건 상시 적용
     └─ 상황  → 특수 규칙 상시 적용
```

| 항목 | 내용 |
|------|------|
| 단위 | 챕터 |
| 역할 | 메카닉 조건 결정. 이야기 카드의 서술은 안 바꿈 |
| 태그와의 관계 | 독립. 태그는 카드 단위, 배경은 챕터 단위 |
| 확장 원칙 | 7스텝으로 안 되는 것을 배경에서 품는다 |

| 축 | 조절 대상 | 영향 범위 |
|----|----------|----------|
| **장소** | 전투 조건 + **우연 빈도 → 홀드 탭 신뢰도** | 전투 + 카드 흐름 |
| **계절** | 낮/밤 + 정보 공개 | 전투 조건 |
| **상황** | 미정. 철이 작성 예정 | — |

## ③ 스토리 팩 연동

```
오더 1: 다리 위의 서자들

배경: [아비뇽/시타델/오를레앙/파리] × [봄/여름/가을/겨울] = 16 조합
챕터1: [a/b/c/d/e/f] 중 1
챕터2: [A/B/C/D/E/F] 중 1
챕터3: [가/나/다/라/마/바] 중 1

총 조합: 16 × 6 × 6 × 6 = 3,456 런
스토리 팩 실물: 18개 (6+6+6)
```

같은 스토리 팩이 다른 배경에서 돌면 메카닉 조건이 달라져 체감이 바뀐다. 콘텐츠 확장 비용을 조합으로 푸는 구조.

## ④ 계절

챕터 시작 시 4계절 중 랜덤 1개 결정. 해당 챕터 전체 적용.

| 계절 | 효과 | 성격 |
|------|------|------|
| **봄** | 미정 | 중립 (양면적) |
| **여름** | 미정 | 중립 (양면적) |
| **가을** | 밤 전투 시 선제 허용 + 적 주사위 공개 (낮처럼 전투) | 유리 |
| **겨울** | 분기 정보 차단 ("?" 처리). 전투 영향 없음 | 불리 |

> **확률 분포:** 유리 25% / 중립 50% / 불리 25%

### 가을 상세

| 항목 | 내용 |
|------|------|
| **서사** | 맑은 하늘, 보름달. 추수 뒤 밝은 밤 |
| **효과 1** | 밤(짝수턴) 전투에서 선제 공격 정상 작동 (밤 스킵 규칙 무시) |
| **효과 2** | 밤 전투에서 적 주사위 결과 공개 ("?" 아닌 실제 면 표시) |
| **낮 전투** | 추가 효과 없음 (낮은 원래 선제 + 공개) |
| **개연성** | 중세 전쟁이 가을에 집중된 이유. 추수 뒤 식량 풍부, 도로 건조, 날씨 온화 |

### 겨울 상세

| 항목 | 내용 |
|------|------|
| **서사** | 눈보라, 정찰 불가. 시야 차단 |
| **효과** | 이야기 카드 분기 선택지 정보가 "?"로 표시. 효과를 모른 채 선택 |
| **전투** | 전투 자체에 영향 없음. 전투 진입 전 분기 판단만 방해 |
| **개연성** | 눈보라 속 정찰 불가. 보급 경로 차단으로 상황 파악 불능 |

### 공개 방식

계절 카드 뒷면 → 자동 뒤집기 연출. 랜덤이므로 뒤집기. 플레이어 조작 불필요.

## ⑤ 장소 (구체 풀 미정)

장소 = 고유 지명. 각 장소가 고유한 전투 조건 + 우연 빈도를 내장한다. 유형 분류(협로/평원/성채 등) 없음 — 장소 이름 자체가 조건을 결정.

| 항목 | 내용 |
|------|------|
| **형태** | 고유 지명 (예: 아브뉴 다리, 랭스 다리) |
| **전투 조건** | 장소마다 고유. 미정 |
| **우연 빈도** | 장소마다 고유. 우연 카드가 막 덱에 들어가는 비율을 결정 |
| **홀드 탭 신뢰도** | 우연이 많을수록 위장 카드가 많아져 신뢰도 하락 |

> 장소 풀은 오더 서사 설계 시 확정.

---

## ⑥ 상황 (미정)

> 상황 풀은 철이 작성 예정. 이전에 기재된 퇴각/역병/기근/강행군/야습/추격은 미확인 임의 작성분으로 삭제.

## ⑦ 설계 근거

**Q. 왜 배경이 필요한가?**
태그는 7스텝 호환만 허용. 공성, 역병, 강행군 같은 역사적 상황은 7스텝으로 표현 불가. 이걸 태그에 억지로 넣으면 7스텝 불변 원칙이 깨진다. 배경이 챕터 레벨에서 메카닉 조건을 깔면 태그는 보수적으로 유지하면서도 표현 폭이 넓어진다.

**Q. 왜 배경 × 스토리 팩 분리인가?**
같은 이야기가 다른 무대에서 벌어지는 구조. 실제 역사에서도 비슷한 전술적 상황이 다른 장소, 다른 시대에 반복된다. 이걸 구조적으로 가능하게 만든 것. 스토리 팩 18개로 3,456 런 조합이 나온다.

**Q. 배경이 서술을 안 바꾸면 어색하지 않나?**
오더 서사 안에서 스토리 팩이 만들어지므로, "다리 위의 서자들"이라는 큰 서사는 어떤 배경에서든 유지된다. 배경이 바뀌면 "아비뇽의 다리" "오를레앙의 다리"가 되는 것뿐이지 서사 구조가 안 깨진다.

**Q. 왜 4계절인가?**
중세 전쟁의 계절성을 반영. 역사적으로 가을이 전쟁 적기, 겨울이 비적기. 이 구조를 메카닉으로 풀었다.

**Q. 왜 계절은 Chapter 단위인가?**
Stage 단위면 같은 작전 안에서 계절이 바뀌는 서사적 모순. Chapter = 새 작전이므로 계절 변경이 자연스럽다.
