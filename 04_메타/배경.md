# META-BACKDROP: 환경 레이어

> 상태: 결정정합 (5-11 마디 박힘) · 의존: @META-BOOK-001, @STAGE-CARD-002, @COMBAT-DICE-001

> 5-11 마디 큰 정정:
> - 시간대 2종 (낮/밤) → 3종 (낮/경계/밤)
> - 시간대 = 페이즈 단위 진행 → 페이즈 시작 시간대 (R1) + 라운드별 변동
> - 라운드별 변동 결: 낮 → 경계 → 밤 → 경계 → 낮 → ...
> - 운명 페이즈 시간대 = 적의 자리 폐기 → 페이즈 흐름 결로 자연 따라감
> - 어휘 정정: "인도" → "의지" (의지 주사위 1종으로 합침)
> - 인격신/자연신 결 = 어휘만 (결산 결 같음, 5-10 박힘 살림)
> 상세: `DOCS/DESIGN/LOG/2026-05-11_의지·시간대·직업_큰정리.md`

## 정의

환경 = 장소(스테이지 단위 고정) + 날씨(스테이지 시작 시 결정) + 시간대(페이즈 시작 R1 + 라운드별 변동). 장소가 스테이지 정체성·특수 규칙을, 날씨가 정찰 조건을, 시간대가 의지 주사위 박힘 조건을 결정한다.

## 규칙

### 구조

```yaml
장소:    스테이지 단위 고정. 변주 무관. 작가가 박은 자리
날씨:    스테이지 시작 시 결정. 4종 랜덤 (잠정). 정찰에 영향
시간대:  페이즈 시작 시간대 (R1) + 라운드별 변동 (5-11 박힘)
         지상 페이즈: 1=낮 / 2=밤 / 3=낮 / 4=밤 (시작점만)
         미궁 페이즈: 1=밤 / 2=낮 / 3=밤 / 4=낮
         경계 페이즈: 챕터 시작 시 랜덤 (시작점)
         라운드 진행: 낮 → 경계 → 밤 → 경계 → 낮 → ...
         운명 페이즈: 페이즈 흐름 결 자연 따라감 (5-11 박힘)
신 결:   지상 = 인격신 / 미궁 = 자연신 (어휘 분리. 결산 결 같음)
가호:    유물 결 (덱 빌딩 / 환경 레이어 — 펜딩, 다음 마디)
```

### 장소

```yaml
정의: 스테이지 = 고유 지명 + 특수 규칙 (있을 수도, 없을 수도)
변주_무관: 같은 스테이지의 다른 변주(인격)에서 장소 동일
표기: "라키아의 들개" → 장소 = 라키아

특수_규칙: 장소별 다름. 카드 시스템·정찰·전투 조건 변경 가능
```

### Order 1 장소 특수 규칙

```yaml
라키아: 특수 규칙 없음 (튜토리얼 결)
미궁:   우연 카드 ? 해제 — 우연이 정찰 시 전투 또는 사건 중 무엇으로 노출
```

### 날씨

```yaml
배정: 스테이지 시작 시 1종 결정 (잠정 — 랜덤)
적용: 해당 스테이지 일반 페이즈 3개 전체

4종:
  맑음:   효과 없음
  흐림:   정찰 시 1장만 볼 수 있음 (3장 중 1장 노출)
  안개:   정찰은 하지만 뒷면이 모두 ?로 처리 (종류 식별 불가)
  악천후: 정찰 스킵. 시스템이 임의로 1장 집고 1장 버림

운명_페이즈: 날씨 영향 없음 (운명 카드는 자동 공개)
```

### 시간대 (5-11 박힘)

```yaml
3종:        낮 / 경계 / 밤

페이즈 시작 시간대 (R1):
  지상: 1 페이즈 = 낮 / 2 = 밤 / 3 = 낮 / 4 = 밤
  미궁: 1 페이즈 = 밤 / 2 = 낮 / 3 = 밤 / 4 = 낮
  경계: 챕터 시작 시 랜덤 (낮밤 또는 밤낮 흐름)
  → 페이즈 = R1 시간대만 결정. 라운드 진행으로 변동.

라운드별 흐름 (5-11 박힘):
  낮 → 경계 → 밤 → 경계 → 낮 → 경계 → 밤 → ...
  → 1 라운드마다 시간대 1회 변동
  → 자기 시간대 ↔ 반대 시간대 번갈아 박힘

자기 시간대:
  지상 = 낮 시간대 (자기 시간대 = 낮)
  미궁 = 밤 시간대 (자기 시간대 = 밤)
  경계 = 경계 시간대 (자기 시간대 = 경계)

영향:
  의지 주사위 박힘 조건 (@COMBAT-DICE-001)
  시간대 보정 (순서 점수, @COMBAT-STRUCT-001)
  
운명 페이즈 시간대 (5-11 정정):
  옛 결 (5-10): 적의 자리 (지상 영웅 = 밤 / 미궁 재앙 = 낮)
  새 결 (5-11): 페이즈 흐름 결 자연 따라감 (적의 자리 폐기)
                지상 영웅 운명 (4 페이즈, 시작 = 밤): R1 밤 → R2 경계 → R3 낮 → R4 경계
                → 운명 시작 = 반대 시간대 자연 박힘 (영웅 결 약함 자리)
                → 옛 결과 *결의 자리 같음*. 단 결 자연 박힘.
```

### 신 결 (5-10 박힘 — 어휘만 분리)

```yaml
지상 신:    인격신 결
            그리스 올림포스 결 (인격 박힌 신, 영웅과 대화 가능)
            결산 결: 신이 *결 박은 자리*에 응답. 결 박힌 만큼 응답.
            카타스테리스모스 정합: 영웅이 *별*이 됨 = 인격으로 박힘 (자연)

미궁 신:    자연신 결
            자연 결 (땅·어둠·바다·동굴 — 인격 X)
            결산 결: 결 박는 자리 X. *결 자체가 신*.
            멸절 정합: 재앙 = 자연으로 돌아감 (자연)

경계:       신앙 무관 (펜딩)
            자기 결로 빛남 (경계 면 박힘 결)

시스템 결:
  결산 자리 = *같음* (어휘만 분리, 의지 주사위 1종 결로 박힘)
  본인 박은 결: "어휘만 분리"
```

### 가호 (유물) 결 — 펜딩

```yaml
본인 박은 결 (5-10):
  "전투 층 사이에 덱 빌딩 레이어 혹은 환경 레이어로 동작"
  슬더스 유물 결 정합
  예: "새벽의 가호 — 첫 라운드만 보유 인물 공격력 +2"

펜딩 자리 (다음 마디):
  - 출처 (사건/우연/운명 카드 / 덕목 / 시작 시드)
  - 효과 자리 (3 패러미터 / 면 / 주사위 수 / 시간대 보정 등)
  - 시간 결 (매 라운드 / 페이즈 / 챕터 / Order)
  - 카드 시스템 ↔ 가호 정합 (별도 레이어)
```
